# qa-carryover.md — QA工程への申し送り事項

Phase A/B のエージェントが作業中に気づいた**未解決の不整合・要確認事項**を集約する。
**Phase D の QA エージェントは、担当業界の節を必ず読み、すべてに対処すること。**
対処した項目には「→ 対処済み（内容）」を追記する。

---

## 全業界共通

### C-1. 官公庁サイトの403で保留になっている数値の埋め戻し
Phase A の時点では `chusho.meti.go.jp` / `meti.go.jp` が WebFetch で403になり、
**中小企業庁「産業別規模別企業数」を本文に書けなかった業界がある**（特に小売業・卸売業・製造業）。
その後 `common/base-statistics.md` にデータを整備済み。
**各業界の `01_overview.md` の「中小企業の特徴」節に、自業界の企業数を出典付きで追記すること。**
統計分類と業界区分が一対一対応しない点（`base-statistics.md` の注意表）を必ず添えること。

### C-2. 経産省系PDFで未取得のまま残っている出典
`19_sources.md` に「取得不可」と記録されている資料は、
`common/base-statistics.md` §3 の curl 手順で**再取得を試みること**。
それでも取れない場合は推測で数値を書かず、取得不可のまま記録を残す。

## manufacturing（製造業）

### M-1. 機能数が指示の9から10に増えている（妥当と判断・対応不要）
Phase A で**③生産技術（工程設計）機能**を追加。見積時の工程設計・標準時間・治具・
NCプログラムの担い手が不在になるため。**この10機能を正とする。**

### M-2. 日本標準産業分類PDFの公表日が「不明」
`19_sources.md` に published_date 不明として記録。
令和5年7月改定が反映されているかの確認が申し送られている。**QAで確認すること。**


### M-3. 頻度語彙の逸脱が1か所 ★要修正
`05_departments.md` ①営業の D 表 `E-1-6` に **「随時」** という表記がある。
「随時」は `methodology.md` §5 の頻度語彙表に存在しない。
同じ業務を F 表側では「受注時／案件発生時／トラブル発生時」と表現しており表記が揺れている。
**QAで §5 の語彙に統一すること。**

### M-4. `03_company-structure.md` の⑨機能定義に「原価計算」が欠けている
- `03` 3-3 の⑨定義は「売上・仕入・経費を記録し、請求・入金・支払を管理し、資金繰りと決算を行う」
- 一方 `03` 3-4 の受け渡し表には「⑨経理 → ①② 原価実績、粗利情報（月次）」がある
- `05` では原価計算を⑨の中核業務として詳述している
**QAで `03` 側の定義文に原価計算を補って整合させること。**

### M-5. 設備保全の法令対応ルートの読みが分かれる（対処済み・確認のみ）
⑧設備保全の I 図は「⑩人事・総務（法令の要求）→ 法定点検の管理」だが、
⑧の J（社外関係者）では検査業者・行政と直結している。
B-1継続側で「法令対応の**全体管理**は⑩、検査の手配・実施は⑧」と分担を明記済み（既存と矛盾なし）。
**QAで⑧側の記述と齟齬がないか確認するだけでよい。**

### R-1. 中小企業庁・経産省の数値が未記載
→ C-1 で対応。小売業：中小527,138社・大企業2,073社（2021年）。

### R-2. モデル企業の「営業利益はほぼ±0」という設定
説明用モデルとして置いた数値だが、これを**業界一般の姿と誤読されないよう**

「中小食品スーパーは儲からない」という評価に読めないか）。

### R-3. 機能の境界が重なる箇所3件（B-1継続側で整理済み・QAは確認のみ）
中小小売では一人が複数機能を兼ねるため、機能の切れ目が曖昧になる箇所がある。
いずれも矛盾ではなく、B-1継続側で切り分け方針を明記済み。**QAは読者が混乱しないか確認するだけでよい。**

1. **⑧売場担当の値付け と ⑩バックヤードの値付け**（どちらもステップ A-6 を指す）
   → 生鮮・惣菜は加工と一体なので売場担当、グロサリーのプライスカードは後方作業、という担当差
2. **⑧入荷品の受け取り と ⑩荷受・検品・検収**
   → 小規模店では売場担当が荷受・検品も兼ねるため「現場では一続きの作業」と明示
3. **⑪清掃・保安 と ⑦店舗の安全衛生管理・⑩廃棄物処理**
   → 「店舗全体を対象とする作業を⑪に、自部門・自持ち場の作業を各機能に置く」という方針

年齢確認はたばこが**第4条**（罰則は第5条）、酒類が**第1条第4項**。e-Gov で条文どおり確認済み。

**QAで他ファイルに異なる条番号が書かれていないか横断確認すること。**
