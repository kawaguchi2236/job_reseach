# common/tools — 調査用ツール

Python標準ライブラリのみで動きます（外部パッケージ不要）。

## PDFからテキストを取り出す

官公庁は統計の実数や告示の全文を**PDFにしか置いていない**ことが多いため、これが無いと
一次情報に到達できません。`pdftotext` / `pypdf` 等は**このMacに入っていません**が、
以下のスクリプトで代替できます。

```bash
TOOLS="<industry-research>/common/tools"

# 本文をそのまま読む
python3 "$TOOLS/pdftext.py" file.pdf | head -60

# 統計表を行・列の配置ごと復元する（座標でグルーピング）
PYTHONPATH="$TOOLS" python3 "$TOOLS/pdftable.py" file.pdf | head -40
```

### 実証済み
公正取引委員会の取適法リーフレット（`https://www.jftc.go.jp/file/toriteki_leaflet.pdf`）は
Batch 1 で「CIDフォントのため抽出不可」と判断されていましたが、**本ツールで全文が読めます**。
国土交通省の報酬告示全文・原状回復ガイドライン・不動産業統計集の統計表も取得実績あり。

### 仕組み（うまく動かないときの手がかり）
1. オブジェクトを収集する
2. **`/Type /ObjStm` を zlib 展開して中のオブジェクトも展開する**
   … PDF 1.5 以降では必須。ここを飛ばすと**抽出結果が空**になる
3. `/ToUnicode` CMap を解析して文字コードを対応付ける
4. `Tf` / `Tm` / `Td` / `TJ` / `Tj` を走査してテキストを拾う

**数値が全部欠落するときの原因**：数値セルは WinAnsiEncoding の単純フォントで
`(1,234)Tj` の形で入っていることが多く、**リテラル `( )` を latin1 でも拾わないと
数字だけ消えます**（見出しは取れるのに中身が空、という症状になる）。

`pdftable.py` は `Tm` / `Td` の座標を使い、**Y座標ごとに行をまとめ、X座標で並べる**ことで
統計表のレイアウトを復元します。

## 使い方の原則
- PDFを出典にする場合、**本ツールで実際に中身を読んでから** `19_sources.md` に記載すること
- それでも読めない場合のみ「所在確認のみ・内容未読」と明記する
