## 6-1. 【最重要】卸売業の人の流れの中心 ——「外に出る人」と「中にいる人」

### 6-1-1. なぜこの2つに分かれるのか

卸売業では、**同じ1件の注文に対して、必ず2種類の人が関わります。**

```
 ┌──────────────────────┐        ┌──────────────────────┐
 │  外に出る人（外勤）           │        │  中にいる人（内勤）           │
 │  ＝ 営業担当                  │        │  ＝ 業務担当（営業事務）      │
 │                              │        │                              │
 │  ・得意先の店・事務所へ行く   │        │  ・事務所にいる               │
 │  ・人と会って話す             │◀──▶│  ・伝票とデータを扱う         │
 │  ・売場を見る                 │  連絡  │  ・電話とFAXを受ける          │
 │  ・値段の話をする             │        │  ・システムに入力する         │
 └──────────────────────┘        └──────────────────────┘
```

**なぜ分かれるのか**（`03_company-structure.md` §3-2-3 の再確認）
営業担当が得意先を訪問している間も、注文は電話・FAX・EDIで会社に届き続けます。
注文は**その日のうちに処理しないと翌朝の配送に間に合いません**。
外出中の人間にはこれができないため、社内に処理専門の人を置きます。【Typical】

### 6-1-2. 2つの役割の「情報の持ち方」が違う

ここが、人の流れを理解するうえで最も大事な点です。

| | **営業（外勤）** | **内勤（業務）** |
|---|---|---|
| 持っている情報 | 得意先の**人**の情報（店主の性格、店の景気、他社の動き、売場の様子、支払いの雰囲気） | 得意先の**数字**の情報（受注履歴、欠品履歴、売掛金残高、請求差異の履歴） |
| 情報の形 | 頭の中・手帳・記憶（形になりにくい） | システム・帳票（形になっている） |
| 誰から得るか | 得意先の店主・バイヤー、同業者、仕入先の営業 | システム、他部署、得意先からの電話 |
| 誰に渡すか | 内勤、商品部、経理、社長 | 営業、物流、商品部、経理 |

> **【Inference】** 営業が持っている情報は**形になっていない**ため、
> 会社の中で共有されるかどうかは、営業本人が話すかどうかに左右されます。
> これが後述する「属人化しやすい構造」（6-7）の出発点になります。

### 6-1-3. 営業と内勤が1日に何度も行き来する場面【Typical】

| 場面 | 誰から誰へ | 何が渡るか |
|---|---|---|
| 朝、注文が入った | 内勤 → 営業 | 「○○商店から昨日FAXで注文が来ています。数量が普段の3倍ですが確認しますか」 |
| 在庫が足りない | 内勤 → 営業 | 欠品情報。「20kg注文ですが12kgしかありません」 |
| 得意先への説明 | 営業 → 得意先 | 「12kgは明日、残り8kgは明後日で大丈夫ですか」 |
| 得意先の回答 | 営業 → 内勤 | 「了解が取れました。12kgで受注を確定してください」 |
| 特売の価格 | 営業 → 内勤 | 「この商品は今週だけ特売価格を適用してください」 |
| 請求の差異 | 内勤・経理 → 営業 | 「先月分、得意先の検収と1ケース差があります。確認してください」 |
| 入金の遅れ | 経理 → 営業 | 「○○商店、今月の入金がまだです。訪問時に様子を見てきてください」 |

> **【Varies】** この行き来を、電話でするか、社内チャットでするか、
> 紙のメモでするか、システム上のメモ欄でするかは会社によって異なります。

### 6-2-2. 「誰と誰がよく話すか」の一覧

| 組み合わせ | 何について話すか | 頻度 |
|---|---|---|
| 営業 ⇔ 内勤 | 受注内容、欠品、納期、売価、得意先の要望 | 常時（1日に何度も） |
| 営業 ⇔ 商品部（バイヤー） | 特売の仕入価格、新商品、販売見込み、在庫の売り切り依頼 | 日次〜週次 |
| 営業 ⇔ 経理（与信担当） | 入金遅れ、与信限度、得意先の経営状況 | 月次／トラブル発生時 |
| 内勤 ⇔ 商品部 | 欠品情報、緊急発注の依頼、入荷予定の確認 | 日次 |
| 内勤 ⇔ 物流 | 出荷指示、締切後の追加注文、誤出荷の確認 | 日次 |
| 商品部 ⇔ 物流 | 入荷予定、入荷不備、保管場所、期限接近在庫 | 日次 |
| 物流 ⇔ 経理 | 受領書の受け渡し、返品伝票、配送費 | 日次〜月次 |
| 経理 ⇔ 社長 | 資金繰り、支払、与信の重大判断 | 週次〜月次 |
| 社長 ⇔ 全機能 | 取引方針、価格方針、トラブルの最終判断 | 常時 |

> **【Varies】** 中小卸売業では「部署を通す」という形式よりも、
> **必要な人が直接話す**ことが多く見られます。45名規模では物理的に全員が近くにいるためです。【Inference】

### 6-2-3. 人が「ものを渡す／情報を渡す」中継点

卸売業には、**情報が必ず通る3つの中継点**があります。

| 中継点 | 誰か | なぜ中継点になるのか |
|---|---|---|
| **内勤（業務担当）** | 受注担当 | 外部からの注文はすべてここに集まり、ここから出荷指示に変わる |
| **物流部長** | 倉庫の責任者 | 出荷指示を実際の作業に割り付ける。現物が通る唯一の場所 |
| **経理（売掛担当）** | 債権担当 | 売上・請求・入金・与信の情報がすべてここに集まる |

> **【Inference】** この3か所のいずれかが止まると、会社全体の流れが止まります。
> 中小企業ではこれらを1〜2名で担っていることが多く、
> 休暇・退職時の引き継ぎが実務上の大きな論点になります【Varies】。

## 6-3. 社外の人の関係図

### 6-3-1. 卸売業は「人と人の間」に立つ仕事

```
 【仕入先側の人】                【自社の人】              【得意先側の人】

 メーカーの営業担当 ◀──────▶ バイヤー
 メーカーの営業所長              商品部長  ◀──▶ 社長
 一次卸の担当者                      ▲
 メーカーの物流担当 ◀──────▶ 物流部長
                                     │
 メーカーの品質保証 ◀──────▶ 品質・衛生担当
                                     │
                                  営業担当 ◀────▶ 店主（個人商店）
                                     │            ◀────▶ バイヤー（スーパー本部）
                                     │            ◀────▶ 店長（スーパー各店）
                                     │            ◀────▶ 料理長・仕入担当（飲食店）
                                     │            ◀────▶ 栄養士（給食・福祉施設）
                                  内勤 ◀───────▶ 得意先の発注担当・事務
                                     │
                                  ドライバー ◀───▶ 得意先の荷受担当・店舗スタッフ
                                     │
                                  経理 ◀────────▶ 得意先の経理担当
```

### 6-3-2. 社外の相手ごとの関係

#### ① 得意先（売る相手）

| 相手 | 誰が主に接するか | 何を話すか |
|---|---|---|
| **個人商店の店主** | 営業担当 | 注文、売れ筋、新商品、世間話、資金の相談まで及ぶことがある |
| **食品スーパーの本部バイヤー** | 営業担当＋営業部長 | 定番採用、特売企画、価格、販促、センター納品条件 |
| **食品スーパーの店長・売場担当** | 営業担当 | 日々の追加注文、売場の状況、欠品のクレーム |
| **飲食店の料理長・オーナー** | 営業担当 | メニュー変更に伴う食材、価格、緊急の追加注文 |
| **給食・福祉施設の栄養士** | 営業担当 | 献立に合わせた食材、規格・アレルギー情報、納品時間 |
| **得意先の発注担当・事務** | 内勤 | 日々の注文、数量確認、納品日の変更 |
| **得意先の荷受担当** | 配送ドライバー | 納品場所、荷降ろし、受領印、破損の申し出 |
| **得意先の経理** | 経理（売掛担当） | 請求金額の確認、入金予定、差異の照合 |

> **【Typical】** 得意先側にも「**決める人**」と「**日々発注する人**」がいます。
> 価格や採用を決めるのはバイヤー・店主、日々の注文を出すのは売場担当・事務です。
> **営業は前者と、内勤は後者と話す**——この対応関係が、卸売業の社外接点の基本形です。

#### ② 仕入先（買う相手）

| 相手 | 誰が主に接するか | 何を話すか |
|---|---|---|
| **メーカーの営業担当** | バイヤー（商品部） | 仕入価格、新商品、販促提案、特売対応、納期 |
| **メーカーの営業所長・部長** | 商品部長・社長 | 年間取引条件、リベート条件、取扱範囲、特約店契約 |
| **一次卸・商社の担当者** | バイヤー | 仕入価格、在庫の融通、緊急手配 |
| **メーカーの物流担当** | 物流部長 | 納品時間、パレット、荷姿、入荷不備の連絡 |
| **メーカーの品質保証担当** | 品質・衛生担当（商品部長兼務） | 規格書、表示、クレーム時の原因調査、回収対応 |

> **【Typical】** メーカーの営業担当は、卸売業者にとって「仕入先」であると同時に、
> **販促情報・商品情報を運んでくる情報源**でもあります。
> 「新商品が出る」「あの店がこの商品を大量に採用した」といった情報は、
> メーカー営業からバイヤーへ、バイヤーから自社営業へ、自社営業から得意先へ、と流れます。

#### ③ その他の社外関係者

| 相手 | 誰が接するか | 内容 |
|---|---|---|
| 運送会社（路線便・チャーター） | 物流部長 | 集荷時刻、運賃、事故・遅延 |
| 倉庫会社（外部倉庫を使う場合） | 物流部長・商品部 | 保管料、入出庫依頼、在庫照合 |
| 信用調査会社 | 経理（与信担当）・社長 | 得意先の信用調査報告 |
| 銀行 | 社長・経理部長 | 借入、当座貸越、手形・でんさいの取扱い |
| 税理士・会計事務所 | 経理部長・社長 | 月次決算、税務申告 |
| 保健所・都道府県の担当部署 | 品質・衛生担当、総務 | 営業許可・届出、立入検査 |
| 業界団体・組合 | 社長・商品部長 | 業界情報、共同購買、講習 |

## 6-4. 「誰が決めるのか」を整理する道具 ——RACI

### 6-4-1. RACIとは（初心者向け）

**RACI（レイシー）**
→ 1つの仕事について、**関わる人の関わり方を4種類に分けて書き出す整理の仕方**です。
　4つの英単語の頭文字を取っています。

| 記号 | 英語 | 日本語 | どういう人か |
|---|---|---|---|
| **R** | Responsible | **実行する人** | 実際に手を動かす人。「やる人」 |
| **A** | Accountable | **承認・責任を持つ人** | 「やっていい」と決める人。結果の責任を負う人。**原則1人** |
| **C** | Consulted | **相談される人** | 決める前に意見を聞く相手 |
| **I** | Informed | **報告を受ける人** | 決まった後に知らされる人 |

**なぜこの整理が役に立つのか**
「この仕事は営業部の仕事です」という言い方では、
**手を動かすのが営業なのか、決めるのが営業なのか**が分かりません。
RACIで分けると、「営業が案を作り（R）、社長が承認し（A）、経理に意見を聞き（C）、
物流には決定後に伝える（I）」という形で、人の動きが見えるようになります。

**実務例【Example】**
> 「B商店の与信限度額を300万円から500万円に上げる」という決定
> - **R（実行）**：経理の与信担当が、信用調査報告と入金履歴を集めて案を作る
> - **A（承認）**：社長が「上げてよい」と決める
> - **C（相談）**：営業担当に「最近の店の様子はどうか」を聞く
> - **I（報告）**：内勤に「限度額が変わった」と伝え、システムに反映してもらう

> **注意**：RACIは**整理のための道具**であって、法律上の決まりではありません。
> 実際の中小卸売業で「うちのRACIはこうです」と文書になっていることは多くありません【Varies】。
> ここでは「誰が決めているか」を読み解くための見方として使います。

### 6-4-2. 中小企業でRACIを見るときの注意

> **【Typical】** 中小卸売業では、**同じ人がRとAを兼ねている**ことがよくあります。
> 例：社長が自ら仕入先と価格交渉し（R）、その場で決める（A）。
> これは「役割が未分化」という事実であって、良し悪しの話ではありません。
> 大企業のように分かれていないことを前提に読んでください。

## 6-5. 【中核】主要な意思決定は誰が決めるのか

> 以下はモデル企業A食品商事（架空）を想定した**典型例**です。【Typical】【Example】
> 実際の権限配分は会社によって大きく異なります【Varies】。
> 「A（承認）」の欄が、その決定の実質的な持ち主です。

### 6-5-1. 意思決定一覧表（簡易RACI）

| # | 意思決定 | R（実行） | **A（承認）** | C（相談） | I（報告） | 頻度 |
|---|---|---|---|---|---|---|
| 1 | **得意先別売価の決定**（定番品） | 営業担当 | **営業部長**（大口は社長） | 商品部（仕入価格）、内勤（登録） | 内勤（価格マスタ登録） | 案件発生時／年次（価格改定時） |
| 2 | **特売・大口の売価決定** | 営業担当 | **社長 または 営業部長＋商品部長** | 商品部（特売仕切）、経理（採算） | 内勤、物流（数量準備） | 案件発生時 |
| 3 | **値引きの可否**（請求時の調整） | 営業担当 | **営業部長**（金額が大きければ社長） | 経理（請求への影響） | 内勤、経理 | トラブル発生時／請求時 |
| 4 | **与信限度額の設定・変更** | 経理（与信担当） | **社長** | 営業担当（得意先の実態）、信用調査会社 | 内勤（システム反映）、営業 | 案件発生時／年次・半期（定期見直し） |
| 5 | **新規取引の可否（口座開設）** | 営業担当＋経理 | **社長** | 経理（与信）、商品部（品揃え対応可否）、物流（配送圏） | 内勤（得意先マスタ登録） | 案件発生時 |
| 6 | **与信超過時の出荷可否** | 内勤（システム警告を受ける） | **経理部長 または 社長** | 営業担当（入金見込み） | 内勤、物流 | トラブル発生時 |
| 7 | **発注量の決定**（定番の補充） | バイヤー | **バイヤー本人**（＝RとAが同一） | 内勤（欠品状況）、営業（販売見込み） | 物流（入荷予定） | 日次 |
| 8 | **発注量の決定**（特売・季節・大口） | バイヤー | **商品部長 または 社長** | 営業（販売見込み）、経理（資金） | 物流、内勤 | 案件発生時 |
| 9 | **仕入先の選定・変更** | バイヤー | **商品部長＋社長** | 営業（品質・評判）、物流（納品条件） | 経理（支払条件） | 案件発生時／年次 |
| 10 | **年間取引条件・リベート条件の合意** | 商品部長 | **社長** | バイヤー、経理 | 全機能 | 年次 |
| 11 | **欠品時の代替提案・分納の決定** | 内勤（起案）→営業（得意先と調整） | **営業担当**（得意先の了承が実質の決定） | 商品部（入荷予定）、物流（出荷可否） | 内勤、物流 | 日次／トラブル発生時 |

### 6-5-2. この表から読み取れること

| 気づき | 内容 |
|---|---|
| **社長のAが多い** | 22件のうち、社長が承認者になるものが9件。**お金と取引関係に直結する判断は社長に集中する**【Typical】 |
| **日次の判断は現場が持つ** | 補充発注（#7）、欠品対応（#11）、配送編成（#20）は、その場で決まらないと業務が止まる。だから現場が決める |
| **「営業が決める」ものは価格と得意先対応** | 売価・値引き・返品受入・クレーム補償。**得意先との約束に関わる判断は営業側にある**【Typical】 |
| **経理は「止める」判断の起案者** | 与信限度、出荷停止、支払。経理は数字を握っているため、**危険を最初に検知して起案する立場**になる |
| **相談（C）の相手は必ず営業か商品部** | 決めるために必要な情報（得意先の実情／仕入価格と入荷予定）を持っているのがこの2機能だから |

> **【Inference】** つまり卸売業の意思決定は、
> **「情報を持っている人（営業・商品部）」と「決める人（社長・部長）」が分かれている**構造です。
> 情報が正しく上がらないと、決める人は判断できません。
> だから6-1で見た「営業と内勤の連絡」が、組織全体の判断の質を左右することになります。

## 6-6. 中小卸売業の実態 ——社長が兼ねているもの

### 6-6-1. 社長＝バイヤー＋与信判断者

> **【Typical】** 中小卸売業では、社長が次の3つを同時に担っていることが多く見られます。

```
          ┌─────────────────────────┐
          │           社  長                        │
          ├─────────────────────────┤
          │ ① 経営者として …… 方針・投資・人事       │
          │ ② バイヤーとして … 主要商品の仕入価格交渉 │
          │ ③ 与信判断者として… 取引可否・限度額・停止 │
          │ ④ 営業として ……… 主要得意先の担当       │
          └─────────────────────────┘
```

**なぜ社長がバイヤーを兼ねるのか**【Inference】
卸売業の利益は**仕入価格と売価の差（粗利）**から生まれます。
仕入価格が1%変われば粗利が大きく動くため、**仕入条件の決定は経営判断そのもの**です。
また、メーカー側も年間の取引条件を決める場には役員クラスを出してくるため、
相手方と同格の立場で交渉できる人が必要になります。

**なぜ社長が与信判断を兼ねるのか**【Inference】
与信の判断は「この相手に、代金未回収のまま何百万円分の商品を渡してよいか」という判断です。
判断を誤れば貸倒れとなり、**その損失は粗利の何倍もの売上に相当します**
（計算は `08_money.md` で扱います）。
社内で最終的にその損失を引き受けるのは経営者であるため、判断も経営者に集まります。

**なぜ社長が主要得意先の営業を兼ねるのか**【Typical】
得意先側も、取引条件を決めるのは店主・社長・役員です。
**相手の決定権者と同じ立場の人が話す**ほうが話が早いため、
「社長同士で会う」関係が主要取引先ごとに存在することが多くあります。

### 6-6-2. 社長以外の兼務（再掲・人の視点から）

| 兼務している人 | 兼ねている機能 | 人の関係としてどう現れるか |
|---|---|---|
| 営業担当 | 営業＋小口配送＋集金 | 得意先にとって「注文も、届けるのも、集金も、同じ人」になる |
| 経理の売掛担当 | 経理＋与信＋督促 | 得意先の経理担当とも、社内の営業とも話す立場になる |
| バイヤー | 仕入＋在庫管理＋販促企画 | メーカー営業・自社営業・物流の三方向と日常的に話す |
| 物流部長 | 物流＋倉庫の衛生管理責任 | 保健所の立入時の応対者にもなる |
| 業務部長 | 内勤の統括＋マスタ管理＋受注締めの判断 | 締切後の注文を受けるか否かを日々判断する |

> **【Varies】** どの兼務が起きるかは会社によって異なります。
> 共通しているのは「**機能は必ずあるが、担当する人が専任とは限らない**」という点です。

## 6-7. 属人化しやすい構造 ——事実としての記述

> ここは**評価や改善提案ではなく、卸売業という仕事の構造として何が起きるか**を記述します。

### 6-7-1. なぜ得意先との関係が営業個人に紐づくのか

卸売業の営業は、同じ得意先を**何年も継続的に訪問**します。
モデル企業では営業1人あたり約32社を担当し、それぞれを定期的に回ります【Example】。

この繰り返しの中で、次のような情報が営業個人に蓄積します。

| 蓄積する情報 | 具体例 |
|---|---|
| 相手の好み・習慣 | 「この店主は電話よりFAXを好む」「木曜の午後は店が空いている」 |
| 商品の使い方 | 「この飲食店はこの調味料を業務用サイズで使う。小容量は要らない」 |
| 過去の経緯 | 「3年前にこの商品で品質クレームがあり、今も別メーカーを使っている」 |
| 価格の経緯 | 「この価格は5年前の取引開始時に決めたもの。触れると話がこじれる」 |
| 支払いの傾向 | 「この店は毎月2〜3日遅れるが、必ず入る」 |
| 人間関係 | 「息子さんが後を継ぐ予定」「同業のX社の営業とも付き合いがある」 |

### 6-7-2. この情報の性質

```
 【システムに残る情報】              【営業個人に残る情報】

  受注履歴                            なぜその注文が増えたか
  売掛金残高                          なぜ支払いが遅れているか
  欠品の回数                          欠品でどれだけ信用を損ねたか
  売価                                その売価になった経緯
  訪問予定                            訪問時に何を話すべきか
```

> **【Inference】** 左側は**記録として残る**ため、誰でも見られます。
> 右側は**会話の中にしか存在しない**ため、本人が話さない限り他の人は知り得ません。
> 得意先との関係が営業個人に紐づくのは、この右側の情報が仕事の成否を左右するためです。

### 6-7-3. 属人化が実務にどう効くか【Typical】

| 場面 | 何が起きるか |
|---|---|
| 担当営業が休んだ日 | 得意先から「いつもの人は？」と聞かれる。代理が対応しても細かい経緯が分からない |
| 担当が変わるとき | 引き継ぎ訪問を行い、前任者が同行して紹介する慣行がある |
| 担当営業が退職するとき | 得意先が「担当が変わるなら取引先も見直す」と考えることがある（帳合が動く可能性） |
| 新規の営業が入るとき | 既存得意先の経緯を知らないため、価格や返品の扱いで過去と違う対応をしてしまうことがある |
| 内勤が代わるとき | 「この得意先はケース単位、この得意先はバラ単位」といった発注の癖が分からず、受注ミスが起きやすい |

> **【Varies】** 属人化の程度は、得意先の業態によって差があります。
> 個人商店・飲食店の比重が高い卸売業ほど個人の関係が濃く、
> EDIで大量の定型注文を受ける量販店中心の卸売業では相対的に薄くなる傾向があります【Inference】。

> **本資料の立場**：属人化は「卸売業が**人と人の継続的な関係**の上に成り立っている」ことの
> 裏返しとして生じる構造です。本資料はこれを事実として記述するにとどめ、
> 良し悪しの評価や対処の提案は行いません。

## 6-9. ヒトの流れの「詰まりやすい場所」【Inference】

> ここも事実の記述であり、対処の提案は行いません。

| 場所 | なぜ情報が滞りやすいか |
|---|---|
| **営業 → 社内** | 営業は日中社外にいる。得意先から聞いた情報（値上げの予告、他社の動き、経営の異変）が社内に届くのは帰社後になる |
| **内勤 → 営業** | 営業が外出中は電話がつながらないことがあり、欠品の判断が遅れると出荷締切に間に合わなくなる |
| **物流 → 内勤・経理** | 受領書という**紙が戻ってくるまで**、納品の完了が確認できない取引形態がある【Varies】 |
| **経理 → 営業** | 入金遅れの情報が経理に見えるのは締め後。営業が得意先の異変に気づくより後になることがある |
| **仕入先 → バイヤー → 営業 → 得意先** | メーカーの価格改定情報は、この4段階を経て得意先に届く。段階が多いほど伝達に時間がかかる |

## この章のまとめ

1. 卸売業のヒトの流れの中心は、**「外に出る人（営業）」と「中にいる人（内勤）」の分業と連絡**である。
2. 営業は得意先の**人の情報**を持ち、内勤は**数字の情報**を持つ。両者が合わさって1件の注文が処理される。
3. 社外の相手は、得意先側にも仕入先側にも**「決める人」「日々やり取りする人」「荷を扱う人」「払う人」**がいて、
   それぞれに自社の別の人が対応している。
4. 意思決定を **RACI（実行・承認・相談・報告）** で見ると、
   **お金と取引関係の判断は社長に集まり、日次の判断は現場が持つ**という配分が見える。
