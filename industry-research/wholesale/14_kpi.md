# CHAPTER 14　KPI・数字 ——卸売業は何を見て判断しているのか

**対象**：日本国内の中小卸売業
**前提**：`12_business-model.md`（収益構造）／`08_money.md`（カネの流れ）を読んでいること
**最終更新**：2026-09-16

> ### このファイルの方針
>
> 各KPIについて、**名称／意味／計算方法／誰が見るか／なぜ重要か**を書きます。
>
> **数値の目安については、出典を示せるもの以外は `【Varies】` とし、
> 「一般的に○%程度」といった根拠のない水準は示しません。**
> 卸売業は扱う商材・業種・得意先構成によってあらゆる数値が変わるため、
> 業界横断で通用する基準値はほとんど存在しないからです。
> 実務では、**自社の過去の数値との比較**と、**自社内の得意先間・商品間の比較**に使われます。【Typical】

---

## 14-0. KPIとは何か、なぜ必要か

**KPI（ケーピーアイ：Key Performance Indicator、重要業績評価指標）**
→ 「今、うまくいっているかどうか」を判断するために継続して見る数字のこと。
→ 実務例：「今月の売上高」「今月の粗利率」「在庫回転率」「欠品件数」など。

**なぜ卸売業でKPIが重要なのか**【Inference】

`12_business-model.md` で見たとおり、卸売業は**粗利率が低く、在庫と売掛金に資金が固定される**構造です。
この構造では、

- 売上が伸びても、粗利率が落ちれば利益は減る
- 粗利が出ていても、在庫が増えれば資金は減る
- 資金が回っていても、回収できなければすべて損失になる

という具合に、**1つの数字だけを見ていると必ず判断を誤ります。**
だから卸売業では、**売上・粗利・在庫・債権の4つを同時に見る**のが基本になります。

```
【卸売業の4つの見るべき軸】

        売上         ←→         粗利
   （どれだけ売ったか）     （いくら残ったか）
          │                      │
          └──────┬──────┘
                    │
        在庫         ←→         債権
   （いくら寝ているか）     （いくら回収できていないか）

  この4つは互いに引っ張り合う。
  ・欠品をなくそうとすれば在庫が増える
  ・売上を伸ばそうとすれば与信が緩み、債権リスクが増える
  ・粗利率を守ろうとすれば売上が落ちる
```

## 14-1. 売上に関するKPI

### 14-1-1. 売上高

| 項目 | 内容 |
|---|---|
| **意味** | 一定期間に商品を販売した金額の合計 |
| **計算方法** | Σ（売価 × 数量）。消費税を含まない（税抜）で見るのが基本 |
| **誰が見るか** | ① 経営、② 営業（全員）、③ 業務、⑧ 経理 |
| **見る頻度** | 日次／月次／年次 |
| **なぜ重要か** | 会社の活動量そのもの。ただし**売上の9割近くは仕入先へ支払うお金**であるため、売上だけでは会社の状態は分からない（`12_business-model.md` 12-1-1） |
| **数値の目安** | 【Varies】規模により大きく異なる |

> **【Fact】** 業界全体の規模の参考として、卸売業の年間商品販売額は389兆3,883億円
> （2020年〈令和2年〉1年間。出典：令和3年経済センサス‐活動調査 産業別集計（卸売業，小売業に関する集計）結果の概要／総務省・経済産業省）。
> これは卸売業・小売業合計の74.5%を占めます。

**よく分解される切り口**【Typical】
- 得意先別売上／得意先グループ別（量販・飲食・給食・小売店 等）
- 商品別／商品カテゴリ別／メーカー別
- 営業担当者別／チーム別
- 配送コース別／エリア別
- 月別・曜日別（季節性や納品曜日の偏りを見るため）

### 14-1-2. 得意先別売上

| 項目 | 内容 |
|---|---|
| **意味** | 得意先1社ごとの売上金額 |
| **計算方法** | 得意先コードで集計 |
| **誰が見るか** | ② 営業（担当分）、① 経営、⑦ 与信 |
| **見る頻度** | 月次（日次で見る会社もある【Varies】） |
| **なぜ重要か** | ①訪問頻度や対応の優先度を決める材料になる ②**急な減少は、他社への切り替えや得意先の経営悪化の兆候**として与信の材料にもなる（`08_money.md` 8-7-4） |
| **数値の目安** | 【Varies】 |

> **【Example】**（説明用の架空例）
> A食品商事の担当営業が、B飲食店の月次売上を見ると、前月の85万円から今月52万円に落ちている。
> 理由は「店が暇だから」かもしれないし、「他の卸に切り替えられた」かもしれないし、
> 「支払が苦しくて仕入を絞っている」かもしれない。
> **数字は原因を教えてくれないが、聞きに行くきっかけになる。**

### 14-1-3. 商品別売上

| 項目 | 内容 |
|---|---|
| **意味** | 商品（SKU）ごとの販売金額・販売数量 |
| **計算方法** | 商品コードで集計。金額と数量の両方で見る |
| **誰が見るか** | ④ 仕入（バイヤー）、② 営業、① 経営 |
| **見る頻度** | 月次／週次【Varies】 |
| **なぜ重要か** | 取扱を続けるか・やめるかの判断、発注量の判断、仕入先との条件交渉の材料（「年間○万本売っている」という実績が交渉材料になる） |
| **数値の目安** | 【Varies】 |

### 14-1-4. 営業1人あたり売上

| 項目 | 内容 |
|---|---|
| **意味** | 営業担当1人が担っている売上規模 |
| **計算方法** | 売上高 ÷ 営業担当者数 |
| **誰が見るか** | ① 経営、② 営業（部長） |
| **見る頻度** | 月次／年次 |
| **なぜ重要か** | 担当の配分（1人が何社を持つか）を考える材料。ただし**得意先の性格によって適正値がまったく違う**ため、単純比較はできない |
| **数値の目安** | 【Varies】 |

> **【重要な注意】** 量販店1社で月5,000万円を担当する営業と、
> 個人商店60社で月800万円を担当する営業では、訪問件数も業務量もまったく違います。
> 1人あたり売上だけで比較すると、実態を見誤ります。【Inference】
> そのため、次の「営業1人あたり粗利」と併せて見られることが多くあります。【Typical】

## 14-2. 利益に関するKPI

### 14-2-1. 粗利額（売上総利益）

| 項目 | 内容 |
|---|---|
| **意味** | 売上高から売上原価（仕入原価）を差し引いた金額。**会社に残る最初の金額** |
| **計算方法** | 売上高 − 売上原価 |
| **誰が見るか** | ① 経営、② 営業、④ 仕入、⑧ 経理 |
| **見る頻度** | 日次／月次／年次 |
| **なぜ重要か** | 人件費・物流費・家賃をすべて払う原資。**売上ではなく粗利が会社の体力**（`12_business-model.md` 12-1-1） |
| **数値の目安** | 【Varies】 |

### 14-2-2. 【最重要】粗利率（荒利率）

**粗利率（あらりりつ）／荒利率**
→ 売上に対して粗利が占める割合。現場では「あらり」と読み、「荒利」と書くこともあります。
→ 実務例：売価180円・仕入原価150円なら、粗利30円。粗利率は 30 ÷ 180 ＝ 16.7%。

| 項目 | 内容 |
|---|---|
| **意味** | 売上100円あたり、いくら手元に残るか |
| **計算方法** | **粗利額 ÷ 売上高 × 100（%）** ※分母は**売上高**。仕入原価ではない |
| **誰が見るか** | ① 経営、② 営業（全員）、④ 仕入、⑧ 経理 |
| **見る頻度** | 日次／月次（得意先別・商品別で月次） |
| **なぜ重要か** | 卸売業は粗利率が低いため、**わずかな低下が利益を大きく削る**。粗利率が1ポイント落ちると、年商40億円なら4,000万円の粗利が消える |
| **数値の目安** | 【Varies】扱う商材・業種・得意先構成により大きく異なる。業界横断の基準値は存在しない |

**粗利率が動く原因**【Typical】

| 原因 | 粗利率への影響 |
|---|---|
| 売価を下げた（値引き、特売、競合対応） | 下がる |
| 仕入価格が上がった（価格改定の転嫁が遅れた） | 下がる |
| 得意先構成が変わった（粗利率の低い大口の比率が上がった） | 下がる |
| 商品構成が変わった（粗利率の低い定番品の比率が上がった） | 下がる |
| リベート条件が改善した／達成した | 上がる |
| 廃棄・値下げ処分が増えた | 下がる |

> **【重要】** 粗利率が下がったとき、原因が「値引きしたから」なのか「構成が変わったから」なのかで、
> 打つ手はまったく違います。だから粗利率は**全社の1つの数字ではなく、得意先別・商品別に分解して**見られます。【Inference】

### 14-2-3. 得意先別粗利・粗利率

| 項目 | 内容 |
|---|---|
| **意味** | 得意先1社ごとの粗利額・粗利率 |
| **計算方法** | 得意先ごとに Σ（売価−仕入原価）× 数量／得意先ごとの売上高で割ると粗利率 |
| **誰が見るか** | ① 経営、② 営業、⑦ 与信 |
| **見る頻度** | 月次 |
| **なぜ重要か** | **売上の順番と粗利の順番は入れ替わる**（`12_business-model.md` 12-2-3）。売上上位の得意先が粗利上位とは限らない。訪問頻度・配送頻度・条件交渉の優先度を決める材料になる |
| **数値の目安** | 【Varies】 |

> **【Example】**（説明用の架空例）
> A食品商事の月次表（架空）：
>
> | 得意先 | 売上 | 粗利率 | 粗利額 | 月間配送回数 |
> |---|---:|---:|---:|---:|
> | 量販店C | 4,200万円 | 7.5% | 315万円 | 26回 |
> | 飲食チェーンD | 1,800万円 | 14.0% | 252万円 | 26回 |
> | 個人商店群（30店計） | 900万円 | 18.5% | 167万円 | 130回 |
>
> 売上では量販店Cが圧倒的だが、粗利額では飲食チェーンDが迫る。
> 個人商店群は売上が小さいのに配送回数が最も多い。
> **粗利額から配送コストを引いたらどうなるか**まで見ないと、判断はできない。

### 14-2-4. 商品別粗利・粗利率

| 項目 | 内容 |
|---|---|
| **意味** | 商品ごとの粗利額・粗利率 |
| **計算方法** | 商品ごとに Σ（売価−仕入原価）× 数量 |
| **誰が見るか** | ④ 仕入（バイヤー）、② 営業、① 経営 |
| **見る頻度** | 月次 |
| **なぜ重要か** | 取扱の継続・中止、発注量、売り込む商品の選定、仕入条件の交渉順位を決める |
| **数値の目安** | 【Varies】 |

### 14-2-5. 営業1人あたり粗利

| 項目 | 内容 |
|---|---|
| **意味** | 営業担当1人が稼いでいる粗利額 |
| **計算方法** | 粗利額 ÷ 営業担当者数（または担当者ごとの担当先の粗利合計） |
| **誰が見るか** | ① 経営、② 営業（部長） |
| **見る頻度** | 月次／年次 |
| **なぜ重要か** | 人件費は粗利から払われるため、**1人あたり粗利が人件費を大きく上回っていなければ事業が成り立たない**。売上と違い、条件の良し悪しが反映される |
| **数値の目安** | 【Varies】 |

### 14-2-6. 労働分配率

**労働分配率（ろうどうぶんぱいりつ）**
→ 稼いだ粗利のうち、**どれだけを人件費に充てているか**の割合。
→ 実務例：粗利4.8億円、人件費2.4億円なら、労働分配率50%。

| 項目 | 内容 |
|---|---|
| **意味** | 粗利に占める人件費の割合 |
| **計算方法** | 人件費 ÷ 粗利額 × 100（%） ※分母は売上高ではなく**粗利** |
| **誰が見るか** | ① 経営、⑧ 経理、⑨ 人事・総務 |
| **見る頻度** | 月次／年次 |
| **なぜ重要か** | 卸売業は人が介在する工程が多いため、人件費が粗利に占める比重が大きい。**売上が伸びても粗利率が落ちれば、労働分配率は悪化する** |
| **数値の目安** | 【Varies】業種・自社配送の有無・パート比率により大きく異なる |

> **【注意】** 労働分配率の分母を「売上高」と勘違いする例が多くあります。
> 卸売業では売上高に占める人件費の割合は数%にしかならず、意味のある数字になりません。
> **分母は粗利**です。【Typical】

### 14-2-7. 営業利益・営業利益率

| 項目 | 内容 |
|---|---|
| **意味** | 粗利から販売費及び一般管理費を引いた、本業の利益 |
| **計算方法** | 粗利額 − 販管費／営業利益 ÷ 売上高 × 100（%） |
| **誰が見るか** | ① 経営、⑧ 経理、金融機関 |
| **見る頻度** | 月次／年次 |
| **なぜ重要か** | 会社が本業で稼げているかの最終的な答え。卸売業は売上が大きいため**営業利益率は小さな数字になる**（`12_business-model.md` 12-3） |
| **数値の目安** | 【Varies】 |

## 14-3. 在庫に関するKPI

### 14-3-1. 在庫金額

| 項目 | 内容 |
|---|---|
| **意味** | 保有している在庫を仕入原価で評価した金額 |
| **計算方法** | Σ（在庫数量 × 仕入原価） |
| **誰が見るか** | ① 経営、④ 仕入、⑤ 在庫、⑧ 経理 |
| **見る頻度** | 月次（日次で見る会社もある【Varies】） |
| **なぜ重要か** | **この金額は「支払済み、または支払う約束をしたが、まだ回収できていないお金」**。増えれば資金が減る |
| **数値の目安** | 【Varies】 |

### 14-3-2. 【最重要】在庫回転率

**在庫回転率**
→ 一定期間に、在庫が**何回入れ替わったか**を表す数字。
→ 実務例：年間の売上原価35.2億円、平均在庫金額2.2億円なら、35.2 ÷ 2.2 ＝ 年16回転。

| 項目 | 内容 |
|---|---|
| **意味** | 在庫がどれだけ速く動いているか |
| **計算方法** | **売上原価 ÷ 平均在庫金額**（原価ベース）<br>または **売上高 ÷ 平均在庫高**（売価ベース）<br>※平均在庫金額＝（期首在庫＋期末在庫）÷ 2 が簡便法 |
| **誰が見るか** | ① 経営、④ 仕入、⑤ 在庫、⑧ 経理 |
| **見る頻度** | 月次／年次 |
| **なぜ重要か** | **卸売業は「粗利率が低くても回転で稼ぐ」構造**（`12_business-model.md` 12-4-2）。回転が落ちれば、同じ粗利を得るのにより多くの資金が必要になる |
| **数値の目安** | 【Varies】温度帯・期限の有無・商材で大きく異なる。同じ会社の中でも商品によって何十倍も違う |

> **【重要な注意】** 在庫回転率は、**原価ベースか売価ベースかで数値がまったく変わります。**
> 比較するときは、必ず同じ計算方法で揃えてください。
> 社内で「16回転」と「18回転」という数字が同時に出回っている場合、
> 分母・分子が違っている可能性があります。【Typical】

### 14-3-3. 在庫回転日数

| 項目 | 内容 |
|---|---|
| **意味** | 在庫がひととおり入れ替わるのに**何日かかっているか**。回転率を「日数」に直したもの |
| **計算方法** | **365 ÷ 在庫回転率（年）**<br>または **平均在庫金額 ÷ 1日あたり売上原価** |
| **誰が見るか** | ① 経営、④ 仕入、⑤ 在庫、⑧ 経理 |
| **見る頻度** | 月次／年次 |
| **なぜ重要か** | 「16回転」より「23日ぶんの在庫を持っている」のほうが直感的に理解しやすい。**賞味期限のある商材では、回転日数が期限に対して長すぎないかが直接の問題になる** |
| **数値の目安** | 【Varies】 |

> **【Example】**（説明用の架空例）
> 賞味期限が製造から90日の商品で、在庫回転日数が45日だとする。
> さらに、`15_rules-customs.md` で扱う納品期限の慣行（いわゆる「3分の1ルール」など）の影響で、
> 得意先が受け取れる残存期限に制約がある場合、実質的に使える期間はさらに短くなる。
> **回転日数は「資金の話」だけでなく「売れる／売れない」の話でもある。**

### 14-3-4. 【卸売業で重要】交差比率

| 項目 | 内容 |
|---|---|
| **意味** | 在庫に投じたお金が、どれだけ粗利を生んだか。**粗利率と回転の両方を1つの数字にしたもの** |
| **計算方法** | **粗利率（%） × 在庫回転率（回）** |
| **誰が見るか** | ④ 仕入（バイヤー）、① 経営、② 営業 |
| **見る頻度** | 月次／四半期 |
| **なぜ重要か** | 粗利率だけを見ると「利幅の大きい商品」が良く見え、回転率だけを見ると「よく売れる商品」が良く見える。**会社が知りたいのは「在庫のお金がどれだけ働いたか」**であり、それがこの1つの数字で表せる（`12_business-model.md` 12-4-3） |
| **数値の目安** | 【Varies】業種横断で通用する基準値は存在しない。自社内の商品間比較・自社の過去との比較に使う |

```
【交差比率の読み方】

  粗利率 高 ┃  ゆっくり売れる高利幅品     ┃  最も稼ぐ商品
           ┃  （交差比率 中）            ┃  （交差比率 高）
           ┃                            ┃
  ─────────╋────────────────────────╋──────────────
           ┃                            ┃
  粗利率 低 ┃  最も稼がない商品            ┃  薄利多売で稼ぐ商品
           ┃  （交差比率 低）            ┃  （交差比率 高）
           ┗━━━━━━━━━━━━━━━━━━━━━━━━┻━━━━━━━━━━━━━━
              回転率 低                      回転率 高
```

### 14-3-5. 滞留在庫額

**滞留在庫（たいりゅうざいこ）**
→ 一定期間動いていない在庫のこと。「寝ている在庫」とも言います。
→ 実務例：過去6か月間、1度も出荷がない商品の在庫金額。

| 項目 | 内容 |
|---|---|
| **意味** | 動いていない在庫が、金額でいくらあるか |
| **計算方法** | 「最終出荷日から○日以上経過した商品」の在庫金額の合計。**何日を滞留とするかは会社が定義する**【Varies】 |
| **誰が見るか** | ④ 仕入、⑤ 在庫、① 経営、⑧ 経理 |
| **見る頻度** | 月次 |
| **なぜ重要か** | 滞留在庫は**資金が固定され続けているうえ、時間が経つほど価値が下がる**。期限のある商材では最終的に廃棄になる（`07_goods.md` 7-7-3） |
| **数値の目安** | 【Varies】 |

**デッドストック**
→ 滞留在庫のうち、**もはや売れる見込みがない在庫**のこと。廃番品、規格変更で使えなくなった商品など。

### 14-3-6. 廃棄額・値下げ（処分）額

| 項目 | 内容 |
|---|---|
| **意味** | 期限切れ・破損・売れ残りにより、廃棄または値下げ処分した金額 |
| **計算方法** | 廃棄した在庫の仕入原価の合計／値下げによって失った粗利額 |
| **誰が見るか** | ④ 仕入、⑤ 在庫、① 経営 |
| **見る頻度** | 月次 |
| **なぜ重要か** | **粗利率が低い卸売業では、廃棄1件を取り戻すのに大きな売上が必要**（`12_business-model.md` 12-3-5） |
| **数値の目安** | 【Varies】常温品と要冷品、期限の長短で大きく異なる |

## 14-4. サービス水準に関するKPI

### 14-4-1. 欠品率

**欠品（けっぴん）**
→ 注文を受けたのに、在庫がなくて出荷できないこと（`04_end-to-end-process.md` 4-1 ②）。

| 項目 | 内容 |
|---|---|
| **意味** | 受注のうち、どれだけが欠品になったか |
| **計算方法** | **欠品件数 ÷ 受注明細件数 × 100（%）**（件数ベース）<br>または **欠品金額 ÷ 受注金額 × 100（%）**（金額ベース） |
| **誰が見るか** | ③ 業務、④ 仕入、⑤ 在庫、② 営業、① 経営 |
| **見る頻度** | 日次／月次 |
| **なぜ重要か** | ①その1件の売上を失う ②**得意先が「あの卸は在庫がない」と判断すると、次から注文自体が来なくなる**。つまり、失うのは1件ではなく取引そのもの |
| **数値の目安** | 【Varies】 |

> **【重要】** 欠品率は**在庫を増やせば下がります。**
> しかし在庫を増やせば在庫回転率が落ち、資金が寝て、廃棄リスクが増えます。
> **欠品率と在庫回転率は必ずセットで見られます。**【Typical】
> 片方だけを良くしようとすると、もう片方が必ず悪化する関係にあります。【Inference】

### 14-4-2. 受注充足率（フィルレート）

**フィルレート（Fill Rate）／受注充足率**
→ 「注文された数のうち、実際に出荷できた数の割合」。欠品率の裏返しの指標です。
→ 実務例：100ケースの注文に対して96ケース出荷できたら、フィルレートは96%。

| 項目 | 内容 |
|---|---|
| **意味** | 得意先の注文を、どれだけそのまま満たせたか |
| **計算方法** | **出荷数量 ÷ 受注数量 × 100（%）**（数量ベース）<br>明細ベース（何明細のうち何明細を満たせたか）、金額ベース、オーダーベース（1件の注文をまるごと満たせたか）など複数の計算方法がある【Varies】 |
| **誰が見るか** | ③ 業務、⑤ 在庫、② 営業、得意先（評価指標として求められることがある）【Varies】 |
| **見る頻度** | 日次／月次 |
| **なぜ重要か** | **得意先側から見た、この卸売業者の「使いやすさ」そのもの**。取引条件の交渉や、帳合の見直しの際に話題になることがある |
| **数値の目安** | 【Varies】 |

> **【重要な注意】** フィルレートは**計算方法によって数値が変わります。**
> 数量ベースで96%でも、オーダーベース（1件でも欠品したら「満たせなかった」と数える）では
> 大きく下がることがあります。得意先と自社で計算方法が違うと、話が噛み合いません。【Typical】

### 14-4-3. 誤出荷率・誤配送率

| 項目 | 内容 |
|---|---|
| **意味** | 出荷・配送のうち、間違いがあった割合 |
| **計算方法** | 誤出荷件数 ÷ 出荷件数 × 100（%）。「誤品」「数量違い」「納品先違い」を区別して数えることが多い【Typical】 |
| **誰が見るか** | ⑥ 物流、③ 業務、① 経営 |
| **見る頻度** | 日次／月次 |
| **なぜ重要か** | 誤出荷は**再配送のコスト、返品処理、得意先の信用低下**の3つを同時に生む。件数が少なくても、1件のインパクトが大きい |
| **数値の目安** | 【Varies】 |

### 14-4-4. 納期遵守率（定時納品率）

| 項目 | 内容 |
|---|---|
| **意味** | 約束した日時に納品できた割合 |
| **計算方法** | 定時に納品できた件数 ÷ 納品件数 × 100（%） |
| **誰が見るか** | ⑥ 物流、② 営業、得意先 |
| **見る頻度** | 日次／月次 |
| **なぜ重要か** | 卸売業の「約束」は最終的に納品で果たされる。特に**納品時間が指定されている得意先**（開店前納品、厨房の仕込み時間に合わせた納品）では、遅れは直接の業務支障になる |
| **数値の目安** | 【Varies】 |

### 14-4-5. 返品率

| 項目 | 内容 |
|---|---|
| **意味** | 出荷したもののうち、返ってきた割合 |
| **計算方法** | 返品金額 ÷ 売上金額 × 100（%）／返品件数 ÷ 出荷件数 × 100（%） |
| **誰が見るか** | ③ 業務、⑥ 物流、② 営業、④ 仕入、① 経営 |
| **見る頻度** | 月次 |
| **なぜ重要か** | 返品は**売上の取り消しに加えて、引取りの物流費・再入庫の作業・再販売できなければ廃棄**という三重のコストを生む。`07_goods.md` 7-7 参照 |
| **数値の目安** | 【Varies】業種差が非常に大きい（アパレル卸と食品卸ではまったく異なる） |

**返品の理由別に分けて見るのが一般的**【Typical】

| 理由 | 誰に起因するか | 打てる手の方向 |
|---|---|---|
| 誤品・数量違い | 自社（物流・業務） | 検品・入力の確認 |
| 破損・汚損 | 自社または輸送 | 荷姿・積付の確認 |
| 期限切れ・期限不足 | 在庫管理・納品期限の条件 | 在庫日数・出荷ロットの管理 |
| 得意先の発注ミス | 得意先 | 受注時の確認 |
| 売れ残り・棚替え | 得意先・商流上の慣行【Varies】 | 取引条件の内容による（`15_rules-customs.md`） |

## 14-5. 債権・資金に関するKPI

### 14-5-1. 【重要】売掛回転日数（回収サイト）

**売掛回転日数／売上債権回転日数**
→ 売ってから、代金が実際に入金されるまでに**平均で何日かかっているか**。
→ 実務例：月商3.3億円、売掛金残高6.6億円なら、6.6億 ÷（3.3億 ÷ 30日）＝ 60日。

| 項目 | 内容 |
|---|---|
| **意味** | 売った代金が回収されるまでの平均日数 |
| **計算方法** | **売掛金残高 ÷（年間売上高 ÷ 365）**<br>または **売掛金残高 ÷ 1日あたり売上高** |
| **誰が見るか** | ⑧ 経理、⑦ 与信、① 経営、金融機関 |
| **見る頻度** | 月次 |
| **なぜ重要か** | この日数ぶん、**会社は代金を立て替えている**。日数が延びれば、それだけ運転資金が必要になる（`08_money.md` 8-4） |
| **数値の目安** | 【Varies】得意先ごとの締め日・支払条件により決まるため、得意先構成で変わる |

> **【Example】**（説明用の架空例）
> 月商3.3億円の会社で、売掛回転日数が60日から70日に延びた。
> 必要な運転資金は 3.3億 ÷ 30 × 10日 ＝ **約1.1億円**増える。
> 売上が1円も増えていなくても、1.1億円をどこかから用意しなければならない。

### 14-5-2. 買掛回転日数（支払サイト）

| 項目 | 内容 |
|---|---|
| **意味** | 仕入れてから、代金を実際に支払うまでの平均日数 |
| **計算方法** | **買掛金残高 ÷（年間売上原価 ÷ 365）** |
| **誰が見るか** | ⑧ 経理、④ 仕入、① 経営 |
| **見る頻度** | 月次 |
| **なぜ重要か** | 支払までの日数が長いほど、その間は資金を手元に置いておける。**売掛回転日数との差が、立て替えの長さになる** |
| **数値の目安** | 【Varies】 |

### 14-5-3. 資金が拘束されている期間（運転資金の長さ）

```
  在庫回転日数 ＋ 売掛回転日数 − 買掛回転日数 ＝ 資金が拘束されている日数

【Example：説明用の架空例】
   在庫回転日数  23日
 ＋ 売掛回転日数  60日
 − 買掛回転日数  45日
 ───────────────
 ＝              38日 ぶんの資金を、常に立て替えていることになる
```

| 項目 | 内容 |
|---|---|
| **意味** | 仕入代金を払ってから、売上代金が入るまでの正味の日数 |
| **誰が見るか** | ⑧ 経理、① 経営、金融機関 |
| **見る頻度** | 月次／年次 |
| **なぜ重要か** | **売上が伸びるほど、この日数ぶんの資金が比例して増える**（増加運転資金）。卸売業で「売上が伸びると資金が苦しくなる」と言われる理由がこれ（`08_money.md` 8-4-2） |
| **数値の目安** | 【Varies】 |

### 14-5-4. 売掛金年齢表（滞留債権）

**売掛金年齢表（エイジングリスト）**
→ 売掛金を「発生してから何日経っているか」で区分した一覧表のこと。
→ 実務例：「30日以内：5.2億円」「31〜60日：1.1億円」「61〜90日：2,400万円」「91日超：380万円」

| 項目 | 内容 |
|---|---|
| **意味** | 回収が遅れている債権が、どれだけあるか |
| **計算方法** | 売掛金を発生日からの経過日数で区分して集計 |
| **誰が見るか** | ⑦ 与信、⑧ 経理、① 経営、② 営業 |
| **見る頻度** | 月次 |
| **なぜ重要か** | **経過日数が長い債権ほど、回収できなくなる可能性が高まる**。督促・出荷停止・与信見直しの判断材料（`04_end-to-end-process.md` S22） |
| **数値の目安** | 【Varies】 |

### 14-5-5. 貸倒れ額・貸倒率

| 項目 | 内容 |
|---|---|
| **意味** | 回収できずに損失となった金額と、その売上に対する割合 |
| **計算方法** | 貸倒損失額 ÷ 売上高 × 100（%） |
| **誰が見るか** | ⑦ 与信、⑧ 経理、① 経営 |
| **見る頻度** | 年次（発生時にも把握） |
| **なぜ重要か** | 粗利率10%の会社で300万円の貸倒れが出れば、取り戻すのに3,000万円の売上が必要（`08_money.md` 8-7-2）。**率としては小さくても、粗利に対する影響は大きい** |
| **数値の目安** | 【Varies】 |

### 14-5-6. 資金繰り（資金繰り表）

**資金繰り（しきんぐり）**
→ 「いつ、いくら入って、いくら出て、手元にいくら残るか」を先まで見通すこと。利益とは別の管理。
→ 実務例：向こう3か月について、週ごと・月ごとの入金予定と支払予定を並べ、残高がマイナスにならないか確認する。

| 項目 | 内容 |
|---|---|
| **意味** | 手元の現金が、支払に足りるかどうかの見通し |
| **計算方法** | 期首残高 ＋ 入金予定 − 支払予定 ＝ 期末残高（月次・週次で並べる） |
| **誰が見るか** | ⑧ 経理（経理部長）、① 経営、金融機関 |
| **見る頻度** | 月次（週次で見る会社もある【Varies】） |
| **なぜ重要か** | **利益が出ていても、支払日に現金がなければ事業は続かない**（`12_business-model.md` 12-6-3）。在庫の積み増しや仕込みの判断は、資金繰りの見通しと一体で行われる |
| **数値の目安** | 【Varies】 |

## 14-6. 物流に関するKPI

### 14-6-1. 1配送あたり売上（1納品あたり売上）

| 項目 | 内容 |
|---|---|
| **意味** | 1回の配送（納品）で、いくらぶん納品しているか |
| **計算方法** | 売上高 ÷ 配送回数（または納品件数） |
| **誰が見るか** | ⑥ 物流、② 営業、① 経営 |
| **見る頻度** | 月次 |
| **なぜ重要か** | **配送のコストは金額ではなく回数でかかる**。同じ1回の配送で20万円納品するのと2万円納品するのでは、かかる費用はほぼ同じなのに粗利額が10倍違う（`12_business-model.md` 12-3-2） |
| **数値の目安** | 【Varies】 |

> **【Example】**（説明用の架空例）
> 1配送あたりコストが2,500円の会社で、
> - 1回20万円納品・粗利率10% → 粗利2万円、配送費を引いて17,500円残る
> - 1回1.5万円納品・粗利率18% → 粗利2,700円、配送費2,500円を引くと200円しか残らない
>
> **粗利率が高い得意先のほうが、配送費を引いた後では利益が薄いことがある。**
> これが、卸売業で「粗利率だけを見てはいけない」と言われる理由の1つ。【Inference】

### 14-6-2. 配送効率に関わるその他の指標【Varies】

| 指標 | 意味 | 見る人 |
|---|---|---|
| 1コースあたり納品件数 | 1台の車が1日で何軒回っているか | ⑥ 物流 |
| 積載率 | 車の容量・重量に対して、実際にどれだけ積めているか | ⑥ 物流 |
| 配送コストの売上比 | 配送にかかった費用 ÷ 売上高 | ⑥ 物流、① 経営 |
| ピッキング生産性 | 1人1時間あたりの処理行数（ピース数） | ⑥ 物流 |
| 入荷検品の処理量 | 1人1時間あたりの検品件数 | ⑥ 物流 |

> **【Varies】** これらは倉庫の構造・商材の荷姿・作業方式によって数値がまったく異なるため、
> **同業他社との比較ではなく、自社の過去との比較**に使われるのが一般的です。【Typical】

## 14-7. 分析手法 ——ABC分析

**ABC分析**
→ 商品や得意先を、金額の大きい順に並べて**A・B・Cの3つのグループに分ける**分析方法。
　「上位2割が全体の8割を占める」という経験則（パレートの法則）を実務に落としたものです。
→ 実務例：4,500SKUを売上金額の大きい順に並べ、累計で上位70%を占める商品をA、
　70〜90%をB、残りをCと区分する。

| 項目 | 内容 |
|---|---|
| **意味** | 「重要なもの」と「そうでないもの」を金額基準で仕分ける |
| **計算方法** | ①金額の大きい順に並べる ②累計構成比を計算する ③区切りを決めてA・B・Cに分ける（**区切りの%は会社が決める**【Varies】） |
| **誰が見るか** | ④ 仕入、⑤ 在庫、② 営業、⑥ 物流、① 経営 |
| **見る頻度** | 月次／四半期 |
| **なぜ重要か** | **4,500SKU・380得意先のすべてに同じ手間はかけられない**。どこに時間と在庫と訪問を配分するかを決めるため |
| **数値の目安** | 【Varies】A・B・Cの区切りに決まった値はない |

### 14-7-1. 卸売業での使われ方【Typical】

| 対象 | A区分に対して行うこと | C区分に対して行うこと |
|---|---|---|
| **商品** | 欠品させない（安全在庫を厚めに）、取りやすい棚に置く、仕入条件を重点的に交渉する | 在庫を持たず都度発注にする、取扱の継続を検討する |
| **得意先** | 訪問頻度を高く、条件交渉を丁寧に、与信を定期的に確認 | 訪問の代わりに電話・受注のみの対応にする【Varies】 |
| **倉庫のロケーション** | 出荷口に近い場所（**ゴールデンゾーン**）に配置 | 奥・上段など取りにくい場所に配置 |

> **【重要な注意】** ABC分析は**金額だけで並べる**ため、
> 「金額は小さいが、それがないと他の商品も売れなくなる商品」を見落とすことがあります。【Inference】
>
> > **【Example】**（説明用の架空例）
> > ある調味料は月間売上3万円でC区分だが、その商品を置いていることで飲食店D社が
> > 「まとめて頼める」と判断し、月200万円の取引全体が成り立っている。
> > この商品をやめると、200万円の取引ごと失う可能性がある。
>
> そのため実務では、ABC分析の結果に**「品揃えとしての役割」**を加味して判断されます。【Typical】

### 14-7-2. 2軸で見る（クロスABC分析）【Varies】

| 組み合わせ | 何が分かるか |
|---|---|
| 売上 × 粗利 | 売れているが儲かっていない商品が浮かぶ |
| 売上 × 出荷頻度 | 金額は小さいが毎日出る商品（＝欠品させてはいけない商品）が浮かぶ |
| 粗利率 × 在庫回転率 | 交差比率のマトリクス（14-3-4） |
| 売上 × 配送回数 | 手間がかかっている割に売上が小さい得意先が浮かぶ |

## 14-8. KPIの組み合わせ ——1つだけ見ると必ず間違える

卸売業のKPIは、**引っ張り合う関係**にあります。【Inference】

| 良くしようとすると | 悪くなるもの | だから同時に見る |
|---|---|---|
| 欠品率を下げる（在庫を増やす） | 在庫回転率、資金繰り、廃棄額 | 欠品率 ＋ 在庫回転日数 |
| 売上を伸ばす（与信を緩める） | 売掛回転日数、貸倒率 | 売上 ＋ 売掛金年齢表 |
| 粗利率を守る（値引きを断る） | 売上、得意先の維持 | 粗利率 ＋ 得意先別売上の推移 |
| 配送頻度を減らす | 納期遵守率、得意先満足 | 1配送あたり売上 ＋ 納期遵守率 |
| 在庫を減らす | 欠品率、受注充足率 | 在庫回転日数 ＋ フィルレート |
| 仕入単価を下げる（まとめ買い） | 在庫金額、滞留在庫額 | 粗利率 ＋ 在庫回転率（＝交差比率） |

> **【Inference】** これが、卸売業で **交差比率**（粗利率×在庫回転率）のような
> **2つを掛け合わせた指標**が重んじられる理由です。
> 1つの数字だけを目標にすると、必ずどこか別の場所が悪化します。

## 14-9. 業種によって重視されるKPIの違い【Level 2】

| 業種 | 特に重く見られるKPI | 理由 |
|---|---|---|
| **食品卸** | 欠品率、在庫回転日数、廃棄額、1配送あたり売上、粗利率 | 日次で回り、期限があり、多頻度小口配送のため |
| **建材卸** | 案件別粗利、売掛回転日数、滞留在庫額 | 案件単位で粗利が決まり、回収サイトが長くなりやすいため【Varies】 |
| **機械・工具卸** | 商品別在庫回転率、ABC分析、納期回答のスピード【Varies】、交差比率 | 型番点数が膨大で、回転の遅い在庫をどこまで持つかが経営判断になるため |
| **医薬品卸** | 納期遵守率、フィルレート、在庫のロット管理精度、売掛回転日数 | 緊急配送があり、法令上の管理が求められ、公的価格制度の影響を受けるため |
| **アパレル卸** | 消化率、返品率、シーズン末在庫額、粗利率 | シーズン内に売り切れるかどうかで粗利が決まるため【Varies】 |

> **【Varies】** 同じ業種でも、得意先構成（量販中心か、小口中心か）によって
> 重視されるKPIは変わります。

## 14-10. 初心者が数字を見るときの注意点

| 注意点 | 内容 |
|---|---|
| **計算方法を必ず確認する** | 在庫回転率は原価ベースか売価ベースか、フィルレートは数量ベースか明細ベースか。同じ名前でも数値が変わる |
| **分母を確認する** | 粗利率の分母は売上、労働分配率の分母は粗利。分母を間違えると意味のない数字になる |
| **期間を確認する** | 「回転率16回」が年なのか月なのかで意味がまったく違う |
| **リベート前か後かを確認する** | 粗利率は、リベートを含めるかどうかで大きく変わる（`12_business-model.md` 12-5-2） |
| **税込か税抜かを確認する** | 売上高は税抜で見るのが基本 |
| **平均値に引きずられない** | 全社の粗利率12%でも、内訳は7%〜20%に分かれている。平均だけでは判断できない |
| **数字は原因を教えてくれない** | 「売上が落ちた」という事実は分かるが、なぜかは現場に聞かないと分からない |

## この章のまとめ

1. 卸売業では**売上・粗利・在庫・債権の4つを同時に見る**。1つだけを見ると必ず判断を誤る。
2. 利益の中心指標は**粗利率（荒利率）**。分母は売上高。
   全社平均ではなく、**得意先別・商品別に分解して**見る。
3. 在庫の中心指標は**在庫回転率／在庫回転日数**。
   粗利率と掛け合わせた**交差比率**が、「在庫に投じたお金がどれだけ働いたか」を示す。
4. サービス水準は**欠品率・受注充足率（フィルレート）**。
   これらは在庫回転率と引っ張り合うため、必ずセットで見る。
5. 資金の中心指標は**売掛回転日数・買掛回転日数**。
   在庫回転日数＋売掛回転日数−買掛回転日数が、立て替えている日数になる。
6. **1配送あたり売上**は卸売業に固有の重要指標。
   配送コストは金額ではなく回数でかかるため、粗利率が高くても配送費で消えることがある。
7. **ABC分析**で、4,500SKU・380得意先に対する手間の配分を決める。
   ただし金額だけで切ると、品揃えとしての役割を見落とす。
8. 数値の目安は業種・商材・得意先構成で大きく変わる。
   **業界横断の基準値はほとんど存在しない**ため、自社の過去と自社内の比較で使う。

→ 次は `15_rules-customs.md` で、**これらの数字が生まれる前提になっている法規制と商習慣**を扱います。
