## 8-0. 最初に押さえる1つのこと

> # **売上が立つ ＝ お金が入る、ではありません。**

これが分からないと、この先の説明がすべて分からなくなります。
逆に、これさえ分かれば卸売業のカネの流れの7割は理解できます。

### 8-0-1. 何が違うのか

| | 売上が立つ | お金が入る |
|---|---|---|
| **いつ起きるか** | 商品を得意先に渡したとき（またはその近辺） | 何十日も後の、決められた支払日 |
| **何が起きているか** | 「この金額をもらう**権利**」が発生する | 実際に銀行口座の残高が増える |
| **帳簿上の名前** | 売上高／**売掛金**（うりかけきん） | 現金・預金 |
| **手元のお金は** | **増えていない** | 増える |

### 8-0-2. 図で見る

```
  3/28              4/20        4/23                    5/31
   │                  │           │                       │
   ▼                  ▼           ▼                       ▼
 商品を渡した      締め日      請求書を送った          入金された
   │                                                      │
   │◀──────────── 約 64 日 ────────────▶│
   │                                                      │
 「売上」が立つ                                    「現金」が増える
 「売掛金」が生まれる                              「売掛金」が消える
   │
   └─ この64日間、会社はこの商品の代金を1円も受け取っていない。
      それどころか、この商品の仕入代金は 4/30 に支払っている。
```

> **【Example】** 上の日付は `04_end-to-end-process.md` §4-4 で追跡した架空取引のものです。

### 8-0-3. なぜこうなるのか ——掛売（信用取引）

**用語**
**掛売（かけうり／信用取引）**
→ 商品を渡すときには代金をもらわず、**後日まとめて支払ってもらう**取引のやり方。
→ 実務例：「20日締め・翌月末払い」＝前月21日から当月20日までに渡した商品の代金を、
　翌月の末日にまとめて振り込んでもらう。

**なぜ卸売業は掛売が前提なのか**

| 理由 | 説明 |
|---|---|
| **取引の回数が多すぎる** | 1つの得意先に月20回も30回も納品する。そのたびに現金をやり取りするのは双方とも不可能 |
| **納品するのは配送ドライバー** | 荷を降ろす人が代金を受け取って持ち帰るのは、金額が大きく現実的でない |
| **得意先も「売ってから払いたい」** | 小売店は商品を仕入れて、それを売ってから代金を払いたい。これが商売の順番 |
| **業界の慣行として定着している** | 「現金でないと売らない」と言えば、その卸売業者は取引の候補から外れる |
| **金額が大きい** | 1回の納品が数万〜数十万円。月に数百万円になる |

> **【Inference】** つまり掛売は、**卸売業者が得意先に「支払いを待ってあげている」状態**です。
> `01_overview.md` の「信用供与機能」が、会計上は**売掛金**という形で現れます。
> 卸売業は商品を売っているだけでなく、**同時に「支払いの猶予」も提供している**のです。

## 8-2. 売掛金と買掛金 ——時間差が生む2つの残高

### 8-2-1. 売掛金（うりかけきん）

**やさしい説明**
> **商品を渡したけれど、まだもらっていない代金。**
> 会社にとっては「これからもらえる権利」なので、**資産**として帳簿に載ります。

**どう動くか**

```
 商品を納品した              ──▶  売掛金が 増える（＋715,000円）
 得意先から入金があった      ──▶  売掛金が 減る （−715,000円）
 返品があった                ──▶  売掛金が 減る （赤伝の分）
 値引きに応じた              ──▶  売掛金が 減る
```

**売掛金の残高が意味するもの**

> **【Inference】** 売掛金残高とは、**「得意先に渡したまま、まだ回収できていない金額の総額」**です。
> つまり**会社が外に出したまま戻っていないお金**です。
> モデル企業（年商40億円）で、平均回収日数が60日だとすれば、
> 売掛金残高はおおむね **40億円 ÷ 365日 × 60日 ≒ 6.6億円**【Example：説明用の計算例】。
> この6.6億円は、会社の資金として自由に使うことはできません。

### 8-2-2. 買掛金（かいかけきん）

**やさしい説明**
> **商品を仕入れたけれど、まだ払っていない代金。**
> 会社にとっては「これから払う義務」なので、**負債**として帳簿に載ります。

**どう動くか**

```
 商品が入荷・検収された      ──▶  買掛金が 増える（＋551,650円）
 仕入先へ支払った            ──▶  買掛金が 減る （−551,650円）
 仕入先へ返品した            ──▶  買掛金が 減る
 リベートを買掛金と相殺した  ──▶  買掛金が 減る
```

> **【重要な区別】発注 ≠ 仕入計上。**
> 注文書を出しただけでは買掛金は生まれません。
> **商品が届いて検収した時点**で、初めて「払う義務」が確定します。

### 8-2-3. 2つの残高の関係

```
       会社の外                会社                  会社の外
   ┌──────────┐                            ┌──────────┐
   │  仕入先      │                            │  得意先      │
   │            │                            │            │
   │  「まだ     │ ◀──【買掛金】──          │  「まだ     │
   │   もらって  │    払う義務                │   払って    │
   │   いない」  │                            │   いない」  │
   │            │          【売掛金】──▶    │            │
   │            │          もらう権利        │            │
   └──────────┘                            └──────────┘

   卸売業者は、上流に対しては「払う側」、下流に対しては「もらう側」。
   その両方の時間差の間に立っている。
```

## 8-3. 【卸売業の特徴】締め日と支払サイトが得意先ごとに違う

### 8-3-1. 締め日とは

**締め日**
→ 「いつからいつまでの取引を1回分としてまとめるか」を区切る日。
→ 実務例：「20日締め」なら、前月21日〜当月20日の納品分をまとめて1枚の請求書にする。

**支払サイト**
→ 締め日から実際に支払われるまでの期間。
→ 実務例：「20日締め・翌月末払い」なら、締めてから約40日後に入金される。

### 8-3-2. ここが卸売業の特徴

> **製造業や建設業では、取引先の数がそれほど多くないため、
> 締め日は「月末締め」で統一されていることが多くあります。**
>
> **卸売業は違います。得意先が数百社あり、締め日も支払条件もバラバラです。**【Typical】

**モデル企業の例【Example】（説明用の架空の分布です）**

| 締め日 | 得意先の数（約380社中） | 主な業態 |
|---|---:|---|
| 月末締め | 約170社 | 飲食店、個人商店 |
| 20日締め | 約110社 | 食品スーパー |
| 15日締め | 約45社 | 給食・福祉施設 |
| 10日締め | 約25社 | 一部の量販店 |
| 25日締め・5日締め等 | 約20社 | 個別条件 |
| 都度現金・前払 | 約10社 | 新規・与信が付かない先 |

**支払条件の組み合わせ【Example】**

| 条件 | 商品を渡してから入金までの目安 |
|---|---|
| 月末締め・翌月末払い | 約30〜60日 |
| 20日締め・翌月末払い | 約41〜71日 |
| 月末締め・翌々月10日払い | 約40〜70日 |
| 20日締め・翌々月10日払い | 約51〜81日 |
| 月末締め・翌月末手形（サイト90日） | 約120〜150日（手形が現金になるまで）【Varies】 |

### 8-3-3. 締め日がバラバラだと何が起きるか

```
 【経理部の1か月】【Example】

  5日   ── 5日締めの得意先分を締める → 請求書作成
  10日  ── 10日締めの得意先分を締める → 請求書作成
         ── 10日払いの得意先からの入金確認・消込
  15日  ── 15日締めの得意先分を締める → 請求書作成
  20日  ── 20日締めの得意先分を締める → 請求書作成（最も件数が多い）
  25日  ── 25日締めの得意先分を締める
  月末  ── 月末締めの得意先分を締める（最も件数が多い）
         ── 月末払いの得意先からの入金確認・消込（最も件数が多い）
         ── 仕入先への支払（買掛金の決済）
```

> **【Inference】** 「月末に締めて月初に請求する」という単純な流れにはなりません。
> **月内に何度も締め処理があり、何度も入金確認があります。**
> モデル企業では経理3名のうち売掛担当1名がこれを担っています【Example】。
>
> さらに、`04` §4-4 の例で見たように、
> **同じ3月28日の納品でも、得意先の締め日が20日なら4月20日締めに入る**ため、
> 「いつの売上がいつ請求され、いつ入金されるか」は得意先ごとに追う必要があります。

### 8-3-4. 手形とでんさい【Varies】

**用語**
**手形（約束手形）**
→ 「○月○日に、この金額を支払います」と書いた紙の証書。
　受け取っても、**支払期日が来るまで現金にはなりません**。
→ 実務例：「120日サイトの手形」＝手形を受け取ってから120日後に現金化される。

**用語**
**手形割引**
→ 期日前の手形を銀行に買い取ってもらい、早く現金にすること。
　その代わり**割引料（利息に相当）を差し引かれます**。

**用語**
**でんさい（電子記録債権）**
→ 手形と同じ役割を、紙ではなく電子的な記録で行う仕組み。
→ 実務例：印紙が不要、紛失の心配がない、分割して譲渡できる、といった違いがあります。

> **【Fact】** 2026年1月1日に施行された**取適法（中小受託取引適正化法。旧・下請代金支払遅延等防止法）**では、
> **手形払が禁止**され、その他の支払手段（電子記録債権等）についても
> **支払期日までに代金相当額満額を得ることが困難なもの**が禁止されました
> （出典：取適法リーフレットNo.01（令和7年8月）／公正取引委員会）。
> ただし同法が適用されるのは**製造委託・修理委託・特定運送委託・情報成果物作成委託・役務提供委託**であり、
> **単純な商品の売買には適用されません**。適用範囲は `15_rules-customs.md` で詳しく扱います。

## 8-4. 【構造】支払が先、入金が後 ——運転資金

### 8-4-1. 順番を並べてみる

`04_end-to-end-process.md` §4-4 の架空取引を、お金の出入りだけで並べます。【Example】

```
  3/14  仕入先C食品から170ケース入荷 → 買掛金 551,650円（税込）が発生
        ※ この時点ではまだ払っていない

  3/28  Bスーパーへ200ケース納品 → 売掛金 715,000円（税込）が発生
        ※ この時点ではまだもらっていない

  4/30  C食品へ支払     ── 551,650円が 出ていく  ★ お金が減る
        │
        │  ◀────── 31日間、立て替えている ──────▶
        │
  5/31  Bスーパーから入金 ── 715,000円が 入ってくる ★ お金が増える
```

> **この31日間、A食品商事は551,650円を自分のお金で立て替えています。**
> これが1件だけなら問題ありませんが、**同じことが毎日、全取引で起きています。**

### 8-4-2. 運転資金とは

**用語**
**運転資金（うんてんしきん）**
→ 事業を回し続けるために、**常に会社の中に置いておかなければならないお金**。
→ 卸売業では、おおむね次の形で必要になります。

```
 必要な運転資金 ＝ 売掛金 ＋ 在庫 − 買掛金

  売掛金 … 渡したけど、まだもらっていないお金（外に出ている）
  在庫   … 買ったけど、まだ売れていない商品（お金が商品の形で寝ている）
  買掛金 … 仕入れたけど、まだ払っていないお金（仕入先が立て替えてくれている分）
```

**【Example】モデル企業で計算してみる**（説明用の架空の数値です）

```
 A食品商事（年商40億円）の仮定【Example】

   売掛金残高   6.6億円  （回収まで平均60日）
   在庫金額     2.2億円  （在庫回転日数 平均20日と仮定）
   買掛金残高   4.3億円  （支払まで平均45日）
   ────────────────────────────
   必要運転資金 6.6 ＋ 2.2 − 4.3 ＝ **4.5億円**

 → 年商40億円の会社が、常に約4.5億円を「使えないお金」として抱えている状態。
```

> **【Example】上記はすべて説明用の架空の計算です。**
> 実際の数値は企業・業種・取引条件によって大きく異なります【Varies】。

> **【Inference】** 運転資金は、**売上が増えるほど増えます。**
> 売上が2倍になれば、売掛金も在庫も（おおむね）2倍になるためです。
> 「売れているのに資金が苦しい」という状態が起こり得るのは、この構造によります。

### 8-4-3. 資金の穴をどう埋めるか【Typical】

| 手段 | 内容 |
|---|---|
| **自己資金** | 過去の利益の蓄積（内部留保）で賄う |
| **短期借入金** | 銀行から運転資金として借りる。1年以内の返済が基本 |
| **当座貸越（とうざかしこし）** | あらかじめ決めた限度額まで、必要なときに自動的に借りられる仕組み |
| **手形割引** | 受け取った手形を期日前に現金化する |
| **でんさいの割引・譲渡** | 電子記録債権を期日前に現金化する |
| **支払条件の交渉** | 仕入先に支払サイトの延長を相談する（`04` S28 の取引条件見直し） |
| **回収条件の交渉** | 得意先に締め日・支払サイトの短縮を相談する |

> **【Typical】** 経理部長・社長が**資金繰り表**（いつ、いくら入って、いくら出るかを並べた表）を
> 作って管理し、支払日前に残高が足りるかを確認するのが実務です。
> 詳細は `13_periodic-work.md` で扱います。

## 8-5. 【構造】卸売業は粗利率が低く、回転で稼ぐ

### 8-5-1. 粗利とは

**用語**
**粗利（あらり／売上総利益）**
→ **売った金額 − 仕入れた金額**。商品そのものが生んだ利益です。
→ 実務例：3,250円で売って2,950円で仕入れたら、粗利は300円。

**用語**
**粗利率（あらりりつ／売上総利益率・荒利率）**
→ 売上に対する粗利の割合。**粗利 ÷ 売上 × 100**。
→ 実務例：売上3,250円、粗利300円なら、粗利率は約9.2%。

### 8-5-2. 卸売業の粗利率は低い【Typical】

> **【Typical】** 卸売業は、**製造業や小売業に比べて粗利率が低い**業態とされています。
> 仕入れた商品をそのまま売るため、加工による付加価値が乗らないためです【Inference】。

```
 【売上100円の内訳のイメージ】

 ■ 小売業（消費者に売る）
   仕入 70円 ┃ 粗利 30円          ← 店舗・接客・陳列のコストを粗利で賄う

 ■ 卸売業
   仕入 88円          ┃ 粗利 12円 ← 物流・与信・営業のコストを粗利で賄う

 ※ 上図の数値は構造を示すためのイメージであり、実際の粗利率は
    業種・商品・取引先によって大きく異なります【Varies】。
```

> **注意**：本資料は「粗利率が低いから厳しい」「だから改善が必要」といった評価は行いません。
> **これは卸売業というビジネスモデルの構造であり、その構造の中で利益を出す仕組みが
> 次に説明する「回転」です。**

### 8-5-3. 「回転で稼ぐ」とはどういうことか

**用語**
**在庫回転率**
→ 在庫が1年間に何回入れ替わったか。**年間の売上原価 ÷ 平均在庫金額**。
→ 実務例：在庫回転率が18回なら、1年で18回、在庫がまるごと入れ替わったことになります。

**なぜ回転が重要なのか**

```
 【同じ100万円の在庫を持つ2つのケース】【Example：説明用の架空例】

 ケースA：粗利率 10%、年12回転
   → 1回転ごとに 100万円 × 10% ＝ 10万円 の粗利
   → 年間 10万円 × 12回 ＝ **120万円** の粗利

 ケースB：粗利率 30%、年3回転
   → 1回転ごとに 100万円 × 30% ＝ 30万円 の粗利
   → 年間 30万円 × 3回 ＝ **90万円** の粗利

 → 粗利率はBのほうが3倍高いが、
    同じ100万円の資金から生まれる年間の粗利はAのほうが多い。
```

> **【Inference】** 卸売業が「薄利多売」と言われるのは、
> **1回あたりの粗利が薄くても、回転を速くすることで年間の粗利額を確保する**構造だからです。
> 逆に言えば、**回転が止まった在庫（滞留在庫）は、卸売業の収益構造そのものを損ないます。**
> この考え方を数値化したものが**交差比率**であり、`12_business-model.md` と `14_kpi.md` で扱います。

## 8-6. 【複雑さの源】リベートがカネの流れをどう変えるか

### 8-6-1. リベートとは（再確認）

**リベート（販売奨励金／割戻し）**
→ 商品の売買代金とは**別に**、一定期間の後に支払われる金銭。

> **【Fact】** 公正取引委員会の指針では、リベートは
> 「仕切価格とは区別されて取引先に制度的に又は個別の取引ごとに支払われる金銭」と説明されています
> （出典：流通・取引慣行に関する独占禁止法上の指針／公正取引委員会）。

### 8-6-2. なぜカネの流れが複雑になるのか

**① 商品ごとの粗利にリベートが表れない**

```
 【この取引の見え方】【Example】

  取引時点で見える数字：
    売上   650,000円
    原価   594,950円
    粗利    55,050円（粗利率 8.5%）
       ↑ 「あまり儲からない取引だった」と見える

  半期後、リベート精算：
    C食品との年間契約 … 期間仕入高が基準を超えたため 1.5% のリベート
    この取引分の仕入 501,500円 × 1.5% ＝ 7,522円

  実質の粗利 ＝ 55,050 ＋ 7,522 ＝ 62,572円（実質粗利率 約9.6%）
```

> **【Inference】** つまり**取引の瞬間には、その取引の本当の利益が分かりません。**
> 取引ごとの粗利だけを見て「この取引は儲かっていない」と判断できないのはこのためです。

**② 入ってくるタイミングが遅く、まとまっている**

```
 商品の粗利      … 納品のたびに、1件ずつ、少しずつ
 リベート        … 四半期／半期／年次に、まとめて、大きな金額で【Varies】
```

**③ 入り方が何通りもある**

| 入り方 | 何が起きるか |
|---|---|
| **現金で振り込まれる** | 銀行残高が増える。収入として計上する |
| **買掛金と相殺される** | 支払額が減る。銀行残高の減り方が小さくなる |
| **次回の仕入価格に反映される** | そもそもリベートとして表に出ず、仕切価格が下がる形になる |
| **商品（現物）で支給される** | 無償で商品が入ってくる。在庫と原価の扱いが必要になる【Varies】 |

**④ 条件の達成が期末まで確定しない**

> **【Typical】** 「年間仕入高が1億円を超えたら2%」という条件の場合、
> 期の途中では「達成できるかどうか」が確定しません。
> 見込みで利益に織り込むか、確定してから計上するかは、会計処理の判断になります【Varies】。

**⑤ 自社が支払う側にもなる**

卸売業者は、仕入先からリベートを**受け取る**だけでなく、
得意先に対してリベートや協賛金を**支払う**立場にもなります。

```
   メーカー ──リベートを支払う──▶ 卸売業者 ──リベート・協賛金を支払う──▶ 小売
              （収入になる）                    （費用になる）
```

> **【Inference】** したがって卸売業者の実質的な利益は、
> **「商品の粗利」＋「受け取るリベート」−「支払うリベート・協賛金」**という
> 3つの要素の合計で決まります。この構造が、卸売業の利益管理を難しくしている一因です。
> （詳細は `12_business-model.md`）

## 8-7. 与信と貸倒れ ——回収できないと何が起きるか

### 8-7-1. 貸倒れとは

**用語**
**貸倒れ（かしだおれ）**
→ 売掛金が**回収できなくなること**。得意先の倒産、行方不明、支払拒否など。
→ 実務例：「B商店が倒産し、売掛金380万円が回収不能になった」。

### 8-7-2. 【Example】貸倒れの重さを計算で見る

> **【Example】** 以下はすべて**説明用の架空の計算**です。実データではありません。

```
 前提：A食品商事の平均粗利率を 12% と仮定する【Example】

 ■ もし 300万円 の売掛金が回収不能になったら

   失うお金：300万円（丸ごと）

   この300万円を粗利で取り戻すには、いくら売ればよいか？

     必要な売上 ＝ 300万円 ÷ 12% ＝ **2,500万円**

   → 300万円の貸倒れを埋めるには、2,500万円を新たに売らなければならない。
      年商40億円の会社にとって、2,500万円は年商の約0.6%に相当する売上。
```

**さらに厳密に見ると**

```
 ■ 実際にはもっと重い

   ・粗利12%とは「売上に対して」の話。
     つまり300万円の売掛金のうち、自社の利益分は 300万円 × 12% ＝ 36万円 だけ。
     残りの 264万円 は、すでに仕入先に支払った（または支払う）仕入代金。

   ・仕入先への支払は、得意先が倒産しても**免除されません。**

   → 貸倒れとは、「利益を失う」のではなく
     「**仕入代金を自腹で払ったうえで、商品も代金も失う**」ことです。
```

**倍率で見る**

| 粗利率 | 100万円の貸倒れを埋めるのに必要な売上【Example】 |
|---:|---:|
| 20% | 500万円（5倍） |
| 15% | 667万円（約6.7倍） |
| **12%** | **833万円（約8.3倍）** |
| 10% | 1,000万円（10倍） |
| 8% | 1,250万円（約12.5倍） |

> **【Inference】** **粗利率が低いほど、貸倒れの影響は大きくなります。**
> 卸売業で与信管理が重視されるのは、この計算が背景にあります。
> `06_people.md` §6-5 で見たとおり、与信限度額の承認が社長に集まるのもこのためです。

### 8-7-3. 貸倒れを防ぐ・小さくするための仕組み【Typical】

| 仕組み | 内容 |
|---|---|
| **与信限度額** | 「未回収のまま渡してよい上限額」を得意先ごとに決める |
| **取引前の信用調査** | 信用調査会社の報告、決算書の確認、業歴・経営者の状況 |
| **入金状況のモニタリング** | 遅れが出た時点で把握する。年齢表（古い売掛金の一覧）で管理 |
| **営業からの情報** | 「店が暗い」「従業員が減った」「他社が取引を止めたらしい」という現場の兆候 |
| **取引信用保険** | 得意先が倒産した場合に保険金が支払われる保険【Varies】 |
| **担保・連帯保証** | 不動産担保、経営者の連帯保証【Varies】 |
| **前払い・現金取引への切替** | 与信が付けられない先には掛売をしない |
| **出荷停止** | 未回収が続く場合に商品を止める（最終手段） |

**用語**
**貸倒引当金（かしだおれひきあてきん）**
→ 「将来回収できなくなりそうな金額」をあらかじめ見積もって、費用として計上しておく会計処理。
→ 実務例：売掛金残高の一定割合、または回収が危ぶまれる特定の先について計上します。

### 8-7-4. 回収できなくなる前の兆候【Typical】

> これは「起きること」の記述であり、対処法の提案ではありません。

| 兆候 | どこで気づくか |
|---|---|
| 入金が数日遅れるようになった | 経理（消込） |
| 一部入金が増えた（満額払われない） | 経理（消込） |
| 支払方法を手形に変えたいと言われた | 営業・経理 |
| 注文量が急に増えた（在庫を積みに来た） | 内勤・営業 |
| 注文量が急に減った（他社へ移った、または仕入を絞った） | 内勤・営業 |
| 店の様子が変わった（品薄、従業員減、改装中断） | 営業（訪問時） |
| 同業他社から噂が入る | 営業・社長 |
| 経営者・担当者と連絡が取りにくくなった | 営業 |

> **【Inference】** このうち上の2つは**経理が最初に気づき**、下の4つは**営業が最初に気づきます。**
> `06_people.md` §6-5 で見たとおり、与信の判断には両方の情報が要ります。
> 経理と営業の情報のやり取りが実務上の要になるのは、このためです。

## 8-8. 消費税とインボイス制度

### 8-8-1. 消費税の基本（卸売業の視点）

> 卸売業は**BtoB（事業者間取引）が中心**ですが、消費税は課税されます。

```
 【消費税の流れ】【Example】（税率10%の場合）

  メーカー ──▶ 卸売業者 ──▶ 小売業者 ──▶ 消費者
   本体 2,400      本体 2,700      本体 3,480
   税    240        税   270        税   348

  卸売業者が納める消費税 ＝ 受け取った270円 − 支払った240円 ＝ 30円
                            （＝ 粗利300円 × 10%）
```

> **【重要】** 卸売業者が国に納めるのは、
> **「売上で預かった消費税」−「仕入で支払った消費税」**の差額です。
> この「仕入で支払った消費税を差し引くこと」を**仕入税額控除**といいます。

### 8-8-2. インボイス制度

**用語**
**インボイス制度（適格請求書等保存方式）**
→ 仕入税額控除を受けるために、**登録した事業者が発行する要件を満たした請求書等（適格請求書）**の
　保存を必要とする仕組み。

> **【Fact】** 令和5年（2023年）10月1日から、複数税率に対応した消費税額の仕入税額控除の方式として
> 「適格請求書等保存方式（インボイス制度）」が開始されました
> （出典：No.6498 適格請求書等保存方式（インボイス制度）／国税庁）。

**卸売業への影響**

| 立場 | 何が必要になるか |
|---|---|
| **売る側として** | 得意先が仕入税額控除を受けられるよう、**適格請求書の要件を満たした請求書**を発行する必要がある。登録番号・適用税率・税率ごとの消費税額等の記載が求められる |
| **買う側として** | 仕入先が適格請求書発行事業者かどうかを確認し、受け取った請求書を保存する必要がある |
| **経理の実務として** | 受け取る請求書を「適格請求書かどうか」で区分して処理する必要が生じる |

**免税事業者からの仕入れに係る経過措置**

> **【Fact】** 適格請求書発行事業者以外の者（免税事業者等）からの課税仕入れについては、
> 一定の要件を満たす場合、**令和5年10月1日から令和13年9月30日までの期間**、
> 仕入税額相当額の一定割合（**80パーセント、7割・5割・3割**）を仕入税額として控除できる
> 経過措置が設けられています。
> また、この経過措置には金額の上限があり、
> **令和8年10月1日以後に開始する課税期間については、一の免税事業者等からの課税仕入れの額の
> 合計額が1億円を超える場合、その超える部分について経過措置の適用がありません**
> （改正前の上限は10億円）
> （出典：No.6498 適格請求書等保存方式（インボイス制度）／国税庁）。

> **【Inference】** 卸売業者は仕入先の数が多い（モデル企業で約180社）ため、
> **仕入先ごとに登録の有無と適用される控除割合を管理する**必要が生じます。
> また、割合が期間によって変わるため、**取引の日付**（引渡し・役務提供の日）で判定することになります。

## 8-9. 【Example】1つの取引のカネの動きを時系列で追う

> **【Example】** 以下はすべて**説明用の架空の例**です。実在の企業・取引ではなく、
> 記載した金額・日付も実データではありません。
> `04_end-to-end-process.md` §4-4 の取引を、**カネの視点だけ**で追い直します。
> 消費税率は10%として計算しています。

### 登場人物（すべて架空）

| | |
|---|---|
| **A食品商事** | モデル企業（卸売業者） |
| **Bスーパー** | 得意先。**20日締め・翌月末払い**、与信限度額500万円 |
| **C食品工業** | 仕入先（メーカー）。**月末締め・翌月末払い** |

### タイムライン

---

#### 【3月10日】商談 ——お金は動かない

営業がBスーパーから特売の引合を受ける。

```
 お金の動き：なし
 帳簿の動き：なし
```

> **なぜ動かないのか**：まだ売買が成立していません。
> **見積 ≠ 契約** です。この段階では「話をしている」だけです。

---

#### 【3月11日】受注 ——お金は動かない

BスーパーからEDIで正式発注。200ケース、単価3,250円、金額650,000円（税抜）。

```
 お金の動き：なし
 帳簿の動き：なし（受注データとして記録されるが、会計上の仕訳は発生しない）
```

> **なぜ動かないのか**：注文を受けただけでは売上にはなりません。
> **受注 ≠ 売上** です。まだ商品を渡していないためです。

---

#### 【3月11日】仕入先へ発注 ——お金は動かない

C食品工業へ170ケース発注。単価2,950円。

```
 お金の動き：なし
 帳簿の動き：なし
```

> **なぜ動かないのか**：**発注 ≠ 仕入計上**。注文書を出しただけでは債務になりません。

---

#### 【3月14日】入荷・検収 ——★ 買掛金が発生する

C食品から170ケース入荷、検品合格、入庫。

```
 ■ 帳簿の動き

   仕入高    501,500円（＝170ケース × 2,950円）
   仮払消費税 50,150円
   ───────────────
   買掛金    551,650円 が発生 ← 「C食品に払う義務」が確定

 ■ 銀行口座の動き：なし（まだ1円も払っていない）

 ■ 在庫の動き：在庫金額が 501,500円 増える
```

> **ここがポイント**：**お金は減っていないのに、払う義務が発生しました。**
> そして**在庫という形で、501,500円が倉庫に固定されました。**
> この時点で会社の「使えるお金」は変わっていませんが、
> **4月30日に551,650円を払う予定が確定しました。**

---

#### 【3月28日】納品・検収 ——★ 売掛金が発生する

Bスーパー4店舗へ200ケース納品。受領印を取得。売上計上基準は納品基準【Example】。

```
 ■ 帳簿の動き

   売掛金    715,000円 が発生 ← 「Bスーパーからもらう権利」が確定
   ───────────────
   売上高    650,000円
   仮受消費税 65,000円

   売上原価  594,950円（在庫33ケース×3,100円 ＋ 新規167ケース×2,950円）
   在庫      594,950円 減少

   → この取引の粗利：650,000 − 594,950 ＝ **55,050円**（粗利率 約8.5%）

 ■ 銀行口座の動き：なし（まだ1円ももらっていない）
```

> **ここがポイント**：**売上が立ち、粗利55,050円が計上されました。**
> **しかし現金は1円も入っていません。** これが冒頭の「売上 ≠ 入金」です。
> 会社の帳簿上の利益は増えましたが、**手元の資金はむしろ減ったまま**です
> （3月14日に仕入れた商品の代金は、これから払うため）。

---

#### 【3月29日】返品発生 ——売掛金が増減する

東店から2ケースの外装破損の申し出。良品2ケースと交換。

```
 ■ 帳簿の動き

   赤伝（返品）：売掛金 −7,150円（2ケース×3,250円×1.1）、売上高 −6,500円
   新規売上    ：売掛金 +7,150円、売上高 +6,500円
   ───────────────
   差引：売掛金・売上高ともに増減なし

   ただし在庫は動く：
     返品2ケース … 在庫に戻さず社内販売へ（評価減として処理）
     出荷2ケース … 在庫が2ケース分減る
   → 在庫金額が 2ケース分だけ余計に減る（＝この取引の実質粗利がその分下がる）
```

> **ここがポイント**：請求金額は変わりませんが、**在庫は確実に減っています。**
> `04` で述べたとおり、赤伝を起こし忘れると棚卸差異として後で発覚します。

---

#### 【4月20日】締め日 ——お金は動かないが、請求額が確定する

Bスーパーの20日締め。3月21日〜4月20日の全納品を集計。

```
 ■ 集計結果【Example】
   Bスーパーへの3/21〜4/20の全売上：4,285,000円（税込）
   （鍋つゆ特売の715,000円を含む）

 ■ お金の動き：なし
 ■ 帳簿の動き：売掛金の残高が確定する（新たな仕訳は発生しない）
```

> **ここがポイント**：**3月28日の納品が、4月20日締めに入ります。**
> 得意先の締め日が20日であるため、3月末締めではないのです。
> 締め日が得意先ごとに違うとは、こういうことです。

---

#### 【4月23日】請求書発行 ——お金は動かない

検収データと突き合わせ、差異1件（1ケースの誤出荷）を赤伝で修正のうえ、請求書を送付。

```
 ■ お金の動き：なし
 ■ 帳簿の動き：赤伝による売掛金の修正のみ
```

> **ここがポイント**：**請求書を出しても、お金は入りません。**
> **請求 ≠ 入金** です。請求書は「支払ってください」という通知にすぎません。

---

#### 【4月30日】★ 仕入先への支払 ——お金が出ていく

C食品工業へ3月分の仕入代金を支払う。

```
 ■ 銀行口座の動き

   −551,650円  ← ★ 実際にお金が減る（鍋つゆ170ケース分）
   ＋ 3月分の他の仕入代金も同日に支払う

 ■ 帳簿の動き
   買掛金 551,650円 が消滅
```

> **ここがポイント**：**Bスーパーからの入金より1か月早く、お金が出ていきます。**
> 経理部長はこの日の前に資金繰り表で残高を確認し、
> 不足する見込みなら当座貸越などの手当てをします。

#### 【5月31日】★ 入金 ——お金が入ってくる

Bスーパーから銀行振込。

```
 ■ 銀行口座の動き

   ＋4,284,340円  ← ★ 実際にお金が増える
   （請求額 4,285,000円に対して 660円少ない）

 ■ 帳簿の動き：まだ売掛金は消えていない（消込をして初めて消える）
```

#### 【6月1日】入金消込 ——売掛金が消える

差額660円の原因を調査 → Bスーパー側が振込手数料を差し引いていたと判明。
契約ではBスーパー負担のため、翌月の入金で調整することで合意。

```
 ■ 帳簿の動き

   売掛金 4,285,000円 に対して
     − 消込   4,284,340円
     ＝ 残高       660円（翌月調整分として繰越）
```

> **ここがポイント**：**入金があっても、消込をするまで「どの請求が回収されたか」は確定しません。**
> 差額の原因が分からないまま放置すると、売掛金残高が実態と合わなくなります。

#### 【9月ごろ・半期の区切りで】リベート精算 ——後からお金が入る

C食品との年間契約に基づき、半期の仕入実績を集計してリベートを精算。

```
 ■ この取引に対応する分【Example】
   仕入 501,500円 × 1.5% ＝ 7,522円

 ■ 入り方（いずれか）【Varies】
   ・現金で振り込まれる → 銀行残高が増える
   ・買掛金と相殺される → 次回の支払額が減る

 ■ 実質粗利
   55,050 ＋ 7,522 ＝ 62,572円（実質粗利率 約9.6%）
```

### この追跡から読み取れること

| 気づき | 内容 |
|---|---|
| **お金が動いた日は2日だけ** | 3月10日から6月1日までの約80日間で、銀行口座が動いたのは**4月30日（出金）と5月31日（入金）**の2日だけ |
| **帳簿が動いた日は5日** | 3/14（買掛金発生）、3/28（売掛金・売上発生）、3/29（赤伝）、4/30（買掛金消滅）、6/1（売掛金消滅） |
| **出金が入金より31日早い** | この31日分の資金を会社が立て替えている |
| **粗利は3/28に確定したが、現金になったのは5/31** | **利益の発生とキャッシュの発生は別の日に起きる** |
| **取引の本当の利益は半期後まで分からない** | リベートの精算を待って初めて実質粗利が確定する |
| **660円の差異で、売掛金は完全には消えない** | 小さな差異でも放置すると残高が合わなくなる |

## この章のまとめ

1. **売上が立つ ≠ お金が入る。** 商品を渡してから代金が入るまでに数十日の時間差がある。
2. その時間差の間に残るのが **売掛金**（もらう権利）と **買掛金**（払う義務）。
   卸売業者は上流に払い、下流からもらう、**両方の時間差の間に立っている**。
3. 卸売業の特徴は、**締め日と支払サイトが得意先ごとに違う**こと。
   経理は月内に何度も締め処理と入金確認を行うことになる。
4. **支払が先、入金が後**になることがあり、その差を埋めるのが**運転資金**。
   運転資金は **売掛金 ＋ 在庫 − 買掛金** で概ね決まり、**売上が増えるほど増える**。
5. 卸売業は**粗利率が低く、在庫を速く回すことで年間の粗利額を確保する**構造にある【Typical】。
6. **リベート**は、取引ごとの粗利に表れず、後からまとめて入る。
   そのため取引時点では本当の利益が分からない。
7. 貸倒れは「利益を失う」のではなく「**仕入代金を自腹で払ったうえで商品も代金も失う**」こと。
   粗利率が低いほど、埋めるのに必要な売上が大きくなる。
