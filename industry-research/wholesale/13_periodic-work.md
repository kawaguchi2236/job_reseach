## 13-0. 先に押さえる ——卸売業の時間の構造

卸売業の定期業務は、**3つのリズムが重なって**できています。【Inference】

```
 ① 日次サイクル（1日で完結する）
    受注 → 引当 → 出荷指示の締切 → ピッキング → 出荷 → 翌朝納品
    ＊食品卸・日用品卸・医薬品卸で特に強い

 ② 月次サイクル（締め日で区切られる）
    売上の締め → 請求書の発行・送付 → 入金 → 消込 → 督促
    仕入の締め → 支払
    ＊得意先ごと・仕入先ごとに締め日が違うため、月の中で何度も発生する

 ③ 年次サイクル（取引条件と季節で区切られる）
    年間の取引条件交渉 → 価格改定 → 季節商品の仕込み → 決算 → 棚卸
    ＊メーカー・得意先の期（3月期・9月期等）に合わせて動く
```

> **【重要】この3つは独立して同時に走ります。**
> 内勤は日次の受注処理をしながら、月次の締め処理をし、その裏で商品部は年間の条件交渉をしています。
> 「今日は何の日か」ではなく「**今、どのサイクルのどこにいるか**」で業務が決まります。【Inference】

## 13-2. 常時 ——止まらずに受け続けているもの

| 業務 | 内容 | なぜ常時なのか | 担う機能 |
|---|---|---|---|
| 注文の受付 | 電話・FAX・メール・EDI・Web受発注で注文が届く | 得意先の都合で入るため、こちらの都合で止められない | ③ 受注・業務 |
| 在庫照会への回答 | 営業・得意先からの「今いくつある？」に答える | 商談は相手のタイミングで起きるため | ③ 受注・業務、⑤ 在庫管理 |
| クレーム・問い合わせの一次受け | 誤品・数量違い・破損・遅延の連絡を受ける | 納品後すぐに発覚するため | ② 営業、③ 受注・業務 |
| 温度監視【Varies】 | 冷蔵・冷凍設備の温度が規定範囲にあるかの監視 | 逸脱は商品の品質に直結するため | ⑥ 物流、⑩ 品質・衛生 |
| 与信残高の監視 | 受注入力時の与信超過チェック | 1件の受注が限度額を超えることがあるため | ③ 受注・業務、⑦ 与信 |

> **【Typical】** 「常時」とは「誰かがずっと張り付いている」という意味ではなく、
> **いつ来るか分からないので、来たら対応する体制がある**という意味です。

### 13-3-2. 【最重要】受注締切という区切り

日次業務の中で、卸売業に特有かつ最も重い区切りが**受注締切**です。

**受注締切（じゅちゅうしめきり）**
→ 「この時刻までに入った注文は、今日出荷する（＝翌日納品する）」という**社内の締切時刻**のこと。
→ 実務例：「当日12時締め・翌日納品」という運用なら、12時1分に入った注文は翌日の出荷分に回る。

**なぜ締切が必要なのか**
締切がなければ、倉庫はいつピッキングを始めればよいか分かりません。
ピッキング・仕分け・検品・積込には物理的な時間がかかり、配送車の出発時刻は動かせません。
そこから逆算して「これ以降の注文は今日のぶんに入れられない」という線を引いたものが受注締切です。【Inference】

> **【Varies】** 締切時刻は会社・得意先・商品の温度帯ごとに異なります。
> 同じ会社の中でも「量販店向けは前日18時締め、飲食店向けは当日11時締め」のように
> 複数の締切を持つことがあります。
> **本資料では特定の時刻を「一般的な締切」として示しません。**

### 13-3-3. 日次で「毎日必ず数字が出る」もの

卸売業では、1日が終わると次の数字が確定します。【Typical】

| 数字 | 誰が見るか | なぜ毎日見るのか |
|---|---|---|
| 当日の受注件数・受注金額 | ② 営業、① 経営 | 月の目標に対する進み具合が分かるため |
| 当日の出荷件数・出荷金額（≒売上） | ③ 業務、① 経営 | 売上は日々積み上がるため |
| 当日の欠品件数 | ③ 業務、④ 仕入 | 欠品が続くと得意先の発注そのものが減るため |
| 当日の入金額 | ⑧ 経理 | 支払に必要な資金の見通しに直結するため |
| 当日の入荷実績 | ⑤ 在庫、④ 仕入 | 明日以降の引当可能数が変わるため |

## 13-4. 週次

| 業務 | 内容 | 担う機能 | なぜ週次なのか |
|---|---|---|---|
| 定例発注 | 仕入先ごとに決められたサイクルでまとめて発注する | ④ 仕入 | 仕入先の生産・出荷サイクルや、まとめることで得られる条件があるため【Varies】 |
| 期限接近在庫の確認 | 賞味期限が近づいた在庫を洗い出し、売り切る手当てをする | ⑤ 在庫、② 営業 | 手遅れになる前に動く必要があるため（`07_goods.md` 7-7） |
| 滞留在庫の確認 | 一定期間動いていない在庫を確認する | ⑤ 在庫、④ 仕入 | 資金が固定され続けるため |
| 営業の進捗確認 | 受注状況・得意先の動き・案件の進捗を共有する | ② 営業、① 経営 | 月次の目標に対して途中で手を打つため |
| 配送コースの見直し | 得意先の増減・数量の変化に合わせてコースを調整する | ⑥ 物流 | 納品先の構成は少しずつ変わるため |
| 返品の整理 | 週の返品をまとめて処理・記録する | ⑥ 物流、③ 業務 | 1件ずつでは処理が細切れになるため【Varies】 |

> **【Varies】** 週次の業務は企業差が大きい領域です。
> 定例発注を日次で行う会社、営業会議を月次で行う会社もあります。

### 13-5-2. 【卸売業の特徴】締めは「月に1回」ではない

`08_money.md` 8-3 で見たとおり、**締め日は得意先ごとに異なります。**【Typical】
月末締めの得意先、20日締めの得意先、15日締めの得意先が混在するため、
経理から見ると**締め処理は月の中で何度も発生します。**

```
【Example：説明用の架空例】A食品商事の1か月

  10日   ── 10日締めの得意先（約20社）の締め → 請求書作成
  15日   ── 15日締めの得意先（約40社）の締め → 請求書作成
  20日   ── 20日締めの得意先（約110社）の締め → 請求書作成
  25日   ── 25日締めの得意先（約10社）の締め → 請求書作成
  月末   ── 月末締めの得意先（約200社）の締め → 請求書作成（最も多い）
         ── 並行して、仕入先への支払（仕入先ごとの支払日）
         ── 並行して、日次の受注・出荷は止まらない
```

**この「締めが分散している」ことが、経理・業務機能の業務量の山を作ります。**【Inference】

### 13-5-3. 締め処理で具体的に何をするのか

**締め処理（しめしょり）**
→ 締め日までの売上を集計して「この期間の請求額はいくらか」を確定させる作業のこと。
→ 実務例：3月1日〜3月31日に納品した分の売上をすべて集計し、返品・値引きを差し引いて、
　「B飲食店への3月分の請求額は42万8,500円」と確定する。

締め処理で確認される主な内容【Typical】：

| 確認すること | なぜ確認するのか |
|---|---|
| 未計上の出荷がないか | 出荷したのに売上が立っていないと、請求が漏れる |
| 単価の誤りがないか | 誤った単価のまま請求すると、得意先との照合で必ず差異が出る |
| 返品・値引きが反映されているか | 反映漏れは過大請求になる |
| 特売価格が正しく適用されているか | 特売期間の判定を誤ると単価が違う |
| リベート・センターフィー等の控除が正しいか | 契約条件と一致していないと差異になる |
| 得意先の請求データと一致するか（EDIの場合） | 一致しないと支払が保留される |

### 13-5-4. 入金消込

**消込（けしこみ）**
→ 入金された金額を、どの請求（どの売掛金）に対するものかを特定して、売掛金の残高から消すこと。
→ 実務例：B飲食店から428,000円の振込があった。請求額は428,500円。500円合わない。
　→ 振込手数料500円を先方が差し引いたためと分かり、手数料分を処理して消し込む。

**なぜ手間がかかるのか**【Typical】
- 振込名義が請求先の名義と違うことがある（代表者名義、屋号違い等）
- 複数の請求をまとめて1回で振り込まれることがある
- 一部だけ支払われることがある
- 振込手数料が差し引かれていることがある
- 相殺（こちらの買掛と相手の売掛を差し引きする）が絡むことがある

消し込めない入金があると、**売掛金の残高が実態と合わなくなり、督促の判断も与信の判断も狂います。**【Inference】

### 13-5-5. 棚卸【Varies】

**棚卸（たなおろし）**
→ 実際に在庫を数えて、帳簿上の在庫数と一致しているかを確認すること（`07_goods.md` 7-8）。
→ 実務例：倉庫の全商品を数え、システム上の数量と突き合わせる。差があれば原因を調べて修正する。

| 棚卸の種類 | 頻度 | 内容 |
|---|---|---|
| 実地棚卸（全品） | 年次〜半期【Varies】 | 全商品を数える。決算のために必須 |
| 循環棚卸（サイクルカウント） | 月次〜週次【Varies】 | 商品を区分に分け、順番に数えて1年で一巡させる |
| 重点棚卸 | 月次【Varies】 | 金額の大きい商品、動きの多い商品だけを数える |

> **【Varies】** どの方式を採るかは、倉庫の規模・SKU数・営業日の取り方によって異なります。
> 実地棚卸は出荷を止めて行うことが多いため、実施日は会社の事情で決まります。

| リベートの精算【Varies】 | 仕入先との条件に基づき、達成状況を確認して精算する（S25） | ④ 仕入、⑧ 経理 |

### 13-8-2. 【卸売業で重い】年間取引条件交渉

**年間取引条件交渉**
→ 1年分の取引条件をまとめて決める話し合いのこと。「年間商談」「条件交渉」などとも呼ばれます。
→ 実務例：メーカーX社と、翌年度の仕切価格、販売数量目標、達成時のリベート率、
　新商品の導入条件、販促費の負担割合を決める。

**なぜ年に1回まとめて決めるのか**【Inference】
- 商品が数千点あるため、1点ずつ都度交渉していては業務が回らない
- リベートは「年間でいくら売ったか」を条件にすることが多く、期間の区切りが必要
- 得意先側も年間で棚割・仕入方針を決めるため、それに合わせる必要がある

**この交渉の結果が、翌1年間の粗利の大部分を決めます。**
`12_business-model.md` 12-3-1 で見たとおり、仕入原価が1%変われば、営業利益とほぼ同じ規模の金額が動きます。【Inference】

> **【Varies】** 交渉の時期は、仕入先・得意先の決算期（3月期・9月期等）に合わせて動くため、
> 会社ごと・取引先ごとに異なります。「毎年○月」と一律には言えません。

### 13-8-3. 【卸売業で重い】価格改定対応

価格改定は、卸売業者にとって**1つの案件ではなく、連鎖する一連の作業**です。【Typical】

```
【価格改定が起きたときの流れ】【Typical】

 ① 仕入先から価格改定の通知が届く（改定日・対象商品・改定幅）
    ↓
 ② 商品部が影響を計算する（対象SKU数、月間の取扱数量、粗利への影響額）
    ↓
 ③ 改定前の在庫をどうするか決める（改定前価格で仕入れた在庫をいつまで、いくらで売るか）
    ↓
 ④ 得意先への売価改定を決める（そのまま転嫁するか、一部を自社で吸収するか、得意先ごとに判断）
    ↓
 ⑤ 営業が得意先へ通知・交渉する（改定日、対象商品、新価格）
    ↓
 ⑥ 業務が価格マスタを改定日で切り替える（旧価格・新価格の適用日を正しく設定する）
    ↓
 ⑦ 改定日をまたぐ受注・返品の単価を確認する
```

> **【Example】**（説明用の架空例）
> 4月1日からの価格改定の通知が2月に届いた。対象は醤油類48SKU、仕入価格が平均4%上がる。
> A食品商事は、3月中に旧価格で仕入れた在庫を4月以降も一定期間抱えることになる。
> 得意先へは4月1日から新価格を適用したいが、量販店の中には「棚替えのタイミングに合わせて
> 4月中旬から」という先もある。
> その場合、**4月1日〜中旬は「高く仕入れて、安く売る」期間**が発生する。
> 内勤はこの期間の単価設定を価格マスタに正しく登録しなければならない。

**改定日をまたぐ返品の単価**も実務上の論点になります。【Typical】
3月に180円で納品した商品が4月に返品された場合、返品の単価を180円とするか新価格とするかを
事前に決めておかないと、請求の照合で差異が出ます。

### 13-8-4. 季節商品の仕込み

**仕込み（しこみ）**
→ 需要の山に間に合わせるため、**事前に仕入れて在庫を積んでおく**こと。
→ 実務例：年末の需要に向けて、10月から段階的に在庫を積み増す。

| 仕込みで決めること | なぜ難しいか |
|---|---|
| いつから積み始めるか | 早すぎると資金が長く寝る、遅すぎると仕入先の生産枠が埋まる |
| どれだけ積むか | 足りなければ売り逃し、多すぎればシーズン後に滞留する |
| どこに置くか | 倉庫の保管能力に限りがある（特に冷蔵・冷凍） |
| 売れ残ったらどうするか | シーズン商品は翌年まで持てないものがある |

> **【Inference】** 仕込みは「在庫と資金のリスクを取って、売上の山を取りに行く」判断です。
> `12_business-model.md` 12-6 で見た運転資金の増加が、この時期に集中して起きます。

### 13-8-5. 展示会・商談会

| 種類 | 何をする場か | 誰が関わるか |
|---|---|---|
| 仕入先（メーカー）主催の展示会 | 新商品の説明を受け、翌シーズンの取扱を検討する | ④ 仕入、② 営業、① 経営 |
| 自社主催の展示会・商談会 | 得意先を招き、自社の取扱商品・新商品・提案を見せる | ② 営業、④ 仕入、① 経営 |
| 業界団体・業界紙主催の展示会 | 業界全体の動向、新規の仕入先・得意先との接点 | ① 経営、④ 仕入 |

> **【Typical】** 自社主催の展示会は、卸売業者にとって
> 「1日で多数の得意先に、多数の商品を一度に見せられる場」という位置づけを持ちます。
> 展示会での商談結果が、その後の受注・仕込み・仕入条件に連動します。

> **【Varies】** 展示会を開催するかどうか、年に何回開催するかは会社により異なります。
> 開催時期は、シーズンの立ち上がり（春夏物／秋冬物、年末商戦の前 等）に合わせて設定されます【Typical】。

特売は「普段の3倍の数量を、指定された日に、指定された店舗へ」という形で来ます。

## 13-11. 季節性 ——山と谷はどこにあるか【Level 2】

> **【Varies】** 季節の山谷は業種・商材によってまったく異なります。
> 以下は「どういう軸で山谷ができるか」を示すもので、具体的な月を断定するものではありません。

| 業種 | 山ができる要因 | 業務への影響 |
|---|---|---|
| **食品卸** | 年末年始、行楽期、気温（冷やす・温める商材）、学校給食の長期休暇、お中元・お歳暮【Varies】 | 仕込み時期の在庫積み増し、配送量の増加、臨時要員の手配 |
| **建材卸** | 工事の工期、年度末の工事集中、天候（屋外工事）【Varies】 | 納期の集中、資金の一時的な逼迫、現場納品の増加 |
| **機械・工具卸** | 得意先の設備投資の時期、年度末の予算消化【Varies】 | 見積・納期回答の増加、機械の据付手配 |
| **医薬品卸** | 感染症の流行期、薬価改定の時期【Varies】 | 需要の急増、価格改定に伴う在庫評価 |
| **アパレル卸** | シーズンの立ち上がり、セール期【Varies】 | 事前の仕込み、シーズン末の在庫処分、返品の集中【Varies】 |

**季節性が業務に効いてくる4つの場面**【Inference】

1. **仕込み**（山の前）：在庫と資金を先に投じる
2. **ピーク対応**（山の中）：倉庫の作業量・配送量が増え、人員と車両の手当てが要る
3. **山の後**：余った在庫の処置（値下げ・返品・廃棄）
4. **谷の時期**：在庫を減らし、条件交渉や整理業務に充てる

1. 卸売業の定期業務は、**日次サイクル・月次（締め）サイクル・年次（条件・季節）サイクル**の
   3つが同時に走っている。
2. 日次の背骨は**受注締切**。ここで出荷内容が確定し、倉庫と配送が動く。
   締切時刻は会社・得意先・温度帯ごとに異なる【Varies】。
3. 月次の中心は**締め処理→請求→入金→消込**。
   締め日が得意先ごとに違うため、締め処理は月に何度も発生する。
4. 年次で最も重いのは**年間取引条件の交渉**と**価格改定対応**。
   仕入原価が1%動けば営業利益と同じ規模の金額が動くため、ここが翌1年の粗利を決める。
5. **季節商品の仕込み・特売対応**は、在庫・資金・倉庫・配送の4つを同時に動かすイベント。
6. **法定期限**（源泉所得税の翌月10日、法人税・消費税の2か月以内、労働保険の年度更新、
   社会保険の定時決定、定期健康診断）は会社の都合で動かせない。
7. 曜日・日付レベルで固定されているのは**法定期限と、契約で決めた締め日・支払日**だけである。
   それ以外の「いつやるか」は会社により異なる【Varies】。
