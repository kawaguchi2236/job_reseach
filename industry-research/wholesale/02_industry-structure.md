# CHAPTER 2　卸売業の業界構造

> このファイルは卸売業の**いちばん重要な章**です。
> 卸売業の本質は「**誰から買って、誰に売るか**」にあり、それを決めているのが**商流**だからです。
> 商品そのものよりも「取引のルート」が価値を持つ——これが卸売業を理解する鍵になります。

---

## 11-1. プレイヤー（業界に登場する人・会社）

### 11-1-1. 登場人物の全体像

```
 ┌──────────┐
 │ 原料供給者 │（農家・漁業者・鉱山・素材メーカー）
 └─────┬────┘
       ▼
 ┌──────────┐      ┌────────┐
 │  メーカー   │◀────▶│  商社   │（原料調達・輸入・大口取引）
 │ （製造者）  │      └────────┘
 └─────┬────┘
       │  ＝ 特約店契約・代理店契約
       ▼
 ┌─────────────────┐
 │  一 次 卸（元卸・特約店）  │  ★中小企業もここにいる
 └─────┬───────────┘
       │
       ├───────────────┐
       ▼                       │
 ┌─────────────────┐      │
 │  二 次 卸（地方卸）        │ ★中小企業の多くはここ
 └─────┬───────────┘      │
       │                       │
       ▼                       ▼
 ┌──────────────────────────┐
 │ 得意先（小売業／飲食店／工事業者／病院・薬局／工場） │
 └─────┬────────────────────┘
       ▼
 ┌──────────┐
 │   消費者    │（小売業の場合）
 └──────────┘

 【横から支える人たち】
 　物流事業者（運送会社・路線便）／倉庫業者／
 　金融機関／与信管理会社・信用調査会社／損害保険会社／システム事業者
```

### 11-1-2. プレイヤー別の役割

| プレイヤー | 何をする人か | 中小卸売業者から見た関係【Typical】 |
|---|---|---|
| **原料供給者** | 農産物・水産物・素材を生産する | 生鮮系の卸では産地との直接取引もある |
| **メーカー（製造業者）** | 商品を製造する。多くの場合、自社では小口配送や小売店への日々の営業をしない | **仕入先**。価格・供給量・販促の条件を決める立場。特約店契約の相手 |
| **商社** | 原料調達・輸入・大口の売買・金融機能を担う。総合商社と専門商社がある | 輸入品や大口の仕入れで**仕入先**になる。案件によっては競合にもなる |
| **一次卸（元卸・特約店）** | メーカーから直接仕入れ、広域に販売する | 自社が一次卸である場合もあれば、一次卸が**仕入先**である場合もある |
| **二次卸（地方卸・サブ卸）** | 一次卸から仕入れ、地域の小規模事業者に販売する | 自社がここに位置することが多い。または**得意先**になる |
| **代理店・特約店** | メーカーと契約し、指定された商品・地域で販売する立場 | 「卸売業者であること」と「特約店であること」は両立する（後述） |
| **小売業** | 消費者に販売する | 主要な**得意先** |
| **飲食店・給食事業者** | 食材を仕入れて調理し提供する | 食品卸の主要な**得意先**。発注が直前になりやすい |
| **工事業者・工務店** | 建物を施工する | 建材卸の主要な**得意先**。納品先が現場になる |
| **医療機関・調剤薬局** | 医薬品を使用・調剤する | 医薬品卸の**得意先** |
| **物流事業者** | 商品を運ぶ（自社便で運びきれない分、遠距離、大量） | **外注先**。路線便・チャーター便・宅配便を使い分ける |
| **倉庫業者** | 商品を保管する（自社倉庫に入りきらない分、特殊温度帯） | **外注先**。営業倉庫・寄託倉庫として利用する |
| **金融機関** | 運転資金の融資、手形・振込の決済 | **資金の出し手**。在庫と売掛金を賄う運転資金の相談先 |
| **与信管理会社・信用調査会社** | 取引先の経営状態を調査・評価する | 新規取引先の与信判断、既存先の見直しに使う |
| **損害保険会社** | 商品・倉庫・車両の事故、取引信用（貸倒れ）の保険 | 在庫・配送・売掛金のリスクをカバーする |

### 11-1-3. 中小卸売業者はどこにいるか

**【Typical】** 中小卸売業者の典型的な位置は次の3パターンです。

| パターン | 仕入先 | 得意先 | 特徴 |
|---|---|---|---|
| **A：地域の二次卸** | 一次卸（元卸） | 地域の個人商店・飲食店・小規模事業者 | 小口・多頻度配送が強み。品揃えの幅で勝負 |
| **B：特定メーカーの地域特約店（一次卸）** | メーカー直 | 地域の小売店・事業者・二次卸 | 特定メーカーの商品知識と販売権が強み |
| **C：特定分野の専門卸** | メーカー＋一次卸＋商社 | 全国または広域の同業種顧客 | 分野を絞った深い品揃えが強み |

多くの中小卸売業者は、これらが**混ざった状態**にあります。【Varies】
たとえば「X社の商品は一次卸（特約店）として直接仕入れ、他社の商品は二次卸として一次卸から仕入れる」
というように、**商品ごとに自社の立ち位置が変わる**のが実態です。

## 11-2. 商流 ——「誰から買って誰に売るか」

> ここが卸売業の心臓部です。時間をかけて読んでください。

### 11-2-1. 商流とは何か

**商流（しょうりゅう）**
→ **商品の「所有権」と「代金請求の権利」が、誰から誰へ移っていくかの流れ**のこと。
→ 実務例：「メーカー → 卸 → 小売」と商品を売買したとき、所有権も代金請求権もこの順に移る。

**物流（ぶつりゅう）**
→ **商品そのもの（現物）が、物理的にどこからどこへ運ばれるかの流れ**のこと。
→ 実務例：「工場の倉庫 → 卸の倉庫 → 店舗のバックヤード」と現物が動く。

### 11-2-2. 【最重要】商流と物流は一致しないことがある

初心者が最初につまずくのがここです。

> **商品の伝票が通るルート（商流）と、商品の現物が動くルート（物流）は、別物です。**

```
 ■ 一致する場合（標準）

   商流：メーカー ──▶ 卸 ──▶ 小売
   物流：メーカー ──▶ 卸 ──▶ 小売
                （倉庫を経由する）


 ■ 一致しない場合（直送）

   商流：メーカー ──▶ 卸 ──▶ 小売   ← 伝票・請求は卸を通る
   物流：メーカー ─────────▶ 小売   ← 現物は卸を素通り
```

**なぜこうなるのか**
現物を卸の倉庫に一度入れて出すと、積み替えの手間と時間がかかります。
大ロットの注文や、かさばる商品、鮮度が重要な商品では、
**現物はメーカーから直接届けたほうが早くて安い**からです。【Typical】

しかし、それでも**取引の関係（商流）は卸を通したまま**にします。理由は後述します。

### 11-2-3. 卸売業特有の3つの形態

#### ① 帳合（ちょうあい）

**用語**
**帳合**
→ 「**この得意先には、この卸売業者を通して商品を供給する**」というルートが決まっている状態。
　「A商店の帳合は当社」「あの店は他社帳合だ」のように使います。
→ 実務例：スーパーB社が調味料メーカーC社の商品を仕入れるとき、
　必ず卸のD社を経由する取り決めになっている。B社がC社に直接注文しても、
　伝票はD社を通り、B社への請求はD社から出る。

**なぜ帳合があるのか**【Typical】

| 誰にとって | 帳合がある理由 |
|---|---|
| メーカー | 全国の小売店1軒ずつと直接取引すると、口座管理・請求・回収の事務が膨大になる。卸にまとめたい |
| 小売店 | 多数のメーカーと個別に取引するより、卸1社に注文をまとめたい。支払いも1本にまとまる |
| 卸 | 「このルートを通る取引」が自社の売上の土台になる |

**帳合が変わる（帳合替え）とは**
得意先が「これからは別の卸を通す」と決めること。
卸売業者にとっては、その得意先分の売上がまるごと動く出来事です。【Typical】

**独占禁止法との関係**
> **【Fact】** 公正取引委員会の「流通・取引慣行に関する独占禁止法上の指針」（平成3年7月11日制定）には
> 「**帳合取引の義務付け**」という項目があり、事業者が卸売業者に対して販売先の小売業者を特定させ、
> 小売業者が特定の卸売業者としか取引できないようにする行為は、
> **価格維持効果が生じる場合には不公正な取引方法に該当し違法となる**とされています
> （出典：流通・取引慣行に関する独占禁止法上の指針／公正取引委員会）。
>
> つまり「帳合という商習慣が存在すること」と「帳合を義務付けること」は別の問題であり、
> 後者は独占禁止法上の論点になります。

#### ② 代理店契約・特約店契約

**用語**
**特約店（とくやくてん）**
→ メーカーと契約を結び、**そのメーカーの商品を仕入れて販売する権利を持つ卸売業者**のこと。
　商品を**買い取る**のが基本です。
→ 実務例：「当社はE社の九州地区特約店です」＝E社の商品をE社から直接仕入れ、九州で販売できる。

**代理店（だいりてん）**
→ メーカーに代わって販売活動を行う立場。
　**買い取らずに手数料を受け取る形**もあれば、**買い取る形**もあり、業界により使い方が異なります。
→ 実務例：機械業界では「メーカー → 代理店 → 販売店 → ユーザー」という段階構成が一般的。

> **【Varies】** 「代理店」「特約店」「販売店」「ディーラー」の呼び名と実際の契約内容の対応は
> **業界・メーカーによってバラバラ**です。名称だけで判断せず、契約書で
> 「買い取るのか／手数料なのか」「地域や顧客の限定があるか」「価格の決め方はどうか」
> を確認するのが実務です。

**契約に書かれる主な内容【Typical】**

| 項目 | 内容 |
|---|---|
| 取扱商品の範囲 | どの商品を扱えるか |
| 販売地域・販売先の範囲 | どのエリア・どの客層に売れるか |
| 仕切価格 | メーカーが卸に売る価格の決め方 |
| 最低取扱高・目標 | 年間いくら以上仕入れるか |
| リベート（販売奨励金） | 条件を満たした場合に支払われる金銭の基準 |
| 販促協力 | 展示会参加、販促資材の負担 |
| 契約期間・解約条件 | 何年契約か、どのような場合に終了するか |

#### ③ 直送（ちょくそう）

**用語**
**直送**
→ **商品の現物はメーカー（または上位の卸）から得意先へ直接届き、
　伝票と請求は卸売業者を通る**取引形態のこと。
→ 実務例：小売チェーンが1台分のトラック満載でジュースを注文した。
　現物は飲料メーカーの工場から小売の物流センターへ直行するが、
　「メーカー→卸」「卸→小売」の2つの売買が成立しており、請求書は卸から小売へ出る。

**直送の流れ**

```
 ① 得意先 ──注文──▶ 卸売業者
 ② 卸売業者 ──発注（直送指示）──▶ メーカー
 ③ メーカー ──現物を配送──▶ 得意先（★卸の倉庫を通らない）
 ④ 得意先 ──受領（検収）──▶ 受領書・検収データ
 ⑤ メーカー ──出荷実績データ──▶ 卸売業者
 ⑥ 卸売業者：仕入計上と売上計上を同時に行う
 ⑦ 卸売業者 ──請求書──▶ 得意先
 ⑧ メーカー ──請求書──▶ 卸売業者
```

**なぜ直送するのか**【Typical】
- 現物の積み替え（倉庫入荷 → 保管 → ピッキング → 出荷）の手間と費用がなくなる
- 卸の倉庫を経由しないぶん、納品までの時間が短くなる
- 大型品・重量物・大量品は、倉庫の保管能力を圧迫せずに済む

**なぜ商流だけ卸を通すのか**【Typical】
- 得意先は請求書・支払先を1本にまとめたい（卸にまとめれば経理が1本で済む）
- メーカーは小売1社ずつの与信管理・代金回収をしたくない
- 卸は、その得意先との取引関係（帳合）を維持できる
- 卸が商品情報の提供・クレーム対応・アフター対応を引き続き担う

> **初心者が混乱しやすいポイント**
> 「現物を触っていないのに、なぜ卸の売上になるのか？」
> → **売買契約が成立しているから**です。卸はメーカーから買い（仕入）、得意先へ売って（売上）います。
> 　卸は**所有権を持ち、代金を支払い、代金を請求し、回収できないリスクも負っています。**
> 　現物を自社倉庫に入れるかどうかは、売買が成立しているかどうかとは別の話です。【Inference】

### 11-2-4. 代表的な商流パターン

#### パターン1：標準型（在庫販売）

```
 メーカー ──▶ 卸（倉庫で在庫）──▶ 得意先
   商流：○          ○                 ○
   物流：○          ○                 ○
```
最も基本的な形。卸が在庫を持ち、注文に応じて出荷します。

#### パターン2：二次卸経由型

```
 メーカー ──▶ 一次卸 ──▶ 二次卸 ──▶ 小規模な得意先
```
一次卸が広域をカバーし、二次卸が細かい配送と地域の顧客対応を担います。

#### パターン3：直送型

```
 商流：メーカー ──▶ 卸 ──▶ 得意先
 物流：メーカー ─────────▶ 得意先
```

#### パターン4：センター納品型（大手小売向け）【Typical】

```
 商流：メーカー ──▶ 卸 ──▶ 小売本部
 物流：卸の倉庫 ──▶ 小売の物流センター ──▶ 各店舗
```

**用語**
**物流センター（センター）**
→ 小売チェーンが自社（または委託先）で運営する、店舗向けの中継倉庫。
→ 実務例：卸はセンターに一括納品し、そこから各店舗へは小売側が配送する。

**センター納品の特徴**
- 卸は店舗1軒ずつではなくセンター1か所に納品すればよいため、配送効率が上がる
- 一方で、**センターフィー**（後述）という費用が発生することがある
- 納品の日時・荷姿（パレット、通い箱、ラベル）が細かく指定される

#### パターン5：商社が入る型

```
 海外メーカー ──▶ 商社（輸入・通関）──▶ 卸 ──▶ 得意先
```
輸入品や大口取引では、商社が資金・為替・通関の機能を担って商流に入ります。【Typical】

#### パターン6：卸売市場を経由する型（生鮮食料品）

> **【Fact】** 中央卸売市場には、次の立場の事業者が関わります
> （出典：市場に関係する人達／東京都中央卸売市場）。
>
> | 立場 | 定義 |
> |---|---|
> | **出荷者** | 生産者、出荷団体、集荷業者、輸入業者など。全国から市場に商品を供給する |
> | **卸売業者** | 農林水産大臣の許可を得て、出荷者から販売委託された品物や買付集荷した品物を、市場内卸売場において仲卸業者または売買参加者に卸売する者。手数料制で運営される |
> | **仲卸業者** | 開設者の許可を得て、卸売業者が行う売買取引に参加し、買い受けた物品を市場内の店舗・荷捌施設で仕分けし、または調製して販売する者 |
> | **売買参加者** | 小売商・加工業者・地方卸売市場業者・大口消費者などのうち、開設者の承認を受けて、卸売業者が行う卸売に仲卸業者と同じ立場で参加できる者 |
> | **買出人** | 仲卸業者から購入する小売商、加工業者、飲食業者、学校給食など |
> | **関連事業者** | 開設者の許可を受けて、買出人を中心とする市場利用者を対象に業務を営む者（運送業、冷蔵庫業、加工業など） |

```
 産地（農家・漁業者）──▶ 出荷団体 ──▶ 【卸売市場】
                                        卸売業者 ──▶ 仲卸業者 ──▶ 小売・飲食店
                                                   └──▶ 売買参加者 ──▶ 小売・飲食店
```

> **注意**：ここでの「卸売業者」は**卸売市場法上の特別な立場**を指しており、
> 一般の卸売業者（本資料が主に扱う対象）とは意味が異なります。混同しやすい点です。

### 11-2-5. 商流パターン別「現物」と「伝票」の対応表

| パターン | 現物はどこを通るか | 伝票・請求はどこを通るか | 卸の在庫になるか |
|---|---|---|---|
| 標準型 | メーカー → 卸倉庫 → 得意先 | メーカー → 卸 → 得意先 | なる |
| 二次卸経由型 | メーカー → 一次卸倉庫 → 二次卸倉庫 → 得意先 | 同じ | なる（両方） |
| 直送型 | メーカー → 得意先 | メーカー → 卸 → 得意先 | **ならない** |
| センター納品型 | メーカー → 卸倉庫 → 小売センター → 店舗 | メーカー → 卸 → 小売本部 | なる |
| 通過型（クロスドック） | メーカー → 卸倉庫（保管せず即日仕分けして出荷）→ 得意先 | メーカー → 卸 → 得意先 | ほぼ持たない【Varies】 |

## 11-3. バリューチェーン ——卸売業の中で価値が積み上がる順序

**バリューチェーン**
→ 「どの仕事が、どの順番で、どんな価値を足しているか」を並べたもの。
→ 実務例：卸売業なら「商品を選ぶ → 仕入れる → 在庫する → 売る → 届ける → 回収する」の連なり。

```
┌───────────────────────────────────────────────────────┐
│                    【主活動】価値を直接生む仕事                              │
├───────┬───────┬───────┬───────┬───────┬───────┤
│ ① 商品調達 │ ② 仕入・  │ ③ 在庫・  │ ④ 営業・  │ ⑤ 受注・  │ ⑥ 物流・  │
│  ・商品選定 │   仕入交渉 │   保管管理 │   商品提案 │   出荷手配 │   配送・納品│
├───────┴───────┴───────┴───────┴───────┴───────┤
│                   ⑦ 代金回収・与信管理（カネを確実に回収する）               │
├───────────────────────────────────────────────────────┤
│                    【支援活動】主活動を支える仕事                            │
│   経理・財務／人事・総務／情報システム／品質・衛生管理／経営管理              │
└───────────────────────────────────────────────────────┘
```

### 各活動が生む価値【Typical】

| # | 活動 | ここで生まれる価値 | これがないとどうなるか |
|---|---|---|---|
| ① | 商品調達・商品選定 | 「売れる品揃え」をつくる | 倉庫が売れない商品で埋まる |
| ② | 仕入・仕入交渉 | 仕入価格を下げ、粗利の元をつくる | 売っても粗利が残らない |
| ③ | 在庫・保管管理 | 「注文された瞬間に出せる状態」をつくる | 欠品して注文を失う／古い在庫が廃棄になる |
| ④ | 営業・商品提案 | 得意先に「買う理由」を提供する | 注文が来ない |
| ⑤ | 受注・出荷手配 | 注文を正確に商品と数量へ変換する | 誤出荷・誤納品でクレームになる |
| ⑥ | 物流・配送・納品 | 約束の日時に約束の場所へ届ける | 得意先の営業に穴が開く |
| ⑦ | 代金回収・与信管理 | 売上を**現金**に変える | 売上は立つのにお金が入らない |

> **【Inference】** 卸売業では、②（仕入交渉）と⑦（回収）が利益に直結します。
> ②で粗利の幅が決まり、⑦で回収できなければ粗利はゼロどころかマイナスになるためです。

## 11-4. サプライチェーン ——在庫はどこに滞留するか

**サプライチェーン**
→ 原料から消費者までの、供給の連なり全体。
→ 実務例：「小麦畑 → 製粉会社 → 製麺メーカー → 卸 → スーパー → 食卓」。

```
 原料供給者          メーカー           卸売業者          小売業者        消費者
    │                  │                 │                │              │
    ▼                  ▼                 ▼                ▼              ▼
 ┌──────┐      ┌──────┐      ┌──────┐     ┌──────┐   ┌────┐
 │原料在庫 │─────▶│製品在庫 │─────▶│卸在庫   │────▶│店頭在庫 │──▶│購入 │
 │        │      │(工場倉庫)│      │(物流拠点)│     │(バック  │   │    │
 └──────┘      └──────┘      └──────┘     │ ヤード) │   └────┘
                                                   └──────┘
    ◀────────── 注文情報・需要情報が上流へ遡る ──────────
```

### 11-4-1. 在庫がどこに、なぜ滞留するか

| 在庫の置き場 | 誰の在庫か | そこに在庫がある理由【Typical】 |
|---|---|---|
| 工場倉庫（メーカー） | メーカー | まとめて作ったほうが安いため（生産ロットの都合） |
| **卸の倉庫** | **卸売業者** | **注文が来てから作っていては間に合わないため。需要の波を吸収するため** |
| 小売の物流センター | 小売業者 | 各店舗へ小分けして配るため |
| 店舗のバックヤード | 小売業者 | 売場に補充するため |
| 店頭の売場 | 小売業者 | 消費者がいつでも買えるようにするため |

> **【Inference】** 卸の倉庫は、サプライチェーンの中で
> **「大ロットの世界（メーカー側）」と「小ロット・多頻度の世界（小売側）」の変換点**に位置します。
> 大きい単位で入ってきたものを、小さい単位で毎日出していく——ここが卸の倉庫の役割です。

### 11-4-2. 在庫が「多すぎる／少なすぎる」とどうなるか

| 状態 | 起きること | 影響を受ける人 |
|---|---|---|
| 在庫が少なすぎる | **欠品**が発生し、得意先に納品できない | 得意先（売場に穴が開く）、営業（信用を失う） |
| 在庫が多すぎる | 保管スペースを圧迫する。資金が在庫に固定される。期限切れ・陳腐化のリスク | 経理・財務（資金繰り）、倉庫（置き場） |

**用語**
**欠品（けっぴん）**
→ 注文を受けたのに在庫がなく、納品できない状態。
→ 実務例：「明日の納品分、A商品が5ケース欠品です」と営業から得意先に連絡する。

**【Varies】** 欠品時の対応（代替品の提案、次回納品での充当、他倉庫からの移動、
メーカーへの緊急発注）は、商品・得意先・会社の方針によって異なります。

### 11-4-3. 情報は「下流から上流へ」遡る

サプライチェーンでは、**モノは上流から下流へ、情報（注文）は下流から上流へ**流れます。

```
 モノの流れ：  メーカー ━━━━━━━━━━━━━━━▶ 消費者
 情報の流れ：  メーカー ◀━━━━━━━━━━━━━━━ 消費者
               （受注情報・売れ行き情報・発注情報）
```

卸売業者は、この**両方向の流れが交差する場所**にいます。
下流（得意先）からの注文を受けて上流（メーカー）へ発注し、
上流からの商品を受けて下流へ出荷します。【Inference】

## 11-6. 卸売業特有の商習慣（商流理解に必要な範囲）

> ここでは「商流を理解するために最低限知っておくべき商習慣」を概説します。
> 各制度の詳細・運用ルール・帳票は `15_rules-customs.md` `10_documents.md` で扱います。

### 11-6-1. 建値（たてね）と仕切価格（しきりかかく）

**用語**
**建値**
→ メーカーが示す**基準となる価格**のこと。「この商品はこの価格帯で流通させたい」という目安。
→ 実務例：「この商品の建値は1ケース3,000円」。

**仕切価格（仕切価／しきりか）**
→ **メーカーが卸売業者に売る価格**、あるいは**卸売業者が得意先に売る価格**のこと。
　立場によって「仕入側から見た仕切」「販売側から見た仕切」の両方の使い方をします。
→ 実務例：「A社からの仕切は2,400円、うちからB商店への仕切は2,700円」。

```
 【価格の重なり方（イメージ）】

  メーカーの建値        3,000円
      │
      ├─ メーカー → 卸 の仕切価格   2,400円  ← 卸の仕入価格
      │
      ├─ 卸 → 小売 の仕切価格       2,700円  ← 卸の販売価格（＝小売の仕入価格）
      │                                          粗利＝2,700 − 2,400 ＝ 300円
      └─ 小売の店頭売価              3,480円  ← 消費者が払う価格
```

> **【Fact】** 公正取引委員会の「流通・取引慣行に関する独占禁止法上の指針」では、
> 流通業者の**販売価格を制限する行為（再販売価格維持行為）**は、流通業者間の価格競争を
> 減少・消滅させることになるため、**原則として不公正な取引方法として違法**とされています
> （出典：流通・取引慣行に関する独占禁止法上の指針／公正取引委員会）。
>
> **初心者が誤解しやすい点**：メーカーが「希望小売価格」「建値」を**示すこと**と、
> 「その価格で売れ」と**拘束すること**は別です。後者が独占禁止法上の論点になります。

### 11-6-2. リベート（販売奨励金／割戻し）

**用語**
**リベート**
→ 商品の売買代金とは**別に**、一定期間後に仕入先から卸売業者へ（または卸売業者から得意先へ）
　支払われる金銭のこと。「販売奨励金」「割戻し」とも呼びます。
→ 実務例：「今期の仕入高が1億円を超えたので、メーカーから2%のリベートが支払われた」。

> **【Fact】** 公正取引委員会の指針では、リベートは
> 「**仕切価格とは区別されて取引先に制度的に又は個別の取引ごとに支払われる金銭**」と説明されています。
> また、**リベートの供与自体が直ちに独占禁止法上問題となるものではない**としつつ、
> 供与の方法によっては取引先事業者の事業活動を制限することとなり問題となる場合があるとされ、
> **供与の基準を明確にし、取引の相手方に示すことが望ましい**とされています
> （出典：流通・取引慣行に関する独占禁止法上の指針／公正取引委員会）。

**なぜリベートという仕組みがあるのか**【Typical】
- 販売量・販売努力に応じて事後的に報いるため
- 得意先ごと・時期ごとに実質的な価格を調整するため
- 販促活動（陳列、チラシ掲載、新商品導入）への協力に対して支払うため

**リベートの代表的な種類**【Typical】

| 種類 | 支払いの条件 |
|---|---|
| 数量リベート・累進リベート | 一定期間の仕入高・販売数量が基準を超えた場合 |
| 販売促進リベート | 特売・陳列・新商品導入など、販促活動への協力に対して |
| 決済リベート | 早期に支払った場合、現金決済した場合 |
| 目標達成リベート | あらかじめ設定された目標を達成した場合 |

**利益への効き方（ここが分かりにくい）**
リベートは商品ごとの粗利には表れず、**期間がたってからまとめて入ってくる**ことが多いため、
「商品単位では粗利が薄いのに、期末に精算すると利益が出る」という状態が起こり得ます。【Typical】
そのため、**リベートを見込んだ利益管理**が必要になります。
（詳細は `12_business-model.md` で扱います）

**医薬品卸における例**
> **【Fact】** 厚生労働省の「医療用医薬品の流通改善に向けて流通関係者が遵守すべきガイドライン」
> （平成30年1月23日施行、令和8年3月4日改訂）では、
> 「**割戻し（リベート）は卸機能の適切な評価に基づくものとし、割戻し、アローアンスのうち
> 仕切価に反映可能なものについては仕切価へ反映した上で、整理・縮小を行う**」ことなどが示されています
> （出典：医療用医薬品の流通改善に向けて流通関係者が遵守すべきガイドライン／厚生労働省）。

**用語（関連）**
**一次売差（いちじばいさ）マイナス**
→ 卸売業者にとって、**売る価格（納入価）が仕入価格（仕切価）を下回る状態**のこと。
→ **【Fact】** 上記ガイドラインでは「一次売差マイナス」を「納入価が仕切価よりも低い状況」と
　注記しています（出典：同ガイドライン／厚生労働省）。
→ この状態では商品単体では粗利がマイナスになり、リベート（割戻し）で補う構造になります。【Inference】

### 11-6-3. 返品

**用語**
**返品**
→ いったん納品した商品が、得意先から卸売業者へ、あるいは卸売業者から仕入先へ戻ってくること。
→ 実務例：「季節商品の売れ残り10ケースが返品で戻ってきた」。

**返品が発生する主な場面**【Typical】
- 誤出荷・誤発注（数量違い、品違い）
- 輸送中・保管中の破損、汚損
- 期限が近づいた商品（食品の場合）
- 季節商品・シーズン商品の売れ残り
- 契約上あらかじめ返品が認められている取引（委託販売など）

**なぜ返品が重要なのか**【Inference】
返品は**売上をさかのぼって取り消す**処理です。
売上・在庫・請求・入金消込のすべてに影響するため、記録が正確でないと
「請求額が合わない」「在庫数が合わない」という形で後の工程に波及します。

**独占禁止法との関係**
> **【Fact】** 公正取引委員会の「大規模小売業者による納入業者との取引における特定の不公正な取引方法」
> （平成17年5月13日公正取引委員会告示第11号。通称「大規模小売業告示」）では、
> 大規模小売業者が納入業者に対して行う **①不当な返品 ②不当な値引き ③不当な委託販売取引
> ④特売商品等の買いたたき ⑤特別注文品の受領拒否 ⑥押し付け販売等 ⑦納入業者の従業員等の不当使用等
> ⑧不当な経済上の利益の収受等 ⑨要求拒否の場合の不利益な取扱い ⑩公正取引委員会への報告に対する
> 不利益な取扱い** の10類型が定められています
> （出典：大規模小売業者による納入業者との取引における特定の不公正な取引方法／公正取引委員会）。
>
> **【Fact】** 同告示における「大規模小売業者」とは、
> **前事業年度の売上高が100億円以上の小売業者**、または
> **一定規模以上の店舗面積を有する店舗（東京都特別区および指定都市は3,000㎡以上、
> その他の市町村は1,500㎡以上）を有する小売業者**をいいます（出典：同告示／公正取引委員会）。

> **卸売業者にとっての意味**：卸売業者は大規模小売業者に対する「納入業者」の立場になることがあり、
> この告示の保護対象となり得ます。同時に、自社が仕入先メーカーに対して行う返品についても、
> 独占禁止法上の**優越的地位の濫用**が問題となり得る立場にあります。【Inference】

### 11-6-4. センターフィー（物流センター使用料）

**用語**
**センターフィー**
→ 小売業者が運営する物流センターに卸売業者が納品する際、
　センターの運営費用の一部として卸売業者が負担する金銭のこと。
→ 実務例：「センター納品分の売上に対して○%をセンターフィーとして支払う」。

**なぜ発生するのか**【Typical】
卸売業者にとっては、店舗1軒ずつに配送するより、センター1か所に納品するほうが配送効率が上がります。
一方、センターから各店舗への配送は小売業者側が行うため、
「卸が節約できた配送コストの一部を負担する」という考え方で費用が設定されます。

**論点**
> **【Fact】** 大規模小売業告示の「**不当な経済上の利益の収受等**」は、
> 自己の取引上の地位が納入業者に優越していることを利用して、
> 正当な理由がないのに、納入業者に**本来提供する必要のない金銭・役務その他の経済上の利益**を
> 提供させることを禁じています（出典：同告示／公正取引委員会）。
>
> **【Inference】** したがって、センターフィーそのものが直ちに問題になるわけではなく、
> **費用の算出根拠が明確であるか、卸売業者が得る利益（配送効率化の効果）に見合っているか、
> 事前に十分協議されているか**が実務上の論点になります。

### 11-6-5. 締め日と支払サイト

**用語**
**締め日（しめび）**
→ 「いつからいつまでの取引を1回分としてまとめるか」を区切る日。
→ 実務例：「20日締め・翌月末払い」＝前月21日〜当月20日の取引をまとめて請求し、翌月末に支払われる。

**支払サイト**
→ 締め日から実際に支払われるまでの期間。
→ 実務例：「月末締め翌月末払い」なら、サイトは約30日。

```
 【20日締め・翌々月10日払いの例】【Example】（説明用の架空例です）

  6/21 ────────── 7/20     7/末        8/10
   │                 │        │           │
   └─ この間の取引 ──┘        │           │
      （売上が発生）            │           │
                     締め日    請求書送付   入金
                               （7月末）    （8月10日）

  → 6月21日に納品した商品の代金が入るのは 8月10日。約50日後。
```

> **【Inference】** 卸売業では、**仕入代金の支払期日が、売上代金の入金日より先に来る**ことがあります。
> この場合、その差額を自社の資金または借入で立て替えることになります。
> これが「卸売業は運転資金が必要な商売」と言われる構造的な理由です。
> （詳細は `08_money.md` `12_business-model.md` で扱います）

### 11-6-6. 食品卸に特有の納品期限の商習慣（3分の1ルール）

> **【Fact】** 農林水産省は、食品業界における「**3分の1ルール**」を
> 「賞味期間を製造日から賞味期限までの3段階に分割し、最初の区間を納品期限、次の区間を販売期限とする商慣習」
> と説明しています。
> また、納品期限を緩和する食品小売事業者の数は、令和4年度の240事業者から
> **令和5年10月末時点で297事業者**に増加したと公表されています
> （出典：商慣習見直しに取り組む食品製造・小売事業者の公表／農林水産省）。

```
 【3分の1ルールのイメージ】

 製造日 ├──────────┼──────────┼──────────┤ 賞味期限
        │  ① 納品期限  │  ② 販売期限  │  ③ 消費期間  │
        │              │              │              │
        └─ 卸はここまでに小売へ納品しなければならない
                       └─ 小売はここまでに売り切る
```

**卸売業者への影響**【Inference】
納品期限を過ぎた在庫は、その得意先へ納品できなくなります。
卸売業者は、期限の残り日数を見ながら在庫を管理し、
納品可能な日数が残っている商品から順に出荷する必要があります。

## この章のまとめ

1. 卸売業の本質は「**誰から買って誰に売るか**」＝**商流**にある。
2. **商流（伝票と所有権の流れ）と物流（現物の流れ）は一致しないことがある。**
   その代表が**直送**（現物はメーカーから得意先へ直行、伝票は卸を通る）。
3. **帳合**＝「この得意先はこの卸を通す」というルートの取り決め。卸の売上の土台になる。
4. **特約店・代理店契約**が、卸とメーカーの関係を規定する。名称と実態は業界ごとに異なる。
5. 商流を理解するには、**建値・仕切価格・リベート・返品・センターフィー・締め日**という
   6つの商習慣を押さえる必要がある。
6. サプライチェーン上、卸の倉庫は「**大ロットの世界と小ロット・多頻度の世界の変換点**」にある。
