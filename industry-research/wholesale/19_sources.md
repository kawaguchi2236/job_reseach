## Phase C 作業上の記録（後続エージェントへの申し送り）

- **e-Gov法令検索は API 経由（`https://laws.e-gov.go.jp/api/1/lawdata/<法令ID>`）で条文を取得できる。**
  法令IDは「元号コード＋年＋種別＋番号」（例：倉庫業法＝`331AC0000000121`、
  独占禁止法＝`322AC0000000054`、健康保険法＝`211AC0000000070`）。
  条文を正確に引用したい場合、この方法が最も確実。
- **国税庁（nta.go.jp）の一部ページは Shift_JIS** のため、`curl | iconv -f SHIFT_JIS -t UTF-8` が必要。
- **政府広報オンライン（gov-online.go.jp）は WebFetch だと HTTP 403** になる。
  `common/base-statistics.md` §3 の curl 手順（ブラウザUA付与）で取得できる。
- WebSearch には1セッションあたりの回数上限がある。**法令原文は e-Gov API、
  制度解説は所管官庁ページを直接 curl** するほうが、検索を消費せず確実。
