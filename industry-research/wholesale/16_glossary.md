**最終更新**：2026-09-16

>
> **前半（16-1〜16-8）は用語集**です。卸売業の現場で交わされる会話を理解するための語を、

# 前半：用語集

## 16-1. 商流・取引の形に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **卸売** | おろしうり | 商品を仕入れて、**事業者（小売店・飲食店・メーカー等）に**販売すること | 「うちは卸売だから、一般のお客様には売りません」。最終消費者に売れば小売になる |
| **商流（しょうりゅう）** | — | 商品の**所有権と代金**が動く流れ。誰が誰に売り、誰が誰に払うか | 「商流はうちを通っているが、物流は直送」。伝票が通る経路のこと |
| **物流（ぶつりゅう）** | — | 商品そのもの（モノ）が動く流れ | 「商流と物流が一致しない」＝伝票は通るが商品は通らない（直送） |
| **帳合（ちょうあい）** | — | どのメーカーの商品を、**どの卸を通して**仕入れるかという経路の取り決め | 「C社のX社商品の帳合を持っている」＝その組み合わせの取引を担っている。帳合が移ると売上がまとめて動く |
| **帳合先（ちょうあいさき）** | — | 伝票（商流）が通る取引相手 | 「帳合先はD卸、納品先はE店」のように、伝票の相手と納品の場所が違うことがある |
| **納品先（のうひんさき）** | — | 商品を**物理的に届ける場所** | 得意先の本部と納品先の店舗が違うのが普通。配送はここへ行く |
| **一次卸（いちじおろし）** | — | メーカーから**直接**仕入れる立場の卸売業者 | 「この商品は一次卸からしか買えない」。商流上の段数を表す言葉で、会社の大小とは別 |
| **二次卸（にじおろし）** | — | 一次卸から仕入れて、さらに小売店等に売る卸売業者 | 1社の中で、商品によって一次卸だったり二次卸だったりする |
| **特約店（とくやくてん）** | — | メーカーと特別な契約を結び、その商品を取り扱う卸売業者 | 「X社の特約店です」＝有利な条件で仕入れる代わりに、販売目標や地域の責任を負う |
| **代理店（だいりてん）** | — | 本人（メーカー等）に代わって取引を行う立場。実務では買取を伴う販売店の意味でも使われる【Varies】 | 名称だけでは買取か手数料かが分からない。**契約の実質を確認する必要がある** |
| **口銭（こうせん）** | — | 仲介・取次に対して受け取る手数料 | 「口銭を抜く」＝手数料を取る。商品代金は売上に立たない取引 |
| **直送（ちょくそう）** | — | 仕入先から得意先へ商品が直接届く取引。伝票は卸を通る | 大口の注文や、自社倉庫を通す必要のない商品で使われる |
| **口座（こうざ）** | 取引口座 | 取引先として登録され、掛売で取引できる状態のこと | 「口座を開く」＝与信審査を通して取引を始める。「口座を止める」＝取引停止 |
| **得意先（とくいさき）** | — | 商品を販売する相手（小売店、飲食店、施設等） | 「得意先マスタ」＝販売先の情報を登録した台帳 |
| **仕入先（しいれさき）** | — | 商品を仕入れる相手（メーカー、一次卸、商社等） | 「仕入先マスタ」＝仕入元の情報を登録した台帳 |
| **相見積（あいみつもり）** | あいみつ | 同じ商品について、複数社から見積を取って比較すること | 「あいみつになっています」＝他社と価格で比較されている状態 |
| **PB（ピービー）** | プライベートブランド | 小売業者や卸売業者が自社ブランドとして企画・販売する商品 | 通常の売買ではなく製造委託になるため、**取適法の対象になりうる**（`15_rules-customs.md`） |
| **NB（エヌビー）** | ナショナルブランド | メーカーが自社ブランドで販売する商品 | 複数の卸が扱えるため価格競争になりやすい |

## 16-2. 価格に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **建値（たてね）** | — | 基準となる価格。標準小売価格・メーカー希望小売価格・標準卸価格など | 「建値の何掛けで」という形で、価格交渉の基準になる |
| **仕切価格（しきりかかく）** | 仕切値（しきりね） | **実際に取引される価格**。特にメーカー・上位卸が自社に売る価格 | 「仕切りはいくら？」＝「実際にいくらで買っている（売っている）？」 |
| **掛率（かけりつ）** | — | 建値に対して実際の取引価格が**何%か** | 「9掛け」＝建値の90%。「七掛け五分」＝75%。**粗利率とは別物** |
| **納価（のうか）** | 納入価格 | 得意先に納品する価格 | 「特売の納価を下げてほしい」＝特売期間中の納入価格の引下げ要請 |
| **上代（じょうだい）／下代（げだい）** | — | 上代＝小売価格、下代＝卸価格【Varies：業種により使い方が異なる】 | アパレル卸等で使われる。「下代は上代の55%」のように使う |
| **値入率（ねいれりつ）** | マークアップ率 | **仕入原価**に対して、いくら上乗せしたかの割合 | 分母が仕入原価。**粗利率（分母は売価）と混同しやすい** |
| **特売価格** | — | 期間・数量を限って設定される通常より安い価格 | 価格マスタに**適用期間付き**で登録する。期間の判定を誤ると単価が狂う |
| **価格改定** | — | 仕入価格・売価を変更すること | 改定日をまたぐ受注・返品の単価をどうするかが実務上の論点になる |
| **値引（ねびき）** | — | 取引のその場で価格を下げること | 粗利がその場で減る。**リベートとは別物** |

## 16-3. 受注・出荷に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **受注（じゅちゅう）** | — | 得意先から注文を受けること | 受注しただけでは売上にならない。出荷・納品して初めて売上になる |
| **受注締切（じゅちゅうしめきり）** | — | 「この時刻までの注文は今日出荷する」という社内の締切時刻 | 配送車の出発時刻から逆算して決まる。得意先・温度帯ごとに複数持つことがある【Varies】 |
| **引当（ひきあて）** | 在庫引当 | 受注に対して、在庫の中からその分を**確保すること** | 「引き当てておいて」＝他の注文に取られないよう押さえること |
| **有効在庫（ゆうこうざいこ）** | フリー在庫 | 実在庫 − 引当済（＋入荷予定）。**今から売れる数** | 「実在庫100、引当80だから、有効在庫は20」 |
| **欠品（けっぴん）** | — | 注文を受けたのに在庫がなくて出荷できないこと | 「Bさんとこ、醤油が欠品です」＝営業へ連絡し、得意先の判断を仰ぐ |
| **フィルレート** | Fill Rate／受注充足率 | 注文された数のうち、実際に出荷できた数の割合 | 「フィルレート96%」。得意先から評価指標として求められることがある【Varies】 |
| **出荷指示（しゅっかしじ）** | — | 「何を、いくつ、どこへ出す」という倉庫への指示 | 受注締切とともに確定し、倉庫へ渡される |
| **ピッキング** | — | 出荷指示に基づき、倉庫の棚から商品を集める作業 | 「ピッキングに入ります」＝倉庫の作業が始まった |
| **摘み取り方式（つみとりほうしき）** | オーダーピッキング | **1件の注文ごと**に棚を回って商品を集める方式 | 1件あたりの点数が多いとき、得意先数が少ないときに向く |
| **種まき方式（たねまきほうしき）** | トータルピッキング | **商品ごとにまとめて集めてから**、得意先別に分ける方式 | 同じ商品を多くの得意先に少しずつ出すときに向く |
| **方面別仕分け（ほうめんべつしわけ）** | — | 配送コース（方面）ごとに商品を分けること | 積込の順番を決めるために必要。「A方面に3件、B方面に5件」 |
| **出荷検品（しゅっかけんぴん）** | — | 出荷する商品が注文どおりかを、出す前に確認する作業 | ここで止められなかった間違いは、そのまま得意先に届く |
| **積込（つみこみ）** | — | 配送車に商品を積む作業 | **降ろす順の逆に積む**のが基本。コースが決まらないと始められない |
| **納品（のうひん）** | — | 得意先に商品を届けること | ここで初めて売上が計上されるのが一般的 |
| **検収（けんしゅう）** | — | 得意先が、届いた商品の内容を確認して受け取ること | 検収が済まないと請求の根拠にならない |
| **受領書（じゅりょうしょ）** | 物品受領書 | 得意先が「確かに受け取った」ことを示す書類 | 納品書の控えに受領印をもらう形が多い |
| **誤出荷（ごしゅっか）** | — | 違う商品・違う数量・違う納品先に出してしまうこと | 再配送・返品処理・信用低下の3つを同時に生む |
| **リードタイム** | — | 注文してから納品されるまでにかかる時間 | 「このメーカーのリードタイムは中4日」＝発注から4日後に入荷する |
| **御用聞き（ごようきき）** | — | 卸売業者の側から得意先に連絡して、注文を聞き出すこと | 小口の得意先に対して、内勤や営業が行う【Varies】 |
| **ルートセールス** | — | 決まった得意先を定期的に訪問して営業する形態 | 卸売業の営業の基本形。新規開拓中心の営業とは動き方が違う |
| **内勤（ないきん）／外勤（がいきん）** | 業務／営業 | 内勤＝社内で受注処理をする人、外勤＝社外で得意先を回る人 | 卸売業の組織を理解する最大の鍵（`03_company-structure.md` 3-2-3） |

## 16-4. 在庫・商品に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **SKU（エスケーユー）** | Stock Keeping Unit | 在庫を管理する**最小の商品単位** | 「醤油1L」と「醤油500mL」は別SKU。「4,500SKU扱っています」 |
| **JANコード** | — | 商品につけられた日本の共通の商品識別番号（バーコード） | ハンディターミナルで読み取り、商品の取り違えを機械が検知する |
| **ロット** | — | 同じ条件で製造された商品のまとまり。ロット番号で識別する | 回収が起きたとき「どのロットをどこへ出したか」を答えるために必要 |
| **賞味期限（しょうみきげん）** | — | **おいしく食べられる期限**。過ぎてもすぐ食べられなくなるわけではない | 比較的日持ちする食品に表示される |
| **消費期限（しょうひきげん）** | — | **安全に食べられる期限**。過ぎたら食べないほうがよい | 日持ちしない食品（弁当、惣菜等）に表示される |
| **3分の1ルール** | 三分の一ルール | 賞味期間の**3分の1以内**で小売店舗に納品するという食品業界の慣例 | 卸売業者が在庫を置いていられる期間が、賞味期限ではなく納品期限で決まる（`15_rules-customs.md` 15-7-15） |
| **先入先出（さきいれさきだし）** | FIFO | 先に入荷したものから先に出荷すること | 期限のある商品では必須。棚の並べ方・ピッキングの指示で実現する |
| **発注点（はっちゅうてん）** | — | 「在庫がこの数を下回ったら発注する」という基準の数 | 「発注点を切った」＝補充発注のタイミングが来た |
| **安全在庫（あんぜんざいこ）** | — | 需要のブレや納期の遅れに備えて、余分に持っておく在庫 | 「安全在庫を厚くする」＝欠品は減るが、在庫金額と廃棄リスクは増える |
| **発注残（はっちゅうざん）** | — | 発注したが、まだ入荷していない数量 | これが見えないと**二重発注**が起きる |
| **在庫回転率** | — | 一定期間に在庫が**何回入れ替わったか** | 「年16回転」。原価ベースか売価ベースかで数値が変わるので確認が必要 |
| **在庫回転日数** | — | 在庫がひととおり入れ替わるのに**何日かかるか** | 「23日ぶんの在庫を持っている」。期限との比較で使う |
| **交差比率（こうさひりつ）** | — | **粗利率 × 在庫回転率**。在庫に投じたお金がどれだけ粗利を生んだか | 粗利率だけ・回転率だけでは判断を誤るため、両方を1つの数字で見る |
| **滞留在庫（たいりゅうざいこ）** | — | 一定期間動いていない在庫 | 「寝ている在庫」。資金が固定され、時間とともに価値が下がる |
| **デッドストック** | — | もはや売れる見込みがない在庫。廃番品、規格変更品など | 最終的に廃棄・処分の対象になる |
| **棚卸（たなおろし）** | — | 実際に在庫を数えて、帳簿の数と一致しているか確認すること | 決算のために年次で全品を数える（実地棚卸）ほか、循環棚卸もある |
| **棚卸差異（たなおろしさい）** | — | 実際の在庫数と帳簿上の在庫数の差 | 差が出たら原因を調べる（記録漏れ、誤出荷、破損、紛失など） |
| **循環棚卸** | サイクルカウント | 商品を区分に分けて順番に数え、1年で一巡させる方式 | 出荷を止めずに棚卸精度を保つための方法【Varies】 |
| **ロケーション** | 棚番地 | 倉庫内で商品が置かれている場所を表す番地 | 「A-03-2」のように表す。WMSが管理する中心の情報 |
| **ゴールデンゾーン** | — | 倉庫内で最も取りやすい場所（出荷口に近い、腰の高さ等） | ABC分析のA区分商品をここに置くのが一般的【Typical】 |
| **温度帯（おんどたい）** | — | 商品を保管・輸送する温度の区分（常温・冷蔵・冷凍等） | 「3温度帯対応の倉庫」＝常温・冷蔵・冷凍のすべてを扱える |
| **定番品（ていばんひん）** | — | 常時取り扱い、常に在庫を持っている商品 | 「定番は在庫、特注は都度手配」という使い分けをする |
| **ABC分析** | — | 商品や得意先を金額の大きい順に並べ、A・B・Cに分ける分析方法 | 「4,500SKUすべてに同じ手間はかけられない」ため、配分を決めるのに使う |
| **荷姿（にすがた）** | — | 商品がどんな形でまとまっているか（ケース、ボール、バラ等） | 「ケースで10、バラで3」のように受注の単位になる |
| **ケース／ボール／バラ** | — | ケース＝外装単位、ボール＝中間単位、バラ＝1個単位 | 卸売業では同じ商品を3つの単位で受注することがある【Varies】 |
| **パレット** | — | 商品を載せて運ぶための台。フォークリフトで動かす | 「1パレット○ケース」が仕入・保管の単位になる |

## 16-5. お金に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **売上高（うりあげだか）** | — | 商品を販売した代金の合計（税抜） | 卸売業では**その大部分が仕入先へ支払うお金**である点に注意 |
| **売上原価（うりあげげんか）** | — | 売れた商品の仕入原価の合計 | 売上高から引くと粗利になる |
| **粗利（あらり）** | 売上総利益 | 売上高 − 売上原価。**会社に残る最初の金額** | 「この案件、粗利いくら出る？」＝いくら残るか |
| **粗利率（あらりりつ）** | 荒利率 | 粗利 ÷ **売上高** × 100（%） | 分母は売上高。仕入原価ではない。卸売業では低い水準になる |
| **売掛金（うりかけきん）** | — | 商品を売ったが、まだ回収していない代金 | 「売掛が3億円ある」＝それだけ立て替えている |
| **買掛金（かいかけきん）** | — | 商品を仕入れたが、まだ支払っていない代金 | 「買掛の支払日」＝仕入先に払う日 |
| **掛売（かけうり）** | 信用取引 | 商品を先に渡し、代金は後日まとめて受け取る取引 | 卸売業の取引の基本形。だから与信が重要になる |
| **与信（よしん）** | — | 取引相手を信用して、後払いを認めること | 「与信を付ける」＝掛売の枠を与える |
| **与信限度額（よしんげんどがく）** | — | その得意先に対して、いくらまで掛売してよいかの上限 | 超えると受注入力の時点で警告が出る仕組みが一般的【Typical】 |
| **締め日（しめび）** | — | 「この日までの売上をまとめて請求する」という区切りの日 | 得意先ごとに異なる。20日締め、月末締め等 |
| **支払サイト／回収サイト** | — | 締めてから実際に支払う（入金される）までの期間 | 「月末締め翌々月末払い」＝最長で約2か月後に入金 |
| **消込（けしこみ）** | 入金消込 | 入金された金額を、どの請求に対するものか特定して売掛金から消すこと | 名義違い・一部入金・手数料差引があると手間がかかる |
| **相殺（そうさい）** | — | こちらの買掛と相手の売掛を差し引きすること | 同じ相手と売り買い両方がある場合に行われる【Varies】 |
| **リベート** | 販売奨励金／報奨金 | 条件を満たしたときに**後から支払われる**金銭 | 伝票上の粗利と実質の粗利がずれる原因になる |
| **センターフィー** | 物流センター使用料 | 得意先の物流センターを経由して納品する際に支払う費用 | 粗利を直接削る。独占禁止法上の論点を持つ【Varies】 |
| **協賛金（きょうさんきん）** | — | 得意先の催事・チラシ・開店等に協力する名目で支払う金銭 | 同上 |
| **貸倒れ（かしだおれ）** | — | 売った代金が回収できずに損失になること | 粗利率10%なら、300万円の貸倒れを取り戻すのに3,000万円の売上が必要 |
| **運転資金（うんてんしきん）** | — | 支払が先・入金が後という時間差を埋めるためのお金 | 在庫回転日数＋売掛回転日数−買掛回転日数 ぶん必要になる |
| **資金繰り（しきんぐり）** | — | いつ、いくら入って、いくら出て、手元にいくら残るかの見通し | 利益とは別に管理する。黒字でも資金が足りなくなることがある |
| **手形（てがた）** | 約束手形 | 「いつまでにいくら支払う」ことを記載した証券 | 期日まで待つか、期日前に金融機関で換金（割引）する【Varies】 |
| **でんさい** | 電子記録債権 | 手形と同様の機能を電子的に記録して扱う仕組み | 手形に代わる決済手段として使われる【Varies】 |
| **インボイス** | 適格請求書 | 正確な適用税率・消費税額等を伝えるための書類 | 名称は問わない。納品書でも要件を満たせばインボイスになる |
| **労働分配率** | — | 人件費 ÷ **粗利** × 100（%） | 分母は売上高ではなく粗利。間違えると意味のない数字になる |
| **営業利益** | — | 粗利 − 販売費及び一般管理費。本業で稼いだ利益 | 卸売業は売上が大きいため、営業利益率は小さな数字になる |
| **交際費／販促費** | — | 得意先・仕入先との関係維持や販売促進に使う費用 | 粗利から支払われる。粗利率が低い卸売業では影響が大きい |

| **ピッキングリスト** | — | 倉庫で何をいくつ集めるかを示したリスト | 紙の場合と、端末に表示される場合がある |

# 後半：初心者が間違えやすいこと

> ここからが本ファイルの核心です。
> 用語を1つずつ覚えるより、**似た2つの違いを理解するほうが、実務では圧倒的に効きます。**
> 各項目は「**何と何が違うか**」「**なぜ混同するか**」「**実務でどう効いてくるか**」の順に書いています。

## 16-9. 混同しやすい概念

### ① 卸売 ≠ 小売

**何が違うか**
- **卸売**：商品を**事業者**（小売店、飲食店、施設、他の卸売業者）に販売する
- **小売**：商品を**最終消費者**に販売する

**なぜ混同するか**
どちらも「商品を仕入れて売る」ため、行為としては同じに見えます。
また、同じ会社が両方を行っていることもあります。

**実務でどう効いてくるか**

| | 卸売 | 小売 |
|---|---|---|
| 相手 | 事業者 | 最終消費者 |
| 代金の受け取り | **掛売（後払い）が基本** | **現金・カード（その場）が基本** |
| 1回あたりの金額 | 大きい | 小さい |
| 与信 | 必要 | 原則不要 |
| 粗利率 | 低い | 卸売より高い |
| 中小企業の定義（中小企業基本法） | 資本金1億円以下 **または** 従業員100人以下 | 資本金5,000万円以下 **または** 従業員50人以下 |

**【Fact】** 中小企業基本法第2条の定義では、卸売業と小売業で基準が異なります
（出典：中小企業基本法／e-Gov法令検索）。
**【Fact】** 統計上も、卸売販売額と小売販売額のどちらが多いかで格付けが決まります
（出典：令和3年経済センサス‐活動調査 産業別集計（卸売業，小売業に関する集計）結果の概要／総務省・経済産業省）。

> 会社の分類が変われば、**中小企業向けの制度の対象になるかどうか**まで変わります。

---

### ② 商流 ≠ 物流

**何が違うか**
- **商流**：商品の**所有権と代金**が動く流れ（誰が誰に売り、誰が誰に払うか）
- **物流**：商品そのもの（**モノ**）が動く流れ

**なぜ混同するか**
通常の取引では、商流と物流が同じ経路をたどります。
「メーカー → 卸 → 小売」という図を見ると、モノも代金もその順に動くように見えます。

**実務でどう効いてくるか**
**直送**では、この2つが一致しません。

```
【通常】  メーカー ──モノ＋伝票──▶ 卸の倉庫 ──モノ＋伝票──▶ 得意先

【直送】  メーカー ─────────モノ─────────────▶ 得意先
              └──伝票──▶ 卸 ──伝票──▶ 得意先
```

直送では、卸売業者は**商品に一度も触れないまま、仕入計上と売上計上を行います。**
そのため、

- 検品を自社でできない（品質・数量の確認が納品先任せになる）
- 納品完了を自社で確認できない（受領の証跡の入手が必要）
- 在庫が動かないのに、売上と仕入が立つ

という状態になります。
**「うちの倉庫を通っていないから、うちの売上じゃない」は誤りです。**

---

### ③ 帳合先 ≠ 納品先

**何が違うか**
- **帳合先**：伝票（商流）が通る取引相手。請求する相手
- **納品先**：商品を物理的に届ける場所

**なぜ混同するか**
小さな取引では、注文をくれた相手と商品を届ける場所が同じです。
「B飲食店から注文が来て、B飲食店に届ける」なら区別する必要がありません。

**実務でどう効いてくるか**
チェーン展開している得意先では、ほぼ必ず分かれます。

```
【Example：説明用の架空例】
  受注元・請求先（帳合先）： 飲食チェーンD社 本部
  納品先               ： D社 ○○店、△△店、□□店（合計12店舗）

  → 受注は本部から1本で来るが、納品は12か所に分かれる
  → 請求は本部宛に1通にまとめる（合計請求）
  → 12店舗それぞれに納品書を渡す
```

さらに、**同じ商品を別の卸を経由して納める**場合もあります。

```
【Example：説明用の架空例】
  A食品商事 ──伝票──▶ E卸（帳合先） ──伝票──▶ F店
  A食品商事 ──────モノ───────────────▶ F店（納品先）

  → A食品商事はE卸に請求し、E卸がF店に請求する
  → しかし商品はA食品商事がF店へ直接届ける
```

**間違えると何が起きるか**
- 請求先を納品先にしてしまい、支払われない
- 納品先を帳合先にしてしまい、商品が本部に届いてしまう
- 与信の管理単位を間違える（与信は**帳合先**に対して設定する）

---

### ④ 受注 ≠ 売上（≠ 出荷）

**何が違うか**

```
  受注    ：注文を受けた（まだ何も動いていない）
    ↓
  引当    ：在庫を確保した（まだ動いていない）
    ↓
  出荷    ：商品が倉庫から出た（まだ相手に渡っていない）
    ↓
  納品・検収：相手が受け取った ← ★ここで売上計上
```

**なぜ混同するか**
「注文が取れた」と聞くと、もう売上になったように感じます。
営業の現場では「今月○○万円受注した」という言い方をするため、余計に混ざります。

**実務でどう効いてくるか**
- 受注しても、**欠品すれば売上にならない**
- 受注しても、**キャンセルされれば売上にならない**
- 受注しても、**与信が通らなければ出荷できない**
- 月末に受注した分は、納品が翌月なら**翌月の売上**になる

> **【重要】** 「受注残」（受注したがまだ出荷していない分）は、
> 売上ではありませんが、**在庫の引当を食っています。**
> 有効在庫を計算するときには必ず差し引きます。

---

### ⑤ 売上 ≠ 入金

**何が違うか**
- **売上**：商品を引き渡したときに計上される。**お金はまだ入っていない**
- **入金**：実際にお金が振り込まれること

**なぜ混同するか**
「売れた＝お金が入った」という日常の感覚が、掛売の世界では通用しないためです。

**実務でどう効いてくるか**

```
【Example：説明用の架空例】月末締め・翌々月末払いの得意先に、3月20日に納品した場合
  3月20日  納品・検収 → 売上計上（428,500円）
  3月31日  締め
  4月上旬  請求書の発行・送付
  5月31日  入金          ← 売上計上から 72日後

  この72日間、A食品商事は428,500円を立て替えている。
  その間に、この商品の仕入代金の支払は済ませている。
```

**だから卸売業では、「今月いくら売れたか」と「今月いくら入ってきたか」を別々に管理します。**
`14_kpi.md` の売掛回転日数と資金繰りが必要になるのは、この時間差のためです。

---

### ⑥ 発注 ≠ 仕入計上

**何が違うか**
- **発注**：仕入先に「これをください」と注文した。**まだ買掛金は発生しない**
- **仕入計上**：商品が届いて検品が済み、買掛金が発生した

**なぜ混同するか**
発注した時点で「買った」気持ちになるためです。

**実務でどう効いてくるか**
- 発注しただけの分は**発注残**として管理する（在庫にも買掛金にも入らない）
- 発注残が見えないと、**同じ商品を二重に発注**する
- 発注点の判定は「実在庫＋発注残−引当済」で行うのが一般的【Typical】

> **【Example】**（説明用の架空例）
> 実在庫30本、発注残120本、引当済25本。
> 単純に実在庫30本だけを見て「発注点50本を下回っている」と判断すると、
> さらに120本を発注してしまい、合計270本の在庫を抱えることになる。

---

### ⑦ 在庫がある ≠ 売れる在庫がある

**何が違うか**
- **実在庫**：倉庫に物理的にある数
- **有効在庫**：実在庫 − 引当済。**今から売れる数**

さらに、有効在庫があっても**売れない在庫**があります。

| 種類 | なぜ売れないか |
|---|---|
| 引当済在庫 | すでに他の受注に確保されている |
| 期限が足りない在庫 | 納品期限（3分の1ルール等）を満たせない |
| 破損・汚損品 | 品質上、出荷できない |
| 出荷保留中の在庫 | 品質確認中、回収対象、ロット不明等 |
| 得意先専用在庫【Varies】 | 特定の得意先向けに確保してある |
| 別の倉庫・別の温度帯にある在庫 | 今日の出荷に間に合わない |

**なぜ混同するか**
在庫一覧の画面には「100」と表示されるためです。

**実務でどう効いてくるか**
営業が実在庫だけを見て「大丈夫です」と回答し、
出荷日に商品が足りないことが判明する——これは卸売業で最も起きやすいトラブルの一つです。【Typical】

> **だから内勤は「引当が取れてから確定します」と言います。**
> 「在庫がある」ことと「その注文に対して確保できた」ことは、別のことです。

### ⑧ 粗利 ≠ 利益

**何が違うか**

```
  売上高
   − 売上原価
  ──────────
  ＝ 粗利（売上総利益）      ← ここはまだ「利益」ではない
   − 販売費及び一般管理費（人件費・物流費・家賃・車両費・通信費・保険料 等）
  ──────────
  ＝ 営業利益               ← 本業で稼いだ利益
```

**なぜ混同するか**
現場では「この案件、粗利が出た」という言い方をするため、粗利＝儲けと感じます。

**実務でどう効いてくるか**
卸売業では、粗利から払う経費（特に**物流費**）が大きいため、
**粗利が出ていても利益が出ていない取引**があります。

> **【Example】**（説明用の架空例）
> 1回の配送コストが2,500円の会社で、
> 1回1.5万円の納品・粗利率18% → 粗利2,700円。配送費2,500円を引くと**200円**。
> 「粗利率18%の良いお客様」に見えても、配送費を引くとほとんど残っていない。

`14_kpi.md` 14-6-1 の「1配送あたり売上」が見られるのは、この構造のためです。

### ⑨ 粗利率 ≠ 掛率

**何が違うか**

```
  建値 200円
  仕入原価 150円 → 仕入側の掛率 75%（150 ÷ 200）
  売価     180円 → 販売側の掛率 90%（180 ÷ 200）

  粗利額 ＝ 180 − 150 ＝ 30円
  粗利率 ＝ 30 ÷ 180 ＝ 16.7%   ← 掛率とはまったく違う数字
```

- **掛率**：**建値**に対する割合
- **粗利率**：**売価**に対する儲けの割合

**なぜ混同するか**
どちらも「%」で表され、価格の会話の中で同時に出てくるためです。
「9掛けで売ってる」と聞くと、なんとなく粗利が10%あるように錯覚します。

**実務でどう効いてくるか**
- 「90掛けで売っている」＝粗利率10%、ではありません（上の例では16.7%）
- 掛率だけを見て「利益が出ている」と判断すると、**仕入側の掛率を見落とします**
- 粗利率は**仕入価格と売価の両方**が分からないと計算できません

> **【重要】** 現場の会話では、掛率は「取引条件」、粗利率は「儲け」を指します。
> **掛率が上がる＝儲かる、ではありません。**
> 販売側の掛率が上がっても、仕入側の掛率も同時に上がっていれば粗利は変わりません。

---

### ⑩ 仕入価格 ≠ 建値

**何が違うか**
- **建値**：基準として示される価格（標準小売価格、メーカー希望小売価格、標準卸価格など）
- **仕入価格（仕切価格）**：**実際に支払っている価格**

**なぜ混同するか**
価格表に載っているのは建値であることが多く、それが「値段」だと思ってしまうためです。

**実務でどう効いてくるか**
- **建値で粗利を計算すると、まったく違う数字になります**
- 建値は取引先によらず同じですが、仕切価格は取引先ごと・数量ごとに違います
- 建値が実態から離れている商材では、建値をいくら見ても実際の利益が分かりません【Varies】

> **【Example】**（説明用の架空例）
> 建値200円の商品を、A食品商事は150円で仕入れ、180円で売っている。
> 建値だけを見て「200円の商品を180円で売っているから20円損している」と考えるのは誤り。
> 実際には30円の粗利が出ている。

---

### ⑪ 返品 ≠ 値引き

**何が違うか**
- **返品**：商品そのものが戻ってくる。**モノが動く**
- **値引き**：商品は戻らず、**金額だけを下げる**

**なぜ混同するか**
どちらも「請求額が減る」という点では同じ結果に見えるためです。

**実務でどう効いてくるか**

| | 返品 | 値引き |
|---|---|---|
| モノ | 戻ってくる | 戻らない |
| 在庫 | 増える（再販売可能なら） | 変わらない |
| 物流費 | 引取りの費用が発生する | 発生しない |
| その後 | 再販売／値下げ販売／廃棄のいずれか | なし |
| 処理 | 返品伝票、在庫の戻し入れ、検品 | 値引伝票のみ |

> **【Example】**（説明用の架空例）
> 破損が10ケース出た。
> - **返品として処理**：10ケースが戻ってくる。引取りの配送を組み、検品し、再販売可否を判定し、
>   不可なら廃棄処理をする。倉庫の作業が増える。
> - **値引きとして処理**：商品は得意先に残る（得意先が処分する）。請求額だけを下げる。
>   倉庫の作業は発生しない。
>
> **どちらで処理するかは、金額だけでなく「モノをどうするか」で決まります。**

さらに、`15_rules-customs.md` で見たとおり、
**返品と減額（値引き）は、独占禁止法・大規模小売業告示・取適法で別々の行為類型として扱われています。**

---

### ⑫ リベート ≠ 値引き

**何が違うか**
- **値引き**：取引の**その場**で価格が下がる。伝票に反映される
- **リベート**：条件を満たしたあと、**後から**支払われる。伝票とは別に動く

**なぜ混同するか**
どちらも「実質の仕入価格が下がる」という効果は同じだからです。

**実務でどう効いてくるか**

| | 値引き | リベート |
|---|---|---|
| タイミング | 取引時 | 四半期・半期・年次など、後から |
| 伝票 | 仕入価格そのものが下がる | 仕入価格は変わらず、別途精算 |
| 日々の粗利 | 正しく反映される | **反映されない**（実質より低く見える） |
| 条件 | その取引限り | 数量・金額・期間の達成が条件 |
| 確定性 | 確定している | **達成できなければもらえない** |

> **【Example】**（説明用の架空例）
> - 値引きの場合：仕入原価150円 → 147円。日々の粗利表に正しく出る
> - リベートの場合：仕入原価150円のまま。半期後に1本3円が支払われる
>   → 日々の粗利表は「粗利30円・粗利率16.7%」だが、実質は「粗利33円・粗利率18.3%」
>
> **リベートを前提に売価を下げると、条件が更新されなかった翌期に粗利が消えます。**

> **【重要】** 「実質いくらで買えているのか」を答えるには、
> リベートを含めた実質仕入原価を把握する必要があります。
> これが、卸売業の粗利管理が難しい最大の理由の1つです。【Inference】

### ⑬ 請求 ≠ 入金

**何が違うか**
- **請求**：「これだけ払ってください」と伝えた
- **入金**：実際にお金が振り込まれた

**なぜ混同するか**
請求書を出したら、あとは自動的に入ってくると思ってしまうためです。

**実務でどう効いてくるか**
請求と入金の間には、次のことが起こりえます。

| 起こりうること | 内容 |
|---|---|
| 金額が合わない | 得意先側の計上と食い違い、支払が保留される |
| 一部だけ支払われる | 差異のある明細だけ保留される |
| 振込手数料が引かれる | 請求額より少ない金額が入金される |
| 支払日が遅れる | 資金繰りに直接影響する |
| まったく入らない | 督促 → 与信見直し → 出荷停止 → 最悪の場合は貸倒れ |

**だから「請求済み」と「入金済み」は別々に管理し、消込という作業が存在します。**
`14_kpi.md` 14-5-4 の売掛金年齢表は、この差を可視化するための表です。

### ⑭ 一次卸 ≠ 大きい卸

**何が違うか**
- **一次卸**：メーカーから**直接**仕入れる立場。**商流上の段数**を表す
- **大きい卸**：売上規模が大きい会社。**規模**を表す

**なぜ混同するか**
「一次」という言葉から、上位・格上のイメージを受けるためです。
また、全国規模の大手卸が一次卸であることが多いのも事実です。

**実務でどう効いてくるか**
- **小さい会社でも一次卸になれます。**
  特定のメーカーと直接取引していれば、その商品については一次卸です。
- **大きい会社でも二次卸になります。**
  そのメーカーの帳合を持っていなければ、他の卸から仕入れることになります。
- **同じ1社の中で、商品によって一次卸だったり二次卸だったりします。**

> **【Example】**（説明用の架空例）
> A食品商事（45名・年商40億円）は、
> - 調味料メーカーX社とは**直接取引（一次卸）**
> - 冷凍食品メーカーY社とは**直接取引（一次卸）**
> - 輸入食材については**商社Z社から仕入れ（二次卸）**
> - 全国規模の食品卸W社からも仕入れている（**二次卸**）
>
> したがって「A食品商事は一次卸か二次卸か」という問いには、
> **「商品による」**としか答えられない。

**なぜこの区別が重要か**
一次卸か二次卸かで、**仕入原価・情報の早さ・リベート条件**が変わります。
同じ商品でも、一次卸のほうが仕切価格が低いのが一般的です【Typical】。
そのため、二次卸として仕入れている商品では粗利率が薄くなります。【Inference】

### ⑮ 見積 ≠ 契約（≠ 受注）

**何が違うか**
- **見積**：「この条件ならこの価格です」と提示しただけ
- **契約・受注**：相手が承諾し、取引が確定した

**なぜ混同するか**
見積を出すところまで手間がかかるため、「話が進んだ」と感じるためです。

**実務でどう効いてくるか**
- 見積を出しても、**相見積で他社に決まれば売上はゼロ**
- 見積の有効期限を切っておかないと、価格改定後に古い見積で注文が来る
- 見積段階では在庫の引当をしないため、受注時に在庫がない可能性がある

> **【Varies】** 卸売業では、定番商品の補充発注は見積を伴わないことが多く、
> 見積が重要になるのは新規取引・大口案件・特売・特注品の場面です。
> 建材卸・機械工具卸では、案件ごとの見積が業務の中心になります。

---

### ⑯ 在庫 ≠ すべて販売可能な資産

**何が違うか**
帳簿上、在庫は「資産」として計上されます。
しかし、**資産としての在庫と、実際に現金化できる在庫は違います。**

| 在庫の状態 | 帳簿上 | 実際に現金化できるか |
|---|---|---|
| よく売れる定番品 | 資産 | できる |
| 滞留在庫 | 資産 | 時間がかかる。値引きが必要な場合も |
| 期限が迫った在庫 | 資産 | 値引きしないと売れない |
| デッドストック | 資産 | **できない**（最終的に廃棄） |
| 破損品 | 資産（評価減されるまで） | できない |

**なぜ混同するか**
在庫一覧の金額欄には、どれも仕入原価で並んで表示されるためです。

**実務でどう効いてくるか**
- 貸借対照表の在庫金額が大きくても、**そのまま現金になるわけではありません**
- 滞留在庫・デッドストックの金額を把握していないと、実態より会社を良く見てしまいます
- 在庫回転率が良く見えても、**動いている商品と動いていない商品が混ざっている**ことがあります

> **だからABC分析（`14_kpi.md` 14-7）と滞留在庫額の把握が必要になります。**
> 「在庫金額2.2億円」という1つの数字だけでは、何も判断できません。

## 16-10. 会話についていくための「よく出る言い回し」

最後に、卸売業の現場で交わされる言い回しと、その意味を整理します。

| 言い回し | 意味 |
|---|---|
| 「帳合はうちです」 | その得意先へのその商品の取引経路を自社が担っている |
| 「仕切りはいくら？」 | 実際の取引価格はいくらか |
| 「9掛けで入れてます」 | 建値の90%の価格で納品している |
| 「引当が取れました」 | 在庫を確保できた。出荷が確定した |
| 「欠品が出てます」 | 注文に対して在庫が足りていない |
| 「締めが違います」 | その得意先の締め日が他と違う |
| 「消込が合いません」 | 入金額と請求額が一致せず、特定できていない |
| 「発注残があります」 | すでに発注して、入荷待ちの分がある |
| 「直送でお願いします」 | 自社倉庫を通さず、仕入先から得意先へ直接届けてほしい |
| 「カットされました」 | 得意先がその商品の取扱をやめた |
| 「導入が決まりました」 | 新商品を取り扱ってもらえることになった |
| 「センターに入れます」 | 得意先の物流センターへ一括納品する |
| 「あいみつです」 | 他社と価格で比較されている |
| 「条件交渉が入ります」 | 年間の取引条件を見直す話し合いが始まる |
| 「棚替えです」 | 得意先の売場見直しにより、商品の入替が発生する |
| 「回転が悪い」 | その商品が売れずに在庫が動いていない |
| 「交差が低い」 | 交差比率が低い＝在庫に置いたお金が粗利を生んでいない |
| 「与信が足りません」 | 与信限度額に対して、その受注を加えると超えてしまう |
| 「サイトが長い」 | 締めてから入金までの期間が長い |
| 「期限が浅い」 | 賞味期限までの残り日数が少なく、納品できない可能性がある |

## この章のまとめ

1. 用語集は**136語**を収録した。業界固有語（帳合・建値・仕切・掛率・交差比率・
   種まき方式・3分の1ルール等）と、商取引・会計の基本語（与信・掛売・締め日・
   売掛金・買掛金・粗利・リードタイム等）の両方を押さえる。
2. 初心者が最も間違えやすいのは、**似た2つの概念の混同**である。
   特に次の6つは、卸売業を理解するうえで決定的に重要である。
   - **商流 ≠ 物流**（直送があるため）
   - **帳合先 ≠ 納品先**（伝票の相手と届ける場所は別）
   - **粗利率 ≠ 掛率**（分母が違う）
   - **リベート ≠ 値引き**（実質の粗利が見えなくなる）
   - **在庫がある ≠ 売れる在庫がある**（引当・期限・保留がある）
   - **一次卸 ≠ 大きい卸**（段数と規模は別の話）
3. 会話についていくには、用語そのものより
   **「その言葉が、どの判断につながっているか」**を理解することが近道である。
   「欠品が出てます」は状態の報告ではなく、**営業と得意先の判断を求める呼びかけ**である。
