## 3-1 説明用モデル企業「Xホテル株式会社」

### 【Example】重要な注意

> `【Example】` **以下の「Xホテル」および後述の「Y旅館」は、本資料を具体的に説明するために
> 設定した架空のモデルです。実在企業ではなく、統計上の平均値でもありません。**
> 数値はすべて説明用の仮置きであり、**業界の代表値として引用してはいけません。**
> 実際の宿泊施設の規模・人員・単価は施設ごとに大きく異なります `【Varies】`。
>
> ただし、モデルの**骨格**（客室規模・提供形態・機能構成）は、
> `01_overview.md` 1-7 で確認した統計（施設の81.1％が従業者10人未満、
> ビジネスホテルの客室稼働率75.3％ 等）と矛盾しない範囲で置いています。

## 3-2 宿泊業の組織は「部署」ではなく「9つの機能」で理解する

### なぜ機能で見るのか

`common/methodology.md` §1 のとおり、中小企業では
**「この仕事（機能）は必ず存在するが、独立した○○部が存在するとは限らない」**
という見方をします。宿泊業ではこれが特に強く当てはまります。

`【Typical】` 大型ホテルであれば「宿泊部」「料飲部」「宴会部」「調理部」「営業部」「管理部」と
部署が分かれます。しかし**客室70室のXホテルには「部」はありません。**
それでも、**やるべき仕事（機能）は大型ホテルとほぼ同じだけ存在します。**

> ✕「宿泊業には予約課と客室課と料飲課がある」
> ○「**予約・販売管理機能**、**フロント機能**、**客室清掃機能**…が必要。
>   会社によって宿泊部／フロント課／支配人直轄など、呼び方も置き方も異なる」

### 宿泊業の9つの機能

```
┌──────────────────────────────────────────────────────────────────────┐
│                      【 売 る 】                                      │
│  ① 予約・販売管理機能（レベニューマネジメント）                        │
│     ・いつ・どこに・いくらで・何室出すか                               │
│     ・在庫配分、価格設定、OTA掲載内容の管理                            │
│  ⑦ 営業機能                                                           │
│     ・法人契約の獲得と維持、旅行代理店との関係、団体の受注             │
└────────────────────────────┬─────────────────────────────────────────┘
                             │（予約情報）
┌────────────────────────────▼─────────────────────────────────────────┐
│                      【 迎える・泊める 】                             │
│  ② フロント機能                                                       │
│     ・予約受付、チェックイン／アウト、精算、電話対応、客室の割り当て   │
│     ・宿泊者名簿の作成、本人確認、鍵の受渡し                           │
│  ④ 料飲（レストラン・宴会）機能 【Varies】                             │
│  ⑤ 調理機能 【Varies】                                                 │
└────────────────────────────┬─────────────────────────────────────────┘
                             │（滞在情報・清掃指示）
┌────────────────────────────▼─────────────────────────────────────────┐
│                      【 商品を作り直す・維持する 】                   │
│  ③ 客室清掃・ハウスキーピング機能                                     │
│     ・原状回復、リネン交換、アメニティ補充、客室点検                   │
│  ⑥ 設備管理機能                                                       │
│     ・空調・給排水・ボイラー・電気・消防設備の維持、故障対応           │
└────────────────────────────┬─────────────────────────────────────────┘
                             │（売上情報・勤務情報）
┌────────────────────────────▼─────────────────────────────────────────┐
│                      【 支える 】                                     │
│  ⑧ 経理・財務機能   ・売上集計、請求、入金消込、支払、資金繰り、税務   │
│  ⑨ 人事・総務機能   ・採用、シフト、給与、社会保険、行政対応、契約管理 │
└──────────────────────────────────────────────────────────────────────┘
```

### 各機能の説明（詳細は `05_departments.md`）

#### ① 予約・販売管理機能（レベニューマネジメント）

- **一般的な名称**：予約課、レベニュー担当、販売企画、支配人直轄
- **何をするか**：どの日付の部屋を、どのチャネルに、いくらで、何室出すかを決める。
  OTAの掲載内容（写真・プラン名・説明文）を管理する。予約状況を日々見て価格を見直す。
- **なぜ必要か**：`01_overview.md` のとおり**部屋は売れ残ると消える**ため、
  「放っておいても売れる」ということがありません。誰かが毎日、
  日付ごとの売れ行きを見て手を打たなければ、空室のまま日付が過ぎていきます。
- `【Varies】` 専任者を置くのは一定規模以上。**Xホテルでは支配人が兼務**。
  Y旅館では女将または予約担当の家族が担当。

#### ② フロント機能

- **一般的な名称**：フロント、フロントオフィス、帳場（旅館）、受付
- **何をするか**：電話・メールでの予約受付、当日のチェックイン、本人確認、
  **宿泊者名簿の記載**、鍵の受渡し、館内案内、滞在中の要望対応、
  チェックアウト時の精算、領収書発行、忘れ物対応。
- **なぜ必要か**：`【Fact】` 法令上、旅館・ホテル営業の施設は
  「宿泊しようとする者との面接に適する玄関帳場その他当該者の確認を適切に行うための設備」を
  備えなければならず（旅館業法施行令第1条第1項第2号）、
  その設備は**宿泊者名簿の正確な記載、鍵の適切な受渡し、宿泊者以外の出入りの状況の確認**を
  可能とするものでなければなりません（旅館業法施行規則第4条の3第2号）。
  つまりフロント機能は**法令が求める機能**です。
- `【Typical】` 中小宿泊業では、フロント担当が**予約受付・電話対応・精算・
  清掃への連絡・館内トラブル対応**をすべて兼ねます。

#### ③ 客室清掃・ハウスキーピング機能

- **一般的な名称**：客室課、ハウスキーピング、清掃、中番（旅館）
- **何をするか**：チェックアウト後の客室清掃、リネン交換、アメニティ補充、
  備品の点検・報告、清掃完了のフロントへの報告、共用部（廊下・ロビー・浴場）の清掃。
- **なぜ必要か**：`02_industry-structure.md` 11-3 のとおり、
  **清掃は「商品（客室）を作り直す製造工程」**です。
  清掃が終わっていない部屋は売れません。
- `【Fact】` また法令上も、営業者は施設について
  **換気・採光・照明・防湿・清潔**その他宿泊者の衛生に必要な措置を講じる義務があります
  （旅館業法第4条第1項）。清掃は法令上の衛生措置そのものです。
- `【Varies】` 自社で行うか外部委託かは施設により異なります。
  Xホテルは委託、Y旅館は自社（家族＋パート）。

#### ④ 料飲（レストラン・宴会）機能 `【Varies】`

- **一般的な名称**：料飲部、レストラン、宴会サービス、サービス課、客室係（旅館）
- **何をするか**：食事の提供、席の準備、配膳・下膳、飲料の販売、
  宴会の設営・進行、アレルギー等の個別対応。
- **なぜ必要か**：食事を出す施設では、**食事そのものが商品の一部**だからです。
  特に旅館では「1人○○円」の中に食事代が含まれており、
  食事の質と提供が売上に直結します。
- `【Varies】` **この機能を持たない施設があります。** 素泊まり専門の簡易宿所、
  民泊、朝食のみのビジネスホテル（Xホテルはパート3名で朝食のみ対応）。

#### ⑤ 調理機能 `【Varies】`

- **一般的な名称**：調理部、厨房、板場（旅館）
- **何をするか**：翌日の予約人数に基づく食材発注、納品の検収、仕込み、調理、
  盛り付け、献立の作成、原価の管理、厨房の衛生管理。
- **なぜ必要か**：`02_industry-structure.md` 11-4 のとおり、
  **食材は人数に連動し、在庫として持ち越せません。**
  予約人数を見て正確に発注し、時間どおりに出す専門機能が要ります。
- `【Fact】` 施設内で客に飲食物を調理提供する場合、営業者は**食品衛生責任者**を
  定めなければなりません（食品衛生法施行規則 別表第17第1号イ）。
- `【Varies】` Y旅館では長男が料理長として常勤。Xホテルは朝食のみでパート対応。

#### ⑥ 設備管理機能

- **一般的な名称**：施設課、営繕、設備、機械室担当
- **何をするか**：空調・給排水・給湯・ボイラー・電気・エレベーター・
  消防用設備・厨房機器・客室の鍵の点検と維持。故障時の一次対応と業者手配。
  客室の備品交換（電球・テレビ・シャワーヘッド等）。
- **なぜ必要か**：`【Inference】` 宿泊業は**設備が止まると営業が止まります**。
  風呂の湯が出ない、エレベーターが動かない、部屋の鍵が開かない——
  いずれも客を泊められない状態に直結します。
- `【Fact】` また、消防用設備等については消防法に基づく点検と報告が必要であり、
  防火管理者は消防計画に基づいて**消防用設備等の点検及び整備**を行わなければなりません
  （消防法施行令第3条の2第2項）。
- `【Varies】` 専任の設備担当を置くのは一定規模以上。
  **Xホテルでは支配人が兼務し、実際の点検・修理は外部業者**に依頼。

#### ⑦ 営業機能

- **一般的な名称**：営業部、セールス、渉外、社長直轄
- **何をするか**：地元企業への法人契約の営業と単価交渉、旅行代理店への訪問・
  商品掲載の依頼、団体（スポーツ大会・学会・工事関係）の受注、
  地域の観光協会・イベント主催者との関係づくり。
- **なぜ必要か**：`【Inference】` OTAや自社サイトは「探しに来た客」を捕まえる仕組みですが、
  **法人契約や団体は、こちらから取りに行かないと入ってこない**需要です。
  また `02_industry-structure.md` のとおり法人需要は平日の稼働を下支えします。
- `【Varies】` 中小では**社長または支配人が兼務**するのが一般的です。

#### ⑧ 経理・財務機能

- **一般的な名称**：経理、管理部、総務経理、事務所
- **何をするか**：日次の売上集計と現金の締め、法人・代理店への請求書発行、
  入金の消込、OTA・代理店からの精算金の確認、仕入先への支払、
  給与計算、資金繰り、税務申告、金融機関対応。
- **なぜ必要か**：`02_industry-structure.md` 11-2 のとおり
  **チャネルによって入金日も手取りも違う**ため、
  「売れた」と「入金された」を突き合わせる作業が必ず要ります。
- `【Typical】` 中小では**社長・支配人・事務パート・顧問税理士**の組み合わせで担います。

#### ⑨ 人事・総務機能

- **一般的な名称**：総務、人事、管理部、社長直轄
- **何をするか**：採用、シフト作成、勤怠管理、給与・社会保険の手続、
  教育（接遇・衛生・防火）、行政への届出、各種契約の管理、
  保険、備品購入、苦情記録の管理。
- **なぜ必要か**：`【Inference】` 宿泊業は**24時間・年中無休で人を配置する**事業であり、
  シフト作成そのものが重要な業務になります。
  また `【Fact】` 営業者は特定感染症のまん延防止や、高齢者・障害者その他特に配慮を要する
  宿泊者への適切なサービス提供のため、**従業者に必要な研修の機会を与えるよう努めなければ
  ならない**とされています（旅館業法第3条の5第2項。努力義務）。
- `【Varies】` 中小では社長・支配人が兼務。社会保険労務士に委託する場合もあります。

## 3-3 【最重要】中小宿泊業では、支配人が予約から経理まで見る

### 「支配人」とは何をする人か

- **支配人（しはいにん）**
  → 宿泊施設の現場全体を統括し、日々の運営の意思決定を行う責任者のこと。
    旅館では「主人」「若主人」「女将」がこれに相当する役割を担うことがあります。
  → 実務例：朝、今日の到着リストと稼働率を確認し、空きが多ければ価格を下げ、
    清掃業者に今日の清掃室数を伝え、食材の発注量を決め、
    シフトの穴を埋め、夕方に飛び込み客の対応をし、夜に日報を締める。

### Xホテルでの実際の担当（モデル）

| 機能 | 誰が担当しているか（Xホテル・`【Example】`） |
|---|---|
| ① 予約・販売管理 | **支配人**（全面） |
| ② フロント | フロント正社員3名＋パート4名（**支配人も入る**） |
| ③ 客室清掃 | 外部委託（**支配人が室数連絡・完了確認**） |
| ④ 料飲 | 朝食パート3名（**支配人が仕入と人員配置**） |
| ⑤ 調理 | 朝食パート3名（簡易。**支配人が発注**） |
| ⑥ 設備管理 | **支配人**（一次対応）＋外部業者 |
| ⑦ 営業 | **社長**（法人開拓）＋**支配人**（既存対応） |
| ⑧ 経理・財務 | 事務パート1名＋**社長**＋顧問税理士（**支配人が日次締め**） |
| ⑨ 人事・総務 | **支配人**（シフト・採用）＋社長（最終決裁） |

> **9機能のうち、支配人が何らかの形で関わらない機能は1つもありません。**
> `【Typical】` これが中小宿泊業の実態です。
> 「部署がない」のではなく、**「機能はすべてあるが、担う人が重なっている」**と理解してください。

### なぜこうなるのか

`【Inference】` 理由は3つあります。

1. **業務が時間的に連鎖している。**
   予約状況 → 清掃の室数 → 食材の量 → シフトの人数 が1本につながっており、
   分けて別の人が持つと、かえって連絡の手間が増えます。
2. **24時間の現場に、判断できる人が居続ける必要がある。**
   飛び込み客の受入可否、設備故障時の部屋の振替、クレーム対応は
   その場で決めなければなりません。
3. **専任者を置けるほどの仕事量が、それぞれの機能には無い。**
   70室規模では、レベニュー専任・設備専任を置くほどの業務量にならない `【Varies】`。

### Y旅館での実際の担当（モデル）

| 機能 | 誰が担当しているか（Y旅館・`【Example】`） |
|---|---|
| ① 予約・販売管理 | **女将**＋長男の配偶者 |
| ② フロント（帳場） | **女将**＋長男の配偶者＋パート |
| ③ 客室清掃 | パート（**女将が指示・確認**）。布団の上げ下ろしは客室係 |
| ④ 料飲（客室係） | パート（客室係）＋**女将** |
| ⑤ 調理 | **長男（料理長）**＋調理補助パート |
| ⑥ 設備管理 | **主人（社長）**＋外部業者 |
| ⑦ 営業 | **主人**（代理店対応・団体受注） |
| ⑧ 経理・財務 | **長男の配偶者**＋顧問税理士 |
| ⑨ 人事・総務 | **女将** |

`【Typical】` 家族経営では、**役職名ではなく「誰が何を見ているか」が実態**です。
外部の人が「担当者を呼んでください」と言っても、
「それは女将が見ています」と返ってくるのが普通です。

## 3-4 旅館業法上の営業形態と、民泊（住宅宿泊事業）の違い

**この節は、宿泊業の会社を理解するうえで避けて通れません。**
同じ「泊める商売」でも、**適用される法律が違えば、できることも義務も違います。**

### 旅館業法上の3つの営業種別

`【Fact】` 旅館業法第2条第1項は、旅館業を
**旅館・ホテル営業／簡易宿所営業／下宿営業**の3つと定義しています。

| 営業の種別 | 条文上の定義 | 根拠 |
|---|---|---|
| **旅館・ホテル営業** | 施設を設け、宿泊料を受けて、人を宿泊させる営業で、簡易宿所営業及び下宿営業以外のもの | 旅館業法第2条第2項 |
| **簡易宿所営業** | **宿泊する場所を多数人で共用する構造及び設備を主とする施設**を設け、宿泊料を受けて、人を宿泊させる営業で、下宿営業以外のもの | 同条第3項 |
| **下宿営業** | 施設を設け、**一月以上の期間を単位とする宿泊料**を受けて、人を宿泊させる営業 | 同条第4項 |

`【Fact】` また「宿泊」とは、**寝具を使用して上記の施設を利用すること**をいいます（同条第5項）。

> 初心者がつまずく点：**「旅館」と「ホテル」は法律上、区別されていません。**
> かつては「ホテル営業」と「旅館営業」が別でしたが、現在は**「旅館・ホテル営業」1つ**です。
> 「あそこは旅館だからホテル営業ではない」という言い方は、法律上は成り立ちません。

### 構造設備の基準（政令で定められている）

`【Fact】` 旅館業法第3条第2項に基づき、施行令が構造設備の基準を定めています。

#### 旅館・ホテル営業（旅館業法施行令第1条第1項）

| 号 | 基準 |
|---|---|
| 一 | **一客室の床面積は7㎡以上**（**寝台を置く客室は9㎡以上**） |
| 二 | 宿泊しようとする者との**面接に適する玄関帳場その他当該者の確認を適切に行うための設備**として厚生労働省令で定める基準に適合するものを有すること |
| 三 | 適当な換気、採光、照明、防湿及び排水の設備を有すること |
| 四 | 近接して公衆浴場がある等の場合を除き、宿泊者の需要を満たす適当な規模の**入浴設備**を有すること |
| 五 | 宿泊者の需要を満たす適当な規模の**洗面設備**を有すること |
| 六 | 適当な数の**便所**を有すること |
| 七 | 学校等の敷地の周囲おおむね100mの区域内にある場合、内部を見通すことを遮ることができる設備を有すること |
| 八 | その他**都道府県（保健所設置市・特別区）が条例で定める基準**に適合すること |

#### 簡易宿所営業（同施行令第1条第2項）

| 号 | 基準 |
|---|---|
| 一 | **客室の延床面積は33㎡以上**（許可申請にあたって宿泊者の数を10人未満とする場合は、3.3㎡×宿泊者数 以上） |
| 二 | **階層式寝台**（二段ベッド等）を有する場合、上段と下段の間隔はおおむね1m以上 |
| 三〜六 | 換気・採光・照明・防湿・排水、入浴設備、洗面設備、便所（旅館・ホテル営業と同趣旨） |
| 七 | その他都道府県が条例で定める基準に適合すること |

> **簡易宿所には「玄関帳場」の基準がありません。**
> `【Inference】` 相部屋（ドミトリー）を主とする施設を想定した基準であり、
> ゲストハウス・ホステルの多くがこの区分にあたります。
> 一方で `【Fact】` 宿泊者名簿の義務（旅館業法第6条）は営業種別にかかわらず適用されます。

`【Fact】` なお、季節的に営業する施設（キャンプ場・スキー場・海水浴場等）、
交通が著しく不便な地域にある利用度の低い施設、体育会・博覧会等のため一時的に営業する施設、
農林漁業体験民宿業に係る施設については、
一部の基準の適用除外・特例が定められています（旅館業法施行規則第5条）。

### 住宅宿泊事業（民泊）との違い

`【Fact】` 住宅宿泊事業法（平成29年法律第65号）は、
**旅館業法の許可を受けずに、届出によって人を宿泊させられる仕組み**を設けています。

`【Fact】` 同法第2条第3項は、住宅宿泊事業を
**「旅館業法第3条の2第1項に規定する営業者以外の者が宿泊料を受けて住宅に人を宿泊させる事業であって、
人を宿泊させる日数として国土交通省令・厚生労働省令で定めるところにより算定した日数が
一年間で百八十日を超えないもの」**と定義しています。

#### 旅館業法と住宅宿泊事業法の比較

| 項目 | **旅館業（旅館・ホテル営業／簡易宿所営業）** | **住宅宿泊事業（民泊）** |
|---|---|---|
| 根拠法 | 旅館業法 | 住宅宿泊事業法 |
| 行政手続 | **許可**（第3条第1項） | **届出**（第3条第1項） |
| 誰に対して | 都道府県知事（保健所設置市・特別区は市長・区長） | 同左 |
| **営業日数の上限** | **なし** | **年間180日以内**（第2条第3項） |
| 施設 | 旅館業のための施設 | **「住宅」**（台所・浴室・便所・洗面設備を備え、人の居住の用に供されていると認められるもの。第2条第1項） |
| 構造設備基準 | 施行令第1条で具体的に規定 | 衛生・安全確保の措置を省令で規定（第5条・第6条） |
| 宿泊者名簿 | **必要**（旅館業法第6条） | **必要**（住宅宿泊事業法第8条） |
| 外国語対応 | 規定なし | **必要**（設備の使用方法・交通手段の案内。第7条） |
| 周辺への配慮 | 規定なし | **騒音防止等について宿泊者へ説明する義務**（第9条）、**周辺住民からの苦情への対応義務**（第10条） |
| 管理の委託 | 規定なし | 居室数が省令で定める数を超えるとき、または**宿泊させる間不在となるとき**は、**住宅宿泊管理業者への委託が必要**（第11条第1項） |
| 罰則の例 | 無許可営業は6月以下の拘禁刑または100万円以下の罰金（第10条第1号） | — |

`【Fact】` 住宅宿泊事業者は、上記のほか
**宿泊者の衛生の確保**（居室の床面積に応じた宿泊者数の制限、定期的な清掃等。第5条）、
**宿泊者の安全の確保**（非常用照明器具の設置、避難経路の表示等。第6条）の
措置を講じなければなりません。

> **理解のポイント**
> `【Inference】` 民泊は「規制が緩い宿泊業」ではなく、**別の枠組み**です。
> 日数に上限がある代わりに施設要件が緩く、
> その代わり**周辺住民への配慮義務**や**外国語対応義務**など、
> 旅館業にはない義務が課されています。
> 「同じ泊める商売なのに違うルール」ではなく、**前提としている施設が違う**
> （旅館業＝宿泊のための施設／民泊＝人が住むための住宅）と押さえてください。

### 許可は「営業者」に対して与えられる

`【Fact】` 旅館業の許可は営業者に対するものであり、次の場合には**都道府県知事の承認**が要ります。

| 場面 | 手続 | 根拠 |
|---|---|---|
| 営業を**譲渡**する | 譲渡人・譲受人が承認を受ける。承認を受ければ譲受人が営業者の地位を承継 | 旅館業法第3条の2 |
| 法人の**合併・分割** | 承認を受ければ、存続法人・新設法人・承継法人が営業者の地位を承継 | 同法第3条の3 |
| 営業者の**死亡（相続）** | **相続人は被相続人の死亡後60日以内**に申請して承認を受ける | 同法第3条の4第1項 |

`【Fact】` 相続の場合、申請をしたときは、被相続人の死亡の日から承認・不承認の通知を受ける日までの間、
被相続人への許可が相続人へされたものとみなされます（同条第2項）。
`【Fact】` また、申請書記載事項に変更があったとき、営業の全部・一部を停止・廃止したときは、
**10日以内**に都道府県知事に届け出なければなりません（旅館業法施行規則第4条）。

`【Inference】` 家族経営が多い中小宿泊業では、**事業承継が法令上の手続を伴う**点が実務上重要です。

## 3-5 必置ポジション（置かなければならない人）

宿泊業では、**法令によって「置かなければならない人」**がいます。
中小施設では、これらを**同じ人が兼ねる**のが一般的です `【Typical】`。

### ① 防火管理者

- **防火管理者**
  → 建物の防火に関する計画を作り、消火・通報・避難の訓練を行い、
    消防設備の点検・整備や火気の監督を担う責任者のこと。
  → **なぜ必要か**：`【Inference】` 宿泊施設は、**不特定多数の人が夜間に就寝している**
    建物です。火災が起きたとき、客は建物の構造も避難経路も知りません。
    あらかじめ計画を作り、訓練しておく人が要ります。

| 項目 | 内容 | 根拠 |
|---|---|---|
| **対象** | 消防法施行令別表第一**（五）項イ**「旅館、ホテル、宿泊所その他これらに類するもの」 | 消防法施行令別表第一 |
| **選任が必要な規模** | **収容人員が30人以上** | 消防法第8条第1項、同法施行令第1条の2第3項第1号ロ |
| **資格** | 甲種防火対象物では甲種防火管理講習の修了者等。一定規模未満は乙種でも可 | 同法施行令第3条 |
| **主な職務** | **消防計画を作成し、所轄消防長または消防署長に届け出る** | 同法施行令第3条の2第1項 |
| | 消防計画に基づき、**消火・通報・避難の訓練の実施**、消防用設備等の点検及び整備、火気の使用・取扱いの監督、避難・防火上必要な構造設備の維持管理、**収容人員の管理** | 同条第2項 |

`【Fact】` なお、収容人員30人以上かつ地階を除く階数が3以上の一定の防火対象物では、
**統括防火管理者**を定めなければならない場合があります（消防法施行令第3条の3第2号）。

`【Varies】` **誰が防火管理者になるか**は施設により異なりますが、
中小では**支配人・社長・設備担当**が務めるのが一般的です `【Typical】`。

### ② 食品衛生責任者

- **食品衛生責任者**
  → 食品を扱う営業施設において、衛生管理を担う責任者のこと。
  → **なぜ必要か**：`【Inference】` 宿泊施設で食中毒が起きれば、
    同じものを食べた多数の客に同時に被害が及びます。
    食材の受入れから提供までを管理する人を定めることが求められています。

| 項目 | 内容 | 根拠 |
|---|---|---|
| **義務** | 営業者は**食品衛生責任者を定めること** | 食品衛生法施行規則 別表第17第1号イ |
| **資格の例** | 食品衛生監視員・食品衛生管理者の資格要件を満たす者／調理師・製菓衛生師・栄養士・管理栄養士・船舶料理士等／都道府県知事等が行う講習会等の受講者 | 同表第1号ロ |
| **兼務** | 食品衛生管理者は食品衛生責任者を兼ねることができる | 同表第1号イ |

`【Varies】` 食事を提供しない施設（素泊まり専門の簡易宿所等）では、
食品衛生法上の営業許可自体が不要な場合があります。
提供の有無・内容によって必要な許可が変わるため、実務では保健所に確認します。

### ③ その他（施設により必要となるもの）`【Varies】`

| ポジション・資格 | どんなときに関係するか |
|---|---|
| **ボイラー技士**（労働安全衛生法関係） | 一定規模以上のボイラーを設置・取扱いする場合 |
| **危険物取扱者**（消防法関係） | 一定量以上の燃料（重油等）を貯蔵・取扱いする場合 |
| **防火対象物点検資格者** | 一定の防火対象物で点検・報告が必要な場合 |
| **調理師** | 法令上の必置ではないが、調理機能の中核として置かれることが多い |
| **温泉の掲示・管理**（温泉法関係） | 温泉を利用する場合、成分等の掲示義務がある |
| **衛生管理者・産業医**（労働安全衛生法） | 常時使用する労働者数が一定以上の場合 |

> `【Varies】` 必要な資格・届出は、**建物の規模、設備の内容、提供するサービス、
> 所在する自治体の条例**によって変わります。
> 本ファイルは「こういう種類の義務がある」ことを示すものであり、
> 個別施設に必要なものの網羅ではありません。詳細は `15_rules-customs.md` で扱います。

### 押さえるべき4点

1. **9つの機能はどの規模でも存在する。部署として分かれているかは規模による。**
2. **中小では支配人が9機能すべてに関与する。** これは例外ではなく標準的な姿。
3. **旅館業法の3営業種別と、住宅宿泊事業（民泊）は別の枠組み。**
   民泊は年間180日以内で、周辺配慮・外国語対応の義務がある。
4. **許可は営業者に与えられる。** 譲渡・合併・相続には承認手続が要る。
