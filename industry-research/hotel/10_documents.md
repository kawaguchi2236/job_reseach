# 10_documents.md — 宿泊業の帳票・書類一覧

> 本ファイルは、中小宿泊業の現場で実際に扱われる帳票・書類を、
> **誰が作る／誰が使う／いつ作る／何が書いてある／何のためか**の6点で整理します。
> 加えて、各帳票に**「これが無いと何が困るのか」**を添えます。
>
> `10-5` の**法定の記録には根拠条文を明記**します。
> `common/methodology.md` の鉄則に従い、**条文の語をそのまま引用し、複数の法令を一文にまとめません。**
>
> 機能の番号（①〜⑨）は `03_company-structure.md` 3-2、
> ステップ名（A-1〜A-11）は `04_end-to-end-process.md` の定義に従います。
> 情報としての側面は `09_information.md`、システムとしての側面は `11_systems.md` を参照してください。

## 10-0 この章の読み方

### 3種類の帳票がある

`【Inference】` 宿泊業の帳票は、性質によって3つに分かれます。**この区別が重要です。**

| 種類 | どういうものか | 例 | 作らなかったら |
|---|---|---|---|
| **① 法令が作成を義務づけている帳票・記録** | 記載事項・保存期間・提出先が法令で決まっている | **宿泊者名簿**、**消防計画**、**消防用設備等の点検結果**、**建築物の定期調査の報告**、**簡易専用水道の検査**、衛生管理の記録 | **法令違反**（罰則があるものもある） |
| **② 業務が回らないため実務上必ず作る帳票** | 法令の義務ではないが、無いと仕事が止まる | 予約台帳、当日到着リスト、ルームアサイン表、客室清掃指示表、日計表 | **業務が止まる**（部屋を渡せない、清掃が始まらない） |
| **③ 相手方とのやり取りのために作る帳票** | 取引の相手に渡す／相手から受け取る | 料金表、請求書、領収書、OTAの精算明細 | **代金を受け取れない／払えない** |

`【Varies】` **紙で作るか、システム上の記録で足りるかは施設により異なります。**
`【Typical】` 中小宿泊業では、**紙とシステムが併用されている**ことが一般的です（`11_systems.md`）。
**本資料はこの併用を、価値判断を加えずに事実として記述します。**

### 帳票の全体像（どこで生まれ、どこへ行くか）

```
  【売る】
    料金表 ──────────────────────────────────▶ 客・法人・代理店・OTA
    予約台帳（予約一覧）─────────────────────▶ 当日到着リスト
                                                      │
  【迎える】                                          ▼
    当日到着リスト ──▶ ルームアサイン表 ──▶ **宿泊者名簿**（法定・3年保存）
                              │                  ＋ 宿泊カード（記入用）
                              │
  【作り直す】                ▼
    客室清掃指示表（ハウスキーピングレポート）──▶ 客室点検記録
                                                  │
                                                  ├─▶ 不具合報告 → 設備の記録
                                                  └─▶ 忘れ物管理台帳（遺失物法）
  【精算する】
    利用明細 ──▶ 領収書（客へ）
              ──▶ **ナイトオーディットの日計表**（日次の売上確定）
                        │
                        ├─▶ 請求書（法人・旅行代理店へ）
                        ├─▶ OTAの精算明細（OTAから受け取る）
                        └─▶ **入湯税・宿泊税の納入書**（市町村へ）
  【守る】
    **消防計画**（消防署へ届出）
    **消防用設備等点検結果報告書**（消防長又は消防署長へ報告）
    **建築物定期調査報告書**（特定行政庁へ報告）
    **簡易専用水道の検査の結果**
    **衛生管理の記録**
  【人】
    勤務シフト表 ──▶ 勤怠の記録 ──▶ 給与計算 ──▶ 給与明細
```

## 10-1 販売・予約に関する帳票

### 10-1-1 料金表

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ① 予約・販売管理機能（`【Example】` Xホテルでは支配人）／⑦ 営業（法人・代理店向け） |
| **誰が使うか** | ② フロント（問い合わせへの回答）／⑦ 営業（法人・代理店への提示）／客・法人・旅行代理店・OTA |
| **いつ作るか** | **日次**（繁忙期の販売価格）／**年次**（法人契約の年間レート）／プラン新設時 `【Varies】` |
| **何が書いてあるか** | 部屋タイプ別・プラン別の料金、適用期間（曜日・季節・連休の区分）、人数による差、食事の有無、子供料金 `【Varies】`、キャンセルポリシー、税の扱い（消費税・入湯税・宿泊税） |
| **何のためか** | **いくらで売るかを、社内と社外で同じ内容にそろえるため** |
| **これが無いと何が困るか** | `【Inference】` **フロント担当者ごとに違う金額を案内してしまいます。** 特に電話予約・飛び込み客の対応で、同じ部屋に別の価格が付きます。法人・代理店に対しては、契約単価の根拠が示せません |

> **宿泊業の料金表は「1枚の定価表」ではありません。**
> `【Typical】` 日付ごとに価格が動くため（`02_industry-structure.md` 11-2）、
> **「基本の料金表」＋「日付別の販売価格」**という二層になっているのが一般的です `【Varies】`。

### 10-1-2 予約台帳（予約一覧）

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロント（電話・メール・自社サイト）／**OTA経由はシステムが自動で記録し、人が確認する** |
| **誰が使うか** | ①（在庫）／②（到着前準備・チェックイン）／③（清掃室数）／④⑤（食数）／⑦（法人・団体）／⑧（請求） |
| **いつ作るか** | **常時**（予約が入るたび。OTAは24時間） |
| **何が書いてあるか** | 宿泊日・泊数・人数（大人・子供）・部屋タイプ・室数・プラン・氏名・連絡先・**決済区分**・特記事項（到着予定時刻、アレルギー、駐車場、連泊時の清掃要否）・予約経路（どのチャネルか）・適用単価 |
| **何のためか** | **将来のどの日に、誰が、何室泊まるかを一覧で把握するため** |
| **これが無いと何が困るか** | `【Inference】` **在庫が分からず、二重に売ってしまいます。** また当日になって「何室仕上げればよいか」「何人分の食事か」が分かりません |

`【Varies】` **PMSの予約一覧画面で足りる施設と、紙の予約台帳を併用する施設があります。**
`【Typical】` 中小では、電話予約をまず紙に書き取り、後でPMSに入力する運用も見られます。

> **予約台帳は「売上の帳簿」ではありません。**
> `【Typical】` 予約を受けた時点では、まだ売上になりません（`09_information.md` 9-2-4）。
> 予約台帳は**見込みの一覧**であり、キャンセルされれば消えます。

### 10-1-3 当日到着リスト

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロント（`【Varies】` 前日または当日朝） |
| **誰が使うか** | ② フロント（受入）／③ 客室清掃（優先順）／④⑤ 料飲・調理（食数）／⑥ 設備管理／⑦ 営業（団体） |
| **いつ作るか** | **日次** |
| **何が書いてあるか** | 当日の到着予定件数・人数、氏名、部屋タイプ、プラン、到着予定時刻、**決済区分**、特記事項（アレルギー・記念日・高齢の客・団体・車椅子の利用・早着/遅着） |
| **何のためか** | **その日に誰が何時ごろ来るかを、各機能が同じ紙（画面）で共有するため** |
| **これが無いと何が困るか** | `【Inference】` **朝の情報共有ができません。** 清掃は何室仕上げればよいか、朝食は何名分か、団体の受入準備は要るかが分かりません |

### 10-1-4 ルームアサイン表

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロント |
| **誰が使うか** | ② フロント（鍵の受渡し）／③ 客室清掃（優先して仕上げる部屋） |
| **いつ作るか** | **日次**（`【Varies】` 前日または当日） |
| **何が書いてあるか** | 予約1件ごとに割り当てた**部屋番号**、その部屋の清掃状況、割り当ての理由（高層階の希望、静かな部屋、団体は同じ階の連番、早朝出発はエレベーター近く） |
| **何のためか** | **「シングル1室」という予約を、「406号室」という実物に結びつけるため** |
| **これが無いと何が困るか** | `【Inference】` **同じ部屋を2人に渡してしまいます。** また、仕上がっていない部屋の鍵を渡してしまいます。団体を別々の階に散らしてしまい、後から苦情になります |

`【Inference】` アサイン表は、**予約情報と清掃状況情報を突き合わせて作る帳票**です
（`09_information.md` 9-2-6）。どちらが欠けても作れません。

## 10-2 フロント・宿泊に関する帳票（法定帳簿を含む）

### 10-2-1 宿泊者名簿 ★法定帳簿★

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロント（**営業者の義務**） |
| **誰が使うか** | ② フロント（在館の把握・忘れ物の照合）／⑥ 設備管理・防火管理者（収容人員の管理）／**都道府県知事（要求があったとき）** |
| **いつ作るか** | **常時**（到着時＝A-7） |
| **何が書いてあるか** | `【Fact】` 宿泊者の**氏名・住所・連絡先**（旅館業法第6条第1項）<br>`【Fact】` ＋ 宿泊者が**日本国内に住所を有しない外国人**であるときは、**その国籍及び旅券番号**（旅館業法施行規則第4条の2第3項第1号）<br>`【Fact】` ＋ その他**都道府県知事が必要と認める事項**（同項第2号） |
| **何のためか** | `【Inference】` **感染症が発生したときに誰がその施設に泊まっていたかを追跡できるようにするため**、また**事件・事故が起きたときの手がかりとするため**。`【Fact】` 旅館業法第1条の目的（公衆衛生及び国民生活の向上に寄与）と対応 |
| **これが無いと何が困るか** | `【Fact】` **法令違反です。** 第6条第1項に違反した者は**五十万円以下の罰金**（旅館業法第11条第1号） |

**根拠条文（条文の語のまま）**

`【Fact】` **旅館業法第6条第1項**
> 「営業者は、厚生労働省令で定めるところにより、
> **旅館業の施設その他の厚生労働省令で定める場所に宿泊者名簿を備え、
> これに宿泊者の氏名、住所、連絡先その他の厚生労働省令で定める事項を記載し、
> 都道府県知事の要求があつたときは、これを提出しなければならない。**」

`【Fact】` **旅館業法施行規則第4条の2**

| 項 | 内容 |
|---|---|
| 第1項 | **正確な記載を確保するための措置を講じた上で作成**し、**作成の日から3年間保存** |
| 第2項 | 備える場所は① **旅館業の施設**、② **営業者の事務所** |
| 第3項第1号 | 宿泊者が**日本国内に住所を有しない外国人**であるときは、**その国籍及び旅券番号** |
| 第3項第2号 | その他**都道府県知事が必要と認める事項** |

`【Fact】` **宿泊者の側にも義務があります。** 宿泊者は、営業者から請求があったときは
上記の事項を告げなければならず（旅館業法第6条第2項）、
これに違反して**偽って告げた者は、拘留又は科料**に処せられます（同法第12条）。

`【Fact】` また**住宅宿泊事業法第8条**は、住宅宿泊事業者について**宿泊者名簿の備付け等**を定めています。
**ただし根拠となる法律が違うため、旅館業法第6条と一文にまとめてはいけません**（`15_rules-customs.md`）。

### 10-2-2 宿泊カード（登録カード）

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロントが用紙を用意し、**客が記入する**（または フロントが予約情報から事前に印字し、客が確認・署名する `【Varies】`） |
| **誰が使うか** | ② フロント（**宿泊者名簿の作成の材料**） |
| **いつ作るか** | **常時**（チェックイン時） |
| **何が書いてあるか** | 氏名・住所・連絡先、（日本国内に住所を有しない外国人の場合）国籍・旅券番号、宿泊日・泊数・人数、車のナンバー `【Varies】`、署名 `【Varies】` |
| **何のためか** | `【Inference】` **宿泊者名簿に記載すべき事項を、客本人から正確に受け取るため** |
| **これが無いと何が困るか** | `【Inference】` **名簿の記載事項を客から聞き取る手段が、口頭だけになります。** 聞き間違い・書き間違いが起きやすくなり、`【Fact】` 旅館業法施行規則第4条の2第1項の「**正確な記載を確保するための措置**」との関係が問題になります |

> **宿泊カードと宿泊者名簿は同じものではありません。**
> `【Inference】` 宿泊カードは**客が記入する用紙**、宿泊者名簿は**営業者が備える法定帳簿**です。
> `【Varies】` **宿泊カードそのものを名簿として綴じて保存する運用**と、
> **カードの内容をシステムに入力して名簿とする運用**があり、施設により異なります。
> `【Fact】` いずれの場合も、**作成の日から3年間の保存**が必要です（施行規則第4条の2第1項）。

### 10-2-3 領収書

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロント |
| **誰が使うか** | 客（`【Typical】` 出張者は**会社への精算**に使う）／⑧ 経理（控え） |
| **いつ作るか** | **常時**（チェックアウト時＝A-9） |
| **何が書いてあるか** | 宛名、金額、日付、但し書き（宿泊代として等）、内訳（宿泊料／飲食／入湯税・宿泊税）`【Varies】`、発行者名 |
| **何のためか** | **客が代金を支払ったことの証明** |
| **これが無いと何が困るか** | `【Inference】` **出張者は会社に経費を精算できません。** ビジネスホテルでは客の大半が法人出張者であり（`03_company-structure.md` 3-1）、領収書の宛名・但し書きの正確さが直接の要求になります |

`【Typical】` 宛名を会社名にするか個人名にするか、但し書きをどう書くかは客の求めによります。
`【Inference】` **入湯税・宿泊税は宿の売上ではないため、内訳として分けて示すことが求められる場合があります** `【Varies】`。

### 10-2-4 忘れ物管理台帳

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロント（**発見は ③ 客室清掃が多い**） |
| **誰が使うか** | ② フロント（問い合わせへの照合・返還）／⑨ 人事・総務（記録の管理）／**警察署**（提出する場合） |
| **いつ作るか** | 案件発生時（発見されたとき） |
| **何が書いてあるか** | 発見した日時、発見した場所（部屋番号・共用部）、発見した人、物の種類と特徴、その部屋の宿泊者（名簿・予約記録で照合）、その後の扱い（**遺失者に返還／警察署長に提出**）とその日付 |
| **何のためか** | `【Inference】` **後から遺失者を特定し、返還または提出を行うため。** また、`【Fact】` 遺失物法第15条が求める**善良な管理者の注意**をもって取り扱ったことを示すため |
| **これが無いと何が困るか** | `【Inference】` **「あったのかなかったのか」も答えられません。** 忘れ物は後から必ず問い合わせが来る種類のものです |

**根拠となる法令（条文の語のまま）**

`【Fact】` **遺失物法第2条第1項**は、「**物件**」を、遺失物及び埋蔵物並びに**準遺失物**
（誤って占有した他人の物、**他人の置き去った物**及び逸走した家畜をいう…）と定義しています。
`【Fact】` **同条第2項**は、「**拾得**」とは、物件の占有を始めること
（埋蔵物及び**他人の置き去った物にあっては、これを発見すること**）をいうと定義しています。

`【Inference】` **客室の忘れ物は「他人の置き去った物」＝準遺失物**であり、
**置き去り物についての「拾得」は「これを発見すること」**です。

`【Fact】` **遺失物法第4条第2項**：施設において物件（埋蔵物を除く。）の拾得をした拾得者
（当該施設の施設占有者を除く。）は、**速やかに、当該物件を当該施設の施設占有者に交付しなければならない。**

`【Fact】` **遺失物法第13条第1項**：第4条第2項の規定による交付を受けた**施設占有者**は、**速やかに**、
当該交付を受けた物件を**遺失者に返還し、又は警察署長に提出しなければならない。**
ただし、法令の規定によりその所持が禁止されている物に該当する物件及び
犯罪の犯人が占有していたと認められる物件は、速やかに、これを警察署長に提出しなければならない。

`【Fact】` **遺失物法第15条**：施設占有者は、交付を受けた物件については、第13条第1項の規定により
遺失者に返還し、又は警察署長に提出するまでの間、**これを善良な管理者の注意をもって取り扱わなければならない。**

`【Varies】` **保管期間の運用は施設により異なります。** 本資料では特定の日数を示しません。
詳細は `07_goods.md` 7-6 および `05_departments.md` E-②-9／E-③-9 を参照してください。

### 10-2-5 貴重品・手荷物の預かり記録（預かり証）`【Varies】`

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ② フロント |
| **誰が使うか** | ② フロント（返却時の本人確認）／客（預かり証） |
| **いつ作るか** | 案件発生時（預かるとき） |
| **何が書いてあるか** | 預かる物の内容、**高価品の場合はその種類及び価額**（客からの通知）、預ける人の氏名・部屋番号、預かった日時、返却の予定、返却した日時と受領のしるし `【Varies】` |
| **何のためか** | `【Inference】` 誰の何をいつ預かったかを確定し、正しい相手に返すため。また `【Fact】` 商法第597条が「**客がその種類及び価額を通知してこれを場屋営業者に寄託した場合**」を条件としていることと対応する |
| **これが無いと何が困るか** | `【Inference】` **預かったことの内容が双方で食い違います。** `【Fact】` 商法第596条第1項により、宿（**場屋営業者**）は客から寄託を受けた物品の滅失・損傷について、**不可抗力によるものであったことを証明しなければ損害賠償の責任を免れることができない**立場にあります |

`【Fact】` なお **商法第596条第3項**は、客が場屋の中に携帯した物品につき
**責任を負わない旨を表示したときであっても、前二項の責任を免れることができない**と定めています。
詳細は `07_goods.md` 7-7 を参照してください。

| 項目 | 内容 |
|---|---|
| **誰が作るか** | ⑧ 経理・財務機能（**特別徴収義務者として**） |
| **誰が使うか** | **市町村**（提出先）／⑧ 経理（控え） |
| **いつ作るか** | `【Fact】` **当該市町村の条例で定める納期限までに**（地方税法第701条の4第2項）。`【Varies】` **納期限は条例による** |
| **何が書いてあるか** | `【Fact】` その徴収すべき入湯税に係る**課税標準額、税額その他条例で定める事項**（地方税法第701条の4第2項） |
| **何のためか** | **客から預かった税を、市町村に納めるため** |
| **これが無いと何が困るか** | `【Fact】` **法令上の義務です。** 特別徴収義務者は、納入申告書を市町村に提出し、**及びその納入金を当該市町村に納入する義務を負う**（同項） |

**根拠条文（条文の語のまま）**

`【Fact】` **地方税法第701条の3**
> 「入湯税の徴収については、**特別徴収の方法によらなければならない。**」

`【Fact】` **地方税法第701条の4第1項**
> 「入湯税を特別徴収によつて徴収しようとする場合においては、
> **浴場の経営者その他徴収の便宜を有する者を当該市町村の条例によつて特別徴収義務者として指定し、
> これに徴収させなければならない。**」

`【Fact】` **地方税法第701条の4第2項**
> 「前項の特別徴収義務者は、**当該市町村の条例で定める納期限までに**その徴収すべき入湯税に係る
> 課税標準額、税額その他条例で定める事項を記載した**納入申告書を市町村に提出し、
> 及びその納入金を当該市町村に納入する義務を負う。**」

> **★宿泊税は別の制度です★**
> `【Fact】` **宿泊税は地方税法に個別の定めがある税ではなく、
> 地方団体が条例で定める特定の費用に充てるために課することができる法定外目的税**です
> （地方税法第731条第1項）。`【Fact】` 新設・変更には**あらかじめ総務大臣に協議し、その同意を得る**必要があります（同条第2項）。
> `【Varies】` **課税の有無・対象・税率・免税点・納期限・納入書の様式は、地方団体ごとに条例で異なります。**
> **本資料では特定の自治体の内容を示しません。一律に「月次」と書くこともできません。**

**根拠条文（条文の語のまま）**

`【Fact】` **消防法第8条第1項**（抜粋）
> 「（…）**多数の者が出入し、勤務し、又は居住する防火対象物で政令で定めるものの管理について
> 権原を有する者は、政令で定める資格を有する者のうちから防火管理者を定め、
> 政令で定めるところにより、当該防火対象物について消防計画の作成、
> 当該消防計画に基づく消火、通報及び避難の訓練の実施、
> 消防の用に供する設備、消防用水又は消火活動上必要な施設の点検及び整備、
> 火気の使用又は取扱いに関する監督、避難又は防火上必要な構造及び設備の維持管理
> 並びに収容人員の管理その他防火管理上必要な業務を行わせなければならない。**」

`【Fact】` **消防法第8条第2項**：防火管理者を定めたときは、**遅滞なくその旨を所轄消防長又は消防署長に
届け出なければならない**（解任したときも同様）。

`【Fact】` **消防法施行令別表第一（五）項イ**は「**旅館、ホテル、宿泊所その他これらに類するもの**」です。
`【Fact】` **消防法施行令第1条の2第3項第1号ロ**により、別表第一（五）項イ等で
**収容人員が30人以上**のものは防火管理者を定めなければならない防火対象物にあたります。
`【Example】` Xホテルの収容定員は90名であり、この人数の基準を上回る規模です。

### 10-5-3 消防用設備等点検結果報告書（維持台帳を含む）

| 項目 | 内容 |
|---|---|
| **誰が作るか** | `【Fact】` 政令で定めるものについては**消防設備士免状の交付を受けている者又は総務省令で定める資格を有する者**が点検し、その他のものは関係者が自ら点検する。`【Example】` Xホテルでは支配人が期限を管理し、業者に依頼 |
| **誰が使うか** | **消防長又は消防署長**（報告先）／⑥ 設備管理（是正すべき事項の把握） |
| **いつ作るか** | `【Fact】` 点検は**種類及び点検内容に応じて、一年以内で消防庁長官が定める期間ごと**（消防法施行規則第31条の6第1項）。報告は`【Fact】`令別表第一（五）項イ等の防火対象物は**一年に一回**（同条第3項第1号） |
| **何が書いてあるか** | 点検した消防用設備等の種類、点検した者（資格）、点検の日、結果、不良箇所と措置 |
| **何のためか** | `【Inference】` 消防用設備は、**使わない期間が長く、いざというときに動かなければ意味がない**ためです |
| **これが無いと何が困るか** | `【Fact】` **法令上の義務です。** 点検させ、**その結果を消防長又は消防署長に報告しなければならない**（消防法第17条の3の3） |

**根拠条文（条文の語のまま）**

`【Fact】` **消防法第17条第1項**（抜粋）
> 「**学校、病院、工場、事業場、興行場、百貨店、旅館、飲食店、地下街、複合用途防火対象物
> その他の防火対象物で政令で定めるものの関係者**は、政令で定める消防の用に供する設備、
> 消防用水及び消火活動上必要な施設（以下「消防用設備等」という。）について
> 消火、避難その他の消防の活動のために必要とされる性能を有するように、
> **政令で定める技術上の基準に従つて、設置し、及び維持しなければならない。**」

`【Fact】` **消防法第17条の3の3**
> 「第十七条第一項の防火対象物（政令で定めるものを除く。）の関係者は、
> 当該防火対象物における消防用設備等又は特殊消防用設備等（…）について、
> **総務省令で定めるところにより、定期に、**当該防火対象物のうち政令で定めるものにあつては
> **消防設備士免状の交付を受けている者又は総務省令で定める資格を有する者に点検させ、**
> その他のものにあつては自ら点検し、
> **その結果を消防長又は消防署長に報告しなければならない。**」

`【Fact】` **消防法施行規則第31条の6第1項**
> 「法第十七条の三の三の規定による消防用設備等の点検は、
> **種類及び点検内容に応じて、一年以内で消防庁長官が定める期間ごとに行うものとする。**」

`【Fact】` **消防法施行規則第31条の6第3項**（抜粋）
> 「防火対象物の関係者は、前二項の規定により点検を行った結果を、
> **維持台帳**（…）**に記録するとともに、**次の各号に掲げる防火対象物の区分に従い、
> **当該各号に定める期間ごとに消防長又は消防署長に報告しなければならない。**（…）
> **一 令別表第一（一）項から（四）項まで、（五）項イ、（六）項、（九）項イ、（十六）項イ、
> （十六の二）項及び（十六の三）項に掲げる防火対象物 一年に一回**」

> **維持台帳という帳票が条文に出てきます。**
> `【Fact】` 第31条の6第3項は、点検の結果を**維持台帳に記録するとともに**報告することを求めています。
> `【Inference】` つまり**記録（維持台帳）と報告（消防長又は消防署長へ）は別の行為**であり、
> どちらも必要です。

### 10-5-5 簡易専用水道の検査の結果

| 項目 | 内容 |
|---|---|
| **誰が作るか** | `【Fact】` **地方公共団体の機関又は国土交通大臣及び環境大臣の登録を受けた者**（検査を行う者）。**設置者が検査を受ける** |
| **誰が使うか** | ⑥ 設備管理（結果の確認・是正）／`【Varies】` 保健所等 |
| **いつ作るか** | `【Fact】` **水道法施行規則第56条第1項**により、法第34条の2第2項の規定による検査は**毎年一回以上定期に行うものとする** |
| **何が書いてあるか** | 検査の日、検査を行った者、水槽の状態、給水栓における水の状態、水質の検査の結果 `【Varies】` |
| **何のためか** | `【Inference】` **受水槽（貯水槽）を経た水は、水道から直接来る水と違い、槽の中で汚染されうる**ためです |
| **これが無いと何が困るか** | `【Fact】` **法令上の義務です**（水道法第34条の2第2項） |

**根拠条文（条文の語のまま）**

`【Fact】` **水道法第34条の2**
> 「**簡易専用水道の設置者は、国土交通省令で定める基準に従い、その水道を管理しなければならない。**
> ２ **簡易専用水道の設置者は、当該簡易専用水道の管理について、国土交通省令**
> （簡易専用水道により供給される水の水質の検査に関する事項については、環境省令）
> **の定めるところにより、定期に、地方公共団体の機関又は
> 国土交通大臣及び環境大臣の登録を受けた者の検査を受けなければならない。**」

`【Fact】` **水道法施行規則第55条**（管理基準。抜粋）
> 「法第三十四条の二第一項に規定する国土交通省令で定める基準は、次に掲げるものとする。
> **一 水槽の掃除を毎年一回以上定期に行うこと。**
> 二 水槽の点検等有害物、汚水等によつて水が汚染されるのを防止するために必要な措置を講ずること。
> 三 給水栓における水の色、濁り、臭い、味その他の状態により供給する水に異常を認めたときは、
> 水質基準に関する省令の表の上欄に掲げる事項のうち必要なものについて検査を行うこと。
> 四 供給する水が人の健康を害するおそれがあることを知つたときは、直ちに給水を停止し、
> かつ、その水を使用することが危険である旨を関係者に周知させる措置を講ずること。」

`【Fact】` **水道法施行規則第56条第1項**
> 「**法第三十四条の二第二項の規定による検査は、毎年一回以上定期に行うものとする。**」

`【Fact】` 「**簡易専用水道**」とは、水道事業の用に供する水道及び専用水道以外の水道であつて、
水道事業の用に供する水道から供給を受ける水のみを水源とするものをいいます
（水道法第3条第7項。ただし、その用に供する施設の規模が政令で定める基準以下のものを除く）。
`【Varies】` **施設の受水槽が簡易専用水道に当たるかは規模により異なります。**

> **水道法と食品衛生法は別の要求です。**
> `【Fact】` 食品衛生法施行規則 別表第17第4号ニは、
> 「**貯水槽を使用する場合は、貯水槽を定期的に清掃し、清潔に保つこと。**」と定めています。
> `【Inference】` **一方を満たせば他方も満たされるという関係にはありません**（`05_departments.md` E-⑥-3）。

| **何が書いてあるか** | 従業者ごとの勤務日・勤務時間帯（早番・遅番・**夜勤**）、休日、各時間帯の配置人数、引き継ぎの時刻 |
| **何のためか** | `【Inference】` **24時間・年中無休で人を配置するため**（`03_company-structure.md` 3-2 ⑨）。宿泊業ではシフト作成そのものが重要な業務になります |
| **これが無いと何が困るか** | `【Inference】` **フロントに誰もいない時間帯が生まれます。** また、繁忙日に人が足りず、閑散日に人が余ります |

**シフト作成に必要な情報は4つの機能から来る**（`05_departments.md` PART 3 3-8-2）

```
  ① 予約・販売管理 ──▶ 先の予約の入り具合（何人来るか）
  ② フロント       ──▶ 到着の時間帯の偏り、夜間の在館状況
  ③ 客室清掃       ──▶ 清掃室数（Xホテルは委託だが、繁忙期は自社パートも投入）
  ④⑤ 料飲・調理    ──▶ 食事の数と提供時刻
                            ↓
                      ⑨ がシフトを組む
```

**関係する法令（条文の語のまま。**それぞれ別の条文です**）**

`【Fact】` **労働基準法第32条第1項**
> 使用者は、労働者に、休憩時間を除き**一週間について四十時間**を超えて、労働させてはならない。

`【Fact】` **労働基準法第35条第1項**
> 使用者は、労働者に対して、**毎週少くとも一回の休日**を与えなければならない。

`【Fact】` **労働基準法第37条第4項**
> 使用者が、**午後十時から午前五時まで**（…）の間において労働させた場合においては、
> その時間の労働については、通常の労働時間の賃金の計算額の**二割五分以上の率**で計算した
> **割増賃金**を支払わなければならない。

`【Fact】` **労働基準法第89条・同第1号**
> 常時十人以上の労働者を使用する使用者は、次に掲げる事項について**就業規則を作成し、
> 行政官庁に届け出なければならない**。
> 一 始業及び終業の時刻、休憩時間、休日、休暇並びに
> **労働者を二組以上に分けて交替に就業させる場合においては就業時転換に関する事項**

`【Inference】` **交替制で働かせること自体が、就業規則の記載事項として法令に出てきます。**
24時間の現場を回す以上、シフトの組み方は労務上の論点になります（`06_people.md` 6-5-4）。

### 押さえるべき7点

1. **帳票は3種類に分かれる。**
   ① 法令が作成を義務づけているもの、② 無いと業務が止まるもの、③ 相手方とのやり取りのためのもの。
2. **宿泊者名簿は法定帳簿。** 旅館業法第6条第1項＋施行規則第4条の2
   （**作成の日から3年間保存**、備える場所、**日本国内に住所を有しない外国人は国籍及び旅券番号**）。
   違反は**五十万円以下の罰金**（第11条第1号）。
   **宿泊カード（客が記入する用紙）とは別物。**
3. **ナイトオーディットの日計表が、経理と価格判断の両方の起点になる。**
   入湯税・宿泊税は**売上と分けて**集計する。
4. **請求書が無ければ代金は入らない。** 法人契約は自動で入金されない。
5. **OTAの精算明細は「受け取る帳票」。** 自社の売上データとの突合が ⑧ 経理の中心業務の1つ。
6. **法定の記録は、法令ごとに対象・周期・報告先・資格要件がすべて違う。**
   消防用設備等の点検結果報告（**一年に一回**・消防長又は消防署長）、
   消火訓練及び避難訓練（**年二回以上**）、
   建築物の定期調査報告（**特定行政庁**・周期は政令と特定行政庁の指定による `【Varies】`）、
   簡易専用水道の検査（**毎年一回以上定期に**）、
   入湯税の納入（**条例で定める納期限まで** `【Varies】`）。
   **一文にまとめてはいけない。**
7. **勤務シフト表は宿泊業に固有の重さを持つ。** 24時間・年中無休の配置であり、
   `【Fact】` 労働基準法第89条第1号は**交替制の就業時転換に関する事項**を就業規則の記載事項としている。

### `【Varies】` として置いた論点

- 紙かシステムか、両方併用か（帳票ごとに施設により異なる）
- 忘れ物の保管期間
- 預かり証を発行するか
- 客室清掃指示表・清掃状況表の様式と伝達手段
- 建築物定期調査報告の対象と周期（政令および特定行政庁の指定による）
- 簡易専用水道に当たるかどうか（受水槽の規模による）
- 衛生管理の記録の様式・項目（営業者が定める措置の内容による）
- 宿泊税の納入書の様式・納期限（自治体の条例による）
- 資金繰り表を作るかどうか、その様式
