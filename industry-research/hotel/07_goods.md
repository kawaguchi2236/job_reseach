## 7-0 【最初に】宿泊業の「モノ」は部屋そのものではない

### よくある誤解

宿泊業のモノと聞くと「客室」を思い浮かべがちですが、**客室は動きません。**
建物に固定されており、入ってくることも出ていくこともありません。

`【Inference】` 宿泊業で実際に動いているモノは、次の2種類です。

```
  ① 部屋を「売れる状態」にするために出入りする物
     → リネン、アメニティ、清掃資材、備品、（食事を出す施設は）食材

  ② 客が持ち込み、客が持ち出す物
     → 客の荷物、預かり品・貴重品、忘れ物（遺失物）
```

### そしてもう1つ、「状態」という形のモノの流れがある

`【Inference】` `02_industry-structure.md` 11-3 のとおり、
**客室清掃は製造工程**です。客室は物理的には移動しませんが、
**「売れない状態」から「売れる状態」へと作り変えられて**います。

```
  使用済み ──(清掃)──▶ 清掃済 ──(点検)──▶ 販売可 ──(販売・宿泊)──▶ 使用済み
     ▲                                                                    │
     └────────────────────────────────────────────────────────────────────┘
```

**この状態遷移が、宿泊業における「製品が工程を流れていく姿」に相当します。**
製造業でいえば、同じ1つの部屋が毎日「原材料 → 仕掛品 → 完成品 → 出荷」を繰り返している、
と考えると理解しやすくなります `【Inference】`。

したがって本ファイルは、次の順で扱います。

| 節 | 扱うもの |
|---|---|
| **7-1** | **客室の状態遷移**（＝売り物そのものの流れ） |
| 7-2 | リネン（**循環する**モノ） |
| 7-3 | アメニティ・消耗品（**使い切る**モノ） |
| 7-4 | 食材（**人数に連動し、持ち越せない**モノ）`【Varies】` |
| 7-5 | 清掃資材・備品・その他 |
| 7-6 | 忘れ物（遺失物）— **法令で扱いが定まっているモノ** |

| 7-8 | 廃棄物 |
| 7-9 | 【Example】1日のモノの動き |

## 7-1 客室という「売り物」の状態遷移

### 7-1-1 5つの状態

`【Typical】` 客室は、次の状態のいずれかにあります。
呼び名は施設・システムにより異なります `【Varies】` が、**中身は共通です**。

| 状態 | どういう状態か | 売れるか | 誰が把握しているか |
|---|---|---|---|
| **販売可（清掃済・点検済）** | 次の客をすぐ迎えられる | **売れる** | ② フロント／① 予約・販売管理 |
| **在室（インハウス）** | 客が滞在中 | 売れない（連泊で埋まっている） | ② フロント |
| **使用済み（チェックアウト済・清掃前）** | 客は出たが、まだ手つかず | **売れない** | ② フロント → ③ 客室清掃 |
| **清掃中／清掃済・点検前** | 作業の途中 | **売れない** | ③ 客室清掃 |
| **使用不可（故障・修繕）** | 設備が壊れている、工事中 | **売れない** | ⑥ 設備管理 → ① 予約・販売管理 |

`05_departments.md` PART 3 3-2-3 の表と同じ区分です。**詳細はそちらを参照してください。**

### 7-1-2 なぜ「清掃済」と「販売可」を分けるのか

`【Inference】` **清掃が終わったことと、売ってよいことは別だからです。**

`05_departments.md` E-③-5 のとおり、清掃の後には**点検（インスペクション）**という工程があります。

- **インスペクション（客室点検）**
  → 清掃が終わった部屋を、別の目で確認する作業のこと。
  → 実務例：シーツにしわや髪の毛がないか、備品がそろっているか、
    照明・テレビ・エアコン・シャワーが動くか、前の客の忘れ物がないかを見る。
  → **なぜするのか**：`【Inference】` 清掃した本人は「終わった」と思っています。
    しかし**客が最初に見る状態が商品の質そのもの**であり、
    不備があれば部屋を替えるか、その場で直すことになります。
    **売ってから気づくのでは遅い**ため、売る前に1回止めます。

> `【Example】`（説明用の架空例）Xホテルの406号室。
> 10:00 チェックアウト → 10:30 清掃開始 → 11:15 清掃完了 →
> 11:20 点検でシャワーの出が悪いことが判明 → **「販売可」にはならず「使用不可」へ**。
> **11:15 の時点では「清掃済」ですが、売れる部屋ではありませんでした。**

### 7-1-3 状態を変える人と、それを知らせる相手

```
  ② フロント ──「今、406が空いた」───────────▶ ③ 客室清掃
                                                  │
                                            （清掃・リネン交換・補充）
                                                  │
                                            （点検＝インスペクション）
                                                  │
        ┌─────────────────────────────────────────┴───────────┐
        │                                                     │
   不備なし                                              不備あり
        │                                                     │
        ▼                                                     ▼
  ③ ──「406は販売可」──▶ ② フロント              ③ ──▶ ⑥ 設備管理
                             │                              │
                             ▼                              ▼
                      ① 予約・販売管理                 修理／売止め
                      （在庫に戻る）                   （在庫から外す）
```

`【Inference】` **部屋が仕上がっていても、その情報が ② に届くまで、その部屋は「無い」のと同じです。**
この点の詳細は `05_departments.md` E-③-6 および PART 3 3-2 にあります。
**情報としての側面は `09_information.md` で扱います。**

### 7-1-4 その日に作れる「商品」の数には上限がある

`【Inference】` 客室は毎日作り直されますが、**作り直せる数には上限があります。**

> **その日に清掃・点検を終えられる部屋数 ＝ その日に受け入れられる客の数の上限**

`04_end-to-end-process.md` A-10 のとおり、
チェックアウト時刻からチェックイン開始時刻までの数時間に、
その日にチェックアウトした全室を仕上げる必要があります。
`【Varies】` チェックアウト時刻・チェックイン開始時刻は施設により異なります。

`【Inference】` したがって**前日の予約状況（＝翌日のチェックアウト室数）が、翌日の清掃の作業量を決めます。**
これは「モノの流れ」であると同時に、人員配置の話でもあります（`06_people.md` 6-6）。

## 7-2 リネン — 唯一「循環する」モノ

### 7-2-1 リネンとは

- **リネン**
  → 宿泊施設で使う布製品の総称。シーツ、枕カバー、掛け布団カバー、
    バスタオル、フェイスタオル、バスマット、浴衣・パジャマなど `【Varies】`。
  → 実務例：1室分のリネンをセットにして清掃カートに積み、
    部屋ごとに使用済みを外して新しいものに替える。
  → **なぜ重要か**：`【Inference】` **リネンが無ければ部屋を売れません。**
    `02_industry-structure.md` 11-4 の表のとおり、リネンを切らした場合の帰結は
    「部屋を売れない」です。アメニティを切らした場合（客からの指摘）とは重さが違います。

- **リネンサプライ**
  → 清潔なリネンを納品し、使用済みのリネンを回収して洗濯・仕上げを行い、
    再び納品する事業者のこと（`02_industry-structure.md` 11-1 ⑤）。
  → **なぜ外部に出すのか**：`【Inference】` 業務用の洗濯設備・乾燥設備・仕上げ設備を
    施設内に持つと、設備投資と人員が必要になります。
    `【Varies】` 自館で洗濯する施設もあり、リネンサプライに委託する施設もあります。

### 7-2-2 リネンの循環（Xホテルの場合・`【Example】`）

```
  【社外】Dリネン（リネンサプライ）
      │
      │ ① 清潔なリネンを納品（枚数を数えて受け取る）
      ▼
  【館内】リネン室（清潔なリネンの保管場所）
      │
      │ ② 清掃時に清掃カートへ積む（1室分ずつセット）
      ▼
  【客室】ベッドメイク・タオル類の設置
      │
      │ ③ 客が使用
      ▼
  【客室】使用済みリネン
      │
      │ ④ 清掃時に回収（新しいものと交換）
      ▼
  【館内】汚物室（使用済みリネンの一時置き場）
      │
      │ ⑤ Dリネンが回収（枚数を数えて引き渡す）
      ▼
  【社外】Dリネン ──（洗濯・乾燥・仕上げ）──▶ ① へ戻る
```

`【Typical】` 納品と回収は**同じ機会に行われる**ことが多く、
「清潔なリネンを置いていき、汚れ物を持っていく」という形になります `【Varies】`。

### 7-2-3 枚数を数えるのはなぜか

`【Inference】` リネンの取引は**枚数**で成り立っているためです。

| 場面 | 数える理由 |
|---|---|
| **納品時** | 発注した枚数が来ているか。足りなければ**その日の清掃が止まる** |
| **回収時** | 引き渡した枚数の記録。`【Varies】` 洗濯代の算定根拠になる契約形態がある |
| **在庫確認** | 館内に何日分あるか。繁忙期に切らさないため |

`【Varies】` 料金の体系（枚数あたりの洗濯代か、リースか、買取か）は契約により異なります。
本資料では特定の単価・体系を示しません。

> **なぜ数日分を館内に持つのか**
> `【Inference】` リネンは**外に出ている間は使えない**からです。
> 今日使った分は洗濯に出ており、戻ってくるのは翌日以降です。
> したがって、**館内 ＋ 客室にセット済み ＋ 洗濯中**の3か所に同時に存在している必要があります。
> `【Typical】` このため、客室数の数倍の枚数を保有・運用することになります `【Varies】`。

### 7-2-4 Y旅館ではどう違うか `【Example】`

| 論点 | Xホテル（ビジネスホテル） | Y旅館（温泉旅館） |
|---|---|---|
| 主なリネン | シーツ・枕カバー・タオル類（**ベッド用**） | 上記＋**敷布団・掛け布団のカバー**、**浴衣**、帯 |
| 交換の作業 | ベッドメイク | **布団の上げ下ろし**を伴う（客室係が担当） |
| 大浴場 | 小規模。タオルの使用量は限定的 `【Varies】` | **内湯・露天**。タオル・バスマットの使用量が多い `【Varies】` |
| 誰が扱うか | C清掃（社外）＋ ③ 客室清掃 | **清掃パート ＋ 客室係（仲居）**（自社） |

`【Inference】` 旅館では**布団という嵩の大きいものを毎日出し入れする**ため、
リネンの重量・体積・作業時間がビジネスホテルより大きくなります
（`03_company-structure.md` 3-1 の比較表「客室清掃」の行）。

## 7-3 アメニティ・消耗品 — 使い切って終わるモノ

### 7-3-1 アメニティとは

- **アメニティ**
  → 客室に備え付けて、客が自由に使える小物のこと。
    歯ブラシ、シャンプー・リンス・ボディソープ、石けん、カミソリ、ヘアブラシ、
    綿棒、シャワーキャップ、スリッパ、ティーバッグなど `【Varies】`。
  → 実務例：清掃時に使われた分を補充し、使われていなければそのまま残す。
  → **なぜ置くのか**：`【Inference】` 客が荷物を減らせること自体が提供価値の一部だからです
    （`01_overview.md` 1-3）。

`【Varies】` 何を置くか、客室に置くかフロントで渡すか（アメニティバー方式）は施設により異なります。

### 7-3-2 アメニティの流れ（一方通行）

```
  【社外】アメニティ業者
      │
      │ ① 発注 → 納品（箱単位・ケース単位）`【Varies】`
      ▼
  【館内】倉庫（ストック）
      │
      │ ② 清掃カートへ補給
      ▼
  【清掃カート】
      │
      │ ③ 清掃時に客室へ補充（使われた分だけ）
      ▼
  【客室】
      │
      │ ④ 客が使用する／持ち帰る
      ▼
  （消費されて終わり。戻ってこない）
```

`【Inference】` **リネンとの決定的な違いは、戻ってこないこと**です。
したがってアメニティは**「使った分だけ買い続ける」**費用になります。

### 7-3-3 在庫はどう管理されるか `【Varies】`

`【Typical】` 発注のきっかけは次の2つです。

| きっかけ | 内容 |
|---|---|
| **定期の在庫確認** | **週次**で倉庫を見て、少ないものを発注する `【Varies】` |
| **繁忙期の前倒し** | 連休・イベント前に多めに確保する |

`【Inference】` 切らすと客からの指摘につながりますが、
**持ちすぎると保管場所を占有し、代金が先に出ていきます。**
`【Varies】` 何週間分を持つかは施設により異なります
（`02_industry-structure.md` 11-4 の表では `【Typical】` 数週間分としています）。

### 7-3-4 消耗品（アメニティ以外）

`【Typical】` 客室・共用部で日々消費されるものには、次のようなものがあります。

| 品目 | どこで使うか | 補充する人 |
|---|---|---|
| トイレットペーパー・ティッシュ | 客室・共用トイレ | ③ 客室清掃 |
| ゴミ袋 | 客室・共用部 | ③ 客室清掃 |
| 客室備え付けの飲料水・お茶 `【Varies】` | 客室 | ③ 客室清掃 |
| 封筒・便箋・館内案内・避難経路図 `【Varies】` | 客室 | ③ 客室清掃 |
| 大浴場のシャンプー類・ドライヤー用品 `【Varies】` | 大浴場 | ③ 客室清掃（共用部担当） |

## 7-4 食材 — 人数に連動し、持ち越せないモノ `【Varies】`

> `【Varies】` **食事を提供しない施設（素泊まり専門の簡易宿所・民泊等）には、この節は該当しません。**
> `03_company-structure.md` 3-2 のとおり、④ 料飲機能・⑤ 調理機能は施設により有無が異なります。

### 7-4-1 食材の流れ

```
  【社内】② フロント／① 予約・販売管理
      │
      │ ① **食数の確定**（何人分の食事を出すか）← これが起点
      ▼
  【社内】⑤ 調理
      │
      │ ② 献立に基づき発注量を計算し、食材卸・酒類卸へ発注
      ▼
  【社外】食材卸・酒類卸
      │
      │ ③ 納品
      ▼
  【館内】検収（数量・鮮度・温度の確認）  ← ここで受け取るかどうかを判断する
      │
      │ ④ 冷蔵・冷凍・常温で保管
      ▼
  【厨房】仕込み → 調理 → 盛り付け
      │
      │ ⑤ ④ 料飲が客へ提供
      ▼
  【客】
      │
      ▼
  残渣・廃棄（7-8 へ）
```

### 7-4-2 食材だけが持つ2つの性質

`02_industry-structure.md` 11-4 のとおりです。**再掲します。**

`【Inference】`

1. **発注量が「部屋数」ではなく「人数」で決まる。**
   リネンとアメニティは客室数に連動しますが、**食材は人数に連動します。**
   だから「2人部屋に1人だけ泊まった」場合、リネンは1室分ですが食材は1人分です。
2. **在庫として持ち越せない（生鮮品）。**
   キャンセルが出ると、**部屋の売上を失うだけでなく、食材そのものが無駄になります。**

> `【Example】`（説明用の架空例。`02_industry-structure.md` 11-4 と同じ例）
> Y旅館（15室）で、明日20名の予約。今日の午後、卸に20名分の刺身用の魚を発注し、夕方に納品を受けます。
> 明日の朝、10名分のキャンセルが入った場合、
> **失うのは10名分の宿泊料だけではなく、10名分の魚の仕入代金もです。**

`【Inference】` これが `01_overview.md` 1-5 の
**「素泊まりと1泊2食付きではビジネスモデルが変わる」**の、モノの側から見た姿です。

### 7-4-3 検収で何を見るか

`05_departments.md` E-⑤-3 に詳細があります。要点のみ示します。

| 確認すること | なぜか |
|---|---|
| **数量** | 発注どおりか。足りなければ献立を変えるか、当日中に手配する |
| **鮮度・状態** | `【Inference】` 傷んだものを受け取れば、そのまま客に出すことになる |
| **温度** | `【Inference】` 冷蔵・冷凍品が適切な温度で届いているか |
| **期限表示** | 消費期限・賞味期限。先に使うべきものを分ける |

`【Fact】` 食品衛生法第51条第1項は、厚生労働大臣が、営業（…）の施設の内外の清潔保持、
**ねずみ及び昆虫の駆除**その他**一般的な衛生管理**に関すること（同項第1号）および
**食品衛生上の危害の発生を防止するために特に重要な工程を管理するための取組**に関すること（同項第2号）について、
**公衆衛生上必要な措置の基準**を定めなければならないと定めています。
`【Fact】` 同条第2項は、**営業者は、同条第1項の基準に従い、厚生労働省令で定めるところにより
公衆衛生上必要な措置を定め、これを遵守しなければならない**と定めています。

`【Fact】` その厚生労働省令である食品衛生法施行規則 別表第17は、たとえば
第3号ロとして「**原材料の仕入れに当たつては、衛生状態に留意して、鮮度等の状態を確認すること**」、
第3号ニとして「**原材料に寄生虫、微生物、農薬、動物用医薬品、重金属、放射性物質等の
食品衛生上の危害の原因となる物質が混入し、又は付着するおそれがある場合には、
使用前に洗浄、殺菌等を行うこと**」を定めています。

`【Inference】` 検収という作業は、この**原材料の確認**にあたる実務です。
食品衛生に関する記述の詳細は `05_departments.md` E-⑤-6 および `15_rules-customs.md` を参照してください。

### 7-4-4 Xホテル（朝食のみ）と Y旅館（1泊2食）の違い `【Example】`

|---|---|---|

## 7-6 忘れ物（遺失物）の流れ — 法令で扱いが定まっているモノ

### 7-6-1 なぜここで扱うのか

`【Inference】` 忘れ物は、**客が持ち込み、客が持ち出さなかったモノ**です。
宿の所有物ではありませんが、**宿の管理下に入ってしまいます。**
そして、その扱いは**遺失物法に定めがあります**。

### 7-6-2 条文の語をそのまま押さえる

> `common/methodology.md` の鉄則に従い、**条文の語をそのまま引用します。要約・言い換えはしません。**
> 引用は `19_sources.md` §H に記録された、team-lead が e-Gov法令API で取得・確認済みの条文です。

**（1）「物件」と「拾得」の定義**

`【Fact】` **遺失物法第2条第1項**
> 「この法律において『**物件**』とは、遺失物及び埋蔵物並びに**準遺失物**
> （誤って占有した他人の物、**他人の置き去った物**及び逸走した家畜をいう…）をいう。」

`【Fact】` **遺失物法第2条第2項**
> 「『**拾得**』とは、物件の占有を始めること
> （埋蔵物及び**他人の置き去った物にあっては、これを発見すること**）をいう。」

> **★ここが重要です★**
> `【Inference】` 客室の忘れ物は「**他人の置き去った物**」にあたり、**準遺失物**です。
> そして**置き去った物についての「拾得」の定義は、「これを発見すること」**です。
> 手に取って持ち上げる必要はなく、**見つけた時点で「拾得」にあたります。**
> 「まだ触っていないから拾得ではない」という理解は、条文と合いません。

**（2）施設と施設占有者の定義**

`【Fact】` **遺失物法第2条第5項**
> 「**施設**」とは、建築物その他の施設（車両、船舶、航空機その他の移動施設を含む。）であって、
> **その管理に当たる者が常駐するもの**をいう。

`【Fact】` **遺失物法第2条第6項**
> 「**施設占有者**」とは、**施設の占有者**をいう。

`【Inference】` 宿泊施設は、その管理に当たる者が常駐する建築物であり、
**宿は施設占有者にあたります。**

**（3）見つけた人がすること**

`【Fact】` **遺失物法第4条第2項**
> 「施設において物件（埋蔵物を除く。）の拾得をした拾得者（当該施設の施設占有者を除く。）は、
> **速やかに、当該物件を当該施設の施設占有者に交付しなければならない。**」

**（4）施設占有者（＝宿）がすること**

`【Fact】` **遺失物法第13条第1項**
> 「第四条第二項の規定による交付を受けた**施設占有者**は、**速やかに**、
> 当該交付を受けた物件を**遺失者に返還し、又は警察署長に提出しなければならない。**
> ただし、法令の規定によりその所持が禁止されている物に該当する物件及び
> 犯罪の犯人が占有していたと認められる物件は、速やかに、これを警察署長に提出しなければならない。」

**（5）返還・提出までの間の取扱い**

`【Fact】` **遺失物法第15条**
> 施設占有者は、交付を受けた物件については、第13条第1項の規定により遺失者に返還し、
> 又は警察署長に提出するまでの間、**これを善良な管理者の注意をもって取り扱わなければならない。**

### 7-6-3 実務に置き換えると

`【Inference】` 条文を宿の現場に置き換えると、モノは次のように流れます。

```
  【客室】客が物を置き去る
      │
      │ ③ 客室清掃のスタッフが**発見する**
      │   ＝ 遺失物法第2条第2項の「拾得」（置き去った物は「発見すること」が拾得）
      ▼
  清掃スタッフ（＝拾得者。施設占有者ではない）
      │
      │ **速やかに施設占有者（＝宿）へ交付する** ← 遺失物法第4条第2項
      ▼
  ② フロント（宿＝施設占有者として受け取る）
      │
      │ 記録・保管（**善良な管理者の注意をもって取り扱う** ← 同法第15条）
      │
      ├──▶ **遺失者に返還する**          ← 同法第13条第1項
      └──▶ **または警察署長に提出する**   ← 同法第13条第1項
             （所持が禁止されている物等は、速やかに警察署長へ提出）
```

`【Typical】` フロントが記録する項目は、おおむね次のとおりです `【Varies】`。

| 記録項目 | なぜ要るか |
|---|---|
| 発見した日時 | `【Inference】` いつ拾得されたかの起点 |
| 発見した場所（部屋番号・共用部） | `【Inference】` 遺失者を特定する手がかり |
| 発見した人 | `【Inference】` 交付の経路を明確にする |
| 物の種類と特徴 | `【Inference】` 問い合わせがあったときの照合 |
| その部屋の宿泊者 | `【Inference】` 宿泊者名簿・予約記録で照合する |
| その後の扱い（返還／警察署長へ提出） | `【Inference】` 処理の結果を残す |

`【Varies】` **保管期間の運用は施設により異なります。** 本資料では特定の日数を示しません。

> **初心者がつまずく点：「落とし物」と「置き去り物」は条文上の扱いが違います。**
> `【Fact】` 遺失物法第2条第1項は、**遺失物**と、**準遺失物**（誤って占有した他人の物、
> **他人の置き去った物**及び逸走した家畜）を分けて定義しています。
> `【Inference】` 客室に忘れられた物は、客が意図して置いていったわけではありませんが、
> **条文の分類上は「他人の置き去った物」＝準遺失物**として扱われます。
> そのため「拾得」の意味も「発見すること」になります（同条第2項）。

### 7-6-4 なぜ宿がこの流れを守るのか

`【Inference】`

1. **法令上の義務だからです。** 第13条第1項は「しなければならない」と定めています。
2. **宿は施設占有者であり、清掃スタッフは拾得者です。**
   `【Inference】` 外部委託であっても、清掃スタッフは「施設において物件の拾得をした拾得者」にあたり、
   **施設占有者（＝宿）に交付する**という経路は変わりません。
3. **忘れ物は、後から必ず問い合わせが来る種類のモノです。**
   記録がなければ、あったのかなかったのかも答えられません。

`05_departments.md` E-②-9（フロント側）および E-③-9（清掃側）に、
それぞれの機能から見た同じ業務の記述があります。**詳細はそちらを参照してください。**

## 7-7 預かり品・貴重品 — 法令で責任が定まっているモノ

### 7-7-1 どんなモノが預かられるか

`【Typical】`

| 預かるもの | いつ預かるか |
|---|---|
| 手荷物・スーツケース | チェックイン前の到着時／チェックアウト後の出発まで |
| 貴重品（現金・カード・パソコン等）`【Varies】` | 滞在中（客室金庫を使う場合もある `【Varies】`） |
| 宅配便の荷物 `【Varies】` | 到着前に送られてくる／出発後に発送する |
| クーポン・宿泊券 | 代理店経由の場合に回収する（`04_end-to-end-process.md` 4-2 ⑤） |

### 7-7-2 条文の語をそのまま押さえる

> `common/methodology.md` の鉄則に従い、**条文の語をそのまま引用します。**
> `19_sources.md` §F のとおり、商法第596条は team-lead が条文本体を再取得して逐語確認済みです。

**（1）場屋営業者の定義と、寄託を受けた物品についての責任**

`【Fact】` **商法第596条第1項**
> 「**旅館、飲食店、浴場その他の客の来集を目的とする場屋における取引をすることを業とする者**
> （以下この節において「**場屋営業者**」という。）は、**客から寄託を受けた物品の滅失又は損傷**については、
> **不可抗力によるものであったことを証明しなければ、損害賠償の責任を免れることができない。**」

**（2）寄託を受けていない携帯品についての責任**

`【Fact】` **商法第596条第2項**
> 「客が寄託していない物品であっても、**場屋の中に携帯した物品**が、
> **場屋営業者が注意を怠ったことによって滅失し、又は損傷したとき**は、
> 場屋営業者は、損害賠償の責任を負う。」

**（3）免責の表示をしても免れない**

`【Fact】` **商法第596条第3項**
> 「客が**場屋の中に携帯した物品につき責任を負わない旨を表示したときであっても**、
> 場屋営業者は、**前二項の責任を免れることができない。**」

**（4）高価品の特則**

`【Fact】` **商法第597条**
> 「**貨幣、有価証券その他の高価品**については、**客がその種類及び価額を通知してこれを
> 場屋営業者に寄託した場合を除き**、場屋営業者は、その滅失又は損傷によって生じた損害を
> **賠償する責任を負わない。**」

### 7-7-3 実務に置き換えると

`【Inference】` 条文から読み取れることを、モノの流れとして整理します。

```
  【客】荷物・貴重品を持って来る
      │
      ├─(a) ② フロントに**預ける**（＝寄託）
      │      → 商法第596条第1項の対象。
      │        滅失・損傷については、**不可抗力によるものであったことを証明しなければ
      │        損害賠償の責任を免れない**
      │      → **高価品**は、**客がその種類及び価額を通知して寄託した場合**に
      │        第597条の除外にあたらなくなる
      │
      └─(b) **預けずに客室・館内に持ち込む**（＝場屋の中に携帯した物品）
             → 商法第596条第2項の対象。
               **場屋営業者が注意を怠ったことによって**滅失・損傷したときは責任を負う

  ※(a)(b)いずれについても、**責任を負わない旨を表示しても、前二項の責任を免れることはできない**
    （同条第3項）
```

`【Inference】` フロントが貴重品を預かるときに**中身を確認し、記録する**という実務は、
第597条が「**種類及び価額を通知して**」寄託した場合を条件としていることと対応しています。

> **初心者がつまずく点：掲示だけでは責任は消えません。**
> `【Fact】` 商法第596条第3項は、**責任を負わない旨を表示したときであっても、
> 前二項の責任を免れることができない**と定めています。
> `【Inference】` 「貴重品の紛失について当館は責任を負いかねます」という掲示は、
> それ自体で第596条第1項・第2項の責任を消すものではありません。
> **本資料は条文の内容を説明するものであり、個別事案の判断を示すものではありません。**

### 7-7-4 預かり品と忘れ物は別物

`【Inference】` **この2つは混同されやすいので、分けて理解してください。**

| | **預かり品・貴重品** | **忘れ物（遺失物）** |
|---|---|---|
| どうやって宿の手元に来たか | **客が預けた**（寄託）／館内に携帯した | **客が置き去った** |
| 根拠となる法律 | **商法**（第596条・第597条） | **遺失物法**（第2条・第4条第2項・第13条第1項・第15条） |
| 宿の立場 | **場屋営業者** | **施設占有者** |
| 宿がすること | 保管し、本人確認のうえ返す | **速やかに遺失者に返還し、又は警察署長に提出する** |
| 客はそのモノの所在を知っているか | **知っている**（預けたので） | **知らない**（忘れたので） |

> **`common/methodology.md` の鉄則のとおり、この2つを一文にまとめてはいけません。**
> 根拠法令が違い、宿の法律上の立場も違い、求められる行為も違います。

## 7-9 【Example】1日のモノの動き

> `【Example】` **以下はすべて説明用の架空の例です。**
> Xホテル（客室70室・朝食のみ・客室清掃は外部委託）のある1日を、モノの動きで追います。
> 数値・時刻は説明のための仮置きであり、業界の代表値ではありません `【Varies】`。

### 前提

- その日のチェックアウト：52室
- その日のチェックイン：55件
- 翌朝の朝食見込み：58名

### モノの動き

| 時点 | 入ってきたモノ | 館内で変化したモノ | 出ていったモノ |
|---|---|---|---|
| **早朝** | — | 朝食の仕込み（前日納品の食材） | — |

## この章のまとめ（後続ファイルへの引き継ぎ事項）

### 押さえるべき8点

1. **宿泊業のモノは「部屋そのもの」ではなく、部屋を売れる状態にするための物である。**
2. **客室は物理的に動かないが、「使用済み → 清掃済 → 販売可」という状態遷移をしており、
   これが製造業における工程の流れに相当する。**
3. **「清掃が終わった」と「販売可」は別。** 間に点検（インスペクション）がある。
4. **リネンだけが循環する。** アメニティ・食材・清掃資材は一方通行。
   リネンは「館内・客室・洗濯中」の3か所に同時に存在している必要がある。
5. **食材は人数に連動し、持ち越せない。** リネン・アメニティは部屋数に連動する。
   この差が、素泊まりと1泊2食のビジネスモデルの差につながる。
6. **忘れ物は遺失物法。** 客室の忘れ物は「他人の置き去った物」＝**準遺失物**であり、
   置き去り物の「拾得」は**発見すること**（第2条第2項）。
   清掃スタッフは拾得者として**速やかに施設占有者（宿）へ交付**（第4条第2項）、
   宿は施設占有者として**速やかに遺失者に返還し、又は警察署長に提出**（第13条第1項）、
   その間は**善良な管理者の注意**（第15条）。
7. **預かり品は商法。** 宿は**場屋営業者**であり、寄託を受けた物品の滅失・損傷は
   **不可抗力によるものであったことを証明しなければ責任を免れない**（第596条第1項）。
   携帯品も注意を怠れば責任を負い（同条第2項）、
   **責任を負わない旨を表示しても免れない**（同条第3項）。
   **高価品は種類及び価額を通知して寄託した場合を除き責任を負わない**（第597条）。
8. **忘れ物と預かり品は別物。** 根拠法令・宿の立場・するべきことがすべて違うため、
   一文にまとめてはいけない。

### `【Varies】` として置いた論点

- リネンの保有枚数、料金体系（枚数あたり／リース／買取）
- アメニティの品目と在庫日数
- 清掃資材を委託先が持ち込むか宿が用意するか
- 忘れ物の保管期間の運用
- 鍵の形式（物理キー／カードキー／暗証番号）
- 廃棄物の分別区分・収集方法・費用（自治体により異なる）
- チェックアウト時刻・チェックイン開始時刻
