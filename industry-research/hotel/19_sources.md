## 4. 本セッションの調査手法（後続フェーズへの申し送り）

| 対象 | 手法 | 備考 |
|---|---|---|
| 法令条文 | e-Gov法令API に素の `curl`（`https://laws.e-gov.go.jp/api/1/lawdata/<法令ID>`） | XMLタグを除去してテキスト化。403にならない |
| 法令IDの検索 | `https://laws.e-gov.go.jp/api/2/laws?law_title=<法令名>` | JSON で law_id が返る |
| 法令の横断検索 | `https://laws.e-gov.go.jp/api/2/keyword?keyword=<語>&limit=N` | 条文の一部が該当法令とともに返る |
| 観光庁・国交省サイト | `curl` にブラウザUA | UTF-8。`sed` でタグ除去可 |
| 厚労省サイト | `curl` にブラウザUA ＋ **`iconv -f CP932 -t UTF-8`** | **Shift_JIS のため変換が必須** |
| xlsx の読み取り | `curl` で取得後、Python の `zipfile` + `re` で `sharedStrings.xml` と `worksheets/sheetN.xml` を直接パース | openpyxl 不要 |
| PDF | **読めない**（本環境にテキスト抽出手段なし） | URLの記録のみ |

> **注意**：xlsx のセルをパースする際、`<c r="A5" s="151"/>` のような**自己終了タグ**を
> 正規表現で取り逃すと、値が1列ずれて読めてしまいます。
> `<c r="..."...(?:/>|>(.*?)</c>)` の形で自己終了タグも明示的に扱ってください。

### `【Varies】` として数値を置かなかった主な論点（後続フェーズで扱う場合は出典が必要）

- OTA・旅行代理店の手数料率、決済手数料率
- 客室単価（ADR）の水準、RevPAR の水準
- キャンセルポリシーの料率と無料期限
- チェックイン／チェックアウトの時刻
- 清掃1室あたりの所要時間・委託単価
- 宿泊税の税率・課税対象（自治体ごとの条例）
- 家族経営の宿泊施設の比率
- 直販／OTA／代理店／法人契約の構成比
