## 3-1 なぜモデル企業を置くのか

建設業は、`01_overview.md` 1-6 で見たとおり、
**元請か下請か／官か民か／どの工種か**で仕事の中身がまったく変わります。
「建設会社一般」を語ろうとすると、どの会社にも当てはまらない抽象論になります。

そこで本資料では、**中小建設業で最も社数が多い層**である
「専門工事を主業とし、ゼネコンからの下請工事が中心の会社」を1社設定し、
その会社の仕事を具体的に追いかけます。

そのうえで、
- **元請として直接受注した場合** の違い
- **他の工種・他の業態（土木・住宅・総合建設）** の違い

を、各章で並べて示します。

## 3-2 モデル企業の設定

> ### ⚠️【Example】重要な注意
> **以下は「説明用のモデル企業」であり、実在する企業でも、統計上の平均値でもありません。**
> 建設業の仕事の流れを具体的に説明するために設定した**架空の会社**です。
> 従業員数・件数・金額はすべて**説明用の架空値**であり、業界の実データではありません。
> 実際の会社の姿は規模・地域・工種・取引先によって大きく異なります【Varies】。

### 会社概要【Example】

| 項目 | 設定 |
|---|---|
| **会社名** | 株式会社サンエイ内装（架空） |
| **所在地** | 首都圏の1都県内に本社1か所（営業所は本社のみ） |
| **創業** | 創業35年、2代目が経営 |
| **主業** | **内装仕上工事**（軽量鉄骨下地組・ボード張り・クロス張り・床仕上げ・間仕切り） |
| **建設業許可** | **都道府県知事許可／一般建設業**：内装仕上工事業、建築工事業、大工工事業 |
| **従業員** | **28名**（うち技能者〈自社職人〉8名） |
| **協力会社** | 12社（うち一人親方が6者） |
| **年間工事件数** | **約60件** |
| **1件あたり請負金額** | 300万円〜5,000万円（平均 約1,500万円） |
| **工期** | 2週間〜4か月（平均 約1.5か月） |
| **年間売上高** | **約9億円** |
| **主な取引先** | 中堅ゼネコン3社、地場ゼネコン4社、内装専業の元請会社2社、ビル管理会社2社 |

### 売上の構成【Example】

| 立場 | 割合 | 内容 |
|---|---|---|
| **1次下請として** | 約70% | 中堅・地場ゼネコンからの新築・大規模改修工事の内装工事 |
| **元請（直請け）として** | 約30% | オフィス移転に伴う内装工事、ビル管理会社経由の小規模改修、店舗内装 |

| 工事の性格 | 割合 | 内容 |
|---|---|---|
| 新築工事 | 約40% | ゼネコンの新築現場の内装工事 |
| 改修・原状回復 | 約60% | テナント入退去、オフィスリニューアル、小規模修繕 |

> **【Typical】この構成にした理由**
> 中小の専門工事会社では、**「下請中心だが直請けもある」という混在型**が一般的です【Varies】。
> 下請だけだと元請の発注量に売上が左右され、直請けだけだと工事量が安定しないためです【Inference】。
> また、新築より改修・小規模工事の件数が多いことも、中小専門工事会社では一般的です【Varies】。

### 原価の大まかな構成【Example】

> ⚠️ **説明用の架空値**です。実際の比率は工種・工事内容・支給材の有無で大きく変動します【Varies】。

| 費目 | 割合の目安 | 中身 |
|---|---|---|
| **材料費** | 約25% | ボード、軽量鉄骨（LGS）、クロス、床材、接合金物、副資材 |
| **外注費**（労務外注） | 約40% | 協力会社・一人親方への発注 |
| **労務費**（自社職人） | 約10% | 自社技能者の人件費 |
| **現場経費** | 約10% | 運搬費、仮設材リース、廃材処分費、駐車場代、現場代理人の人件費の一部 |
| **工事原価 計** | 約85% | |
| **工事総利益（粗利）** | **約15%** | |
| 販売費及び一般管理費 | 約11% | 役員報酬、内勤者人件費、事務所家賃、車両費、保険料 |
| 営業利益 | 約4% | |

> 詳細は `08_money.md` `12_business-model.md` で扱います。ここでは**「外注費が最大の費目になる」**という
> 専門工事業の構造だけ押さえてください。これは `01_overview.md` 1-7 で見た
> 「工種ごとに専門会社に分ける」構造の裏返しです【Inference】。

## 3-3 組織を「部署」ではなく「機能」で整理する理由

### 中小建設会社の実態

【Typical】従業員30名規模の建設会社に、
「営業部」「積算部」「工事部」「安全管理部」「調達部」が独立して存在することはほとんどありません。
しかし、**それぞれの仕事（機能）は必ず存在します**。誰かが必ずやっています。

そこで本資料では、`common/methodology.md` §1 の方針に従い、

> **「この機能は必ず存在するが、独立した○○部が存在するとは限らない」**

という視点で整理します。

### モデル企業の8つの機能

```
┌─────────────────────────────────────────────────────┐
│  ①営業機能        仕事を取ってくる                    │
│  ②積算・見積機能   いくらでできるかを計算する          │
│  ③工事管理機能     現場を回す（施工管理）★中核        │
│  ④現場作業機能     実際に造る                          │
│  ⑤安全・品質管理機能 事故を起こさない・不良を出さない  │
│  ⑥資材調達・外注管理機能 モノと人を手配する            │
│  ⑦経理・財務機能   お金を管理する                      │
│  ⑧人事・総務機能   人と会社の手続を管理する            │
└─────────────────────────────────────────────────────┘
```

## 3-4 各機能の定義と人員配置【Example】

### ① 営業機能

| 項目 | 内容 |
|---|---|
| **一般的な部署名** | 営業部、営業課、業務部、社長直轄【Varies】 |
| **何のために存在するか** | 工事の引合い（見積依頼）を継続的に得るため。建設業は受注生産なので、引合いが途切れると仕事そのものが無くなる |
| **モデル企業の人員** | 2名（＋代表取締役が実質的に最大の営業担当） |
| **主な相手** | 元請ゼネコンの工事部・購買部、設計事務所、ビル管理会社、既存の発注者 |
| **建設業固有の特徴** | 「新規開拓」より**「既存の元請との関係維持」が中心**になることが多い【Typical】。元請の発注担当者から見積依頼が来ることが引合いの主要ルート |

> **【Typical】建設業の営業の実態**
> 下請中心の会社では、営業の中身は「売り込み」よりも
> **①見積依頼に確実に応じること、②現場で問題を起こさないこと、③無理な依頼に応えたこと**
> の積み重ねで次の依頼が来る、という形になりやすいです。
> そのため**現場代理人が実質的な営業機能を担う**ことが非常に多くなります【Typical】。

### ② 積算・見積機能

| 項目 | 内容 |
|---|---|
| **一般的な部署名** | 積算部、見積課、工務、営業部内の担当【Varies】 |
| **何のために存在するか** | 建設業は1件ごとに価格が違うため、**図面から数量を拾い、単価を掛けて金額を出す**作業が必ず必要になる。ここを誤ると、受注しても赤字になる |
| **モデル企業の人員** | 2名（繁忙期は工事管理機能の担当者も拾いを分担する）【Example】 |
| **主なアウトプット** | 数量拾い表、見積書、内訳書、実行予算書（受注後） |
| **建設業固有の特徴** | 「**拾い**（ひろい）」＝図面から面積・長さ・本数を数える作業が仕事の中心。図面を読む力が要求される |

> **積算（せきさん）**
> → 図面と仕様書から、必要な材料の数量と手間（人工）を算出し、金額を計算すること。
> → 実務例：平面図から間仕切り壁の総延長を測り、天井高を掛けて面積を出し、
>   ボードの枚数・軽量鉄骨の本数・必要な人工数を算出する。

### ③ 工事管理機能（施工管理）★中核

| 項目 | 内容 |
|---|---|
| **一般的な部署名** | 工事部、施工部、工務部【Varies】 |
| **何のために存在するか** | 決められた工期・品質・予算・安全基準の中で工事を完成させるため。**建設業の中核機能** |
| **モデル企業の人員** | **8名**（現場代理人 兼 主任技術者） |
| **1人あたりの担当** | 同時に2〜4現場を掛け持つ【Varies】 |
| **主なアウトプット** | 施工計画書、工程表、施工図、日報、写真、出来高報告、是正記録 |
| **建設業固有の特徴** | **現場代理人が営業・積算・施工管理・安全書類作成・出来高請求まで兼ねる**のが中小では一般的【Typical】 |

> **現場代理人（げんばだいりにん）**
> → 請負契約上、その工事現場において会社を代表する人のこと。
>   工程・品質・安全・原価の責任を現場で負う。
> → 実務例：元請の現場所長との打合せ、協力会社への指示、材料の発注、
>   出来高の報告、検査の立会いをすべて行う。

> **施工管理（せこうかんり）の4本柱**
> | 管理 | 何を管理するか | 実務例 |
> |---|---|---|
> | **工程管理** | いつ何を終わらせるか | 週間工程表を作り、他業者との取り合いを調整する |
> | **品質管理** | 図面・仕様どおりにできているか | 下地のピッチ、ボードのビス間隔、仕上げの平滑度を確認する |
> | **原価管理** | 実行予算の中に収まっているか | 発注済み金額と出来高を突き合わせ、残予算を確認する |
> | **安全管理** | 事故を起こさないか | 朝礼・KY活動、作業手順の確認、保護具の着用確認 |
>
> この4つを**同時に**回すのが施工管理です【Typical】。

### ④ 現場作業機能

| 項目 | 内容 |
|---|---|
| **一般的な呼び方** | 技能者、職人、作業員、班、職長【Varies】 |
| **何のために存在するか** | 実際に手を動かして工事目的物を造るため |
| **モデル企業の人員** | 自社技能者 **8名**（うち職長資格者3名）＋協力会社12社・一人親方6者 |
| **建設業固有の特徴** | **自社職人と協力会社の職人が同じ現場で混在して作業する**。ただし指揮命令系統は会社ごとに分かれる（→ `02_industry-structure.md` 請負≠派遣） |

> **職長（しょくちょう）**
> → 現場で作業員を直接指揮・監督する人。作業手順の指示、安全の確認、作業の割り振りを行う。
> → 労働安全衛生法に基づき、一定の業種では**職長教育**を受けた者を充てることが義務づけられている【Fact】。
> → 実務例：朝礼後にその日の持ち場と手順を班員に伝え、危険箇所を指差し確認する。

### ⑤ 安全・品質管理機能

| 項目 | 内容 |
|---|---|
| **一般的な部署名** | 安全管理部、品質管理部、安全衛生管理者、管理部【Varies】 |
| **何のために存在するか** | 現場で人身事故を起こさないため／不良施工による手直し・クレームを防ぐため |
| **モデル企業の人員** | **1名（専任）**＋各現場代理人が現場ごとに兼務 |
| **主なアウトプット** | 安全書類（グリーンファイル）、安全パトロール記録、KY記録、災害報告、品質記録 |
| **建設業固有の特徴** | 元請が実施する**安全衛生協議会（災害防止協議会）**への参加、元請の安全パトロールへの対応が下請側の実務になる【Typical】 |

> **【Varies】中小建設会社では、独立した安全管理の専任者を置く会社と、
> 経営者・現場代理人が兼務する会社の両方があります。** 規模が小さいほど兼務が一般的です。

### ⑥ 資材調達・外注管理機能

| 項目 | 内容 |
|---|---|
| **一般的な部署名** | 購買部、資材部、工務、工事部内の担当【Varies】 |
| **何のために存在するか** | 材料と職人を「必要な日に、必要な量だけ」現場に届けるため。建設現場には倉庫がないため、タイミングの管理が仕事の中心になる |
| **モデル企業の人員** | 2名（＋現場代理人が現場ごとの発注を直接行う） |
| **主なアウトプット** | 材料発注書、協力会社への注文書、納期管理表、リース契約 |
| **建設業固有の特徴** | 「モノの調達」と「**ヒトの調達（労務外注）**」を同じ機能が担うことが多い。建設業では外注費が最大の原価費目になるため【Typical】 |

### ⑦ 経理・財務機能

| 項目 | 内容 |
|---|---|
| **一般的な部署名** | 経理部、総務部、管理部【Varies】 |
| **何のために存在するか** | 入金より先に支払が発生する建設業で、資金を切らさないため／工事ごとの損益を把握するため |
| **モデル企業の人員** | 2名 |
| **主なアウトプット** | 請求書、入出金管理、工事別原価、試算表、決算書、資金繰り表 |
| **建設業固有の特徴** | **工事別原価管理**（現場ごとに損益を集計する）が必須。また**未成工事支出金・未成工事受入金**という建設業固有の勘定科目を扱う【Fact】 |

> **未成工事支出金（みせいこうじししゅつきん）**
> → まだ完成していない工事に、すでに使ったお金のこと。製造業でいう「仕掛品」に当たる。
> → 実務例：3月末時点で進行中の現場に投入済みの材料費・外注費は、
>   その期の費用にせず「未成工事支出金」として資産に計上しておく。

> **未成工事受入金（みせいこうじうけいれきん）**
> → まだ完成していない工事について、先に受け取ったお金のこと。前受金。
> → 実務例：着工時に受け取った前払金は、まだ売上ではないので「未成工事受入金」として負債に計上する。

> 詳細は `08_money.md` `12_business-model.md` で扱います。

### ⑧ 人事・総務機能

| 項目 | 内容 |
|---|---|
| **一般的な部署名** | 総務部、管理部、社長室、経理と一体【Varies】 |
| **何のために存在するか** | 人を採用・維持し、会社が事業を継続するための法定手続を欠かさず行うため |
| **モデル企業の人員** | 1名（経理機能と一体運用） |
| **主なアウトプット** | 雇用契約、給与、社会保険手続、資格取得管理、許可の更新・変更届、経審申請、入札参加資格申請 |
| **建設業固有の特徴** | **建設業許可の維持**（5年ごとの更新、毎期の決算変更届）、**経営事項審査**、**入札参加資格**、**CCUS登録**、**建設業退職金共済（建退共）**など、建設業固有の手続が多い【Fact】 |

> **建設業退職金共済（建退共／けんたいきょう）**
> → 建設現場で働く人が、会社を移っても退職金が積み立てられる業界共通の共済制度。
>   事業主が働いた日数分の証紙（または電子申請の掛金）を納める。
> → 実務例：現場に入った日数に応じて掛金を納付し、技能者の手帳に記録する。

## 3-5 【必須】配置技術者 ― 建設業法上の必置ポジション

ここは他産業にはない、建設業だけの重要な仕組みです。

### 何が義務づけられているか【Fact】

> **建設業者は、請け負った建設工事を施工するときは、
> 工事現場における建設工事の施工の技術上の管理をつかさどる者として、
> 「主任技術者」または「監理技術者」を置かなければなりません。**
> （建設業法第26条／出典：国土交通省）

これを **配置技術者** と呼びます。**現場に人を配置する法律上の義務**です。

### 主任技術者と監理技術者の違い【Fact】

| | **主任技術者** | **監理技術者** |
|---|---|---|
| **誰が置くか** | すべての建設業者（元請・下請を問わず） | **元請の特定建設業者** |
| **いつ必要か** | 建設工事を施工するとき（原則すべての現場） | 元請として、下請契約の総額が**5,000万円以上**（建築一式工事は**8,000万円以上**）になる場合 |
| **資格要件** | 一般建設業の営業所技術者等と同等の要件（国家資格または実務経験） | 一般に1級施工管理技士等の国家資格者。**監理技術者資格者証**と**監理技術者講習修了証**が必要 |
| **モデル企業の場合** | **これに該当**（下請または小規模な元請のため） | 該当しない（特定建設業許可を持たないため） |

> **【Fact】金額基準は2025年（令和7年）2月1日に4,500万円／7,000万円から
> 5,000万円／8,000万円へ引き上げられました**（出典：国土交通省報道発表資料）。

### 「専任」という追加ルール【Fact】

| 項目 | 内容 |
|---|---|
| **どんな工事か** | 公共性のある施設・工作物、または多数の者が利用する施設・工作物に関する**重要な建設工事** |
| **金額基準** | 工事1件の請負代金が **4,500万円以上（建築一式工事は9,000万円以上）**【Fact】（2025年2月1日改正後。改正前は4,000万円／8,000万円） |
| **専任とは** | **他の工事現場の職務を兼務せず、常時継続的にその現場の職務にのみ従事すること**【Fact】 |
| **雇用関係の要件** | 主任技術者・監理技術者は、工事を請け負った会社と**直接的かつ恒常的な雇用関係**にあることが必要【Fact】 |

> **なぜ「直接的かつ恒常的な雇用関係」が要るのか**
> 技術者を工事のたびに外部から借りてくることを認めると、
> 「許可は持っているが施工能力のない会社」が名義だけで工事を請けられてしまいます。
> 配置技術者の要件は、**許可を持つ会社が実際に施工能力を持っていることを担保する仕組み**です【Inference】。

### 専任義務の合理化【Fact】

2024年（令和6年）改正建設業法により、**情報通信機器を活用する等の一定の要件を満たす工事について、
現場技術者の兼任を可能とする制度**が設けられています（出典：国土交通省）。
また、監理技術者については、**監理技術者補佐**を専任で配置することで
監理技術者が複数現場を管理できる特例（特例監理技術者）があります【Fact】。

> 制度は改正が続いているため、**実務では必ずその時点の国土交通省
> 「監理技術者制度運用マニュアル」等の公式情報で確認**が必要です。

### モデル企業における配置技術者【Example】

【Example】モデル企業では、工事管理機能の8名がそれぞれ主任技術者の資格要件を満たしており、
**現場代理人＝主任技術者**として現場に配置されます。

| 工事の規模 | 配置 |
|---|---|
| 請負金額4,500万円未満の工事 | 主任技術者は専任不要 → **1人が2〜4現場を掛け持つ**【Typical】 |
| 請負金額4,500万円以上の工事 | 主任技術者を**専任**で配置 → その技術者は他現場を持てない |

> **【Inference】これが経営に直結する理由**
> 有資格者の人数が、**同時に請けられる工事の数の上限**を事実上決めます。
> とくに専任が必要な規模の工事を受注すると、その技術者は1現場に固定されます。
> `01_overview.md` 1-7 で述べた「有資格者が何人いるかは経営そのもの」とは、この意味です。

### 現場代理人と主任技術者は別概念【重要】

初心者が最も混同する点です。

| | **現場代理人** | **主任技術者・監理技術者** |
|---|---|---|
| **根拠** | **請負契約**（契約上の取り決め） | **建設業法第26条**（法律上の義務） |
| **役割** | その現場で会社を代表し、契約に関する事項を処理する | 施工の**技術上の管理**をつかさどる |
| **資格** | 資格要件は法定されていない【Typical】 | 法定の資格要件がある【Fact】 |
| **兼務** | 中小では**同一人が両方を兼ねることが一般的**【Typical】 | 同左 |

> つまり「現場代理人 兼 主任技術者」という表記は、
> **契約上の代表者としての顔と、法律上の技術管理者としての顔を、同じ人が持っている**という意味です。

### 機能どうしの主な受け渡し（インプット／アウトプット）

| 渡す側 | 渡すもの | 受け取る側 | なぜ必要か |
|---|---|---|---|
| ① 営業 | 見積依頼書・図面・現地情報 | ② 積算・見積 | 金額を出すには図面と現地条件が要る |

| ① 営業 | 受注情報（契約金額・工期・条件） | ③ 工事管理 | 現場を組み立てる前提になる |
| ② 積算・見積 | **実行予算書** | ③ 工事管理 | 現場が使ってよい原価の上限を示す |
| ③ 工事管理 | 材料の発注依頼・外注の依頼 | ⑥ 資材調達・外注管理 | モノとヒトを手配するため |
| ⑥ 資材調達・外注管理 | 発注金額・納期情報 | ③ 工事管理／⑦ 経理財務 | 工程の確定と原価の把握のため |
| ③ 工事管理 | 作業指示・工程 | ④ 現場作業 | 何をいつやるかを伝えるため |
| ④ 現場作業 | 日報・出来高・不具合情報 | ③ 工事管理 | 進捗と原価を把握するため |
| ⑤ 安全・品質管理 | 安全書類・指摘事項・検査記録 | ③ 工事管理 | 現場の是正と、元請への提出のため |
| ③ 工事管理 | 出来高報告・完成報告 | ⑦ 経理・財務 | 請求の根拠になる |
| ⑦ 経理・財務 | 工事別原価の実績 | ② 積算・見積／③ 工事管理 | 次回の見積精度と、現場の残予算把握のため |

> **【Typical】中小建設会社で最も詰まりやすい接点**
> ②積算 → ③工事管理 の **実行予算の受け渡し**と、
> ③工事管理 → ⑦経理財務 の **出来高情報の受け渡し**です。
> 前者が曖昧だと現場は「いくらまで使ってよいか」が分からず、
> 後者が遅れると請求が出せず入金が遅れます【Inference】。
