# CHAPTER 10｜帳票・書類（何を作り、何のために使うのか）

> 本ファイルは `03_company-structure.md` のモデル企業（株式会社サンエイ内装／内装仕上工事・従業員28名）が
> 実際に扱う書類を、**「誰が作る／誰が使う／いつ作る／何が書いてある／何のためか／無いと何が困るか」**で整理します。
> ステップ名（S1〜S21）は `04_end-to-end-process.md` の定義を使います。
> 機能の呼称（①〜⑧）は `03_company-structure.md` 3-8 の定義を使います。
> 出典の詳細は `19_sources.md` を参照してください。

---

## 10-1 建設業はなぜ書類が多いのか

初心者が建設業を見て最初に驚くのが、書類の多さです。理由は4つあります。

| 理由 | 説明 |
|---|---|
| **① 法令で提出・作成・保存が義務づけられている** | 建設業法、労働安全衛生法、廃棄物処理法、建設リサイクル法など【Fact】 |
| **② 複数の会社が1つの現場で働く** | 「誰がどの資格で現場にいるか」を書面で把握しないと、安全管理も事故対応もできない（→ `06_people.md`） |
| **③ 完成すると見えなくなる部分が大量にある** | 写真と記録でしか品質を証明できない（→ `09_information.md` 9-7） |
| **④ 1件ごとに条件が違い、口頭では範囲が確定しない** | 「どこまでが契約範囲か」を書面で定めないと、後から争いになる |

> **【重要】書類の目的は3つに分けられる**
> ```
>   A. 契約・金銭のための書類   ← 何をいくらでやるかを確定する
>   B. 施工管理のための書類     ← どう作るかを決め、記録する
>   C. 法令遵守のための書類     ← 法律が作成・提出・保存を求めている
> ```
> **同じ書類が複数の目的を兼ねることもあります**（例：工事写真は B でもあり C でもある）。

> **媒体（紙・Excel・システム・クラウド等）は企業により大きく異なります【Varies】。**
> 本資料では媒体を決めつけません。

## 10-3 受注前の帳票

### 引合い台帳

| 項目 | 内容 |
|---|---|
| **誰が作る** | ①営業機能 |
| **誰が使う** | 代表取締役、②積算・見積機能、③工事管理機能 |
| **いつ作る** | **案件発生時**（引合いを受けた都度） |
| **何が書いてある** | 案件番号、発注者／元請名、工事名、工事場所、見積提出期限、担当者、進捗状況（見積中／提出済／受注／失注） |
| **何のためか** | 同時並行で走る複数の引合いを一覧で管理するため |
| **これが無いと何が困るか** | **見積提出期限を逃して失注する**。どの案件がどの段階か分からなくなる【Typical】 |

### 現地調査報告書／現場写真

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能（現場代理人）、②積算・見積機能 |
| **誰が使う** | ②積算（見積の根拠）、③工事管理（施工計画の前提）、①営業（価格折衝の根拠） |
| **いつ作る** | **案件発生時**（現地調査の当日） |
| **何が書いてある** | 既存の状態、搬入経路、置き場の有無、作業可能時間、電源・水、近隣条件、廃材搬出経路、駐車条件、実測寸法、現場写真 |
| **何のためか** | **図面に描かれていない原価要因を記録するため** |
| **これが無いと何が困るか** | 受注後に発覚した条件がそのまま赤字になる。価格折衝で「図面と現況が違う」根拠を示せない【Typical】 |

### 数量拾い表

| 項目 | 内容 |
|---|---|
| **誰が作る** | ②積算・見積機能 |
| **誰が使う** | ②積算（見積書の作成）、③工事管理（実行予算）、⑥資材調達（発注数量）、③工事管理（出来高の分母） |
| **いつ作る** | **案件発生時**（現調の後） |
| **何が書いてある** | 工種別の数量（面積・長さ・本数）、必要人工数、運搬回数、廃材量 |
| **何のためか** | 金額を出すため。**建設業は1件ごとに価格を計算するため、この作業が必ず要る** |
| **これが無いと何が困るか** | 金額の根拠がなくなる。発注数量も決まらない。出来高の算定基準もなくなる |

### ★見積書・見積内訳書・見積条件書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ②積算・見積機能（**承認は代表取締役**） |
| **誰が使う** | 元請の購買部・工事部／発注者（他社と比較し査定する）、自社（実行予算の出発点） |
| **いつ作る** | **案件発生時** |
| **何が書いてある** | ・**見積書**：工事名、工事場所、工期、見積金額、消費税、**見積有効期限**<br>・**見積内訳書**：工種・数量・単位・単価・金額、諸経費（現場管理費・一般管理費）、**法定福利費**<br>・**見積条件書**：見積に含む範囲／含まない範囲、前提条件（作業時間、支給材の有無、残材処分の負担 等） |
| **何のためか** | 自社がこの工事をいくらで請けるかを示すため。**同時に契約の範囲を定めるため** |
| **これが無いと何が困るか** | 範囲の認識違いによるトラブル（建設業で最も多い）。着工後に「入っているはずだ」「入っていない」の争いになる【Typical】 |

> **【Fact】見積期間には法定の下限があります。**
> 注文者は、受注予定者が見積りを行うために必要な期間を設けなければならず、
> 工事1件の予定価格が **500万円未満は1日以上／500万円以上5,000万円未満は10日以上／
> 5,000万円以上は15日以上**と定められています（建設業法第20条、同施行令第6条／出典：国土交通省）。

> **【Fact】2025年（令和7年）12月12日に完全施行された改正建設業法**により、
> **建設工事の見積書に記載すべき事項、および入札金額の内訳書に記載すべき事項が明確化**されました。
> また、**著しく低い労務費等による見積り・契約が禁止**されています
> （出典：国土交通省報道発表資料）。

> **【Typical】法定福利費の明示**
> 建設業では、下請が提出する見積書に**法定福利費を内訳として明示する**取扱いが推進されてきました。
> **なぜか**：法定福利費が請負金額に含まれていることが分からないと、
> 価格交渉で削られ、結果として社会保険料を払えなくなるためです【Inference】。

## 10-4 契約の帳票

### ★注文書・注文請書

| 項目 | 内容 |
|---|---|
| **誰が作る** | **注文書＝注文する側（元請）／注文請書＝受ける側（自社）** |
| **誰が使う** | 全機能。請求の根拠、工期の根拠、実行予算の前提 |
| **いつ作る** | **受注時** |
| **何が書いてある** | 工事名、工事場所、**請負代金の額**、**工期（着手・完成の時期）**、支払条件（締日・支払日・手形の有無）、契約の範囲、設計変更時の取扱い、不可抗力時の取扱い、契約不適合責任 |
| **何のためか** | 契約を成立させ、その内容を書面に残すため |
| **これが無いと何が困るか** | **法令違反になり得る**【Fact】。金額・工期・範囲の根拠がなくなり、請求できない |

> **【Fact】建設業法第19条の書面交付義務**
> 請負契約の当事者は、次の事項を書面に記載し、**署名または記名押印して相互に交付**しなければなりません
> （出典：国土交通省）。

```
・工事内容
・請負代金の額
・工事着手の時期、工事完成の時期
・前金払・出来高部分払の定めをするときは、その支払の時期・方法
・設計変更、工事着手の延期、工事の全部または一部の中止の場合における
  工期の変更、請負代金の額の変更、損害の負担、それらの額の算定方法
・天災その他不可抗力による工期の変更、損害の負担、その算定方法
  （このほか、価格変動時の取扱い、検査・引渡しの時期、代金の支払時期・方法、
    契約不適合責任、契約に関する紛争の解決方法 等）
```

> **注意**：**注文書・注文請書による方式でも、これらの事項を満たす必要があります**【Fact】。
> 「電話で頼まれて着工し、後から書面が来る」という進み方は、書面交付義務の観点から問題となり得ます。

> **【Fact】電子契約**：国土交通省は
> 「電磁的措置による建設工事の請負契約の締結に係るガイドライン」（最終改正 2025年9月30日）を示しており、
> 一定の要件を満たす電子的方法による契約締結が認められています。

### 工事請負契約書（直請けの場合）

| 項目 | 内容 |
|---|---|
| **誰が作る** | 自社（元請の立場）または発注者 |
| **誰が使う** | 全機能、発注者 |
| **いつ作る** | **受注時** |
| **何が書いてある** | 上記の法定記載事項＋**約款**（契約の詳細なルール） |
| **何のためか** | 同上。民間工事では約款付きの契約書を交わすことが多い【Varies】 |

> **【Fact】標準的な約款**：中央建設業審議会は
> **公共工事標準請負契約約款／民間建設工事標準請負契約約款（甲）（乙）／建設工事標準下請契約約款**を
> 作成し、その実施を勧告しています（出典：国土交通省）。
> 実務では、これらをベースにした約款や、元請独自の約款が使われます【Varies】。

### 工事台帳

| 項目 | 内容 |
|---|---|
| **誰が作る** | ⑦経理・財務機能 |
| **誰が使う** | 全機能 |
| **いつ作る** | **受注時**（工事番号を採番する） |
| **何が書いてある** | 工事番号、工事名、発注者／元請、請負金額、工期、担当者、契約情報 |
| **何のためか** | **工事別原価管理の起点**。すべての支出にこの工事番号を付ける（→ `08_money.md` 8-8） |
| **これが無いと何が困るか** | どの支出がどの現場のものか分からず、**工事別の損益が出せない** |

## 10-5 着工準備の帳票

### ★実行予算書【社内限り】

| 項目 | 内容 |
|---|---|
| **誰が作る** | ②積算・見積機能＋③工事管理機能（**承認は代表取締役**） |
| **誰が使う** | ③工事管理（原価管理の基準）、⑥資材調達（発注の上限）、⑦経理・財務（実績との対比） |
| **いつ作る** | **受注時**（契約金額が確定した直後） |
| **何が書いてある** | 費目別の予算（**材料費・労務費・外注費・現場経費**）、目標粗利、想定人工数 |
| **何のためか** | **現場が使ってよい原価の上限を決めるため** |
| **これが無いと何が困るか** | 現場が「いくらまで使ってよいか」を判断できない。**原価の超過に気づくのが工事完了後になる**【Inference】 |

> **【最重要】社外に出さない書類**
> 実行予算書には**自社の原価構造と利益率**が書かれています。
> 見積内訳書（社外に出す）とは別物です（→ `09_information.md` 9-8）。

### ★施工計画書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能（現場代理人 兼 主任技術者） |
| **誰が使う** | **元請・工事監理者（承認する）**、④現場作業（施工の指示書）、⑤安全品質（検査の基準） |
| **いつ作る** | **受注時**（着工前） |
| **何が書いてある** | 工事概要、**使用材料のメーカー・品番**、施工手順、工法、**品質管理の方法**、作業員の体制、安全対策、**配置技術者** |
| **何のためか** | 着工前に「どう作るか」を元請・監理者と合意しておくため |
| **これが無いと何が困るか** | 着工後に「その材料は認めていない」「その工法では不可」となり、**すべてやり直しになる**【Typical】 |

### 工程表

| 項目 | 内容 |
|---|---|
| **誰が作る** | **元請**（全体工程表）／自社（自社工種の詳細工程） |
| **誰が使う** | ③工事管理（進捗管理）、④現場作業（段取り）、⑥資材調達（搬入日・労務手配日） |
| **いつ作る** | **受注時**。見直しは**週次**【Typical】 |
| **何が書いてある** | 横軸に日付、縦軸に作業項目。各作業の開始日・終了日をバーで表す（バーチャート工程表） |
| **何のためか** | いつ何を終わらせるかを共有するため。**材料と職人の手配日を決める基準** |
| **これが無いと何が困るか** | 材料と職人の手配タイミングが決まらない。他業者との取り合いを調整できない |

> **【Typical】下請は工程を自分では決められない**
> 元請の全体工程表の中に、自社の作業期間が割り当てられます（→ `09_information.md` 9-3 ⑨）。

### 施工図

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能（外部の施工図業者に委託する場合もある）【Varies】 |
| **誰が使う** | **元請・工事監理者（承認する）**、④現場作業（これを見て施工する）、⑥資材調達（発注の根拠） |
| **いつ作る** | **受注時**（着工前）。変更のつど改訂 |
| **何が書いてある** | 下地の割付、開口部の補強、他業者の配管・配線との取り合い、詳細な寸法・納まり |
| **何のためか** | 設計図のままでは現場で「ここはどう納めるのか」が決まらないため |
| **これが無いと何が困るか** | 現場で判断がつかず作業が止まる。他業者との取り合いが決まらず、後から手戻りになる |

### 配置技術者の届出

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能、⑧人事・総務機能（資格の確認） |
| **誰が使う** | **元請**（施工体制台帳への記載）、発注者 |
| **いつ作る** | **受注時**（着工前） |
| **何が書いてある** | 主任技術者（または監理技術者）の氏名、資格、専任の有無、雇用関係 |
| **何のためか** | **建設業法第26条の配置義務を満たしていることを示すため**【Fact】 |
| **これが無いと何が困るか** | 法令上の義務を果たしていないことになる。元請の施工体制台帳が作れない |

> **【Fact】配置技術者の専任義務**
> 公共性のある施設・工作物、または多数の者が利用する施設・工作物に関する重要な建設工事で、
> 工事1件の請負代金が **4,500万円以上（建築一式工事は9,000万円以上）** の場合、
> 主任技術者・監理技術者は**専任**でなければなりません
> （2025年〈令和7年〉2月1日改正後の金額／出典：国土交通省。→ `03_company-structure.md` 3-5）。

## 10-6 【最重要】グリーンファイル（安全書類）

### まず全体像

> **グリーンファイル（安全書類／労務安全書類）**
> → 現場に入る**会社と作業員の情報、保険加入状況、資格、作業計画**などをまとめた書類一式のこと。
>   ファイルの表紙が緑色だったことから、業界でこう呼ばれている【Typical】。
> → 実務例：新しい現場に入る前に、元請から「グリーンファイルを○日までに出してください」と求められる。

> **【重要】なぜこれだけの書類が必要なのか**
> 建設現場では**複数の会社の作業員が同時に働きます**（→ `06_people.md` 6-1）。
> 事故が起きたとき「誰の会社の、誰が、どの資格で、何の作業をしていたか」が分からないと、
> **救護も原因究明も責任の所在の確定もできません**。
> グリーンファイルは、**現場にいる全員を事前に把握しておくための仕組み**です【Inference】。

### 主な書類【Typical】

| 書類名 | 誰が作る | 誰が使う | いつ | 何が書いてある | 何のためか／無いと何が困るか |
|---|---|---|---|---|---|
| **再下請負通知書** | 自社（1次下請） | **元請**（施工体制台帳の作成） | 受注時（着工前）、再下請の変更時 | 自社がどの会社に再下請けさせるか、その会社の許可番号・施工範囲・配置技術者 | **建設業法第24条の8の施工体制台帳の記載事項**【Fact】。無いと元請が台帳を作れない |
| **作業員名簿** | 自社／各協力会社 | 元請、現場の管理者 | 受注時（着工前）、**作業員が変わるたび** | 氏名、生年月日、**保有資格**、**社会保険（健康保険・厚生年金・雇用保険）の加入状況**、雇用形態、血液型、緊急連絡先 | 誰が現場にいるかを把握するため。**労災時の対応に使う**。無いと**その作業員は現場に入場できない**【Typical】 |
| **工事安全衛生計画書** | 自社 | 元請、自社の職長 | 受注時（着工前） | その工事で想定される危険と対策、安全管理の体制 | 労働安全衛生法に基づく安全管理のため |
| **持込機械等使用届** | 自社／協力会社 | 元請 | 持ち込む前 | 現場に持ち込む機械・工具（高所作業車、電動工具等）の種類、点検状況、**操作する有資格者** | **整備不良の機械・無資格者の操作を防ぐため**。無いと機械を持ち込めない |
| **有資格者名簿／資格証の写し** | 自社／協力会社 | 元請 | 受注時（着工前） | 玉掛け、高所作業車、足場の組立て等作業主任者、職長教育 等の資格 | **資格が必要な作業に無資格者を就かせないため**【Fact】 |
| **作業主任者選任届** | 自社／協力会社 | 元請、現場 | 該当作業の前 | 誰をどの作業の作業主任者に選任したか | **労働安全衛生法第14条の選任義務**【Fact】（→ `06_people.md` 6-3） |
| **健康保険・厚生年金・雇用保険の加入状況** | 自社／協力会社 | 元請 | 受注時（着工前） | 会社ごと・作業員ごとの加入状況 | **社会保険未加入対策として元請が確認する**【Typical】。経審のW評点にも関わる【Fact】 |
| **建設業許可証の写し** | 自社／協力会社 | 元請 | 受注時（着工前） | 許可番号、許可業種、有効期間 | **許可のない会社に500万円以上（建築一式は1,500万円以上）の工事を出していないか**の確認【Fact】 |
| **新規入場者調査票／教育記録** | 自社 | 元請、現場 | **その人が初めて現場に入る日** | 本人の経験、健康状態、受けた教育の内容 | 現場のルール・危険箇所を知らないまま作業させないため |
| **一人親方の特別加入の証明** | 一人親方本人 | 元請、自社 | 受注時（着工前） | 労災保険の特別加入の状況 | **一人親方は労働者ではないため元請の労災でカバーされない**【Fact】（→ `06_people.md` 6-5） |

### ★施工体制台帳・施工体系図【元請が作る】

| 項目 | 内容 |
|---|---|
| **誰が作る** | **元請**（発注者から直接請け負った特定建設業者） |
| **誰が使う** | 元請、発注者、行政（立入検査時）、現場の全員（体系図は掲示される） |
| **いつ作る** | 着工前。下請が変わるたびに更新 |
| **何が書いてある** | ・**施工体制台帳**：その工事に関わる**すべての下請会社**の名称、建設業許可番号、施工範囲、**配置技術者**、社会保険加入状況、契約日<br>・**施工体系図**：元請から下請への流れが分かる**樹形図**。**現場に掲示する** |
| **何のためか** | **工事全体の施工体制を明らかにするため**。一括下請負の防止、無許可業者の排除、安全管理の基礎 |
| **これが無いと何が困るか** | **法令違反**【Fact】。誰が施工しているか分からない状態になる |

> **【Fact】作成義務の基準**
> 発注者から直接建設工事を請け負った特定建設業者は、その工事について締結した
> **下請契約の総額が5,000万円以上（建築一式工事は8,000万円以上）**になる場合、
> 施工体制台帳を作成し、**施工体系図**を作成して**工事現場の見やすい場所に掲げなければなりません**
> （建設業法第24条の8。金額は2025年2月1日改正後／出典：国土交通省）。

> **モデル企業（下請）の立場では**：
> 台帳を作るのは元請ですが、**その材料となる情報（自社と再下請の情報）を提供する義務**があります。
> それが**再下請負通知書**です【Fact】。

### 各種届出【Typical】

| 届出 | 誰が作る | 提出先 | いつ | 何のためか |
|---|---|---|---|---|
| **道路使用許可申請** | 実際に作業する会社（元請または下請）【Varies】 | 警察署 | 道路上に車両を停めて作業する前。**法定・契約上のタイミング** | 道路交通の安全のため |
| **道路占用許可申請** | 元請または道路占用者 | 道路管理者 | 道路に足場等を設置する前 | 同上 |
| **ビル管理者への工事申請** | 実際に作業する会社【Varies】 | ビル管理会社 | テナント工事の前 | 館内規則の遵守、搬入時間・エレベーターの調整 |
| **消防への届出** | 元請・設計者 | 消防署 | 内装制限・防火対象物の用途変更等がある場合 | 消防法に基づく |
| **建築確認・中間検査・完了検査の申請** | 建築主（発注者）・設計者 | 指定確認検査機関・特定行政庁 | 建築基準法上必要な場合【Fact】 | 建築基準法への適合確認 |
| **特定建設作業の実施届出** | 施工者 | 市区町村 | 騒音規制法・振動規制法の対象作業を行う場合【Fact】 | 騒音・振動の規制 |
| **建設リサイクル法の届出** | **発注者または自主施工者** | 都道府県知事等 | 対象建設工事に**着手する7日前まで**【Fact】 | 分別解体・再資源化の実施確保 |
| **石綿の事前調査結果の報告** | 元請 | 労働基準監督署等 | 一定規模以上の工事【Fact】 | 石綿ばく露の防止 |

> **【Typical】下請の場合**：多くの届出は元請が行いますが、
> **道路使用許可やビル管理会社への搬入申請は、実際に作業する下請が行うこともあります**【Varies】。
> **誰が出すのかは着工前に必ず確認します。**

### 協力会社への注文書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ⑥資材調達・外注管理機能、③工事管理機能（**自社が「注文者」になる**） |
| **誰が使う** | 協力会社・一人親方、⑦経理・財務（支払の根拠） |
| **いつ作る** | **発注時** |
| **何が書いてある** | 工事名、**施工範囲**、請負金額（または人工単価×人数×日数）、工期、支払条件、変更時の取扱い |

| **これが無いと何が困るか** | **建設業法第19条の書面交付義務違反になり得る**【Fact】。範囲と金額の争いになる |

> **【Fact】協力会社へ発注するときに確認が必要なこと**
> - **建設業許可**：500万円以上（建築一式は1,500万円以上）の工事を許可のない業者に発注できない
> - **書面での契約**：建設業法第19条の書面交付義務は、**下請への発注にも適用される**
> - **見積期間**：建設業法第20条・同施行令第6条の見積期間を確保する
> - **一括下請負にならないこと**：建設業法第22条
> - **支払期日**：建設業法第24条の3（→ `08_money.md` 8-10）

| **いつ作る** | **日次**（施工した日ごと） |
| **何が書いてある** | 日付、天候、**工事番号**、作業内容、**作業した会社と人数（人工）**、進捗した数量、使用機械、特記事項（手待ち・手戻り・トラブル） |

>            ──▶ 出来高の根拠（請求）
>            ──▶ 実績歩掛の更新（次回見積）
> ```

| **これが無いと何が困るか** | ・隠蔽部の施工が正しいことを証明できない<br>・追加工事の根拠を示せない<br>・**公共工事では契約上の提出物**のため、引渡しができない【Typical】 |

### KY記録・新規入場者教育の記録

| 項目 | 内容 |
|---|---|
| **誰が作る** | ④現場作業機能（職長）、③工事管理機能 |
| **誰が使う** | 元請、自社の⑤安全品質、労働基準監督署（事故時）【Fact】 |
| **いつ作る** | KYは**日次**。新規入場者教育は**その人が初めて現場に入る日** |
| **何が書いてある** | ・KY記録：その日の作業に潜む危険、対策、参加者<br>・新規入場者教育：現場のルール、危険箇所、緊急時の連絡、避難経路、教育の実施記録 |
| **何のためか** | 作業に入る前に危険を共有するため |
| **これが無いと何が困るか** | 安全管理を行った記録が残らない。**事故発生時に、何をしていたかを説明できない** |

### 打合せ記録

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能（現場代理人） |
| **誰が使う** | 自社、元請、工事監理者。**追加工事の請求根拠** |
| **いつ作る** | 打合せの都度（**案件発生時**） |
| **何が書いてある** | 日時、出席者、決定事項、**誰が何を指示したか**、宿題事項と期限 |
| **何のためか** | 「言った・言わない」を防ぐため。**変更指示の証拠になる** |
| **これが無いと何が困るか** | **口頭で指示された追加工事を請求できない**（→ `04_end-to-end-process.md` S15）【Typical】 |

> 「発注者との打合せ記録（工事内容に関するものであって、当事者間で相互に交付されたものに限る）」は
> 「営業に関する図書」として、引渡しから10年間の保存義務があります**
> （建設業法第40条の3、同施行規則／出典：国土交通省）。

### 産業廃棄物管理票（マニフェスト）

| 項目 | 内容 |
|---|---|
| **誰が作る** | **排出事業者**（建設工事では原則として**元請**）【Fact】 |
| **誰が使う** | 収集運搬業者、処分業者、排出事業者、行政 |
| **いつ作る** | **廃棄物を搬出するたび**（納品時・搬出時） |
| **何が書いてある** | 排出事業者、廃棄物の種類・数量、運搬業者、処分業者、運搬先、処分方法、各段階の日付と署名 |
| **何のためか** | **「誰が出した、どんな廃棄物が、誰によって運ばれ、どこで、どう処理されたか」を追跡するため** |
| **これが無いと何が困るか** | **法令違反**【Fact】。不法投棄の責任を問われうる |

> **【Fact】主なルール**（出典：環境省）
> - 交付した管理票の写しは、**交付した日から5年間**保存しなければならない
> - 排出事業者は、事業場ごとに、**その年の6月30日までに、その年の3月31日以前の1年間に交付した
>   産業廃棄物管理票の交付等の状況を報告**する（産業廃棄物管理票交付等状況報告書）
> - **建設工事に伴い生ずる廃棄物については、原則として元請負人が排出事業者となる**
>   （廃棄物処理法第21条の3）

> **モデル企業（下請）の実務では**【Typical】
> 分別は自社が行い、搬出・処理の委託とマニフェストの交付は元請が行うことが多いです。
> ただし、**下請が自ら処理費を負担し、自社で処理業者に委託する取り決めの場合もあります**【Varies】。
> **どちらの取り決めなのかは、見積段階（S5）で必ず確認します。**

## 10-9 出来高・変更の帳票

### ★出来高報告書・出来高内訳書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能（現場代理人） |
| **誰が使う** | **元請（査定する）**、⑦経理・財務（請求の根拠） |
| **いつ作る** | **月次**（元請・発注者が定めた締日） |
| **何が書いてある** | 締日時点の工種別の施工済み数量、出来高金額、出来高率（%）、前回までの累計、今回分 |
| **何のためか** | 完成前に代金の一部を請求するため（→ `08_money.md` 8-5） |
| **これが無いと何が困るか** | **その月の請求ができない → 入金が1か月遅れる**【Typical】 |

> **【重要】元請が査定する**
> 下請が「70%」と報告しても、元請が「60%」と査定すれば、請求できるのは60%分です【Typical】。
> **だから出来高の根拠（施工済み数量、工事写真、作業日報）を示せる状態にしておくことが重要**です。

### ★変更見積書・変更注文書／変更契約書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ②積算・見積機能、③工事管理機能（変更見積書）／元請（変更注文書） |
| **誰が使う** | 元請・発注者（承認）、⑦経理・財務（請求金額の更新） |
| **いつ作る** | **案件発生時**（変更が生じたとき） |
| **何が書いてある** | 変更の内容、増減する数量と金額、工期への影響、変更後の請負金額 |
| **何のためか** | **契約の内容を正式に変更するため** |
| **これが無いと何が困るか** | **施工したのに請求できない**（建設業で最も多い損失の形の1つ）【Typical】 |

> **【Fact】建設業法第19条第2項**
> 請負契約の内容を変更するときは、**変更の内容を書面に記載し、
> 署名または記名押印して相互に交付しなければなりません**（出典：国土交通省）。
> つまり**変更も書面で行うのが法律上の建て付け**です。

> **【Typical】実務での基本動作**
> 1. 変更の指示は、口頭で受けても**記録（メール・打合せ記録・作業日報）に残す**
> 2. 数量と金額の増減を出し、**変更見積を提出する**
> 3. **承認を得てから施工する**（緊急でやむを得ず先行する場合も、記録は必ず残す）

### 自主検査記録・是正リスト

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能、⑤安全・品質管理機能 |
| **誰が使う** | 自社（是正の管理）、④現場作業（直す） |
| **いつ作る** | **納品時**（自社工事の完了時。工程の区切りごとに中間で行うことも）【Typical】 |
| **何が書いてある** | 検査項目、検査結果、不具合の内容と場所、是正の期限、是正完了の確認 |
| **何のためか** | **自分で見つけて自分で直してから、元請・発注者の検査に出すため** |
| **これが無いと何が困るか** | 元請・施主検査で大量の指摘が出て、**是正に時間がかかり引渡し日に間に合わない**。指摘の多さは次の受注機会に影響する【Typical】 |

### 検査記録・是正完了報告

| 項目 | 内容 |
|---|---|
| **誰が作る** | 元請・工事監理者・発注者（検査記録）／自社（是正完了報告） |
| **誰が使う** | 元請、発注者、自社 |
| **いつ作る** | **納品時** |
| **何が書いてある** | 検査日、検査者、指摘事項とその場所、是正期限、**是正前・是正後の写真** |
| **何のためか** | 指摘が確実に是正されたことを証明するため |
| **これが無いと何が困るか** | 検査に合格したことを示せず、**引渡しができない → 請求できない** |

### ★完成引渡書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能、①営業機能 |
| **誰が使う** | 元請・発注者、⑦経理・財務（請求の根拠） |
| **いつ作る** | **納品時**（検査合格・是正完了後） |
| **何が書いてある** | 工事名、引渡日、引渡しの対象、引き渡す書類の一覧 |
| **何のためか** | **引渡しの事実と日付を確定するため** |
| **これが無いと何が困るか** | **引渡し日が確定しない**。引渡しにより①管理責任の移転②請求権の発生③契約不適合責任の起算 が同時に起こるため、日付が極めて重要（→ `07_goods.md` 7-5） |

### ★竣工図

| 項目 | 内容 |
|---|---|
| **誰が作る** | ③工事管理機能（施工図を基に変更を反映） |
| **誰が使う** | 発注者、ビル管理会社、**将来の改修工事を行う会社** |
| **いつ作る** | **納品時** |
| **何が書いてある** | **実際に施工された状態**を反映した最終版の図面（配管ルートの変更、下地の追加等を反映） |
| **何のためか** | 後から改修・修繕をするとき、実際にどう作られているかが分からないと工事ができないため |
| **これが無いと何が困るか** | 将来の改修時に、壁や天井を開けてみないと中が分からない |

> **【Fact】発注者から直接請け負った場合、「完成図（工事目的物の完成時の状況を表した図）」は
> 「営業に関する図書」として、引渡しから10年間の保存義務があります**
> （建設業法第40条の3、同施行規則／出典：国土交通省）。

### 材料の証明書・保証書

| 項目 | 内容 |
|---|---|
| **誰が作る** | メーカー（証明書）／自社（保証書） |
| **誰が使う** | 元請、発注者、行政（検査時） |
| **いつ作る** | **納品時** |
| **何が書いてある** | ・証明書：不燃材料認定証、ホルムアルデヒド放散等級、防火材料の認定番号 等<br>・保証書：保証の対象範囲、保証期間、免責事項 |
| **何のためか** | **法令で定められた性能の材料を使ったことを証明するため**／引渡し後の責任の範囲を明確にするため |
| **これが無いと何が困るか** | 建築基準法上の検査に通らないことがある。保証の範囲が曖昧になる |

### ★請求書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ⑦経理・財務機能（根拠は③工事管理機能から） |
| **誰が使う** | 元請の経理／発注者、自社（完成工事未収入金の管理） |
| **いつ作る** | **請求時**（出来高請求は**月次**、完成請求は**納品時**） |
| **何が書いてある** | 工事名、工事番号、請求金額、消費税、**前回までの累計と今回分**、振込先、支払期日 |
| **何のためか** | 代金を請求するため |
| **これが無いと何が困るか** | **入金されない**。締日に間に合わないと1か月分入金が遅れる |

> **【Typical】請求できる金額の根拠**
> ```
>   契約金額（注文書・注文請書）
>     ＋ 変更契約（承認済みの追加分）
>     ＋ 出来高情報（査定済み）
>     ＋ 完成引渡しの事実
>   ───────────────────────
>   ＝ 請求できる金額
> ```
> **どれか1つが欠けると請求できません。**

| **何のためか** | 消し込み（請求と入金の照合）のため |
| **これが無いと何が困るか** | **回収漏れに気づかない**【Typical】（→ `08_money.md` 8-16） |

### ★工事別原価表（実行予算対比）

| 項目 | 内容 |
|---|---|

| **いつ作る** | **工事完了時**（月次で途中経過を見る場合もある）【Varies】 |

| **何のためか** | この工事でいくら残ったかを確定し、**次の見積の精度を上げるため** |
| **これが無いと何が困るか** | **何年たっても見積の精度が上がらない**（→ `09_information.md` 9-12）【Inference】 |

| **何のためか** | **支払が先、入金が後**の建設業で、資金を切らさないため |
| **これが無いと何が困るか** | いつ資金が不足するか分からない（→ `08_money.md` 8-12） |

## 10-12 会社として常時必要な帳票（工事単位ではないもの）

### ★建設業許可証・許可票（標識）

| 項目 | 内容 |
|---|---|
| **誰が作る** | 許可行政庁（許可証）／自社（標識） |
| **誰が使う** | 元請（許可の確認）、発注者、公衆 |
| **いつ** | **常時** |
| **何が書いてある** | 商号、代表者名、許可を受けた建設業の種類、許可番号、許可年月日、一般／特定の別、（工事現場の標識には）**主任技術者・監理技術者の氏名、専任の有無、資格名** |
| **何のためか** | **建設業の営業・施工が許可を受けた適法な業者によって行われていることを対外的に明らかにするため** |

> **【Fact】標識の掲示義務**
> 建設業法第40条により、建設業者は、**その店舗および建設工事の現場ごとに、
> 公衆の見やすい場所に標識を掲げなければなりません**（出典：国土交通省）。
> 工事現場に掲げる標識のサイズは**縦25cm以上×横35cm以上**と定められています【Fact】。

### ★帳簿・営業に関する図書

| 項目 | 内容 |
|---|---|
| **誰が作る** | ⑦経理・財務機能、⑧人事・総務機能 |
| **誰が使う** | 自社、行政（立入検査時） |
| **いつ** | **常時**（営業所ごとに備える） |
| **何が書いてある** | 営業所の代表者名、請け負った建設工事の内容（注文者、工事名、工事現場の所在地、契約日、完成年月日、請負代金の額 等）、下請契約の内容、配置技術者 等 |
| **何のためか** | 建設業法に基づく記録義務 |

> **【Fact】保存期間**
> - **帳簿とその添付書類**：**5年間**。ただし**発注者と締結した住宅を新築する建設工事に係るものは10年間**
> - **営業に関する図書**（完成図、発注者との打合せ記録、施工体系図）：
>   **発注者から直接建設工事を請け負った場合**、その目的物の**引渡しから10年間**
>
> （建設業法第40条の3、同施行規則第26条・第28条／出典：国土交通省）

### 決算変更届（事業年度終了届）

| 項目 | 内容 |
|---|---|
| **誰が作る** | ⑧人事・総務機能、⑦経理・財務機能（税理士・行政書士に委託することも多い）【Varies】 |
| **誰が使う** | 許可行政庁、（閲覧制度を通じて）発注者 |
| **いつ作る** | **年次**。**事業年度終了後4か月以内**【Fact】 |
| **何が書いてある** | **工事経歴書**、直前3年の各事業年度における**工事施工金額**、**建設業の財務諸表**（完成工事高、完成工事原価報告書、貸借対照表、損益計算書 等）、使用人数、納税証明書 等 |
| **何のためか** | **建設業許可を維持するため**の法定の届出 |
| **これが無いと何が困るか** | **許可の更新ができない**。行政指導の対象になる【Fact】 |

> **【Fact】建設業法第11条に基づき、建設業許可業者は
> 毎事業年度終了後4か月以内に、決算に関する変更届出書を提出しなければなりません**
> （出典：国土交通省「許可後の手続き」）。

### 経営事項審査の申請書類

## 10-14 【最重要】法令で作成・提出・保存が義務づけられている書類

建設業は**書類の義務が法令で定められている点**が他業界と大きく違います。ここを一覧にします。

| 書類 | 義務の内容 | 根拠法令 | 出典 |
|---|---|---|---|
| **請負契約書（注文書・注文請書を含む）** | 法定記載事項を書面に記載し、署名または記名押印して相互に交付 | **建設業法第19条** | 国土交通省 |
| **変更契約の書面** | 契約内容を変更するときは、変更の内容を書面にして相互に交付 | **建設業法第19条第2項** | 国土交通省 |
| **見積書** | 注文者は見積りに必要な期間を設ける（500万円未満：1日以上／500万円以上5,000万円未満：10日以上／5,000万円以上：15日以上）。記載すべき事項が明確化 | **建設業法第20条**、同施行令第6条／2025年12月完全施行の改正建設業法 | 国土交通省 |
| **施工体制台帳・施工体系図** | 発注者から直接請け負った特定建設業者が、下請契約の総額5,000万円以上（建築一式8,000万円以上）で作成。体系図は現場に掲示 | **建設業法第24条の8** | 国土交通省 |
| **帳簿** | 営業所ごとに備え、**5年間**（住宅新築工事は10年間）保存 | **建設業法第40条の3**、同施行規則第26条・第28条 | 国土交通省 |
| **営業に関する図書**（完成図、発注者との打合せ記録、施工体系図） | 発注者から直接請け負った工事について、引渡しから**10年間**保存 | **建設業法第40条の3**、同施行規則第28条 | 国土交通省 |
| **標識（許可票）** | 店舗および工事現場ごとに、公衆の見やすい場所に掲示 | **建設業法第40条** | 国土交通省 |
| **決算変更届** | 毎事業年度終了後**4か月以内**に提出 | **建設業法第11条** | 国土交通省 |
| **作業主任者の選任** | 一定の危険な作業について、技能講習修了者から選任 | **労働安全衛生法第14条** | 厚生労働省 |
| **職長教育** | 新たに職長等になる者に安全衛生教育を実施 | **労働安全衛生法第60条** | 厚生労働省 |
| **特別教育** | 危険・有害業務に就かせるときに特別教育を実施 | **労働安全衛生法第59条第3項** | 厚生労働省 |
| **統括安全衛生責任者等の選任** | 混在作業の現場で選任 | **労働安全衛生法第15条・第15条の2・第16条** | 厚生労働省 |
| **産業廃棄物管理票（マニフェスト）** | 交付。写しを**交付日から5年間**保存。**6月30日までに交付等状況報告書を提出** | **廃棄物処理法**（建設工事の排出事業者は原則元請＝第21条の3） | 環境省 |
| **建設リサイクル法の届出** | 対象建設工事について、着手の**7日前まで**に発注者等が届出 | **建設リサイクル法** | 国土交通省・環境省 |
| **労働保険の年度更新** | 毎年**6月1日〜7月10日**に申告・納付 | **労働保険徴収法** | 厚生労働省 |

## 10-15 元請と下請で、扱う書類がどう違うか

| 書類 | **下請として**（モデル企業の売上70%） | **元請（直請け）として**（同30%） |
|---|---|---|
| **見積書** | 元請の**指定様式・指定内訳**で提出することが多い【Typical】 | 自社様式。発注者に分かる言葉で説明する必要がある |
| **契約書** | **注文書・注文請書**が多い【Typical】 | 請負契約書（約款付き）が多い【Varies】 |
| **施工計画書** | 自社工種のみ。元請の全体計画に組み込まれる | **工事全体の計画を作る** |
| **工程表** | **元請の全体工程表に従う** | **自社が全体工程を組む** |
| **グリーンファイル** | **元請に提出する側**。協力会社から集めて出す | **自社が集約する側**。下請から集めて台帳を作る |
| **施工体制台帳** | 情報を提供する側（再下請負通知書） | **作成する側**（要件に該当する場合）【Fact】 |
| **各種届出** | 元請が行うことが多い。道路使用・ビル申請は自社のことも【Varies】 | **自社が行う** |
| **マニフェスト** | 分別を行う。交付は元請【Typical】 | **排出事業者として交付する**【Fact】 |
| **出来高報告書** | 元請の締日に合わせ、**査定を受ける** | 自社が発注者に報告する／完成一括払いのことも |
| **請求書** | 元請の締日・支払サイトに従う | 契約で定めた条件に従う |
| **完成引渡書** | 元請に引き渡す | **発注者に直接引き渡す** |
| **営業に関する図書（10年保存）** | 直請け分のみ対象【Fact】 | **対象になる**【Fact】 |
| **標識（許可票）** | 自社の店舗に掲示【Fact】 | 店舗＋**工事現場**に掲示【Fact】 |
