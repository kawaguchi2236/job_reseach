# CHAPTER 16｜用語集＋初心者が間違えやすいこと

> **本章の使い方**
> 前半（16-1〜16-12）は**用語集**です。カテゴリ別に整理しています。
> 後半（16-13）は **「初心者が間違えやすいこと」** です。
> **似ているのに違う言葉**を、「何と何が違うか／なぜ混同するか／実務でどう効くか」まで解説します。
>
> 用語集は「辞書的な定義」で終わらせず、**実務でどう使われるか**を必ず書いています。
> 建設会社の人との会話で詰まりそうな語を優先して収録しました。

## 16-1 立場・関係者に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **発注者** | はっちゅうしゃ | 工事を注文する人・組織。**建物を建てたい／直したい当事者** | 「発注者は〇〇ビル管理会社です」。**公共工事では国・自治体等**。建物の所有者・使用者であることが多い |
| **施主** | せしゅ | 発注者のこと。とくに**建物の持ち主・注文主**を指す言い方 | 「施主検査は来週です」。住宅・建築の分野でよく使われる |
| **元請** | もとうけ／元請負人 | **発注者から直接工事を請け負った会社** | 「この現場の元請は〇〇建設です」。工事全体の責任を負う |
| **下請** | したうけ／下請負人 | **元請（または上位の下請）から工事の一部を請け負った会社** | 「うちは1次下請です」。何次下請かで立場が変わる |
| **1次下請／2次下請** | いちじしたうけ | 元請から直接請け負うのが1次、1次から請け負うのが2次 | 施工体制台帳で何次かが明示される |
| **専門工事会社** | せんもんこうじがいしゃ | 特定の工種（内装、電気、鉄筋など）を専門とする建設会社 | 「内装の専門工事会社です」。**モデル企業サンエイ内装がこれ** |
| **ゼネコン** | General Contractor／総合建設業者 | 工事全体を請け負い、各専門工事会社に発注して統括する会社 | 「中堅ゼネコンからの引合いです」 |
| **サブコン** | Subcontractor | 元請の下で専門工事を担う会社。**設備工事会社を指すことが多い**【Varies】 | 「空調のサブコンと取り合いを調整する」 |
| **協力会社** | きょうりょくがいしゃ | 継続的に取引している下請会社の呼び方 | 「協力会社12社と一人親方6者」。「下請」より対等な響きで使われる【Typical】 |
| **現場代理人** | げんばだいりにん | **請負契約上、その現場において会社を代表する人** | 「現場代理人は〇〇です」。工程・品質・原価・安全の現場責任者 |
| **監督（現場監督）** | げんばかんとく | 現場を管理する人の一般的な呼び方 | 正式な法律用語ではない。**現場代理人・主任技術者・所長の総称的に使われる**【Typical】 |
| **所長（現場所長）** | しょちょう | **元請の現場責任者**の呼び方 | 「元請の所長に確認します」 |
| **主任技術者** | しゅにんぎじゅつしゃ | **建設業法上、現場に配置が義務づけられた技術者**【Fact】 | 元請・下請を問わず、施工するときは必ず配置する |
| **監理技術者** | かんりぎじゅつしゃ | **元請の特定建設業者が、下請総額5,000万円以上（建築一式8,000万円以上）の工事で配置する技術者**【Fact】 | 監理技術者資格者証と講習修了証が必要 |
| **職長** | しょくちょう | **現場で作業員を直接指揮・監督する人** | 「職長に作業範囲を伝える」。職長教育を受けた者を充てる【Fact】 |
| **技能者／職人** | ぎのうしゃ／しょくにん | 実際に手を動かして施工する人 | 「自社技能者8名」 |
| **一人親方** | ひとりおやかた | **労働者を雇わず、自分（および家族）だけで事業を行う事業主** | 「一人親方6者と取引」。**労働者ではなく事業主**。労災は特別加入【Fact】 |
| **常用** | じょうよう | **人日（人工）単位で金額を決める取引の形** | 「明日、常用で2人お願いします」。請負契約の一形態であり派遣ではない |
| **設計者／設計事務所** | せっけいしゃ | 建物を設計する人・会社 | 図面の作成、**工事監理**を担う |
| **監理者** | かんりしゃ | 設計者側の立場で、**設計図書どおりに施工されているか確認する人** | 「監理者の承認を得る」。施工管理とは別（→ 16-13） |
| **許可行政庁** | きょかぎょうせいちょう | 建設業許可を出す役所（都道府県知事または国土交通大臣） | 決算変更届・経審の提出先 |

## 16-2 契約・受注に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **請負** | うけおい | **仕事の完成を約束し、完成した結果に対して報酬が支払われる契約**（民法第632条）【Fact】 | 「請負金額1,800万円」。建設業の契約の基本形 |
| **請負金額** | うけおいきんがく | 工事の対価として契約した金額 | 「請負金額に対して原価がいくら残るか」 |
| **引合い** | ひきあい | **見積の依頼**が来ること | 「先週は引合いが5件ありました」（→ `04` S1） |
| **現調** | げんちょう／現場調査 | 見積前に**現地の条件を確認**すること | 「来週、現調に行きます」。搬入経路、養生の必要性、既存の状況を見る |
| **注文書・注文請書** | ちゅうもんしょ・ちゅうもんうけしょ | 注文する側が出す書面と、受ける側が返す書面 | 【Typical】下請取引では**契約書の代わりに**この2枚で取り交わすことが多い |
| **契約約款** | けいやくやっかん | 契約の詳細な条件を定めた文書 | 「約款は〇〇の標準契約約款による」 |
| **設計変更** | せっけいへんこう | 契約後に、設計の内容が変わること | 「設計変更が入ったので変更見積を出します」 |
| **追加工事** | ついかこうじ | 当初の契約に含まれていなかった工事 | **書面での変更契約がないと、原価だけ増えて損失になる**【Fact】 |
| **変更契約** | へんこうけいやく | 契約内容の変更を書面で取り交わすこと | **建設業法第19条第2項の義務**【Fact】 |
| **工期** | こうき | 着工から完成までの期間 | 「工期は4月1日から6月30日まで」 |
| **着工** | ちゃっこう | 工事を開始すること | 「着工は来週月曜です」。**契約日とは違う** |
| **竣工** | しゅんこう | 工事が完成すること | 「竣工検査」「竣工図」 |
| **引渡し** | ひきわたし | 完成した目的物を発注者（または元請）に引き渡すこと | **完成と引渡しは別の手続**（→ 16-13） |
| **出来高** | できだか | **金額換算した進捗** | 「今月の出来高は60%です」 |
| **出来形** | できがた | **できあがった構造物の形状・寸法** | 「出来形管理」（主に土木）。**出来高とは別の言葉** |
| **相見積** | あいみつもり／あいみつ | 複数社から見積を取って比較すること | 「相見積で3社競合です」 |
| **指値発注** | さしねはっちゅう | 注文者が見積を十分検討せず、**一方的に金額を提示して発注する**こと | **建設業法上問題となり得る行為**としてガイドラインで扱われる【Fact】 |
| **失注** | しっちゅう | 見積を出したが受注できなかったこと | 「金額が合わず失注しました」 |
| **予定価格** | よていかかく | **公共工事で、発注機関があらかじめ定める契約の上限額**【Fact】 | 入札金額がこれを超えると落札できない |
| **最低制限価格** | さいていせいげんかかく | 公共工事で、これを下回ると失格となる価格【Fact】 | ダンピング防止のための制度 |
| **落札** | らくさつ | 入札で受注者に決まること | 「落札率」＝落札金額÷予定価格 |

## 16-3 積算・見積に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **積算** | せきさん | **図面と仕様書から、必要な数量と手間を算出し、金額を計算すること** | 「積算に3日かかります」（→ `04` S4） |
| **拾い／拾い出し** | ひろい | **図面から面積・長さ・本数を数え上げること** | 「平面図から壁の延長を拾う」。**積算の中核作業** |
| **歩掛** | ぶがかり | **単位量の作業に必要な手間の量**（人工／㎡ など） | 「ボード張りの歩掛は0.08人工/㎡」。**その会社の経験の蓄積**そのもの |
| **人工** | にんく | **1人が1日働く量**を表す単位 | 「この工事は延べ80人工」。労務費＝人工数×労務単価 |
| **数量拾い表** | すうりょうひろいひょう | 拾いの結果をまとめた表 | 見積の根拠になり、発注数量の基礎にもなる |
| **単価** | たんか | 1単位あたりの金額 | 材料単価、労務単価、複合単価（材工共） |
| **材工共** | ざいこうとも | **材料と手間（労務）を合わせた単価** | 「クロス張りは材工共1,300円/㎡」 |
| **直接工事費** | ちょくせつこうじひ | その工事目的物を造るのに直接かかる費用 | 材料費・労務費・直接経費 |
| **共通仮設費** | きょうつうかせつひ | 現場全体で共通に使うものの費用 | 足場、仮囲い、仮設電気、養生 |
| **現場管理費** | げんばかんりひ | その現場を管理するための費用 | 現場代理人の人件費、労災保険料、法定福利費 |
| **一般管理費** | いっぱんかんりひ | **会社を維持するための費用と利益** | 本社人件費、事務所家賃、役員報酬 |
| **経費率・掛け率**【Varies】 | けいひりつ | 直接工事費に対して経費を乗せる割合 | 「経費は直工の10%」 |
| **見積条件書** | みつもりじょうけんしょ | **見積に含む範囲・含まない範囲**を明示した書面 | 「養生・廃材処分は別途」と明記しておく |
| **別途** | べっと | **この見積には含まれていない**という意味 | 「解体は別途です」。後のトラブルを防ぐ重要な言葉 |
| **実行予算** | じっこうよさん | **受注後に作り直す、社内管理用の原価計画**【社外に出さない】 | 「実行予算に対して残予算がいくらか」（→ `04` S8） |
| **公共工事設計労務単価** | こうきょうこうじせっけいろうむたんか | **公共工事の予定価格の積算に使うため**、国が職種別・都道府県別に公表する労務単価【Fact】 | **技能者に支払うべき賃金額そのものではない**点に注意 |
| **労務費に関する基準** | ろうむひにかんするきじゅん | **中央建設業審議会が2025年12月2日に勧告した、適正な労務費の基準**【Fact】 | **これを著しく下回る見積り・見積り依頼は禁止**【Fact】 |

## 16-4 施工管理に関する用語

| 用語 | 正式名称・読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **施工管理** | せこうかんり | **工程・品質・原価・安全の4つを同時に管理して工事を完成させること** | 「施工管理の4大管理」 |
| **工事監理** | こうじかんり | **設計図書のとおりに施工されているか確認すること**（建築士が行う） | **施工管理とは別**。業界では「さらかん／たけかん」と言い分ける【Typical】 |
| **工程表** | こうていひょう | いつ何を行うかを時系列で表した表 | バーチャート工程表、ネットワーク工程表 |
| **週間工程** | しゅうかんこうてい | 1週間単位の詳細な作業予定 | 週間工程会議で調整する |
| **取り合い** | とりあい | **複数業者の作業が同じ場所・時期で接する部分** | 「天井裏の取り合いを調整する」。工程管理の中心課題 |
| **手配** | てはい | 材料や職人を確保すること | 「来週の手配は済んでいます」 |
| **搬入** | はんにゅう | 材料・機械を現場に入れること | 「搬入は夜間しかできません」。**独立した工程になる**（→ `07_goods.md` 7-6） |
| **段取り** | だんどり | 作業をスムーズに進めるための準備 | 「段取り8分（だんどりはちぶ）」＝準備が仕事の8割という言い回し【Typical】 |
| **手戻り** | てもどり | **いったん施工したものをやり直すこと** | 「図面の版が古くて手戻りが出た」。**材料費・労務費が二重にかかる** |
| **是正** | ぜせい | 不良・不適合を直すこと | 「是正リスト」「是正完了報告」 |
| **ダメ出し／ダメ工事**【Varies】 | だめだし | 検査で指摘された箇所の手直し | 「ダメ工事が3日かかる」 |
| **養生** | ようじょう | **傷つけないように保護すること**／**コンクリートを適切な状態に保つこと** | 「床を養生する」「コンクリートの養生期間」。**2つの意味がある** |
| **墨出し** | すみだし | **図面の寸法を現場の床・壁に線で示す作業** | 「墨出しをしてから下地を組む」。施工の起点になる |
| **納まり** | おさまり | 部材と部材がどう接するか、その仕上がり方 | 「この納まりだと隙間が出る」 |
| **施工図** | せこうず | **どう造るかを示す図面**（施工者が作る） | 設計図だけでは施工できないため必要 |
| **設計図書** | せっけいとしょ | 設計図・仕様書など、工事の内容を定める書類一式 | 「設計図書のとおりに施工する」 |
| **仕様書** | しようしょ | 使う材料・工法・品質基準を文章で定めた書類 | 図面に描けない条件を書く |
| **竣工図** | しゅんこうず | **実際にできあがった状態を反映した図面** | 引渡し時に発注者へ渡す。**営業に関する図書として10年保存**【Fact】 |
| **RC／S／SRC** | 鉄筋コンクリート造／鉄骨造／鉄骨鉄筋コンクリート造 | 建物の構造の種類 | 「RC造5階建て」 |
| **躯体** | くたい | **建物の骨組み**（基礎・柱・梁・壁・床） | 「躯体工事が終わったら内装に入る」 |
| **仮設** | かせつ | **工事中だけ使って、完成時には撤去するもの** | 足場、仮囲い、仮設電気、仮設トイレ |

## 16-5 現場・作業に関する用語

| 用語 | 読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **朝礼** | ちょうれい | 始業前に全員で当日の作業・危険を共有する集まり | 元請が主催し、下請が参加する |

| **出面** | でづら | **その日どの現場に誰が何人入ったかの記録** | **労務費・外注費を工事別に集計する根拠**になる |
| **常用と請負** | — | 人日単位の取引と、完成に対する取引 | 「今日は常用でお願いします」 |
| **手元** | てもと | 職人の補助をする作業員 | 「手元を1人つける」 |
| **応援** | おうえん | 一時的に人を出すこと | 「明日、応援2名お願いします」 |
| **段取り替え** | だんどりがえ | 作業の順序や配置を組み替えること | 「材料が入らないので段取り替えする」 |
| **手待ち** | てまち | **作業ができず待たされている状態** | 「前工程が終わらず手待ちが出た」。**原価だけ発生する** |

| **クロス** | 壁紙 | 壁・天井の仕上げ材 | 「クロス張りは最後の工程」 |
| **原状回復** | げんじょうかいふく | **テナント退去時に、元の状態に戻す工事** | 【Typical】モデル企業の主要な仕事の一つ |
| **仮囲い** | かりがこい | 工事現場を囲う仮設の塀 | 第三者の立入防止と安全確保のため |
| **玉掛け** | たまがけ | **クレーンで荷を吊るために、荷にワイヤー等を掛ける作業** | 1トン以上は技能講習が必要【Fact】 |

## 16-6 安全に関する用語

| 用語 | 読み | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **グリーンファイル** | 労務安全書類 | **現場に入る会社と人の情報**をまとめた書類一式 | 「グリーンファイルを提出しないと入場できない」 |
| **作業員名簿** | さぎょういんめいぼ | その現場に入る作業員の氏名・資格・健康診断日等の一覧 | グリーンファイルの中心的な書類 |
| **再下請負通知書** | さいしたうけおいつうちしょ | **さらに下請に出した場合に、元請へ通知する書面** | 施工体制台帳の基礎情報になる |

|---|---|
| **「この現場は飛んだ」** | その工事が赤字になった |
| **「予算が食われた」** | 実際原価が実行予算を超えた |
| **「段取り8分」** | 準備が仕事の大半を決めるという考え方 |
| **「ダメが出た」** | 検査で手直しの指摘を受けた |
| **「まるなげ」** | 一括下請負のこと。**建設業法で禁止されている**【Fact】 |
| **「サイトが長い」** | 締めから支払までの期間が長く、資金負担が重い |
| **「拾いが甘い」** | 数量の算出が不正確だった |
| **「上（うえ）」「下（した）」** | 上位の請負人／下位の請負人 |
| **「一式（いっしき）で」** | 内訳を分けずにまとめて、という意味 |
| **「別途で」** | この見積・契約には含まない、という意味 |

## 16-13 【最重要】初心者が間違えやすいこと

ここからが本章の核心です。
**似ているのに違う言葉**を、「何と何が違うか／なぜ混同するか／実務でどう効くか」まで解説します。

---

### ■ A. すべての業界に共通する6つの基本

#### A-1. 受注 ≠ 売上（完成工事高）

| | 受注 | 売上（完成工事高） |
|---|---|---|
| **いつのことか** | **注文を受けたとき**（契約成立時） | **工事が完成・引き渡されたとき**（または進捗に応じて） |
| **何を表すか** | これからやる仕事の金額 | 終わった仕事の金額 |

**なぜ混同するのか**：日常語では「仕事が取れた＝売上が立った」と感じるためです。
しかし会計上、契約しただけでは何も計上されません。

**実務でどう効くか**：
【Example】3月に5,000万円の工事を受注しても、完成が7月なら、**3月期の完成工事高は0円**です。
決算期をまたぐ工事では、「受注したのに売上がない期」が発生します。
したがって **「今期は受注が絶好調なのに、決算は前期より悪い」ことが普通に起きます**。
金融機関や取引先に業績を説明するとき、**受注残とセットで見せる**必要があります
（→ `14_kpi.md` 14-1）。

#### A-2. 売上（完成工事高）≠ 入金

| | 完成工事高 | 入金 |
|---|---|---|
| **いつのことか** | 完成・引渡し時 | **請求後、支払サイトを経てから** |
| **何が動くか** | 帳簿上の数字（完成工事未収入金が立つ） | **実際のお金** |

**なぜ混同するのか**：「売上が上がった＝儲かった＝お金がある」と感じるためです。

**実務でどう効くか**：
【Example】6月に完成・請求 → 元請の支払条件が「月末締め翌々月末払い」なら、
**入金は8月末**です。その間の2か月、職人の給与も材料代も支払い続けます。
**建設業で最も多くの会社が直面するのがこの時間差**です（→ `08_money.md` 8-4）。
**利益が出ていても資金が足りなくなる**のはこれが理由です。

#### A-3. 発注 ≠ 仕入計上

| | 発注 | 仕入計上 |
|---|---|---|
| **いつのことか** | 注文書を出したとき | **材料が納品された／工事が完了したとき** |
| **帳簿はどうなるか** | **何も計上されない** | 原価が計上される |

**なぜ混同するのか**：「もう注文したのだから、お金は決まった」と感じるためです。

**実務でどう効くか**：
【最重要】**残予算を見るときは、必ず「発注残」を含めて見ます**。
【Example】実行予算の外注費720万円に対し、実際原価が430万円しか計上されていなくても、
すでに720万円分の注文書を出していれば、**残予算は0円**です。
ここを見誤ると「まだ余裕がある」と思って追加発注し、赤字になります
（→ `14_kpi.md` 14-3）。

#### A-4. 在庫 ≠ すべて完成品（建設業では「在庫を持たない」）

建設業には、製造業のような**販売用の在庫が存在しません**。

| 建設業で「持っているもの」 | 会計上の扱い |
|---|---|
| **進行中の工事に投入した原価** | **未成工事支出金**（資産） |
| 現場に搬入済みでまだ使っていない材料 | 未成工事支出金に含める【Typical】 |
| 仮設材 | **リースであることが多い**（自社資産ではない）【Typical】 |
| 完成した建物 | **発注者のものであり、自社の資産ではない** |

**なぜ混同するのか**：他業界の「在庫」の感覚を持ち込むためです。

**実務でどう効くか**：
建設業では**現場に倉庫がありません**。だから「必要な日に必要な量だけ届ける」搬入計画が
業務の中心になります（→ `07_goods.md` 7-1）。
また、**未成工事支出金は費用ではなく資産**なので、
**帳簿上は損益ゼロなのに現金は確実に減っている**という状態が生じます（→ `12_business-model.md` 12-4）。

#### A-5. 粗利 ≠ 利益

| | 完成工事総利益（粗利） | 営業利益 |
|---|---|---|
| **計算** | 完成工事高 − 完成工事原価 | 粗利 − 販売費及び一般管理費 |
| **何が引かれていないか** | **本社の人件費、事務所家賃、役員報酬、営業経費** | — |

**なぜ混同するのか**：「粗利が出ている＝儲かっている」と感じるためです。

**実務でどう効くか**：
【Example】モデル企業では粗利率15%に対し、販管費が11%あります。
つまり**粗利率が11%を下回ると、会社全体が赤字**になります。
現場ごとに「粗利12%出たから大丈夫」と思っても、
**会社としては1%しか残っていない**という状況が起き得ます。

#### A-6. 見積 ≠ 契約

| | 見積 | 契約 |
|---|---|---|
| **何を意味するか** | 「この金額でできます」という**提示** | **双方の合意**。法的な拘束力が生じる |
| **書面** | 見積書 | **請負契約書、または注文書＋注文請書**【Fact】 |

**なぜ混同するのか**：見積を出した段階で「仕事が決まった」と感じるためです。
実際には相見積で他社に決まることもあります。

**実務でどう効くか**：
【最重要】**見積を出しただけで着工してはいけません。**
建設業法第19条により、契約の締結に際して法定事項を書面で交付する必要があります【Fact】。
書面がないまま施工すると、**金額・工期・変更の扱いについて争いになったときに根拠がありません**。
これは追加工事でも同じです（→ B-6）。

---

### ■ B. 建設業固有の混同ペア

#### B-1. 請負 ≠ 派遣 ★最重要

| | **請負**（建設業で正しい形） | **労働者派遣**（建設業務では禁止）【Fact】 |
|---|---|---|
| **契約の目的** | **仕事の完成** | **労働力の提供** |
| **誰が指揮命令するか** | **請け負った側（自社の職長）が指揮する** | **派遣先が指揮命令する** |
| **雇用主** | 請け負った会社 | 派遣元 |
| **報酬の対象** | 完成した仕事 | 働いた時間 |
| **建設業務での可否** | ○ | **×（労働者派遣法第4条第1項の適用除外業務）**【Fact】 |

**なぜ混同するのか**：
**現場では、複数の会社の職人が同じ場所で一緒に働いている**からです。
見た目には、元請の社員も下請の職人も一人親方も、同じ現場で同じ作業をしています。
さらに**常用（人日単位の取引）**の形だと、「人を出している」ように見えます。

**実務でどう効くか**：
【最重要】**元請が、下請の作業員一人ひとりに直接指示を出すと、偽装請負の問題になり得ます。**
正しい形は、
```
  元請の所長 ──（作業範囲・工程を伝える）──→ 下請の職長
                                                  │
                                       （具体的な作業を指示）
                                                  ↓
                                            下請の作業員
```
これが **現場で「職長」というポジションが法的にも実務的にも重要な理由**です。
また、建設業で**常用取引でも「請負」の形をとる**のはこのためです（→ `15_rules-customs.md` 15-3(3)）。

#### B-2. 元請 ≠ 発注者 ★最重要

| | **発注者** | **元請** |
|---|---|---|
| **誰か** | **工事を注文した当事者**（建物の所有者・使用者、国・自治体） | **発注者から直接工事を請け負った建設会社** |
| **お金の向き** | 元請に払う | 発注者からもらい、下請に払う |
| **立場** | 注文する側 | **発注者に対しては請ける側、下請に対しては注文する側** |

**なぜ混同するのか**：
**下請会社から見ると、元請は「注文をくれる相手」なので、発注者のように見えます**。
実際、日常会話では下請が元請を「発注者さん」と呼ぶこともあります。
また建設業法上、**「注文者」には発注者も元請も含まれます**【Fact】。

**実務でどう効くか**：
| 論点 | 発注者との関係 | 元請との関係 |
|---|---|---|
| 契約 | 元請が発注者と契約 | 下請は元請と契約 |
| 追加工事 | **発注者が認めなければ元請も取れない** | 下請は元請としか交渉できない |
| 情報 | **下請は発注者と直接やり取りしない**のが原則【Typical】 | すべて元請を経由する |
| 支払 | 発注者→元請 | 元請→下請 |

【最重要】**下請にとって「発注者がどう言っているか」は、元請を通してしか分かりません。**
追加工事が認められるかどうかも、**元請が発注者から取れるかどうか**に依存します
（→ `09_information.md` 9-1「情報は契約の線に沿ってしか流れない」）。

#### B-3. 施主 ≠ 元請

| | **施主** | **元請** |
|---|---|---|
| **誰か** | **建物の持ち主・注文主**（＝発注者） | 工事を請け負った建設会社 |
| **検査** | **施主検査**を行う（最終的な確認） | **元請検査**を行う（下請の施工を確認） |

**なぜ混同するのか**：
どちらも「下請に指示を出す側」に見えるためです。
また現場では、施主の担当者と元請の所長が並んで現場を歩くことがあります。

**実務でどう効くか**：
【最重要】**検査は二段階あります**（→ `04_end-to-end-process.md` S17）。
```
 ① 自主検査（下請＝自社）
       ↓
 ② 元請検査（元請が下請の施工を確認）
       ↓
 ③ 施主検査（施主が最終確認）
```
**元請検査に通っても、施主検査で指摘が出ることがあります。**
このとき是正の費用を誰が負担するかは、指摘の原因によって変わります。
また、**施主から直接言われたことでも、必ず元請に確認してから対応する**のが原則です【Typical】。
勝手に対応すると、契約関係のない作業を無償で行うことになります。

#### B-4. 契約金額 ≠ 入金額

| | 契約金額（請負金額） | 実際の入金額 |
|---|---|---|
| **何か** | 契約で定めた工事の対価 | **実際に振り込まれた金額** |

**なぜ差が出るのか**【Typical】：

| 差の原因 | 内容 |
|---|---|
| **支給材代の相殺** | 元請が支給した材料の代金が差し引かれる |
| **立替金の相殺** | 元請が立て替えた電気代・廃材処分費・駐車場代などが差し引かれる |
| **安全協力会費**【Varies】 | 協力会費が差し引かれることがある |
| **手形と現金の内訳** | 一部が手形で支払われる【Varies】 |
| **査定による減額** | 出来高の査定結果が報告額より低い |
| **是正費用の負担** | 手直しの費用が差し引かれる |
| **振込手数料** | 差し引かれることがある【Varies】 |

**実務でどう効くか**：
【最重要】**入金があったら、必ず請求額と突き合わせ（消込）、差額の原因を確認します**
（→ `08_money.md` 8-16）。
差額を放置すると、**工事別の損益が正しく把握できなくなります**。
また、**下請代金から一方的に費用を差し引くことは建設業法上の問題となり得ます**【Fact】。
差し引かれる項目は、**あらかじめ契約や注文書で合意しておく必要があります**。

#### B-5. 完成 ≠ 引渡し

| | **完成（竣工）** | **引渡し** |
|---|---|---|
| **何を意味するか** | **工事が終わった**という事実 | **目的物の占有・危険負担が発注者に移る**という手続 |
| **何が必要か** | 施工が終わり、検査に合格すること | **完成引渡書などの書面**を取り交わすこと【Typical】 |
| **お金との関係** | — | **引渡しが請求の前提になることが多い**【Typical】 |

**なぜ混同するのか**：日常語では「工事が終わった＝渡した」と感じるためです。

**実務でどう効くか**：
| 論点 | 内容 |
|---|---|
| **請求のタイミング** | **引渡しをもって請求できる**契約が多い【Typical】。完成しても引渡しが済まないと請求できない |
| **危険負担** | 引渡し前に火災などで損害が生じた場合の負担が変わる【Fact】（→ `07_goods.md` 7-5） |
| **契約不適合責任の起算点** | 引渡しからの期間で定められることが多い【Typical】 |
| **営業に関する図書の保存** | **引渡しから10年間**【Fact】 |
| **建築基準法** | **完了検査を受け、検査済証の交付を受けるまでは原則として建築物を使用できません**【Fact】 |

【最重要】**「工事は終わったが、まだ引き渡していない」という期間が実際に存在します。**
是正が残っている、書類が揃っていない、検査済証がまだ出ていない、といった理由です。

#### B-6. 見積 ≠ 実行予算 ★最重要

| | **見積** | **実行予算** |
|---|---|---|
| **いつ作るか** | **受注前**（S4〜S5） | **受注後**（S8） |
| **何のためか** | **仕事を取るため**の提出用の金額 | **実際に施工するため**の内部管理用の計画 |
| **誰に見せるか** | **元請・発注者に提出する** | **社外に出さない** |
| **単価の根拠** | 標準的な歩掛・単価 | **実際に手配できる協力会社の単価** |
| **前提** | 現場の詳細は未確定 | 現調・打合せの結果を反映 |

**なぜ混同するのか**：
どちらも「この工事にいくらかかるか」を計算した数字だからです。
どちらも積算担当が作ることが多く、**見積の内訳をそのまま流用することもあります**。

**実務でどう効くか**：
【最重要】**利益は「見積粗利」ではなく「予算粗利に対して実際原価がどうなったか」で決まります。**
```
 ①見積粗利  → 価格交渉で請負金額が下がる
      ↓
 ②予算粗利  ← ここが実際の目標
      ↓
 ③実際粗利  ← ここが結果
```
【Example】見積で粗利20%を見込んでいても、
価格交渉で5%値引きし、協力会社の単価が想定より高ければ、
**実行予算を組んだ時点で粗利12%**ということが起こります。
**「見積の粗利が出ているから大丈夫」は誤りです**（→ `12_business-model.md` 12-6）。

**もう一つの重要な点**：**実行予算書は社外に出してはいけません。**
自社の原価構造（協力会社の単価、自社の歩掛）が相手に分かってしまうためです【Typical】。

#### B-7. 完成工事高 ≠ 受注高 ≠ 受注残

| | 受注高 | 受注残（手持ち工事高） | 完成工事高 |
|---|---|---|---|
| **いつの数字か** | **期間内に契約した分** | **時点での残高** | **期間内に完成した分** |
| **性格** | 先行指標（フロー） | 先行指標（ストック） | 結果指標（フロー） |
| **関係** | 期首受注残 ＋ 受注高 − 完成工事高 ＝ 期末受注残 | | |

**なぜ混同するのか**：すべて「工事の金額」だからです。

**実務でどう効くか**：
【Example】ある会社の話を聞いて「今年は10億円やりました」と言われたとき、
それが**受注高なのか完成工事高なのか**で意味がまったく違います。
- 受注高10億円 → これから10億円分の工事をする
- 完成工事高10億円 → すでに10億円分の工事を終えた

**建設業の会社と話すときは、「それは受注ベースですか、完工ベースですか」と聞くのが確実です。**

#### B-8. 主任技術者 ≠ 現場代理人 ★混同が非常に多い

| | **主任技術者** | **現場代理人** |
|---|---|---|
| **何に基づくか** | **建設業法第26条**（法律上の義務）【Fact】 | **請負契約**（契約上の地位） |
| **役割** | **施工の技術上の管理**をつかさどる | **請負契約の履行に関し、その現場を代表する** |
| **資格要件** | **国家資格または実務経験が必要**【Fact】 | **法律上の資格要件はない**【Fact】 |
| **誰に対する立場か** | 行政（法令上の配置義務） | **注文者に対する会社の代表** |

**なぜ混同するのか**：
**中小建設会社では、同じ人が両方を兼ねるのが普通**だからです【Typical】。
モデル企業でも「現場代理人 兼 主任技術者」と設定しています。

**実務でどう効くか**：
| 論点 | 内容 |
|---|---|
| **兼務の可否** | 主任技術者は**専任が必要な工事では他現場と兼務できません**【Fact】。現場代理人には法律上の兼務制限はありません |
| **資格** | 主任技術者になるには**資格または実務経験が必要**【Fact】。無資格者を主任技術者にはできません |
| **変更** | 現場代理人の変更は契約上の手続。主任技術者の変更は法令上の配置に関わる |
| **常駐**【Varies】 | 現場代理人の常駐義務は**契約の定めによる**。公共工事では緩和されている場合がある【Varies】 |

【最重要】**「うちの現場代理人は資格がなくても大丈夫」は誤りです。**
現場代理人としては資格不要ですが、**同じ現場に主任技術者は必ず必要**で、
その人には資格または実務経験が必要です【Fact】。

#### B-9. 着工 ≠ 契約

| | 契約 | 着工 |
|---|---|---|
| **何か** | 書面で合意すること | 実際に工事を開始すること |
| **順序** | **契約が先** | 着工が後 |

**なぜ混同するのか**：
現場では「急ぎだから先に始めてくれ」と言われることがあり、
**契約書が後から来る**ことが実際にあるためです【Typical】。

**実務でどう効くか**：
【最重要】**契約書面がないまま着工すると、非常に大きなリスクを負います。**
| リスク | 内容 |
|---|---|
| **金額が確定しない** | 「その金額では合意していない」と言われる可能性 |
| **工期の争い** | いつまでに完成させる約束だったかが不明確 |
| **追加工事の扱い** | 当初契約の範囲が曖昧なので、追加かどうかが争える |
| **法令上の問題** | **建設業法第19条は書面の交付を義務づけています**【Fact】 |

【Fact】建設業法令遵守ガイドラインでも、**契約書面は着工前に取り交わすべき**ことが
繰り返し示されています。

#### B-10. 一般建設業許可 ≠ 小さい会社用 ★最重要な誤解

| | **一般建設業許可** | **特定建設業許可** |
|---|---|---|
| **区分の基準** | 特定に該当しない場合 | **元請として、下請契約の総額が5,000万円以上（建築一式8,000万円以上）になる場合**【Fact】 |
| **会社の規模との関係** | **関係ない** | **関係ない** |

**なぜ混同するのか**：
「一般」「特定」という言葉から、「特定＝特別に大きな会社」という印象を受けるためです。

**実務でどう効くか**：
| ケース | 必要な許可 |
|---|---|
| 売上50億円だが**すべて下請**として施工 | **一般建設業許可で足りる** |
| 売上3億円だが、**元請として1件で6,000万円を下請に出す** | **特定建設業許可が必要** |
| 元請だが、**すべて自社施工**（下請に出さない） | **一般建設業許可で足りる** |

【最重要】**判断の軸は「元請として下請に出す金額」だけです。**
自社の売上高・従業員数・資本金は関係ありません。
ただし、**特定建設業許可には財産的基礎の要件がより厳しく課されます**【Fact】。

#### B-11. 出来高 ≠ 出来形

| | **出来高（できだか）** | **出来形（できがた）** |
|---|---|---|
| **何を表すか** | **金額換算した進捗** | **できあがった構造物の形状・寸法** |
| **何に使うか** | **請求・支払**（S14・S19） | **品質管理・検査**（S16・S17） |
| **単位** | 円、% | mm、m、㎡、m³ |
| **よく使う分野** | 全分野 | **主に土木**【Typical】 |

**なぜ混同するのか**：読みが「できだか」「できがた」で1文字しか違わないためです。

**実務でどう効くか**：
「出来形管理」と言われたら**寸法の話**、「出来高査定」と言われたら**お金の話**です。
聞き間違えると会話がまったく噛み合いません。

#### B-12. 工事監理 ≠ 施工管理

| | **工事監理** | **施工管理** |
|---|---|---|
| **誰が行うか** | **建築士**（設計者側） | **施工者**（現場代理人・主任技術者） |
| **何をするか** | **設計図書のとおりに施工されているか確認する** | 工程・品質・原価・安全を管理して工事を完成させる |
| **立場** | **発注者側** | **施工者側** |

**なぜ混同するのか**：読みがどちらも「こうじかんり／せこうかんり」で似ており、
どちらも「現場を見る仕事」だからです。

**実務でどう効くか**：
業界では **「さらかん（皿の監理）」「たけかん（竹の管理）」** と言い分けます【Typical】。
「監理者の承認を得てください」と言われたら、**設計者側の確認**が必要という意味です。
自社の施工管理担当が確認しても、それは監理ではありません。

#### B-13. 労務費 ≠ 外注費

| | **労務費** | **外注費** |
|---|---|---|
| **誰に払うか** | **自社が雇用している従業員** | **他の会社・一人親方** |
| **契約** | 雇用契約 | **請負契約** |
| **指揮命令** | 自社が直接行う | **相手の会社が行う** |
| **消費税** | **課税仕入にならない**（給与のため）【Fact】 | **課税仕入になる**【Fact】 |
| **社会保険** | 自社が事業主として負担 | 相手の会社が負担 |
| **費用の性格** | **固定費に近い**（仕事がなくても発生） | **変動費に近い**（仕事量に連動） |

**なぜ混同するのか**：
どちらも「人が働いた対価」で、**現場では自社の職人も協力会社の職人も一緒に作業している**ためです。

**実務でどう効くか**：
| 論点 | 内容 |
|---|---|
| **消費税** | 区分を誤ると消費税の計算が変わる【Fact】 |
| **社会保険** | 誰が事業主として負担するかが変わる |
| **偽装請負** | 外注として契約しているのに自社が直接指揮命令すると、法律上の問題になる（→ B-1） |
| **経審** | **技術職員数は自社の職員で数える**【Fact】 |
| **固定費の重さ** | 自社雇用が多いと、工事量が減ったときに固定費が重くなる【Inference】 |

#### B-14. 現場労災 ≠ 事務所労災

| | **現場労災（有期事業の労災）** | **事務所労災（継続事業の労災）** |
|---|---|---|
| **対象** | **現場で作業する労働者**（下請の労働者を含む） | **現場作業に従事しない従業員**（事務員、営業など） |
| **誰が加入するか** | **元請が現場単位で加入**（元請一括）【Fact】 | **各社が自社で加入**【Fact】 |

**なぜ混同するのか**：「労災に入っている」という言葉が両方に使われるためです。

**実務でどう効くか**：
【最重要】**下請会社も、事務所労災には自社で加入する必要があります**【Fact】。
「元請が労災に入っているから大丈夫」は、**現場作業についてのみ**正しい説明です。
また、**一人親方は労働者ではないため元請の労災の対象外**であり、
**特別加入**が必要です【Fact】（→ `15_rules-customs.md` 15-3(4)）。

#### B-15. 建設業許可 ≠ 経営事項審査 ≠ 入札参加資格

| | **建設業許可** | **経営事項審査** | **入札参加資格** |
|---|---|---|---|
| **何のため** | **工事を請け負うため** | **公共工事を元請として受注するため** | **その発注機関の入札に参加するため** |
| **誰に申請** | 都道府県知事／国土交通大臣 | 許可行政庁（＋登録経営状況分析機関） | **各発注機関** |
| **有効期間** | **5年**【Fact】 | **審査基準日から1年7か月**【Fact】 | 発注機関ごと【Varies】 |
| **民間工事だけなら** | **必要** | 不要 | 不要 |

**なぜ混同するのか**：すべて「建設業をやるための手続」だからです。

**実務でどう効くか**：
【最重要】**この3つは「積み上げ」の関係です。**
```
  建設業許可 → 経営事項審査 → 入札参加資格 → 入札に参加できる
```
1つでも欠けたり期限が切れたりすると、その先に進めません。
【Example】決算変更届を出し忘れていると、**経審が受けられません**。
経審の有効期間が切れると、**公共工事を受注できません**（契約締結日の1年7か月前以降の
決算日を基準日とする経審が必要）【Fact】。

#### B-16. 取適法（旧・下請法）≠ 建設業法の下請規制

| | **取適法**（旧・下請法）【Fact】 | **建設業法の下請規制** |
|---|---|---|
| **正式名称** | 製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律（略称：中小受託取引適正化法／通称：取適法。**2026年1月1日施行**）【Fact】 | 建設業法（昭和24年法律第100号） |
| **対象** | 製造委託、修理委託、情報成果物作成委託、役務提供委託、特定運送委託【Fact】 | **建設工事の請負**【Fact】 |
| **建設工事の請負** | **適用対象から明示的に除外されている**（第2条第4項）【Fact】 | **これが適用される** |
| **所管** | 公正取引委員会、中小企業庁 | **国土交通省**（および都道府県） |
| **支払期日** | 受領日から60日以内【Fact】 | **1か月以内／50日以内**【Fact】 |

**なぜ混同するのか**：
どちらも「立場の弱い受注側を守るための法律」だからです。
さらに、**取適法は2026年1月1日まで「下請代金支払遅延等防止法（下請法）」という題名**で、
**現在も業界では「下請法」と呼ばれることが多い**ため、
建設業の下請取引にも及ぶと誤解されやすくなっています【Fact】。

**実務でどう効くか**：
【最重要】**建設工事の下請取引は取適法の対象外です。**
相談先は**国土交通省または都道府県の建設業担当部署**になります。
ただし、**建設業者が建設工事以外の取引（資材の加工委託、設計・情報成果物の作成委託、
運送の委託など）を行う場合は、取適法の対象になり得ます**【Fact】。
また、独占禁止法の優越的地位の濫用は、建設工事の請負にも適用され得ます【Fact】。

#### B-17. 瑕疵 ≠ 契約不適合（用語の変更）

| | 瑕疵担保責任（旧） | **契約不適合責任**（現行）【Fact】 |
|---|---|---|
| **いつから** | 2020年3月31日以前の契約 | **2020年4月1日以後の契約**（改正民法） |
| **考え方** | 「隠れた瑕疵」があるかどうか | **契約の内容に適合しているかどうか** |
| **買主・注文者の権利** | 修補請求、損害賠償、解除 | **追完請求、報酬減額請求、損害賠償、解除**【Fact】 |

**なぜ混同するのか**：
**実務では今も「瑕疵」という言葉が広く使われている**ためです。
「瑕疵保険」「住宅瑕疵担保履行法」など、**法令の名称にも残っています**【Fact】。

**実務でどう効くか**：
会話では「瑕疵」で通じますが、**契約書の条項を読むときは、
その契約がどちらの枠組みかを確認する**必要があります。
とくに**期間の起算点と権利の内容**が違います。

#### B-18. 常用 ≠ 応援 ≠ 派遣

| | **常用** | **応援**【Varies】 | **派遣** |
|---|---|---|---|
| **契約の形** | **請負契約**（人日単位の精算） | **請負契約**（常用と同義に使われることが多い）【Typical】 | **労働者派遣契約** |
| **指揮命令** | **送り出した会社（職長）** | 同左 | **派遣先** |
| **建設業務での可否** | ○ | ○ | **×**【Fact】 |

**なぜ混同するのか**：
**3つとも「人を出す」ように見える**ためです。
とくに常用は、金額が「人日×単価」なので、**派遣の料金体系に似ています**。

**実務でどう効くか**：
【最重要】**金額の決め方が人日単位でも、契約の性質は請負です。**
判断の分かれ目は **「誰が指揮命令しているか」** です。
建設業務で派遣にあたる形をとると、**労働者派遣法違反**になります【Fact】。

#### B-19. 養生（保護）≠ 養生（コンクリート）

| | **保護としての養生** | **コンクリートの養生** |
|---|---|---|
| **何をするか** | **傷つけないように覆う・囲う** | **適切な温度・湿度を保ち、強度を発現させる** |
| **例** | 「床を養生シートで覆う」 | 「コンクリートを7日間養生する」 |

**なぜ混同するのか**：同じ「養生」という言葉が、**まったく違う意味で使われている**ためです。

**実務でどう効くか**：
「養生期間が必要です」と言われたとき、
- **内装工事なら**：保護材を敷く・剥がす手間と時間
- **躯体工事なら**：コンクリートが固まるまでの待ち時間（**工程に直接影響する**）

意味を取り違えると、工程の理解を誤ります。

#### B-20. 工事原価 ≠ 販売費及び一般管理費

| | **工事原価** | **販売費及び一般管理費** |
|---|---|---|
| **何が入るか** | 材料費・労務費・外注費・経費（**現場管理費を含む**） | 本社人件費、事務所家賃、役員報酬、営業経費 |
| **工事別に集計するか** | **する**（工事番号が付く） | **しない** |
| **粗利への影響** | **粗利を減らす** | 粗利の下で引かれる |

**なぜ混同するのか**：
**現場代理人の人件費**のように、**どちらに入れてもおかしくない費目がある**ためです【Varies】。

**実務でどう効くか**：
【最重要】**この線引きが違うと、粗利率が数ポイント変わります。**
他社と粗利率を比較するときは、**必ず「何を工事原価に入れているか」を確認する**必要があります
（→ `14_kpi.md` 14-3）。
同じ実力でも、粗利率15%の会社と22%の会社に見えることがあります。

## 16-14 まとめ ― 最低限これだけは

**業界の人と話すときに、これを押さえていれば会話が成立します。**

| # | 押さえること |
|---|---|
| 1 | **請負**は「仕事の完成」に対する対価。時間に対する対価ではない |
| 2 | **元請と発注者は別**。下請は元請としか契約していない |
| 3 | **請負と派遣は別**。建設業務への派遣は禁止。指揮命令は自社の職長が行う |
| 4 | **見積 → 実行予算 → 実際原価**。利益は「実行予算に対してどれだけ残ったか」 |
| 5 | **受注 ≠ 売上 ≠ 入金**。建設業では先に払って後から入る |
| 6 | **主任技術者は法律上の配置義務、現場代理人は契約上の地位**。中小では兼務が普通 |
| 7 | **一般／特定の区別は会社の規模ではなく「元請として下請にいくら出すか」** |
| 8 | **完成工事高・未成工事支出金など、建設業固有の勘定科目**がある |
| 9 | **工事写真は「完成すると見えなくなる部分」の証拠**。だから撮る |
| 10 | **建設業許可（5年）→ 経審（1年7か月）→ 入札参加資格**は積み上げの関係 |
| 11 | **建設工事の請負に取適法（旧・下請法）は適用されない**。建設業法が規律する |
| 12 | **制度は改正が続いている**。最新の公式情報で確認する（直近：2025年12月12日完全施行） |
