# CHAPTER 4｜全社 End-to-End 業務フロー（引合いから入金・アフターまで）

> 本ファイルは、`03_company-structure.md` で設定したモデル企業
> （株式会社サンエイ内装／内装仕上工事・従業員28名・下請70%＋直請け30%）を主語に、
> **1件の工事が始まってから終わるまで**を一続きで追います。
>
> 各ステップは「**誰が／何を受け取り／何をして／何を作り／次に誰へ渡すか**」＋**頻度**で記述します。
> 頻度の語彙は `common/methodology.md` §5 に従います。
> 機能の呼称（①〜⑧）は `03_company-structure.md` 3-8 の定義を使います。

---

## 4-1 全体像（20ステップ）

```
【受注前】
  S1  引合い情報の入手
  S2  引合いの受け・不受けの判断
  S3  現場調査（現調）
  S4  積算（数量拾い）
  S5  見積書の作成・提出
  S6  見積調整・価格折衝
  S7  受注確定（注文書・注文請書／請負契約の締結）

【着工準備】
  S8  実行予算の作成
  S9  着工準備（施工計画書・工程表・配置技術者の決定）
  S10 安全書類（グリーンファイル）の作成・提出／各種届出
  S11 資材の発注・搬入計画
  S12 協力会社・職人の手配（労務手配）

【施工中】
  S13 着工・施工（工程／品質／原価／安全の日次管理）
  S14 出来高報告・出来高査定
  S15 契約変更（設計変更・追加工事）の処理

【完成〜入金】
  S16 自主検査・社内検査
  S17 元請検査・施主検査（竣工検査）・是正
  S18 引渡し
  S19 請求
  S20 入金・支払・原価確定

【引渡し後】
  S21 瑕疵（契約不適合）対応・アフター
```

---

## 4-2 【重要】元請の場合と下請の場合でフローがどう違うか

同じ会社でも、立場が変わるとフローが変わります。まず対比で全体像をつかみます。

| ステップ | **下請として受注した場合**（モデル企業の売上70%） | **元請（直請け）として受注した場合**（同30%） |
|---|---|---|
| **S1 引合い** | **元請ゼネコンの工事部・購買部から見積依頼**が届く | 発注者・ビル管理会社・設計事務所から直接依頼が来る |
| **S3 現調** | 元請が現場を案内する。工程・搬入ルートは元請が説明 | **自社で発注者と現地を確認する**。近隣条件・管理規約も自社で確認 |
| **S4 積算** | 自社工種の範囲のみ。元請から「この範囲を見てほしい」と指定される | **工事全体の範囲を自社で切り分ける**。他工種の外注見積も集める |
| **S5 見積** | 元請の指定様式・指定内訳で提出することが多い【Typical】 | 自社様式。発注者に分かる言葉で説明する必要がある |
| **S7 契約** | **注文書・注文請書**での取り交わしが多い【Typical】 | 請負契約書（約款付き）を交わすことが多い【Varies】 |
| **S9 着工準備** | **元請の施工計画・全体工程に従う**。自社工程はその中に組み込む | **自社が全体工程を組む**。他業者の工程も自社が調整する |
| **S10 安全書類** | **元請に提出する側**（作業員名簿、施工体制台帳への記載事項など） | **自社が集める側**。下請から書類を集約する |
| **S10 届出** | 元請が行う（建築確認・道路使用許可など）ことが多い | **自社が行う**（道路使用許可、消防、ビル管理会社への申請など） |
| **S13 施工** | 自社工種のみ。**他業者との取り合い調整は元請が仕切る** | 全工種。自社が各業者を仕切る |
| **S14 出来高** | 元請の締日に合わせて出来高を報告し、**元請の査定を受ける** | 自社が発注者に出来高を報告する／完成一括払いのことも多い |
| **S17 検査** | **元請検査 → 施主検査**の二段階を受ける | 自社が社内検査 → 発注者の検査を受ける |
| **S18 引渡し** | 元請に引き渡す（元請が発注者に引き渡す） | 発注者に直接引き渡す |
| **S19 請求** | **元請の締日・支払サイトに従う**【Typical】 | 契約で定めた条件に従う |
| **S20 入金** | 元請から入金。建設業法の支払期日規定が適用される【Fact】 | 発注者から直接入金 |
| **責任の範囲** | 自社工種の施工と安全 | **工事全体の完成責任と安全責任** |

> **最も大きな違い**：
> 下請の場合、**工期も工程も自分では決められません**。元請の全体工程の中に自社の工程が埋め込まれます。
> このため、前工程が遅れると自社の作業日が押し、後ろの工程は動かないため、
> **同じ作業を短い日数でこなす**必要が生じます【Typical】。
> これが「建設業の下請では、受注時の見積と実際の投入人工が乖離しやすい」構造の背景です【Inference】。

## 4-3 各ステップの詳細

---

### 受注前

---

#### S1｜引合い情報の入手

| 項目 | 内容 |
|---|---|
| **きっかけ** | 元請から見積依頼が届く／発注者から相談が来る／入札情報が公告される |
| **誰が** | ① 営業機能、代表取締役、③ 工事管理機能（現場代理人が直接受けることも多い）【Typical】 |
| **受け取るもの** | 見積依頼書、設計図書（意匠図・仕上表・展開図）、仕様書、現場説明資料、見積期限 |
| **何をするか** | 図面が揃っているか、見積範囲がどこまでかを確認する。見積提出期限を確認する |
| **作るもの** | 引合い台帳（案件番号・発注者・元請名・工事名・見積期限・担当）の記録 |
| **次に渡す先** | ② 積算・見積機能 |
| **頻度** | **案件発生時**（モデル企業では年間の引合い件数は受注件数の数倍になる）【Varies】 |

> **なぜ台帳に記録するのか**：建設業では引合いが同時並行で複数走ります。
> 「どの案件がどの段階か」を見失うと、見積提出期限を逃して失注します【Typical】。

> **【Fact】見積期間には法定の下限があります。**
> 注文者は、受注予定者が見積りを行うために必要な期間を設けなければならず、
> 工事1件の予定価格が **500万円未満は1日以上／500万円以上5,000万円未満は10日以上／
> 5,000万円以上は15日以上**と定められています（建設業法第20条、同施行令第6条）。

> **公共工事の場合**：入札情報は発注機関のホームページ等で公告されます。
> 参加するには事前に**入札参加資格**の登録が必要です【Fact】（→ `02_industry-structure.md` 11-6）。

---

#### S2｜引合いの受け・不受けの判断

| 項目 | 内容 |
|---|---|
| **きっかけ** | S1 の引合い受付 |
| **誰が** | 代表取締役、① 営業機能、③ 工事管理機能 |
| **受け取るもの** | 引合い情報、現在の受注残と技術者の空き状況 |
| **何を確認するか** | ①**施工体制が組めるか**（配置技術者と職人を手当てできるか）②工期が自社の他現場と重ならないか ③元請・発注者の支払条件と信用 ④自社の許可業種でカバーできるか ⑤見積作成に割ける工数 |
| **何を判断するか** | 見積を出すか、辞退するか |
| **作るもの** | 見積作成の指示（担当者・期限）、または辞退の連絡 |
| **次に渡す先** | ② 積算・見積機能（進める場合）／① 営業機能（辞退連絡） |
| **頻度** | **案件発生時** |

> **【Typical】建設業で「受けない判断」が重要な理由**
> 受注しても人が手当てできなければ、工期を守れず、元請との関係を失います。
> `03_company-structure.md` 3-5 で見たとおり、**専任が必要な規模の工事を受けると技術者が1現場に固定される**ため、
> 同時に請けられる工事数には物理的な上限があります。
> 「受けられる量」を超えて受注しないことが、建設業の受注判断の基本になります【Inference】。

---

#### S3｜現場調査（現調／げんちょう）

| 項目 | 内容 |
|---|---|
| **きっかけ** | 見積作成の決定 |
| **誰が** | ③ 工事管理機能（現場代理人）、② 積算・見積機能 |
| **受け取るもの** | 設計図書、現場の所在地、立入の日時指定 |
| **何を確認するか** | 下記「現調チェック項目」参照 |
| **何をするか** | 現地に行き、図面と実際の状態の違いを確認し、写真と寸法を記録する |
| **作るもの** | 現地調査報告書、現場写真、実測寸法メモ |
| **次に渡す先** | ② 積算・見積機能 |
| **頻度** | **案件発生時**（改修工事では必須。新築でも現地条件の確認のため行う）【Typical】 |

> **現調チェック項目【Typical】**
> | 分類 | 何を見るか | なぜ見るか |
> |---|---|---|
> | 既存の状態 | 既存下地、天井内の状態、床レベル、壁の垂直 | 図面どおりでないと、下地補修の手間が追加で発生する |
> | 搬入経路 | エレベーターの寸法、荷揚げ経路、養生の要否 | 材料が入らなければ、分割納入や手運びで人工が増える |
> | 置き場 | 資材の仮置きができる場所があるか | 置けなければ小分け納入になり、運搬費と手間が増える |
> | 作業時間 | 施工可能な時間帯（日中／夜間／土日） | 夜間・休日作業は人件費の単価が変わる |
> | 電源・水 | 仮設電源の有無、容量、給排水 | 無ければ仮設工事の費用が発生する |
> | 近隣・入居者 | テナントが営業中か、住民がいるか | 騒音作業の時間制限、養生の程度が変わる |
> | 廃材 | 廃材の搬出経路、集積場所 | 処分費と運搬の手間に直結する |
> | 駐車 | 車両を停められるか | 停められなければコインパーキング代が現場経費になる |

> **なぜ現調が決定的に重要か**
> **建設業では「図面に描かれていないこと」が原価の大半を左右します。**
> 同じ100㎡のクロス張りでも、エレベーターが使えない8階の現場と、
> 台車で入れる1階の現場では、必要な人工が変わります。
> 現調を省いて見積を出すと、受注後に発覚した条件がそのまま赤字になります【Typical】。

#### S4｜積算（数量拾い）

| 項目 | 内容 |
|---|---|
| **きっかけ** | 現調の完了 |
| **誰が** | ② 積算・見積機能 |
| **受け取るもの** | 設計図書（平面図・天井伏図・展開図・仕上表・仕様書）、現地調査報告書 |
| **何をするか** | 図面から数量を「拾い」、材料単価と労務単価を掛けて原価を積み上げる |
| **作るもの** | **数量拾い表**、原価の積上げ表 |
| **次に渡す先** | ② 積算・見積機能（見積書作成へ） |
| **頻度** | **案件発生時** |

##### 積算で拾うもの【Typical】

```
①【材料数量】 ボード何枚／軽量鉄骨(LGS)何本／クロス何m／床材何㎡／ビス・ボンド等の副資材
②【労務数量】 各作業に何人工（にんく）かかるか
③【運搬】     何回・何トン車で運ぶか
④【仮設】     養生材、脚立・足場、仮設照明
⑤【廃棄】     廃材が何m³出るか、処分費はいくらか
⑥【現場経費】 駐車場、交通費、現場代理人の管理工数
```

> **人工（にんく）による積算**
> → 職人1人が1日働く量を1人工として、作業量を人数×日数で見積る方法。
> → 実務例：「軽鉄下地100㎡で6人工、ボード張り100㎡で8人工」のように、
>   自社の過去実績から「㎡あたり何人工か」の歩掛（ぶがかり）を持っておき、
>   数量を掛けて必要人工数を算出する。

> **歩掛（ぶがかり）**
> → 一定の作業量をこなすのに必要な手間（人工）や材料の標準量のこと。
> → 実務例：「クロス張りは1人1日あたり60㎡」という歩掛を持っていれば、
>   300㎡なら5人工と即座に計算できる。
> → **歩掛の精度が、その会社の見積精度そのもの**になります【Typical】。

> **なぜ積算を誤ると致命的か**
> 建設業は**契約時に金額が確定し、その後の原価上振れは原則として自社負担**です。
> 「思ったより手間がかかった」は、そのまま利益の減少になります。
> そのため積算は、営業の一部ではなく**独立した専門技能**として扱われます【Typical】。

#### S5｜見積書の作成・提出

| 項目 | 内容 |
|---|---|
| **きっかけ** | 積算の完了 |
| **誰が** | ② 積算・見積機能、① 営業機能、代表取締役（最終承認） |
| **受け取るもの** | 数量拾い表、原価積上げ表 |
| **何をするか** | 原価に一般管理費・利益を乗せて請負金額を決め、見積書の形に整える |
| **何を判断するか** | 利益率をいくらに設定するか（受注確度、元請との関係、工事の難易度、繁忙期かどうかを踏まえる）【Varies】 |
| **作るもの** | **見積書**、**見積内訳書**、見積条件書（見積に含む範囲／含まない範囲の明記） |
| **次に渡す先** | ① 営業機能 → 元請・発注者 |
| **頻度** | **案件発生時** |

##### 見積書に必ず書くこと【Typical】

| 項目 | なぜ必要か |
|---|---|
| 工事名・工事場所 | どの工事の見積かを特定するため |
| 工期 | 金額は工期とセットで決まる（短い工期は応援が必要になり原価が上がる） |
| **見積有効期限** | 資材価格が変動するため。期限を切らないと古い単価で契約させられる恐れがある |
| **見積条件（含む／含まない）** | 「範囲の認識違い」が建設業で最も多いトラブルの原因【Typical】 |
| 内訳（工種・数量・単価・金額） | 元請が他社見積と比較し、査定するため |
| 諸経費 | 現場管理費・一般管理費の区分 |

> **【Fact】2025年（令和7年）12月12日に完全施行された改正建設業法により、
> 建設工事の見積書に記載すべき事項、および入札金額の内訳書に記載すべき事項が明確化されました。**
> また、**著しく低い労務費等による見積り・契約が禁止**され、
> 見積書で示された金額を著しく下回る金額で契約を締結した発注者に対する
> 勧告・公表の権限が新設されました（出典：国土交通省報道発表資料）。

> **【Typical】見積条件書が重要な理由**
> 「この見積に、既存壁の解体は含まれているのか」「残材処分は誰の負担か」
> 「夜間作業の割増は含まれているのか」——
> これらを書いていないと、着工後に「入っているはずだ」「入っていない」の争いになります。
> 建設業の見積書に付く「見積条件」「特記事項」は、**契約の範囲を定める文書**として機能します。

#### S6｜見積調整・価格折衝

| 項目 | 内容 |
|---|---|
| **きっかけ** | 元請・発注者からの照会、査定結果の連絡 |
| **誰が** | ① 営業機能、代表取締役、② 積算・見積機能 |
| **受け取るもの** | 元請の査定金額、他社との比較、追加の図面や条件変更 |
| **何をするか** | 金額の根拠を説明する／仕様の変更で金額を調整する（材料のグレード変更、施工方法の変更）／範囲の見直し |
| **何を判断するか** | どこまで下げられるか（＝どこまでが自社の利益で、どこからが赤字か） |
| **作るもの** | 修正見積書、変更内訳書 |
| **次に渡す先** | 元請・発注者 |
| **頻度** | **案件発生時**（1案件で複数回繰り返されることが一般的）【Typical】 |

> **【Typical】建設業の価格折衝の特徴**
> 「一律○%引き」という形の要請を受けることがあります。
> 材料費は下げようがないため、実質的には**労務費（人工）か自社の利益を削ること**になります。
> `02_industry-structure.md` 11-7 のとおり、**不当に低い請負代金の禁止**（建設業法）と
> **著しく低い労務費等による見積り・契約の禁止**（2025年12月完全施行）が法律上のルールとして存在します【Fact】。

---

#### S7｜受注確定（注文書・注文請書／請負契約の締結）

| 項目 | 内容 |
|---|---|
| **きっかけ** | 元請・発注者からの内示・発注の連絡 |
| **誰が** | 代表取締役、① 営業機能、⑧ 人事・総務機能（契約書の管理） |
| **受け取るもの** | **注文書**（下請の場合）／請負契約書案（元請の場合） |
| **何を確認するか** | 金額、工期、支払条件（締日・支払日・手形の有無）、契約の範囲、変更時の取扱い、瑕疵の範囲 |
| **何をするか** | 内容を確認し、**注文請書**を返送する／請負契約書に記名押印して取り交わす |
| **作るもの** | **注文請書**（下請）／**請負契約書**（元請）、受注登録（工事番号の採番） |
| **次に渡す先** | ② 積算・見積機能（実行予算へ）、③ 工事管理機能、⑦ 経理・財務機能 |
| **頻度** | **受注時** |

##### 注文書と注文請書【Typical】

> **注文書（ちゅうもんしょ）**
> → 注文する側（元請）が「この工事をこの条件で頼みます」と出す書面。
> → 実務例：元請ゼネコンから「○○ビル改修工事のうち内装仕上工事 一式 1,500万円、
>   工期 ○月○日〜○月○日」と記載された注文書が届く。

> **注文請書（ちゅうもんうけしょ）**
> → 注文を受ける側（下請）が「その条件でお受けします」と返す書面。
> → 実務例：注文書の内容を確認し、記名押印して元請に返送する。
> → **注文書と注文請書がセットで交わされて、初めて契約が成立した扱いになります**【Typical】。

##### 請負契約書の法定記載事項【Fact】

建設業法第19条により、請負契約の当事者は次の事項を書面に記載し、
署名または記名押印して相互に交付しなければなりません（出典：国土交通省）。

```
・工事内容
・請負代金の額
・工事着手の時期、工事完成の時期
・前金払・出来高部分払の定めをするときは、その支払の時期・方法
・設計変更、工事着手の延期、工事の全部または一部の中止の場合における
  工期の変更、請負代金の額の変更、損害の負担、それらの額の算定方法
・天災その他不可抗力による工期の変更、損害の負担、その算定方法
   （このほか、価格変動時の取扱い、検査・引渡しの時期、代金の支払時期・方法、
     契約不適合責任、契約に関する紛争の解決方法 等）
```

> **注意**：注文書・注文請書による方式でも、これらの事項を満たす必要があります【Fact】。
> 「電話で頼まれて着工し、後から書面が来る」という進み方は、書面交付義務の観点から問題となり得ます。

> **【Fact】電子契約について**：国土交通省は
> 「電磁的措置による建設工事の請負契約の締結に係るガイドライン」（最終改正 2025年9月30日）を示しており、
> 一定の要件を満たす電子的方法による契約締結が認められています。

#### S8｜実行予算の作成

| 項目 | 内容 |
|---|---|
| **きっかけ** | 受注確定 |
| **誰が** | ② 積算・見積機能、③ 工事管理機能（現場代理人）、代表取締役（承認） |
| **受け取るもの** | 受注金額、見積内訳、現地調査報告書 |
| **何をするか** | 受注金額から「この現場で使ってよい原価の上限」を費目別に配分する |
| **作るもの** | **実行予算書**（材料費・外注費・労務費・現場経費の費目別予算） |
| **次に渡す先** | ③ 工事管理機能（現場の原価管理の基準になる）、⑦ 経理・財務機能 |
| **頻度** | **受注時** |

> **実行予算（じっこうよさん）**
> → 受注した金額の中で、実際に現場でいくらまで使ってよいかを決めた社内の予算のこと。
> → 実務例：請負金額1,500万円の工事で、材料費375万円・外注費600万円・労務費150万円・
>   現場経費150万円＝原価1,275万円、粗利225万円（15%）という予算を組む。
> → **見積は「取るための金額」、実行予算は「守るための金額」**という違いがあります【Typical】。

> **なぜ実行予算が要るのか**
> 見積の段階では受注のために金額を調整することがあります。
> そのため、**確定した受注金額をもとに予算を組み直さないと、
> 現場が「いくらまで使ってよいか」を判断できません**。
> 実行予算がないまま着工すると、原価の超過に気づくのが工事完了後になります【Inference】。

#### S9｜着工準備（施工計画書・工程表・配置技術者の決定）

| 項目 | 内容 |
|---|---|
| **きっかけ** | 受注確定・実行予算の確定 |
| **誰が** | ③ 工事管理機能（現場代理人）、⑤ 安全・品質管理機能 |
| **受け取るもの** | 設計図書、元請の全体工程表（下請の場合）、実行予算書 |
| **何をするか** | 施工の手順を決め、工程を組み、配置する技術者と職人を決める |
| **作るもの** | **施工計画書**、**工程表**、**施工図**、配置技術者の届出（元請へ） |
| **次に渡す先** | ⑤ 安全・品質管理機能、⑥ 資材調達・外注管理機能、元請 |
| **頻度** | **受注時** |

##### 作るものの中身【Typical】

> **施工計画書**
> → どんな手順・工法・材料・体制で工事を進めるかをまとめた書類。
> → 実務例：使用材料のメーカー・品番、下地のピッチ、施工手順、品質管理の方法、
>   作業員の体制、安全対策を記載し、元請（および工事監理者）の承認を受ける。
> → **なぜ必要か**：着工後に「その材料は認めていない」「その工法では不可」となると
>   すべてやり直しになるため、**着工前に合意しておく**必要があります。

> **工程表（こうていひょう）**
> → いつ、どの作業を、どこまで進めるかを日付で表した表。
> → 実務例：横軸に日付、縦軸に作業項目を取り、バーで期間を示す（バーチャート工程表）。
> → **下請の場合は、元請の全体工程表の中に自社の作業期間が割り当てられます**【Typical】。

> **施工図（せこうず）**
> → 設計図をもとに、実際に施工できるレベルまで詳細化した図面。
> → 実務例：設計図には「軽量鉄骨下地 t=15 ボード2重張り」としか書かれていない壁について、
>   下地の割付、開口部の補強、他業者の配管・配線との取り合いまで描き込む。
> → **なぜ必要か**：設計図のままでは、現場で「ここはどう納めるのか」が決まらないためです。

##### 配置技術者の決定【Fact】

`03_company-structure.md` 3-5 のとおり、**工事現場ごとに主任技術者（または監理技術者）を
配置することが建設業法第26条で義務づけられています**。

| 請負代金 | モデル企業での扱い |
|---|---|
| 4,500万円未満 | 主任技術者は専任不要。現場代理人が他現場と兼務できる【Fact】 |
| 4,500万円以上（建築一式は9,000万円以上）で、公共性のある施設等の重要な工事 | **主任技術者を専任で配置**【Fact】（2025年2月1日改正後の金額） |

#### S10｜安全書類（グリーンファイル）の作成・提出／各種届出

| 項目 | 内容 |
|---|---|
| **きっかけ** | 着工日の決定、元請からの提出依頼 |
| **誰が** | ③ 工事管理機能、⑤ 安全・品質管理機能、⑧ 人事・総務機能 |
| **受け取るもの** | 元請指定の様式、自社と協力会社の情報（許可証、保険加入状況、資格証、作業員名簿） |
| **何をするか** | 書類を作成し、協力会社から書類を集め、元請に提出する |
| **作るもの** | **グリーンファイル（安全書類）一式** |
| **次に渡す先** | 元請（元請はこれをもとに施工体制台帳を作る） |
| **頻度** | **受注時**（着工前）＋ 作業員や協力会社が変わるたびに更新【Typical】 |

##### グリーンファイル（安全書類）とは

> **グリーンファイル（安全書類／労務安全書類）**
> → 現場に入る会社と作業員の情報、保険加入状況、資格、作業計画などをまとめた書類一式のこと。
>   ファイルの表紙が緑色だったことから、業界でこう呼ばれている【Typical】。
> → 実務例：新しい現場に入る前に、元請から「グリーンファイルを○日までに出してください」と求められる。

##### 主な書類【Typical】

| 書類名 | 中身 | なぜ必要か |
|---|---|---|
| **再下請負通知書** | 自社がどの会社に再下請けさせるかを元請に知らせる書類 | 元請が施工体制台帳を作るために必要【Fact】 |
| **作業員名簿** | 現場に入る作業員の氏名、生年月日、保有資格、社会保険加入状況、雇用形態 | 誰が現場にいるかを元請が把握するため。労災時の対応にも使う |
| **施工体制台帳に係る再下請負通知書** | 2次以下の下請の情報 | 建設業法第24条の8に基づく施工体制台帳の記載事項【Fact】 |
| **工事安全衛生計画書** | その工事で想定される危険と対策 | 労働安全衛生法に基づく安全管理のため |
| **持込機械等使用届** | 現場に持ち込む機械・工具（高所作業車、電動工具等） | 機械の点検状況と有資格者の確認のため |
| **有資格者名簿・資格証の写し** | 玉掛け、高所作業車、足場組立作業主任者 等 | 資格が必要な作業に無資格者を就かせないため【Fact】 |
| **健康保険・厚生年金・雇用保険の加入状況** | 会社ごと・作業員ごとの加入状況 | 社会保険未加入対策として元請が確認する【Typical】 |
| **建設業許可証の写し** | 自社と協力会社の許可 | 許可のない会社に500万円以上の工事を出していないかの確認【Fact】 |

> **なぜこれだけの書類が必要なのか**
> `02_industry-structure.md` 11-2 で見たとおり、建設現場では**複数の会社の作業員が同時に働きます**。
> 事故が起きたとき「誰の会社の、誰が、どの資格で、何の作業をしていたか」が分からないと、
> 救護も原因究明も責任の所在の確定もできません。
> グリーンファイルは、**現場にいる全員を事前に把握しておくための仕組み**です【Inference】。

##### 施工体制台帳・施工体系図【Fact】

> **施工体制台帳（せこうたいせいだいちょう）**
> → その工事に関わるすべての下請会社・技術者・作業内容を記載した台帳。**元請が作成する**。
> → 実務例：元請が、1次下請・2次下請・3次下請まですべての会社名、
>   建設業許可番号、施工範囲、配置技術者、社会保険加入状況を一覧にする。

> **施工体系図（せこうたいけいず）**
> → 施工体制台帳の内容を、元請から下請への流れが分かる樹形図にしたもの。**現場に掲示する**。

【Fact】発注者から直接工事を請け負った特定建設業者は、その工事について締結した
**下請契約の総額が5,000万円以上（建築一式工事は8,000万円以上）**になる場合、
施工体制台帳と施工体系図を作成しなければなりません（建設業法第24条の8。
金額は2025年2月1日改正後／出典：国土交通省）。

> **モデル企業（下請）の立場では**：台帳を作るのは元請ですが、
> **その材料となる情報（自社と再下請の情報）を提供する義務**があります。
> これが上記の「再下請負通知書」です【Fact】。

##### 各種届出【Typical】

| 届出 | 提出先 | いつ |
|---|---|---|
| 道路使用許可 | 警察署 | 道路上に車両を停めて作業する場合。**法定・契約上のタイミング** |
| 道路占用許可 | 道路管理者 | 道路に足場等を設置する場合 |
| ビル管理者への工事申請 | ビル管理会社 | テナント工事の場合。館内規則に従う |
| 消防への届出 | 消防署 | 内装制限・防火対象物の用途変更等がある場合 |
| 建築確認・中間検査・完了検査 | 指定確認検査機関・特定行政庁 | 建築基準法上必要な場合【Fact】。通常は元請・設計者が対応 |
| 特定建設作業の届出 | 市区町村 | 騒音・振動規制法の対象作業を行う場合【Fact】 |

> **【Typical】下請の場合**：多くの届出は元請が行いますが、
> **道路使用許可やビル管理会社への搬入申請は、実際に作業する下請が行うこともあります**【Varies】。
> 誰が出すのかは着工前に必ず確認します。

#### S11｜資材の発注・搬入計画

| 項目 | 内容 |
|---|---|
| **きっかけ** | 施工計画・工程表の確定、施工図の承認 |
| **誰が** | ⑥ 資材調達・外注管理機能、③ 工事管理機能 |
| **受け取るもの** | 数量拾い表、施工図、工程表、実行予算（材料費の枠）、現地調査報告書（搬入条件） |
| **何を確認するか** | 材料の納期（特注品は数週間〜数か月かかることがある）、搬入可能日時、置き場の有無、支給材の有無 |
| **何をするか** | 建材商社に見積を取り、価格を決めて発注する。搬入日を工程に合わせて指定する |
| **作るもの** | **材料発注書**、納期管理表、搬入計画（いつ・何を・どのルートで） |
| **次に渡す先** | 建材商社・リース会社、③ 工事管理機能、⑦ 経理・財務機能（買掛の把握） |
| **頻度** | **発注時**（工程に合わせて分割発注されることが多い）【Typical】 |

> **なぜ「分割発注」になるのか**
> `02_industry-structure.md` 11-4 のとおり、現場には置き場がありません。
> 全量を一度に納入すると、置く場所がなく、他業者の作業の邪魔になり、
> 養生不良で材料が傷みます。そのため**工程に合わせて小刻みに納入**します【Typical】。

> **【Typical】注意すべきこと**
> - **特注品・長納期品の先行発注**：オーダーサッシ、特注家具、輸入建材などは、
>   施工図の承認後すぐに発注しないと工程に間に合わない
> - **支給材の確認**：元請支給か自社手配かで、材料費が原価に入るかどうかが変わる
>   （→ `02_industry-structure.md` 11-4）
> - **資材価格の変動**：見積時と発注時で単価が変わることがある。
>   【Fact】2025年12月完全施行の改正建設業法では、
>   **資材価格高騰の「おそれ情報」の通知義務**と**請負代金変更の協議に関する規定**が設けられています
>   （出典：国土交通省）

#### S12｜協力会社・職人の手配（労務手配）

| 項目 | 内容 |
|---|---|
| **きっかけ** | 工程表の確定 |
| **誰が** | ⑥ 資材調達・外注管理機能、③ 工事管理機能（現場代理人） |
| **受け取るもの** | 工程表、必要人工数（積算時に算出済み）、実行予算（外注費の枠） |
| **何を確認するか** | 協力会社の空き状況、必要な資格の保有、社会保険の加入状況、CCUS登録の有無 |
| **何をするか** | 協力会社に日程と作業内容を伝え、請負金額または人工単価を決めて発注する |
| **作るもの** | **協力会社への注文書**、労務手配表（どの日に誰が何人入るか） |
| **次に渡す先** | 協力会社・一人親方、⑤ 安全・品質管理機能（グリーンファイルへ反映） |
| **頻度** | **発注時**（工程の進捗に応じて調整が続く）【Typical】 |

> **【Fact】協力会社への発注時に確認が必要なこと**
> - **建設業許可**：500万円以上（建築一式は1,500万円以上）の工事を許可のない業者に発注できない
> - **書面での契約**：建設業法第19条の書面交付義務は、下請への発注にも適用される
> - **見積期間**：建設業法第20条・同施行令第6条の見積期間を確保する
> - **一括下請負にならないこと**：建設業法第22条（→ `02_industry-structure.md` 11-2）
> - **請負か常用か**：指揮命令の実態が偽装請負にならないようにする（→ 同 11-2）

> **【Typical】建設業の労務手配の難しさ**
> 職人は複数の会社の現場を掛け持ちしています。
> 前の現場が延びると、自社の現場に予定どおり入れません。
> 逆に、自社の前工程が遅れると、手配した職人が来ても仕事がない状態（**手待ち**）になります。
> **手待ちが発生しても人工代は発生します**。これが原価に直接効きます【Typical】。

#### S13｜着工・施工（日次の管理）

| 項目 | 内容 |
|---|---|
| **きっかけ** | 着工日 |
| **誰が** | ③ 工事管理機能（現場代理人 兼 主任技術者）、④ 現場作業機能（職長・職人）、⑤ 安全・品質管理機能 |
| **受け取るもの** | 施工計画書、工程表、施工図、実行予算書、労務手配表、納入された材料 |
| **何をするか** | 下記の日次サイクルを回す |
| **作るもの** | 作業日報、工事写真、KY記録、打合せ記録、是正記録 |
| **次に渡す先** | 元請（日々の報告）、⑦ 経理・財務機能（原価情報） |
| **頻度** | **日次**（工事期間中は毎日）【Typical】 |

##### 現場の1日（日次サイクル）【Typical】

```
 朝   ① 朝礼           元請主催。全業者が集合し、その日の作業内容・危険箇所を共有
      ② KY活動         その日の作業の危険を予知し、対策を確認する（危険予知活動）
      ③ 作業前点検     工具・機械・保護具・足場の点検
 日中 ④ 作業           職長が班を指揮して施工する
      ⑤ 品質確認       下地のピッチ、レベル、通り、ビス間隔などを確認
      ⑥ 工事写真       施工前・施工中・施工後を記録（後で見えなくなる部分は必ず撮る）
      ⑦ 他業者との調整 同じ場所で作業する電気・設備業者との取り合いを調整
 夕方 ⑧ 片付け・清掃   翌日の作業ができる状態にする
      ⑨ 作業日報       誰が何人、何をどこまで進めたかを記録
      ⑩ 翌日の段取り   材料・人員・作業場所を確認
```

##### 施工中に現場代理人が回す4つの管理

| 管理 | 見るもの | 頻度 | なぜ |
|---|---|---|---|
| **工程管理** | 工程表と実績の差、他業者の進捗 | **日次**（週間工程の見直しは**週次**）【Typical】 | 遅れが後工程に波及し、全体の完成日に影響するため |
| **品質管理** | 図面・仕様との一致、下地の状態 | **日次** | **仕上げてしまうと下地は見えなくなり、後から直せないため** |
| **原価管理** | 投入人工、材料の消費、実行予算との差 | **日次〜週次**【Varies】 | 工事完了後に気づいても取り返せないため |
| **安全管理** | 作業手順、保護具、危険箇所、整理整頓 | **常時** | 事故は一度起きると工事が止まり、人が傷つくため |

##### 工事写真がとくに重要な理由【Typical】

> 建設業では、完成すると見えなくなる部分（**隠蔽部／いんぺいぶ**）が大量にあります。
> 天井裏の下地、壁の中の配線、床下の配管、コンクリートの中の鉄筋——
> これらは完成後に目視では確認できません。
> そのため、**施工の各段階で写真を撮って記録を残すことが、品質の証明になります**。
> 公共工事では写真管理基準が契約上の要求事項となっています【Fact】。

#### S14｜出来高報告・出来高査定

ここは建設業に固有の重要な仕組みです。

##### 出来高払いとは

> **出来高（できだか）**
> → 工事全体のうち、その時点でどこまで完成しているかを金額で表したもの。
> → 実務例：請負金額1,500万円の工事で、月末時点で6割の作業が終わっていれば、
>   出来高は900万円となる。

> **出来高払い（できだかばらい／出来形部分払）**
> → 工事が完成する前に、できあがった分に応じて代金の一部を支払う方式。
> → 実務例：工期4か月の工事で、毎月末に出来高を確認し、その分を翌月に支払ってもらう。

> **なぜ出来高払いが必要なのか**
> 請負契約は本来「完成して引き渡してから代金を受け取る」のが原則です【Typical】。
> しかし工期が数か月〜数年に及ぶ建設業で完成まで一切入金がないと、
> **その間の材料費・外注費・給与をすべて自社の資金で立て替える**ことになります。
> 中小建設会社にとっては資金が持ちません。そのため出来高払いが広く行われています【Inference】。

##### プロセス

| 項目 | 内容 |
|---|---|
| **きっかけ** | 元請・発注者が定めた締日（月末が多い）【Typical】 |
| **誰が** | ③ 工事管理機能（現場代理人） |
| **受け取るもの** | 工程の実績、投入した人工の記録、施工済みの数量 |
| **何をするか** | 締日時点の施工済み数量を数え、出来高率（何%進んだか）を算出して元請に報告する |
| **何が起きるか** | **元請が現場を確認し、出来高を査定（認定）する。** 自社の申請どおりに認められるとは限らない【Typical】 |
| **作るもの** | **出来高報告書**、出来高内訳書 |
| **次に渡す先** | 元請 → 査定結果を受けて ⑦ 経理・財務機能（請求へ） |
| **頻度** | **月次**（元請の締日に合わせる）【Typical】 |

> **【重要】出来高査定という仕組み**
> 下請が「70%進んだ」と報告しても、元請が現場を見て「60%」と査定すれば、
> その月に請求できるのは60%分です。
> このため、**出来高の根拠（施工済み数量、写真、日報）を示せる状態にしておくこと**が実務上重要になります【Typical】。

> **【Fact】元請の支払義務**
> 元請は、注文者から出来形部分に対する支払を受けたときは、
> その支払の対象となった工事を施工した下請負人に対して、
> **その支払を受けた日から1か月以内**に下請代金を支払わなければなりません（建設業法第24条の3）。
> また**特定建設業者**は、下請（資本金4,000万円以上の法人を除く）から工事目的物の
> **引渡しの申出があった日から50日以内**に下請代金を支払わなければなりません（建設業法第24条の6）。

#### S15｜契約変更（設計変更・追加工事）の処理

建設業の実務で最も揉めやすいステップです。

| 項目 | 内容 |
|---|---|
| **きっかけ** | 発注者の要望変更／図面の不整合の発覚／現場条件が図面と違った／他業者との取り合いの変更 |
| **誰が** | ③ 工事管理機能（現場代理人）、② 積算・見積機能、① 営業機能、代表取締役 |
| **受け取るもの** | 変更指示、変更図面、現場での発見事項 |
| **何をするか** | 変更内容を確認し、**数量と金額の増減を算出し、変更見積を提出し、承認を得てから施工する** |
| **作るもの** | **変更見積書**、変更指示記録、**変更契約書または変更注文書・注文請書** |
| **次に渡す先** | 元請・発注者 → 承認後、③ 工事管理機能（施工へ）、⑦ 経理・財務機能 |
| **頻度** | **案件発生時**（規模の大きい工事ほど発生しやすい）【Typical】 |

##### 用語の整理

> **設計変更（せっけいへんこう）**
> → 発注者・設計者の判断で、当初の設計内容が変わること。
> → 実務例：「やはり会議室の壁をガラスパーティションに変更したい」

> **追加工事（ついかこうじ）**
> → 当初の契約範囲になかった工事を追加で行うこと。
> → 実務例：解体してみたら既存下地が腐っていたため、下地の作り直しが必要になった

> **手戻り（てもどり）**
> → すでに施工した部分を、やり直すこと。
> → 実務例：ボードを張った後に、中に配管を通す必要があると判明し、剥がしてやり直す

##### なぜここが揉めるのか【Typical】

```
現場では：「工期が迫っている。今やらないと間に合わない」
           ↓
        書面を交わす前に、口頭の指示で先に施工してしまう
           ↓
        後から「それは当初の契約範囲に含まれている」と言われる
           ↓
        追加費用を請求できない
```

> **【Fact】法律上の建て付け**
> 建設業法第19条は、**設計変更等による工期の変更・請負代金の額の変更の取扱いを
> 契約書面に記載すること**を求めています。
> また第19条第2項は、**請負契約の内容を変更するときは、変更の内容を書面に記載し、
> 署名または記名押印して相互に交付しなければならない**としています。
> つまり**変更も書面で行うのが法律上の建て付け**です。

> **【Typical】実務での基本動作**
> 1. 変更の指示は、口頭で受けても**記録（メール・打合せ記録・工事日報）に残す**
> 2. 数量と金額の増減を出し、**変更見積を提出する**
> 3. **承認を得てから施工する**（緊急でやむを得ず先行する場合も、記録は必ず残す）
>
> 本資料は改善提案を行いませんが、この3手順が業界で「変更の基本」とされている実務です。

> **【Fact】2025年12月完全施行の改正建設業法**では、
> **契約書における請負代金等の変更方法の明確化**、資材価格高騰時の
> **「おそれ情報」の通知義務**と**協議に関する規定**が新設されています（出典：国土交通省）。

#### S16｜自主検査・社内検査

| 項目 | 内容 |
|---|---|
| **きっかけ** | 自社工事の完了 |
| **誰が** | ③ 工事管理機能（現場代理人）、⑤ 安全・品質管理機能 |
| **受け取るもの** | 設計図書、仕様書、施工計画書、チェックリスト |
| **何を確認するか** | 図面・仕様どおりにできているか、傷・汚れ・不陸（凹凸）・建具の建付け・仕上げの精度 |
| **何をするか** | 全数または抜取りで確認し、不具合を記録して直す |
| **作るもの** | **自主検査記録**、是正リスト（ダメ出しリスト）、是正完了の記録 |
| **次に渡す先** | 元請（検査依頼） |
| **頻度** | **納品時**（工事完了時。工程の区切りごとに中間で行うこともある）【Typical】 |

> **なぜ先に自分で検査するのか**
> 元請や発注者の検査で大量の指摘が出ると、是正に時間がかかり、引渡し日に間に合いません。
> また、指摘の多さは次の受注機会に影響します【Typical】。
> **自分で見つけて自分で直してから検査に出す**のが基本動作とされています。

> **ダメ出し／ダメ工事（だめこうじ）**
> → 検査で指摘された不具合を直す作業のこと。「ダメ直し」「手直し」ともいう。
> → 実務例：クロスの継ぎ目の浮き、建具の建付け不良、塗装のムラなどを一覧にして、
>   一つずつ直して消し込んでいく。

---

#### S17｜元請検査・施主検査（竣工検査）・是正

| 項目 | 内容 |
|---|---|
| **きっかけ** | 自主検査の完了、検査日の設定 |
| **誰が** | 元請の現場所長、工事監理者（設計事務所）、発注者、③ 工事管理機能（立会い） |
| **受け取るもの** | 検査の日程、検査基準 |
| **何をするか** | 検査に立ち会い、指摘事項を記録し、期限までに是正する |
| **作るもの** | 検査記録、是正報告（写真付き） |
| **次に渡す先** | 元請・発注者（是正完了報告） |
| **頻度** | **納品時**【Typical】 |

##### 検査の段階【Typical】

```
 ① 自主検査（自社）         ← S16
 ② 元請検査（元請の現場所長） ← 下請の場合はここが主な検査
 ③ 工事監理者の検査（設計事務所）
 ④ 施主検査（発注者）        ← 竣工検査・完成検査
 ⑤ 行政・確認検査機関の検査  ← 建築基準法上の完了検査等【Fact】（元請・設計者が対応）
```

> **【Varies】検査の段階数と厳しさは、発注者・元請・工事の性格によって大きく異なります。**
> 公共工事では検査項目と記録の要求が契約上定められています【Typical】。

---

#### S18｜引渡し

| 項目 | 内容 |
|---|---|
| **きっかけ** | 検査合格、是正完了 |
| **誰が** | ③ 工事管理機能、① 営業機能、⑧ 人事・総務機能（書類） |
| **受け取るもの** | 検査合格の確認 |
| **何をするか** | 完成した工事目的物を引き渡し、必要書類を提出する |
| **作るもの** | **完成引渡書**、**竣工図**（実際に施工した状態の図面）、施工記録・工事写真、材料の証明書（不燃材料認定等）、保証書、取扱説明書、鍵の引渡し記録 |
| **次に渡す先** | 元請・発注者、⑦ 経理・財務機能（請求へ） |
| **頻度** | **納品時** |

> **【重要】引渡しの意味**
> 引渡しによって、
> ・**工事目的物の管理責任が発注者に移る**
> ・**請負代金の請求ができるようになる**
> ・**契約不適合責任（瑕疵担保）の期間が始まる**
> の3つが同時に起こります【Typical】。
> だから「いつ引き渡したか」は、建設業ではきわめて重要な日付です。

> **竣工図（しゅんこうず）**
> → 実際に施工された状態を反映した最終版の図面。
> → 実務例：設計図から変更になった箇所（配管ルートの変更、下地の追加等）を反映して作り直す。
> → **なぜ必要か**：後から改修や修繕をするとき、実際にどう作られているかが分からないと工事ができないため。

---

#### S19｜請求

| 項目 | 内容 |
|---|---|
| **きっかけ** | 出来高の査定確定（月次）、または引渡しの完了 |
| **誰が** | ⑦ 経理・財務機能、③ 工事管理機能（出来高の根拠） |
| **受け取るもの** | 査定済みの出来高、完成引渡書、注文書・注文請書、変更契約 |
| **何を確認するか** | 契約金額＋変更分の合計と請求額が一致するか、締日と支払日、請求書の様式 |
| **何をするか** | 請求書を作成し、元請・発注者の指定する方法・期日までに提出する |
| **作るもの** | **請求書**、**工事完成高の計上**（会計処理） |
| **次に渡す先** | 元請・発注者、⑦ 経理・財務機能（売掛金の管理） |
| **頻度** | **請求時**（出来高請求は**月次**、完成請求は**納品時**）【Typical】 |

> **【重要】受注 ≠ 売上 ≠ 入金**
> | 段階 | 何が起きたか | 会計上 |
> |---|---|---|
> | 受注（S7） | 注文を受けた | **まだ売上ではない** |
> | 施工中（S13） | 原価は発生している | 未成工事支出金（資産）に計上【Typical】 |
> | 出来高／完成（S14/S18） | できあがった分が確定 | 完成工事高（売上）を計上 |
> | 請求（S19） | 請求書を出した | **売掛金（完成工事未収入金）** が立つ |
> | 入金（S20） | お金が入った | 現預金になる |
>
> **売上が立った時点では、まだお金は入っていません。** これが建設業の資金繰りの起点です。
> 詳細は `08_money.md` `12_business-model.md` で扱います。

#### S20｜入金・支払・原価確定

| 項目 | 内容 |
|---|---|
| **きっかけ** | 請求書の提出、支払日の到来 |
| **誰が** | ⑦ 経理・財務機能、代表取締役 |
| **受け取るもの** | 入金（振込／手形）、協力会社・建材商社からの請求書 |
| **何を確認するか** | 請求額と入金額が一致するか（査定減・相殺がないか）、支払日、手形のサイト |
| **何をするか** | 入金を消し込む／協力会社・仕入先に支払う／工事別原価を締めて実行予算と比較する |
| **作るもの** | 入金記録、支払記録、**工事別原価の実績（原価確定表）**、実行予算対比 |
| **次に渡す先** | ② 積算・見積機能（次回見積の精度向上のための実績歩掛）、代表取締役（工事別損益の報告） |
| **頻度** | **入金時**／支払は**月次**／原価確定は工事完了時【Typical】 |

##### 入金と支払のタイミングのズレ

```
 【下請の立場】
 　1月：材料を仕入れ、職人に作業してもらう（原価が発生）
 　2月：職人・協力会社に支払う（★お金が出ていく）
 　1月末：出来高を報告
 　2月：元請に請求
 　3月末：元請から入金（★お金が入る）

 　→ 支払が先、入金が後。この間の資金を自社で用意する必要がある【Typical】
```

> **【Fact】建設業法上の支払ルール（再掲）**
> - 元請は、注文者から支払を受けた日から**1か月以内**に下請代金を支払う（第24条の3）
> - 特定建設業者は、下請から引渡しの申出があった日から**50日以内**に支払う（第24条の6）
> - 特定建設業者は、前払金を受けたときは下請への前払金の支払に適切な配慮をする（第24条の3第3項）

> **【Typical】手形による支払**
> 建設業では手形による支払が行われることがあります。
> 手形は「一定期間後に現金化できる証券」で、受け取っても**すぐには現金になりません**。
> 手形サイト（振出から支払期日までの期間）の長さが、資金繰りに直結します。
> 【Fact】国土交通省は手形期間（サイト）のルールについて指針を示しています
> （出典：国土交通省「手形による下請代金の支払」）。詳細は `08_money.md` で扱います。

##### 原価確定と振り返り

工事完了後、**実行予算（S8）と実際の原価を突き合わせます**。

| 見る項目 | なぜ見るか |
|---|---|
| 費目別の予算と実績の差 | どこで差が出たか（材料か、外注か、人工か）を特定するため |
| 実際に投入した人工数 | 次の見積の**歩掛**を更新するため |
| 手待ち・手戻りの発生状況 | 何が原価の増加要因だったかを記録するため |
| 変更工事の請求漏れ | 請求できたはずの変更が漏れていないかを確認するため |

> **なぜ振り返るのか**：建設業は1件ごとに原価が違うため、
> **実績を積み上げなければ次の見積の精度が上がりません**。
> S4 で述べた「歩掛の精度が見積精度そのもの」は、このステップで支えられています【Inference】。

#### S21｜瑕疵（契約不適合）対応・アフター

| 項目 | 内容 |
|---|---|
| **きっかけ** | 発注者・元請・入居者からの不具合の連絡 |
| **誰が** | ③ 工事管理機能、④ 現場作業機能、① 営業機能 |
| **受け取るもの** | 不具合の内容、発生時期、現場の状況 |
| **何を確認するか** | 自社の施工範囲か／施工に起因するものか、経年劣化や使用方法によるものか、保証期間内か |
| **何を判断するか** | 無償で直すか、有償の修繕として見積を出すか |
| **何をするか** | 現地を確認し、原因を特定し、是正する |
| **作るもの** | 不具合対応記録、是正完了報告、（有償の場合は）修繕の見積書 |
| **次に渡す先** | 発注者・元請、① 営業機能（次の改修工事の機会になることがある）【Typical】 |
| **頻度** | **トラブル発生時**／定期点検を契約している場合は**年次**等【Varies】 |

> **【Fact】契約不適合責任**
> 引き渡された工事目的物が契約の内容に適合しない場合、
> 請け負った側は修補等の責任を負います（民法）。
> **新築住宅**については、住宅品質確保促進法により、
> 構造耐力上主要な部分等について**10年間**の瑕疵担保責任が義務づけられています【Fact】。
> 具体的な保証期間・範囲は契約によって定められます【Varies】。

> **【Typical】アフターが次の仕事につながる**
> 不具合の対応や小さな修繕への対応が、次の改修工事の引合い（S1）につながることがあります。
> `01_overview.md` 1-2 で述べた「維持管理・改修」が建設業の重要な仕事であるというのは、
> フローの上ではこの循環を指します。

| S17 元請検査・施主検査 | 納品時 |
| S18 引渡し | 納品時 |
| S19 請求 | 請求時（出来高請求は月次、完成請求は納品時） |
| S20 入金・支払・原価確定 | 入金時／支払は月次／原価確定は工事完了時 |
| S21 瑕疵対応・アフター | トラブル発生時／定期点検は年次等【Varies】 |

## 4-5 【Example】1工事を最初から最後まで追跡する

> ⚠️ **以下はすべて説明用の架空の事例です。実在する工事・企業・金額ではありません。**
> 日付は「着工日を基準とした相対日」で示し、曜日・特定の日付は使いません。

### 案件の概要【Example】

| 項目 | 内容 |
|---|---|
| **工事名** | ○○ビル 5階テナント内装工事（架空） |
| **場所** | 首都圏の8階建てオフィスビルの5階（延べ床 約400㎡） |
| **発注者** | ビルオーナー（不動産会社） |
| **元請** | 中堅ゼネコンG社 |
| **モデル企業の立場** | **1次下請**（内装仕上工事を担当） |
| **工事内容** | 既存内装の解体、軽量鉄骨下地・ボード張りによる間仕切り、クロス張り、タイルカーペット敷設 |
| **請負金額** | **1,500万円**（税別） |
| **工期** | 約2か月 |
| **配置** | 現場代理人 兼 主任技術者 1名（他2現場と兼務。請負金額4,500万円未満のため専任不要） |

### 時系列【Example】

#### 〈着工の約8週間前〉S1：引合い

元請G社の工事部から、**① 営業機能**にメールで見積依頼が届いた。
添付は平面図・天井伏図・仕上表・展開図と、見積提出期限（2週間後）。
営業担当が引合い台帳に登録し、担当を工事管理機能のA（現場代理人）に割り当てた。

#### 〈着工の約8週間前〉S2：受け・不受けの判断

代表取締役とAで検討。
・工期が、Aが担当中の別現場の完了直後であること
・必要な人工が確保できる見込みであること
・G社とは継続取引があり支払条件が明確であること
を確認し、**見積を出すと判断**した。

#### 〈着工の約7週間前〉S3：現場調査

Aと積算担当Bが現地へ。以下を確認した。

| 確認項目 | 結果 | 見積への影響 |
|---|---|---|
| 既存壁の解体量 | 図面より2か所多い | 解体の人工と廃材処分費が増える |
| 荷揚げ | 人荷用エレベーターが使えるが、寸法に制約あり | ボードを3×6板から3×8板に変えられない → 継ぎ目が増え手間が増える |
| 作業時間 | 平日9:00〜18:00のみ。解体・斫り作業は他テナントの営業を考慮し朝夕に制限 | 解体の日数が延びる |
| 資材置き場 | 5階フロア内に仮置き可 | 分割納入の回数を減らせる |
| 廃材搬出 | 荷捌き場が1階に1か所、時間指定あり | 搬出の手間を見込む |

#### 〈着工の約6週間前〉S4：積算

積算担当Bが数量を拾った。

| 項目 | 数量 | 備考 |
|---|---|---|
| 間仕切り壁（軽量鉄骨下地＋ボード両面） | 約180㎡ | |
| クロス張り | 約620㎡ | 壁・天井 |
| タイルカーペット | 約340㎡ | |
| 既存解体 | 約60㎡ | 現調で判明した追加分を含む |
| 必要人工（合計） | 約110人工 | 社内の歩掛から算出 |

#### 〈着工の約5週間前〉S5：見積提出

原価を積み上げ、一般管理費と利益を乗せて **1,620万円** で提出。
見積条件書に「既存の不陸調整は別途」「軽微な補修を超える下地補修は別途」
「夜間・休日作業は含まない」「有効期限30日」を明記した。

#### 〈着工の約4週間前〉S6：価格折衝

元請G社の査定は 1,450万円。
Aが「解体量が図面より多い」根拠を現調写真とともに説明し、
タイルカーペットのグレードを1段階下げる代替案を提示。
**1,500万円で合意**した。

#### 〈着工の約3週間前〉S7：受注確定

G社から**注文書**（工事名・請負金額1,500万円・工期・支払条件：月末締め翌々月末払い）を受領。
内容を確認し、**注文請書**に記名押印して返送。
経理が工事番号を採番し、社内の工事台帳に登録した。

#### 〈着工の約3週間前〉S8：実行予算【Example】

| 費目 | 予算 | 内訳 |
|---|---|---|
| 材料費 | 375万円 | LGS、ボード、クロス、タイルカーペット、副資材 |
| 外注費 | 600万円 | 解体、クロス、床仕上げの各協力会社 |
| 労務費（自社） | 150万円 | 自社職人による軽鉄・ボード工事 |
| 現場経費 | 150万円 | 運搬、廃材処分、駐車場、養生材、現場管理工数の一部 |
| **原価 計** | **1,275万円** | |
| **工事総利益** | **225万円（15.0%）** | |

#### 〈着工の約2週間前〉S9〜S10：着工準備

- 施工計画書と工程表を作成し、元請G社に提出して承認を受けた
- **配置技術者**：現場代理人A（主任技術者を兼ねる）を届出
- 施工図（間仕切りの割付、開口部の補強、設備との取り合い）を作成し、元請と工事監理者の承認を受けた
- **グリーンファイル**を作成：作業員名簿（自社8名、協力会社12名）、再下請負通知書、
  有資格者証の写し、社会保険加入状況、持込機械等使用届
- ビル管理会社へ工事申請を提出（搬入時間・エレベーター使用の予約）

#### 〈着工の約1週間前〉S11〜S12：発注と手配

- 建材商社へ LGS・ボード・クロス・タイルカーペットを発注。
  **工程に合わせて3回に分けて搬入する**よう納期を指定
- 解体業者、クロス業者、床工事業者へ**注文書**を発行（見積期間を確保したうえで）
- 労務手配表を作成し、各社に入場日を連絡。CCUSの登録状況を確認

#### 〈着工日〉S13：着工

元請の朝礼に参加。工事看板・施工体系図の掲示を確認。
Aは他2現場と掛け持ちのため、**午前は本現場、午後は別現場**という回り方をする日もあった。
職長が班を指揮し、解体から着手。

#### 〈着工から約2週間後〉S15：契約変更が発生【Example】

既存壁を解体したところ、**壁内に図面にない古い配管が残っていた**ことが判明。
Aは元請G社の現場所長に即日報告し、写真を送付。
撤去範囲と費用（**18万円**）の変更見積を提出。
2日後に元請から**変更注文書**を受領し、施工した。

> この案件では書面を先に交わせたが、**口頭指示で先行着手して後から書面**という進み方になることもある【Typical】。
> その場合でも、指示内容と日付を記録に残すのが実務上の基本動作とされている。

#### 〈着工から約4週間後（月末）〉S14：出来高報告

締日時点で、解体・軽鉄下地・ボード張りが完了し、クロスが3割進行。
Aは施工済み数量を集計し、**出来高55%（825万円）**として元請に報告。
元請の現場所長が現場を確認し、**出来高52%（780万円）**で査定された。
（クロスの進捗の見方が異なったため）

#### 〈着工から約5週間後〉S19（1回目）：出来高請求

経理が **780万円**の請求書をG社に提出。

#### 〈着工から約7週間後〉S16：自主検査

工事がほぼ完了。Aと安全・品質管理担当が自主検査を実施。
クロスの継ぎ目の浮き6か所、巾木の隙間3か所、カーペットの端部処理2か所の
計11か所を是正リストに記載し、2日で是正を完了した。

#### 〈着工から約8週間後〉S17：元請検査・施主検査

元請G社の検査で指摘4か所。翌日に是正完了。
その後の施主（ビルオーナー）検査では指摘1か所。当日中に是正。

#### 〈着工から約8週間後〉S18：引渡し

元請G社に引き渡し、下記を提出した。

```
・完成引渡書
・竣工図（施工図に変更を反映したもの）
・工事写真（施工前／施工中／施工後。隠蔽部を含む）
・使用材料の証明書（不燃材料認定証、ホルムアルデヒド等級の証明）
・是正完了報告
```

#### 〈着工から約8週間後〉S19（2回目）：完成請求

契約金額1,500万円＋変更18万円＝**1,518万円**。
うち出来高請求済み780万円を差し引き、**738万円**を請求。

#### 〈着工から約12週間後〉S20：入金・支払・原価確定

- G社の支払条件（月末締め翌々月末払い）に従い、**1回目の出来高分780万円が入金**
- 協力会社・建材商社への支払は、入金より先に完了していた
- 工事完了後、実行予算と実績を突き合わせた【Example】

| 費目 | 予算 | 実績 | 差 | 差の理由 |
|---|---|---|---|---|
| 材料費 | 375万円 | 382万円 | **▲7万円** | ボードの端材が想定より多く出た |
| 外注費 | 600万円 | 611万円 | **▲11万円** | 解体の追加分（変更工事で回収済み） |
| 労務費 | 150万円 | 168万円 | **▲18万円** | 荷揚げの制約で搬入に手間がかかった |
| 現場経費 | 150万円 | 144万円 | ＋6万円 | 廃材処分量が想定を下回った |
| **原価 計** | **1,275万円** | **1,305万円** | **▲30万円** | |
| **請負金額** | 1,500万円 | **1,518万円** | ＋18万円 | 変更工事分 |
| **工事総利益** | 225万円（15.0%） | **213万円（14.0%）** | ▲12万円 | |

- **② 積算・見積機能**へ実績の歩掛（「このビル形状・この搬入条件なら軽鉄・ボードは何人工か」）を申し送り

#### 〈引渡しから約3か月後〉S21：瑕疵対応

入居テナントから「会議室のクロスに1か所浮きがある」と元請経由で連絡。
Aが現地を確認。施工に起因すると判断し、**無償で是正**。
同時に「隣のフロアも同様の内装にしたい」という相談を受け、
**① 営業機能**へ引き継いだ（→ 新たな S1 へ）。

## 4-6 このフローで押さえるべき建設業固有の要素（まとめ）

| 要素 | どのステップで登場するか | なぜ重要か |
|---|---|---|
| **工期** | S5, S7, S9, S13 | 金額と不可分。工期が短ければ応援が必要になり原価が上がる。著しく短い工期は建設業法第19条の5で禁止【Fact】 |
| **積算・歩掛** | S4, S20 | 1件ごとに価格を出す建設業の中核技能。実績の蓄積が精度を決める |
| **実行予算** | S8, S13, S20 | 「取るための金額（見積）」と「守るための金額（実行予算）」は別物 |
| **注文書・注文請書** | S7, S12, S15 | 建設業の契約の実務形態。書面交付義務がある【Fact】 |
| **見積期間** | S1, S12 | 建設業法第20条・施行令第6条で下限が法定【Fact】 |
| **配置技術者** | S9 | 建設業法第26条の必置義務。専任要件が同時受注数の上限を決める【Fact】 |
| **グリーンファイル（安全書類）** | S10 | 現場にいる全員を事前に把握するための仕組み |
| **施工体制台帳・施工体系図** | S10 | 元請の作成義務。下請は情報提供の義務を負う【Fact】 |
| **出来高払い・出来高査定** | S14, S19 | 完成前に資金を回収する仕組み。査定により申請どおりとは限らない |
| **契約変更（設計変更・追加工事）** | S15 | 建設業で最も揉めやすい。書面での変更が法律上の建て付け【Fact】 |
| **建設業法の支払い規定** | S20 | 1か月以内（第24条の3）、特定建設業者は50日以内（第24条の6）【Fact】 |
| **隠蔽部の工事写真** | S13, S18 | 完成後に確認できない部分の品質を証明する唯一の手段 |
| **引渡し** | S18 | 管理責任の移転・請求権の発生・契約不適合責任の起算が同時に起こる |
