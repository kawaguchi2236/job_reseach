# 04_end-to-end-process.md — 不動産業の全社End-to-End業務フロー

**対象**：日本国内の中小不動産業（モデル企業：株式会社ミナト不動産）
**読み手**：不動産業をまったく知らない人
**最終更新**：2026-09-17

> 会社設定・機能名は `03_company-structure.md` を前提とします。
> 法令・告示の根拠は `02_industry-structure.md` で条文を確認済みのものを参照しています。

---

## 4-0【最初に】不動産業のフローは1本では描けない

### なぜ2本に分けるのか

製造業なら「受注 → 生産 → 納品 → 請求 → 入金」という1本の流れで説明できます。
しかし不動産業では、**類型によってフローが根本的に違います**。

| | A. 賃貸仲介＋管理 | B. 売買仲介 |
|---|---|---|
| **1件の期間** | 問い合わせから入居まで**1〜3週間**【Typical】、その後の管理は**数年〜十数年続く** | 媒介契約から決済まで**3〜6か月**【Typical】、終わったら終わり |
| **1件の金額** | 仲介手数料は家賃1か月分（上限）／管理料は毎月 | 仲介手数料は数十万〜数百万円 |
| **成約後に仕事が続くか** | **続く**（入居後の管理がここから始まる） | **終わる**（アフター対応を除く） |
| **お金の受け取り** | 契約時に初期費用一括、以後毎月 | 契約時と決済時に分けることが一般的【Varies】 |
| **登記が動くか** | 動かない（占有が移るだけ） | **動く**（所有権移転登記） |
| **関わる外部者** | 保証会社、火災保険、原状回復業者 | 金融機関、司法書士、土地家屋調査士、法務局 |

> **したがって本章では、AとBを完全に分けて書きます。**
> 「不動産業の業務フロー」として1本にまとめると、どちらの実態も説明できなくなるからです。
>
> なお `01_overview.md` の5類型のうち **④不動産開発・分譲** と **⑤自社所有賃貸** のフローは
> `02_industry-structure.md` 11-3 に概略を示しています。中小企業の主戦場ではないため、本章では扱いません。

### 2本のフローが同じ会社の中で同時に走っている

```
  【フローA：賃貸】1〜3月に案件が集中し、成約すると管理業務が積み上がっていく
   ▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░  （仲介：季節変動が大きい）
   ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒  （管理：毎月ずっと続く）

  【フローB：売買】年間12件。1件あたり3〜6か月かかる
   ──■────■──────■───■─────■──■────  （成約はまばら）

   1月   3月   5月   7月   9月   11月
```

【Typical】賃貸の繁忙期（1〜3月）には、フローAの前半（仲介）と、
入居に伴う管理の立ち上げ、さらに3月の退去ラッシュへの対応が同時に発生します。
【Inference】そこにフローBの重要事項説明や決済が重なると、宅建士が関わる予定が一点に集中します。

## 4-1【フローA】賃貸仲介 ＋ 入居後の管理

### 全体図

```
 ── 前半：仲介（単発。問い合わせから鍵渡しまで 1〜3週間）【Typical】──────────

 A-01 募集の開始         オーナーと募集条件を決め、募集を始める
   ↓
 A-02 広告掲載           ポータルサイト・店頭・業者間へ情報を出す
   ↓
 A-03 問い合わせ対応     電話・メール・来店の応対、希望条件のヒアリング
   ↓
 A-04 内見案内           鍵を持って現地へ案内する
   ↓
 A-05 入居申込の受付     入居申込書を受け取る
   ↓
 A-06 入居審査           貸主・管理会社・保証会社が可否を判断する
   ↓
 A-07 重要事項説明       【法定】宅建士が契約成立前に説明する
   ↓
 A-08 賃貸借契約の締結   契約書に署名押印、37条書面の交付
   ↓
 A-09 初期費用の入金確認 敷金・礼金・前家賃・仲介手数料・保証料・保険料
   ↓
 A-10 鍵の引渡し         入居開始。ここで仲介の仕事は完了
   ↓
 A-11 仲介手数料・ADの精算

 ── 後半：管理（継続。入居している限りずっと続く）─────────────────────

 A-12 家賃の入金確認      ────┐
 A-13 滞納督促                │
 A-14 オーナーへの送金        │  毎月繰り返す
 A-15 入居者対応・修繕手配    │
 A-16 オーナーへの定期報告 ───┘
   ↓
 A-17 契約更新            契約期間の満了前（【法定・契約上のタイミング】）
   ↓
 A-18 解約の受付          借主から解約の申入れがあったとき
   ↓
 A-19 退去立会い          鍵の返却、室内の状態確認
   ↓
 A-20 原状回復の範囲判定・見積
   ↓
 A-21 敷金精算            返還または請求
   ↓
 A-22 原状回復工事の手配
   ↓
 A-01 へ戻る（再募集）
```

---

### 各ステップの詳細

#### A-01 募集の開始

| 項目 | 内容 |
|---|---|
| **きっかけ** | 退去予告を受けたとき／新築物件の管理を受託したとき／オーナーから空室の相談があったとき |
| **誰が** | 【オーナー対応機能】＋【賃貸管理機能】 |
| **何を受け取るか** | 解約通知書（借主から）、オーナーの意向、前回の募集条件、周辺の募集事例 |
| **何を確認するか** | 退去予定日／原状回復の完了見込み／周辺相場と比べた家賃水準／設備の状況 |
| **何をするか** | 募集条件（家賃・共益費・敷金・礼金・フリーレント・AD・入居条件）をオーナーに提案し、合意を得る |
| **何を判断するか** | 家賃を据え置くか下げるか／礼金をなくすか／ADを付けるか／ペット可などの条件変更をするか |
| **誰と連携するか** | オーナー、原状回復業者（いつ仕上がるか） |
| **できあがるもの** | **募集条件の合意**（書面またはメール）、募集図面（マイソク）の原案 |
| **次に渡す先** | 【販促・集客機能】 |
| **頻度** | 案件発生時（退去の申出があったつど） |

> **募集図面（マイソク）**
> → 1枚の紙に**間取り図・写真・家賃・敷金礼金・住所・最寄駅・設備・取引態様・広告料の有無**などをまとめた、
>    業者間で使われる物件資料のことです。
> → 実務例：他社の営業担当は、この1枚を見て「自分のお客さんに紹介できるか」を判断し、
>    元付業者に空室確認の電話をかける。

> **フリーレント**
> → 入居後の一定期間（例：1か月）の家賃を無料にする条件のことです。
> → 実務例：家賃を下げると以後ずっと収入が減るが、フリーレント1か月なら初回だけの負担で済む。
>    空室期間を短くするための条件として使われます。【Varies】採用するかどうかは物件・オーナーにより異なります。

---

#### A-02 広告掲載

| 項目 | 内容 |
|---|---|
| **きっかけ** | 募集条件が確定したとき |
| **誰が** | 【販促・集客機能】 |
| **何を受け取るか** | 募集条件、間取り図、室内写真、設備リスト |
| **何を確認するか** | 【Fact】**誇大広告に当たらないか**（宅地建物取引業法第32条：著しく事実に相違する表示、実際より著しく優良・有利と誤認させる表示の禁止）／**取引態様の明示**／写真が現況と一致しているか |
| **何をするか** | 不動産ポータルサイトへの掲載、自社サイト掲載、店頭貼り出し、業者間ネットワーク・レインズへの情報提供 |
| **誰と連携するか** | 他の宅建業者（客付業者） |
| **できあがるもの** | 掲載広告、募集図面（マイソク） |
| **次に渡す先** | 【賃貸仲介機能】（問い合わせが来る） |
| **頻度** | 案件発生時。掲載後は常時（内容の更新・成約時の掲載停止） |

> **成約したら掲載を止める必要がある理由**
> 【Typical】すでに決まった部屋を掲載し続けると、問い合わせた人を無駄に動かすことになります。
> 【Fact】広告について宅地建物取引業法第32条は誇大広告等を禁止しています。

---

#### A-03 問い合わせ対応

| 項目 | 内容 |
|---|---|
| **きっかけ** | 電話・メール・ポータルサイト経由・飛び込み来店 |
| **誰が** | 【賃貸仲介機能】（受付パートが一次対応することもある）【Varies】 |
| **何を受け取るか** | 問い合わせ内容（物件名、希望条件） |
| **何を確認するか** | **その部屋がまだ空いているか**（元付業者への空室確認）／希望条件（エリア・家賃上限・間取り・入居希望日・勤務先・同居人・ペット・駐車場） |
| **何をするか** | 条件に合う物件を複数提示し、内見の日程を決める |
| **何を判断するか** | 希望条件と予算が合っているか／条件を満たす物件が自社管理物件にあるか、他社物件を紹介するか |
| **誰と連携するか** | 他社（元付業者）、オーナー（鍵の所在） |
| **できあがるもの** | 内見の予約、提案物件のリスト |
| **次に渡す先** | 【賃貸仲介機能】（内見案内へ） |
| **頻度** | 問い合わせ時（繁忙期は日次で多数） |

> **なぜ「空室確認」が必要なのか**
> 【Typical】ポータルサイトの情報には、すでに申込みが入った物件が残っていることがあります。
> 案内した先で「実は決まっていた」となれば顧客の時間を無駄にするため、
> 案内の前に元付業者へ電話・メールで現況を確認する作業が発生します。

---

#### A-04 内見案内

| 項目 | 内容 |
|---|---|
| **きっかけ** | 内見予約の日時 |
| **誰が** | 【賃貸仲介機能】 |
| **何を受け取るか** | 鍵（自社管理物件なら自社のキーボックス、他社物件なら元付業者から借りる） |
| **何を確認するか** | 鍵の持ち出し記録／現地までの経路／室内の状態（清掃されているか）／設備の動作 |
| **何をするか** | 現地へ案内し、部屋・共用部・周辺環境を見てもらう。質問に答える |
| **何を判断するか** | その場で申込みに進むか／別の物件も見るか |
| **誰と連携するか** | 元付業者（鍵の返却）、オーナー（在室中の物件の場合は日程調整） |
| **できあがるもの** | 内見の結果（申込む／見送る）、鍵の返却記録 |
| **次に渡す先** | 【賃貸仲介機能】（申込受付へ） |
| **頻度** | 案件発生時（繁忙期は1日に複数件） |

> **鍵の扱いが業務上の管理対象になる理由**
> 【Typical】1日に複数件を案内すると、複数の物件の鍵を同時に持ち歩くことになります。
> 返し忘れ・紛失はそのまま入居者の安全とコストに直結するため、持ち出しと返却の記録が必要になります。

---

#### A-05 入居申込の受付

| 項目 | 内容 |
|---|---|
| **きっかけ** | 内見後、借主候補が「この部屋にしたい」と意思表示したとき |
| **誰が** | 【賃貸仲介機能】 |
| **何を受け取るか** | **入居申込書**（申込者の氏名・住所・生年月日・勤務先・年収・連帯保証人・緊急連絡先・入居予定者）、本人確認書類 |
| **何を確認するか** | 記載漏れ／入居希望日／入居人数／ペット・楽器などの特約に関わる事項 |
| **何をするか** | 申込内容を元付業者・管理会社・オーナーへ取り次ぐ。保証会社への審査申込を行う |
| **何を判断するか** | この段階では判断しない（審査はA-06） |
| **誰と連携するか** | 元付業者、管理会社、保証会社 |
| **できあがるもの** | 入居申込書、保証会社への審査申込 |
| **次に渡す先** | 【賃貸管理機能】【オーナー対応機能】（審査へ） |
| **頻度** | 案件発生時 |

> **入居申込は契約ではない**
> 【Typical】申込みの時点ではまだ契約は成立していません。審査に通らなければ契約に至りません。
> **「申込 ≠ 契約」**は初心者が混同しやすい点です（`16_glossary.md` で再度扱います）。

---

#### A-06 入居審査

| 項目 | 内容 |
|---|---|
| **きっかけ** | 入居申込書を受領したとき |
| **誰が** | 【賃貸管理機能】＋**保証会社**＋**オーナー**（最終判断） |
| **何を受け取るか** | 入居申込書、本人確認書類、（求める場合）収入を示す書類 |
| **何を確認するか** | **家賃を継続して支払えるか**（収入と家賃のバランス）／勤務先・勤続年数／連帯保証人の有無と属性／保証会社の審査結果／入居人数と間取りが合っているか |
| **何をするか** | 保証会社へ審査を依頼し、その結果を添えてオーナーに諾否を確認する |
| **何を判断するか** | 入居の可否。条件付き承諾（連帯保証人の追加等）となることもある【Varies】 |
| **誰と連携するか** | 保証会社、オーナー、客付業者（結果の連絡） |
| **できあがるもの** | **審査結果**（承諾／否認）、保証会社の保証委託契約の準備 |
| **次に渡す先** | 【賃貸仲介機能】（契約手続へ） |
| **頻度** | 案件発生時 |

> **なぜ入居審査があるのか**
> 家賃は**毎月・長期にわたって**支払われるものです。売買のように一度で完結しません。
> 【Typical】入居後に支払いが滞ると、督促、明渡し交渉と、長期にわたる手間と損失が発生します。
> そのため**入る前に確認する**という工程が置かれています。

> **家賃債務保証会社**
> → 借主が家賃を払えなくなったとき、**借主に代わって貸主へ家賃を立て替える（代位弁済する）**会社です。
>    借主は契約時に保証料を払い、保証委託契約を結びます。
> → 実務例：借主が家賃を滞納すると、保証会社が貸主（または管理会社）へ支払い、
>    その後、保証会社が借主へ請求する。管理会社から見ると**家賃の入金が途切れにくくなります**。
> → 【Varies】保証料の水準や、連帯保証人と保証会社の両方を求めるかは、物件・貸主により異なります。

#### A-07 重要事項説明【法定】

| 項目 | 内容 |
|---|---|
| **きっかけ** | 審査が承諾され、契約日が決まったとき |
| **誰が** | **宅地建物取引士**【Fact】（宅地建物取引業法第35条第1項） |
| **何を受け取るか** | 物件調査の結果（登記記録、法令上の制限、設備、管理規約、周辺環境） |
| **何を確認するか** | 【Fact】同法第35条第1項各号の事項（登記された権利、法令上の制限、飲用水・電気・ガス・排水の整備状況、契約の解除、損害賠償額の予定・違約金、支払金・預り金の保全措置 等）。賃貸では**私道負担**は建物の貸借では除かれる（同項第三号） |
| **何をするか** | **契約が成立するまでの間に**、重要事項説明書（35条書面）を交付して説明する。【Fact】説明の際は**宅地建物取引士証を提示**する（同条第4項）。書面には**宅建士が記名**する（同条第5項） |
| **何を判断するか** | 借主が内容を理解したうえで契約に進むか |
| **誰と連携するか** | 【物件調査・契約書作成機能】（書面の作成）、元付業者 |
| **できあがるもの** | **重要事項説明書（35条書面）**、説明済みの記録 |
| **次に渡す先** | 【賃貸仲介機能】（契約締結へ） |
| **頻度** | 法定・契約上のタイミング（契約成立前に必ず） |

> **「契約の前に説明する」ことがなぜ法律で決まっているのか**
> 契約した後に「この建物は取り壊し予定だった」と知らされても、借主はもう引き返せません。
> 【Fact】そこで宅地建物取引業法第35条第1項は、**契約が成立するまでの間に**、
> **宅地建物取引士をして**、書面を交付して説明させることを業者に義務づけています。
> **「契約書にハンコを押す前」でなければ意味がない**、という制度設計です。

> **IT重説について**
> 【Fact】第35条第8項により、相手方の承諾を得て、書面に記載すべき事項を**電磁的方法で提供**することができます。
> 【Fact】国土交通省は「IT を活用した重要事項説明及び書面の電子化について」のページを設けています
> （出典：国土交通省）。運用の詳細はそちらに拠ります。

#### A-08 賃貸借契約の締結

| 項目 | 内容 |
|---|---|
| **きっかけ** | 重要事項説明が終わったとき |
| **誰が** | 【賃貸仲介機能】（契約当事者は**貸主と借主**。業者は媒介） |
| **何を受け取るか** | 借主の署名押印、本人確認書類、連帯保証人の署名押印（求める場合） |
| **何を確認するか** | 契約期間／賃料・共益費の額と支払期日／敷金・礼金／更新の条件／禁止事項・特約／原状回復の負担区分／解約の予告期間 |
| **何をするか** | 賃貸借契約書に署名押印を受け、保証委託契約・火災保険の申込も併せて行う。【Fact】契約成立後、**遅滞なく37条書面を契約の各当事者に交付**する（宅地建物取引業法第37条第2項）。書面には**宅建士が記名**する（同条第3項） |
| **何を判断するか** | 特約の内容に双方が合意しているか |
| **誰と連携するか** | オーナー（または管理会社）、保証会社、損害保険会社 |
| **できあがるもの** | **賃貸借契約書**、**37条書面**、保証委託契約書、火災保険の申込 |
| **次に渡す先** | 【経理・財務機能】（入金確認へ）、【賃貸管理機能】（入居後の管理へ） |
| **頻度** | 案件発生時 |

> **【Fact】貸借の37条書面の記載事項**（宅地建物取引業法第37条第2項）
> 当事者の氏名・住所／物件を特定するために必要な表示／引渡しの時期／契約の解除に関する定め／
> 損害賠償額の予定・違約金／天災その他不可抗力による損害の負担／
> **借賃の額・支払の時期・方法**／借賃以外の金銭の授受の定めがあるときはその額・時期・目的。

> **普通借家か定期借家か**
> 【Fact】更新のない契約（定期建物賃貸借）にするには、**公正証書による等書面によって契約**し、
> **あらかじめ、更新がなく期間満了で終了する旨を記載した書面を交付して説明**しなければなりません
> （借地借家法第38条第1項・第3項）。**説明しなかったときは、更新がない旨の定めは無効**です（同条第5項）。
> 【Typical】一般的な居住用物件では普通借家契約が多く見られます【Varies】。

#### A-09 初期費用の入金確認

| 項目 | 内容 |
|---|---|
| **きっかけ** | 契約締結時（または契約前に入金を求める場合は契約日の前）【Varies】 |
| **誰が** | 【経理・財務機能】＋【賃貸仲介機能】 |
| **何を受け取るか** | 借主からの振込（または現金） |
| **何を確認するか** | 入金額が請求額と一致しているか／入金名義／入金日 |
| **何をするか** | 内訳ごとに仕分ける（後述） |
| **できあがるもの** | 入金記録、領収書、各先への送金の準備 |
| **次に渡す先** | 【賃貸管理機能】（鍵渡しの可否判断） |
| **頻度** | 案件発生時 |

**初期費用の内訳と、そのお金が最終的にどこへ行くか**【Typical】

| 項目 | やさしい説明 | 最終的な受取先 | 返るか |
|---|---|---|---|
| **敷金** | 【Fact】賃料債務等を**担保する目的**で借主が貸主に交付する金銭（民法第622条の2第1項） | 貸主 | **返る**（債務を控除した残額） |
| **礼金** | 貸主に支払う、返還されない金銭 | 貸主 | 返らない |
| **前家賃** | 入居月（および翌月）の家賃を前もって払うもの | 貸主 | 返らない（家賃だから） |
| **日割家賃** | 月の途中入居のとき、入居日から月末までの日数分の家賃 | 貸主 | 返らない |
| **仲介手数料** | 【Fact】媒介の報酬。借賃1か月分の1.1倍が双方合計の上限（告示 第四） | 仲介した業者 | 返らない |
| **保証委託料** | 家賃債務保証会社に払う保証料 | 保証会社 | 返らない |
| **火災保険料** | 借家人賠償責任保険等を含む保険料 | 損害保険会社 | 返らない（中途解約時の扱いは契約による）【Varies】 |
| **鍵交換費用** | 前入居者の鍵を使えなくするための交換費用 | 貸主または鍵業者 | 返らない【Varies】 |

> **【Typical】家賃は前払いが一般的**
> 【Typical】賃貸借の実務では、**当月分または翌月分の家賃を前もって支払う**定めが置かれることが一般的です。
> 【Example】「毎月末日までに翌月分を支払う」という定めなら、
> 3月入居の人は契約時に3月分（日割）と4月分を払い、以後は毎月末に翌月分を払う、という形になります。
> 【Varies】支払期日や前払い・後払いの別は契約により異なるため、契約書の定めが基準になります。
> 【Fact】なお民法上、賃料は原則として**後払い**（毎月末に支払う）と定められており（民法第614条本文）、
> 前払いは**契約による定め**によるものです。

#### A-13 滞納督促

| 項目 | 内容 |

#### A-15 入居者対応・修繕手配

| 項目 | 内容 |
|---|---|
| **きっかけ** | 入居者からの連絡（設備の故障、水漏れ、騒音、鍵の紛失、虫、駐車場のトラブル 等） |
| **誰が** | 【賃貸管理機能】 |
| **何を確認するか** | 何が起きているか／緊急性（水漏れ・ガス・鍵は緊急）／**費用負担は貸主か借主か** |
| **何をするか** | 現地確認、業者の手配、オーナーへの報告と承認取得、入居者への経過連絡 |
| **何を判断するか** | 【Fact】**修繕費用の負担区分**。民法第606条第1項により、賃貸人は賃貸物の使用収益に必要な修繕をする義務を負う。**ただし賃借人の責めに帰すべき事由**によって修繕が必要となったときはこの限りでない |
| **誰と連携するか** | 入居者、オーナー、設備業者、（保険事故なら）損害保険会社 |
| **できあがるもの** | 修繕の記録、業者への発注、費用の立替・精算 |
| **頻度** | トラブル発生時（常時発生しうる） |

> **【Example】負担区分の考え方（説明用の例）**
> | 事象 | 一般的な考え方 |
> |---|---|
> | 給湯器が経年で壊れた | 【Typical】貸主負担（自然に使えなくなったもの） |
> | 入居者が鍵を紛失した | 【Typical】借主負担（借主の責めに帰すべき事由） |
> | 上階からの水漏れで天井が汚れた | 【Typical】借主の責めに帰さない事由。原則として借主の負担ではない |
> | 網戸が破れた（経年劣化） | 【Varies】経年か使い方かで判断が分かれる |
>
> 【Varies】具体的な負担区分は契約書の定めと個別事情によります。

> **なぜ「オーナーの承認」が必要なのか**
> 【Typical】修繕費はオーナーの負担になるため、管理会社が勝手に高額な工事を発注することはできません。
> 【Varies】少額（例：数万円まで）は管理会社の判断で発注し、それを超えるものは承認を得る、
> といった取り決めが管理受託契約で定められることがあります。

#### A-17 契約更新

| 項目 | 内容 |
|---|---|
| **きっかけ** | 契約期間の満了が近づいたとき（一般に満了の数か月前）【Varies】 |
| **誰が** | 【賃貸管理機能】＋【オーナー対応機能】 |
| **何を確認するか** | 更新後の賃料をどうするか（据置きか改定か）／更新料の有無／保証委託契約・火災保険の更新／入居者の状況（滞納の有無） |
| **何をするか** | 更新の案内を送付し、更新契約書を取り交わす。保証会社・保険の更新手続を行う |
| **何を判断するか** | 賃料を改定するか。【Fact】借地借家法第32条第1項により、租税等の負担の増減・経済事情の変動・近傍同種の建物の借賃との比較で不相当となったときは、当事者は将来に向かって借賃の増減を請求できる（一定期間増額しない特約があるときはその定めに従う） |
| **できあがるもの** | 更新契約書、更新料の請求・入金、更新事務手数料 |
| **頻度** | 法定・契約上のタイミング（契約期間の満了前） |

> **更新料**
> → 契約を更新する際に、借主が貸主に支払う金銭のことです。
> → 【Varies】更新料の有無・金額（家賃の0.5〜1か月分など）は**地域差・物件差が非常に大きい**慣行で、
>    まったく授受されない地域もあります。契約書に定めがある場合に支払われます。
> → **更新事務手数料**は、これとは別に、更新手続の事務に対して管理会社等が受け取る費用です【Varies】。

> **【Fact】更新しない場合はどうなるか**
> 【Fact】借地借家法第26条第1項により、期間の定めがある建物賃貸借で、
> 当事者が**期間満了の1年前から6月前までの間**に更新をしない旨の通知をしなかったときは、
> **従前と同一の条件で更新したものとみなされます**（ただし期間は定めがないものとなる）。
> 【Fact】さらに、賃貸人からの更新拒絶の通知には**正当の事由**が必要です（同法第28条）。

#### A-20 原状回復の範囲判定・見積

| 項目 | 内容 |
|---|---|
| **きっかけ** | 退去立会いが完了したとき |
| **誰が** | 【賃貸管理機能】（判断は管理会社、最終的な負担は貸主・借主） |
| **何を確認するか** | 【Fact】**民法第621条**：賃借人は、賃借物を受け取った後に生じた損傷（**通常の使用及び収益によって生じた損耗ならびに経年変化を除く**）を原状に復する義務を負う。ただし賃借人の責めに帰することができない事由によるものは除く |
| **何をするか** | ガイドラインの考え方に沿って、貸主負担と借主負担を仕分け、原状回復の見積を取る |
| **できあがるもの** | **原状回復の負担区分表**、工事見積書 |
| **次に渡す先** | A-21（敷金精算） |
| **頻度** | 案件発生時 |

**【Fact】国土交通省「原状回復をめぐるトラブルとガイドライン（再改訂版）」の考え方**（出典：国土交通省）

原状回復の定義：
> **賃借人の居住、使用により発生した建物価値の減少のうち、賃借人の故意・過失、善管注意義務違反、
> その他通常の使用を超えるような使用による損耗・毀損を復旧すること**

建物価値の減少の3区分と負担：

| 区分 | 内容 | 負担 |
|---|---|---|
| ①-A **経年変化** | 建物・設備等の自然的な劣化・損耗等 | **賃貸人**負担 |
| ①-B **通常損耗** | 賃借人の通常の使用により生ずる損耗等 | **賃貸人**負担 |
| ② それ以外 | 賃借人の故意・過失、善管注意義務違反、通常の使用を超える使用による損耗等 | **賃借人**負担 |

【Fact】同ガイドラインは、賃借人の負担について**建物・設備等の経過年数を考慮**し、
同じ損耗等でも**経過年数に応じて負担を軽減する**考え方を採用しています。
【Fact】また、次の入居者を確保する目的で行う設備の交換・化粧直しなどのリフォームは、
①-A・①-Bの修繕であり**賃貸人が負担すべき**としています。

> **【Example】仕分けの例（説明用の架空例）**
> | 事象 | 区分 | 負担 |
> |---|---|---|
> | 日照によるクロスの変色 | ①-A 経年変化 | 貸主 |
> | 家具を置いていた床のへこみ | ①-B 通常損耗 | 貸主 |
> | タバコのヤニによる壁一面の変色・臭い | ② | 借主【Typical】 |
> | ペットが柱をひっかいた傷 | ② | 借主【Typical】 |
> | 掃除をしなかったことによる台所の油汚れ | ② | 借主【Typical】 |
>
> 【Varies】実際の判断は契約書の特約、入居期間、経過年数によって変わります。

> **特約について**
> 【Fact】同ガイドラインは、賃借人に特別の負担を課す特約について、
> **「特約の必要性があり、かつ暴利的でないなどの客観的、合理的理由が存在すること」**など
> 一定の要件を示しています。

#### A-21 敷金精算

| 項目 | 内容 |
|---|---|
| **きっかけ** | 原状回復の負担区分と金額が確定したとき |
| **誰が** | 【賃貸管理機能】＋【経理・財務機能】 |
| **何を確認するか** | 未払賃料・未払共益費の有無／借主負担分の原状回復費用／日割精算 |
| **何をするか** | 【Fact】民法第622条の2第1項：賃貸人は、**賃貸借が終了し、かつ賃貸物の返還を受けたとき**、受け取った敷金の額から賃貸借に基づいて生じた債務の額を控除した**残額を返還**しなければならない |
| **何を判断するか** | 敷金で足りるか、足りず追加請求になるか |
| **できあがるもの** | **敷金精算書**、返還（または請求） |
| **頻度** | 案件発生時 |

> | **返還額** | **46,000円** |

> 【Example】説明のための架空の数値です。

| 項目 | 内容 |
|---|---|
| **きっかけ** | 負担区分が確定したとき |
| **誰が** | 【賃貸管理機能】 |
| **何をするか** | 原状回復業者へ発注し、工期を管理する。完了後に室内を確認する |

## 4-2【フローB】売買仲介

### 全体図

```
   ↓

   ↓
 B-03 媒介契約の締結            【法定】34条の2書面を遅滞なく交付
   ↓
 B-04 物件調査                  登記・法令・道路・上下水道・境界を調べる
   ↓
 B-05 レインズ登録              【法定】専任7日以内／専属専任5日以内（休業日を除く）
   ↓
 B-06 販売活動                  広告掲載・チラシ・オープンハウス

   ↓
 B-09 住宅ローン事前審査        買主が借りられるかを先に確かめる
   ↓
 B-10 重要事項説明              【法定】宅建士が契約成立前に説明
   ↓
 B-11 売買契約の締結・手付金の授受
   ↓

   ↓
 B-13 決済準備                  司法書士・金融機関・当事者の日程調整
   ↓
 B-14 決済・引渡し・所有権移転登記   ← ここが山場
   ↓
 B-15 仲介手数料の受領・アフター対応
```

---

### 各ステップの詳細

#### B-01 売却相談を受ける

| 項目 | 内容 |
|---|---|
| **きっかけ** | 売主からの問い合わせ（転勤、住み替え、相続、資産整理、離婚 等）／管理しているオーナーからの相談 |
| **誰が** | 【売買仲介機能】（中小では社長・専務が対応することが多い）【Typical】 |
| **何を受け取るか** | 物件の所在、間取り、築年数、売却の理由、希望時期、希望価格 |
| **何を確認するか** | 売主が本当に所有者か／共有名義か／住宅ローンの残債があるか／相続登記は済んでいるか |
| **何をするか** | 現地を確認し、必要書類（登記識別情報、測量図、建築確認済証、管理規約 等）の有無を聞き取る |
| **何を判断するか** | 売却できる状態か（相続登記未了、共有者の同意がない等の障害がないか） |
| **できあがるもの** | 相談記録、査定の依頼 |
| **次に渡す先** | B-02（価格査定） |
| **頻度** | 問い合わせ時 |

> **「残債」がなぜ最初に問題になるのか**
> 【Typical】売主に住宅ローンが残っていると、その物件には**抵当権**（担保）が付いています。
> 買主は抵当権が付いたままの物件は買えないため、**売却代金でローンを完済して抵当権を抹消する**必要があります。
> 【Inference】売却価格が残債を下回ると完済できず、そのままでは取引が成立しません。
> このため残債額の確認が、売却相談の初期に必要になります。

---

#### B-02 価格査定

| 項目 | 内容 |
|---|---|
| **きっかけ** | 売却相談を受けたとき |
| **誰が** | 【売買仲介機能】＋【物件調査・契約書作成機能】 |
| **何を受け取るか** | 物件の概要、現地の状況 |
| **何を確認するか** | 周辺の**成約事例**（レインズ等）／現在売り出されている**競合物件**／土地の形状・道路付け／建物の状態 |
| **何をするか** | 査定価格の根拠を整理し、売主に説明する |
| **何を判断するか** | いくらで売り出すか（査定価格 ＝ 売出価格 とは限らない） |
| **できあがるもの** | **査定書** |
| **次に渡す先** | B-03（媒介契約） |
| **頻度** | 案件発生時 |

> **【Fact】価額について意見を述べるときの義務**
> 【Fact】宅地建物取引業法第34条の2第2項は、
> 「宅地建物取引業者は、〔媒介契約書面に記載する〕価額又は評価額について意見を述べるときは、
> **その根拠を明らかにしなければならない**」と定めています。
> 【Inference】このため、査定は「なんとなくこのくらい」ではなく、
> 成約事例等の根拠を示して行う必要があります。

---

#### B-03 媒介契約の締結【法定】

| 項目 | 内容 |
|---|---|
| **きっかけ** | 売主が「この会社に任せる」と決めたとき |
| **誰が** | 【売買仲介機能】 |
| **何を確認するか** | 3種類のうちどれにするか（一般／専任／専属専任）／売出価格／有効期間 |
| **何をするか** | 【Fact】宅地建物取引業法第34条の2第1項：媒介契約を締結したときは、**遅滞なく**、所定の事項を記載した書面を作成して**記名押印し、依頼者に交付**しなければならない |
| **できあがるもの** | **媒介契約書（34条の2書面）** |
| **次に渡す先** | B-04（物件調査）、B-05（レインズ登録） |
| **頻度** | 案件発生時。以後、契約に応じた報告義務が発生 |

**【Fact】媒介契約書の記載事項**（宅地建物取引業法第34条の2第1項各号）
物件を特定するために必要な表示／**売買すべき価額または評価額**／**他の業者に重ねて依頼することの許否
および明示義務の存否**／既存建物のときは**建物状況調査を実施する者のあっせん**に関する事項／
**有効期間および解除**／**指定流通機構への登録**／**報酬**／その他国土交通省令・内閣府令で定める事項。

**【Fact】3種類の違いと、そこから発生する義務**（`02_industry-structure.md` 11-2(3) の再掲）

| | 一般媒介 | 専任媒介 | 専属専任媒介 |
|---|---|---|---|
| 他社への重ねての依頼 | 可 | 不可 | 不可 |
| 自己発見取引 | 可 | 可 | **不可** |
| 有効期間 | 制限なし | 3か月以内 | 3か月以内 |
| レインズ登録 | 義務なし | **7日以内**（休業日を除く） | **5日以内**（休業日を除く） |
| 業務処理状況の報告 | 定めなし | **2週間に1回以上** | **1週間に1回以上** |

> **媒介契約を結んだ瞬間から、業者には期限のある義務が発生する**
> 【Fact】専任媒介なら「7日以内にレインズ登録」「2週間に1回以上の報告」という
> **日数で決まった義務**が走り出します（宅地建物取引業法第34条の2第5項・第9項、施行規則第15条の10）。
> 【Fact】これらに反する特約は無効です（同条第10項）。

#### B-04 物件調査

| 項目 | 内容 |
|---|---|
| **きっかけ** | 媒介契約を締結したとき |
| **誰が** | 【物件調査・契約書作成機能】（中小では社長・専務が兼務することもある）【Varies】 |
| **何を受け取るか** | 物件の所在・地番、売主から預かった書類 |
| **何を確認するか** | 下表のとおり |
| **何をするか** | 法務局・市区町村・水道局・ガス会社などを回り、資料を集める |
| **できあがるもの** | **調査結果一式**（重要事項説明書のもとになる） |
| **次に渡す先** | B-10（重要事項説明）で使う |
| **頻度** | 案件発生時 |

**調査の項目と調査先**【Typical】

| 何を調べるか | どこで | なぜ必要か（【Fact】35条のどの号に対応するか） |
|---|---|---|
| 登記された権利（所有者、抵当権、地上権 等） | 法務局（登記事項証明書） | 【Fact】第35条第1項第一号 |
| 土地の形・隣接関係 | 法務局（公図、地積測量図） | 境界・面積の確認 |
| 都市計画（用途地域、建ぺい率・容積率、地区計画 等） | 市区町村の都市計画課 | 【Fact】第35条第1項第二号 |
| 建築基準法上の道路の種別・幅員、接道状況 | 市区町村の建築指導課 | 【Fact】第35条第1項第二号。建て替えができるかに直結する |
| 私道の負担 | 公図・現地・市区町村 | 【Fact】第35条第1項第三号（建物の貸借を除く） |
| 上下水道・電気・ガスの整備状況 | 水道局、ガス会社、現地 | 【Fact】第35条第1項第四号 |
| 区分所有建物の場合：管理規約、管理費・修繕積立金、滞納の有無、大規模修繕の計画 | 管理会社・管理組合 | 【Fact】第35条第1項第六号 |
| 既存建物の場合：建物状況調査の実施の有無・結果、設計図書等の保存状況 | 売主、調査事業者 | 【Fact】第35条第1項第六号の二 |
| 過去の経緯（浸水・土砂災害の区域、埋蔵文化財 等） | 市区町村のハザードマップ等 | 買主の判断に影響する事項 |

> **なぜ調査にこれだけ手間をかけるのか**
> 【Example】「4m以上の道路に2m以上接していない土地」は、原則として建物を建てられません
> （**接道義務**。【Fact】**建築基準法第43条第1項**「建築物の敷地は、道路…に**二メートル以上接しなければならない**」。
> ここでいう「道路」は【Fact】**同法第42条第1項**が**幅員四メートル以上**のものと定義しています
> 〈特定行政庁が指定する区域では六メートル〉。出典：e-Gov法令検索・建築基準法 `325AC0000000201`）。
> **見た目ではまったく分かりません。**
> 調査を怠って「建て替えられる」と説明してしまえば、買主は建て替えのできない土地を買うことになります。
> 【Inference】不動産仲介の作業時間のうち、この調査が大きな比重を占めるのはこのためです。

#### B-05 レインズ登録【法定】

| 項目 | 内容 |
|---|---|
| **きっかけ** | 専任媒介契約または専属専任媒介契約を締結したとき |
| **誰が** | 【物件調査・契約書作成機能】または【売買仲介機能】 |
| **何をするか** | 【Fact】宅地建物取引業法第34条の2第5項：所在・規模・形質・売買すべき価額その他の事項を指定流通機構に登録する |
| **期限** | 【Fact】**専任媒介：契約締結の日から7日以内／専属専任媒介：5日以内**。**休業日数は算入しない**（施行規則第15条の10） |
| **登録後にすること** | 【Fact】**登録を証する書面を遅滞なく依頼者に引き渡す**（同条第6項）。※依頼者の承諾を得て電磁的方法で提供することも可（同条第12項） |
| **成約したら** | 【Fact】**遅滞なく指定流通機構に通知する**（同条第7項） |
| **できあがるもの** | レインズ登録、登録証明書 |
| **頻度** | 法定・契約上のタイミング |

#### B-06 販売活動

| 項目 | 内容 |
|---|---|
| **きっかけ** | レインズ登録・広告準備が整ったとき |
| **誰が** | 【販促・集客機能】＋【売買仲介機能】 |
| **何をするか** | ポータルサイト掲載、チラシ配布、現地看板、オープンハウス、業者間への情報提供 |
| **何を確認するか** | 【Fact】誇大広告等の禁止（第32条）／【Fact】**取引態様の明示**／工事完了前の物件なら【Fact】広告開始時期の制限（第33条：開発許可・建築確認等の後でなければ広告できない） |

| **次に渡す先** | B-07（内見対応） |

| **報告義務** | 【Fact】専任媒介なら**2週間に1回以上**、専属専任媒介なら**1週間に1回以上**、業務の処理状況を依頼者に報告する（第34条の2第9項）。また【Fact】**申込みがあったときは遅滞なく報告する**（同条第8項） |
|---|---|

> **報告の中身**【Typical】
> 「広告を何件掲載したか」「問い合わせが何件あったか」「内見が何件あったか」「他社からの反響はどうか」
> 「価格を見直す必要があるか」といった内容が報告されます。
> 【Fact】報告の頻度は法律で決まっていますが、報告の内容・様式は法定されていません。

#### B-08 買付申込・条件交渉

| 項目 | 内容 |
|---|---|
| **きっかけ** | 買主が「この物件を買いたい」と意思表示したとき |
| **誰が** | 【売買仲介機能】（元付・客付の両業者が関わる） |
| **何を受け取るか** | **買付証明書（購入申込書）**（購入希望価格、手付金の額、引渡希望時期、住宅ローン利用の有無） |
| **何を確認するか** | 買主の資金計画（自己資金と借入額）／ローンが通る見込み／引渡時期が売主の希望と合うか |
| **何をするか** | 売主に内容を伝え、価格・引渡時期・付帯設備・特約について調整する |
| **何を判断するか** | 売主が受けるかどうか。複数の申込みがある場合は条件を比較する |
| **できあがるもの** | 買付証明書、（売主側の）売渡承諾の意思表示、契約日の決定 |
| **次に渡す先** | B-09（ローン事前審査）、B-10（重要事項説明） |
| **頻度** | 案件発生時 |

> **買付証明書は契約ではない**
> 【Typical】買付証明書は購入の意思を示す書面であり、これだけで売買契約が成立するものではありません。
> 【Fact】売買契約は、当事者の一方が財産権を移転することを約し、相手方が代金を支払うことを約することで
> 効力を生じます（民法第555条）。
> 【Fact】宅建業者は、媒介により契約が成立したときは**遅滞なく37条書面を交付**しなければなりません（第37条第1項）。

#### B-09 住宅ローン事前審査

| 項目 | 内容 |
|---|---|
| **きっかけ** | 買付申込の前後 |
| **誰が** | 買主（【売買仲介機能】が金融機関を紹介・書類の案内をすることが多い）【Typical】 |
| **何を確認するか** | 買主の年収・勤続年数・他の借入・信用情報／物件の担保評価 |
| **何をするか** | 金融機関へ事前審査を申し込み、借入可能額の見通しを得る |
| **何を判断するか** | 資金計画が成り立つか。成り立たなければ契約に進まない |
| **できあがるもの** | 事前審査の結果 |
| **頻度** | 案件発生時 |

> **なぜ「事前」と「本」の2段階なのか**
> 【Typical】本審査には売買契約書が必要になるため、契約前には行えません。
> 一方、契約してから借りられないと分かると双方に損害が出ます。
> そこで契約前に**事前審査**で見通しを立て、契約後に**本審査**を行う、という2段階が取られます。

> **【Fact】ローン特約（融資利用の特約）**
> 【Fact】宅地建物取引業法第35条第1項第十二号は、
> **代金・交換差金に関する金銭の貸借のあっせんの内容と、当該貸借が成立しないときの措置**を
> 重要事項として説明することを定めています。
> 【Fact】第37条第1項第九号も、金銭の貸借のあっせんの定めがある場合の**不成立のときの措置**を
> 37条書面の記載事項としています。
> 【Typical】実務では、一定期日までにローンの承認が得られない場合は契約を解除でき、
> 受領済みの金銭を返還するという特約が置かれることが一般的です。

#### B-11 売買契約の締結・手付金の授受

| 項目 | 内容 |
|---|---|
| **きっかけ** | 重要事項説明が終わったとき（同日に続けて行うのが一般的）【Typical】 |
| **誰が** | 【売買仲介機能】（契約当事者は売主と買主） |
| **何を確認するか** | 売買代金／手付金の額／引渡しの時期／所有権移転登記の申請時期／固定資産税等の精算方法／契約不適合責任の範囲／ローン特約／違約金 |
| **何をするか** | 売買契約書に署名押印。**買主が売主へ手付金を交付**する。【Fact】契約成立後、**遅滞なく37条書面を契約の各当事者に交付**する（第37条第1項）。**宅建士が記名**する（同条第3項） |
| **できあがるもの** | **売買契約書（37条書面を兼ねるのが一般的）**【Typical】、手付金の領収書 |
| **次に渡す先** | B-12（本審査）、B-13（決済準備） |
| **頻度** | 案件発生時 |

> **手付金（てつけきん）とは何か**
> → 売買契約を結ぶときに、**買主が売主に渡すお金**です。代金の一部に充当されるのが一般的です。
> → **なぜ渡すのか**：契約を結んでから決済まで数か月あくため、その間に一方が勝手にやめてしまうことを
>    抑える機能を持ちます。
> → 【Fact】民法第557条第1項：買主が売主に手付を交付したときは、**買主はその手付を放棄し、
>    売主はその倍額を現実に提供して、契約の解除をすることができる**。
>    ただし、**その相手方が契約の履行に着手した後は、この限りでない**。
> → 【Example】手付金200万円なら、買主は200万円を放棄すればやめられ、売主は400万円を現実に提供すればやめられる。
>    ただし相手が履行に着手した後はできない。

> **【Fact】業者が自ら売主となる場合の特別なルール**
> 【Fact】宅地建物取引業法第39条第1項：業者が自ら売主となる売買契約の締結に際して、
> **代金の額の10分の2を超える額の手付を受領することができない**。
> 【Fact】同条第2項：業者が手付を受領したときは、その手付がいかなる性質のものであっても、
> 買主は手付を放棄して、業者は**倍額を現実に提供**して契約を解除できる（相手方が履行に着手した後を除く）。
> 【Fact】同条第3項：これに反する特約で買主に不利なものは**無効**。
>
> **これは業者が売主のときのルールです。** 売主が個人で業者が媒介しているだけの場合は適用されません。

> **【Fact】手付金等の保全措置（業者が自ら売主の場合）**
> | 場面 | 措置 | 例外（措置不要） |
> |---|---|---|
> | **工事完了前**の物件（第41条第1項） | 保証委託契約または保証保険契約 | 代金の**5%以下かつ1,000万円以下**（施行令第3条の5）、または買主への所有権移転登記等がされたとき |
> | **工事完了後**の物件（第41条の2第1項） | 上記の措置、または指定保管機関への手付金等寄託契約＋質権設定契約 | 代金の**10分の1以下かつ1,000万円以下**（施行令第3条の5）、または買主への所有権移転登記等がされたとき |

> **【Fact】クーリング・オフ（業者が自ら売主の場合）**
> 【Fact】宅地建物取引業法第37条の2第1項：業者が自ら売主となる売買契約について、
> **事務所等以外の場所**で買受けの申込みをした者・売買契約を締結した買主は、書面により申込みの撤回等ができる。
> ただし次の場合はできない。
> - 撤回等を行うことができる旨とその方法を**書面で告げられた日から起算して8日を経過**したとき
> - **宅地・建物の引渡しを受け、かつ代金の全部を支払った**とき
>
> 【Fact】同条第3項：撤回等が行われたときは、業者は**速やかに手付金その他の金銭を返還**しなければならない。
> 【Fact】同条第4項：これに反する特約で申込者等に不利なものは**無効**。

|---|---|
| **きっかけ** | 融資の承認が下りたとき |
| **誰が** | 【売買仲介機能】＋【物件調査・契約書作成機能】 |
| **何をするか** | **決済日・場所・時刻を、売主・買主・金融機関・司法書士の4者で合わせる**。必要書類の準備を各者に依頼する |

#### B-14 決済・引渡し・所有権移転登記 ← **フローBの山場**

| 項目 | 内容 |
|---|---|
| **きっかけ** | 決済日 |
| **誰が** | 売主、買主、金融機関、司法書士、元付業者、客付業者（全員が同席するのが一般的）【Typical】 |
| **場所** | 【Typical】買主が融資を受ける金融機関の一室 |
| **何をするか** | 下記の手順（同時履行） |
| **できあがるもの** | 代金の授受、鍵の引渡し、登記申請、精算、仲介手数料の受領 |
| **頻度** | 案件発生時 |

**決済当日に何が起きるか（順序が重要）**【Typical】

```
 ① 司法書士が、売主・買主の本人確認と書類の確認を行う
     └ 【Fact】所有権移転登記は、原則として登記権利者（買主）と登記義務者（売主）が
        共同して申請する（不動産登記法第60条）。実務では双方が司法書士に委任する
     └ 司法書士が「この書類で登記できる」と確認したことを、当事者に伝える
          ↓
 ② 買主の住宅ローンが実行され、買主の口座に入金される
          ↓
 ③ 買主 → 売主 へ残代金を振り込む
          ↓
 ④ 売主のローン残債がある場合は、その場で返済し、
    金融機関から抵当権抹消の書類が交付される
          ↓
 ⑤ 固定資産税・都市計画税・管理費・修繕積立金を日割りで精算する
          ↓
 ⑥ 売主 → 買主 へ 鍵・物件関係書類を引き渡す
          ↓
 ⑦ 仲介手数料の残額、登記費用を支払う
          ↓
 ⑧ 司法書士が法務局へ登記を申請する（当日中）
          ↓
 （数日〜2週間後）【Varies】登記が完了し、買主名義の登記識別情報が交付される
```

> **なぜ①が先で②③が後なのか（同時履行の考え方）**
> 売主は「代金をもらう前に権利証（登記識別情報）を手放したくない」、
> 買主は「登記が自分に移る保証がないのに大金を払いたくない」。
> どちらも当然の言い分です。
>
> そこで、**司法書士が先に書類をすべて確認し、「これで登記できます」と確認した時点で送金する**
> という手順が取られます。司法書士は書類を預かった状態で、その日のうちに法務局へ申請します。
> 【Inference】この段取りにより、代金の支払いと権利の移転が実質的に同時に行われる形が作られています。

> **【Fact】登記が「引き渡し」に相当する理由**
> 【Fact】民法第177条：不動産に関する物権の得喪及び変更は、
> **登記をしなければ第三者に対抗することができない**。
> 【Fact】民法第560条：売主は買主に対し、登記その他の対抗要件を備えさせる義務を負う。
> 【Inference】したがって、買主にとって「モノを受け取った」といえる状態は、
> 鍵を受け取ったことではなく、**自分の名義に登記が移ること**です。

> **固定資産税の日割精算とは**
> 【Typical】固定資産税は、その年の1月1日時点の所有者に課税されます。
> しかし年の途中で売買すれば、残りの期間は買主が使うことになります。
> そこで、**引渡日を境に日割りで計算し、買主が負担分を売主に渡す**という精算が慣行として行われます。
> 【Fact】宅地建物取引業法第37条第1項第十二号は、租税その他の公課の負担に関する定めがあるときは
> その内容を37条書面に記載することとしています。
> 【Varies】起算日を1月1日とするか4月1日とするかは地域慣行により異なります。

#### B-15 仲介手数料の受領・アフター対応

| 項目 | 内容 |
|---|---|
| **きっかけ** | 決済が完了したとき |
| **誰が** | 【経理・財務機能】＋【売買仲介機能】 |
| **何をするか** | 仲介手数料を受領し、売上に計上する。レインズへ成約の通知を行う。売主・買主へ書類を引き渡す |
| **何を確認するか** | 【Fact】報酬額が告示の上限内か（宅地建物取引業法第46条第2項）／【Fact】**成約したら遅滞なく指定流通機構に通知**（第34条の2第7項）／【Fact】**取引のあったつど帳簿に記載**（第49条） |
| **できあがるもの** | 売上計上、領収書、帳簿への記載、成約通知 |
| **その後** | 【Typical】買主からの問い合わせ（設備の不具合、近隣との関係 等）への対応。契約不適合責任の期間中は売主との調整も生じうる |
| **頻度** | 案件発生時 |

> **【Varies】仲介手数料はいつ受け取れるのか**
> 【Fact】宅地建物取引業法・告示は、報酬の**上限額**を定めていますが、**受領の時期は定めていません**。
> 【Typical】実務では、**売買契約時に半額、決済・引渡時に残額**という分け方が用いられることが一般的です。
> 【Varies】全額を決済時に受け取る、契約時に全額受け取るなど、取り決めは会社・案件により異なります。
> 媒介契約書の「報酬に関する事項」（第34条の2第1項第七号）に記載されます。
>
> 【Inference】この時期の違いは、会社の資金繰りに直接影響します。
> 契約から決済まで数か月あくため、**契約時に一部を受け取れるかどうかで、入金のタイミングが変わります**。

## 4-3 2つのフローを重ねて見る — お金が入るタイミングの違い

```
 【フローA：賃貸（1件）】
  問合せ ─ 内見 ─ 申込 ─ 審査 ─ 重説 ─ 契約 ─ 鍵渡し ── 入居中（毎月）──────▶
                                         ▲                ▲ ▲ ▲ ▲ ▲ ▲
                                    初期費用一括        毎月の家賃（→管理料）
                                    （仲介手数料もここ）

  期間：1〜3週間【Typical】            以後、数年間ずっと管理料が入り続ける


 【フローB：売買（1件）】
  相談 ─ 査定 ─ 媒介契約 ─ 調査 ─ 登録 ─ 販売活動 ─ 申込 ─ 重説 ─ 契約 ──── 決済
                  ▲                     （数週間〜数か月）        ▲          ▲
             ここから義務が発生                             手数料の半額  残額
             （報告・登録の期限）                           【Varies】

  期間：3〜6か月【Typical】            終わったら、その案件の収入は終わり
```

> **この図が示していること**
> 【Inference】賃貸は「短く・小さく・続く」、売買は「長く・大きく・一度きり」です。
> 賃貸管理の収入は積み上がっていきますが、売買仲介の収入は毎年ゼロから積み直しになります。
> `03_company-structure.md` で見たモデル企業の売上構成（管理料36%／賃貸仲介41%／売買仲介17%）は、
> この性質の違う収入を組み合わせた結果です。

| 敷金（1か月） | 68,000円 | 山田さん（預かり） |

| **合計** | **352,300円** | |

> **【Fact】仲介手数料の上限の確認**
> 【Fact】賃貸の媒介報酬は、依頼者双方からの合計が**借賃1か月分の1.1倍**以内（告示 第四）。
> 家賃68,000円 × 1.1 ＝ **74,800円**。
> 【Fact】居住用建物では、依頼を受けるにあたり承諾を得ている場合を除き、

> 【Example】この事例では、鈴木さんから1.1か月分相当を受け取る前提として、
> 依頼を受けるにあたり承諾を得ているものとしています。

| 収入 | 金額 | いつ |

| 仲介手数料（鈴木さんから） | 74,800円 | 契約時 |
| AD（山田さんから／広告料） | 74,800円 | 契約時 |

| 管理料（203号室分。家賃71,000円の5%） | 3,550円／月 | 毎月、入居している限り |
| **初期の収入合計** | **149,600円** | |

> **この例から読み取れること**
> - 1件の賃貸仲介で得られる収入は**十数万円**。売買仲介1件（数十万〜数百万円）とは桁が違います。

> - つまり**賃貸仲介の1件は「その場の手数料」と「その後の管理料」の2階建て**になっています。
> - 退去から次の入居までに**約1か月の空室期間**が生じ、その間の家賃収入・管理料はゼロです。

```
 成約価格 2,480万円（片手＝売主 高橋さんからのみ受領）

 【Fact】告示 第二による上限額の計算：
   200万円以下の部分       ： 200万円 × 5.5% ＝ 110,000円
   200万円超400万円以下の部分： 200万円 × 4.4% ＝  88,000円

   合計                                      ＝ 884,400円
```

> - **4月5日の相談から8月28日の決済まで約5か月**かかっています。この間ずっと収入はありません。

> - 仲介手数料を契約時と決済時に分けて受け取ることで、5か月間まったく入金がない状態を避けています【Varies】。

### 押さえるべき7点

1. **賃貸と売買はフローが別物**。賃貸は成約してから管理が始まり、売買は決済で終わる。
2. **重要事項説明は契約が成立するまでの間に、宅地建物取引士が、宅建士証を提示して行う**
   （【Fact】宅建業法第35条第1項・第4項）。35条書面と37条書面は別物。
3. **媒介契約を結んだ瞬間から、日数で決まった法定義務が走り出す**
   （レインズ登録7日／5日、報告2週間／1週間に1回以上）。
4. **決済は同時履行**。司法書士が登記できることを確認してから送金する。
   登記が移って初めて買主は第三者に対抗できる（【Fact】民法第177条）。
5. **仲介手数料の受領時期は法定されていない**。【Varies】契約時と決済時に分けるのが一般的。
6. **家賃は契約の定めにより前払いが一般的**【Typical】。【Fact】民法上の原則は後払い（民法第614条本文）。
7. **原状回復は「借りた当時の状態に戻すこと」ではない**。
   【Fact】通常損耗と経年変化は除かれる（民法第621条）。負担区分は国土交通省ガイドラインの考え方による。
