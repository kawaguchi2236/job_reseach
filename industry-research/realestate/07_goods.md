# 07_goods.md — 不動産業のモノ（物件）の流れ

**対象**：日本国内の中小不動産業（モデル企業：株式会社ミナト不動産）
**読み手**：不動産業をまったく知らない人
**最終更新**：2026-09-20

> 会社設定・機能名は `03_company-structure.md`、業務フロー記号（A-01〜A-22／B-01〜B-15）は
> `04_end-to-end-process.md` を前提とします。

---

## 7-0【この章の出発点】不動産は動かない。動くのは「権利」と「鍵」と「情報」

### 他業界との決定的な違い

`common/methodology.md` §6 は、モノの流れを
「物理的なモノがどこから入り、どこで変化し、どこで保管され、どこへ出るか」と定義しています。
しかし不動産業では、この問いがそのままでは成り立ちません。

| 業界 | モノはどう動くか |
|---|---|
| 製造業 | 材料が入り、加工され、製品になり、出荷されて客先へ**移動する** |
| 卸売・小売業 | 商品を仕入れ、倉庫や店舗に**保管し**、客に渡して**移動する** |
| 物流業 | 預かった荷物を**運ぶ**（移動そのものが商品） |
| **不動産業** | **土地と建物は動かない。1ミリも移動しない** |

> **不動産（ふどうさん）という言葉そのものが、動かないことを意味しています。**
> 【Fact】民法第86条第1項：**土地及びその定着物は、不動産とする。**
> 【Fact】同条第2項：**不動産以外の物は、すべて動産とする。**

では不動産業には「モノの流れ」がないのか。あります。**動くものが3つあります。**

```
  ┌─────────────────────────────────────────────────────────┐
  │  不動産そのもの（土地・建物）＝ 動かない                   │
  │                                                          │
  │  では何が動くのか                                         │
  │                                                          │
  │  ① 権利（けんり）  ── 所有権 ／ 使用する権利（賃借権）     │
  │     → 売買では「所有権」が売主から買主へ移る               │
  │     → 賃貸では「使う権利」が貸主から借主へ渡る             │
  │     → 目に見えない。だから「登記」と「契約書」で記録する    │
  │                                                          │
  │  ② 鍵（かぎ）    ── 実際にその部屋・建物を使える状態       │
  │     → 賃貸では鍵を渡した瞬間に借主が使い始める             │
  │     → 売買でも決済日に鍵が売主から買主へ渡る               │
  │     → **不動産業で唯一、物理的に手渡しされるモノ**         │
  │                                                          │
  │  ③ 情報（じょうほう）── 物件が今どういう状態かという情報    │
  │     → 空室か入居中か、申込が入っているか、売れたか         │
  │     → これは `09_information.md` で詳述する               │
  └─────────────────────────────────────────────────────────┘
```

> **したがって本章では、「モノの流れ」を次の3本立てで書きます。**
> 1. **権利の移転**（所有権が動く＝売買／使用権が渡る＝賃貸）
> 2. **物件の状態遷移**（空室 → 募集 → 内見 → 申込 → 契約 → 入居 → 退去 → 原状回復 → 再募集）
> 3. **鍵の管理**（不動産業で唯一の物理的な在庫管理に近いもの）
>
> そのうえで、**設備の所有と修繕責任**、**原状回復の範囲**（民法第621条・第622条の2）を扱います。

## 7-1【最重要】仲介と管理で、モノの流れがまったく違う

| | **仲介（フロー型）** | **管理（ストック型）** |
|---|---|---|
| **扱う物件の数** | その時点で預かっている案件の数だけ | 【Example】**850戸を常時ずっと抱え続ける** |
| **物件との関係の始まり** | 媒介契約を締結したとき | 管理受託契約を締結したとき |
| **物件との関係の終わり** | **成約・決済したとき**（手離れする） | **管理受託契約が終わるまで終わらない** |
| **何が動くか** | **所有権**（売買）／**使用権**（賃貸） | **物件の状態**（空室↔入居）が繰り返し循環する |
| **鍵の扱い** | 案件のあいだ一時的に借りる・預かる | **850戸分の鍵を保管し続ける** |
| **建物の劣化への関与** | しない（現況を調べて説明するだけ） | **する**（点検・清掃・修繕・原状回復） |
| **モノの流れの形** | **直線**（預かる → 引き渡す → 終わり） | **循環**（入居 → 退去 → 原状回復 → 再募集 → 入居） |

```
 【仲介のモノの流れ：直線】

  媒介契約 ─▶ 調査 ─▶ 広告 ─▶ 内見 ─▶ 契約 ─▶ 引渡し（鍵＋登記） ─▶ 終わり
                                                      │
                                              ここで手が離れる


 【管理のモノの流れ：循環】

       ┌──────────── 再募集 ◀──── 原状回復工事 ◀──── 退去立会い
       │                                                   ▲
       ▼                                                   │
    募集 ─▶ 内見 ─▶ 申込 ─▶ 審査 ─▶ 契約 ─▶ 入居 ─▶ 入居中 ──┘
                                                （数年間）
                                                     │
                                          点検・清掃・修繕が続く
```

> **なぜ循環が重要なのか**
> 【Inference】管理では、**同じ部屋が何度も同じサイクルを回ります**。
> 【Example】モデル企業の管理戸数850戸、年間退去約170戸（退去率20%と置いた場合）なら、
> **毎月14戸前後がこのサイクルのどこかにいる**ことになります。
> 【Inference】つまり管理のモノの流れは「1件を追う」ものではなく、
> 「850戸のうち今どの部屋がどの状態にあるか」を常に把握し続けるものです。

## 7-2 権利の移転①：所有権が動く（売買）— 登記が引渡しに相当する

### 所有権とは

> **所有権（しょゆうけん）**
> → その物を自由に使い、貸し、売り、壊すことができる、最も強い権利のことです。
> → 実務例：自分の家なら、住んでも人に貸しても売っても壊して建て替えてもよい。

### 所有権はいつ移るのか — 2つの条文を分けて読む

**条文①：当事者の間では、意思表示だけで移る**

【Fact】民法第176条
> **物権の設定及び移転は、当事者の意思表示のみによって、その効力を生ずる。**

**条文②：しかし第三者に対しては、登記がなければ主張できない**

【Fact】民法第177条
> **不動産に関する物権の得喪及び変更は、不動産登記法……その他の登記に関する法律の定めるところに従い
> その登記をしなければ、第三者に対抗することができない。**

**条文③：売主には、登記を備えさせる義務がある**

【Fact】民法第560条
> 売主は、買主に対し、登記、登録その他の売買の目的である権利の移転についての
> **対抗要件を備えさせる義務を負う。**

> **この3つが意味すること（初心者向けの説明）**
> 【Inference】売主と買主の2人の間では、「売ります」「買います」の合意で所有権が動きます（第176条）。
> しかし、その事実は**外からは見えません**。
> もし売主が同じ家を別の人にも売ってしまったら、どちらが本当の所有者か決まりません。
> 【Inference】そこで「**登記した人が勝つ**」というルールが置かれています（第177条）。
> **だから買主にとって「モノを受け取った」といえる状態は、鍵をもらったことではなく、
> 自分の名義に登記が移ることです。**

> **登記（とうき）**
> → 土地・建物について「どこにある、どんな大きさの、誰のものか、誰が担保に取っているか」を
>    国（法務局）の帳簿に記録する仕組みのことです。
> → 実務例：登記事項証明書を取ると、所有者の氏名・住所、抵当権（担保）の有無が分かる。
>    売却相談（B-01）で最初に確認するのはこれです。
> → 【Fact】不動産登記法第3条は、登記することができる権利として所有権・地上権・賃借権・抵当権などを挙げています。

### 【Fact】登記は原則として売主と買主が共同で申請する

【Fact】不動産登記法第60条
> 権利に関する登記の申請は、法令に別段の定めがある場合を除き、
> **登記権利者及び登記義務者が共同してしなければならない。**

> **これがなぜ決済の段取りを決めるのか**
> 【Typical】所有権移転登記では、**登記権利者＝買主、登記義務者＝売主**です。
> 2人が共同して申請する必要があるため、実務では**双方が司法書士に委任する**形をとります。
> 【Inference】司法書士が両者の書類を同じ場に集めて確認するからこそ、
> 「代金の支払い」と「権利の移転」を実質的に同時に行うことができます（B-14）。

### 【Fact】決済日に物理的・法的に動くもの（B-14）

```
 決済日（買主が融資を受ける金融機関の一室）【Typical】

 ① 司法書士が本人確認と書類確認
      売主が持参 ── 登記識別情報（または登記済証）、印鑑証明書、実印、
                    固定資産評価証明書、（抵当権があれば）抹消書類
      買主が持参 ── 本人確認書類、実印、住民票、残代金、登記費用
                     ↓
      司法書士「この書類で登記できます」と確認
 ② 住宅ローンの実行（買主の口座へ入金）
 ③ 残代金の振込（買主 → 売主）
 ④ 売主のローン残債を返済 → 抵当権抹消書類を受領
 ⑤ 固定資産税・都市計画税・管理費・修繕積立金の日割精算
 ⑥ ★ 鍵・物件関係書類の引渡し（売主 → 買主）← 唯一の物理的なモノの移動
 ⑦ 仲介手数料の残額、登記費用の支払
 ⑧ 司法書士が法務局へ登記を申請（当日中）
      ↓
 （数日〜2週間後）【Varies】登記完了。買主名義の登記識別情報が交付される
```

**⑥で実際に渡されるモノ**【Typical】

| 渡されるモノ | なぜ必要か |
|---|---|
| **鍵**（玄関・勝手口・門扉・郵便ポスト・車庫、スペアを含む全本数） | 建物を使うために必要。本数を確認して引き渡す |
| 建築確認済証・検査済証 | 【Inference】建物が適法に建てられたことを示す書類。将来の売却・増改築で必要になる |
| 設備の取扱説明書・保証書 | 給湯器・エアコン・食洗機などの使い方と保証の確認 |
| 地積測量図・境界標の位置の資料 | 隣地との境界の確認 |
| 管理規約・使用細則（区分所有建物の場合） | ペット・楽器・リフォームの可否などのルール |
| 確定測量図・越境の覚書（あれば） | 塀や配管が隣地にかかっている場合の取り決め |

> **なぜ鍵だけでは足りないのか**
> 【Inference】鍵は「今日から使える」ことを意味しますが、
> 「これは自分のものである」ことを第三者に示すのは登記です。
> 【Inference】さらに「適法な建物か」「境界はどこか」「何をしてよいか」は書類でしか分かりません。
> 不動産の引渡しが**鍵＋書類＋登記**の3点セットになっているのはこのためです。

## 7-3 権利の移転②：使用する権利が渡る（賃貸）— 鍵が引渡しに相当する

### 賃貸では所有権は動かない

【Fact】民法第601条（賃貸借）
> 賃貸借は、当事者の一方が**ある物の使用及び収益を相手方にさせることを約し**、
> 相手方が**これに対してその賃料を支払うこと**及び**引渡しを受けた物を契約が終了したときに
> 返還することを約する**ことによって、その効力を生ずる。

> **条文から読み取れること**
> 【Fact】賃貸借は「使用及び収益をさせる」契約であって、所有権を移す契約ではありません。
> 【Fact】そして条文自身が「**引渡しを受けた物を契約が終了したときに返還する**」と書いています。
> **借りたものは返すのが前提**であり、これが退去・原状回復・敷金精算の根っこにあります。

### だから賃貸の「引渡し」は鍵渡しである（A-10）

```
   賃貸の引渡し（A-10 鍵の引渡し）

   契約成立（A-08）           所有権は動かない
        ↓                    登記も動かない
   初期費用の入金確認（A-09）
        ↓
   ★ 鍵の引渡し（A-10）  ←  ここで借主が部屋を使える状態になる
        ↓                    ＝ 賃貸における「引渡し」
   入居開始
```

**鍵を渡す前に確認すること**【Typical】（`04_end-to-end-process.md` A-10）

| 確認すること | なぜ必要か |
|---|---|
| 初期費用の入金が完了しているか | 【Inference】入金前に鍵を渡すと、未入金のまま占有が始まる |
| 契約書類がすべて揃っているか | 署名押印の漏れ、連帯保証人欄の未記入 |
| 保証会社の保証が開始しているか | 保証が始まる前に入居すると、滞納時に保証が及ばないおそれ |
| 火災保険が有効か | 【Inference】入居初日の事故に備える |
| 室内の清掃・原状回復が完了しているか | **前の入居者の原状回復が終わっていないと引き渡せない**（7-6 参照） |

> **一緒に渡されるモノ**【Typical】
> 鍵（本数を確認）、鍵の受領書、入居のしおり（設備の使い方・ゴミ出しのルール・緊急連絡先）、
> 駐車場の許可証・ステッカー（契約がある場合）、宅配ボックスや共用部の暗証番号の案内。

### 賃借権と登記の関係（補足）

> 【Fact】不動産登記法第3条は、登記することができる権利として**賃借権**も挙げています。
> 【Typical】しかし一般の居住用賃貸では、賃借権の登記を行うことは通常ありません。
> 【Fact】建物の賃貸借については、借地借家法第31条が
> 「建物の賃貸借は、その**登記がなくても、建物の引渡しがあったときは**、
> その後その建物について物権を取得した者に対し、その効力を生ずる」と定めています。
> 【Inference】つまり借主は、**鍵を受け取って住み始めた（引渡しを受けた）ことで保護されます**。
> ここでも「鍵＝引渡し」が法的な意味を持ちます。

## 7-4【最重要】物件の状態遷移 — 850戸が今どの状態にあるか

### 状態遷移図

```
                      ┌──────────────────────────────────┐
                      │                                  │
                      ▼                                  │
   ┌───────────┐  ┌───────────┐  ┌───────────┐  ┌────────┴──────┐
   │ ① 空室    │─▶│ ② 募集中  │─▶│ ③ 内見済 │─▶│ ④ 申込あり    │
   │（入居者なし）│  │（広告掲載中）│  │（案内した）│  │（審査中）      │
   └───────────┘  └───────────┘  └───────────┘  └────────┬──────┘
         ▲                ▲                                │
         │                │           審査否認 ─────────────┤
         │                └────────────────────────────────┘
         │                                                  │ 審査承諾
         │                                                  ▼
   ┌─────┴────────┐  ┌──────────────┐          ┌──────────────┐
   │ ⑨ 原状回復中  │  │ ⑧ 空室（退去後）│◀─────────│ ⑤ 契約済    │
   │（工事中）      │◀─│（鍵返却済）      │          │（鍵未渡し）  │
   └──────────────┘  └──────────────┘          └───────┬──────┘
                              ▲                            │
                              │                            ▼
                      ┌───────┴────────┐          ┌──────────────┐
                      │ ⑦ 解約予告中    │◀─────────│ ⑥ 入居中     │
                      │（退去日が決まった）│          │（数年間続く） │
                      └────────────────┘          └──────────────┘
                                                          │  │
                                                    更新 ─┘  └─ 修繕・点検
```

### 各状態で誰が何をするか

| # | 状態 | フロー記号 | 誰が | 何をしているか | この状態の間の収入 |
|---|---|---|---|---|---|
| ① | **空室**（募集前） | — | ③賃貸管理 | 原状回復の完了確認、募集条件をオーナーと相談 | **家賃ゼロ・管理料ゼロ** |
| ② | **募集中** | A-01・A-02 | ⑥販促・集客 | ポータル掲載、マイソク配布、業者間へ情報提供 | **ゼロ** |
| ③ | **内見済** | A-03・A-04 | ②賃貸仲介 | 鍵を持って現地案内。反応を記録 | ゼロ |
| ④ | **申込あり（審査中）** | A-05・A-06 | ③賃貸管理＋保証会社＋オーナー | 入居審査。**この間は他の人に案内を止める**【Typical】 | ゼロ |
| ⑤ | **契約済（鍵未渡し）** | A-07〜A-09 | ②賃貸仲介＋⑦経理 | 重要事項説明、契約、初期費用の入金確認 | **契約時に仲介手数料・ADが入る** |
| ⑥ | **入居中** | A-10〜A-16 | ③賃貸管理 | 家賃入金確認、修繕手配、点検・清掃、オーナー報告 | **毎月 家賃（預り）＋管理料（売上）** |
| ⑦ | **解約予告中** | A-18 | ③賃貸管理 | 退去立会いの日程調整、次の募集の準備（①へ） | 退去日までは家賃・管理料あり |
| ⑧ | **空室（退去後）** | A-19 | ③賃貸管理 | 退去立会い、鍵の全本数の回収、状態の記録 | **ゼロになる** |
| ⑨ | **原状回復中** | A-20〜A-22 | ③賃貸管理＋原状回復業者 | 負担区分の判定、見積、工事、敷金精算 | **ゼロ**（工事費が動く） |

> **【最重要】④の「申込あり」で掲載を止める理由**
> 【Fact】**不動産の表示に関する公正競争規約第21条**は、次の広告表示を禁止しています。
> > (1) 物件が存在しないため、実際には取引することができない物件に関する表示
> > (2) 物件は存在するが、実際には取引の対象となり得ない物件に関する表示
> > (3) 物件は存在するが、実際には取引する意思がない物件に関する表示
>
> 【Fact】この規約は**法令ではなく、不当景品類及び不当表示防止法第36条第1項の規定に基づき
> 設定された公正競争規約**です（同規約第1条。出典：不動産公正取引協議会連合会）。
> 【Inference】申込みが入り、実際には案内できない状態の部屋を掲載し続けることは、
> この規約が禁じる表示に当たり得ます。**だから状態が変わったら掲載を更新・停止する作業が発生します。**
> 詳細は `09_information.md` および `15_rules-customs.md` を参照。

### 【Example】850戸の状態の内訳（説明用の架空の断面）

```
   ある月の1日時点【Example】

   ⑥ 入居中          799戸  ← 94%（入居率）
   ① ② ③ ④ ⑤ ⑧ ⑨   51戸  ← 6%（空室）
       うち
       ② 募集中          30戸
       ④ 申込あり         6戸
       ⑤ 契約済（鍵未渡し） 5戸
       ⑨ 原状回復中      10戸

   ⑦ 解約予告中（⑥の中に含まれる）14戸 ← 翌月以降の退去が決まっている
```

> 【Example】これは説明のための架空の断面です（入居率94%は `03_company-structure.md` の設定値）。
> 【Inference】読み取ってほしいのは、**管理会社の仕事は「51戸をいかに⑥へ戻すか」と
> 「799戸を⑥のまま保つか」の両方である**ということです。
> 【Inference】そして⑧⑨①②の期間が長くなるほど、オーナーの家賃収入と管理会社の管理料収入が止まります。
> このため「空室期間」が `14_kpi.md` の重要な指標になります。

## 7-5 鍵の管理 — 不動産業で唯一、在庫管理に近いもの

### なぜ鍵が管理対象になるのか

【Typical】管理物件の鍵は、内見・修繕・退去立会い・工事の立会いのたびに持ち出されます。
【Example】管理戸数850戸なら、キーボックスには850戸分（＋スペア）の鍵が保管されます。

> **鍵を失うと何が起きるか**
> 【Inference】① 入居者の安全に直結する（第三者が入れる状態になりうる）
> ② シリンダー（錠の芯）の交換費用が発生する
> ③ 誰が持ち出したか分からなければ、原因も特定できない
> 【Typical】このため、鍵の保管と持ち出し・返却の記録が、賃貸管理機能の日常業務の1つになります
> （`03_company-structure.md` 3-6、`05_departments.md` ③ E-③-15）。

### 鍵の流れ（3つの場面）

```
 【場面1】内見のための持ち出し（A-04）

   キーボックス ──▶ 賃貸仲介担当が持ち出し（記録）──▶ 現地で使用
                                                        │
   キーボックス ◀── 返却（記録）◀────────────────────────┘

   ※ 他社管理の物件を案内する場合
   元付業者のキーボックス ──▶ 借用（記録）──▶ 案内 ──▶ 元付業者へ返却


 【場面2】入居時の引渡し（A-10）

   キーボックス ──▶ 入居者へ引渡し（受領書に本数を記載）
                    ※ このとき鍵は借主の手元に移り、会社の保管から外れる
                    ※ 【Typical】前の入居者の鍵を使えなくするため、
                       入居前にシリンダーを交換することが行われる【Varies】


 【場面3】退去時の回収（A-19）

   入居者 ──▶ 全本数を返却 ──▶ 本数を確認 ──▶ キーボックスへ戻す
                                 │
                       不足があれば？
                                 ▼
                   【Typical】不足分の費用（シリンダー交換等）を
                   借主負担として敷金から控除することが行われる【Varies】
```

### 鍵の管理で確認すること

| 確認すること | なぜ必要か | いつ |
|---|---|---|
| 本数（何本渡し、何本返ったか） | 【Inference】1本でも欠けると、誰かが入れる状態が残る | 引渡し時・退去時 |
| 持ち出した人・日時・返却日時 | 【Inference】紛失時に所在をたどれるようにする | 常時 |
| どの物件のどの部屋の鍵か（タグ） | 【Inference】850戸分では、取り違えが起きうる | 常時 |
| シリンダー交換の履歴 | 【Inference】いつ誰が交換したかで、有効な鍵の本数が変わる | 案件発生時 |
| 内見用と引渡し用の区別 | 【Typical】内見用は会社が管理し続け、引渡し用は入居者に渡す | 常時 |
| 共用部（オートロック・宅配ボックス・ゴミ庫）の鍵・暗証番号 | 入居者に伝える必要がある。変更時は周知が必要 | 案件発生時 |

> **【Typical】キーボックス以外の運用**
> 【Varies】現地に暗証番号式のキーボックスを設置し、業者間で番号を共有して内見する運用も行われます。
> この場合、鍵は事務所に戻りませんが、**番号を誰に伝えたか**が管理対象になります。
> 【Varies】どの運用を採るかは会社・物件により異なります。

> **売買における鍵**
> 【Typical】売買では、空き家の内見のために売主から鍵を預かることがあります（B-07）。
> 決済日（B-14）に売主から買主へ全本数を引き渡して終わりです。
> **賃貸管理のように何年も保管し続けることはありません。** ここも仲介と管理の違いです。

## 7-6【最重要】原状回復の範囲 — 「借りた当時の状態に戻すこと」ではない

### まず条文をそのまま読む

【Fact】**民法第621条**（賃借人の原状回復義務）
> 賃借人は、賃借物を受け取った後にこれに生じた損傷
> （**通常の使用及び収益によって生じた賃借物の損耗ならびに賃借物の経年変化を除く。**以下この条において
> 「損傷」という。）がある場合において、賃貸借が終了したときは、その損傷を原状に復する義務を負う。
> **ただし、その損傷が賃借人の責めに帰することができない事由によるものであるときは、この限りでない。**

【Fact】**民法第622条の2第1項**（敷金）
> 賃貸人は、敷金（**いかなる名目によるかを問わず、賃料債務その他の賃貸借に基づいて生ずる
> 賃借人の金銭の給付を目的とする債務を担保する目的で、賃借人が賃貸人に交付する金銭**をいう。以下この条において同じ。）
> を受け取っている場合において、次に掲げるときは、賃借人に対し、
> **その受け取った敷金の額から賃貸借に基づいて生じた賃借人の賃貸人に対する金銭の給付を目的とする債務の額を
> 控除した残額を返還しなければならない。**
> 一 **賃貸借が終了し、かつ、賃貸物の返還を受けたとき。**
> 二 賃借人が適法に賃借権を譲り渡したとき。

### 条文が言っていることの整理

> **第621条が「除く」と書いている2つ**
> - **通常の使用及び収益によって生じた賃借物の損耗**（＝通常損耗）
> - **賃借物の経年変化**
>
> 【Fact】この2つは、条文の文言上、賃借人の原状回復義務の対象から**除かれています**。
> 【Inference】したがって「原状回復＝新品に戻すこと」ではありません。
> 普通に住んでいて生じた傷みと、時間が経ったことによる傷みは、借主が直す対象ではないということです。

> **第622条の2第1項が定めている返還の条件**
> 【Fact】条文は「**賃貸借が終了し、かつ、賃貸物の返還を受けたとき**」と書いています。
> 【Inference】つまり、契約が終わるだけでは足りず、**部屋が返ってきて初めて**返還義務が生じます。
> これが「退去立会いで鍵を全本数受け取る」ことが精算の前提になる理由です。
> 【Fact】また返還額は「**受け取った敷金の額から……債務の額を控除した残額**」です。

### 【Fact】国土交通省ガイドラインの考え方（`04_end-to-end-process.md` A-20 の再掲）

【Fact】国土交通省「原状回復をめぐるトラブルとガイドライン（再改訂版）」は、
原状回復を次のように定義しています（出典：国土交通省）。

> **賃借人の居住、使用により発生した建物価値の減少のうち、賃借人の故意・過失、善管注意義務違反、
> その他通常の使用を超えるような使用による損耗・毀損を復旧すること**

建物価値の減少の3区分と負担：

| 区分 | 内容 | 負担 |
|---|---|---|
| ①-A **経年変化** | 建物・設備等の自然的な劣化・損耗等 | **賃貸人**負担 |
| ①-B **通常損耗** | 賃借人の通常の使用により生ずる損耗等 | **賃貸人**負担 |
| ② それ以外 | 賃借人の故意・過失、善管注意義務違反、通常の使用を超える使用による損耗等 | **賃借人**負担 |

【Fact】同ガイドラインは、賃借人の負担について**建物・設備等の経過年数を考慮**し、
同じ損耗等でも**経過年数に応じて負担を軽減する**考え方を採用しています。
【Fact】また、次の入居者を確保する目的で行う設備の交換・化粧直しなどのリフォームは、
①-A・①-Bの修繕であり**賃貸人が負担すべき**としています。
【Fact】賃借人に特別の負担を課す特約については、
**「特約の必要性があり、かつ暴利的でないなどの客観的、合理的理由が存在すること」**など
一定の要件を示しています。

### モノの流れとして見た原状回復（A-19 → A-22）

```
  A-19 退去立会い
   ├ 鍵を全本数回収            → 7-5 の鍵の流れへ
   └ 室内の状態を借主と一緒に確認 → 写真・チェックシートに記録
        ↓
  A-20 範囲判定・見積
   ├ 【Fact】民法第621条で「除かれる」ものを仕分ける
   │   （通常損耗・経年変化 → 貸主負担）
   ├ ガイドラインの3区分にあてはめる
   └ 経過年数を考慮して借主負担額を算定
        ↓
  A-22 工事手配（実際にモノが直る工程）
   ├ クロス張替え、床の補修、ハウスクリーニング、設備の交換
   ├ 貸主負担分 → オーナーへ請求（または送金から控除）
   └ 借主負担分 → 敷金から控除
        ↓
  A-21 敷金精算
   【Fact】民法第622条の2第1項：賃貸借が終了し、かつ賃貸物の返還を受けたとき、
   受け取った敷金の額から債務の額を控除した残額を返還する
        ↓
  A-01 再募集（① 空室 へ戻る）
```

> **【Example】仕分けの例**（`04_end-to-end-process.md` A-20 の再掲）
> | 事象 | 区分 | 負担 |
> |---|---|---|
> | 日照によるクロスの変色 | ①-A 経年変化 | 貸主 |
> | 家具を置いていた床のへこみ | ①-B 通常損耗 | 貸主 |
> | タバコのヤニによる壁一面の変色・臭い | ② | 借主【Typical】 |
> | ペットが柱をひっかいた傷 | ② | 借主【Typical】 |
> | 掃除をしなかったことによる台所の油汚れ | ② | 借主【Typical】 |
>
> 【Varies】実際の判断は契約書の特約、入居期間、経過年数によって変わります。

> **なぜ工期がモノの流れの制約になるのか**
> 【Inference】原状回復工事が終わるまで内見ができず、募集を始めても案内できません。
> 空室期間はオーナーの家賃収入が止まり、管理会社の管理料収入も減ります。
> 【Typical】このため、退去日から工事完了までの日数が賃貸管理の業務上の関心事になります。
> 【Example】モデル企業の事例では、2月28日退去 → 3月3日発注 → 工期3日で、
> 3月28日の鍵引渡しに間に合っています（`04_end-to-end-process.md` 4-4）。

## 7-7 設備の所有と修繕責任 — 「誰のモノか」で誰が直すかが決まる

### 設備は誰のモノか

賃貸物件の中にあるモノは、**所有者が3通りに分かれます。**

| 種別 | 所有者 | 例 | 壊れたときに直すのは誰か |
|---|---|---|---|
| **建物に付いている設備**（貸主の所有） | **貸主（オーナー）** | 給湯器、キッチン、浴室、トイレ、洗面台、エアコン（備付け）、インターホン、網戸、建具、照明（備付け） | 【Fact】原則として**貸主**（民法第606条第1項） |
| **借主が持ち込んだモノ** | **借主** | 家具、家電、カーテン、借主が自分で付けたエアコン | **借主**（貸主に義務はない） |
| **共用部の設備** | **貸主（または管理組合）** | オートロック、エレベーター、受水槽、共用廊下の照明、ゴミ庫、宅配ボックス | 貸主（または管理組合） |

> **なぜ「誰のモノか」から始めるのか**
> 【Inference】入居者から「エアコンが壊れた」と連絡が来たとき、
> **そのエアコンが備付け（貸主の所有）か、前の入居者が置いていったものか、借主が付けたものか**で、
> 対応がまったく変わります。
> 【Typical】このため、入居時に**設備の一覧（付帯設備表）**を作り、
> どれが貸主の設備かを記録しておく運用が行われます。

> **【Typical】「残置物（ざんちぶつ）」という扱い**
> → 前の入居者が置いていったモノで、貸主が「使ってもよいが、壊れても直さない」とするものです。
> → 実務例：前の入居者のエアコンを残置物とし、「故障しても貸主は修理・交換をしない」と契約書に明記する。
> → 【Inference】備付け設備なら貸主が直す義務を負いますが、残置物としておけばその義務を負わない、
>    という区別のための扱いです。【Varies】採用するかは物件・貸主により異なります。

### 修繕義務の条文

【Fact】**民法第606条第1項**
> **賃貸人は、賃貸物の使用及び収益に必要な修繕をする義務を負う。
> ただし、賃借人の責めに帰すべき事由によってその修繕が必要となったときは、この限りでない。**

【Fact】**民法第606条第2項**
> 賃貸人が賃貸物の保存に必要な行為をしようとするときは、**賃借人は、これを拒むことができない。**

> **条文を分けて読む**
> 【Fact】本文：貸主は「使用及び収益に必要な修繕」をする義務を負う。
> 【Fact】ただし書：**賃借人の責めに帰すべき事由**によって修繕が必要になったときは、この義務を負わない。
> 【Inference】つまり「自然に壊れた → 貸主が直す」「借主のせいで壊れた → 貸主の義務ではない」
> という線引きが条文に書かれています。

### 【Example】負担区分の考え方（`04_end-to-end-process.md` A-15 の再掲）

| 事象 | 一般的な考え方 |
|---|---|
| 給湯器が経年で壊れた | 【Typical】貸主負担（自然に使えなくなったもの） |
| 入居者が鍵を紛失した | 【Typical】借主負担（借主の責めに帰すべき事由） |
| 上階からの水漏れで天井が汚れた | 【Typical】借主の責めに帰さない事由。原則として借主の負担ではない |
| 網戸が破れた（経年劣化） | 【Varies】経年か使い方かで判断が分かれる |

【Varies】具体的な負担区分は契約書の定めと個別事情によります。

### モノの流れとして見た修繕（A-15）

```
   入居者から連絡（故障・水漏れ・鍵の紛失 等）
        ↓
   ③賃貸管理：何が起きているか確認（電話・現地）
        ↓
   ① そのモノは誰の所有か（貸主設備／借主の持ち込み／残置物）
   ② 原因は何か（経年／借主の責めに帰すべき事由／第三者・不可抗力）
   ③ 緊急性はあるか（水漏れ・ガス・鍵は緊急【Typical】）
        ↓
   貸主負担の場合 ──▶ ④オーナー対応：承認を取る（一定額超）
                       ↓
                   設備業者へ発注 ──▶ 部品・機器が現地へ入る
                       ↓
                   工事完了 ──▶ 入居者へ完了連絡
                       ↓
                   ⑦経理：立替 → A-14 のオーナー送金から控除
   借主負担の場合 ──▶ 借主自身が手配、または管理会社が手配して借主へ請求
   保険事故の場合 ──▶ 損害保険会社へ連絡（火災保険・借家人賠償責任保険）
```

> **なぜ管理会社が立替えるのか**
> 【Typical】工事業者への支払は工事完了後すぐに発生しますが、
> オーナーへの請求は月次の送金のタイミングで行われます。
> 【Inference】この時間差を埋めるため、管理会社が先に支払い、
> 家賃から差し引く形で回収する運用が行われます（詳細は `08_money.md`）。

### 建物そのものの維持保全（入居中ずっと続くモノの管理）

【Typical】管理会社は個別の故障対応だけでなく、建物全体の状態も見ています。

| 対象 | 何をするか | 頻度 |
|---|---|---|
| 共用部の清掃 | 廊下・階段・ゴミ置場の清掃、草刈り | 【Varies】契約による（週次・月次など） |
| 共用部の電球・照明 | 切れていないか確認、交換 | 月次（巡回時） |
| 受水槽・消防設備・エレベーター | 法令に基づく点検の手配【Varies】 | 法定・契約上のタイミング |
| 建物の外観・外壁・屋上 | ひび割れ・漏水の兆候の確認 | 【Varies】巡回時 |
| ゴミ出しのルールの周知 | 掲示物の設置・更新 | トラブル発生時 |

> 【Fact】賃貸住宅管理業法第2条第2項は、賃貸住宅管理業を
> 「委託に係る賃貸住宅の**維持保全**（住宅の居室及びその他の部分について、
> 点検、清掃その他の維持を行い、及び必要な修繕を行うことをいう。……）を行う業務」等と定めています。
> 【Inference】つまり点検・清掃・修繕は、法律が管理業務として挙げているものです。
> 具体的な範囲は管理受託契約で定まります【Varies】。

## 7-8 売買における「モノ」— 在庫を持たない仲介と、在庫を持つ開発分譲

本資料のモデル企業は仲介と管理を営むため**在庫（物件）を持ちません**。
しかし `01_overview.md` の5類型のうち **④不動産開発・分譲** と **⑤自社所有賃貸** は、
物件そのものを保有します。モノの流れとしては性質がまったく違うため、対比だけ示します。

| | **①②仲介** | **③管理** | **④開発・分譲** | **⑤自社所有賃貸** |
|---|---|---|---|---|
| 物件を所有するか | **しない** | **しない**（預かるだけ） | **する**（棚卸資産） | **する**（固定資産） |
| モノの流れ | 権利の移転を媒介する | 状態を循環させる | **土地を仕入れ → 建てる → 売る** | 建てて（買って）**貸し続ける** |
| 在庫リスク | ない | ない | **ある**（売れ残れば資金が寝る） | ある（空室が続けば収入が止まる） |
| 先に出るお金 | ほぼない（広告費のみ） | ほぼない（立替修繕費） | **土地代・建築費が先に出る** | 取得費・建築費が先に出る |
| 中小企業の主戦場か | **主戦場**【Typical】 | **主戦場**【Typical】 | 【Typical】必要な資本が桁違いに大きい | 【Varies】兼業する例がある |

> 【Inference】「不動産業は在庫を持つ商売だ」という理解は、④⑤についてのものです。
> **①②③の仲介・管理は在庫を持たない**ため、コスト構造も資金の動きもまったく違います
> （`03_company-structure.md` のコスト構造、`12_business-model.md` を参照）。

## 7-9【Example】1つの部屋を2年半追跡する

> **以下はすべて説明用の架空の事例です。** 設定は `04_end-to-end-process.md` 4-4 と同じです。
> サンライズ203号室（家賃68,000円・共益費3,000円・2年契約）を、モノの流れとして追います。

| 時期 | 状態 | 物理的に何が動いたか | 権利はどうなっているか |
|---|---|---|---|
| 3年前 | ⑥入居中（佐藤さん） | — | 所有権：山田さん／使用権：佐藤さん |
| 1月20日 | ⑦解約予告中 | — | 変わらない（2月28日まで佐藤さんが使える） |
| 1月22日 | ⑥＋②募集中 | 室内写真の撮影（在室のため佐藤さんの承諾を得る） | 変わらない |
| 2月3日 | ③内見済 | **鍵をキーボックスから持ち出し、現地で使用、返却** | 変わらない |
| 2月5〜7日 | ④申込あり | — | 変わらない（契約はまだ成立していない） |
| 2月28日 | ⑧空室 | **佐藤さんから鍵を全本数回収**。室内の状態を記録 | 使用権が山田さんに戻る（賃貸借終了・賃貸物の返還） |
| 3月2日 | ⑨原状回復中 | — | — |
| 3月3〜6日 | ⑨原状回復中 | **クロス張替え・ハウスクリーニングの資材と職人が現地に入る** | — |
| 3月8日 | ①空室 | — | 【Fact】民法第622条の2第1項により敷金の残額51,500円を返還 |
| 3月10日 | ⑤契約済 | 重要事項説明書・契約書の交付（**紙が動く**） | 山田さんと鈴木さんの間に賃貸借契約が成立 |
| 3月28日 | ⑤→⑥ | **★鍵を鈴木さんへ引渡し**（受領書に本数を記載） | 使用権が鈴木さんへ渡る＝**賃貸の引渡し** |
| 4月1日 | ⑥入居中 | — | 契約期間の開始 |
| 8月 | ⑥入居中 | 【Example】**給湯器の部品交換**（経年による故障 → 貸主負担） | 変わらない |
| 2年後 | ⑥入居中 | 更新契約書の取り交わし（**紙が動く**） | 契約が更新される |

> **この表から読み取ってほしいこと**
> 1. **土地と建物は一度も動いていません。** 動いたのは鍵・紙・資材・職人だけです。
> 2. **鍵が動いた瞬間（2月28日と3月28日）が、使用権の移動と一致しています。**
> 3. ⑧⑨①の約1か月（2月28日〜3月28日）は、**家賃も管理料もゼロ**です。
> 4. 給湯器の修理では、**モノ（部品）は現地に入るが、所有権は山田さんのまま**です。
> 5. 売買と違い、**登記は一度も動いていません。**

## 7-10 この章のまとめ

### 押さえるべき9点

1. **不動産は動かない。** 動くのは**権利**と**鍵**と**情報**の3つ。
   【Fact】民法第86条第1項：土地及びその定着物は、不動産とする。
2. **売買では所有権が動き、登記が引渡しに相当する。**
   【Fact】民法第176条（意思表示のみで移転）と第177条（登記がなければ第三者に対抗できない）を分けて理解する。
   【Fact】登記は原則として売主と買主が共同して申請する（不動産登記法第60条）。
3. **賃貸では所有権は動かない。渡るのは使用する権利で、鍵が引渡しに相当する。**
   【Fact】民法第601条：賃貸借は使用及び収益をさせることを約する契約であり、
   借りた物は契約終了時に返還する。
4. **管理のモノの流れは直線ではなく循環する。**
   空室 → 募集 → 内見 → 申込 → 契約 → 入居 → 退去 → 原状回復 → 再募集。
   【Example】850戸のうち毎月14戸前後がこのサイクルのどこかにいる。
5. **申込みが入った部屋は掲載を止める。**
   【Fact】不動産の表示に関する公正競争規約第21条（おとり広告の禁止）。
   ※これは**法令ではなく公正競争規約**であり、景表法第36条第1項に基づき設定されたもの。
6. **鍵は不動産業で唯一、在庫管理に近い対象。** 本数・持ち出し・返却・シリンダー交換を記録する。
7. **原状回復は「新品に戻すこと」ではない。**
   【Fact】民法第621条は**通常の使用及び収益によって生じた損耗ならびに経年変化を除く**と定めている。
   【Fact】敷金は、賃貸借が終了し、かつ賃貸物の返還を受けたときに、
   債務の額を控除した残額を返還する（民法第622条の2第1項）。
8. **設備は「誰のモノか」で誰が直すかが決まる。**
   【Fact】民法第606条第1項：賃貸人は使用及び収益に必要な修繕をする義務を負う。
   **ただし賃借人の責めに帰すべき事由による場合はこの限りでない。**
9. **仲介・管理は在庫を持たない。** 在庫を持つのは④開発・分譲と⑤自社所有賃貸であり、
   モノの流れの性質がまったく違う。
