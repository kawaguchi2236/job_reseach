# 14_kpi.md — 不動産業のKPI・見ている数字

**対象**：日本国内の中小不動産業（モデル企業：株式会社ミナト不動産）
**読み手**：不動産業をまったく知らない人（経営指標の知識も前提としません）
**最終更新**：2026-09-20

> 会社設定は `03_company-structure.md`、収益構造は `12_business-model.md` を前提とします。
> 各機能が見ている数字は `05_departments.md` の O 欄に記載があるため、
> 本ファイルは**数字そのものを主語にして**、意味と読み方を説明します。

## 14-0 KPIとは何か（初心者向け）

> **KPI（ケーピーアイ：Key Performance Indicator ／ 重要業績評価指標）**
> → **「この会社が今どうなっているかを知るために、いつも見ている数字」**のことです。
> → 実務例：賃貸管理を軸にする会社なら「管理戸数」と「入居率」を毎月見る。
>    この2つが分かれば、来月いくら管理料が入るかの見当がつくからです。

> **なぜ数字を見るのか**
> 【Inference】売上は結果です。結果が出てから気づいても、もう変えられません。
> 【Inference】そこで「結果の手前にある数字」を見ます。
> 【Example】賃貸仲介の成約件数は結果ですが、その手前には**反響件数**があります。
> 反響が減っていれば、数週間後に成約も減ります。

### 【最重要】不動産業のKPIは、フローとストックで分かれる

```
  ■ フロー型（仲介）のKPI ─ 「今月どれだけ取れたか」

     反響件数 → 来店件数 → 内見件数 → 申込件数 → 成約件数
                                                   × 1件あたり手数料
                                                   ＝ 仲介収入

     → 毎月ゼロから積み直す。先月の成約は今月の売上に貢献しない


  ■ ストック型（管理）のKPI ─ 「今どれだけ積み上がっているか」

     管理戸数 × 平均家賃 × 入居率 × 管理料率 ＝ 管理料収入

     → 積み上がっている。先月の管理戸数がそのまま今月の売上の土台になる
     → 増減は「新規受託 − 解約」と「入居 − 退去」で決まる
```

> **★この2つは性質がまったく違うため、見方も違います。**
> フロー型は「**期間の間にいくつ通ったか**」（流量）を見ます。
> ストック型は「**今いくつ持っているか**」（残高）を見ます。
> 【Inference】ダムにたとえると、フローは「流れ込む水の量」、ストックは「溜まっている水の量」です。

## 14-1【★最重要】管理戸数 — ストックの中核指標

### 定義

> **管理戸数（かんりこすう）**
> → その会社が管理を受託している**賃貸住宅の部屋数の合計**です。
> → 実務例：10戸のアパートを5棟、8戸のマンションを10棟、戸建を20戸管理していれば、
>    10×5 ＋ 8×10 ＋ 20 ＝ **150戸**。
> → 【Example】モデル企業は**850戸**（オーナー約60名）。

### なぜこれが中核なのか

【Inference】製造業の「生産能力」、小売業の「店舗数」に相当するものです。

```
  管理戸数 850戸
    │
    ├─▶ 【売上】 管理料 月約260万円／年約3,100万円（全社売上の36%）
    │
    ├─▶ 【業務量】 年間退去 約170戸（退去率20%と置いた場合）【Example】
    │              ＝ 月あたり約14戸の退去立会い・原状回復・敷金精算
    │
    ├─▶ 【業務量】 年間更新 約340件（2年契約なら管理戸数の約4割）【Example】
    │              ＝ 月あたり約28件の更新手続
    │
    ├─▶ 【業務量】 入居者からの問い合わせ・修繕依頼（常時）
    │
    ├─▶ 【仲介の案件】 退去した約170戸が、そのまま自社の募集案件になる
    │
    └─▶ 【将来の仕事】 オーナーの相続・資産整理 → 売買仲介につながることがある【Typical】
```

> **★管理戸数は「売上の大きさ」と「業務量の大きさ」を同時に表す**
> 【Inference】管理料収入は管理戸数にほぼ比例して増えます。
> 同時に、退去・更新・修繕・苦情対応といった**仕事の量も比例して増えます**。
> 【Typical】管理戸数と人員配置のバランスが、賃貸管理を軸にする会社の組織設計の中心になります。

### どう変化するか

```
   今月の管理戸数 ＝ 先月の管理戸数
                    ＋ 新規受託（オーナーから新しく預かった戸数）
                    − 解約（管理受託契約が終わった戸数）
                    ± 物件の増減（建て替え、売却 等）
```

> **【Inference】1件の解約が大きい理由**
> 【Example】モデル企業は850戸をオーナー約60名から預かっています。
> つまり**1オーナーあたり平均14戸**です。
> 【Inference】1オーナーが管理を他社に移すと、**一度に十数戸が減ります**。
> 賃貸仲介の1件（十数万円）とは影響の大きさが違います。

## 14-2 入居率（稼働率）と空室

### 定義

> **入居率（にゅうきょりつ）／稼働率**
> → 管理戸数のうち、**実際に入居者がいる部屋の割合**です。
> → 計算：**入居戸数 ÷ 管理戸数**
> → 【Example】モデル企業：799戸 ÷ 850戸 ＝ **94%**

> **★管理戸数 ≠ 入居戸数**
> 【Inference】管理戸数は「預かっている部屋の数」、入居戸数は「今埋まっている部屋の数」です。
> 850戸を管理していても、入居しているのは799戸で、51戸は空室です。
> **この2つを混同すると、収入の計算がまったく合わなくなります。**

### なぜ重要か

```
   【Example】入居率が1ポイント（8.5戸）変わると

     8.5戸 × 平均家賃 65,000円 × 管理料率 5% ＝ 月 約27,600円
     年間で 約33万円

   【Example】入居率が94% → 90% に下がると（4ポイント＝34戸）

     34戸 × 65,000円 × 5% ＝ 月 約110,500円
     年間で 約133万円の管理料収入の減少

   ★オーナー側の影響はもっと大きい
     34戸 × 65,000円 ＝ 月 約221万円の家賃収入の減少
```

> 【Example】これは説明のための架空の計算です。
> 【Inference】読み取ってほしいのは、**入居率はオーナーの収入に直結する**ということです。
> 【Typical】管理会社がオーナーに報告する数字の中心が入居状況であるのは、このためです
> （【Fact】賃貸住宅管理業法施行規則第40条第1項第2号「管理業務の実施状況」）。

### 空室期間

> **空室期間（くうしつきかん）**
> → **退去してから、次の入居者の契約が始まるまでの日数**です。
> → 【Example】モデル企業の事例では、2月28日退去・4月1日契約開始で**約1か月**
>    （`04_end-to-end-process.md` 4-4）。

```
   空室期間の内訳（`07_goods.md` 7-4 の状態遷移に対応）

   退去（A-19）
     ├─ ⑨原状回復中           … 工期。この間は内見できない
     ├─ ①②募集中             … 反響を待つ
     ├─ ③内見済・④申込あり     … 審査
     └─ ⑤契約済（鍵未渡し）    … 契約開始日まで
   次の入居（A-10）
```

| 内訳 | 短くするために見る数字 |
|---|---|
| 原状回復の工期 | **退去日から工事完了までの日数** |
| 募集から申込まで | **反響件数、内見件数** |
| 申込から契約まで | 審査にかかった日数 |

> **【Inference】なぜ工期が関心事になるのか**
> 工事が終わるまで内見ができず、募集を始めても案内できません。
> 空室期間はオーナーの家賃収入が止まり、管理会社の管理料収入も減ります。

## 14-3 フロー型のKPI — 反響から成約までの転換率

### 転換の階段

```
   ① 反響件数      （広告から来た問い合わせの数）
        ↓  反響 → 来店
   ② 来店件数      （実際に店舗へ来た数）
        ↓  来店 → 内見
   ③ 内見件数      （現地を案内した数）
        ↓  内見 → 申込
   ④ 申込件数      （入居申込書を受け付けた数）
        ↓  申込 → 成約（審査の承認率）
   ⑤ 成約件数      （賃貸借契約が成立した数）
```

> **転換率（てんかんりつ）とは**
> → **ある段階から次の段階へ進んだ割合**のことです。
> → 計算：次の段階の件数 ÷ 前の段階の件数
> → 実務例：反響100件のうち40件が来店したなら、反響→来店の転換率は40%。

> **なぜ段階ごとに見るのか**
> 【Inference】成約件数だけを見ても「なぜ減ったか」が分かりません。
> 【Example】反響が減ったのか、来店が減ったのか、内見しても決まらないのか。
> 段階ごとに見れば、**どの段階で落ちているか**が分かります。
> 【Inference】ただし本資料では、どうすればよいかという提案は行いません。
> 「そういう数字を見ている」という事実のみを記述します。

### 【Example】モデル企業の賃貸仲介の数字（説明用の架空の形）

```
   年間成約件数 400件
     │
     ├─ 1件あたり受取額（仲介手数料＋AD）平均 約87,500円
     │    【Fact】仲介手数料の上限は借賃1か月分の1.1倍（告示 第四）
     │    【Varies】ADの有無・金額により1件あたりは大きく変わる
     │
     └─ 賃貸仲介収入 年3,500万円（全社売上の41%）

   月別の分布【Typical】
     1〜3月に年間の4割近くが集中
```

### 売買仲介のKPI

| 数字 | 意味 | 【Example】モデル企業 |
|---|---|---|
| **媒介契約の獲得件数** | 預かった物件の数。**すべての起点** | — |
| **成約件数** | 契約が成立した件数 | **年12件** |
| 成約価格 | 実際に売れた価格 | 物件により大きく異なる【Varies】 |
| **1件あたり受取報酬** | 手数料の単価 | **約117万円**（片手と両手が混在） |
| **売買仲介収入** | 年間の合計 | **1,400万円（全社売上の17%）** |
| 媒介契約から成約までの日数 | 販売にかかっている時間 | 【Typical】3〜6か月 |
| 反響件数・内見件数 | 販売活動の反応 | 【Example】事例では内見6件で成約 |
| **成約価格 ÷ 売出価格** | どれだけ価格を下げて成約したか | 【Example】2,480万円 ÷ 2,680万円 ＝ 約93% |
| **両手・片手の別** | 1件から受け取る報酬が1者分か2者分か | 【Fact】告示 第二の上限は依頼者の一方につきの額 |
| **法定期限の遵守状況** | レインズ登録日、報告日が期限内か | 【Fact】守るべき期限は法定 |

> **★媒介契約の獲得件数が「すべての起点」である理由**
> 【Inference】売買仲介は、預かった物件がなければ何も始まりません。
> 【Fact】そして媒介契約を締結した瞬間から、**7日以内のレインズ登録**（専任の場合）と
> **2週間に1回以上の報告**という法定義務が走り出します
> （宅建業法第34条の2第5項・第9項、同法施行規則第15条の10）。
> 【Inference】つまり獲得件数は「将来の売上の見込み」であると同時に「今負っている義務の量」でもあります。

## 14-4【★最重要】フロー収入とストック収入の比率

### この1つの比率が経営の安定度を表す

> **フロー収入**＝成約するたびに1回だけ入る収入（①売買仲介手数料、②賃貸仲介手数料・AD）
> **ストック収入**＝契約が続く限り毎月入り続ける収入（③賃貸管理料）

```
   【Example】モデル企業の場合

     ストック収入（管理料）        3,100万円  … 36%
     フロー収入（賃貸仲介＋売買仲介） 4,900万円  … 58%
     その他                         500万円  …  6%
     ─────────────────────────────
     合計                         8,500万円

     ストック比率 ＝ 3,100万円 ÷ 8,500万円 ＝ 約36%
```

### なぜこの比率が「安定度」なのか

```
   ■ ストック比率が高い会社（管理中心）

     来月の収入が「だいたい分かる」
       → 管理戸数 × 平均家賃 × 入居率 × 管理料率
     固定費（人件費・家賃）を賄える土台がある
     一方で、1戸あたりが小さいため、大きく増やすには戸数を増やす必要がある


   ■ ストック比率が低い会社（仲介中心）

     来月の収入が「分からない」
       → 成約するかしないかで決まる
     成約が続けば大きいが、ゼロの月もありうる
     【Inference】人件費・店舗家賃は成約に関係なく出ていく
```

> **【Example】もしモデル企業が管理を持たなかったら**
>
> ```
>    売上：賃貸仲介 3,500万円 ＋ 売買仲介 1,400万円 ＋ その他 500万円 ＝ 5,400万円
>    （管理料3,100万円がない）
>
>    固定的な費用【Example】
>      人件費 4,700万円 ＋ 店舗家賃等 700万円 ＋ 通信・システム 200万円
>      ＋ 租税公課等 250万円 ＝ 5,850万円
>
>    → 売上5,400万円に対して固定費5,850万円。
>       【Inference】人員か店舗の規模を変えなければ成り立たない構造になる
> ```
>
> 【Example】これは説明のための架空の計算です。
> 【Inference】読み取ってほしいのは、**管理料3,100万円が固定費の約半分を支えている**という構造です。

> **【Inference】比率をどう読むか（初心者向けのまとめ）**
> | ストック比率 | どういう会社か | 【Inference】何が起きやすいか |
> |---|---|---|
> | **高い**（管理中心） | 管理戸数が多い。毎月の収入が読める | 収入は安定するが、大きく伸ばすには戸数の積み上げが要る |
> | **中程度**【Example】36% | 管理で固定費の一部を賄い、仲介で利益を作る | モデル企業の形 |
> | **低い**（仲介中心） | 成約次第。当たれば大きい | 月ごとの収入の振れが大きい |
>
> **本資料では、どの比率が望ましいかという評価は行いません。** 構造の違いを説明するにとどめます。

### 比率を上げる・下げるものは何か

| ストック（管理料）を増やすもの | ストック（管理料）を減らすもの |
|---|---|
| 新規オーナーからの管理受託 | 管理受託契約の解約 |
| 管理物件の入居率の上昇 | 入居率の低下（空室の増加） |
| 家賃の改定（上昇） | 家賃の改定（下落） |
| — | オーナーが物件を売却したとき |

> **【Typical】管理受託の獲得が経営上の関心事になる理由**
> 【Inference】管理戸数は一度増やすと毎月の収入として積み上がり続けます。
> 逆に、解約されれば一度に大きく減ります（14-1）。
> 【Typical】このため、新規オーナーの開拓と既存オーナーとの関係の維持が、
> ④オーナー対応機能の中心的な業務になります（`05_departments.md` ④）。

## 14-5 管理業務の質を表す数字

### 滞納率・滞納額

> **滞納率（たいのうりつ）**
> → **家賃の支払期日に入金がなかった割合**です。
> → 計算の仕方は会社により異なります【Varies】（件数ベース／金額ベース／月末時点か期日直後か）。

| 見る数字 | 何が分かるか |
|---|---|
| 滞納件数・滞納額 | 回収されていない金額の規模 |
| 滞納月数の分布（1か月／3か月／6か月以上） | 【Typical】**滞納は放置すると増え続ける**。長期化しているものがどれだけあるか |
| **代位弁済の件数・金額** | 保証会社に請求した件数。【Inference】保証で埋められている割合 |
| 保証会社の保証が付いている割合 | 【Inference】保証がない契約の滞納は、直接オーナーの減収になる |

> **なぜ滞納が管理業務にとって重いのか**
> 【Typical】1か月の滞納が6か月になれば、回収も明渡しも難しくなります。
> 【Fact】一方、賃貸人からの解約の申入れ・更新拒絶には**正当の事由**が必要です
> （借地借家法第28条）。
> 【Inference】そのため、早い段階で連絡を取り、保証会社の仕組みを使って回収を図る運用が取られます。

### 更新率・退去率

> **更新率（こうしんりつ）**
> → 契約期間の満了を迎えた契約のうち、**更新された割合**です。
> → 【Inference】更新されれば、その部屋は空室にならず、管理料が続きます。

> **退去率（たいきょりつ）**
> → 1年間に退去した戸数の、管理戸数に対する割合です。
> → 計算：年間退去戸数 ÷ 管理戸数
> → 【Example】モデル企業：170戸 ÷ 850戸 ＝ **20%**（説明用に置いた値）

```
   【Example】退去率が業務量を決める

     退去率 20% → 年間170戸 → 月あたり約14戸
       ・退去立会い        14件／月
       ・原状回復の判定    14件／月
       ・敷金精算          14件／月
       ・工事の手配        14件／月
       ・再募集            14件／月

     退去率が25%になったら → 年間約213戸 → 月あたり約18戸
       → 【Inference】業務量が約27%増える。管理料収入は増えない
```

> **★退去率が上がっても管理料は増えない**
> 【Inference】管理戸数が同じなら、管理料収入は変わりません。
> しかし退去が増えれば、立会い・判定・精算・工事手配・再募集の**業務量だけが増えます**。
> 【Inference】同時に空室期間が発生するため、入居率が下がり、管理料収入はむしろ減ります。
> **退去率は「業務量が増えて収入が減る」方向に働く数字**です。

### 修繕の数字

| 見る数字 | 何が分かるか |
|---|---|
| 修繕件数 | 対応の量。常時発生する |
| 修繕費の総額と、**貸主負担・借主負担の内訳** | 【Fact】民法第606条第1項の負担区分（`07_goods.md` 7-7） |
| **立替えている金額の残高** | 【Inference】業者へ支払済みで、まだオーナー送金から回収していない額 |
| 緊急対応の件数 | 【Typical】水漏れ・ガス・鍵 |
| **原状回復の工期**（退去日から工事完了までの日数） | 【Inference】空室期間に直結する |

## 14-6 1人あたりの数字 — 仕入原価がない商売だから見る

### なぜ「1人あたり」を見るのか

> 【Typical】不動産仲介・管理業には**仕入原価がありません**。
> 【Example】モデル企業では費用の55%が人件費です。
> 【Inference】つまり「人が動いて成約させる」ことが直接そのまま原価になる構造です。
> 【Inference】このため、1人あたりの数字が業績に直結します。

### 主な「1人あたり」の数字

| 数字 | 計算 | 【Example】モデル企業 |
|---|---|---|
| **1人あたり管理戸数** | 管理戸数 ÷ 管理担当者数 | 850戸 ÷ 3名（課長＋担当2名）＝ **約283戸／人** |
| **1人あたり賃貸仲介成約件数** | 年間成約件数 ÷ 賃貸仲介担当者数 | 400件 ÷ 2名＝ **200件／人**（専務の関与を除く） |
| **1人あたり売上** | 年間売上 ÷ 従業者数 | 8,500万円 ÷ 10名＝ **850万円／人** |
| 1人あたり売買仲介成約件数 | 年間成約件数 ÷ 担当者数 | 12件 ÷ 2名（社長・専務）＝ 6件／人 |

> 【Example】これらはモデル企業の設定値から計算した架空の数値です。
> 【Varies】実際の水準は、会社の業務範囲・物件の種類・地域により大きく異なります。
> **本資料では「何戸が適正か」という評価は行いません。**

### 宅建士の人数という制約

> **【Fact】宅建士の人数が、契約できる件数の制約になる**
> 【Fact】重要事項説明は**宅地建物取引士**が行わなければなりません（宅建業法第35条第1項）。
> 【Fact】説明の際は**宅地建物取引士証を提示**します（同条第4項）。
> 【Example】モデル企業は宅建士4名（うち専任2名）なので、重要事項説明を4名で分担できます。
> 【Typical】宅建士が社長1名しかいない会社では、繁忙期の重要事項説明がすべて社長に集中します。

> **【Fact】専任の宅建士の数は法定**
> 【Fact】事務所等ごとに、**業務に従事する者の数に対する割合が5分の1以上**の
> 成年者である専任の宅地建物取引士を置かなければなりません
> （宅建業法第31条の3第1項、同法施行規則第15条の5の3）。
> 【Fact】欠けたときは**2週間以内**に必要な措置を執ります（同法第31条の3第3項）。
> 【Example】モデル企業は業務従事者10名なので2名以上が必要で、専任2名で充足しています。
> 【Inference】つまり**従業者を増やすと、必要な専任宅建士の数も増える**という関係があります。

## 14-8 自社客付率と両手・片手

> **自社客付率（じしゃきゃくづけりつ）**
> → 自社が管理している物件の空室のうち、**自社が客付けして決めた割合**です。
> → 計算：自社が客付けした件数 ÷ 自社管理物件の成約件数

```
   自社管理物件が決まったとき

   ■ 自社が客付け（＝両手）
     仲介手数料（借主から）    … 入る
     AD（貸主から）            … 入る
     他社へのAD支払            … 発生しない

   ■ 他社が客付け（＝片手）
     仲介手数料（借主から）    … 他社が受け取る
     AD                        … 自社が他社へ支払う（費用）
     管理料                    … 自社に入る（変わらない）
```

> 【Inference】自社客付率が高いほど、1件あたりの受取額が大きくなり、AD支払が減ります。
> 【Typical】一方、他社に情報を出さなければ母集団が狭くなり、空室期間が延びる可能性があります。
>
> **なお本資料では、両手・片手のどちらが望ましいかという評価は行いません。
> 制度としてどうなっているか、数字としてどう表れるかのみを記述します。**

## 14-9 会社全体の数字（会計の指標）

### 用語（初心者向け）

> **売上高（うりあげだか）**：1年間に稼いだ金額の合計。**入金とは別**。
> **粗利（あらり／売上総利益）**：売上から直接の原価を引いたもの。
> 【Typical】仲介・管理業には仕入原価がないため、**粗利＝売上に近い形**になります。
> **営業利益（えいぎょうりえき）**：粗利から販管費（人件費・家賃・広告費等）を引いたもの。本業の利益。
> **営業利益率**：営業利益 ÷ 売上高。

### 【Example】モデル企業の数字

| 指標 | 【Example】値 | 補足 |
|---|---|---|
| 年間売上高 | **8,500万円** | 管理料36%／賃貸仲介41%／売買仲介17%／その他6% |
| 費用合計 | 7,750万円 | 人件費55%、店舗家賃8%、広告宣伝費9% |
| **営業利益** | **750万円** | |
| **営業利益率** | **約9%** | |
| 1人あたり売上 | 850万円 | 8,500万円 ÷ 10名 |
| 人件費率 | 55% | 4,700万円 ÷ 8,500万円 |
| 広告宣伝費率 | 9% | 800万円 ÷ 8,500万円 |

> **★口座の残高は指標にならない**
> 【Inference】不動産管理会社の口座には、毎月多額の**他人のお金**が入ります
> （【Example】月約5,194万円の家賃）。
> 【Fact】これは賃貸住宅管理業法第16条・同法施行規則第36条により、
> 自己の固有財産を管理する口座と明確に区分され、
> 帳簿により直ちに判別できる状態で管理されます。
> 【Inference】したがって**「口座にいくらあるか」は会社の業績を表しません**。
> 見るべきは預り金を除いた自社の資金であり、そのために資金繰り表が作られます。

### 見ている残高（預り金）

| 数字 | 何を表すか |
|---|---|
| **預り敷金の残高** | 【Fact】退去時に返す義務があるお金（民法第622条の2第1項） |
| **未送金の家賃の残高** | オーナーに渡すお金 |
| **立替えている修繕費の残高** | まだオーナー送金から回収していない額 |
| 売掛金（未入金の手数料等） | 売上に計上したが入金されていない額 |

## 14-11 この章のまとめ

### 押さえるべき8点

1. **★不動産業のKPIはフロー型とストック型に分かれる。**
   フローは「期間中にいくつ通ったか」（反響→来店→内見→申込→成約）、
   ストックは「今いくつ持っているか」（管理戸数・入居率）。
2. **★管理戸数が中核指標。**
   売上の大きさ（管理料）と業務量の大きさ（退去・更新・修繕）を同時に決める。
   【Example】850戸 ＝ 月約260万円 ＋ 月あたり約14戸の退去・約28件の更新。
3. **★管理戸数 ≠ 入居戸数。**
   【Example】850戸を管理していても、入居しているのは799戸（入居率94%）。
   混同すると収入の計算が合わなくなる。
4. **★フロー収入とストック収入の比率が、経営の安定度を表す。**
   【Example】モデル企業のストック比率は36%。
   管理料3,100万円が固定費の約半分を支え、残りを仲介で埋める構造。
   **本資料では、どの比率が望ましいかという評価は行わない。**
5. **退去率は「業務量が増えて収入が減る」方向に働く。**
   管理戸数が同じなら管理料は変わらないが、退去が増えれば業務量が増え、
   空室期間が発生して入居率が下がる。
6. **1人あたりの数字を見るのは、仕入原価がなく人件費が55%だから。**
   1人あたり管理戸数、1人あたり成約件数、1人あたり売上。
7. **★宅建士の人数が契約できる件数の制約になる。**
   【Fact】重要事項説明は宅地建物取引士が行う（宅建業法第35条第1項）。
   【Fact】専任の宅建士は業務に従事する者の5分の1以上（同法第31条の3第1項、施行規則第15条の5の3）。
   **従業者を増やすと、必要な専任宅建士の数も増える。**
8. **★口座の残高は業績を表さない。**
   【Fact】賃貸住宅管理業法第16条・同法施行規則第36条により、
   管理業務で受領する金銭は自己の固有財産と分別して管理される。
   残高の大半は預り金（他人のお金）。
