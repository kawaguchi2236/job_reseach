# 13_periodic-work.md — 不動産業の定期業務

**対象**：日本国内の中小不動産業（モデル企業：株式会社ミナト不動産）
**読み手**：不動産業をまったく知らない人
**最終更新**：2026-09-20

> 会社設定・機能名は `03_company-structure.md`、業務フロー記号（A-01〜A-22／B-01〜B-15）は
> `04_end-to-end-process.md` を前提とします。
> `04_end-to-end-process.md` 4-6 の一覧を、本章で本格的に展開します。

## 13-0 この章の書き方（先にお断り）

### タイムスケジュールは作りません

> **「何時に何をする」という時間割は本資料では作りません。**
> 【Inference】不動産業の仕事は**相手の都合で動きます**。
> 内見は借主の都合、契約は当事者の都合、決済は金融機関と司法書士の都合、
> 修繕の連絡は故障が起きた時刻に入ります。
> 【Typical】固定した時間割を組める業務は多くありません。
> `common/methodology.md` §3 も「毎週月曜日に行う」のような根拠のない具体化を禁じています。

### 使う頻度の語彙

本章では `common/methodology.md` §5 の分類語のみを使います。

```
常時 / 日次 / 週次 / 月次 / 四半期 / 半期 / 年次
案件発生時 / 問い合わせ時 / 受注時 / 発注時 / 納品時 / 請求時 / 入金時
トラブル発生時 / 法定・契約上のタイミング / その他
```

> **【Fact】法定期限は根拠を示したうえで日数・年数で書きます。**
> 「7日以内」「2週間に1回以上」「5年ごと」といった記述は、すべて条文に基づくものです。

### 【最重要】仲介と管理で、業務のリズムがまったく違う

| | **仲介（フロー型）** | **管理（ストック型）** |
|---|---|---|
| **仕事が始まるきっかけ** | **問い合わせ・相談が来たとき** | **カレンダー**（家賃の支払期日、契約の満了日） |
| **繰り返しがあるか** | ない。1件ごとに始まって終わる | **ある。毎月同じことを繰り返す** |
| **予定が立つか** | 立たない（相手の都合で決まる） | **立つ**（期日が決まっている） |
| **代表的な業務** | 内見案内、重要事項説明、契約、決済 | 家賃の入金確認、オーナーへの送金、更新の案内 |
| **量の決まり方** | 反響の数・成約の数 | **管理戸数**（850戸から機械的に発生する） |
| **本章での扱い** | 主に「案件発生時」「問い合わせ時」 | 主に「日次」「月次」「年次」 |

> **【Inference】中小では、この2つが同じ人に同時に積み上がります。**
> 【Typical】兼務しているスタッフには「今日の案件対応」と「毎月のルーティン」が同時に来ます
> （`03_company-structure.md` 3-2）。

## 13-1 常時（いつ発生するか分からないが、常に起こりうる）

| 業務 | 担当する機能 | 何をするか | 補足 |
|---|---|---|---|

| **空室の募集広告の掲載・更新** | ⑥販促・集客 | 掲載内容の更新、写真の差し替え、条件の変更 | 【Example】常時30戸前後が募集中 |
| **★成約・申込済み物件の掲載停止** | ⑥販促・集客 | 決まった部屋の掲載を複数の媒体で止める | 【Fact】不動産の表示に関する公正競争規約第21条（おとり広告の禁止）※**法令ではなく公正競争規約** |
| **鍵の保管・持ち出し・返却の記録** | ②賃貸仲介／③賃貸管理 | キーボックスの出納、持ち出した人・日時の記録 | 【Example】850戸分の鍵 |
| **電話の一次対応** | 受付・事務パート | 入居者・オーナー・他社業者からの電話を受け、担当へつなぐ | 【Typical】事務スペースの電話は常時鳴る |
| **標識・報酬額の掲示の維持** | ⑨免許・コンプライアンス管理 | 掲示内容が最新か（免許番号、有効期間、専任宅建士の氏名） | 【Fact】宅建業法第50条第1項・第46条第4項、賃貸住宅管理業法第19条 |

| **個人情報を含む書類の保管・廃棄** | ⑧人事・総務 | 施錠保管、廃棄時のシュレッダー処理 | 【Fact】個人情報保護法第23条（安全管理措置） |

## 13-4 月次（★管理のリズムの中心）

### 家賃の入金から送金までの一連の流れ

```
   ① 家賃の支払期日が到来（A-12）
         ↓
   ② 入金データの取得（口座振替の結果、振込、保証会社からの送金）
         ↓
   ③ ★消し込み（誰から入って、誰から入っていないかを確定させる）
         ↓
      ┌──────────────────┴──────────────────┐
      ▼                                        ▼
   ④ 未入金者リストの作成                   ⑤ オーナーごとの送金額の計算（A-14）
         ↓                                     入金額 − 管理料 − 立替費用
   ⑥ 滞納督促（A-13）                            ↓
      電話・書面での督促                      ⑦ ★送金明細書の作成
      保証会社への代位弁済請求                    ↓
         ↓                                  ⑧ オーナーへ送金
   ⑦' オーナーへの報告                           ↓
                                             ⑨ 管理料を自社の売上に計上
```

### 月次業務の一覧

| 業務 | 担当する機能 | 何をするか | 根拠・補足 |
|---|---|---|---|
| **★家賃の入金確認（消し込み）** | ③賃貸管理＋⑦経理・財務 | 入居者ごとに入金があったか・金額が合っているかを確認し、**誰から入って誰から入っていないかを確定させる** | A-12。支払期日の直後。【Varies】確認自体を日次で行うこともある |
| **未入金者リストの作成** | ③賃貸管理 | 未入金の入居者・金額・滞納月数・保証の有無を一覧にする | A-12 |
| **滞納督促・代位弁済の請求** | ③賃貸管理 | 電話・書面での督促。保証会社の保証がある場合は代位弁済を請求する | A-13。トラブル発生時でもあるが、月次の入金確認から機械的に発生する |
| **★オーナーへの送金の計算** | ③賃貸管理＋⑦経理・財務 | 入金額 − 管理料 − 立替修繕費 − 立替広告費等 ＝ 送金額 | A-14 |
| **★送金明細書の作成・送金** | ⑦経理・財務 | オーナーごとの明細を作り、契約で定めた送金日に振り込む | A-14。【Varies】送金日は契約による |
| **管理料の計上** | ⑦経理・財務 | 控除した管理料を自社の売上に計上する | A-14 と同時 |
| **【法定】専任媒介契約の業務処理状況の報告** | ①売買仲介 | 依頼者（売主）へ販売活動の状況を報告する | 【Fact】**2週間に1回以上**（宅建業法第34条の2第9項）。したがって月2回以上 |
| **契約更新の案内** | ③賃貸管理 | 満了が近い契約を抽出し、更新の案内を送付する | A-17。【Example】年間更新約340件＝月あたり約28件 |
| **更新手続・更新料の請求** | ③賃貸管理 | 更新契約書の取り交わし、更新料・更新事務手数料の請求、保証・保険の更新 | A-17 |
| **退去立会い・原状回復・敷金精算** | ③賃貸管理 | 退去のたびに発生するが、管理戸数から機械的に量が決まる | A-19〜A-22。【Example】年間退去約170戸＝月あたり約14戸 |
| **支払業務** | ⑦経理・財務 | 工事業者・広告媒体・保証会社への支払、他社への分配・ADの支払 | 請求時・支払時 |
| **給与計算・支給** | ⑧人事・総務＋⑦経理・財務 | 勤怠の集計、給与計算、支給 | 【Fact】労働基準法第108条（賃金台帳） |
| **【法定】源泉所得税の納付** | ⑦経理・財務 | 給与から徴収した源泉所得税を納付する | 【Fact】**支給した月の翌月10日まで**（所得税法第183条第1項）。納期の特例の適用を受ける場合は異なる【Varies】 |
| **社会保険料・労働保険料の納付** | ⑦経理・財務 | — | 法定・契約上のタイミング |
| **月次決算（試算表の作成）** | ⑦経理・財務 | 売上・費用を締め、試算表を作る。預り金の残高を確認する | 【Inference】預り敷金・未送金家賃の残高が正しいかを確認する |
| **資金繰りの確認** | ⑦経理・財務＋社長 | 翌月以降の入金予定・支払予定・残高を見る | 【Inference】売買仲介は3〜6か月入金がなく、賃貸は季節変動が大きい |
| **媒体別の費用と反響の集計** | ⑥販促・集客 | 媒体ごとの掲載料・反響件数・内見件数・成約件数を集計する | `05_departments.md` E-⑥-10 |
| **KPIの集計** | 各機能＋社長 | 管理戸数、入居率、滞納率、成約件数、反響数 | `14_kpi.md` |

> **★なぜ「消し込み」が月次業務の起点なのか**
> 【Inference】誰から入って誰から入っていないかが確定しないと、
> **オーナーへの送金額も、督促の対象も、管理料の額も決まりません**。
> 【Example】850戸分の入金を1戸ずつ照合する作業が、毎月必ず発生します。
> 【Inference】これが賃貸管理機能の月次のリズムの中心になります。

> **【Fact】預かった家賃は自社のお金と分けて管理する**
> 【Fact】賃貸住宅管理業法第16条は、管理受託契約に基づく管理業務で受領する家賃・敷金・共益費
> その他の金銭を、**自己の固有財産および他の管理受託契約に基づく管理業務において受領する
> 家賃、敷金、共益費その他の金銭と分別して管理**しなければならないと定めています。
> 【Fact】その方法（同法施行規則第36条）：**口座を自己の固有財産を管理するための口座と明確に区分**し、
> かつ、**自己の帳簿により直ちに判別できる状態で管理する方法**。

## 13-6【法定】法定期限のある業務（条文で確認する）

> **★ここが不動産業の定期業務の最大の特徴です。**
> 【Inference】他の多くの業界と違い、不動産業には
> **「この日までにやらなければならない」と法律が定めた業務が多数あります**。
> **複数の法律が別々に定めているため、まとめて1つに要約しないでください。**

### (1) 宅地建物取引業法が定めるもの

| 業務 | 期限 | 条文 |
|---|---|---|
| **媒介契約書（34条の2書面）の作成・交付** | **遅滞なく** | 【Fact】第34条の2第1項 |
| **★レインズ登録（専任媒介）** | **契約の締結の日から7日以内**（**休業日数は算入しない**） | 【Fact】第34条の2第5項、同法施行規則第15条の10 |
| **★レインズ登録（専属専任媒介）** | **契約の締結の日から5日以内**（**休業日数は算入しない**） | 【Fact】同上 |
| **登録を証する書面の引渡し** | **遅滞なく** | 【Fact】第34条の2第6項 |
| **成約の通知（指定流通機構へ）** | **遅滞なく** | 【Fact】第34条の2第7項 |
| **申込みがあったときの報告** | **遅滞なく** | 【Fact】第34条の2第8項 |
| **★業務処理状況の報告（専任媒介）** | **2週間に1回以上** | 【Fact】第34条の2第9項 |
| **★業務処理状況の報告（専属専任媒介）** | **1週間に1回以上** | 【Fact】同上 |
| **重要事項の説明（35条書面の交付・説明）** | **契約が成立するまでの間に** | 【Fact】第35条第1項 |
| **供託所等に関する説明** | **契約が成立するまでの間に** | 【Fact】第35条の2 |
| **37条書面の交付** | 契約が成立したとき、**遅滞なく** | 【Fact】第37条第1項・第2項 |
| **帳簿への記載** | **取引のあつたつど** | 【Fact】第49条 |

## 13-8【Typical】季節性 — 1〜3月の繁忙期

### 何が起きるか

```
   【Typical】1月〜3月

   ■ 入ってくる側
     進学・就職・転勤による部屋探しが集中
       → 問い合わせ・来店・内見・申込・契約が集中
       → 【Typical】賃貸仲介の年間の4割近くがこの3か月に集中

   ■ 出ていく側
     転居する人も同じ時期に動く
       → 解約通知・退去立会いが集中（3月がとくに多い【Typical】）
       → 原状回復工事が集中し、工期が取りにくくなる【Inference】
       → 敷金精算・返金が集中

   ■ 同時に発生すること
     ・重要事項説明の予定が集中する（宅建士の人数が制約になる）
     ・鍵の出し入れが増える
     ・広告費・残業代が増える
     ・立替修繕費が増える
     ・入居と退去が同じ部屋で連続する（退去 → 原状回復 → 入居）
```

### 【Example】繁忙期に同時に走るもの

```
  【Example】ある年の3月（説明用の架空の状況）

   3月上旬  ・2月末退去の10戸の原状回復工事が進行中
            ・4月入居の契約が20件控えている（重要事項説明が必要）
            ・3月末退去の15戸の退去立会いの日程調整
            ・新規の問い合わせが毎日入る
   3月中旬  ・工事完了 → 内見再開 → 追加の申込
            ・契約・重要事項説明が連日
   3月下旬  ・退去立会いが集中
            ・鍵の引渡しが集中（4月1日契約開始が多い）
            ・敷金精算の計算が積み上がる
   3月末    ・月次の家賃入金確認・オーナー送金は通常どおり発生する
            ・年度末の決算対応【Varies】（決算期による）
```

> **【Inference】繁忙期の構造上の特徴**
> 1. **仲介（フロー型）と管理（ストック型）の仕事が同時にピークを迎える。**
>    月次の入金確認・送金は繁忙期でも通常どおり発生します。
> 2. **重要事項説明が一点に集中する。** 【Fact】宅建士でなければ行えないため（宅建業法第35条第1項）、
>    宅建士の人数が制約になります。
> 3. **退去 → 原状回復 → 入居が数週間の間に連続する。**
>    工期が遅れると鍵を渡せず、入居予定日に間に合いません。
> 4. **費用も同時に増える。** 広告費、残業代、立替修繕費。
>
> なお、この状態の良し悪しについて本資料では評価しません。

### 4〜12月

| | 内容 |
|---|---|
| **賃貸仲介** | 【Typical】相対的に薄い。件数が減る |
| **賃貸管理** | **変わらない**。月次の入金確認・送金・更新・修繕対応は同じだけ発生する |
| **売買仲介** | 【Typical】季節性は賃貸ほど明確ではない【Varies】 |
| **収入** | 【Inference】管理料が土台として残り、仲介収入が薄くなる |
| **費用** | 人件費・店舗家賃は変わらない |

## 13-10 この章のまとめ

### 押さえるべき8点

1. **仲介と管理では業務のリズムが違う。**
   仲介は「相手の都合で始まる」、管理は「カレンダーで始まる」。
   本資料ではタイムスケジュール（時間割）を作らない。
2. **★月次のリズムの中心は「家賃の消し込み」。**
   誰から入って誰から入っていないかが確定しないと、
   オーナーへの送金額も督促の対象も管理料の額も決まらない。
3. **★管理戸数が月次の業務量を機械的に決める。**
   【Example】850戸 → 月あたり約14戸の退去立会い・原状回復・敷金精算、約28件の更新手続。
4. **★法定期限のある業務が多数ある。**
   レインズ登録（専任7日以内／専属専任5日以内、休業日を除く）、
   業務処理状況の報告（専任2週に1回以上／専属専任1週に1回以上）、
   重要事項説明（契約が成立するまでの間に）、37条書面の交付（遅滞なく）、
   帳簿への記載（取引のあったつど）、源泉所得税の納付（原則として支給した月の翌月10日まで）。
5. **★5年ごとのものが3つあり、いずれも別のもの。**
   【Fact】宅地建物取引業免許の更新（宅建業法第3条第2項）＝**会社**、
   【Fact】賃貸住宅管理業の登録の更新（賃貸住宅管理業法第3条第2項）＝**会社**、
   【Fact】宅地建物取引士証の更新（宅建業法第22条の2。**交付の申請前6月以内の講習**）＝**個人**。
6. **★帳簿も2つあり、保存期間の規定も別。**
   【Fact】宅建業法第49条の帳簿と賃貸住宅管理業法第18条の帳簿。
   いずれも各事業年度の末日をもって閉鎖し、閉鎖後5年間保存
   （宅建業法のものは自ら売主となる新築住宅に係るものは10年間）。
   **従業者名簿は最終の記載をした日から10年間**（宅建業法施行規則第17条の2第4項）。
7. **★オーナーへの法定報告は年に1回以上。**
   【Fact】賃貸住宅管理業法第20条・同法施行規則第40条第1項：
   **管理受託契約を締結した日から一年を超えない期間ごと**、および**契約期間の満了後遅滞なく**、
   管理業務報告書を作成して**交付して説明**する。
   【Varies】月次の送金明細は契約・運用によるもので、法定の頻度とは区別する。
8. **【Typical】1〜3月は仲介と管理の両方が同時にピークを迎える。**
   賃貸仲介の年間の4割近くが集中し、同時に3月の退去も集中する。
   月次の入金確認・送金は繁忙期でも通常どおり発生する。
