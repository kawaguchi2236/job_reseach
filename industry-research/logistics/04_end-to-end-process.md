# 04_end-to-end-process.md — 全社End-to-End業務フロー（依頼から入金まで）

**対象**：日本国内の中小運輸・物流業
**前提**：`01_overview.md` `02_industry-structure.md` `03_company-structure.md` を読んでいること
**最終更新**：2026-09-17

> このファイルは、**「仕事が入ってから、お金が入るまで」を一続きで追う**ものです。
> 部署ごとに切らず、1本の流れとして見ることで、
> 「誰が何を受け取り、何をして、何を作って、次に誰へ渡すか」が分かります。
> 部署ごとの詳細は `05_departments.md` で扱います。

> **⚠️ 番号の読み方**
> - **ステップ番号**（❶〜⓲）：本ファイル 4-1 の運送フローの手順。
> - **倉庫ステップ**（W1〜W8）：本ファイル 4-4 の倉庫業務フローの手順。
> - **機能番号**（①〜⑨）：`03_company-structure.md` で定義した9機能。
>   本ファイルでは必ず「**② 配車・運行管理機能**」のように「機能」の語を付けて表記します。

## 4-1. 全体像 — 運送の18ステップ

```
【貸切（チャーター）運送の基本フロー】

 ❶引合い受付 → ❷条件ヒアリング → ❸運賃計算・見積 → ❹受注・書面交付
      → ❺配車計画 → ❻庸車手配（自社で足りない場合） → ❼運行指示・前日準備
      → ❽日常点検 → ❾乗務前点呼 → ❿積地へ回送・待機 → ⓫積込
      → ⓬輸送 → ⓭納品（荷降ろし・待機） → ⓮受領書の受け取り
      → ⓯帰庫・乗務後点呼 → ⓰記録の回収（業務の記録・運行記録計）
      → ⓱締め・請求 → ⓲入金・消込
                            ┗━━━━━ 並行して ━━━━━▶ 庸車先への支払
```

### 時間軸のイメージ【Example】

> ※以下は理解のための架空の例です。実際の期間は荷主・契約条件により大きく異なります。

```
 Day -3    Day -1     Day 0                 Day 0        月末      翌月末
   │         │      ┌──┴──────────────┐        │          │         │
 引合い     配車    点呼 積込 輸送 納品 受領書   帰庫      請求      入金
 見積      確定     5:00 6:30 7:00 11:00 11:30  14:00
   │         │      └───────────────────┘        │          │         │
   │         │         運行1日で完結              │          │         │
   │         │                                   │          │         │
   │         └── 前日までに車と人を確定 ──────────┘          │         │
   │                                                        │         │
   └────────────── 役務の提供 ──────────────────────────────┘         │
                                                   └── 回収サイト ────┘
                                                      （締め支払い）
```

> **ここが運輸・物流業を理解するうえで重要**
> 【Typical】**運ぶという仕事は1日で終わるのに、その代金が入るのは1〜2か月後**です。
> 一方、燃料代・高速代・ドライバーの給与・庸車先への支払は先に出ていきます。
> 走れば走るほど、いったんは手元の現金が減る構造になっています。
> 詳しくは `08_money.md` `12_business-model.md` で扱います。

## 4-2. 各ステップの詳細

以下、各ステップについて
**［誰が］［何を受け取り］［何をして］［何を作り］［次に誰へ渡すか］［頻度］［なぜするのか］**
を記述します。

---

### ❶ 引合い受付

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能（担当：営業担当者。小規模企業では社長）／既存荷主からの依頼は ② 配車・運行管理機能が直接受けることも多い |
| **何を受け取り** | 荷主からの依頼（電話、メール、FAX、荷主の配送依頼システム経由）。「○月○日、A工場からB物流センターまで、4t車1台」といった内容 |
| **何をして** | 自社で対応できるかを一次判断する。車格、日時、積地・卸地、荷物の種類、必要な装備（パワーゲート、冷凍機など）を確認する |
| **何を作り** | 引合い記録（案件番号の付与） |
| **次に誰へ** | ❷へ進む（対応可能な場合）／お断り（対応できない場合） |
| **頻度** | **問い合わせ時**。【Varies】既存荷主の定期便は日次で自動的に発生する |

> **なぜするのか**
> 【Typical】引合いの段階で車格と装備を確認するのは、
> 「受けたが積めない」を防ぐためです。パレット積みなのか手積みなのか、
> フォークリフトが使えるのか、荷降ろし場所に4t車が入れるのか——
> これらは運賃だけでなく所要時間にも直結します。

> **新規と既存の違い**
> 【Typical】新規荷主の場合は**与信の確認**が入ります。
> 運送は先にサービスを提供して後から請求するため、
> 相手が支払えない会社だと回収できません。
> 【Varies】与信の取り方（信用調査会社の利用、取引限度額の設定など）は企業により異なります。

### ❷ 条件ヒアリング

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能／② 配車・運行管理機能 |
| **何を受け取り** | 荷主からの依頼内容（❶） |
| **何をして** | 運賃を計算するために必要な条件を詰める（下表参照） |
| **何を作り** | 見積条件シート／依頼内容の確認メール |
| **次に誰へ** | ❸ 運賃計算へ |
| **頻度** | **問い合わせ時** |

**確認する項目**

| 項目 | なぜ聞くのか |
|---|---|
| 積地（つみち）・卸地（おろしち） | 距離が運賃の基本。高速代の有無も決まる |
| 日時（積込指定・納品指定） | 夜間・早朝なら割増。指定が厳しいほど待機が発生しやすい |
| 荷物の内容・重量・容積 | 車格が決まる。危険物・要冷なら特別な装備が要る |
| 荷姿（にすがた） | パレットか、バラ（手積み）か。手積みなら時間も人手もかかる |
| 荷役の有無 | **積込み・荷降ろしを誰がやるのか**。ドライバーがやるなら料金が発生する |
| 付帯作業の有無 | 仕分け、棚入れ、値札付けなど、運ぶ以外の作業があるか |
| 待機の見込み | バース待ちが常態化していないか |
| 支払条件 | 締め日と支払日。回収までの期間 |

> **用語：荷姿（にすがた）**
> → 荷物がどういう形にまとまっているか。
> → 実務例：「パレット積み」ならフォークリフトで一度に動かせるが、
>    「バラ（ケース単位で山積み）」ならドライバーが1個ずつ手で積む。
>    同じ重量でも作業時間が何倍も変わるため、運賃・料金の前提として必ず確認する。

> **なぜ荷役の有無を最初に確認するのか**
> 【Fact】貨物自動車運送事業法第10条第2項第3号は、運送約款において
> **運送の対価としての運賃**と、**運送以外の役務や特別に生ずる費用に係る料金**とを
> 区分して収受する旨を明確に定めることを求めています（出典：同法／e-Gov法令検索）。
> 【Inference】「運賃に含まれているつもりだった」という食い違いを後から正すのは困難なため、
> 入口で決めておく必要があります。

### ❸ 運賃計算・見積

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能（金額の最終判断は ⑨ 経営機能＝社長） |
| **何を受け取り** | 見積条件シート（❷） |
| **何をして** | 距離・車格・時間・重量から運賃を算出し、待機時間料・積込料・取卸料・高速代・燃料サーチャージ等の料金を積み上げる |
| **何を作り** | **見積書** |
| **次に誰へ** | 荷主へ提出 → ❹へ |
| **頻度** | **問い合わせ時**。定期便は**年次**または契約更新時に見直し |

**運賃の組み立て方【Typical】**

```
  運  賃 ＝ 距離制運賃 または 時間制運賃（車格別）
          ＋ 燃料サーチャージ（燃料価格の変動分）
          ＋ 各種割増（深夜早朝、休日、速達、有料道路を使わない場合 等）

  料  金 ＝ 待機時間料（荷主都合で待たされた時間）
          ＋ 積込料・取卸料（荷役作業の対価）
          ＋ 附帯業務料（仕分け・検品・棚入れ等）
          ＋ 実費（高速道路料金、フェリー代 等）

  請求額 ＝ 運賃 ＋ 料金
```

【Fact】国土交通省が告示する「標準的な運賃」は、**距離制**と**時間制**の運賃表を車格別に示す形をとっており、
令和6年（2024年）3月22日の告示では、
**運賃水準を8%引き上げるとともに、荷役の対価等を新たに加算**しました
（出典：新たなトラックの標準的運賃を告示しました〔令和6年3月22日〕／国土交通省）。

【Fact】同告示に先立つ検討会の提言では、
「待機時間料に加え、荷役作業ごとの**『積込料・取卸料』**を加算」、
「**『下請け手数料』**を設定」、「共同輸配送等を念頭に**『個建運賃』**を設定」、
「リードタイムが短い運送の際の**『速達割増』**や、**有料道路を利用しない**ことによる
ドライバーの運転の長時間化を考慮した割増を設定」といった内容が示されています
（出典：「標準的な運賃・標準運送約款の見直しに向けた検討会」の提言を公表します〔令和5年12月15日〕／国土交通省）。

> **用語：燃料サーチャージ**
> → 燃料価格が上下したときに、その差額を運賃とは別に加算・減算する仕組み。
> → 実務例：基準価格を1リットル120円と決めておき、140円に上がったら差額20円分を上乗せする。
> → 【Fact】令和6年3月の見直しでは、原価のうちの燃料費を120円に変更し、
>    燃料サーチャージも120円を基準価格に設定しています（出典：同上）。
> → **なぜ必要か**：【Inference】燃料費は運送原価の大きな部分を占めますが、
>    運送会社には価格をコントロールする手段がありません。
>    運賃を固定したままにすると、燃料が上がった分だけそのまま利益が減ります。

> **用語：距離制運賃／時間制運賃**
> → **距離制**＝「何km運んだか」で計算する。長距離の幹線輸送に向く。
> → **時間制**＝「何時間、車と人を拘束したか」で計算する。
>    市内を1日かけて何か所も回るような配送に向く。
> → 実務例：「4t車で終日、市内20か所を配送」という仕事は距離では測りにくいため、
>    「4t車8時間」として時間制で見積もる。

### ❹ 受注・書面交付

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能 ／ ② 配車・運行管理機能 |
| **何を受け取り** | 荷主からの発注（注文書、依頼書、システム上の配送依頼、電話） |
| **何をして** | 受注として記録し、**運送契約の内容を書面（または電磁的方法）で相互に交付する** |
| **何を作り** | **受注記録**、**運送契約に関する書面** |
| **次に誰へ** | ❺ 配車計画へ |
| **頻度** | **受注時** |

【Fact】貨物自動車運送事業法第12条第1項は、
**真荷主および一般貨物自動車運送事業者は、運送契約を締結するときは、
国土交通省令で定める場合を除き、
① 運送の役務の内容及びその対価、
② 運送の役務以外の役務の提供が含まれる場合にはその内容及び対価、
③ その他国土交通省令で定める事項
を書面に記載して相互に交付しなければならない**と定めています。
同条第3項により、相手方の承諾を得て電磁的方法で提供した場合は書面を交付したものとみなされます。
（出典：貨物自動車運送事業法／e-Gov法令検索）

【Fact】この書面交付義務は**令和7年（2025年）4月1日から施行**され、
【Fact】**令和8年（2026年）4月1日からは全ての貨物利用運送事業者にも課される**ことになりました
（出典：改正貨物自動車運送事業法（令和7年4月1日施行）について／トラック適正化二法について／国土交通省）。

> **なぜするのか**
> 【Inference】従来は電話1本で運送が発注されることがあり、
> 何をいくらで引き受けたのかが後から確認できませんでした。
> 待機や荷役の対価を請求しようにも、それが契約に含まれていたのかどうかを示すものがありません。
> 書面の相互交付は、この状態を解消するための制度です。

> **用語：運送約款（うんそうやっかん）**
> → 運送を引き受けるときの共通のルールをあらかじめ定めた文書。
>    運賃の収受方法、荷物が壊れたときの責任範囲、引き受けられない荷物などが書いてある。
> → 【Fact】貨物自動車運送事業法第10条第1項により、一般貨物自動車運送事業者は
>    運送約款を定めて**国土交通大臣の認可**を受けなければなりません。
>    ただし、国土交通大臣が定めて公示した**標準運送約款**と同一の約款を定めた場合は、
>    認可を受けたものとみなされます（同条第3項）。
> → 実務例：多くの中小事業者は標準運送約款と同一のものを使い、事務所に掲示している。

### ❺ 配車計画

| 項目 | 内容 |
|---|---|
| **誰が** | ② 配車・運行管理機能（担当：配車担当者＝多くは運行管理者） |
| **何を受け取り** | 受注記録（❹）、翌日の車両の状況（⑤ 車両整備・管理機能から）、ドライバーの出勤予定と労働時間の残り（⑧ 人事・総務機能から） |
| **何をして** | どの荷物を、どの車に、どのドライバーで運ぶかを組み合わせる。1台で複数の仕事を回せないかを検討する（**帰り荷**の手配を含む） |
| **何を作り** | **配車表（配車計画）**、**乗務割** |
| **次に誰へ** | 足りなければ ❻ 庸車手配へ／足りていれば ❼ 運行指示へ |
| **頻度** | **日次**（翌日分を当日の午後から夕方にかけて確定していくのが一般的【Typical】） |

> **なぜするのか — 配車が何を同時に解いているのか**
> 【Typical】配車担当は、次の4つの制約を同時に満たす組み合わせを探しています。
>
> 1. **荷物の制約**：積込時刻・納品時刻が指定されている
> 2. **車両の制約**：車格が合うか、整備で入庫していないか、装備（冷凍機・ゲート）があるか
> 3. **人の制約**：誰が出勤か、その車を運転できる免許を持っているか、慣れたコースか
> 4. **法令の制約**：そのドライバーの労働時間が上限に達していないか
>
> 【Fact】4つ目については、貨物自動車運送事業輸送安全規則第20条第1項第3号が、
> 運行管理者の業務として「定められた**勤務時間及び乗務時間の範囲内において乗務割を作成**し、
> これに従い運転者を事業用自動車に乗務させること」を挙げています。
> 【Fact】その勤務時間・乗務時間は、同規則第3条第4項により
> **国土交通大臣が告示で定める基準に従って**定めるものとされています。
> （出典：貨物自動車運送事業輸送安全規則／e-Gov法令検索）

> **用語：帰り荷（かえりに）／復荷（ふくに）**
> → 荷物を届けた後、帰りの道中で積む荷物のこと。
> → 実務例：東京から大阪へ荷物を運んだ後、空のまま東京へ戻ると、
>    帰りの燃料代・高速代・ドライバーの人件費はまるまる費用になる。
>    大阪で東京行きの荷物を積めれば、同じ1往復で2回分の運賃が得られる。
> → **なぜ重要か**：【Inference】長距離運送の採算は、帰り荷が取れるかどうかで大きく変わります。
>    このため運送会社は、自社で帰り荷を持っていない場合、
>    他社や利用運送事業者（水屋）に帰り荷を探してもらうことがあります。

> **用語：実車率（じっしゃりつ）／空車（からしゃ）**
> → **空車**＝荷物を積んでいない状態で走ること。
> → **実車率**＝走った距離のうち、荷物を積んで走った距離の割合。
> → 実務例：往復600kmのうち、行き300kmは積載、帰り300kmは空車なら実車率50%。
>    詳しくは `14_kpi.md` で扱う。

### ❻ 庸車手配（自社で足りない場合）

| 項目 | 内容 |
|---|---|
| **誰が** | ② 配車・運行管理機能 |
| **何を受け取り** | 配車計画上の不足（❺） |
| **何をして** | 協力会社（庸車先）に電話・メール・求車求貨システムで運送を依頼する。条件と金額を決め、**書面を交付する** |
| **何を作り** | **庸車依頼書**（法第24条第2項の書面）、外注の記録 |
| **次に誰へ** | 庸車先へ／⑦ 経理・財務機能へ（支払の対象として） |
| **頻度** | **案件発生時**。【Varies】繁忙期は日次で発生する |

【Fact】貨物自動車運送事業法第24条第2項は、一般貨物自動車運送事業者が
他の一般貨物自動車運送事業者の運送を利用するときは、
国土交通省令で定める場合を除き、**当該他の事業者に対して**
① 運送の役務の内容及びその対価、② 運送以外の役務が含まれる場合はその内容及び対価、
③ その他国土交通省令で定める事項を記載した**書面を交付しなければならない**と定めています。

【Fact】同法第24条第1項は、さらに次の措置を講ずる**努力義務**を定めています。
- その利用する運送に要する**費用の概算額を把握**したうえで、その概算額を勘案して利用の申込みをすること
- 荷主が提示する運賃・料金がその概算額を下回る場合は、**荷主に対し運賃・料金について交渉をしたい旨を申し出る**こと
- 当該貨物の運送について、当該他の事業者からの**二以上の段階にわたる委託の制限**その他の条件を付すること

【Fact】また同法第23条の4は、真荷主から引き受けた運送について他社の運送を利用するときは、
**二以上の段階にわたる委託を制限するために必要な措置を講ずるよう努めなければならない**と定めています。
国土交通省はこれを「**委託段階を2次までに制限する努力義務**」と説明しており、
令和8年（2026年）4月1日から適用されています
（出典：貨物自動車運送事業法／e-Gov法令検索、トラック適正化二法について／国土交通省）。

**実運送体制管理簿の作成**

【Fact】同法第24条の5第1項により、真荷主から引き受けた貨物の運送
（国土交通省令で定める重量以上のものに限る）について他社の運送を利用したときは、
災害その他緊急やむを得ない場合を除き、真荷主から引き受けた運送ごとに、
① 実運送を行う事業者の商号・名称、② その事業者が実運送を行う貨物の内容・区間、
③ その事業者の**請負階層**（真荷主との運送契約の後に締結された運送契約の数）、
④ その他国土交通省令で定める事項
を記載した**実運送体制管理簿**を作成し、運送が完了した日から**1年間**営業所に備え置く必要があります。

【Fact】元請事業者は、利用する運送を行う他の事業者に対し、
自らの連絡先と、その事業者が運送する貨物の真荷主の商号・名称等を**通知**しなければなりません（同条第2項）。
【Fact】真荷主は、元請事業者の業務取扱時間内であればいつでも、
実運送体制管理簿の**閲覧または謄写を請求**できます（同条第5項）。
（出典：貨物自動車運送事業法／e-Gov法令検索）

> **なぜ庸車をするのか（再掲）**
> 【Typical】荷物の量は日々変動しますが、車両とドライバーの数はすぐに変えられません。
> 山に合わせて車を持てば谷で余るため、**山の部分だけ他社に頼む**ことで保有台数を抑えます。
> 逆に自社の車が空いている日は、他社から庸車を受ける側に回ります。

### ❼ 運行指示・前日準備

| 項目 | 内容 |
|---|---|
| **誰が** | ② 配車・運行管理機能 → ③ 運行（ドライバー）機能 |
| **何を受け取り** | 確定した配車表（❺） |
| **何をして** | 翌日の運行内容をドライバーに伝える（掲示、口頭、端末への配信）。必要な場合は**運行指示書**を作成する |
| **何を作り** | 配車指示、**運行指示書**（対象となる運行の場合） |
| **次に誰へ** | ③ 運行（ドライバー）機能へ |
| **頻度** | **日次** |

【Fact】貨物自動車運送事業輸送安全規則第9条の3第1項は、
**乗務前・乗務後の点呼のいずれも対面（またはこれと同等の効果を有する国土交通大臣が定める方法）で
行うことができない業務を含む運行**ごとに、所定の事項を記載した**運行指示書**を作成し、
これによりドライバーに適切な指示を行い、**これを携行させなければならない**と定めています
（出典：同規則／e-Gov法令検索）。

> **なぜするのか**
> 【Inference】日帰りで戻る運行なら、出発時と帰着時に営業所で点呼ができます。
> しかし泊まりがけの長距離運行では、途中で営業所に戻れません。
> そこで、あらかじめ運行の内容を書面にして持たせ、
> 運行管理者が把握していない状態でドライバーが単独で判断することを避けます。

### ❽ 日常点検

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 運行（ドライバー）機能（方法を定めるのは ⑤ 車両整備・管理機能＝整備管理者） |
| **何を受け取り** | 運行の指示（❼）、車両 |
| **何をして** | 灯火装置の点灯、制動装置（ブレーキ）の作動、タイヤの状態など、日常的に点検すべき事項を目視等で点検する |
| **何を作り** | 点検の結果（異常があれば整備管理者へ報告） |
| **次に誰へ** | ❾ 乗務前点呼へ／異常があれば ⑤ 車両整備・管理機能へ |
| **頻度** | **日次**（法令上は「1日1回、運行の開始前」） |

【Fact】道路運送車両法第47条の2第2項は、
**自動車運送事業の用に供する自動車**等の使用者またはこれを運行する者は、
**1日1回、その運行の開始前**において、日常点検をしなければならないと定めています。
【Fact】点検の結果、保安基準に適合しなくなるおそれがある状態または適合しない状態にあるときは、
必要な整備をしなければなりません（同条第3項）。
【Fact】整備管理者は、この日常点検の**実施方法を定め**、
**点検の結果に基づき運行の可否を決定する**権限を持ちます（同法施行規則第32条第1項第1号・第2号）。
（出典：道路運送車両法、同施行規則／e-Gov法令検索）

> **なぜ毎日やるのか**
> 【Inference】トラックは1日に数百km走り、重い荷物を積みます。
> ブレーキやタイヤの不具合は、そのまま重大事故につながります。
> 「前日は問題なかった」は根拠になりません。

### ❾ 乗務前点呼

| 項目 | 内容 |
|---|---|
| **誰が** | ② 配車・運行管理機能（運行管理者または補助者）→ ③ 運行（ドライバー）機能 |
| **何を受け取り** | 出勤したドライバー、日常点検の結果（❽） |
| **何をして** | 対面（または国土交通大臣が定める同等の方法）で点呼を行い、報告を求め、確認を行い、必要な指示を与える |
| **何を作り** | **点呼記録簿**（1年間保存） |
| **次に誰へ** | ❿ 積地へ回送へ |
| **頻度** | **日次**（運行の業務に従事しようとするたび） |

> **用語：点呼（てんこ）**
> → 運行管理者がドライバー一人ひとりと向き合って、
>    「今日、安全に運転できる状態か」を確認し、記録に残す行為。
> → **この業界で最も特徴的な業務のひとつ**であり、法令上の義務です。

【Fact】貨物自動車運送事業輸送安全規則第7条第1項は、
事業用自動車の運行の業務に従事しようとする運転者等に対して
**対面により、または対面による点呼と同等の効果を有するものとして国土交通大臣が定める方法**
（運行上やむを得ない場合は電話その他の方法）により点呼を行い、
次の事項について**報告を求め、確認を行い、運行の安全を確保するために必要な指示を与える**こと、
と定めています。

| 号 | 確認する事項 |
|---|---|
| 第1号 | 運転者に対しては、**酒気帯びの有無** |
| 第2号 | 運転者に対しては、**疾病、疲労、睡眠不足**その他の理由により安全な運転をすることができないおそれの有無 |
| 第3号 | 道路運送車両法第47条の2第1項・第2項の規定による**点検（日常点検）の実施またはその確認** |
| 第4号 | 特定自動運行保安員に対しては、自動運行装置の設定の状況に関する確認 |

【Fact】同条第4項は、**アルコール検知器**（呼気に含まれるアルコールを検知する機器であって
国土交通大臣が告示で定めるもの）を**営業所ごとに備え、常時有効に保持**するとともに、
酒気帯びの有無の確認を行う場合には、**運転者の状態を目視等で確認するほか、
当該運転者の属する営業所に備えられたアルコール検知器を用いて行わなければならない**と定めています。

【Fact】同条第5項は、点呼を行ったときは、運転者等ごとに
点呼を行った旨、報告・確認・指示の内容、および
① 点呼を行った者と受けた運転者等の氏名、② 事業用自動車を識別できる表示、
③ **点呼の日時**、④ **点呼の方法**、⑤ その他必要な事項
を記録し、**その記録を1年間保存**しなければならないと定めています。
（出典：貨物自動車運送事業輸送安全規則／e-Gov法令検索）

> **なぜするのか**
> 【Inference】飲酒運転や体調不良による運転は、本人だけでなく第三者の生命を奪います。
> しかし本人が「大丈夫です」と言えばそれまで、という状態では確認になりません。
> そこで法令は、**第三者（運行管理者）が確認すること**、
> **機器（アルコール検知器）を使うこと**、**記録に残すこと**の3点を義務づけています。
> 中小企業で配車担当が運行管理者を兼ねているのは、
> どのみち毎朝ドライバー全員と顔を合わせるのが配車の仕事だからです。

> **早朝・深夜の点呼**
> 【Typical】長距離便が午前3時〜5時に出発する会社では、
> その時刻に点呼を行える人が営業所にいなければなりません。
> 【Fact】このため、運行管理者の業務を補助させる**補助者**を選任できる仕組みが
> 置かれています（輸送安全規則第18条第3項）。

### ❿ 積地へ回送・待機

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 運行（ドライバー）機能 |
| **何を受け取り** | 運行の指示（❼）、点呼での指示（❾） |
| **何をして** | 積込場所（荷主の工場・倉庫）へ向かう。到着後、順番を待つ |
| **何を作り** | 待機が発生した場合は**待機時間の記録** |
| **次に誰へ** | ⓫ 積込へ |
| **頻度** | **日次** |

> **用語：待機時間（たいきじかん）／荷待ち（にまち）**
> → 積込・荷降ろしの順番が来るのを待っている時間のこと。
> → 実務例：指定時刻の9時に着いたが、前に5台並んでいて、実際に積み始められたのは11時だった。
>    この2時間が待機時間。

【Fact】貨物自動車運送事業輸送安全規則第8条第1項第7号は、
**荷主の都合により集貨または配達を行った地点（集貨地点等）で待機した場合**には、
次の事項を記録させ、1年間保存しなければならないと定めています。

| 記号 | 記録する事項 |
|---|---|
| イ | 集貨地点等 |
| ロ | 集貨地点等への到着の日時を**荷主から指定された場合**は、当該日時 |
| ハ | 集貨地点等に**到着した日時** |
| ニ | 集貨地点等における積込みまたは取卸し（**荷役作業**）の**開始および終了の日時** |
| ホ | 集貨地点等で、荷造り・仕分その他の運送事業に**附帯する業務**を実施した場合は、その開始・終了の日時 |
| ヘ | 集貨地点等から**出発した日時** |

【Fact】同項第8号は、集貨地点等で荷役作業または附帯業務を実施した場合
（**荷主との契約書に実施した荷役作業等のすべてが明記されている場合**にあっては、
**当該荷役作業等に要した時間が1時間以上である場合に限る**）には、
集貨地点等、荷役作業等の開始・終了の日時、**荷役作業等の内容**、
および**荷主の確認が得られた場合はその旨、得られなかった場合はその旨**を
記録させなければならないと定めています。
（出典：貨物自動車運送事業輸送安全規則／e-Gov法令検索）

> **なぜ待機時間を記録するのか**
> 【Inference】待機の間、ドライバーは拘束されており、車も他の仕事に使えません。
> しかし記録がなければ「どれだけ待たされたか」を示すことができず、
> 待機時間料を請求する根拠も、荷主と改善を話し合う材料もありません。
> 【Fact】厚生労働省も、道路貨物運送業の長時間労働の要因の一つとして
> 「荷主・元請運送事業者の都合による**長時間の荷待ち**」を挙げ、
> 荷主・元請運送事業者に対する要請等の取組を行っています
> （出典：自動車運転者の労働時間等の改善のための基準（改善基準告示）／厚生労働省）。

### ⓫ 積込

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 運行（ドライバー）機能／荷主側の作業者／④ 倉庫・庫内作業機能（自社倉庫からの出荷の場合） |
| **何を受け取り** | 荷物、出荷指示書・納品書 |
| **何をして** | 荷物を車両に積載する。数量を確認する。荷崩れしないよう固縛する |
| **何を作り** | 積込完了の記録、受け取った送り状・納品書 |
| **次に誰へ** | ⓬ 輸送へ |
| **頻度** | **日次** |

【Fact】貨物自動車運送事業輸送安全規則第5条は、貨物を積載するときは
① **偏荷重が生じないように積載する**こと、
② 貨物が運搬中に荷崩れ等により落下することを防止するため、
**貨物にロープまたはシートを掛ける等必要な措置を講ずる**こと
と定めています。
【Fact】同規則第4条は、**過積載による運送の防止**について、
運転者等に対する適切な指導・監督を怠ってはならないと定めています。
【Fact】また貨物自動車運送事業法第15条第3項は、事業者に対し、
**事業用自動車の最大積載量を超える積載をすることとなる運送の引受け、
当該運送を前提とする運行計画の作成、ドライバー等への当該運送の指示**を
してはならないと定めています。
（出典：貨物自動車運送事業法、貨物自動車運送事業輸送安全規則／e-Gov法令検索）

> **用語：送り状（おくりじょう）**
> → 【Fact】商法第571条第1項により、荷送人は運送人の請求により、
>    運送品の種類、容積・重量または包・個品の数と記号、荷造りの種類等を記載した書面を
>    交付しなければならないとされています（出典：商法／e-Gov法令検索）。
> → 実務例：現場では「送り状」「運送状」「伝票」などと呼ばれる紙が荷物とともに動く。
>    何を何個運ぶのかを、荷主・運送会社・納品先の三者が同じ内容で共有するためのもの。

> **用語：過積載（かせきさい）**
> → 車両ごとに決まっている最大積載量を超えて荷物を積むこと。
> → **なぜ禁止されるのか**：【Inference】ブレーキが効かなくなり、
>    タイヤが破裂し、道路そのものを傷めます。
>    運送会社にとっては、1台に多く積めばその分運賃が稼げるという誘因が働くため、
>    法令は事業者側（引受け・運行計画・指示）にも明確に禁止をかけています。

### ⓬ 輸送

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 運行（ドライバー）機能 |
| **何を受け取り** | 積み込まれた荷物、運行の指示 |
| **何をして** | 指定された経路・時刻で目的地へ運転する。休憩をとる。異常時は営業所へ連絡する |
| **何を作り** | **運行記録計の記録**（瞬間速度・運行距離・運行時間）、業務の記録（日報） |
| **次に誰へ** | ⓭ 納品へ |
| **頻度** | **日次** |

【Fact】貨物自動車運送事業輸送安全規則第9条は、次の事業用自動車について、
**瞬間速度、運行距離および運行時間を運行記録計により記録し、その記録を1年間保存**しなければならない
と定めています。

| 号 | 対象となる事業用自動車 |
|---|---|
| 第1号 | **車両総重量が7トン以上**または**最大積載量が4トン以上**の普通自動車 |
| 第2号 | 第1号に該当する被けん引自動車をけん引するけん引自動車 |
| 第3号 | 特別積合せ貨物運送に係る運行系統に配置する事業用自動車 |

【Fact】同規則第20条第1項第11号は、運行管理者の業務として
**運行記録計により記録することのできないものを運行の用に供さないこと**を挙げています。
（出典：貨物自動車運送事業輸送安全規則／e-Gov法令検索）

> **用語：デジタコ（デジタルタコグラフ）**
> → 運行記録計のうち、記録をデジタルデータで残す装置のこと。
>    「タコグラフ」は元々、円形の記録紙に速度を針で描く装置（アナタコ）を指した。
> → 実務例：デジタコのデータを営業所のパソコンに取り込むと、
>    その日の走行距離、速度、急加速・急ブレーキの回数、エンジン停止時間などが分かる。
>    運行管理者はこれを見て、法令上の記録保存を行うとともに、指導の材料にする。

> **用語：異常気象時等における措置**
> → 【Fact】輸送安全規則第11条は、異常気象その他の理由により輸送の安全の確保に支障が生ずるおそれが
>    あるときは、乗務員等に対する必要な指示その他輸送の安全を確保するための措置を講じなければならない
>    と定めています（出典：同規則／e-Gov法令検索）。
> → 実務例：大雪・台風の際に運行の中止や経路変更を決めるのは、
>    現場のドライバーではなく運行管理者の役割である。

### ⓭ 納品（荷降ろし・待機）

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 運行（ドライバー）機能／納品先の担当者 |
| **何を受け取り** | 荷物、送り状・納品書 |
| **何をして** | 納品先に到着し、順番を待ち、荷物を降ろす。納品先の担当者と数量を確認する |
| **何を作り** | 待機・荷役の記録（❿と同じ規定が適用される） |
| **次に誰へ** | ⓮ 受領書の受け取りへ |
| **頻度** | **日次** |

> **注意：ここで接しているのは「お金を払ってくれる相手」ではない**
> 【Typical】納品先（着荷主）は運賃を払っていません。
> しかし現場での要求（待たされる、荷降ろしをさせられる、検品に立ち会わされる）は
> 納品先から出てきます。
> 運送会社がこれを交渉できる相手は**運賃を払っている荷主（発荷主）**です。
> `01_overview.md` 1-4 で触れた「接している相手と契約している相手のずれ」が、
> 最も強く現れるのがこのステップです。

### ⓮ 受領書の受け取り ★この業界で最も重要な書類のひとつ

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 運行（ドライバー）機能 |
| **何を受け取り** | 納品先からの**受領印・サイン** |
| **何をして** | 納品書の控えに受領印またはサインをもらう。数量に過不足があればその場で記載する |
| **何を作り** | **受領書（受領印のある納品書控え）** |
| **次に誰へ** | ⓯ 帰庫時に ② 配車・運行管理機能へ提出 → ⑦ 経理・財務機能へ |
| **頻度** | **納品時** |

> **なぜ受領書が重要なのか**
>
> 【Typical】**受領書がないと、運送が完了したことを証明できず、請求ができません。**
>
> 運送というサービスは形が残りません。
> 「確かに届けた」ことを示すものは、受け取った側の**受領印・サイン**だけです。
> これがないと、荷主から「届いていない」と言われたときに反証する手段がなく、
> 請求書を出しても支払を留保されることがあります。
>
> 【Fact】法律上も、運送人の責任は**運送品の受取から引渡しまで**の間に生じた
> 滅失・損傷・延着について発生します（商法第575条）。
> つまり「いつ引き渡したか」が、責任の終わる時点を決めます。
> 【Fact】そして運送賃は「到達地における運送品の**引渡しと同時に**支払わなければならない」
> のが商法上の原則です（商法第573条第1項）。
> 【Typical】実務では締め支払いによる後払いが一般的ですが、
> **引渡しの事実が支払の前提である**という構造は変わりません。
> （出典：商法／e-Gov法令検索）

> **【Example】受領書がないとどうなるか（架空の例）**
> ドライバーが急いでいて受領印をもらい忘れ、その日のうちに次の配送へ向かった。
> 月末、経理が請求書を作成しようとしたが、この1件だけ受領書がない。
> 荷主に確認すると「納品先に聞いてみる」となり、確認に2週間かかった。
> 結果としてこの1件は翌月請求に回り、入金は1か月遅れた。
>
> 【Inference】1件なら影響は小さいのですが、
> 「受領書が揃わないと締められない」という構造があるため、
> 月末に受領書を回収して突き合わせる作業は、この業界の経理の定番業務になります。

> **用語：検収（けんしゅう）と受領の違い**
> → **受領**＝荷物を受け取ったこと。
> → **検収**＝受け取った荷物の中身・数量・品質を確認して、問題ないと認めること。
> → 実務例：納品先が「箱の数だけ数えて受領印」を押す場合と、
>    「中身を開けて検品してから」の場合がある。後者だと受領書をもらうまで時間がかかる。

### ⓯ 帰庫・乗務後点呼

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 運行（ドライバー）機能 → ② 配車・運行管理機能 |
| **何を受け取り** | 帰着したドライバー、受領書、日報 |
| **何をして** | 対面（または同等の方法）で点呼を行い、事業用自動車・道路・運行の状況について報告を求め、酒気帯びの有無を確認する |
| **何を作り** | **点呼記録簿**（1年間保存） |
| **次に誰へ** | ⓰ 記録の回収へ |
| **頻度** | **日次**（運行の業務を終了したとき） |

【Fact】貨物自動車運送事業輸送安全規則第7条第2項は、
**運行の業務を終了した運転者等に対して**対面により（または同等の方法により）点呼を行い、
**当該業務に係る事業用自動車、道路及び運行の状況について報告を求め、
運転者に対しては酒気帯びの有無について確認**しなければならないと定めています。
運転者等が他の運転者等と交替した場合は、交替した運転者への通告についても報告を求めます。

【Fact】また同条第3項は、**乗務前・乗務後の点呼のいずれも対面（または同等の方法）で
行うことができない業務**を行う運転者等に対しては、
それらの点呼のほかに、**業務の途中において少なくとも1回**、
対面と同等の効果を有する方法（困難な場合は電話その他の方法）により点呼を行い、
酒気帯びの有無と、疾病・疲労・睡眠不足等の有無について報告を求め、確認し、指示をしなければならない
と定めています（**中間点呼**）。
（出典：貨物自動車運送事業輸送安全規則／e-Gov法令検索）

> **なぜ帰ってからも点呼をするのか**
> 【Inference】乗務後の点呼には2つの意味があります。
> 1つは**その日の運行で何が起きたかを会社が把握する**こと
> （道路状況、車両の不具合、荷主とのやり取り、ヒヤリハット）。
> もう1つは**運転を終えた時点での飲酒の有無を確認する**ことです。
> 帰庫後に飲酒して翌朝の運転に影響が残る可能性もあるため、
> 記録として両端を押さえる構造になっています。

### ⓰ 記録の回収と保存

| 項目 | 内容 |
|---|---|
| **誰が** | ② 配車・運行管理機能（運行管理者） |
| **何を受け取り** | 業務の記録（日報）、運行記録計の記録、受領書、高速道路の領収書、給油伝票 |
| **何をして** | 記録を確認し、法定の保存期間どおりに保存する。運賃計算に必要な実績（距離・時間・待機・荷役）を確定させる |
| **何を作り** | **保存された記録**、**運行実績データ** |
| **次に誰へ** | ⑦ 経理・財務機能（請求の基礎）／⑥ 安全管理機能（指導の材料） |
| **頻度** | **日次**（記録の確認）／**法定・契約上のタイミング**（保存） |

【Fact】貨物自動車運送事業輸送安全規則第8条第1項は、
事業用自動車に係る**運転者等の業務**について、業務を行った運転者等ごとに
次の事項を記録させ、**その記録を1年間保存**しなければならないと定めています。

| 号 | 記録する事項 |
|---|---|
| 第1号 | 運転者等の氏名 |
| 第2号 | 従事した運行の業務に係る事業用自動車を識別できる表示 |
| 第3号 | **業務の開始及び終了の地点及び日時**、主な経過地点、**業務に従事した距離** |
| 第4号 | 業務を交替した場合は、その地点及び日時 |
| 第5号 | **休憩または睡眠**をした場合は、その地点及び日時 |
| 第6号 | **車両総重量8トン以上または最大積載量5トン以上**の普通自動車である事業用自動車の場合は、**貨物の積載状況** |
| 第7号 | 荷主都合で待機した場合の記録（❿参照） |
| 第8号 | 荷役作業等を実施した場合の記録（❿参照） |
| 第9号 | **交通事故**または自動車事故報告規則第2条に規定する事故、著しい運行の遅延その他の異常な状態が発生した場合は、その**概要及び原因** |
| 第10号 | 運行指示があった場合は、その内容 |

【Fact】同条第2項により、これらの記録は、運転者等ごとに記録させることに代えて、
**運行記録計により記録することができます**。
その場合、運行記録計で記録されない事項は、運転者等ごとに運行記録計の記録に付記させます。

**保存期間の一覧**

| 記録 | 根拠 | 保存期間 |
|---|---|---|
| 点呼の記録 | 【Fact】輸送安全規則第7条第5項 | **1年間** |
| 業務の記録（日報） | 【Fact】同規則第8条第1項 | **1年間** |
| 運行記録計の記録 | 【Fact】同規則第9条 | **1年間** |
| 事故の記録 | 【Fact】同規則第9条の2 | **3年間**（運行を管理する営業所において） |
| 実運送体制管理簿 | 【Fact】貨物自動車運送事業法第24条の5第1項 | 運送完了日から**1年間**（営業所に備え置く） |

（出典：貨物自動車運送事業法、貨物自動車運送事業輸送安全規則／e-Gov法令検索）

> **なぜここまで記録を残すのか**
> 【Inference】理由は3つあると考えられます。
> 1. **監査・巡回指導への対応**：地方運輸局や適正化事業実施機関が記録を確認する
> 2. **事故が起きたときの検証**：何が原因だったかを事後に追えるようにする
> 3. **請求の根拠**：待機時間・荷役作業の記録がなければ、その対価を請求できない
>
> 3つ目は法令の目的とは別ですが、実務上は極めて大きい意味を持ちます。
> **記録は「法令のため」だけでなく「お金のため」でもある**、という理解が必要です。

### ⓱ 締め・請求

| 項目 | 内容 |
|---|---|
| **誰が** | ⑦ 経理・財務機能 |
| **何を受け取り** | 運行実績データ（⓰）、受領書、庫内作業の実績、倉庫の保管実績 |
| **何をして** | 荷主ごとの締め日で実績を集計し、運賃・料金を計算して請求書を作成する。受領書と突き合わせて漏れがないか確認する |
| **何を作り** | **請求書**、**売掛金の計上** |
| **次に誰へ** | 荷主へ送付 → ⓲ 入金へ |
| **頻度** | **月次**（締め日は荷主ごとに異なる【Varies】：月末締め、20日締め など） |

> **用語：締め日（しめび）**
> → 「いつからいつまでの分をまとめて請求するか」の区切りの日。
> → 実務例：月末締めなら、4月1日〜4月30日の運送分をまとめて請求する。
>    20日締めなら、3月21日〜4月20日の分になる。
> → **なぜ荷主ごとに違うのか**：【Typical】締め日と支払日は荷主側の経理の都合で決まることが多く、
>    運送会社は荷主ごとに異なる締めに合わせて請求を作ることになります。

**請求時に確認されること【Typical】**

| 確認項目 | なぜ確認するのか |
|---|---|
| 受領書がすべて揃っているか | 揃わないと運送完了を証明できない（⓮参照） |
| 待機時間料・荷役料が漏れていないか | 記録（⓰）に基づいて請求する |
| 高速道路代・フェリー代の実費 | 立て替えているため、領収書とともに請求する |
| 燃料サーチャージの適用 | 基準価格との差額を計算する |
| 庸車分の請求 | 自社で運んでいなくても、荷主への請求は自社が行う |

### ⓲ 入金・消込

| 項目 | 内容 |
|---|---|
| **誰が** | ⑦ 経理・財務機能 |
| **何を受け取り** | 荷主からの振込（または手形等） |
| **何をして** | 入金額と請求額を突き合わせ、売掛金を消し込む。差額があれば原因を調べる |
| **何を作り** | **入金記録**、**売掛金残高の更新** |
| **次に誰へ** | 差額があれば ① 営業機能へ（荷主に確認） |
| **頻度** | **月次**（支払日は荷主ごとに異なる【Varies】） |

> **用語：消込（けしこみ）**
> → 請求していた金額に対して入金があったことを確認し、
>    売掛金（まだもらっていないお金）の記録を消す作業。
> → 実務例：4月分として120万円請求していたところ、5月末に118万円が振り込まれた。
>    差額2万円が何なのか（値引きか、1件抜けているか、振込手数料か）を調べる。

> **用語：売掛金（うりかけきん）**
> → 商品やサービスを提供したが、まだ代金をもらっていない状態の金額。
> → **なぜ重要か**：【Typical】運送会社は「運んでから1〜2か月後に入金」という形が一般的なため、
>    常に1〜2か月分の売上が売掛金として外に出たままになります。
>    その間の燃料代・給与は自社の現金で払う必要があります。

### ⓲-b 庸車先への支払（⓱⓲と並行）

| 項目 | 内容 |
|---|---|
| **誰が** | ⑦ 経理・財務機能 |
| **何を受け取り** | 庸車先からの請求書、庸車依頼の記録（❻） |
| **何をして** | 依頼した内容と請求内容を照合し、支払う |
| **何を作り** | **支払記録**、**買掛金（未払金）の消込** |
| **頻度** | **月次** |

> **ここに時間差の問題がある**
> 【Typical】荷主からの入金より、庸車先への支払のほうが先に来ることがあります。
> その場合、運送会社は**まだもらっていないお金を先に払う**ことになります。
> 庸車の比率が高いほど、この立て替えの負担は大きくなります。
> 詳しくは `08_money.md` で扱います。

## 4-3. 【Example】1案件を最初から最後まで追う

> **以下はすべて架空の例です。実在の企業・取引ではなく、金額も説明のための仮の数値です。**

### 案件の概要

| 項目 | 内容 |
|---|---|
| 荷主 | 食品メーカー M社（T運輸倉庫の既存荷主） |
| 内容 | M社の工場（県内）から、S卸売の物流センター（隣県）へ、常温の加工食品を配送 |
| 荷姿 | パレット10枚（1枚あたり約500kg、合計約5トン） |
| 車格 | 中型4t車（増トン） |
| 距離 | 片道約120km |
| 指定 | 積込 7:00、納品 11:00 |

### 時系列

```
【3月10日（月）15:00】❶❷ 引合い・条件確認
  M社の物流担当から配車依頼システム経由で依頼が入る。
  「3月13日（木）、工場7:00積み、S卸センター11:00着、パレット10枚」
  → ② 配車・運行管理機能の配車担当が内容を確認。
     4t車1台で対応可能と判断。荷役はフォークリフトで荷主側が行う（＝ドライバーは荷役なし）と確認。

【3月10日（月）16:00】❸❹ 運賃・受注
  M社とは年間契約があり、この区間の運賃は既に取り決め済み。
  距離制運賃 32,000円 ＋ 燃料サーチャージ 1,600円 ＝ 33,600円（税別）
  高速道路利用の場合は実費を別途請求する取り決め。
  → 契約内容は年間の基本契約書と個別の運送依頼データで書面要件を満たす形にしている。
     （法第12条の書面交付義務への対応）

【3月12日（水）16:00】❺ 配車計画
  配車担当が翌13日の配車表を作成。
  ・車両：中型No.14（4t・パワーゲート付き）
  ・ドライバー：Kさん（このコースは月に数回担当しており勝手が分かる）
  ・Kさんの今月の時間外労働の累計を確認 → 余裕あり
  ・帰り荷：S卸センター近くのJ社から、県内向けの荷物を積んで戻る手配が取れた
    → 往復とも実車になる（❺の「帰り荷」参照）

【3月12日（水）17:00】❼ 運行指示
  配車表を配車室に掲示し、Kさんに翌日の内容を伝える。
  日帰りで営業所に戻る運行のため、運行指示書の作成対象ではない。

【3月13日（木）05:30】❽ 日常点検
  Kさんが車両No.14の日常点検を実施。灯火、ブレーキ、タイヤ、オイル量などを確認。異常なし。

【3月13日（木）05:45】❾ 乗務前点呼
  運行管理者（配車課長）が対面で点呼。
  ・アルコール検知器で測定 → 0.00mg/L、目視でも異常なし
  ・体調確認「昨夜は何時に寝ましたか」→ 睡眠十分
  ・日常点検の実施を確認
  ・指示：「S卸のバースが混みやすいので、10:30には現着するように。待機が出たら時刻を必ず記録」
  → 点呼記録簿に記録（1年間保存）

【3月13日（木）06:00】❿ 積地へ回送
  営業所を出発。M社工場まで20km。

【3月13日（木）06:40】❿ 到着・待機
  M社工場着。指定は7:00のため待機なし（自社都合の早着）。

【3月13日（木）07:00】⓫ 積込
  M社のフォークリフトオペレーターがパレット10枚を積載。
  Kさんは枚数を確認し、荷崩れ防止のためラッシングベルトで固縛。
  M社から送り状（納品書3枚綴り）を受け取る。
  07:25 積込完了、出発。

【3月13日（木）07:25〜10:20】⓬ 輸送
  一般道と高速道路を経由して約120km。途中30分の休憩。
  デジタコが速度・距離・時間を記録。

【3月13日（木）10:20】⓭ 納品先着・待機
  S卸センター着。指定は11:00だが、バースが埋まっており順番待ち。
  10:20 到着、11:40 荷降ろし開始 → **待機 1時間20分**
  → Kさんは業務の記録に、到着日時・荷主指定日時・荷役開始日時を記録
     （輸送安全規則第8条第1項第7号）

【3月13日（木）11:40〜12:10】⓭ 荷降ろし
  S卸センターのフォークリフトで荷降ろし。Kさんは立会いと枚数確認のみ（荷役作業はしていない）。

【3月13日（木）12:10】⓮ 受領書の受け取り
  S卸センターの担当者が納品書に受領印を押す。
  Kさんは受領印のある控え1枚を受け取り、車内のファイルに保管。
  ★これがないと請求できない。

【3月13日（木）12:30】❺ 帰り荷の積込

【3月13日（木）16:00】⓯ 帰庫・乗務後点呼
```

## 4-4. 倉庫業務のフロー（W1〜W8）

運送とは別の流れです。**保管は継続的に発生し、売上も継続的に立ちます。**

```
 W1 入庫予定の連絡 → W2 入庫・荷受 → W3 検品 → W4 格納（ロケーション登録）
      → W5 保管・在庫管理 → W6 出庫指示の受領 → W7 ピッキング・出荷検品
      → W8 積込・出荷
                 ┗━━ 並行 ━━▶ 棚卸（定期）／保管料の計算（締め）
```

### W1 入庫予定の連絡

| 項目 | 内容 |
|---|---|
| **誰が** | 荷主 → ④ 倉庫・庫内作業機能 |
| **何を受け取り** | 入庫予定データ（品名、数量、入荷予定日、車番） |
| **何をして** | 受入体制（人員・スペース・バース）を準備する |
| **何を作り** | 入庫予定表 |
| **頻度** | **日次**／**納品時** |

### W2 入庫・荷受

| 項目 | 内容 |
|---|---|
| **誰が** | ④ 倉庫・庫内作業機能 |
| **何を受け取り** | 荷物、納品書・送り状 |
| **何をして** | トラックから荷降ろしする。数量を数える |
| **何を作り** | 入庫実績、受領（署名・押印） |
| **頻度** | **日次** |

### W3 検品

| 項目 | 内容 |
|---|---|
| **誰が** | ④ 倉庫・庫内作業機能 |
| **何を受け取り** | 荷降ろしされた荷物、入庫予定表 |
| **何をして** | 予定と現物を照合する。品名・数量・**賞味期限／ロット**・外装の破損を確認する |
| **何を作り** | **検品結果**（差異があれば荷主へ報告） |
| **頻度** | **日次** |

> **なぜ検品が重要なのか**
> 【Typical】倉庫は**他人の物を預かっている**ため、
> 「預かった時点で何がいくつあったか」が確定していないと、
> 後から数が合わなかったときに誰の責任か分かりません。
> 【Fact】商法第610条は「倉庫営業者は、寄託物の保管に関し**注意を怠らなかったことを証明しなければ**、
> その滅失又は損傷につき損害賠償の責任を免れることができない」と定めています
> （出典：商法／e-Gov法令検索）。
> 立証の負担が倉庫側にあるため、入庫時の記録が防御の基礎になります。

### W4 格納（ロケーション登録）

| 項目 | 内容 |
|---|---|
| **誰が** | ④ 倉庫・庫内作業機能 |
| **何を受け取り** | 検品済みの荷物 |
| **何をして** | 保管場所（ロケーション）に運び、どこに置いたかを登録する |
| **何を作り** | **在庫データ（ロケーション付き）** |
| **頻度** | **日次** |

> **用語：ロケーション**
> → 倉庫内の保管場所を示す住所のようなもの。「A列-03段-05番」のように番地を振る。
> → **なぜ必要か**：【Inference】4,000㎡の倉庫に数千種類の商品があると、
>    番地がなければ探すだけで時間がかかります。
>    出荷指示が来たときに迷わず取りに行けるようにするための仕組みです。

### W5 保管・在庫管理

| 項目 | 内容 |
|---|---|
| **誰が** | ④ 倉庫・庫内作業機能（倉庫管理主任者を含む） |
| **何を受け取り** | 在庫データ |
| **何をして** | 温度管理、先入先出の管理、賞味期限の管理、火災防止、防虫・防鼠、荷崩れ防止 |
| **何を作り** | **在庫報告**（荷主へ）、**保管実績**（保管料の基礎） |
| **頻度** | **常時**（管理）／**日次・週次・月次**（在庫報告。荷主により異なる【Varies】） |

【Fact】倉庫業法第11条は、倉庫業者に対し、倉庫ごとに倉庫管理主任者を選任して
**倉庫における火災の防止その他の国土交通省令で定める倉庫の管理に関する業務**を
行わせなければならないと定めています（出典：倉庫業法／e-Gov法令検索）。

> **用語：先入先出（さきいれさきだし／FIFO）**
> → 先に入れたものから先に出すこと。
> → 実務例：食品では賞味期限の古いものから出さないと、
>    奥に残った古い在庫が期限切れになって廃棄になる。
>    「どこに、いつ入れたものがあるか」を把握していないと実行できない。

### W6 出庫指示の受領

| 項目 | 内容 |
|---|---|
| **誰が** | 荷主 → ④ 倉庫・庫内作業機能 |
| **何を受け取り** | **出庫指示データ**（出荷先、品名、数量、出荷日） |
| **何をして** | 在庫があるか確認する。作業量から人員を配置する |
| **何を作り** | **ピッキングリスト** |
| **頻度** | **日次**（多くの荷主は前日または当日朝に指示を出す【Varies】） |

### W7 ピッキング・出荷検品

| 項目 | 内容 |
|---|---|
| **誰が** | ④ 倉庫・庫内作業機能 |
| **何を受け取り** | ピッキングリスト |
| **何をして** | 指示された商品を保管場所から取り出し、出荷先ごとにまとめる。数量を再確認する |
| **何を作り** | 出荷準備の完了した荷物、**出荷検品結果** |
| **頻度** | **日次** |

> **用語：ピッキング**
> → 保管されている商品の中から、注文された分だけを取り出す作業。
> → 実務例：「A商品を3ケース、B商品を1ケース、C商品を12個」という指示に従って棚を回る。
>    出荷先が多いほど、回る距離と時間が増える。

### W8 積込・出荷

| 項目 | 内容 |
|---|---|
| **誰が** | ④ 倉庫・庫内作業機能 → ③ 運行（ドライバー）機能 |
| **何を受け取り** | 出荷準備の完了した荷物 |
| **何をして** | トラックに積み込む。送り状・納品書を渡す |
| **何を作り** | **出庫実績**、**在庫データの更新** |
| **次に誰へ** | 運送のフロー（⓫積込）へ接続する |
| **頻度** | **日次** |

### 並行して発生するもの

| 業務 | 内容 | 頻度 |
|---|---|---|
| **棚卸（たなおろし）** | 帳簿上の在庫と実際の在庫を数えて突き合わせる | 【Varies】月次・四半期・年次。荷主との取り決めによる |
| **保管料の計算** | 保管実績に基づき保管料を算出する | **月次** |
| **在庫報告** | 荷主に在庫状況を報告する | 【Varies】日次・週次・月次 |

> **保管料はいつ請求できるのか**
> 【Fact】商法第611条は「倉庫営業者は、**寄託物の出庫の時以後でなければ**、
> 保管料及び立替金その他寄託物に関する費用の支払を請求することができない。
> ただし、寄託物の一部を出庫するときは、出庫の割合に応じて、その支払を請求することができる」
> と定めています（出典：商法／e-Gov法令検索）。
> 【Typical】実務では倉庫寄託約款や荷主との契約で締め・請求の方法を定めるのが一般的ですが、
> 商法上の原則としてこのような規定がある点は押さえておく必要があります。

> **【Fact】保管期間を定めなかった場合**
> 商法第612条は「当事者が寄託物の保管期間を定めなかったときは、倉庫営業者は、
> 寄託物の**入庫の日から6箇月**を経過した後でなければ、その返還をすることができない。
> ただし、やむを得ない事由があるときは、この限りでない」と定めています
> （出典：商法／e-Gov法令検索）。

## 4-5. 2024年4月から適用されたドライバーの時間外労働の上限規制

このフロー全体に、横断的に効いている制約があります。

### 労働基準法上の上限

【Fact】労働基準法第36条は、いわゆる36協定により時間外・休日労働をさせることができる旨を定め、
同条第3項・第4項で**限度時間を1か月45時間・1年360時間**と定めています。
同条第5項の特別条項により臨時的にこれを超える場合でも、
一般には**1年について720時間**を超えない範囲、
**1か月100時間未満**、**複数月平均80時間以内**（同条第6項第2号・第3号）という制限がかかります。

【Fact】これに対し、労働基準法**第140条第1項**は、
**貨物自動車運送事業法第2条第1項に規定する貨物自動車運送事業の業務**その他の
自動車の運転の業務として厚生労働省令で定める業務について、
「当分の間」第36条の規定を読み替えて適用するとしており、
特別条項で定められる**1年についての時間外労働の上限を960時間**とし、
同条第6項第2号・第3号（月100時間未満、複数月平均80時間以内）の規定は**適用しない**としています。

【Fact】同条第2項により、この読替えは**令和6年（2024年）3月31日まで**の間は適用が猶予されていました。
つまり**2024年4月1日から、年960時間の上限が適用されています**。

（出典：労働基準法／e-Gov法令検索）

【Fact】国土交通省も「標準的な運賃」の説明の中で、
「令和6年度から年間960時間の時間外労働の限度時間が設定されること等を踏まえ」と述べています
（出典：「標準的な運賃」について／国土交通省）。

### 改善基準告示

【Fact】これとは別に、**自動車運転者の労働時間等の改善のための基準（改善基準告示）**
（平成元年労働省告示第7号）があり、
**令和4年厚生労働省告示第367号により令和4年12月23日に改正され、
令和6年（2024年）4月1日から適用**されています
（出典：自動車運転者の労働時間等の改善のための基準（改善基準告示）／厚生労働省）。

【Fact】トラック（貨物自動車運送事業）の運転者については、**告示第4条第1項**が
拘束時間・休息期間・運転時間を次のように定めています
（出典：（改正後全文）自動車運転者の労働時間等の改善のための基準（平成元年労働省告示第7号）／厚生労働省）。

| 区分 | 告示の定め（第4条第1項） |
|---|---|
| **1か月・1年の拘束時間** | 1か月について**284時間**を超えず、かつ1年について**3,300時間**を超えない。ただし労使協定により、1年について6か月までは1か月**310時間**まで、1年**3,400時間**まで延長できる（第1号） |
| 同上の歯止め | 上記ただし書の場合、1か月の拘束時間が284時間を超える月が**3か月を超えて連続しない**こと。1か月の時間外労働と休日労働の合計が**100時間未満**となるよう努めること（第2号） |
| **1日の拘束時間** | **13時間**を超えない。延長する場合でも最大拘束時間は**15時間**（第3号） |
| 　同上の例外 | 1週間の運行がすべて**長距離貨物運送**（1運行の走行距離**450km以上**）で、かつその運行の休息期間が運転者の**住所地以外**の場所である場合は、**1週間について2回に限り**最大拘束時間を**16時間**にできる（第3号ただし書） |
| **休息期間** | **継続11時間以上**を与えるよう努めることを基本とし、**継続9時間**を下回らない。上記ただし書に該当する場合は1週間について2回に限り**継続8時間**にでき、その場合は一の運行終了後に**継続12時間以上**を与える（第5号） |
| **運転時間** | **2日（始業時刻から起算して48時間）を平均して1日当たり9時間**、**2週間を平均して1週間当たり44時間**を超えない（第6号） |
| **連続運転時間** | **4時間**を超えない。運転の中断は**1回がおおむね連続10分以上、かつ合計30分以上**（第7号）。高速道路等のSA・PA等に駐停車できずやむを得ない場合は**4時間30分**まで延長できる（同号ただし書） |

> **【Fact】予期し得ない事象への対応時間**
> 1日の拘束時間・2日平均の運転時間・連続運転時間の適用にあたっては、
> **予期し得ない事象への対応時間をそれらの時間から除くことができます**（第4条第3項）。
> この場合、勤務終了後に第1項第5号本文の継続した休息期間を与えます。

> **⚠️ 本資料が扱わない範囲**
> 上記は告示本文の定めです。**分割休息・2人乗務・隔日勤務の特例**（第4条第4項）、
> 本資料で扱っていない細目、および**個別の事案がこれらに該当するかの判断**については、
> 厚生労働省の上記ページに掲載されている告示本文および
> 「トラック運転者の労働時間等の改善基準のポイント」を参照してください。
> （`19_sources.md` に所在を記録しています）

> **用語：拘束時間（こうそくじかん）**
> → 始業から終業までの時間。労働時間だけでなく**休憩時間・待機時間も含む**。
> → 実務例：5時に点呼を受け、17時に帰庫したら拘束時間は12時間。
>    そのうち3時間が待機で動いていなくても、拘束時間には入る。
> → **なぜこの概念があるのか**：【Inference】ドライバーは待機中も自宅に帰れず、
>    自由に過ごせるわけではありません。実際に運転していた時間だけを見ると、
>    その日どれだけ会社に縛られていたかが分かりません。

### この規制がフローのどこに効くか

| ステップ | どう効くか |
|---|---|
| ❺ 配車計画 | 【Typical】ドライバーごとの時間外労働の累計を見ながら配車する必要がある |
| ❿⓭ 待機 | 【Typical】待機時間は拘束時間に含まれるため、長い待機は「走れる時間」を食う |
| ⓬ 輸送 | 【Typical】1日で行って帰れない距離は、途中で休息をとるか、交替運転者を配置するか、中継するかの検討が必要になる |
| ❸ 運賃 | 【Fact】標準的な運賃の制度趣旨そのものが、この上限規制を前提に説明されている（出典：「標準的な運賃」について／国土交通省） |

> **本資料の立場**
> ここでは「2024年4月から年960時間の上限が適用された」という**制度の事実**と、
> それが業務フローのどこに関係するかを記述しています。
> それが業界にとって良いか悪いか、どう対応すべきかについては、本資料では扱いません。

## 4-6. この章のまとめ

1. **運送は18ステップ**。引合い → 見積 → 受注・書面交付 → 配車 → 点呼 → 積込 → 輸送 →
   納品 → **受領書** → 帰庫・点呼 → 記録 → 請求 → 入金。
2. **点呼は法令上の義務**。乗務前・乗務後の両方で、アルコール検知器を使い、記録を1年間保存する
   （【Fact】貨物自動車運送事業輸送安全規則第7条）。
3. **受領書がないと請求できない**。運送は形が残らないため、受領印が唯一の証明になる。
4. **待機時間・荷役作業は記録義務がある**（【Fact】同規則第8条第1項第7号・第8号）。
   記録は法令対応であると同時に、対価を請求する根拠でもある。
5. **庸車には書面交付義務と、委託段階の制限、実運送体制管理簿の作成義務がかかる**
   （【Fact】貨物自動車運送事業法第23条の4・第24条・第24条の5）。
6. **帰り荷が取れるかどうかで採算が変わる**。
7. **倉庫は別のフロー（W1〜W8）**。売上は保管期間の経過とともに継続的に発生する。
8. **2024年4月1日から、ドライバーの時間外労働は年960時間が上限**
   （【Fact】労働基準法第140条第1項・第2項）。配車計画はこの制約の下で組まれる。
