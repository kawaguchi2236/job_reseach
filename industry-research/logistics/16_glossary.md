# 前半：用語集

## 16-1. 事業と制度の基本語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **運送** | 貨物自動車運送事業 等 | モノの**場所を変える**こと | 「運送の話ですか、倉庫の話ですか」で適用される法律も約款も変わる。会話の入口で必ず確認する |
| **倉庫** | 倉庫業 | 寄託を受けた物品を**保管する**こと | 「倉庫を持っている」と言われたら、営業倉庫か自家倉庫かを確認しないと話が噛み合わない |
| **物流** | — | モノの流れ全般を指す総称 | 【Fact】国土交通省が物流部門で所管する物流産業として挙げているのは倉庫業・貨物利用運送事業・トラックターミナル業（出典：物流産業の紹介／国土交通省）。行政上も単一の業種を指す言葉ではない |
| **一般貨物自動車運送事業** | 同左 | 【Fact】**他人の需要に応じ、有償で、自動車**（三輪以上の軽自動車及び二輪の自動車を除く）**を使用して貨物を運送する事業**（特定貨物自動車運送事業以外のもの。貨物自動車運送事業法第2条第2項） | 【Fact】経営には国土交通大臣の**許可**が必要（同法第3条）。緑ナンバーのトラック運送会社はこれ |
| **貨物軽自動車運送事業** | 同左 | 軽自動車・二輪車で他人の貨物を有償で運送する事業 | 【Fact】**届出**で足りる（同法第36条）。宅配のラストワンマイルを担う軽貨物の個人事業主が多い【Typical】 |
| **特別積合せ貨物運送** | 同左 | 【Fact】営業所等で集貨した貨物の**仕分**その他の業務を行い、事業場の間で**一定の日時に、一定の経路に従って**行う運送（同法第2条第6項） | いわゆる「路線便」の制度上の呼び名 |
| **実運送（じつうんそう）** | 同左 | **自分の会社のトラックで、自分の会社のドライバーが実際に運ぶ**こと | 「御社は実運送もされていますか」＝自社で車を持っているかという質問 |
| **利用運送（りようそう）** | 貨物利用運送事業 | **自分では運ばず、他の運送会社に運んでもらう**こと。自分は荷主と運送契約を結び運ぶ責任を負う | 【Fact】第一種は**登録**、第二種は**許可**（貨物利用運送事業法第3条・第20条）。車を持たない運送業者が存在する |
| **水屋（みずや）** | （俗称）利用運送事業者 | 車両を持たず、荷主から受けた荷物を他社に運んでもらう事業者の業界での呼び名 | 「あそこは水屋さんだから車はないよ」。帰り荷を探すときに頼ることもある |
| **庸車（ようしゃ）** | （貨物自動車利用運送） | **他の運送会社に運んでもらうこと**、またはその相手の車・会社 | 「明日3台必要だが2台しか出せない。1台庸車に出す」。逆に自社の車が空いていれば「庸車を受ける」側に回る |
| **貨物自動車利用運送** | 同左 | 【Fact】一般貨物自動車運送事業者等が他の一般貨物自動車運送事業者等の行う運送（実運送に係るものに限る）を利用してする貨物の運送（貨物自動車運送事業法第2条第7項） | 庸車の法令上の呼び名 |
| **元請（もとうけ）** | — | 荷主から**直接**仕事を受けた会社 | 「元請さんからの庸車です」＝元請の下請として受けている |
| **下請（したうけ）** | — | 元請から仕事を受けた会社。さらに2次・3次がある場合がある | 【Fact】法は委託段階を2次までに制限する努力義務を定めている（貨物自動車運送事業法第23条の4） |
| **荷主（にぬし）** | — | 運んでほしい荷物を持っている側。運送を頼む人 | 運賃を払う相手。現場で接する納品先とは別人であることが多い |
| **真荷主（しんにぬし）** | 同左 | 【Fact】自らの事業に関して運送を委託する者であって、運送事業者・利用運送事業者ではないもの（貨物自動車運送事業法第12条第2項） | 「最初に運送を発注した本当の持ち主」を法律上区別したもの。実運送体制管理簿の閲覧請求権を持つ |
| **発荷主（はつにぬし）／着荷主（ちゃくにぬし）** | — | **発荷主**＝荷物を出す側。**着荷主**＝荷物を受け取る側 | 運賃を払うのは通常**発荷主**。しかし現場で要求を出してくるのは**着荷主**（納品先） |
| **3PL（サードパーティー・ロジスティクス）** | Third Party Logistics | 荷主でも実際の運び手でもない「第三者」が、荷主の物流業務をまとめて請け負う形態 | 【Varies】言葉の使われ方の幅が広い。「倉庫の運営受託」程度から物流全体の設計まで。**契約書で範囲を確認しないと通じない** |
| **ラストワンマイル** | — | 物流の最後の区間。物流センターから**受け取る人の手元まで**の部分 | 宅配のイメージ。個口が多く、1件あたりの距離は短いが件数が多い |
| **標準的な運賃** | 同左 | 【Fact】**平成30年（2018年）の貨物自動車運送事業法改正**で導入され、直近では**令和6年（2024年）3月22日**に告示された（令和6年国土交通省告示第209号） | 【Fact】令和6年告示では運賃水準を8%引き上げ、荷役の対価等を新たに加算（出典：国土交通省報道発表〔2024-03-22〕） |
| **標準運送約款** | 同左 | 【Fact】国土交通大臣が定めて公示した運送約款。これと同一の約款を定めた場合は認可を受けたものとみなされる（貨物自動車運送事業法第10条第3項） | 多くの中小事業者はこれと同一のものを使い、事務所に掲示している【Typical】 |
| **巡回指導（じゅんかいしどう）** | — | 【Fact】貨物自動車運送事業法第6章が定める**地方貨物自動車運送適正化事業実施機関**等が行う指導 | 【Typical】実務上この指定を受けているのが各都道府県のトラック協会。点呼記録・業務の記録・運転者等台帳等を確認される |
| **白トラ（しろトラ）** | — | 【Fact】**許可の取得又は届出をすることなく有償で貨物を運送する行為**（出典：トラック適正化二法について／国土交通省） | 【Fact】令和8年（2026年）4月1日から**白トラを利用した荷主等も処罰の対象**になる |

## 16-2. 運送の現場語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **点呼（てんこ）** | 同左 | 運行管理者がドライバー一人ひとりと向き合い、安全に運転できる状態かを確認して記録に残す行為 | 【Fact】乗務前・乗務後に行い、酒気帯びの有無をアルコール検知器と目視で確認し、記録を**1年間保存**（輸送安全規則第7条）。この業界で最も特徴的な業務 |
| **乗務（じょうむ）** | — | ドライバーが車に乗って業務を行うこと | 「今日は乗務できません」＝運転の仕事に就けないという意味 |
| **運行（うんこう）** | — | 車を出してから戻るまでの一連の走行 | 「この運行は運行指示書の対象ですか」＝泊まりがけで対面点呼ができない運行かという質問 |
| **乗務割（じょうむわり）** | 同左 | 誰をいつ乗務させるかの勤務の割り振り | 【Fact】運行管理者が**勤務時間及び乗務時間の範囲内**で作成し、これに従い乗務させる（輸送安全規則第20条第1項第3号）。配車表とは別の概念 |
| **配車（はいしゃ）** | — | どの荷物を、どの車で、誰が運ぶかを決めること | この業界の**心臓部**。荷物・車両・人・法令上の労働時間の4制約を同時に満たす組み合わせを毎日作る |
| **積地（つみち）／卸地（おろしち）** | — | **積地**＝荷物を積む場所。**卸地**＝荷物を降ろす場所 | 「積地は県内、卸地は隣県です」。運賃を決める最初の情報 |
| **着車（ちゃくしゃ）／接車（せっしゃ）** | — | トラックを荷降ろし口（バース）に着けること | 「10時に着車してください」＝10時にバースに車を着ける |
| **バース** | 接車バース | トラックを倉庫の荷降ろし口に着ける位置 | バースが6つしかない倉庫に同時に10台が到着すれば4台は待つ。**待機時間の発生源のひとつ** |
| **待機時間（たいきじかん）／荷待ち（にまち）** | — | 積込・荷降ろしの順番が来るのを待っている時間 | 【Fact】荷主都合の待機は記録義務がある（輸送安全規則第8条第1項第7号）。記録がなければ待機時間料を請求できない |
| **荷役（にやく）** | 同左 | 荷物を積む・降ろす・動かす作業全般。「にえき」ではなく「にやく」 | 「荷役は誰がやるんですか」＝ドライバーが積み降ろしするのかという確認。**運賃に含まれない別建ての料金**の対象 |
| **附帯作業／附帯業務** | 同左 | 運ぶこと以外の作業。仕分、検品、棚入れ、値札付けなど | 【Fact】実施した場合は記録義務がある（輸送安全規則第8条第1項第8号） |
| **荷姿（にすがた）** | 同左 | 荷物がどういう形にまとまっているか | 「荷姿はパレットですか、バラですか」。同じ重量でも作業時間が何倍も変わるため、運賃・料金の前提として必ず確認する |
| **バラ積み** | — | パレットに載せず、ケース単位で1個ずつ積むこと | ドライバーが1個ずつ手で積む＝**手積み**。時間も人手もかかる |
| **帰り荷（かえりに）／復荷（ふくに）** | — | 荷物を届けた後、帰りの道中で積む荷物 | 「帰り荷は取れましたか」。長距離運送の採算はこれで大きく変わる |
| **空車（からしゃ）／回送（かいそう）** | — | **空車**＝荷物を積んでいない状態で走ること。**回送**＝積むため／戻るために空で移動すること | 空車でも軽油・高速代・人件費はかかるが、運賃は発生しない |
| **貸切（かしきり）／チャーター** | — | 1台のトラックを1つの荷主のために丸ごと使うこと | 「チャーターでお願いします」＝1台まるごと押さえる。半分しか積まなくても運賃は1台分 |
| **混載（こんさい）** | 同左 | 1台に複数の荷主の荷物を混ぜて積むこと | 積んだ分だけの運賃。埋まらなければ収入が減るので、**積載率のリスクは運送会社側** |
| **路線便（ろせんびん）** | （特別積合せ貨物運送） | 決まった経路・日時で、複数の荷主の荷物を集約して運ぶ定期の便 | 「路線便で送ってください」＝小口なので混載の定期便に乗せる |
| **求荷求車（きゅうかきゅうしゃ）** | 求荷求車システム | 「運んでほしい荷物」と「空いている車」が互いに相手を探す仕組み。「求車求貨」とも【Varies】 | 帰り荷を探すときに使う。ここで見つけた相手にも庸車の書面交付義務はかかる |
| **送り状（おくりじょう）** | 同左 | 何を何個運ぶのかを書いた紙。荷物と一緒に動く | 【Fact】商法第571条第1項が記載事項を定める。現場では「運送状」「伝票」とも呼ばれる |
| **受領書（じゅりょうしょ）** | （受領印のある納品書控） | 「この荷物を確かに引き渡した」ことを**受け取った側が認めた**書類 | ★**これがないと請求できない**。この業界で最も重要な書類のひとつ |
| **検収（けんしゅう）** | 同左 | 受け取った荷物の中身・数量・品質を確認して、問題ないと認めること | 「検収してから受領印を押します」＝中身を開けて確認するので時間がかかる |
| **過積載（かせきさい）** | 同左 | 車両ごとに決まっている最大積載量を超えて荷物を積むこと | 【Fact】法は事業者に、最大積載量を超える積載となる運送の引受け・運行計画の作成・指示を禁止している（貨物自動車運送事業法第15条第3項） |
| **固縛（こばく）／ラッシング** | — | 荷崩れしないように荷物を固定すること | 【Fact】貨物にロープ又はシートを掛ける等必要な措置を講ずる義務がある（輸送安全規則第5条） |
| **偏荷重（へんかじゅう）** | 同左 | 荷物が片側に寄って、重さのバランスが崩れること | 【Fact】偏荷重が生じないように積載する義務がある（輸送安全規則第5条） |
| **拘束時間（こうそくじかん）** | 同左 | 始業から終業までの時間。**休憩時間・待機時間も含む** | 5時に点呼を受け17時に帰庫すれば拘束時間は12時間。3時間待機して動いていなくても拘束時間に入る |
| **休息期間（きゅうそくきかん）** | 同左 | 勤務と勤務の間の、会社の拘束を離れて自由に使える時間 | 17時に帰庫して翌朝5時に点呼なら、その12時間が休息期間 |
| **運転時間** | — | 実際にハンドルを握って運転していた時間 | 拘束時間のうち、待機・休憩・荷役を除いた部分 |
| **手待ち（てまち）** | — | 作業ができず待っている状態。荷待ちとほぼ同義に使われる【Varies】 | 「手待ちが2時間ありました」 |
| **中継（ちゅうけい）** | — | 1人で行って帰れない距離を、途中でドライバーや車両を交替して運ぶこと | 【Inference】1日で往復できない距離への対応のひとつ |
| **交替運転者** | 同左 | 【Fact】長距離運転または夜間の運転で疲労等により安全な運転を継続できないおそれがあるときに、あらかじめ配置する運転者（輸送安全規則第20条第1項第5号） | 2人乗務の形になる |

## 16-3. 車両・設備の用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **緑ナンバー** | 事業用自動車 | 他人の需要に応じ有償で貨物を運送するための許可・届出を受けた車 | 「緑ナンバーですか」＝運送事業の許可を持っているかという確認 |
| **白ナンバー** | 自家用自動車 | 自社の荷物を自社で運ぶための車 | メーカーが自社製品を自社の車で運ぶ場合は白ナンバーでよい |
| **車格（しゃかく）** | — | 車両の大きさの区分 | 「車格は4tでお願いします」。運賃を決める主要な軸のひとつ |
| **大型／中型／準中型／普通** | 同左 | 【Fact】道路交通法施行規則第2条第1項による区分。**大型**＝車両総重量11,000kg以上、最大積載量6,500kg以上 等／**中型**＝車両総重量7,500kg以上11,000kg未満、最大積載量4,500kg以上6,500kg未満 等／**準中型**＝車両総重量3,500kg以上7,500kg未満、最大積載量2,000kg以上4,500kg未満 | 免許の種類がこの区分に対応する。「この人は中型免許だから大型には乗せられない」 |
| **車両総重量** | 同左 | 車体そのものの重さ＋乗員＋最大積載量を合計した重さ | 【Fact】**7トン以上**なら運行記録計の対象（輸送安全規則第9条第1号）。**8トン以上**なら業務の記録に貨物の積載状況の記録が必要（同規則第8条第1項第6号） |
| **最大積載量** | 同左 | その車に積める荷物の最大の重さ | 【Fact】**4トン以上**なら運行記録計の対象（同規則第9条第1号）。**5トン以上**なら貨物の積載状況の記録が必要（同規則第8条第1項第6号）。車検証に記載されている |
| **バン（バンボディ）** | — | 箱型の荷台を持つトラック | 雨に濡れない。ただし後ろからしか積み降ろしできない |
| **平ボディ（ひらボディ）** | 平ボディ車 | 荷台が箱ではなく、あおり（側板）だけの平らなトラック | 横からも上からも積める。長尺物や建材に向く。雨に濡れるのでシートをかける |
| **ウイング（ウイング車）** | ウイングボディ | 荷台の側面が翼のように上に開くトラック | フォークリフトで横から一度に積み降ろしできる。パレット輸送に向く |
| **冷凍車・冷蔵車** | — | 荷台に冷凍機を備えたトラック | 【Typical】食品・医薬品の輸送に使う。冷凍機を回すため燃料の消費が増える |
| **パワーゲート／テールゲート** | — | 荷台の後部に付いた、荷物を昇降させる装置 | 【Typical】フォークリフトのない納品先でも重い荷物を降ろせる。「ゲート付きの車でお願いします」 |
| **トレーラー／けん引** | — | 動力のある車（トラクタ）が、荷台だけの車（トレーラー）を引くもの | 【Fact】重被牽引車を牽引するには**牽引免許**が必要（道路交通法第85条第3項） |
| **デジタコ** | デジタル式運行記録計 | 瞬間速度・運行距離・運行時間をデジタルデータで記録する装置 | 【Fact】対象車両は記録を**1年間保存**（輸送安全規則第9条）。**記録できない車は運行に使えない**（同規則第20条第1項第11号） |
| **アナタコ** | アナログ式運行記録計 | 円形の記録紙に速度を針で描くタイプの運行記録計 | デジタコと対比して使われる |
| **動態管理（GPS）**【Varies】 | — | 車が今どこにいるかをリアルタイムで見る仕組み | 【Varies】法令上の義務ではない。デジタコとは別物 |
| **アルコール検知器** | 同左 | 呼気に含まれるアルコールを検知する機器 | 【Fact】**営業所ごとに備え、常時有効に保持**し、目視等の確認と併用する（輸送安全規則第7条第4項） |
| **車検（しゃけん）** | 継続検査 | 自動車検査証の有効期間が切れる前に受ける国の検査 | 【Fact】貨物の運送の用に供する自動車の有効期間は原則1年（道路運送車両法第61条第1項） |
| **日常点検** | 日常点検整備 | 【Fact】**1日1回、運行の開始前**に行う点検（道路運送車両法第47条の2第2項） | ドライバーが実施するが、**運行の可否を決めるのは整備管理者** |
| **定期点検** | 定期点検整備 | 【Fact】**3月ごと**に行う点検整備（道路運送車両法第48条第1項第1号） | 車検とは別のもの。点検整備記録簿に記載する |
| **インタンク** | — | 事業者が自分の敷地内に持つ給油設備 | ドライバーがスタンドに寄る時間が省ける。一方、燃料をまとめて買うため**価格変動の影響を在庫として抱える**【Varies】 |
| **パレット** | 同左 | 荷物を載せる台。フォークリフトの爪を差し込む隙間がある | 1枚に段ボール40箱を積んでフィルムで巻けば、1つの単位として一度に動かせる |
| **かご車（かごしゃ）／カゴ台車** | — | キャスター付きの金属製のかご。荷物を入れて押して運ぶ | 【Typical】店舗配送で使われる。空のかご車を持ち帰ることがある |
| **フォークリフト** | 同左 | 爪でパレットを持ち上げて運ぶ車両 | 【Fact】**最大荷重1トン以上**の運転（道路上を走行させる運転を除く）は就業制限の対象（労働安全衛生法第61条第1項、同施行令第20条第11号） |

## 16-4. 倉庫の用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **営業倉庫** | （倉庫業法上の倉庫） | 【Fact】**寄託を受けた物品**を保管する、倉庫業法第3条の登録を受けた倉庫 | 他人の荷物を預かって料金をもらう倉庫。倉庫管理主任者の選任が必要 |
| **自家倉庫** | — | 自社の商品・材料を置くための自社の倉庫 | 寄託を受けていないため倉庫業法の登録は不要。建物の形は営業倉庫と同じでも制度上は別 |
| **寄託（きたく）** | 同左 | 【Fact】**ある物を保管することを相手方に委託し、相手方がこれを承諾すること**（民法第657条） | 倉庫業法が「他人の」という語を使わずに他人の物を預かる要件を表している語 |
| **倉庫管理主任者** | 同左 | 【Fact】倉庫業法第11条により**倉庫ごとに**選任し、倉庫における火災の防止その他の倉庫の管理に関する業務を行わせる者 | 選任しないと登録を拒否される（同法第6条第1項第5号）。未選任は50万円以下の罰金（同法第29条第3号） |
| **入庫（にゅうこ）／出庫（しゅっこ）** | — | **入庫**＝倉庫に荷物を入れること。**出庫**＝倉庫から荷物を出すこと | 「明日の入庫予定はパレット20枚です」 |
| **検品（けんぴん）** | 同左 | 予定と現物を照合し、品名・数量・賞味期限／ロット・外装の破損を確認すること | 預かる前に何がいくつあったかを確定させる。**倉庫会社が自社を守る材料**にもなる |
| **ロケーション** | 同左 | 倉庫内の保管場所を示す住所のようなもの | 「A列-03段-05番」のように番地を振る。これがないと出荷指示が来ても探せない |
| **ピッキング** | 同左 | 保管されている商品の中から、注文された分だけを取り出す作業 | 「A商品3ケース、B商品1ケース」という指示に従って棚を回る |
| **ピッキングリスト** | 同左 | どのロケーションから何をいくつ取るかを書いた作業指示 | 【Typical】WMSが出力する。回る順番も示される |
| **流通加工（りゅうつうかこう）** | 同左 | 保管中や出荷前に行う、値札付け・詰め合わせ・ラベル貼りなどの作業 | 【Varies】どこまでやるかは契約による |
| **先入先出（さきいれさきだし／FIFO）** | First In First Out | 先に入れたものから先に出すこと | 食品では期限の古いものから出さないと、奥に残った在庫が期限切れになる |
| **ロット** | 同左 | 同じ条件でまとめて作られた製品のかたまり、およびその番号 | 不良が見つかったとき、その番号の分だけを特定して回収できる |
| **棚卸（たなおろし）** | 同左 | 帳簿上の在庫数と実際にある数を数えて突き合わせること | 【Varies】頻度は月次・四半期・年次など荷主との取り決めによる。差異があれば原因を調べて荷主に報告 |
| **WMS** | Warehouse Management System（倉庫管理システム） | 倉庫の中の在庫と作業を管理する仕組み | 在庫データ（ロケーション付き）を中心に、入出庫の実績・保管実績・作業実績を扱う |
| **保管料** | 同左 | 一定期間預かって置いておくことの対価 | 【Typical】保管数量（個数・パレット数・面積・容積）× 期間 |
| **荷役料（にやくりょう）／庫内作業料** | 同左 | 入庫・出庫・ピッキング・検品・梱包などの作業の対価 | 【Typical】作業量（個数・行数・時間）に応じて |
| **定温（ていおん）／常温／冷蔵／冷凍** | — | 保管する温度帯の区分 | 【Example】モデル企業の倉庫は常温エリアと定温エリア（15℃）を持つ設定 |
| **プラットホーム** | — | トラックの荷台の高さに合わせた、倉庫の荷捌き場 | バースはこのプラットホームに設けられる |

## 16-5. 法令・記録の用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **運行管理者** | 同左 | 【Fact】貨物自動車運送事業法第16条第1項により選任する、事業用自動車の運行の安全の確保に関する業務を行う者 | 【Fact】車両数÷30（端数切捨て）＋1名以上（輸送安全規則第18条第1項）。点呼・乗務割・運行指示書・記録の保存を担う |
| **統括運行管理者** | 同左 | 【Fact】一の営業所で複数の運行管理者を選任する場合に、それらの業務を統括する者（輸送安全規則第18条第2項） | 【Typical】配車課長が務めることが多い |
| **補助者** | 同左 | 【Fact】運行管理者の業務を補助させるために選任できる者（同条第3項） | 早朝・深夜の点呼に対応するために置かれる【Typical】 |
| **整備管理者** | 同左 | 【Fact】道路運送車両法第50条第1項により選任する、点検・整備と自動車車庫の管理に関する事項を処理する者 | 【Fact】事業用トラック**5両以上**で必要（同法施行規則第31条の3第1項第3号）。**点検の結果に基づき運行の可否を決定する権限**を持つ（同規則第32条第1項第2号） |
| **運行管理規程** | 同左 | 【Fact】運行管理者の職務・権限、安全確保業務の処理基準に関する規程（輸送安全規則第21条第1項） | 事業者が定める義務がある |
| **運行指示書** | 同左 | 【Fact】**乗務前・乗務後の点呼のいずれも対面等で行うことができない業務を含む運行**ごとに作成し、運転者等に携行させる書面（輸送安全規則第9条の3第1項） | 日帰りで戻る運行は対象ではない。**毎日全車分を作る書類ではない** |
| **業務の記録** | （運転日報・乗務日報） | 【Fact】業務を行った運転者等ごとに10号の事項を記録させ、**1年間保存**する（輸送安全規則第8条第1項） | 待機・荷役の記録も含まれる。法令上の記録であると同時に**請求の根拠** |
| **運転者等台帳** | 同左 | 【Fact】運転者等ごとに所定の事項を記載し、営業所に備え置く台帳（輸送安全規則第9条の5） | 免許、事故の概要、健康状態、指導の実施及び適性診断の受診の状況を記載 |
| **実運送体制管理簿** | 同左 | 【Fact】真荷主から引き受けた運送ごとに、実運送を行う事業者名・貨物の内容と区間・**請負階層**等を記載する簿冊（貨物自動車運送事業法第24条の5第1項） | **運送完了日から1年間**営業所に備え置く。真荷主は閲覧又は謄写を請求できる |
| **請負階層** | 同左 | 【Fact】真荷主との運送契約の後に締結された運送契約の数（同条第1項第3号） | 何次下請かを示す数 |
| **点検整備記録簿** | 同左 | 【Fact】点検又は整備をしたときに記載し、**当該自動車に備え置く**記録簿（道路運送車両法第49条第1項） | 【Fact】保存期間は**記載の日から1年間**（事業用トラック。自動車点検基準第4条第2項）。継続検査のときに提示する |
| **適性診断** | 同左 | 【Fact】国土交通大臣が告示で定め、国土交通大臣の認定を受けた診断（輸送安全規則第10条第2項） | 【Fact】事故惹起者・新たに雇い入れた者・高齢者（65才以上）が対象 |
| **特別な指導** | 同左 | 【Fact】上記3類型に対して行う指導（同項） | 適性診断とセットで実施する |
| **事故防止対策（事故警報）** | 同左 | 【Fact】国土交通大臣又は地方運輸局長が報告書・速報に基づき定め、関係者に周知させるもの（自動車事故報告規則第5条） | 【Fact】運行管理者はこれに基づき従業員に指導及び監督を行う（輸送安全規則第20条第1項第17号） |
| **事業報告書** | 同左 | 【Fact】**毎事業年度の経過後100日以内**に所轄地方運輸局長に提出（貨物自動車運送事業報告規則第2条第1項） | 貸借対照表・損益計算書・損益明細表・人件費明細表を含む |
| **事業実績報告書** | 貨物自動車運送事業実績報告書（第四号様式） | 【Fact】**毎年7月10日まで**に提出（前年4月1日〜3月31日の期間に係るもの。同条第1項・第3項） | 輸送実績（走行距離・輸送トン数等）を報告する |
| **改善基準告示** | 自動車運転者の労働時間等の改善のための基準 | 【Fact】平成元年労働省告示第7号。令和4年厚生労働省告示第367号により令和4年12月23日に改正され、**令和6年4月1日から適用** | 拘束時間・休息期間・運転時間の基準を定める。【Varies】具体的な数値は本資料では扱っていない |

## 16-6. 商取引・会計の基本語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **運賃（うんちん）** | 同左 | 【Fact】**運送の役務の対価**（貨物自動車運送事業法第10条第2項第3号） | 「運ぶこと自体」の値段。距離制・時間制がある |
| **料金（りょうきん）** | 同左 | 【Fact】**運送の役務以外の役務又は特別に生ずる費用に係る**対価（同号） | 待機時間料、積込料・取卸料、附帯業務料、高速道路代など。運賃と**区分して収受する**ことが約款の認可基準 |
| **距離制運賃／時間制運賃** | 同左 | **距離制**＝何km運んだかで計算。**時間制**＝何時間拘束されたかで計算 | 「市内20か所配送」は距離で測れないので時間制で見積もる |
| **個建運賃（こだてうんちん）** | 同左 | 「1台いくら」ではなく「1個・1ケースいくら」で計算する運賃 | 共同配送で各荷主への請求を明確にするのに使う |
| **燃料サーチャージ** | 同左 | 燃料価格が上下したときに、その差額を運賃とは別に加算・減算する仕組み | 【Fact】令和6年の標準的な運賃の見直しでは基準価格を120円に設定（出典：国土交通省の検討会提言〔令和5年12月15日〕） |
| **見積（みつもり）** | 見積書 | 「この条件ならいくらで運ぶか」を示す書類 | 出しただけでは仕事は確定していない |
| **受注（じゅちゅう）** | — | 荷主からの発注を受けて、引き受けが確定すること | 【Fact】運送契約を締結するときは書面を**相互に交付**する（貨物自動車運送事業法第12条第1項） |
| **売上（うりあげ）** | 売上高 | 提供した役務の対価として得られる収入の金額 | **お金が入ったかどうかとは関係ない**。運び終えて請求を立てた時点で売上になる |
| **売掛金（うりかけきん）** | 同左 | 役務を提供したが、まだ代金をもらっていない金額 | 運送会社は常に1〜2か月分の売上が売掛金として外に出たままになる |
| **買掛金（かいかけきん）／未払金** | 同左 | 仕入やサービスを受けたが、まだ支払っていない金額 | 庸車先への支払はここに立つ |
| **締め日（しめび）** | 同左 | 「いつからいつまでの分をまとめて請求するか」の区切りの日 | 【Varies】月末締め、20日締めなど荷主により異なる |
| **支払サイト** | — | 締め日から実際に入金される日までの期間 | 「月末締め・翌月末払い」なら約30日 |
| **消込（けしこみ）** | 同左 | 入金があったことを確認し、売掛金の記録を消す作業 | 差額があれば原因（値引き・抜け・振込手数料）を調べる |
| **与信（よしん）** | 同左 | 相手が代金を支払えるかどうかを確認し、取引の限度を決めること | 運送は先にサービスを提供して後から請求するため、新規荷主では確認が入る【Typical】 |
| **粗利（あらり）／売上総利益** | 同左 | 売上から売上原価を引いた残り | **粗利は利益ではない**。ここから販売費及び一般管理費を引いて営業利益になる |
| **営業利益** | 同左 | 粗利から販売費及び一般管理費を引いたもの | 本業でいくら稼いだかを示す |
| **固定費（こていひ）／変動費（へんどうひ）** | 同左 | **固定費**＝売上が増減してもあまり変わらない費用。**変動費**＝売上に応じて増減する費用 | リース料・保険料・税は固定費。軽油・高速代・庸車費は変動費 |
| **減価償却（げんかしょうきゃく）** | 減価償却費 | 高い買い物の費用を、使う年数にわたって少しずつ費用にしていく会計処理 | **現金は買った年に出るが、費用は何年かに分かれる**。このずれが利益と現金を食い違わせる |
| **リース** | 同左 | 車両などを買わずに借りること | 現金の支出と費用が一致する。買う場合とは資金の動き方が違う |
| **資金繰り（しきんぐり）** | 同左 | いつ現金が入り、いつ出るかを予測して、支払に必要な現金が足りなくならないようにやりくりすること | **利益が出ていても現金がなければ支払えない**。⑦ 経理・財務機能の独立した業務 |
| **リードタイム** | 同左 | 依頼を受けてから納品するまでにかかる期間 | 「リードタイムが短い」＝急ぎ。【Fact】令和6年の見直しでは「速達割増」の設定が提言された |
| **原価（げんか）** | 売上原価／運送原価 | その売上を得るために直接かかった費用 | 【Varies】運送業では燃料費・人件費・車両費・外注費を含めることが多いが、区分は会社の経理方針による |
| **売掛回転日数** | 売上債権回転日数 | 売上が現金になるまでに平均何日かかっているか | 受領書の欠落で請求が翌月に回れば、この日数が延びる |

## 16-7. KPI（指標）の用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **実働率（じつどうりつ）** | （稼働率） | **保有している車のうち、実際に稼働した割合** | 「車が動いたか」を測る。動かない車も減価償却費・保険料・税・基本給は出る |
| **実車率（じっしゃりつ）** | 同左 | **走った距離のうち、荷物を積んで走った距離の割合** | 「積んで走ったか」を測る。実車キロ÷走行キロ。帰り荷が取れるかで大きく変わる |
| **積載率（せきさいりつ）** | 同左 | **最大積載量（または荷台容積）に対して実際に積めた割合** | 「どれだけ積めたか」を測る。**100%を超えてはならない**（過積載の禁止） |
| **燃費（ねんぴ）** | km/L | 軽油1リットルで何km走れたか | 走行距離÷給油量。車格・積載重量・路線・季節・車齢で変わるため、同条件で比べる |
| **庸車比率（ようしゃひりつ）** | （外注比率） | 運送のうち他社に運んでもらった割合 | 【Varies】金額ベース（庸車費÷運送収入）と件数ベースがある |
| **1台あたり売上** | 車両1台あたり運送収入 | トラック1台が一定期間にいくら稼いだか | 運送収入÷車両台数。車格が違えば比べられないので、車格別に見る |
| **1運行あたり運賃** | （1件あたり運賃） | 1回の運送でいくらの運賃を得たか | 運送収入÷運行件数。件数が減ったのか単価が下がったのかを分けられる |
| **事故率** | 同左 | 事故の発生の密度 | 【Varies】分母を走行距離・車両台数・ドライバー数のどれにするかは会社により異なる |
| **保管効率／充填率**【Varies】 | — | 倉庫のスペースのうち保管に使われている割合 | 【Inference】倉庫は空いていても家賃・光熱費・人件費が出るため、利益に直結する |

> （目安の60語以上を満たしています）。

## 16-8. 全業界共通の6項目（運輸・物流業に即して）

### (1) 売上 ≠ 入金

| | 内容 |
|---|---|
| **何が違うのか** | **売上**＝役務を提供して請求を立てた時点で計上される金額。**入金**＝実際に現金が振り込まれること |
| **なぜ混同するのか** | 日常の言葉では「売れた＝お金が入った」と考えるため。また、小売業や飲食業では実際に両者がほぼ同時に起きる |
| **実務でどう効いてくるのか** | 【Example】3月13日に運んだ代金が入るのは4月30日（48日後）。その間に軽油代・給与・庸車費が出ていく。**帳簿上は利益が出ていても、現金がなければ支払えない**。だから ⑦ 経理・財務機能に「資金繰り」が独立した業務として存在する（`08_money.md` 8-8） |

### (2) 受注 ≠ 売上

| | 内容 |
|---|---|
| **何が違うのか** | **受注**＝引き受けが確定した状態。**売上**＝役務を提供し、請求を立てた状態 |
| **なぜ混同するのか** | 「仕事を取った」という感覚と、会計上の売上の計上時点がずれるため |
| **実務でどう効いてくるのか** | 3月10日に受注しても、3月13日に運び、3月31日に請求して初めて売上になる。**受注した時点では、まだ1円も売上になっていない**。しかも運ぶ前に配車を組み、軽油を入れ、人を手配する必要がある |

### (3) 発注 ≠ 仕入計上（運輸業では「庸車の発注 ≠ 外注費の計上」）

| | 内容 |
|---|---|
| **何が違うのか** | **発注**＝庸車先に運送を依頼した状態。**外注費の計上**＝実際に運んでもらった（役務の提供を受けた）状態 |
| **なぜ混同するのか** | 「頼んだ」と「終わった」の区別が、口頭の依頼では曖昧になりやすいため |
| **実務でどう効いてくるのか** | 【Fact】庸車を依頼するときは、法第24条第2項の書面を交付しなければなりません。**書面がなければ「いくらで頼んだか」を後から確認できず**、庸車先の請求額と照合できません（`10_documents.md` 10-10） |

### (4) 在庫 ≠ すべて完成品（運輸業では「倉庫の在庫 ≠ 自社の在庫」）

| | 内容 |
|---|---|
| **何が違うのか** | 製造業の在庫は原材料・仕掛品・完成品に分かれる。**運輸・物流業の倉庫にある在庫は、そもそも自社の在庫ではない** |
| **なぜ混同するのか** | 「倉庫に5,000ケースある」と聞くと在庫のように見えるため |
| **実務でどう効いてくるのか** | 倉庫にあるのは**荷主の財産**であり、自社の貸借対照表には載りません（`07_goods.md` 7-1）。だから在庫報告を荷主に出し、棚卸で現物と突き合わせ、差異があれば責任問題になります。【Fact】倉庫営業者は**注意を怠らなかったことを証明しなければ**滅失・損傷の責任を免れられません（商法第610条） |

### (5) 粗利 ≠ 利益

| | 内容 |
|---|---|
| **何が違うのか** | **粗利（売上総利益）**＝売上−売上原価。**営業利益**＝粗利−販売費及び一般管理費 |
| **なぜ混同するのか** | 「儲け」という日常語が両方を指すため |
| **実務でどう効いてくるのか** | 【Example】運賃100,000円を庸車先に85,000円で頼めば粗利15,000円。しかしここから配車担当・経理・総務の人件費、事務所の費用、保険料を賄わなければなりません。**粗利15,000円は利益15,000円ではありません**（`12_business-model.md` 12-6） |

### (6) 見積 ≠ 契約

| | 内容 |
|---|---|
| **何が違うのか** | **見積**＝こちらから金額を提示した状態。**契約**＝双方が合意した状態 |
| **なぜ混同するのか** | 見積を出すと仕事が取れた気になるため |
| **実務でどう効いてくるのか** | 【Fact】2025年4月1日から、運送契約を締結するときは**書面を相互に交付**しなければなりません（貨物自動車運送事業法第12条第1項）。**見積書は自社が一方的に出すもので、相互交付された書面ではありません**（`10_documents.md` 10-1・10-2） |

## 16-9. ★運輸・物流業に固有の混同しやすいペア

### (1) ★運送 ≠ 倉庫

| | 内容 |
|---|---|
| **何が違うのか** | **運送**＝モノの**場所を変える**こと。**倉庫**＝モノを**一定期間預かる**こと。根拠法・許認可・料金の取り方・必要な資産がすべて違う |
| | ・根拠法：【Fact】運送＝貨物自動車運送事業法／倉庫＝倉庫業法 |
| | ・行政手続：【Fact】運送＝国土交通大臣の**許可**（同法第3条）／倉庫＝国土交通大臣の**登録**（倉庫業法第3条） |
| | ・売上が立つきっかけ：運送＝運送1回ごと（都度）／倉庫＝保管期間の経過（継続） |
| | ・必置ポジション：運送＝運行管理者・整備管理者／倉庫＝倉庫管理主任者 |
| **なぜ混同するのか** | 現場では「物流会社さん」と一括りに呼ばれ、**同じ会社が両方をやっていることが非常に多い**ため（モデル企業も両方を持つ） |
| **実務でどう効いてくるのか** | 見積を頼むとき、契約を結ぶとき、事故が起きたときの責任範囲を決めるとき、**「これは運送の話か、保管の話か」で適用される約款も責任も変わります**。会話の入口で取り違えると、話が最後まで噛み合いません。1つの会社の中に、**別々の許認可を持つ別々の商売が同居している**と理解してください（`01_overview.md` 1-1） |

### (2) ★実運送 ≠ 利用運送

| | 内容 |
|---|---|
| **何が違うのか** | **実運送**＝自分の会社のトラックで、自分の会社のドライバーが実際に運ぶこと。**利用運送**＝自分では運ばず、他の運送会社に運んでもらうこと（自分は荷主と契約し運ぶ責任を負う） |
| | 【Fact】貨物利用運送事業法第2条第1項が両者を定義している |
| **なぜ混同するのか** | どちらも「運送会社」と呼ばれ、荷主から見れば同じように運送を引き受けてくれるため。**車を持たない運送業者が存在すること自体が初心者には意外** |
| **実務でどう効いてくるのか** | ・**必要な許認可が違う**：【Fact】実運送は**許可**（貨物自動車運送事業法第3条）／第一種利用運送は**登録**、第二種は**許可**（貨物利用運送事業法第3条・第20条） |
| | ・**収益構造が違う**：実運送は運賃から燃料費・人件費・車両費を引いた残り。利用運送は**受けた運賃と実運送への支払の差額**（`12_business-model.md` 12-6） |
| | ・**売上高の見え方が違う**：利用運送は売上を全額計上するため、**売上高だけで会社の規模を比べると実態より大きく見えます** |
| | ・**品質の管理の仕方が違う**：実運送は自社で管理できるが、利用運送は委託先次第 |

### (3) ★営業倉庫 ≠ 自家倉庫

| | 内容 |
|---|---|
| **何が違うのか** | **営業倉庫**＝**寄託を受けた物品**（他人の荷物）を保管する、倉庫業法第3条の登録を受けた倉庫。**自家倉庫**＝自社の商品・材料を置く自社の倉庫 |
| **なぜ混同するのか** | **建物の形も、中のラックも、フォークリフトも、作業内容も同じに見える**ため |
| **実務でどう効いてくるのか** | ・**登録の要否**：【Fact】営業倉庫は倉庫業法第3条の登録が必要。自家倉庫は寄託を受けていないため不要 |
| | ・**倉庫管理主任者**：【Fact】営業倉庫は倉庫ごとに選任が必要（同法第11条）。未選任は50万円以下の罰金（同法第29条第3号） |
| | ・**責任の性質**：【Fact】営業倉庫は商法第610条により、寄託物の保管に関し**注意を怠らなかったことを証明しなければ**責任を免れられない |
| | ・**会話での確認**：「倉庫を持っている」と言われたら、**どちらなのかを必ず確認する**。営業倉庫でなければ、他社の荷物を有償で預かることはできません |
| **★条文の注意** | 【Fact】**倉庫業法の条文には「他人の」という語はありません。** 要件は「**寄託**を受けた物品の倉庫における保管」（同法第2条第2項）であり、「他人から預かる」ことは「寄託」（【Fact】民法第657条）の語に含まれています。一方、【Fact】貨物自動車運送事業法第2条第2項には「**他人の需要に応じ、有償で**」が逐語で存在します。**2つの法律の要件を1文にまとめてはいけません**（`15_rules-customs.md` 15-4） |

### (4) ★緑ナンバー ≠ 白ナンバー

| | 内容 |
|---|---|
| **何が違うのか** | **緑ナンバー**＝**事業用自動車**。他人の需要に応じ有償で貨物を運送するための許可・届出を受けた車。**白ナンバー**＝**自家用自動車**。自社の荷物を自社で運ぶための車 |
| **なぜ混同するのか** | **同じメーカーの同じ型のトラックが、色の違うナンバーを付けて走っている**ため。外見では区別がつきにくい |
| **実務でどう効いてくるのか** | 緑ナンバーであることは、次のすべてがかかることを意味します。 |
| | ・運行管理者・整備管理者の選任 |
| | ・点呼（乗務前・乗務後）、業務の記録、運行記録計の記録の作成と保存 |
| | ・日常点検（1日1回、運行の開始前）、定期点検整備（3月ごと） |
| | ・【Fact】車検の有効期間は原則1年（道路運送車両法第61条第1項） |
| | ・事業報告書・事業実績報告書 |
| | **同じ形のトラックでも、ナンバーの色で適用される義務がまったく違います。** |
| **★白トラの問題** | 【Fact】国土交通省は「白トラ」を**許可の取得又は届出をすることなく有償で貨物を運送する行為**と説明し、令和8年（2026年）4月1日から**白トラを利用した荷主等も処罰の対象**になる旨を示しています（出典：トラック適正化二法について／国土交通省）。【Fact】無許可営業は3年以下の拘禁刑又は300万円以下の罰金（貨物自動車運送事業法第70条） |

### (5) ★庸車 ≠ 派遣

| | 内容 |
|---|---|
| **何が違うのか** | **庸車**＝**運送という仕事そのもの**を他社に委託すること。相手の会社が、相手の車で、相手の指揮命令のもとに運ぶ。**派遣**＝人を借りて、**自社の指揮命令のもとに**働いてもらうこと |
| **なぜ混同するのか** | どちらも「自社の人員で足りない部分を他社に埋めてもらう」という点で似ているため。また、庸車のドライバーが自社の事務所に出入りし、自社の荷主の現場に行くため、見た目が似ている |
| **実務でどう効いてくるのか** | ・**指揮命令の関係が違う**：庸車の場合、自社は庸車先の会社に**運送を依頼**します。庸車先のドライバーに対して自社が直接指揮命令するのではありません |
| | ・**点呼の責任**：【Fact】点呼は**その運転者の属する営業所**の運行管理者が行い、**当該運転者の属する営業所に備えられたアルコール検知器**を用います（輸送安全規則第7条第4項）。庸車先のドライバーの点呼は庸車先が行います |
| | ・**法令上の手続**：【Fact】庸車には**書面の交付**（貨物自動車運送事業法第24条第2項）、**実運送体制管理簿**の作成（同法第24条の5）、**委託段階の制限の努力義務**（同法第23条の4）が伴います |
| | ・**会計上の扱い**：庸車費は**外注費**。派遣なら派遣料金 |

### (6) ★実車率 ≠ 実働率

| | 内容 |
|---|---|
| **何が違うのか** | **実働率**＝**保有している車のうち、実際に稼働した割合**（車が動いたか）。**実車率**＝**走った距離のうち、荷物を積んで走った距離の割合**（積んで走ったか） |
| **なぜ混同するのか** | **漢字が1文字しか違わず、読みも「じつどうりつ」「じっしゃりつ」で似ている**ため。どちらも「車をどれだけ活用できたか」を測る指標であるため |
| **実務でどう効いてくるのか** | ・**測っているものが違う**：車が1日走っても、全部空車なら実働率は100%、実車率は0%です |
| | ・**分母が違う**：実働率の分母は**保有台数**（または実働可能日数）、実車率の分母は**走行距離** |
| | ・**下がる原因が違う**：実働率が下がるのは荷物がない・人がいない・整備で入庫・故障・労働時間の上限など。実車率が下がるのは**帰り荷が取れなかった**ことが主な原因 |
| | ・**積載率も別物**：積載率は「どれだけ積めたか」（分母は最大積載量・荷台容積）。**3つは独立した指標**です（`14_kpi.md` 14-5〜14-7） |

### (7) ★拘束時間 ≠ 労働時間

| | 内容 |
|---|---|
| **何が違うのか** | **拘束時間**＝始業から終業までの時間で、**休憩時間・待機時間も含む**。**労働時間**＝労働基準法上、実際に労働した時間（休憩時間を除く） |
| **なぜ混同するのか** | ドライバーは待機中も自宅に帰れず自由に過ごせるわけではないため、感覚としては「働いている」時間に思えるため。また、運輸業では改善基準告示が「拘束時間」という独自の概念を使うため |
| **実務でどう効いてくるのか** | ・**根拠が違う**：労働時間の上限は【Fact】労働基準法第140条第1項の**年960時間**（2024年4月1日から適用）。拘束時間の基準は**改善基準告示**（厚生労働省告示）。**2つは別の制度**です |
| | ・**待機の扱い**：5時に点呼を受け17時に帰庫すれば拘束時間は12時間。そのうち3時間が待機で車が1mも動いていなくても、**拘束時間には入ります** |
| | ・**配車への影響**：待機が長いほど「走れる時間」を食います。つまり、**待機は収入を生まないだけでなく、その日の他の仕事の可能性も奪います**（`04_end-to-end-process.md` 4-5） |
| | ・【Varies】改善基準告示の具体的な数値は、本資料では扱っていません |

### (8) ★運賃 ≠ 料金

| | 内容 |
|---|---|
| **何が違うのか** | **運賃**＝【Fact】**運送の役務の対価**。**料金**＝【Fact】**運送の役務以外の役務又は特別に生ずる費用に係る**対価（貨物自動車運送事業法第10条第2項第3号） |
| | 料金にあたるもの：待機時間料、積込料・取卸料、附帯業務料、高速道路料金等の実費、深夜早朝の割増、保管料 |
| **なぜ混同するのか** | 日常語では「運賃」も「料金」も「払うお金」を指すため、区別する必要を感じないため。また「運賃一式いくら」という言い方が現場で使われることがあるため |
| **実務でどう効いてくるのか** | ・**法令が区分収受を求めている**：【Fact】運送約款の認可基準として、両者を**区分して収受する旨が明確に定められている**ことが必要（同号） |
| | ・**請求できるかどうかが変わる**：「運賃一式いくら」とまとめてしまうと、実際にドライバーが2時間待たされて荷降ろしまでやっても、**その分の対価を請求できなくなります** |
| | ・**契約書の記載事項**：【Fact】運送契約の書面には、**運送の役務の内容及びその対価**と、**運送の役務以外の役務の提供が含まれる場合にはその内容及び対価**を分けて記載します（同法第12条第1項） |
| | ・**記録が前提**：【Fact】待機・荷役作業は記録義務があり（輸送安全規則第8条第1項第7号・第8号）、**記録がなければ料金を請求する根拠がありません** |

### (9) ★納品 ≠ 請求可能

| | 内容 |
|---|---|
| **何が違うのか** | **納品**＝荷物を届けたこと。**請求可能**＝**受領書があり、実績が確定し、締め日が来た**状態 |
| **なぜ混同するのか** | 「届けたのだから当然お金がもらえる」と考えるため。製造業なら製品が相手の手元に残るが、**運送は形が何も残らない**ことに気づきにくい |
| **実務でどう効いてくるのか** | ・**受領書がなければ請求できない**：運送が完了したことを示すものは、受け取った側の**受領印・サイン**だけです |
| | ・【Fact】商法第575条：運送人の責任は**運送品の受取から引渡しまで**。つまり「いつ引き渡したか」が責任の終わる時点を決めます |
| | ・【Fact】商法第573条第1項：「運送賃は、到達地における**運送品の引渡しと同時に**、支払わなければならない」。**引渡しの事実が支払の前提**です |
| | ・【Example】受領印をもらい忘れると、確認に2週間かかり、その1件は翌月請求に回り、**入金が1か月遅れます**（`08_money.md` 8-3） |
| | ・だから**月末に受領書を回収して突き合わせる作業**が、この業界の経理の定番業務になります |

### (10) ★荷物の所有者 ≠ 運ぶ会社

| | 内容 |
|---|---|
| **何が違うのか** | **所有者**＝その荷物が誰の財産か（荷主のまま）。**占有者**＝そのモノを事実上手元に持っている者（運送会社・倉庫会社） |
| **なぜ混同するのか** | 荷台に積まれている荷物、倉庫に並んでいる商品を見ると、その会社のもののように見えるため |
| **実務でどう効いてくるのか** | ・**運送会社は一度も所有者にならない**：鉄板を運んでも、鉄板は荷主のものです |
| | ・**それでも責任を負う**：【Fact】商法第575条により、運送人は**運送品の受取から引渡しまで**の滅失・損傷・延着について賠償責任を負います。ただし**注意を怠らなかったことを証明したとき**は免れます。**証明する負担は運送人側**にあります |
| | ・**荷物の扱いを決めるのは荷主**：破損した荷物を返送するか、値引きして引き取ってもらうか、廃棄するかを決めるのは**所有者である荷主**です。運送会社は決められません（`07_goods.md` 7-5） |
| | ・**賠償額は荷物の価格で決まる**：【Fact】商法第576条第1項により、損害賠償の額は**引渡しがされるべき地及び時における運送品の市場価格**で定めます。**運賃は距離・車格・時間で決まるので、運賃と賠償額の大きさは連動しません**。【Example】運賃33,600円の運送で、荷物の価格が500万円ということが起こり得ます。だから貨物保険が必要になります |
| | ・**倉庫も同じ**：倉庫にある在庫は荷主の財産であり、自社の貸借対照表には載りません |

## 16-10. さらに混同しやすい点（補足）

### (11) 定期点検 ≠ 車検

| | 内容 |
|---|---|
| **何が違うのか** | **定期点検整備**＝**自社（または委託先）が点検・整備する**義務。【Fact】3月ごと（道路運送車両法第48条第1項第1号）。**車検（継続検査）**＝**国の検査を受ける**義務。【Fact】貨物の運送の用に供する自動車の有効期間は原則1年（同法第61条第1項） |
| **なぜ混同するのか** | どちらも「車を点検してもらう」という感覚で捉えられるため。実務上、整備工場に出す点も同じ |
| **実務でどう効いてくるのか** | 【Fact】継続検査を受けようとする者は**点検整備記録簿を提示しなければなりません**（同法施行規則第39条）。つまり、定期点検をきちんと行って記録していないと、車検の手続に支障が出ます。また、**3月ごとの定期点検と1年ごとの車検は、期限の管理が別々に必要**です |

### (12) デジタコ ≠ 動態管理（GPS）

| | 内容 |
|---|---|
| **何が違うのか** | **デジタコ**＝【Fact】輸送安全規則第9条の運行記録計。瞬間速度・運行距離・運行時間を記録し**1年間保存**する**法令上の義務**。**動態管理（GPS）**＝**今どこにいるか**をリアルタイムで見る道具。【Varies】法令上の義務ではない |
| **なぜ混同するのか** | どちらも車に付ける機器であり、近年は両方の機能を持つ機器もあるため |
| **実務でどう効いてくるのか** | 【Fact】デジタコで記録できない車は運行の用に供せません（同規則第20条第1項第11号）。**装置の故障がそのまま配車の制約になります**。動態管理にはそのような制約はありません（`11_systems.md` 11-5） |

### (13) 点呼 ≠ 朝礼

| | 内容 |
|---|---|
| **何が違うのか** | **点呼**＝【Fact】運転者等**一人ひとり**に対して行い、酒気帯びの有無・疾病疲労睡眠不足の有無・日常点検の実施を確認し、指示を与え、**記録を1年間保存**する法令上の義務（輸送安全規則第7条）。**朝礼**＝全員に向けた連絡・周知 |
| **なぜ混同するのか** | 「点呼」という言葉が、学校や職場での「出席確認」の意味で使われるため |
| **実務でどう効いてくるのか** | 【Fact】点呼は**対面により、または国土交通大臣が定める同等の方法**により行います。**アルコール検知器を用い、目視等でも確認**します（同条第4項）。**全員を集めて一度に済ませるものではありません**。乗務前と乗務後の2回、一人ひとりに行います |

### (14) 運行指示書 ≠ 配車表

| | 内容 |
|---|---|
| **何が違うのか** | **配車表**＝実務上の帳票。どの荷物をどの車で誰が運ぶかを示す。**運行指示書**＝【Fact】**乗務前・乗務後の点呼のいずれも対面等で行うことができない業務を含む運行**ごとに作成し、運転者等に**携行させる**法定の書面（輸送安全規則第9条の3第1項） |
| **なぜ混同するのか** | どちらも「運行の内容をドライバーに伝えるもの」だから |
| **実務でどう効いてくるのか** | **日帰りで営業所に戻る運行は、運行指示書の作成対象ではありません。** 「毎日全車分を作る書類」と誤解すると、実務の理解を誤ります（`10_documents.md` 10-5） |

### (15) 事故の記録 ≠ 自動車事故報告書

| | 内容 |
|---|---|
| **何が違うのか** | **事故の記録**＝【Fact】輸送安全規則第9条の2により**社内で作成し3年間保存**するもの。**自動車事故報告書**＝【Fact】自動車事故報告規則第2条各号に該当する事故について、**30日以内に国土交通大臣に提出**するもの（同規則第3条第1項） |
| **なぜ混同するのか** | どちらも「事故の報告書」と呼ばれるため |
| **実務でどう効いてくるのか** | **すべての事故が自動車事故報告書の対象になるわけではありません。** 社内の記録は作るが、報告書は出さない事故もあります。【Fact】報告の対象となる事故は同規則第2条に15号にわたって限定列挙されています。判断がつかない場合は運輸支局に確認するのが実務上の対応です【Typical】 |

### (16) 事業報告書 ≠ 事業実績報告書

| | 内容 |
|---|---|
| **何が違うのか** | **事業報告書**＝【Fact】**毎事業年度の経過後100日以内**に提出。貸借対照表・損益計算書等の**財務**が中心。**事業実績報告書**＝【Fact】**毎年7月10日まで**（前年4月1日〜3月31日の期間）に提出。走行距離・輸送トン数等の**輸送実績**が中心（貨物自動車運送事業報告規則第2条第1項） |
| **なぜ混同するのか** | 名前が似ており、どちらも地方運輸局に出す年次の報告書だから |
| **実務でどう効いてくるのか** | ・**期限の性格が違う**：事業報告書は**決算期に連動**（会社ごとに違う）。事業実績報告書は**暦に連動**（全社共通で7月10日） |
| | ・**作る人が違う**：事業報告書は ⑦ 経理・財務機能の決算データ、事業実績報告書は ② 配車・運行管理機能の輸送実績データが元になります |

### (17) 許可 ≠ 登録 ≠ 届出

| | 内容 |
|---|---|
| **何が違うのか** | **許可**＝原則として禁止されている行為を、行政が個別に解除するもの。**登録**＝一定の要件を満たしていることを行政が確認して名簿に載せるもの。**届出**＝行政に知らせるもの |
| **なぜ混同するのか** | 日常語ではどれも「役所の手続」として一括りにされるため |
| **実務でどう効いてくるのか** | 【Fact】運送（一般貨物自動車運送事業）は**許可**（貨物自動車運送事業法第3条）、倉庫業は**登録**（倉庫業法第3条）、貨物軽自動車運送事業は**届出**（貨物自動車運送事業法第36条）、第一種貨物利用運送事業は**登録**、第二種は**許可**（貨物利用運送事業法第3条・第20条）。**手続の重さが違います** |

### (18) 荷役 ≠ 荷造り

| | 内容 |
|---|---|
| **何が違うのか** | **荷役**＝荷物を積む・降ろす・動かす作業。**荷造り**＝荷物を梱包してまとめる作業 |
| **なぜ混同するのか** | どちらも「荷物に対する手作業」だから |
| **実務でどう効いてくるのか** | 【Fact】輸送安全規則第8条第1項第7号ニは「積込み又は取卸し（**荷役作業**）の開始及び終了の日時」、同号ホは「**荷造り**、仕分その他の運送事業に**附帯する業務**を実施した場合」の開始・終了の日時を、それぞれ別に記録させると定めています。**条文上も区別されています** |

## 16-11. この章のまとめ — 会話で詰まらないための5つの確認質問

【Inference】運輸・物流業の会社と話すとき、最初に次の5つを確認すると、
話が噛み合わなくなることを避けられます。

```
① 「運送の話ですか、倉庫の話ですか」
   → 根拠法・許認可・約款・責任がすべて変わる（16-9(1)）

② 「自社で運ばれていますか、他社に出されていますか」
   → 実運送か利用運送か。収益構造も必要な許認可も違う（16-9(2)）

③ 「倉庫は営業倉庫ですか、自家倉庫ですか」
   → 倉庫業法の登録の要否、倉庫管理主任者の選任の要否が変わる（16-9(3)）

④ 「その金額は運賃だけですか、料金も含みますか」
   → 待機時間料・荷役料・高速代が入っているかどうかで金額の意味が変わる（16-9(8)）

⑤ 「受領書はもう戻っていますか」
   → 請求できる状態かどうかがこれで決まる（16-9(9)）
```

> **最後にもう一度：この業界を理解する核心**
>
> 1. **扱っているのは他人の荷物である**（所有者は荷主のまま。それでも責任を負う）
> 2. **運ぶ仕事は1日で終わるのに、代金が入るのは1〜2か月後である**
> 3. **費用は走らなくてもかかる／走れば必ずかかるのに、収入は積んで走っているときだけ発生する**
> 4. **ドライバーは1人で現場に出る**（だから点呼と記録で管理する）
> 5. **受領書がないと請求できない**（情報とカネをつなぐ結び目）
