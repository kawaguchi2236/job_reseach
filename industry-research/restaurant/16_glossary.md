## 16-1 店の中の仕事・現場の用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **仕込み**（しこみ） | 仕込み／下ごしらえ／プレップ | 営業前に、時間のかかる下処理をまとめて済ませておくこと | 「明日は予約が多いので、牛すじを15人前追加で仕込む」。**注文を受けてから全部作っていては間に合わない**ため、時間のかかる工程を営業時間の外へ出す。飲食業の中核工程（`07_goods.md` 7-5） |
| **下処理**（したしょり） | 下処理 | 野菜を洗って切る、肉に下味をつける、魚をさばくなど、調理の前段の作業 | 仕込みの中の具体的な作業を指す。「鶏の下処理をしておいて」 |
| **調理** | 調理 | 注文を受けてから、仕込み品を使って料理を仕上げること | 仕込みと区別される。**仕込みは営業前、調理は営業中**（16-8(16)） |
| **オーダー** | 注文／注文伝票 | 客からの注文、またはそれを書いた伝票 | 「3番テーブルのオーダー、通します」。ホールが受け、キッチンが作る根拠になる |
| **通す**（とおす） | オーダーを通す | 客から受けた注文を、厨房が作業できる形で伝えること | 「刺身2つ、通します」。**注文はホールから厨房へ一方向に流れて確定する**ため「通す」と言う。通し忘れ・二重通しは提供漏れや作りすぎに直結する（`09_information.md` 9-7） |
| **一括で通す**（いっかつ） | 一括 | 注文をまとめて厨房へ渡すこと | 「4名様、一括でお願いします」 |
| **追加オーダー** | 追加注文 | 食事の途中で追加される注文 | **客単価を押し上げる要素**。ホールがテーブルを見ていないと取りこぼす（`14_kpi.md` 14-3） |
| **止め**（とめ） | 止め | 厨房が一時的に注文を受けられない状態にすること | 「揚げ物、5分止めます」。受け続けると提供時間が延び、先に注文した客の料理も遅れるため。売上を一時的に捨てる判断（`06_people.md` 6-4） |
| **番手**（ばんて） | 番手 | 提供の順番 | 「この番手で出して」 |
| **デシャップ** | ディッシュアップ（dish up）に由来 | キッチンとホールの受け渡し場所（カウンター・棚） | 「デシャップに3番の唐揚げ出てます」。**場所を決めないと、完成した料理が放置されて冷める**。テーブル番号を声で言い合うことで渡し間違いを防ぐ |
| **ハンディ** | ハンディターミナル／オーダーエントリー端末 | 注文をその場で入力し、厨房とPOSに同時に伝える小型の機械 | 「ハンディで通す」。1回の入力で2か所に情報が届く（`11_systems.md` 11-2） |
| **キッチンプリンタ** | キッチンプリンタ | ホールで入力された注文を、厨房で紙の伝票として出力する機器 | 「プリンタから伝票が出る」 |
| **ラストオーダー（L.O.）** | ラストオーダー | その日の注文を受け付ける最終時刻 | 「まもなくラストオーダーです」。**閉店ぎりぎりに注文を受けると、調理・食事・片付けが閉店後にずれ込む**ため（`04_end-to-end-process.md` A-8.5） |
| **バッシング** | bussing（英語） | 食べ終わった食器を下げて、テーブルを次の客のために片付けること | 「バッシング急いで」。**席が空かなければ次の客を入れられない**ため、回転率に直結する。「下げ膳（さげぜん）」「片付け」とも言う |
| **下げ膳**（さげぜん） | 下膳 | 使用済みの食器を下げること | バッシングとほぼ同義で使われる |
| **セッティング** | テーブルセッティング | 箸・調味料・おしぼりを並べ、次の客を迎えられる状態にすること | 片付けとセットで行う |
| **ピークタイム** | ピーク | 客が集中して来店し、最も忙しい時間帯 | 「ピークは人を厚くする」。**必要な人数がこの時間帯に集中する**（`06_people.md` 6-8） |
| **アイドルタイム** | アイドルタイム | ピークとピークの間の、客が少ない時間帯 | 「アイドルタイムに仕込みを進める」。`【Inference】` 人が余る時間帯になりやすい |
| **上がり**（あがり） | 上がり | ①シフトの勤務を終えること　②（飲食店の隠語で）お茶 | 「21時上がりです」。勤務終了の意味で使われることが多い |
| **通し営業**（とおしえいぎょう） | 通し営業 | 昼と夜の間に閉めず、続けて営業すること | 「土日は通し営業」。**アイドルタイムも人を置く**ことになる |
| **締め**（しめ） | 締め | ①営業終了後にレジと売上を照合すること　②取引の期間を区切って合計すること | ①「レジを締める」②「月末締め、翌月払い」。**2つの意味があるので文脈で区別する**（16-8(15)） |
| **まかない** | まかない | 従業員が店で食べる食事 | `【Varies】` 提供の有無・扱いは企業により異なる |
| **洗い場**（あらいば） | 洗い場 | 食器・調理器具を洗浄する持ち場 | `【Inference】` ピーク時に洗浄が追いつかないと、**皿がないために料理を盛れない**状態が起こり得る（`07_goods.md` 7-11） |
| **ポジション** | ポジション | 担当する持ち場（ホール／揚げ場／洗い場 など） | 「今日は揚げ場に入って」。その日いる人の習熟度に合わせて割り振る（`06_people.md` 6-3） |
| **先入先出**（さきいれさきだし） | 先入先出 | 先に入ってきたものから先に使うこと | 冷蔵庫の中で、古い日付のものを手前に置く。**新しいものから使うと、古いものがいつまでも残り、最後は廃棄になる**（`07_goods.md` 7-10） |
| **歩留まり**（ぶどまり） | 歩留まり | 仕入れた食材のうち、**実際に料理に使える部分の割合** | 「このキャベツは外葉が多いから歩留まりが悪い」。魚をさばけば骨・内臓が出る。**歩留まりが悪いと、同じ仕入額でも作れる皿数が減る**ため、実際の原価は標準原価より高くなる |
| **ロス** | ロス／廃棄ロス | 仕入れたのに売上にならなかった食材 | 「昼の揚げ置きがロスになった」。**記録しないと、原価率が上がった原因が「仕入値」なのか「捨てた量」なのか分からなくなる**（`07_goods.md` 7-9） |
| **廃棄**（はいき） | 廃棄 | 食材・仕込み品・料理を捨てること | ロスの中で、実際に捨てた行為を指す。廃棄記録に「何を・どれだけ・なぜ」を書く |
| **揚げ置き**（あげおき） | 揚げ置き | ピークに備えて、揚げ物を先に揚げておくこと | **提供の速さと引き換えに、売れ残れば廃棄になるリスクを取っている**（`07_goods.md` 7-7） |
| **出数**（でかず） | 出数 | そのメニューが何皿売れたかの数 | 「先月の牛すじ煮込みの出数は320」。**翌日の仕込み量の根拠、メニュー見直しの判断材料になる**（`14_kpi.md` 14-1） |
| **品切れ**（しなぎれ） | 品切れ | そのメニューを提供できなくなること | **開店前に共有しないと、ホールが注文を受けてしまい、客に謝って取り直すことになる**（`04_end-to-end-process.md` A-4） |
| **数量限定** | 数量限定 | 提供できる数に上限を設けること | 品切れを避けるための扱い。「本日10食限定」 |
| **レシピ** | レシピ／標準的な作り方の文書 | 1品を作るのに必要な材料・分量・手順を書いた文書 | **作る人が変わると味が変わり、原価も変わる**ため文書化する。多店舗になるほど不可欠（`10_documents.md` 10-4） |
| **アレルゲン** | アレルゲン | アレルギーの原因となる食材 | 客から申し出があれば、ホールは必ず厨房に伝え、厨房は使用食材と調理器具の使い回しを確認する。**接客の丁寧さではなく、客の生命に関わる情報伝達**（`09_information.md` 9-7） |
| **セントラルキッチン** | セントラルキッチン | 複数店舗分の仕込みをまとめて行う専用工場 | `【Varies】` **大手外食チェーンが持つことがある仕組み。中小飲食企業一般の姿ではない**（`01_overview.md` 1-6） |

## 16-2 数字・指標の用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **売上高** | 売上高 | その期間に確定した代金の合計 | `売上＝席数×回転数×客単価`（＋席を使わない売上）。**すべての比率の分母になる** |
| **客数**（きゃくすう） | 客数 | 来店した人の延べ人数 | 客単価を計算する分母。POSで会計時に入力される |
| **組数**（くみすう） | 組数 | 来店したグループの数 | **客数とは別の情報。**40名の客が2名×20組で来るか8名×5組で来るかで、席の使い方が違う（`14_kpi.md` 14-2） |
| **客単価**（きゃくたんか） | 客単価 | 客1人あたりの平均支払額 | `客単価＝売上高÷客数`。**メニューの価格そのものではない**（16-8(11)） |
| **回転率**（かいてんりつ） | 回転率／回転数 | 1つの席が、その営業で何回使われたか | `回転率＝客数÷席数`。**片付けの速さで決まる部分がある**（`14_kpi.md` 14-4） |
| **席稼働率**（せきかどうりつ） | 席稼働率／座席稼働率 | 席がどれだけ埋まっていたかの割合 | `【Varies】` 定義が複数ある。**回転率とは別の指標**（16-8(12)） |
| **原価率**（げんかりつ） | 原価率／F比率 | 売上に対する食材費の割合 | `原価率＝食材費÷売上高×100`。**食材費＝月初在庫＋当月仕入−月末在庫**であり、仕入額そのものではない |
| **人件費率**（じんけんひりつ） | 人件費率／L比率 | 売上に対する人件費の割合 | `人件費率＝人件費÷売上高×100`。**人を入れすぎたのか、売上が足りなかったのかが分からない**ため、人時売上高と合わせて見る |
| **FL比率**（エフエルひりつ） | Food & Labor ratio | 食材費と人件費の合計が売上に占める割合 | `FL＝（食材費＋人件費）÷売上高×100`。**この2つは互いに置き換えが効く**（店で切るか、カット済みを買うか）ため、合計で見る |
| **FLR比率** | FLR比率 | FL に家賃（Rent）を加えた割合 | `FLR＝（食材費＋人件費＋家賃）÷売上高×100`。**家賃の重さを視界に入れるため**（`12_business-model.md` 12-4） |
| **ドリンク比率** | ドリンク比率／酒類比率 | 売上のうちドリンク（酒類）が占める割合 | **ドリンクの原価率はフードより低いことが一般的**なため、比率が高いほど全体の原価率が下がる（`14_kpi.md` 14-10） |
| **ロス率**（ロスりつ） | ロス率／廃棄率 | 捨てた食材の金額の割合 | `【Varies】` 分母は売上高または食材費。**ロス率が低いことは必ずしもよい状態を意味しない**（品切れを連発していても低く出る） |
| **人時売上高**（にんじうりあげだか） | 人時売上高 | 働いた1時間あたりの売上 | `人時売上高＝売上高÷総労働時間`。**山谷にどれだけ人数を合わせられたかを示す数字**（`14_kpi.md` 14-13） |
| **坪売上**（つぼうりあげ） | 坪売上／坪効率 | 面積1坪あたりの売上 | `坪売上＝売上高÷店舗面積（坪）`。**家賃は面積に応じて決まることが多い**ため、家賃に見合う売上が取れているかを見る |
| **坪**（つぼ） | 坪 | 面積の単位。1坪 ≒ 約3.3平方メートル | 不動産と飲食業の実務で広く使われる |
| **限界利益**（げんかいりえき） | 限界利益 | 売上から変動費だけを引いた金額 | `限界利益＝売上高−変動費`。**客が1人増えても家賃は増えない**ため、増えた売上のうち変動費を引いた分がそのまま利益の増加になる |
| **限界利益率** | 限界利益率 | 限界利益が売上に占める割合 | `限界利益率＝1−変動費率`。`【Example】` 46％なら、売上が1万円増えると利益が4,600円増える |
| **損益分岐点売上高** | 損益分岐点売上高 | 利益がちょうどゼロになる売上高 | `損益分岐点売上高＝固定費÷限界利益率`。**これを超えた分から利益が出る**（`12_business-model.md` 12-6） |
| **標準原価** | 標準原価 | レシピどおりに作った場合の1皿の食材原価 | メニュー別原価計算表の値。**実際の原価はこれより高くなるのが通常**（歩留まり・廃棄・計量のばらつきのため） |
| **実際原価** | 実際原価 | 棚卸から計算した、実際にかかった食材費 | 標準原価との差を見ることで、どこで差が出たかを追う（`14_kpi.md` 14-8） |

## 16-3 商取引・会計の基本用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **掛仕入**（かけしいれ） | 掛仕入 | 受け取った時点では支払わず、一定期間分をまとめて後で払う取引 | 「毎日届く野菜の代金を、月末で締めて翌月に振り込む」。**毎日払っていては事務作業が膨大になる**ため |
| **掛売**（かけうり） | 掛売／掛売上 | その場で代金を受け取らず、後日まとめて請求する取引 | `【Typical】` 飲食業では法人の宴会・仕出しで行われることがある。`【Varies】` 行うかどうかは企業により異なる |
| **締める**（しめる） | 締め | ある日付で区切って、その期間の取引を合計すること | 「月末締め」。`【Varies】` 締め日から支払日までの間隔は取引先との取り決めによる |
| **締め日** | 締め日 | 取引を区切る日付 | 「20日締め、翌月末払い」 |
| **買掛金**（かいかけきん） | 買掛金 | 食材を受け取ったが、まだ支払っていない代金。**払う義務** | 「今月届いた食材の代金180万円は翌月末に払う」→ この180万円が買掛金。**把握していないと、翌月にいくら払うのか分からず資金が足りなくなる** |
| **売掛金**（うりかけきん） | 売掛金 | 売上は立ったが、まだ入金されていないお金。**受け取る権利** | `【Typical】` 飲食業では**ほとんど発生しない**（その場で回収するため）。法人の掛売がある場合のみ管理が必要 |
| **売上原価** | 売上原価 | その期間に売れたものの原価。飲食業では食材費 | `売上原価＝月初在庫＋当月仕入−月末在庫`。**仕入額そのものではない**（16-8(13)） |
| **粗利**（あらり） | 粗利／売上総利益 | 売上高から売上原価（食材費）だけを引いた金額 | 「売上500万円、食材費170万円なら粗利は330万円」。**ここからまだ人件費も家賃も引いていない**ため「粗い利益」と呼ぶ |
| **営業利益** | 営業利益 | 粗利から販売費及び一般管理費（人件費・家賃など）を引いた金額 | **本業でいくらもうかったか**を示す |
| **固定費**（こていひ） | 固定費 | 売上が増えても減っても金額が変わらない費用 | 家賃、正社員の給与、リース料。「今月は客が半分だったが、家賃は満額払う」 |
| **変動費**（へんどうひ） | 変動費 | 売上に比例して増減する費用 | 食材費、割り箸などの消耗品費。「今月は客が半分だったので、食材の仕入も概ね半分」 |
| **棚卸**（たなおろし） | 棚卸 | 実際の在庫を数え、金額に換算すること | `月次`（`【Varies】`）。**これをしないとその月の本当の原価率が分からない**（`04_end-to-end-process.md` A-I） |
| **減価償却**（げんかしょうきゃく） | 減価償却 | 厨房機器などの資産の価値を、使う期間にわたって費用として配分すること | **お金は出ていかないが、費用として計上される**。開業時の設備投資が毎月の費用に影響する |
| **資金繰り**（しきんぐり） | 資金繰り | 口座の残高が支払の日に足りるかを先読みして把握すること | **利益が出ていても、支払日に残高が足りなければ払えない**。「もうかっているか」と「払えるか」は別問題（`08_money.md` 8-10） |
| **釣銭準備金**（つりせんじゅんびきん） | 釣銭準備金 | 開店時にレジに入れておく釣銭用の現金。**売上ではない** | 「毎朝5万円をセットし、締めのときはレジの現金から5万円を引いて照合する」。**混ぜて数えると毎日5万円多い計算になる** |
| **レジ差異／現金過不足** | 現金過不足 | レジの現金とPOSの現金売上額が合わないこと | **毎日確認すれば「今日ずれた」と分かるが、月末にまとめると追えなくなる**（`08_money.md` 8-9） |
| **レジ締め** | レジ締め | 営業終了後に、レジの現金とシステム上の売上記録が一致するかを確認すること | `日次`。一致しない場合、釣銭の渡し間違い・打ち間違い・記録漏れのいずれかが起きている |
| **前受金**（まえうけきん） | 前受金 | 提供する前に受け取ったお金 | `【Varies】` 貸切・宴会の予約金など。`【Varies】` 受け取った時点では売上ではない扱いになる |

## 16-6 業態・市場・販路の用語

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **内食**（ないしょく／うちしょく） | 内食 | 食材を買って家で調理して食べること | 外食・中食との対比で使う |

| **外食**（がいしょく） | 外食 | 店に行って、その場で食べること | `【Fact】` 2023年の外食産業市場規模は24兆1,512億円（同上） |
| **外食率** | 外食率 | 食料・飲料支出額のうち、外食が占める割合 | `【Fact】` 2023年は30.3％（出典：外食率と食の外部化率の推移／食の安全・安心財団） |

| **業態**（ぎょうたい） | 業態 | 何をどう売る店かという分類（居酒屋、カフェ、食堂 など） | **経営の規模・形態（個人店／多店舗チェーン）とは独立した軸**（`01_overview.md` 1-6） |
| **イートイン** | イートイン／店内飲食 | 店の中で食べること | `【Fact】` 消費税法別表第一第1号イの「食事の提供」に該当し、軽減対象から除かれる |
| **テイクアウト** | テイクアウト／持ち帰り | 料理を持ち帰ること | `【Fact】` 「持帰りのための容器に入れ、又は包装を施して行う譲渡」は同イのかっこ内で除外されており、飲食料品の譲渡として軽減対象になる |
| **デリバリー** | デリバリー／配達 | 料理を客のところへ届けること | 自社で配達する形と、プラットフォーム経由の形がある |

| **グルメサイト** | グルメサイト／予約サイト | 店舗情報を掲載し、予約を受け付けるサイト | `【Typical】` 客が店を探す入口の1つ。`【Varies】` 掲載料・予約手数料の体系は事業者と契約により異なる |
| **POS**（ピーオーエス） | Point of Sales（販売時点） | 会計を処理し、その時点で何が売れたかを記録する仕組み | **多くの数字がここから出る**（売上・客数・客単価・メニュー別出数・決済手段別の内訳） |
| **券売機** | 券売機 | 先に代金を受け取り、注文を確定させる機械 | 食券が厨房への指示にもなる |
| **モバイルオーダー** | モバイルオーダー | 客が自分の端末で注文を入力する仕組み | `【Varies】` |
| **自動釣銭機** | 自動釣銭機 | 釣銭の受け渡しを機械が行う道具 | `【Varies】` `【Inference】` 数え間違いが起きる場所が減る |
| **仕出し**（しだし） | 仕出し | 料理を作って店外へ届けること | `【Varies】` 法事・会議用の弁当など |
| **貸切**（かしきり） | 貸切 | 店舗全体を一定時間占有する利用 | `【Varies】` 最低金額・人数の条件を設ける場合がある |
| **飲み放題** | 飲み放題 | 一定時間・一定料金で酒類を提供する形 | `【Varies】` 時間・対象・料金は店により異なる |
| **お通し**（おとおし） | お通し／突き出し | `【Varies】` 席に着いた客に最初に出す小皿の料理 | `【Varies】` 提供の有無・金額・名称は店により異なる。`【Inference】` 客への事前の説明の仕方が、景品表示法第5条に関わる論点になりうる |

## 16-8 混同しやすい概念

### 【全業界共通の基本】

---

### (1) 売上 ≠ 入金

**何と何が違うのか**
- **売上**＝料理を提供し、代金が確定した時点で立つもの
- **入金**＝実際にお金が口座・レジに入ること

**なぜ混同するのか**
`【Inference】` 飲食業では**現金払いなら売上と入金が同時**に起きるため、
「飲食業は売上＝入金」と覚えてしまいがちです。

**実務でどう効いてくるのか**
`【Typical】` クレジットカード・電子マネー・コード決済・デリバリープラットフォーム経由の売上は、
**決済事業者・プラットフォームがいったん代金を受け取り、後日まとめて店へ入金されます。**
`【Varies】` 入金のサイクルと手数料は事業者と契約により異なります。

> `【Example】`（説明用の架空例）ある日の売上が412,600円でも、
> そのうち264,400円がキャッシュレスなら、**その日レジに入る現金は148,200円だけ**です。
> `【Inference】` 売上の数字を見て「今日はこれだけ現金が増えた」と考えると、資金繰りを誤ります
> （`08_money.md` 8-2）。

---

### (2) 受注 ≠ 売上（飲食業では「予約 ≠ 売上」）

**何と何が違うのか**
- **予約**＝来店の約束。まだ提供していない
- **売上**＝実際に提供し、代金が確定したもの

**なぜ混同するのか**
`【Inference】` 予約が入ると「その分の売上が確定した」と感じやすいためです。

**実務でどう効いてくるのか**
`【Typical】` 予約は**キャンセルされることがあります。**
`【Inference】` 予約分の食材を仕込んでいた場合、その分が廃棄になり、
さらにその時間帯は他の客を断っている可能性があります（無断キャンセル）。
`【Varies】` キャンセル料の設定と徴収の有無は企業により異なります。

> `【Inference】` **予約は「仕込み量を決めるための確定情報」であって、「確定した売上」ではありません。**
> この2つを分けて考えることが、仕込み量の判断の前提になります（`09_information.md` 9-2）。

---

### (3) 発注 ≠ 仕入計上

**何と何が違うのか**
- **発注**＝注文を伝えた時点
- **仕入計上**＝モノが届いて検品が済み、仕入として記録した時点

**なぜ混同するのか**
`【Inference】` 発注した時点で「買った」という感覚になるためです。

**実務でどう効いてくるのか**
`【Typical】` 発注したが届かなかったもの、届いたが返品したものは、**仕入になりません。**
`【Inference】` 検品の結果（不足・返品）を納品書に残しておかないと、
月末の請求書照合（B-5）で差異の根拠が示せません（`04_end-to-end-process.md` B-3）。

---

### (4) 在庫 ≠ すべて完成品

**何と何が違うのか**
飲食業の在庫には3つの段階があります。
- **食材（原材料）**＝仕入れたままの状態（丸ごとのキャベツ、鶏もも肉5kg）
- **仕込み品（半製品）**＝下処理を済ませた状態（千切りキャベツ、下味をつけた鶏肉、だし）
- **完成品**＝**飲食業では在庫として持てない**

**なぜ混同するのか**
`【Inference】` 小売業の在庫が「完成品」であるため、同じイメージを持ち込みがちです。

**実務でどう効いてくるのか**
`【Typical】` **仕込むと日持ちが短くなります。**
丸ごとのキャベツは数日持ちますが、千切りにすると当日〜翌日です。
`【Inference】` つまり仕込みは「時間を前倒しで買う」と同時に、「日持ちを短くする」工程でもあります。
`【Typical】` 棚卸では、食材と仕込み品の**両方**を数えます（`07_goods.md` 7-5）。

---

### (5) 粗利 ≠ 利益

**何と何が違うのか**
- **粗利（売上総利益）**＝売上高 − 売上原価（食材費）
- **営業利益**＝粗利 − 販売費及び一般管理費（人件費・家賃・水道光熱費 など）

**なぜ混同するのか**
`【Inference】` 「原価率30％」と聞くと、「残り70％がもうけ」と思ってしまうためです。

**実務でどう効いてくるのか**
> `【Example】`（説明用の架空例）売価1,200円のハンバーグ定食の食材費が360円なら原価率30％。
> しかし**残りの840円は利益ではありません。**
> 人件費・家賃・水道光熱費・食器や備品の費用がここから出ます（`01_overview.md` 1-5）。
>
> `【Inference】` FL比率で見ると、すでに60％前後が消えていることがあります（`【Varies】`）。

---

### (6) 見積 ≠ 契約（飲食業では「メニューの価格 ≠ 見積」）

**何と何が違うのか**
`【Typical】` 飲食業では、**メニューに価格が書いてあり、都度の見積はありません**
（`04_end-to-end-process.md` 4-0）。
ただし宴会・仕出しなど、事前に内容と金額を決める取引では見積が行われます（`【Varies】`）。

**なぜ混同するのか**
`【Inference】` 他業界の「見積→受注」の流れを持ち込むと、飲食業のフローが理解できなくなります。

**実務でどう効いてくるのか**
`【Typical】` 通常の来店では、**口頭の注文で取引が確定します。**書面の契約はありません。
`【Varies】` 宴会・仕出しでは見積・予約という形で事前に内容が決まり、
法人利用では**請求書払い（掛売）**になる場合があります。

---

### 【飲食業に固有の混同ペア】

---

### (7) 売上 ≠ 利益

**何と何が違うのか**
- **売上**＝提供して代金が確定した金額
- **利益**＝売上から**すべての費用**を引いた残り

**なぜ混同するのか**
`【Inference】` 飲食業は毎日現金が入り、大きな支払は月末にしか来ません。
そのため**日々の売上が大きく見え、手元に余裕があるように感じられます。**

**実務でどう効いてくるのか**
> `【Inference】` 毎日入ってくる現金の中には、
> **翌月に払う仕入代金の分、翌月払う給与の分、月末に払う家賃の分が含まれています。**
> `【Typical】` 「日々の売上をそのまま使ってしまうと、月末の支払で資金が足りなくなる」
> という事態は、この構造から生じます（`08_money.md` 8-10）。
>
> `【Inference】` さらに、**利益とお金も別物です。**
> 月の利益が30万円出ていても、同じ月に厨房機器を80万円で買い替えれば、その月の現金は減ります。
> **「もうかっているか」（月次決算）と「払えるか」（資金繰り）は別に見ます。**

---

### (8) 原価率 ≠ FL比率

**何と何が違うのか**
- **原価率**＝**食材費だけ**が売上に占める割合（`食材費 ÷ 売上高`）
- **FL比率**＝**食材費＋人件費**が売上に占める割合（`(食材費＋人件費) ÷ 売上高`）

**なぜ混同するのか**
`【Inference】` どちらも「コストの割合」を示す指標で、飲食業の会話で両方が出てくるためです。

**実務でどう効いてくるのか**
`【Typical】` この2つは**互いに置き換えが効く**関係にあります。

| 選択 | F（食材費） | L（人件費） |
|---|---|---|
| 野菜を丸ごと仕入れて店で切る | ↓ | ↑ |
| カット済み野菜を仕入れる | ↑ | ↓ |
| 丸の魚を仕入れて店でさばく | ↓ | ↑ |
| さばいた切り身を仕入れる | ↑ | ↓ |

> `【Inference】` **原価率だけを見て「下がった」と判断すると、
> その裏で人件費が上がっていることに気づけません。**
> だから合計（FL）で見る、という発想になります（`12_business-model.md` 12-4）。
>
> `【Varies】` なお、本資料では原価率・FL比率の目安となる数値を示しません
> （業態により前提がまったく異なり、公的統計で確定できないため）。

---

### (9) 廃棄ロス ≠ 食べ残し

**何と何が違うのか**
- **廃棄ロス（仕入ロス・仕込みロス）**＝**店が仕入れすぎた／作りすぎた**結果、捨てたもの
- **食べ残し**＝**客が食べ切れなかった**もの

**なぜ混同するのか**
`【Inference】` どちらも「捨てた食材」であり、廃棄記録には両方が載るためです。

**実務でどう効いてくるのか**
> `【Inference】` **原因がまったく違うため、見るべき場所が違います。**
>
> | | 廃棄ロス（仕入・仕込み） | 食べ残し |
> |---|---|---|
> | 原因 | 発注量・仕込み量の判断 | メニューの分量／注文時の助言 |
> | 対応する工程 | A-1 発注／A-3 仕込み | メニュー設計／A-6 注文 |
> | 誰が気づくか | ⑧仕込み機能・⑦店長機能 | ⑩ホール機能（下げ膳のとき） |
>
> `【Typical】` だから廃棄記録には「何を・どれだけ・**なぜ**捨てたか」を書きます。
> **理由が分かれば、発注・仕込み・オーダーのどこに原因があったかまで遡れます**（`07_goods.md` 7-9）。

---

### (10) 回転率 ≠ 席稼働率

**何と何が違うのか**

| | **回転率** | **席稼働率** |
|---|---|---|
| 何を見るか | **1席が何回使われたか**（時間方向） | **何席が埋まっているか**（空間方向） |
| 計算 | 客数 ÷ 席数 | 使われた席 ÷ 全席 |

**なぜ混同するのか**
`【Inference】` どちらも「席がどれだけ使われたか」を示す指標に見えるためです。

**実務でどう効いてくるのか**
> `【Example】`（説明用の架空例）40席の店で、
> - **ケース1**：4人掛けテーブル10卓に、**2名ずつ**入っている
>   → **席稼働率は50％**だが、**テーブルは全部埋まっており、新しい客を案内できない**
> - **ケース2**：4人掛けテーブル5卓に**4名ずつ**入っている
>   → 席稼働率も50％だが、**5卓が空いており、案内できる**
>
> `【Inference】` **「席が空いているのに入れない」という状態が、飲食業では普通に起こります。**
> 席稼働率だけを見ても、店が満席かどうかは分かりません（`14_kpi.md` 14-5）。

---

### (11) 客単価 ≠ 1品単価

**何と何が違うのか**
- **1品単価**＝メニュー1品の価格
- **客単価**＝客1人あたりの**平均支払額**（`売上高 ÷ 客数`）

**なぜ混同するのか**
`【Inference】` 「うちの主力は900円の定食だから、客単価は900円」と考えてしまうためです。

**実務でどう効いてくるのか**
`【Inference】` 客単価は次で決まります。

```
客単価 ＝ （フードの1品単価 × フードの注文点数）
        ＋（ドリンクの1杯単価 × ドリンクの杯数）
```

> `【Example】`（説明用の架空例）900円の定食を1品だけ頼む客の客単価は900円ですが、
> 900円の定食＋300円のドリンクを頼めば1,200円になります。
> 逆に、2名で1,800円の料理を分けて食べれば、客単価は900円です。
>
> `【Typical】` だから**追加オーダーを取れるかどうかが客単価を動かします**（`14_kpi.md` 14-3）。

---

### (12) 客数 ≠ 組数

**何と何が違うのか**
- **客数**＝来店した**人**の延べ人数
- **組数**＝来店した**グループ**の数

**なぜ混同するのか**
`【Inference】` 会話で「今日は50来た」と言われたとき、どちらか分からないためです。

**実務でどう効いてくるのか**
> `【Example】`（説明用の架空例）40席の店に、
> 「2名の組が20組（客数40名）」来る日と、「8名の組が5組（客数40名）」来る日では、
> 客数は同じですが、**席の使い方も、接客の手間も、会計の件数も違います。**
>
> `【Inference】` **客数は料理を作る量に、組数は席の使われ方に対応します。**

---

### (13) 仕入 ≠ 売上原価（食材費は棚卸で確定する）

**何と何が違うのか**
- **仕入**＝その期間に**買った**金額
- **売上原価（食材費）**＝その期間に**使った**金額

**なぜ混同するのか**
`【Inference】` 「今月180万円仕入れたから、食材費は180万円」と考えてしまうためです。

**実務でどう効いてくるのか**
`【Typical】` その月の食材費は、次で計算します。

```
当月の食材費 ＝ 月初の在庫 ＋ 当月の仕入 − 月末の在庫
```

> `【Example】`（説明用の架空例。数値は説明のための仮置きです）
> 月初在庫60万円、当月仕入180万円、月末在庫70万円なら、
> 当月の食材費＝60＋180−70＝**170万円**。
> 売上が500万円なら原価率は34.0％。**仕入額180万円で計算すると36.0％となり、2ポイントずれます。**
>
> `【Inference】` **月末の在庫を数えなければ、この区別ができません。**
> だから棚卸（A-I）をしないと、その月の本当の原価率もFL比率も出せません
> （`04_end-to-end-process.md` A-I）。

---

### (14) キャッシュレス売上 ≠ 即時入金

**何と何が違うのか**
- **キャッシュレスで会計した時点**＝売上が確定した時点
- **店の口座にお金が入る時点**＝決済事業者の入金サイクルに応じた後日

**なぜ混同するのか**
`【Inference】` 「その場で代金を回収する」という飲食業の特徴と、
「その場で現金が手元に入る」ことを同じだと思ってしまうためです。

**実務でどう効いてくるのか**
`【Varies】` 入金のサイクルと手数料は、決済事業者・プラットフォームと契約内容により異なります。
`【Inference】` **キャッシュレス比率が上がるほど、
「売上が立った日」と「現金が手元に来る日」のずれが大きくなります。**

> `【Inference】` さらに、**手数料が差し引かれた額が入金されます。**
> 売上1,000円のキャッシュレス取引で、店の口座に入るのは1,000円ではありません
> （`08_money.md` 8-2）。

---

### (15) 「締め」の2つの意味

**何と何が違うのか**
- **レジ締め**＝営業終了後に、レジの現金とPOSの売上記録が一致するかを確認すること（`日次`）
- **（取引の）締め**＝ある日付で区切って、その期間の取引を合計すること（`月次`）

**なぜ混同するのか**
`【Inference】` 同じ「締める」という言葉が、まったく違う作業を指すためです。

**実務でどう効いてくるのか**
`【Typical】` 「締め日」と言われたら**取引の締め**、
「締め作業」と言われたら**レジ締め**を指すことが多いですが、文脈で確認が必要です。

> `【Inference】` 前者は**現金が合っているかの確認**、
> 後者は**いくら請求されるか・いくら払うかを確定させる作業**です。
> 担当する機能も違います（レジ締め＝⑦⑪、取引の締め＝④）。

### (16) 仕込み ≠ 調理

**何と何が違うのか**
- **仕込み**＝**営業前**に、時間のかかる下処理をまとめて済ませておくこと
- **調理**＝**営業中**に、注文を受けてから仕込み品を使って仕上げること

**なぜ混同するのか**
`【Inference】` どちらも「厨房で食材を扱う作業」であり、同じ人が行うことも多いためです。

**実務でどう効いてくるのか**
> `【Example】`（説明用の架空例）「牛すじの煮込み」を注文後に一から作ると、
> 下茹で30分＋煮込み2時間＝2時間半かかります。客は待てません。
> そこで**開店前に煮込んでおき（仕込み）、注文時は温めて器に盛るだけ（調理・2〜3分）**にします。
>
> `【Inference】` つまり、
> - **仕込みの量は「見込み」で決める**（外れれば廃棄か品切れ）
> - **調理の量は「注文」で決まる**（外れようがない）
>
> **判断の性質がまったく違います。**
> 仕込み量の判断がその日の利益を左右する、と言われるのはこのためです（`07_goods.md` 7-6）。

### (17) 店内飲食とテイクアウトで消費税率が違う

**何と何が違うのか**
`【Fact】` 消費税法第29条は、軽減対象課税資産の譲渡等について100分の6.24、
それ以外について100分の7.8と定めています。
`【Fact】` 軽減対象となる「飲食料品の譲渡」からは、
**飲食店業その他の政令で定める事業を営む者が行う食事の提供**
（テーブル、椅子、カウンターその他の飲食に用いられる設備のある場所において飲食料品を
飲食させる役務の提供をいい、**当該飲食料品を持帰りのための容器に入れ、又は包装を施して行う譲渡は、
含まないものとする**。）が除かれます（消費税法別表第一第1号イ）。

**なぜ混同するのか**
`【Inference】` **同じ料理・同じ厨房・同じ店員が扱うのに、税率が変わる**ためです。

**実務でどう効いてくるのか**
| 取引 | 別表第一第1号イに該当するか | 結果 |
|---|---|---|
| 店内で飲食させる | **該当する**（軽減対象から除かれる側） | 軽減対象ではない |
| 持帰りのための容器に入れ、又は包装を施して行う譲渡 | **該当しない**（イのかっこ内で除外） | 飲食料品の譲渡として軽減対象になる |

> `【Typical】` だからPOSでは、会計時に「店内」「持ち帰り」を区別して入力することになります。
> `【Fact】` 個別の取引が該当するかどうかの判定は条文および政令の定めによります。
> **本資料は条文の文言を示すにとどめ、個別の判定は行いません**（`15_rules-customs.md` 15-8）。

### (18) 飲食店営業許可 ≠ 菓子製造業許可

**何と何が違うのか**
`【Fact】` 食品衛生法施行令第35条は、法第54条の規定により都道府県が施設についての基準を
定めるべき営業を号ごとに列挙しています。

| 号 | 営業の種類 |
|---|---|
| 第1号 | **飲食店営業** |
| 第11号 | **菓子製造業**（`【Fact】` 「菓子（パン及びあん類を含む。）を製造する営業をいい、第二十六号又は第二十八号に該当するものを除く。」） |
| 第25号 | **そうざい製造業**（`【Fact】` 「通常副食物として供される煮物（つくだ煮を含む。）、焼物（いため物を含む。）、揚物、蒸し物、酢の物若しくはあえ物又はこれらの食品と米飯その他の通常主食と認められる食品を組み合わせた食品を製造する営業をいい、…」） |

**なぜ混同するのか**
`【Inference】` 「飲食店の許可を持っているのだから、食べ物に関することは何でもできる」
と思ってしまうためです。

**実務でどう効いてくるのか**
> `【Inference】` **飲食店営業の許可は、第35条第1号に掲げられた1つの営業についての許可です。**
> 菓子製造業（第11号）、そうざい製造業（第25号）は、それぞれ別の号に掲げられた別の営業です。
>
> `【Typical】` 飲食店が次のようなことを行おうとする場合、
> **飲食店営業の許可とは別の許可が必要になる場合があります。**
> - 店で焼いた菓子・パンを、容器包装に入れて販売する
> - 惣菜を作って他の店に卸す
>
> `【Varies】` **どの営業に該当するかの判断は、具体的な製造・販売の形態によります。
> 実務上は保健所に確認することになります**（`15_rules-customs.md` 15-15）。

### (19) 食品衛生責任者 ≠ 食品衛生管理者

**何と何が違うのか**
- **食品衛生責任者**＝`【Fact】` 営業者が施設ごとに定める衛生管理の責任者
  （食品衛生法施行規則別表第17第1号イ）
- **食品衛生管理者**＝`【Fact】` 食肉製品・乳製品など特定の食品を製造・加工する施設に置く専門職
  （食品衛生法第48条）

**なぜ混同するのか**
`【Inference】` 名称が似ており、どちらも「食品衛生」の資格に見えるためです。

**実務でどう効いてくるのか**
`【Fact】` **一般の飲食店に求められるのは食品衛生責任者のほうです。**
`【Fact】` なお、食品衛生管理者は食品衛生責任者を兼ねることができます（別表第17第1号イ）。

> `【Fact】` 食品衛生責任者は、衛生管理の措置の遵守のために必要な注意を行うとともに、
> **営業者に対し必要な意見を述べるよう努める**こととされ（別表第17第1号ホ）、
> **営業者は食品衛生責任者の意見を尊重**しなければなりません（同ニ）。

### (20) 収容人員 ≠ 席数

**何と何が違うのか**
- **席数**＝店の中の席の数
- **収容人員**＝`【Fact】` 当該防火対象物に出入し、勤務し、または居住する者の数
  （消防法施行令第1条の2第4項。算定方法は総務省令で定める）

**なぜ混同するのか**
`【Inference】` 「30人以上」という数字を見て、席数で判断してしまうためです。

**実務でどう効いてくるのか**
`【Fact】` 消防法施行令別表第一（三）項ロが「飲食店」にあたり、
同令第1条の2第3項第1号ロにより、**（一）項から（四）項までの防火対象物で、
収容人員が30人以上のもの**が防火管理者の選任対象です。

> `【Inference】` **収容人員には従業員も含まれます。席数と同じではありません。**
> `【Example】` モデル企業のC店（24席）については、
> 収容人員の算定結果により該当・非該当が分かれるため、
> 実際には所轄消防署に確認することになります（`15_rules-customs.md` 15-2）。

### (21) 店内で酒を出す ≠ 酒を売る（酒税法上は別の行為）

**何と何が違うのか**
`【Fact】` 酒税法第9条第1項は酒類の販売業免許について定めており、
**同項ただし書により、「酒場、料理店その他酒類をもつぱら自己の営業場において飲用に供する業」については
免許を要しません。**

**なぜ混同するのか**
`【Inference】` どちらも「酒を扱う」行為であり、同じ店の中で起きるためです。

**実務でどう効いてくるのか**
> `【Fact】` **店内で客に飲ませるだけなら、酒類販売業免許は要りません。**
> `【Inference】` 一方、**未開栓の酒を持ち帰り用に売る**行為は「販売業」にあたるため、
> 販売業免許が必要になります。
>
> `【Example】` モデル企業のB店（居酒屋）は店内提供のみのため免許不要、
> C店で瓶ワインを持ち帰り販売する場合には免許の取得が必要になる、という整理になります
> （`15_rules-customs.md` 15-4）。

### (22) 食品表示の義務は、店内飲食には原則として及ばない

**何と何が違うのか**
`【Fact】` 食品表示基準（平成27年内閣府令第10号）第1条（適用範囲）は次のとおりです。

> **この府令は、食品関連事業者等が、加工食品、生鮮食品又は添加物を販売する場合について適用する。
> ただし、加工食品又は生鮮食品を設備を設けて飲食させる場合には、
> 第四十条の規定を除き、適用しない。**

**なぜ混同するのか**
`【Inference】` スーパーやコンビニの食品に原材料名・消費期限・アレルゲンが表示されているため、
「飲食店の料理にも同じ表示義務がある」と思ってしまうためです。

**実務でどう効いてくるのか**
> `【Fact】` **店内飲食には、第40条の規定を除いて、食品表示基準は適用されません。**
> `【Fact】` 例外の第40条は、**生食用の牛肉を容器包装に入れないで消費者に販売する場合**の
> 注意喚起表示を定めています。
>
> `【Inference】` **ただし、これは「アレルギー対応をしなくてよい」という意味ではありません。**
> `【Typical】` 客からアレルギーの申し出があれば、ホールは厨房に伝え、
> 厨房は使用食材と調理器具の使い回しを確認します。
> `【Inference】` これは表示の義務ではなく、**客の生命に関わる情報伝達**として行われています
> （`09_information.md` 9-7）。
>
> `【Fact】` なお、テイクアウトのように容器包装に入れて販売する場合は、
> 食品表示基準第3条・第5条の定めが関わります。
> **「食品を製造し、又は加工した場所で販売する場合」の特例（第5条）には
> アレルゲンが掲げられていません**（`15_rules-customs.md` 15-9）。

### (23) 「深夜」の定義は法律によって違う

**何と何が違うのか**
- `【Fact】` **風営法上の「深夜」＝午前0時から午前6時まで**（風営法第13条第1項）
- `【Fact】` **労働基準法第37条第4項の割増賃金が関わる時間帯＝午後10時から午前5時まで**
  （厚生労働大臣が必要であると認める場合においては、
  その定める地域又は期間については午後11時から午前6時まで）

**なぜ混同するのか**
`【Inference】` どちらも「夜の営業」に関わる話であり、同じ「深夜」という語が使われるためです。

**実務でどう効いてくるのか**
> `【Example】` モデル企業のA店は23:00閉店です。
> - **風営法**：午前0時より前に閉店するため、第33条第1項の届出は不要
> - **労働基準法**：午後10時以降に働いた時間については、深夜の割増賃金が発生
>
> `【Inference】` **つまり「届出は要らないが、割増賃金は発生する」という状態があり得ます。**
> 2つの法律を1つに混ぜて考えると、この違いが見えなくなります。

### (24) レシート ≠ 領収書

**何と何が違うのか**
`【Typical】` 実務では、
- **レシート**＝会計のたびに全員に渡すもの（POSが出力する）
- **領収書**＝客から求められたときに、宛名を書いて渡すもの

という使い分けがされます。

**なぜ混同するのか**
`【Inference】` どちらも「支払ったことの証明」であり、重なる部分があるためです。

**実務でどう効いてくるのか**
`【Fact】` レシートの記載事項については、消費税法第57条の4第2項が
適格簡易請求書の記載事項を定めています。
`【Fact】` 領収書については、印紙税法別表第一第17号が金銭または有価証券の受取書を
課税文書として掲げています。
`【Varies】` 記載金額に応じた取扱いは同法および別表の定めによります。

> `【Inference】` 客が会社の経費として精算する場合に領収書を求めることが多い、という背景があります。

### (25) 納品書 ≠ 請求書

**何と何が違うのか**
- **納品書**＝「これを届けました」という、モノに添えられる書類。**届いた都度**もらう
- **請求書**＝「この期間分の合計はこれです」という、お金を請求する書類。**締めた後**にもらう

**なぜ混同するのか**
`【Inference】` どちらも仕入先から受け取る書類で、金額が書いてあるためです。

**実務でどう効いてくるのか**
`【Typical】` 飲食業では毎日納品があるため、納品書は毎日たまり、請求書は月に1枚来ます
（`【Varies】` 締めのサイクルは取引先により異なります）。

> `【Inference】` **納品書を捨ててしまうと、請求書照合ができません。**
> 「届いていないものの代金」「返品した分の代金」「取り決めと違う単価」を
> そのまま払うことになり得ます（`10_documents.md` 10-1）。

### (26) 個人店の姿 ≠ 中小多店舗企業の姿 ≠ 大手チェーンの姿

**何と何が違うのか**

| | 個人店（1店舗） | 中小多店舗（2〜10店舗程度） | 大手外食チェーン |
|---|---|---|---|
| 意思決定 | `【Typical】` 店主が1人で決める | `【Typical】` 本部と店舗の二層 | `【Varies】` 本部に専門部署 |
| 仕込み | `【Typical】` 各店の厨房 | `【Typical】` 各店の厨房 | `【Varies】` セントラルキッチンを持つことがある |
| 仕入 | `【Typical】` 店ごとに発注 | `【Typical】` 取引先と単価は本部、数量は店舗（`【Varies】`） | `【Varies】` 本部一括仕入 |
| レシピ | `【Typical】` 店主の頭の中で足りる | `【Typical】` 文書化が必要になる | `【Varies】` 標準化されている |

**なぜ混同するのか**
`【Inference】` 飲食業の話題として目にする情報の多くが、
**大手外食チェーンの姿**を扱っているためです。

**実務でどう効いてくるのか**
> `【Fact】` `01_overview.md` 1-7 のとおり、2021年6月1日現在、
> 飲食店（中分類76）の民営事業所499,176のうち**個人経営は311,574事業所（62.4％）**であり、
> 個人経営の事業所1か所あたりの従業者数は約3.0人です
> （出典：令和3年経済センサス‐活動調査／総務省・経済産業省）。
>
> `【Inference】` **セントラルキッチンや本部一括仕入は大手の姿であって、
> 中小飲食企業一般の姿ではありません。**
> 本資料が想定するのは、代表取締役＋本部スタッフ数名という規模の本部です
> （`03_company-structure.md` 3-1）。

### (27) 企業数 ≠ 事業所数 ≠ （営業許可）施設数

**何と何が違うのか**
- **企業数**＝会社・個人事業主の数。3店舗を運営する1社は「1」
- **事業所数**＝店舗の数。3店舗を運営する1社は「3」
- **（営業許可）施設数**＝営業許可の単位となる施設の数。1つの店舗が複数の許可を持つこともある

**なぜ混同するのか**
`【Inference】` 記事や資料で「◯◯万店」という数字を見たとき、
どれを数えたものか書かれていないことが多いためです。

**実務でどう効いてくるのか**
> `【Fact】` 飲食店（中分類76）の事業所数は499,193事業所（2021年6月1日現在。
> 出典：令和3年経済センサス‐活動調査／総務省・経済産業省）。
> `【Fact】` 一方、2024年度末現在、食品衛生法（改正法）に基づく許可を受けている
> 「飲食店営業」の営業施設数は946,451施設です
> （出典：令和6年度衛生行政報告例 第5章食品衛生 第3表－1／厚生労働省）。
>
> `【Typical】` 「飲食店営業」の許可は、いわゆる飲食店だけでなく、
> 旅館・ホテルの食事提供、病院や社員食堂の給食施設、スーパーの調理コーナー、
> キッチンカーなども対象になります。
> **したがって経済センサスの「飲食店の事業所数」とは一致しません**（`01_overview.md` 1-1）。
>
> `【Fact】` また、中小企業庁の統計では**飲食業は「宿泊業，飲食サービス業」として
> 宿泊業と合算**されており、**飲食業単独の企業数を分離することはできません。**

## 16-9 会話についていくための「頻出フレーズ」

`【Typical】` 飲食業の現場でよく交わされる言い回しを、意味とともに掲げます。

| フレーズ | 意味 | どの場面か |
|---|---|---|
| 「3番、通します」 | 3番テーブルの注文を厨房に伝える | A-6 注文 |
| 「揚げ物、5分止めます」 | 厨房が一時的に揚げ物の注文を受けられない | A-7 調理 |
| 「デシャップに出てます」 | 完成した料理が受け渡し場所に置かれている | A-8 提供 |
| 「バッシングお願い」 | 食器を下げてテーブルを片付けて | A-10 片付け |
| 「◯◯、あと3つです」 | その食材・仕込み品の残りが3つ分しかない | 営業中の在庫連絡 |
| 「品切れ入りました」 | そのメニューが提供できなくなった | 営業中 |
| 「L.O.（エルオー）お願いします」 | ラストオーダーを取りに回って | A-8.5 |
| 「レジ締めます」 | 営業終了後の現金とPOSの照合を始める | A-11 |
| 「今日のFLどうだった？」 | 食材費と人件費が売上に対してどうだったか | `月次`の会話 |
| 「月末締め、翌月末払いです」 | 月末で取引を区切り、翌月末に代金を支払う | 取引条件の確認 |
