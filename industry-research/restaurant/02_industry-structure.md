# 02_industry-structure.md — 飲食業の業界構造

> 飲食店は1軒だけでは成り立ちません。食材を運ぶ人、酒を届ける人、おしぼりを替える人、
> 予約を取り次ぐ仕組み、家賃を受け取る大家、そして許可を出す保健所。
> このファイルでは「飲食店の周りに誰がいて、モノとお金と情報がどう流れるか」を扱います。
> 出典の詳細は `19_sources.md` を参照してください。

---

## 11-1 主要プレイヤー（飲食店の周りにいる人たち）

`【Typical】` 1軒の飲食店を動かすために関わる事業者を、役割ごとに整理します。
中小飲食企業では、このうち複数の役割を1社が兼ねていることもあります（`【Varies】`）。

### (1) 食材を供給する側

| プレイヤー | 何をしてくれるか | なぜ必要か |
|---|---|---|
| **業務用食品卸（食材卸）** | 肉・魚・野菜・冷凍食品・調味料・米などを店まで配達する | `【Typical】` 少量ずつ多品目を、営業前の時間に届けてくれる。店が買いに行かずに済む |
| **青果卸／鮮魚卸／精肉卸（専門卸）** | 特定の分野の食材を扱う | `【Typical】` 品質・鮮度・産地にこだわる場合、専門卸から直接仕入れる |
| **卸売市場の仲卸** | 市場でその日の入荷から選んで売る | `【Typical】` 店主が自分の目で見て選びたい場合に使う（`11-2` 参照） |
| **業務用食品メーカー** | 冷凍食品・調味料・ソース・製菓材料などを作る | `【Typical】` 店で一から作ると時間がかかるものを、半製品・完成品の形で供給する |
| **産地・生産者（直送）** | 農家・漁協などから直接届く | `【Typical】` 「◯◯産」を売りにする店が使う。数量・時期が読みにくい |
| **量販店・業務用スーパー** | 店が買いに行って現金で買う | `【Typical】` 急に足りなくなったとき、少量だけ要るときに使う |
| **酒類卸（酒販店）** | ビール・日本酒・焼酎・ワイン等を配達する | `【Fact】` 酒類の販売には販売業免許が必要（酒税法第9条）。免許を持つ事業者から仕入れる |

### (2) 店の設備・備品を支える側

| プレイヤー | 何をしてくれるか | なぜ必要か |
|---|---|---|
| **厨房機器メーカー・販売業者** | コンロ・冷蔵庫・食洗機・製氷機の販売と設置 | `【Typical】` 開業時の設備一式を揃える |
| **厨房機器の保守・修理業者** | 故障時の修理、定期点検 | `【Typical】` **冷蔵庫が止まれば食材が全滅する。** 営業継続に直結する |
| **おしぼり・リネン（布製品）業者** | おしぼり・テーブルクロス・ユニフォームを定期的に回収し、洗浄したものを届ける | `【Typical】` 店で洗濯する手間と設備を持たずに済む |
| **食器・消耗品業者** | 食器、割り箸、紙ナプキン、テイクアウト容器 | `【Typical】` 割れた食器の補充、容器の補充は継続的に発生する |
| **清掃業者（ダクト・グリストラップ等）** | 排気ダクトの油汚れ除去、グリストラップ（厨房排水の油を溜める装置）の清掃 | `【Typical】` 油汚れは火災の原因になり、排水設備の詰まりは営業停止につながる |
| **害虫・害獣駆除業者** | ねずみ・ゴキブリ等の駆除と予防 | `【Fact】` 「ねずみ及び昆虫の駆除」は食品衛生法が定める衛生管理の基準に含まれる（食品衛生法第51条第1項第1号、同法施行規則別表第17第2号） |
| **廃棄物収集運搬業者** | 生ごみ・廃食用油・段ボール等の回収 | `【Typical】` 飲食店からは毎日ごみが出る。事業系ごみとして処理が必要 |
| **ガス・電気・水道事業者** | エネルギーと水の供給 | `【Typical】` 飲食店は水道光熱費の負担が大きい業種の1つ |

### (3) 客と店をつなぐ側

| プレイヤー | 何をしてくれるか | なぜ必要か |
|---|---|---|
| **グルメサイト・予約サイト** | 店の情報を掲載し、客からの予約を取り次ぐ | `【Typical】` 客が「近くの店」を探す入口になっている |
| **デリバリープラットフォーム** | アプリで注文を受け、配達員が店から客へ運ぶ | `【Typical】` 店が配達員を自前で抱えずに配達販売ができる |
| **クーポン・ポイント事業者** | 割引・ポイント付与の仕組みを提供する | `【Varies】` 利用の有無は企業により異なる |
| **地図・口コミサービス** | 店の位置・営業時間・口コミを表示する | `【Typical】` 来店前に客が見る情報源 |

### (4) 場所とお金に関わる側

| プレイヤー | 何をしてくれるか | なぜ必要か |
|---|---|---|
| **不動産オーナー（大家）・管理会社** | 店舗物件を貸す | `【Typical】` 飲食店の多くは賃借。**家賃は毎月固定で発生する** |
| **不動産仲介業者** | 物件を探す、契約を仲介する | `【Typical】` 飲食店可の物件は限られる（排気・給排水・ガス容量の制約があるため） |
| **内装・設備工事業者** | 厨房・客席の工事 | `【Typical】` 開業時と改装時に関わる |
| **POS・レジ事業者** | 注文の記録、会計、売上集計の仕組みを提供する | `【Typical】` 「何が何個売れたか」を記録する道具。日々の締め作業の土台になる |
| **キャッシュレス決済事業者（カード会社・コード決済事業者）** | 現金以外の支払手段を提供する | `【Typical】` 店は手数料を負担し、代金は後日まとめて入金される |
| **金融機関** | 開業資金・運転資金の融資、口座 | `【Typical】` 設備投資が先に必要な業種のため、借入を伴うことがある |
| **税理士・会計事務所** | 記帳、決算、税務申告 | `【Typical】` 個人店では経理を外部に委託することが多い |
| **社会保険労務士** | 雇用・社会保険の手続き | `【Varies】` 委託の有無は企業により異なる |

### (5) 行政・公的機関

| プレイヤー | 何をするか | 根拠 |
|---|---|---|
| **保健所（都道府県・保健所設置市・特別区）** | 飲食店営業の**許可**を出す。施設を調査・監視指導する。食中毒が起きれば調査する | `【Fact】` 食品衛生法第54条・第55条（許可）、第63条（中毒の調査） |
| **消防署** | **防火管理者**の選任届・消防計画の届出を受ける。消防用設備を検査する | `【Fact】` 消防法第8条第1項・第2項、同法施行令第3条の2第1項 |
| **警察署（公安委員会）** | 深夜に酒類を提供する飲食店営業の**届出**を受ける | `【Fact】` 風俗営業等の規制及び業務の適正化等に関する法律第33条第1項 |
| **税務署** | 酒類の**販売業免許**を出す（持ち帰り販売を行う場合）。税務申告の窓口 | `【Fact】` 酒税法第9条第1項 |
| **労働基準監督署・年金事務所・ハローワーク** | 労働・社会保険・雇用に関する手続きの窓口 | — |

> `【Fact】` **保健所・消防署・警察署は、それぞれ別の法律に基づいて別々に手続きを求めます。**
> 「保健所の許可が下りたから全部終わり」ではありません。詳細は `15_rules-customs.md` で扱います。

## 11-2 商流（食材はどの経路で店に届くのか）

飲食業の仕入には、性格の異なる複数の経路が**同時に**使われます。
1つの店が1つの経路だけを使うことは、むしろ稀です（`【Typical】`）。

### 主な仕入ルート

```
【ルート1】業務用食品卸から配達してもらう  ← 最も一般的
   生産者/メーカー → 卸 → 【店】
   ・多品目をまとめて、決まった時間に届けてくれる
   ・代金は掛（後払い）が一般的

【ルート2】卸売市場で仕入れる
   生産者 → 卸売市場（卸売業者）→ 仲卸 → 【店】
   ・店主が早朝に市場へ行き、自分の目で選ぶ
   ・その場で現金で払うこともある

【ルート3】産地・生産者から直送してもらう
   生産者 → （宅配便等）→ 【店】
   ・品質・希少性・物語性を重視する場合
   ・入荷量と時期が読みにくい

【ルート4】量販店・業務用スーパーで買い出し
   【店】が買いに行く → その場で現金・カードで支払う
   ・急に足りなくなったとき、少量だけ要るとき

【ルート5】酒類卸（酒販店）から配達してもらう
   酒造メーカー → 酒類卸 → 【店】
   ・重量物なので配達が前提になりやすい
   ・空き瓶・ビールサーバーの樽の回収も担うことがある
```

### 現金仕入と掛仕入が混在する

飲食業の仕入の特徴は、**支払い方法が経路ごとにバラバラである**ことです。

| ルート | 支払い方 | いつ払うか |
|---|---|---|
| 業務用卸・酒類卸 | **掛（かけ）仕入**＝後払い | `【Typical】` 月末などに締めて、翌月にまとめて支払う |
| 卸売市場の仲卸 | `【Varies】` 現金または掛 | 取引関係により異なる |
| 産地直送 | `【Varies】` 前払い・代引き・掛 | 取引先により異なる |
| 量販店での買い出し | **現金・カード** | **その場** |

> **用語：掛仕入（かけしいれ）**
> → 商品を受け取った時点では支払わず、**一定期間分をまとめて後で支払う**取引のこと。
> → 実務例：「毎日届く野菜の代金を、月末で締めて、翌月にまとめて振り込む」。
> → **なぜそうするのか：** 毎日届くたびに支払っていては、店も卸も事務作業が膨大になります。
>   まとめることで、支払いも記帳も月1回で済みます。
>
> 「締める（しめる）」とは、**ある日付で区切って、その期間の取引を合計すること**です。
> 締め日から支払日までの間隔は取引先との取り決めで決まります（`【Varies】`）。

> `【Inference】` **この混在が、飲食業の経理を少し複雑にします。**
> 同じ「食材費」でも、現金で買った分はレシートを集めて記帳し、
> 掛で買った分は請求書と納品書を突き合わせて記帳する必要があります
> （`04_end-to-end-process.md` B系列の工程で扱います）。

### 客の側の商流（販売経路）

`【Typical】` 売る側の経路も複数あります。

```
【販路1】店内飲食（イートイン）  ← 本体
   客が来店 → 注文 → 提供 → その場で会計

【販路2】テイクアウト（持ち帰り）
   客が来店 → 注文 → 容器に詰めて渡す → その場で会計

【販路3】自社デリバリー（店が自分で配達）
   電話・自社サイトで注文 → 店の人が配達 → 現地で回収 or 事前決済

【販路4】デリバリープラットフォーム経由
   客がアプリで注文 → 店が調理 → 配達員が受け取り配達
   → 代金はプラットフォームが回収し、手数料を差し引いて店へ送金

【販路5】法人向け（仕出し・宴会・貸切）
   事前に見積・予約 → 実施 → その場で支払 または 請求書で後日回収
```

`【Fact】` **販路4では、代金は客からプラットフォームへ、そこから手数料を差し引いて店へ入ります。**
`【Varies】` 手数料率・入金サイクルは事業者と契約により異なります。
`【Inference】` したがって、同じ1,000円の料理でも、店に残る金額は販路によって変わります。

## 11-3 バリューチェーン（店の中で価値が付いていく順序）

**バリューチェーン**
→ 原材料が客に届くまでに、どの工程でどんな価値が加わるかを順番に並べたもの。
→ 飲食業では次の6段階になります。

```
① 仕入   ② 仕込み   ③ 調理   ④ 提供   ⑤ 会計   ⑥ 片付け
  ↓        ↓         ↓        ↓        ↓        ↓
食材を    使える     注文品を  客の前に  代金を    次の客を
手に入れる 状態にする  仕上げる  届ける    受け取る  迎えられる
                                                  状態に戻す
```

| 工程 | 何が起きるか | どんな価値が加わるか | なぜこの工程が要るのか |
|---|---|---|---|
| **① 仕入** | 食材・酒類・消耗品が店に入る | まだ価値は加わっていない（原価が発生しただけ） | `【Typical】` 必要なものが必要な日にないと、その日のメニューが出せない |
| **② 仕込み** | 洗う・切る・下茹でする・だしを取る・タレを作る・肉を漬ける | **「注文が来たらすぐ出せる状態」という価値** | `【Typical】` 注文を受けてから全工程をやると客を待たせすぎる。**時間を前倒しして買っている** |
| **③ 調理** | 注文を受けて火を通す・盛り付ける | **「今食べられる料理」という価値** | `【Typical】` 温度・食感は時間が経つと失われるため、注文後でなければならない |
| **④ 提供** | 客席まで運ぶ、説明する、取り分ける | **「席にいるだけで食べられる」という価値** | `【Typical】` 客が厨房に取りに行かなくてよいこと自体が売り物（セルフ業態は逆にここを削って価格を下げる） |
| **⑤ 会計** | 注文内容を合計し、代金を受け取る | 価値の**回収** | `【Typical】` ここで初めて売上が現金・カード債権になる |
| **⑥ 片付け** | 食器を下げる・洗う・テーブルを拭く・席を整える | **「次の客を迎えられる」という価値** | `【Typical】` これが遅いと**回転が止まる。片付けは売上に直結する工程** |

> **初心者がつまずく点：⑥片付けは「後始末」ではありません。**
> `【Inference】` 席が空かなければ次の客は入れず、売上は増えません（1-5 の基本式を参照）。
> ピーク時に片付けが滞ると、客席に空き皿が残り、待っている客を入れられません。
> **飲食業では片付けは生産工程の一部**です。

## 11-4 サプライチェーン（食材はどう流れ、どこに溜まるのか）

**サプライチェーン**
→ 原材料の産地から最終消費者までの、モノの流れ全体のこと。

```
【生産】          【集荷・加工】        【流通】            【店】          【客】
農家・漁業者  →  産地市場・加工場  →  卸売市場・卸  →  飲食店の厨房  →  客の口
畜産農家         食肉処理施設         業務用食品卸     ├ 冷蔵庫
食品メーカー     食品工場             酒類卸           ├ 冷凍庫
                                                       ├ 常温倉庫
                                                       └ 仕込み品
```

### 飲食業のサプライチェーンの特徴

#### (1) 生鮮品は毎日届く

`【Typical】` 野菜・鮮魚・精肉などの生鮮食材は、**営業日ごとに届く**のが基本です。
まとめ買いして置いておくことができないため、「今日使う分を今日受け取る」という流れになります。

#### (2) 在庫を持てない ＝ 在庫がリスクになる

`【Typical】` 製造業や卸売業では、在庫は「いつでも売れる資産」です。
飲食業では違います。**食材の在庫は、時間が経つほど価値が下がり、最後はゼロ（廃棄）になります。**

| 食材の種類 | 保管方法 | 持てる期間の目安 |
|---|---|---|
| 生鮮（葉物野菜・鮮魚） | 冷蔵 | `【Typical】` 1〜数日 |
| 精肉 | 冷蔵／冷凍 | `【Varies】` 部位・加工状態による |
| 仕込み済みの半製品 | 冷蔵 | `【Typical】` 生鮮よりさらに短い |
| 冷凍食品 | 冷凍 | `【Typical】` 比較的長い |
| 乾物・調味料・米 | 常温 | `【Typical】` 長い |
| 酒類（瓶・缶） | 常温／冷蔵 | `【Typical】` 長い |

> `【Inference】` **「在庫を厚く持って欠品を防ぐ」という製造業の発想が、飲食業では通用しません。**
> 多く持てば廃棄が増え、少なく持てば品切れで機会を失う。
> この綱引きが毎日発生するのが飲食業の在庫管理です。

#### (3) 欠品＝メニューが出せない

`【Typical】` 卸売業や小売業なら、ある商品が欠品しても他の商品を売れます。
飲食業では、食材が1つ足りないだけで**そのメニューが提供できなくなります。**

> `【Example】`（説明用の架空例）「本日のおすすめ・鮮魚の刺身」を出す店で、
> その日の市場に目当ての魚が入らなかった場合、
> 店は「別の魚に替える」「そのメニューを外す」のどちらかを、開店前に決めなければなりません。
> この判断は、仕入担当（中小では店主）が行います。

#### (4) 相場が変動する

`【Typical】` 生鮮食材の価格は、天候・漁獲・季節によって変動します。
`【Typical】` 一方、メニューの価格は貼り出してあるため、**仕入値が上がってもその日のうちには変えられません。**
`【Inference】` この非対称性が、飲食業の原価率を日々変動させる要因の1つになります。

#### (5) 食材以外にも流れがある

`【Typical】` 食材の逆方向にも、次のモノが流れています。

- **おしぼり・リネン**：業者が汚れたものを回収し、洗浄済みのものを置いていく（循環）
- **空き瓶・ビール樽**：酒類卸が回収していく（循環）
- **生ごみ・廃食用油**：廃棄物収集運搬業者が回収する（一方向・外へ）
- **テイクアウト容器**：店から客へ出ていったきり戻らない（一方向・外へ）

## 11-5 関係者マップ（誰が誰とやりとりするか）

```
                        ┌──────────────┐
                        │   行政機関     │
```

## 11-6 ★飲食業に特有の構造（ここが他業界と決定的に違う）

飲食業を理解するうえで外せない5つの構造です。
後続のすべてのファイルは、この5つを前提に書かれています。

---

### (1) 席数 × 回転数 × 客単価 ＝ 売上 （売上に物理的な天井がある）

```
売上 ＝ 席数 × 回転数 × 客単価
```

`【Typical】` 席数は店の面積で決まり、簡単には増やせません。
回転数は1組あたりの滞在時間と営業時間で決まり、これも無限には上げられません。

> `【Example】`（説明用の架空例）20席の店が、昼の営業（2時間）で1組60分滞在するなら、
> 理論上の上限は 20席 × 2回転 = 40人。
> 客単価が1,000円なら、**昼営業の売上上限は4万円**です。
> 行列ができていても、これ以上は売れません。

> `【Inference】` **だから飲食業では「需要があるのに売れない」という状態が普通に起きます。**
> 製造業なら残業して生産量を増やせますが、飲食業では席が空かない限り客を入れられません。
> 逆に、客が来ない時間帯は席が空いていても売上はゼロです。
> テイクアウトとデリバリーは、この天井の外側にある売上、という位置づけになります。

---

### (2) 立地が売上を決め、家賃が固定費としてのしかかる

`【Typical】` 飲食店の来店客の多くは、その場所の近くにいる人です。
店の前を通る人の数、周辺の人口、駅からの距離、競合店の有無が、
**その店が到達しうる客数の上限**をほぼ決めてしまいます。

そして**立地の良さと家賃は比例します。**

> **固定費（こていひ）と変動費（へんどうひ）**
> → **固定費**＝売上が増えても減っても金額が変わらない費用。家賃、正社員の給与、リース料など。
> → **変動費**＝売上に比例して増減する費用。食材費、割り箸などの消耗品費など。
> → 実務例：「今月は客が半分だったが、家賃は満額払う」＝家賃は固定費。
>   「今月は客が半分だったので、食材の仕入も概ね半分」＝食材費は変動費。

`【Inference】` 家賃が固定費であることの意味は重大です。
**台風で客が来なかった日も、家賃は日割りで発生し続けます。**
したがって飲食業では「その家賃を払える売上が、その立地で本当に取れるか」が
物件を決める時点で問われることになります（`12_business-model.md` で扱います）。

`【Typical】` また、飲食店に使える物件は限られます。
排気ダクトが設置できるか、ガスの容量が足りるか、給排水が確保できるか、
上階や近隣への臭い・音の影響がないか、といった条件があるためです。

---

### (3) 食材は腐る（在庫がそのままリスクになる）

`【Typical】` 飲食業の在庫は、放っておくと価値がゼロになります。
このため、次のような構造が生まれます。

| 起きること | なぜ起きるか | 店がやること |
|---|---|---|
| **廃棄（ロス）** | 売れ残った食材・仕込み品が使えなくなる | `日次` 廃棄した内容と量を記録する |
| **先入先出** | 古いものから使わないと、古い方が残って廃棄になる | `常時` 入荷日を書いて手前から使う |
| **仕込み量の判断** | 多く仕込めば廃棄、少なく仕込めば品切れ | `日次` 予約状況・天候・曜日を見て量を決める |
| **棚卸** | 帳簿上の在庫と実際の在庫がずれる | `月次`（`【Varies】` 頻度は企業により異なる）実際に数えて合わせる |

> **用語：ロス**
> → 仕入れたのに売上にならなかった食材のこと。
> → 実務例：「傷んで捨てた」「作りすぎて残った」「調理に失敗した」「注文を間違えた」。
> → **なぜ記録するのか：** 記録しないと、原価率が上がった原因が
>   「仕入値が上がったから」なのか「捨てすぎたから」なのか分からなくなるためです。

---

### (4) ピークタイムに人が集中して要る（人員配置の山谷）

`【Typical】` 飲食業の忙しさは、営業時間の中で均一ではありません。

```
【昼営業の例】                      【夜営業の例】
開店前  仕込み・準備（少人数）       開店前  仕込み・準備（少人数）
開店直後 ゆるやか                   開店直後 ゆるやか
ピーク  一気に満席（最大人数が要る） ピーク  予約・来店が集中（最大人数が要る）
ピーク後 客が引く                   ラストオーダー後 会計・片付け
閉店後  片付け・締め（少人数）       閉店後  片付け・締め（少人数）
```

`【Inference】` この山谷が、飲食業の人の使い方を決めます。

- **ピークに合わせて人を雇うと、暇な時間に人が余る**（人件費が無駄になる）
- **暇な時間に合わせて人を雇うと、ピークに回らない**（客を待たせ、機会を失う）

`【Typical】` だから飲食業では、**短時間だけ働くパート・アルバイトを組み合わせてシフトを作る**という
人の使い方が一般的になります。
`【Fact】` 深夜（午後10時から午前5時まで）に労働させた場合、使用者は通常の賃金の2割5分以上の割増賃金を支払う必要があります
（労働基準法第37条第4項）。
`【Inference】` 夜遅くまで営業する業態では、この割増が人件費の構造に影響します。

`【Varies】` 具体的なシフトの組み方・人数・時間帯は、業態・立地・店舗規模により大きく異なります。

---

### (5) デリバリープラットフォームという新しいコスト構造

`【Typical】` 2020年前後から、アプリ経由で注文を受け、
プラットフォーム事業者が手配した配達員が客まで運ぶ販売形態が一般化しました。

**店から見た構造の違い**

| | 店内飲食 | デリバリープラットフォーム経由 |
|---|---|---|
| 客と店の接点 | 店の中で直接 | **アプリの画面の中**（店は客と会わない） |
| 席を使うか | 使う（席数の制約を受ける） | **使わない**（席数の制約の外側） |
| ホール（接客）の人手 | 必要 | 不要（受け渡しのみ） |
| 容器 | 店の食器（洗って再利用） | **使い捨て容器**（都度コストが発生） |
| 代金の受け取り | その場で店が受け取る | **プラットフォームが受け取り、後日店へ送金** |
| 手数料 | なし（決済手数料を除く） | **売上に対して手数料が発生** `【Varies】` |
| 価格 | メニュー価格 | `【Varies】` 店内と異なる価格を設定する場合がある |

`【Varies】` **手数料率・契約条件・入金サイクルは事業者と契約内容により異なり、
公表されていない場合もあるため、本資料では具体的な数値を示しません。**

`【Inference】` 構造としては、
**「席の制約を受けずに売上を作れる代わりに、1件あたりに手数料と容器代という新しい費用が乗る販路」**
と理解してください。
同じ料理でも、店内で出す場合と配達で出す場合では、店に残る金額の計算がまったく別になります。
