# 13_periodic-work.md — 定期業務

**対象**：日本国内の中小規模の医療機関（主モデル：無床の内科診療所・院外処方）
**読み手**：医療をまったく知らない人
**最終更新**：2026-09-20

---

## 13-0. この章の書き方

> ### タイムスケジュールは作りません
>
> 【Inference】「9:00 朝礼、9:15 診療開始」といった時刻表は、医療機関ごとに大きく異なります。
> 根拠のない具体化は、かえって理解を誤らせます（`common/methodology.md` §3）。
>
> そこで本章は、**頻度の区分**と**イベント起点**で整理します。

### 使う頻度の語彙（`common/methodology.md` §5 と同一）

```
常時 / 日次 / 週次 / 月次 / 四半期 / 半期 / 年次
案件発生時 / 問い合わせ時 / 発注時 / 納品時 / 請求時 / 入金時
トラブル発生時 / 法定・契約上のタイミング / その他
```

【Inference】医療には「受注時」に当たる工程がありません（`04_end-to-end-process.md` 4-0）。
代わりに、患者が来院したことそのものが業務の起点になるため、**常時**という区分が多くなります。

### 医療機関の定期業務は「2つのサイクル」に支配されている

```
【A. 患者ごとのサイクル】  常時（患者が来るたび）
【B. 月次のサイクル】      月末締め → 翌月10日までに請求 → 約2か月後に入金
```

> 【Inference】診療所の1か月は、**月初（請求）と月末（締め）に山がある**形になります。
> これは他の業界の「月末締め・翌月末払い」と似ていますが、
> **提出期限が法令で「翌月10日」と決まっている**点が決定的に違います。

## 13-1. 常時（患者が来るたびに発生する）

| 業務 | 誰が | 関連ステップ | なぜするのか |
|---|---|---|---|
| 予約の受付・調整 | 医療事務 | A-1 | 【Inference】その日の患者の見通しを立て、準備を整えるため |
| **受付・資格確認** | 医療事務 | A-2 | 【Fact】療担規則第3条第1項が資格の確認を義務づけているため。**請求先と負担割合が決まる** |
| 問診・バイタル測定 | 看護師 | A-3 | 【Inference】医師が診察に使える時間を確保し、安全に関わる情報を先に拾うため |
| 診察 | 医師 | A-4 | 【Fact】医師法第17条により医業をなせるのは医師のみ |
| 検査の実施・検体の取り扱い | 看護師、【Varies】臨床検査技師 | A-5 | 【Fact】療担規則第20条第1号ホ「診療上必要があると認められる場合に行う」 |
| 診断・説明 | 医師 | A-6 | 【Fact】医師法第23条「療養の方法その他保健の向上に必要な事項の指導をしなければならない」 |
| 処置・注射・処方 | 医師（指示）、看護師（実施） | A-7 | 【Fact】保健師助産師看護師法第37条により、主治の医師等の指示があった場合を除くほか行えない |
| **診療録（カルテ）の記載** | 医師、看護師（看護記録） | A-8 | 【Fact】医師法第24条第1項「診療をしたときは、**遅滞なく**……記載しなければならない」 |
| **算定入力と会計** | 医療事務 | A-9 | 【Inference】当日の会計額と約2か月後の入金額の両方が、この入力で決まる |
| 処方箋の交付 | 医師（交付）、医療事務（手渡し） | A-10 | 【Fact】医師法第22条本文の交付義務（同条各号に例外） |
| 次回予約 | 医療事務 | A-11 | 【Typical】検査結果の説明日の案内を含む |
| 電話・窓口の問い合わせ対応 | 医療事務 | — | 【Typical】予約の変更、薬局からの疑義照会の取り次ぎ 等 |
| **疑義照会への回答** | 医師 | A-10 | 【Fact】薬剤師法第24条により、薬剤師は疑わしい点を確かめた後でなければ調剤できない |
| 手指衛生・器具の洗浄滅菌・環境の清拭 | 看護師 | C-4 | 【Fact】医療法施行規則第1条の11第2項第1号の院内感染対策の体制に対応 |
| 感染性廃棄物の分別 | 看護師 | C-5 | 【Fact】廃棄物処理法第12条の2第2項の保管、同条第5項の委託先の制限 |
| 医薬品・診療材料の在庫の把握 | 看護師 | — | 【Inference】切れると、その処置そのものができないため |

> **【Inference】「常時」が多いことの意味**
> 医療機関の業務の大半は、**患者が来たという事実によって始まります**。
> 一般の会社のように「案件が受注できたら始まる」という形ではないため、
> 1日の中で何が起きるかは、その日に誰が来るかで決まります。

## 13-4. 月次 — この業界で最も重い定期業務

### レセプト請求のサイクル（B-2〜B-7）

| # | 業務 | 誰が | いつ | 根拠・備考 |
|---|---|---|---|---|
| 1 | **月末締め**（B-2） | 医療事務 | 月次 | 【Inference】その月の診療分をすべて確定させる。未入力・未確定を洗い出す |
| 2 | **レセプト点検**（B-3） | 医療事務（主担当）＋医師 | 月次 | 【Typical】病名の抜け、資格の誤り、算定の要件、摘要欄の記載を確認 |
| 3 | **医師への差し戻しと確認** | 医療事務 → 医師 | 月次 | 【Typical】病名の追加・修正は医師がカルテを見て判断する |
| 4 | **審査支払機関への提出**（B-4） | 医療事務 | **法定・契約上のタイミング（各月分について翌月10日まで）** | 【Fact】請求命令第2条第1項 |
| 5 | **請求額の集計と院長への報告** | 医療事務 → 院長 | 月次 | 【Inference】その月の収入の見込みを把握するため |
| 6 | **入金の確認と突合**（B-6） | 院長（経理・財務機能） | 月次（入金時） | 【Typical】請求額と入金額を突き合わせる |
| 7 | **返戻への対応・再請求**（B-7） | 医療事務＋医師 | 月次 | 【Typical】内容を直して次の月の請求に乗せ直す |
| 8 | **査定の確認と再審査請求の判断**（B-7） | 医療事務＋医師＋院長 | 月次 | 【Typical】増減点連絡書を見て、再審査請求をするか判断する |

【Fact】**療養の給付及び公費負担医療に関する費用の請求に関する命令第2条第1項**
「第一条第一項の請求は、**各月分について翌月十日までに行わなければならない**」
（出典：療養の給付及び公費負担医療に関する費用の請求に関する命令／e-Gov法令検索）

> **【Inference】なぜ月初が最も忙しいのか**
> 提出期限が**翌月10日**と法令で決まっているためです。
> 締めてから提出までの日数が限られており、その間に点検・医師への確認・修正を終える必要があります。
> しかもこの間も、**通常の診療（常時の業務）は止まりません**。
> 【Typical】このため月初の数日は、医療事務にとって最も負荷が高い期間になります。

> **【Inference】1か月の中に「3つの月」が同時に存在する**
> ```
>   5月10日の時点で、医療事務が扱っているもの
>     ├─ 5月分 …… 今まさに診療している月（日次の算定入力）
>     ├─ 4月分 …… 点検して提出する月（B-3・B-4）
>     └─ 3月分 …… 入金と返戻・査定を確認する月（B-6・B-7）
> ```
> 3つの月の仕事が重なっている——これが医療事務の月次業務の実体です。

### そのほかの月次業務

| 業務 | 誰が | 備考 |
|---|---|---|
| **給与の計算と支払** | 医療事務／社会保険労務士 | 【Fact】労働基準法第24条第1項「賃金は、通貨で、直接労働者に、その全額を支払わなければならない」 |
| **源泉所得税の納付** | 医療事務／顧問税理士 | 【Fact】所得税法第183条第1項「**その徴収の日の属する月の翌月十日までに**、これを国に納付しなければならない」 |
| **社会保険料の納付** | 医療事務／社会保険労務士 | 【Fact】健康保険法第164条第1項（翌月末日まで） |
| **賃金台帳への記入** | 医療事務／社会保険労務士 | 【Fact】労働基準法第108条「賃金支払の都度遅滞なく記入」 |
| 医薬品・診療材料の仕入代金の支払 | 医療事務／院長 | 【Varies】卸との取引条件による |
| 委託費の支払（検査・清掃・廃棄物） | 医療事務／院長 | 【Typical】月次 |
| 家賃・リース料・水道光熱費の支払 | 医療事務／院長 | 月次 |
| **月次決算（試算表）の確認** | 顧問税理士 → 院長 | 【Inference】収入と費用の状況を把握するため |
| **資金繰り表の更新** | 院長／顧問税理士 | 【Inference】約2か月後に入る収入を前提に支払を組むため |
| 勤務シフトの作成 | 看護師リーダー／医療事務 | 【Typical】翌月分を作る |
| 【Varies】在庫の棚卸 | 看護師・医療事務 | 【Varies】頻度は医療機関により異なる。使用期限の点検を兼ねる |
| 窓口未収金の確認と督促 | 医療事務 | 【Fact】健康保険法第74条第2項が「善良な管理者と同一の注意をもってその支払を受けることに努めた」ことを前提としている |

> **【Inference】翌月10日に、2つの期限が重なる**
> | 期限 | 内容 | 根拠 |
> |---|---|---|
> | 翌月10日 | **レセプトの提出** | 【Fact】請求命令第2条第1項 |
> | 翌月10日 | **源泉所得税の納付** | 【Fact】所得税法第183条第1項 |
>
> 【Inference】根拠法はまったく別ですが、**同じ日が期限**になります。
> 月初に事務の負荷が集中する理由の一つです。

### ③ 医療安全・院内感染対策の研修（C-2・C-4）

【Fact】**医療法施行規則第1条の11第1項第3号**は、安全管理体制として
「……医療に係る安全管理のための基本的な事項及び具体的な方策についての**職員研修を実施**すること」を掲げています。

【Fact】**同条第2項第1号ハ**は、院内感染対策のための体制の確保に係る措置として
「従業者に対する院内感染対策のための**研修の実施**」を掲げています。
（出典：医療法施行規則／e-Gov法令検索）

> **【重要】条文は「実施すること」を求めており、回数の記載はここにはありません。**
> 【Inference】本資料では、条文で確認できる範囲を超えて回数を書きません。
> 頻度としては **法定・契約上のタイミング** として扱い、
> 具体的な実施回数は【Varies】とします。
> （実施の回数が施設基準の要件になっている場合があるかどうかは、本作業では確認していません。）

【Fact】同条第1項第2号（医療安全管理委員会の設置）および第5号（医療安全管理者の配置）は、
**病院、患者を入院させるための施設を有する診療所及び入所施設を有する助産所に限る**とされています。
【Fact】同条第2項第1号ロ（院内感染対策のための委員会の開催）についても同様です。
（出典：医療法施行規則／e-Gov法令検索）

> 【Inference】したがって無床診療所では、**指針の整備・研修の実施・事故報告のしくみ・記録の整備**が対象で、
> 委員会の設置・開催と医療安全管理者の配置は対象外となります（`03_company-structure.md` 3-5）。

## 13-8. 1年を通して見たときの姿（時刻表ではなく、負荷の形）

```
  【毎月くり返されるもの】
    月末 ──▶ 締め（B-2）
    月初 ──▶ 点検（B-3）→ 翌月10日までに提出（B-4）【Fact：請求命令第2条第1項】
             同じ10日に源泉所得税の納付【Fact：所得税法第183条第1項】
    月中 ──▶ 約2か月前の診療分の入金確認（B-6）・返戻／査定への対応（B-7）

  【年に1回まわってくるもの】
    職員の健康診断【Fact：労働安全衛生法第66条第1項】
    労働保険の年度更新【Fact：徴収法第19条第1項／6月1日から40日以内】
    年次決算・税務申告

  【2年に1度まわってくるもの】
    診療報酬改定への対応（C-7）【Fact：厚生労働省 診療報酬改定関係ページ】
      └─▶ マスタの更新、施設基準の届出のやり直し、掲示の差し替え、職員への周知

  【いつ来るか分からないもの】
    立入検査・個別指導【Varies】
    インシデント／医療事故／針刺し事故
    届出対象の感染症の診断
    職員の退職 → 施設基準への影響の確認
    機器の故障
```

> **【Inference】この図が示していること**
> 医療機関の定期業務には、**3つの周期**があります。
> 1. **月次の周期**（レセプト請求）——毎月必ず来る、最も重い周期。
> 2. **年次の周期**（健康診断・年度更新・決算）——一般の事業者と共通。
> 3. **2年の周期**（診療報酬改定）——**医療に固有**。収入の前提そのものが変わる。
>
> このうち、3の2年周期を持っている業界は多くありません。
> 「**2年に1度、国が定めた単価改定を受け取る**」——これが医療の定期業務の最大の特徴です。

## 13-9. モデルB（中小病院）で変わること

| 軸 | モデルA（無床診療所） | モデルB（一般病床120床） |
|---|---|---|
| 24時間の業務 | なし。診療時間で閉まる | 【Typical】入院患者がいるため、看護は日勤・準夜勤・深夜勤の交代制。**申し送り**が勤務交代のたびに発生 |
| 月次のレセプト | 外来レセプトのみ | 外来＋**入院レセプト**。金額が大きく点検の重みが違う |
| 会計 | 診療のたび | 外来はそのつど、入院は【Typical】月ごと・退院時にまとめて |
| 委員会 | 【Fact】医療法施行規則第1条の11第1項第2号・第5号、同条第2項第1号ロは対象外 | 【Fact】医療安全管理委員会の設置、医療安全管理者の配置、院内感染対策のための委員会の開催が対象 |
| 記録 | 診療録＋看護記録 | 【Fact】医療法施行規則第20条第10号の「診療に関する諸記録」を**過去2年間分** |
| 給食 | なし | 【Fact】医療法第21条第1項第8号により給食施設を有する。日次で食事の提供が発生 |
| 人員 | 【Fact】医療法第21条の人員基準の対象外 | 【Fact】医療法第21条第1項＋同施行規則第19条。【Fact】同条第5項により入院患者・外来患者・取扱処方箋の数は**前年度の平均値** |

> 【Inference】医療法施行規則第19条第5項が「前年度の平均値」としているため、
> 病院では**前年度の患者数の実績**が、当年度に必要な人員の標準を決めます。
> これは無床診療所には存在しない、年次の周期です。

## この章のまとめ

1. 本章は**タイムスケジュールを作らない**。頻度の区分とイベント起点で整理する。
2. 医療機関の業務は **常時（患者ごと）** と **月次（レセプト請求）** の2つのサイクルに支配される。
3. **月初が最も忙しい。** 【Fact】レセプトの提出期限が翌月10日（請求命令第2条第1項）で、
   同じ日に源泉所得税の納付期限も来る（所得税法第183条第1項）。
4. 月次の業務では、**3つの月が同時に動く**（今月＝診療／前月＝点検と提出／2か月前＝入金と返戻・査定）。
5. 年次の業務は**職員の健康診断**（【Fact】労働安全衛生法第66条第1項）、
   **労働保険の年度更新**（【Fact】徴収法第19条第1項＝次の保険年度の6月1日から40日以内）、年次決算。
6. **医療に固有なのは「2年の周期」**——診療報酬改定。その後2年間の収入の前提が書き換わる。
7. 医療安全・院内感染対策の研修は、【Fact】医療法施行規則第1条の11第1項第3号・第2項第1号ハが
   「実施すること」を求めている。**回数は条文に記載がないため、本資料では書かない**（【Varies】）。
8. 立入検査（保健所・都道府県／医療法）と個別指導（地方厚生局／保険診療）は**別のもの**。
9. 無床診療所では、委員会の設置・開催と医療安全管理者の配置は法令上の対象外
   （【Fact】医療法施行規則第1条の11第1項第2号・第5号、第2項第1号ロ）。
