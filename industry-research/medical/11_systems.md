# 11_systems.md — システム一覧

**対象**：日本国内の中小規模の医療機関（主モデル：無床の内科診療所・院外処方）
**読み手**：医療をまったく知らない人
**最終更新**：2026-09-20

---

## 11-0. この章で扱うこと／扱わないこと

> ### 【重要】この章は「今の仕事を理解するための道具の説明」です。
>
> **扱うこと**
> - その仕組みは**何のための道具か**
> - 誰が、どの業務で、何を入力し、何を取り出すか
> - 他の仕組みとどうつながっているか
>
> **扱わないこと（`common/methodology.md` §0 に従います）**
> - 導入の提案、製品の比較・選定、費用の話
> - 「導入すると効率が上がる」等の**評価**
> - DX、AI活用、業務改善、オンライン診療の推進に関する一切の記述
> - 紙で運用していることへの価値判断

【Varies】**紙のカルテを使っている診療所もあります。** 本章はこれを事実として記述し、良し悪しは述べません。
電子的な仕組みを使っている場合と紙の場合とで、**業務そのものの中身は変わりません**（記載する、算定する、請求する）。
変わるのは**記録の媒体と、情報の受け渡しの手順**です【Inference】。

## 11-2. 電子カルテ

> **用語：電子カルテ**
> → 診療録（カルテ）を、紙ではなく電子的に記録・保存・検索するための仕組みのこと。
> → 実務例：診察室の画面に、過去の受診歴、検査結果の推移、処方の履歴が並び、
>    医師がその日の所見を入力します。
> → **何のための道具か**：【Fact】医師法第24条第1項が診療録への記載を義務づけ、同条第2項が5年の保存を義務づけています。
>    その記載と保存を電子的に行うための仕組みです。

| 項目 | 内容 |
|---|---|
| 誰が使うか | 医師（記載）、看護師（看護記録）、医療事務（参照） |
| どの業務で | A-3 問診／A-4 診察／A-6 診断・説明／A-8 カルテ記載／B-3 レセプト点検（記載の確認） |
| 何を入力するか | 主訴、所見、判断、方針、指示、処方、経過 |
| 何を取り出すか | 過去の受診歴、検査結果の推移、処方の履歴、紹介状を書くための経過 |
| 他とのつながり | 【Typical】レセコンと連携している場合、診療内容がそのまま算定の入力に渡る。【Varies】連携の有無・範囲は施設により異なる |

【Varies】**紙のカルテを使っている診療所もあります。**

| | 電子カルテ | 紙カルテ |
|---|---|---|
| 記録の媒体 | 電子的な記録 | 紙のカルテ（袋やファイル） |
| 受付での準備 | 【Typical】患者を呼び出すと画面に表示される | 【Typical】カルテ棚から取り出して診察室へ運ぶ（A-2） |
| 保存 | 【Fact】いずれも5年（医師法第24条第2項）。保存の要件を満たす必要がある点は同じ | 同左 |
| 検索 | 【Inference】条件を指定して探せる | 【Inference】綴じられた順に追う |
| 同時に見られるか | 【Inference】複数の場所から同時に参照できる | 【Inference】現物は1か所にしかない |

> 【Inference】どちらであっても、**「診療をしたら遅滞なく記載する」「5年保存する」という法令上の要件は同じ**です。
> 本資料はどちらが良いという評価を行いません。

## 11-3. レセプトコンピュータ（レセコン）／医事会計システム

> **用語：レセプトコンピュータ（レセコン）**
> → 診療内容を入力すると、点数表に従って点数を計算し、会計額とレセプトを作る仕組みのこと。
> → 実務例：受付で「再診」「血液検査」「処方箋料」と入力すると、合計点数と患者負担額が出てきます。
> → **何のための道具か**：【Inference】診療報酬の点数表は膨大で、算定のルールも細かいため、
>    手計算では現実的でないからです（`04_end-to-end-process.md` B-1）。

| 項目 | 内容 |
|---|---|
| 誰が使うか | 医療事務（全員）、特にレセプト主担当 |
| どの業務で | A-9 会計／B-1 算定入力／B-2 月末締め／B-3 レセプト点検 |
| 何を入力するか | 行った診療行為（診察・検査・処置・注射・投薬・指導 等）、病名、保険の情報 |
| 何を取り出すか | **その日の窓口会計額**、領収証、診療明細書、**レセプト**、診療報酬請求書、日計表 |
| 他とのつながり | 電子カルテ（診療内容）、オンライン資格確認（保険の情報）、オンライン請求（提出データ） |

> **この仕組みの出力が、2つの用途を持つ**
> ```
>   算定の入力
>     ├─▶ その日の窓口会計額 ……………… 当日（A-9）
>     └─▶ 月末にレセプトになる ………… 約2か月後の入金（B-4→B-6）
> ```
> 【Inference】1つの入力が、当日の会計と約2か月後の入金の両方を決めます（`08_money.md` 8-9、`09_information.md` 9-3⑩）。

**点数表のマスタ**

> **用語：マスタ**
> → 点数表の内容（どの診療行為が何点か、どの組み合わせが算定できるか）を、システムが参照できる形で持っているデータのこと。
> → 実務例：診療報酬改定があると、このマスタを新しい内容に入れ替えます。
> → **なぜ重要か**：【Inference】古い点数のまま請求すれば、査定・返戻の原因になります。
>    改定への対応（C-7）に、このマスタの更新が含まれるのはこのためです。

## 11-4. オンライン資格確認

> **用語：オンライン資格確認**
> → 患者の保険資格の情報を、その場で電子的に確認する仕組みのこと。
> → 実務例：受付に置かれた顔認証付きカードリーダーで本人確認を行い、資格の情報を受け取ります。
> → **何のための道具か**：【Fact】療担規則第3条第1項第1号が、資格の確認の方法の一つとして「**電子資格確認**」を掲げ、
>    同条第4項が、患者が電子資格確認によって資格の確認を受けることができるよう**あらかじめ必要な体制を整備しなければならない**
>    と定めているためです（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索）。

| 項目 | 内容 |
|---|---|
| 誰が使うか | 医療事務（受付） |
| どの業務で | A-2 受付・資格確認 |
| 何を確認するか | どの保険に加入しているか、**負担割合は何割か** |
| これが決めるもの | **その日の会計額**と**約2か月後の請求先**の両方（`09_information.md` 9-3②） |
| 他とのつながり | レセコン（取得した資格の情報が会計とレセプトに使われる） |

【Fact】療担規則第3条第1項は、確認の方法として、第1号の電子資格確認のほか、
第2号「患者の提出し、又は提示する**資格確認書**」、第3号（過去に取得した資格情報を用いて保険者に照会し回答を受けて取得した直近の情報を確認する方法。一定の場合に限る）、
第4号「その他厚生労働大臣が定める方法」を掲げています（出典：同上）。

> 【Inference】つまり、資格の確認は**電子的な方法だけに限られているわけではありません**。
> 条文は複数の方法を列挙しており、第4項が電子資格確認の体制の整備を求めている、という構造です。

## 11-5. オンライン請求の仕組み

> **用語：オンライン請求**
> → レセプトのデータを、通信回線を通じて審査支払機関に送る仕組みのこと。
> → 実務例：月初にレセコンからデータを出し、専用の端末・回線で送信します。
> → **何のための道具か**：【Fact】療養の給付及び公費負担医療に関する費用の請求に関する命令第1条第1項は、
>    費用を請求しようとするときは「**電子情報処理組織の使用による請求**」により行うものとする、と定めています
>    （同令附則には、書面による請求を行っている保険医療機関等に関する規定が置かれています）
>    （出典：療養の給付及び公費負担医療に関する費用の請求に関する命令／e-Gov法令検索）。

| 項目 | 内容 |
|---|---|
| 誰が使うか | 医療事務（レセプト主担当） |
| どの業務で | B-4 審査支払機関への提出 |
| いつ | **各月分について翌月10日まで**【Fact：請求命令第2条第1項】 |
| 何を送るか | 点検済みのレセプトデータ |
| 何が戻るか | 【Typical】受付の結果、【Typical】返戻・増減点の連絡（B-7） |

【Fact】同令第2条第2項「第一条第一項の請求は、**審査支払機関の使用に係る電子計算機に備えられたファイルへの記録がされた時に
当該審査支払機関に到達したものとみなす**」（出典：同上）。

> 【Inference】この条文があるため、「いつ到達したか」が明確に定まります。
> 提出期限（翌月10日）との関係で、実務上の意味を持つ規定です。

## 11-6. 予約の仕組み【Varies】

> **用語：予約システム**
> → 診療の枠を管理し、患者の来院日時を押さえるための仕組みのこと。
> → 実務例：電話で受けた予約を画面上の枠に入れる、あるいは患者が自分で画面から枠を取る。
> → **何のための道具か**：【Inference】その日の患者の見通しを立て、診療の順番と必要な準備を整えるためです。

| 項目 | 内容 |
|---|---|
| 誰が使うか | 医療事務 |
| どの業務で | A-1 予約・来院／A-11 次回予約 |
| 何を扱うか | 日時、患者、初診か再診か、目的（定期受診・検査結果の説明・予防接種 等） |

【Varies】**予約制を採るかどうか、どの程度厳密に運用するかは医療機関により大きく異なります。**
予約を取らず来院順に診る医療機関もあります。本資料はどちらが良いとは述べません。

## 11-7. 検査に関する仕組み【Varies】

| 仕組み | 何のための道具か | 誰が使うか |
|---|---|---|
| **院内検査の機器と、その結果を扱う仕組み** | 院内で実施した検査（尿検査、簡易血液検査、心電図 等）の結果を記録・参照するため | 看護師、医師 |
| **検査センターとの結果授受の仕組み** | 委託した検体検査の結果を電子的に受け取るため | 医師、看護師 |
| **検査の依頼（オーダー）を伝える仕組み** | 医師の検査の指示を、院内および検査センターに伝えるため | 医師 → 看護師・検査センター |

【Fact】医療法施行規則第20条第6号は、病院の臨床検査施設について
「検体検査の業務を委託する場合にあつては、当該検査に係る設備を設けないことができる」と定めています
（出典：医療法施行規則／e-Gov法令検索）。

> 【Varies】どこまで院内で行い、どこから委託するかは施設により大きく異なります。
> 【Example】モデルAは、院内で尿検査・簡易血液検査・心電図・超音波を行い、それ以外は検査センターに委託しています。

## 11-8. 画像を保存・表示する仕組み（PACS）【Varies】

> **用語：PACS（パックス）**
> → エックス線写真などの医療画像を電子的に保存し、診察室の画面で呼び出して見るための仕組みのこと。
>    （Picture Archiving and Communication System の略）
> → 実務例：撮影した胸部エックス線の画像が、診察室の画面に表示されます。
> → **何のための道具か**：【Inference】画像を記録し、必要なときに取り出して見るためです。
>    【Fact】病院では、エックス線写真は医療法施行規則第20条第10号の「診療に関する諸記録」に含まれ、過去2年間分を備えます。

| 項目 | 内容 |
|---|---|
| 誰が使うか | 医師、【Varies】診療放射線技師 |
| どの業務で | A-5 検査（撮影）／A-6 診断・説明 |
| 【Varies】 | 導入の有無は施設と標榜科により異なる。【Example】モデルAはエックス線装置を持つが、CT・MRIはなく、必要時は近隣の病院に依頼する |

## 11-10. 仕組みどうしがつながっている／つながっていない

【Varies】中小の医療機関では、上記の仕組みが**すべてつながっているとは限りません**。

| つながり | つながっている場合 | つながっていない場合 |
|---|---|---|
| 電子カルテ ↔ レセコン | 【Typical】診療内容が算定の入力に渡る | 【Typical】医療事務がカルテを見て、レセコンに入力し直す |
| オンライン資格確認 ↔ レセコン | 【Typical】取得した資格の情報が会計・レセプトに使われる | 【Typical】確認した内容を手で入力する |
| 検査センター ↔ 電子カルテ | 【Typical】結果が電子的に取り込まれる | 【Typical】紙の報告書を受け取り、カルテに綴じる |
| レセコン ↔ オンライン請求 | 【Typical】作成したレセプトデータをそのまま送信 | — |

> 【Inference】つながっていない部分は、**人が情報を移し替える仕事**になります。
> 業務を理解するうえでは、「どこまでが自動で、どこからが手作業か」を見ると、
> その医療機関の1日の仕事量の内訳が見えてきます。
> 本資料は、どちらの状態が望ましいかについては述べません。

## 11-11. モデルB（中小病院）で増える仕組み

| 仕組み | なぜ増えるか |
|---|---|
| **オーダリングの仕組み** | 【Inference】診察室と、検査・薬剤・放射線の各部門が離れているため、指示を電子的に伝える必要が生じる |
| **入院の会計・入院レセプトを扱う仕組み** | 【Typical】外来とは別に、入院の料金計算とレセプト作成が必要になる |

| **薬剤部の仕組み**【Varies】 | 【Fact】医療法第21条第1項第7号により病院は調剤所を有する。院内での調剤・投薬の管理が必要になる |
| **給食に関する仕組み**【Varies】 | 【Fact】医療法第21条第1項第8号により病院は給食施設を有する |
| **勤務表（3交代・2交代）を組む仕組み**【Varies】 | 【Typical】入院病棟は24時間動くため |

## この章のまとめ

1. この章は**「今の仕事を理解するための道具」**の説明であり、導入・選定・評価は一切扱わない。
2. 中核にあるのは2つ —— **電子カルテ**（診療録を記録・保存・検索する）と
   **レセプトコンピュータ（レセコン）**（点数を計算し、会計額とレセプトを作る）。
3. **レセコンの入力1つが、その日の会計額と約2か月後の入金額の両方**を決める。
4. **オンライン資格確認**は、【Fact】療担規則第3条第1項第1号の電子資格確認に対応する仕組み。
   同条第4項が体制の整備を求めている。ただし条文は**複数の確認方法を列挙している**。
5. **オンライン請求**は、【Fact】請求命令第1条第1項の「電子情報処理組織の使用による請求」に対応する仕組み。
   提出期限は**翌月10日**（同令第2条第1項）、到達時期は**ファイルへの記録がされた時**（同条第2項）。
6. 予約・検査連携・画像（PACS）は**【Varies】**。導入の有無は医療機関により異なる。
7. **紙のカルテを使っている診療所もある。** 記載義務も5年保存も、媒体にかかわらず同じ。
8. 仕組みどうしが**つながっていない部分は、人が情報を移し替える仕事**になる。

次章 `12_business-model.md` では、この仕組みで記録され請求された診療が、
**どういう構造の収益**になっているのかを整理します。
