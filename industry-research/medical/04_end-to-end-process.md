# 04_end-to-end-process.md — 全社End-to-End業務フロー（患者が来てから入金まで）

**対象**：日本国内の中小規模の医療機関（主モデル：無床の内科診療所）
**読み手**：医療をまったく知らない人
**最終更新**：2026-09-17

> 本章は `03_company-structure.md` のモデルA（【Example】「さくら内科クリニック」／架空）を前提に書いています。
> モデルは説明用の架空設定であり、実在の医療機関の統計値ではありません。

---

## 4-0. 他業界とどこが違うのか（最初に読む）

多くの業界の業務フローは、次のように整理されます。

```
  引き合い → 見積 → 受注 → 手配・生産・施工 → 納品 → 検収 → 請求 → 入金
```

**医療には、この流れのうち「見積」「受注」「検収」に当たる工程がありません。**
代わりに、次の流れになります。

```
  受付（資格確認） → 診療 → 一部負担金の収受 → レセプト請求 → 審査 → 入金
```

### 何が消え、何が加わったのか

| 他業界の工程 | 医療では | なぜそうなるのか |
|---|---|---|
| **見積** | **存在しない** | 【Fact】保険診療の費用は「厚生労働大臣が定めるところにより、算定する」（健康保険法第76条第2項）。値段の交渉が原理的にない |
| **受注（契約）** | **存在しない** | 【Fact】医師法第19条第1項により、診察治療の求めがあれば正当な事由がなければ拒めない。「受けるかどうかを決める」工程がない |
| **検収** | **存在しない** | 【Inference】患者が「この治療は合格」と判定して初めて代金が発生する、という構造ではない |
| — | **資格確認**が加わる | 【Fact】療担規則第3条第1項により、療養の給付を受ける資格の確認が義務 |
| — | **診療録（カルテ）記載**が加わる | 【Fact】医師法第24条第1項により義務。同時に請求の根拠になる |
| **請求** | **レセプト請求**になる | 【Fact】各月分について翌月10日まで（請求命令第2条第1項） |
| — | **審査**が加わる | 【Fact】健康保険法第76条第4項「審査の上、支払うものとする」 |
| **入金** | **1回の診療で2回に分かれる** | 当日（一部負担金）と約2か月後（審査支払機関から） |

### 2つのサイクルが並行して回っている

医療機関の業務は、**時間の単位が違う2つのサイクル**が同時に回っています。

```
【A. 患者ごとのサイクル】     1人の患者が来てから帰るまで（数十分〜数時間）
   受付 → 問診 → 診察 → 検査 → 処置・処方 → 会計 → 処方箋交付
        └────── この間に発生した内容が、すべて記録として積み上がる ──────┘
                                    │
                                    ▼
【B. 月次のサイクル】         1か月分をまとめて請求し、入金を受けるまで（約2か月）
   日々の算定入力 → 月末締め → レセプト点検 → 翌月10日までに提出
        → 審査 → 約2か月後に入金 →（返戻・査定があれば）再請求・再審査請求
```

> **初心者が最も誤解しやすい点**
> 「診療が終われば仕事は終わり」ではありません。
> **診療が終わった時点で、収入の7〜9割はまだ1円も入っていません。**
> その分を回収するのがサイクルBです。医療機関にとって、AとBは同じくらい重要な業務です。

## 4-A. 1患者の受診サイクル

各ステップを **「誰が／何を受け取り／何をして／何を作り／次に誰へ渡すか」＋頻度** の形で記述します。
頻度は共通語彙（常時／日次／週次／月次／四半期／半期／年次／案件発生時／問い合わせ時／受注時／発注時／納品時／請求時／入金時／トラブル発生時／法定・契約上のタイミング／その他）を使います。

---

### A-1. 予約・来院

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（受付機能） |
| **何を受け取るか** | 患者からの電話・オンラインの予約、または予約なしの来院 |
| **何をするか** | 予約枠を確認し、日時を押さえる。初診か再診かを確認する |
| **何を判断するか** | 【Typical】症状の急ぎ具合によっては、予約を待たずに来てもらうか、他院・救急への受診を案内するかを、看護師・医師に確認する |
| **何を作るか** | 予約情報 |
| **次に誰へ渡すか** | 受付（当日の受付担当） |
| **頻度** | 常時 |

> 【Varies】予約制を採るかどうか、どの程度厳密に運用するかは医療機関により大きく異なります。

---

### A-2. 受付・資格確認（最重要工程）

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（受付機能） |
| **何を受け取るか** | 患者、資格確認の情報（電子資格確認または資格確認書）、公費の受給者証、診察券 |
| **何を確認するか** | 【Fact】療担規則第3条第1項「保険医療機関は、患者から療養の給付を受けることを求められた場合には、次に掲げるいずれかの方法によつて**療養の給付を受ける資格があることを確認しなければならない**。……一 ……電子資格確認……　二 患者の提出し、又は提示する資格確認書　三 （過去に取得した資格情報を用いて保険者に照会し回答を受けて取得した直近の情報を確認する方法。一定の場合に限る）　四 その他厚生労働大臣が定める方法」（ただし緊急やむを得ない事由により確認できない患者であって資格が明らかなものを除く）（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索） |
| **何をするか** | 資格を確認し、負担割合を確定する。初診なら診療申込書・問診票を渡し、カルテを新規に作る。再診ならカルテを準備する |
| **何を作るか** | 受診の記録、（初診なら）新規カルテ、問診票 |
| **次に誰へ渡すか** | 看護師（問診）、医師（診察） |
| **頻度** | 常時 |

> **なぜこの工程が最重要なのか**
> 【Inference】ここで確認した情報が、**その日の会計額**と**約2か月後の請求先**の両方を決めます。
> 資格が失効していた保険に請求すると、レセプトは返戻され、入金は1か月以上遅れます。
> 場合によっては医療機関が患者から後日回収しなければなりません。
> 「受付＝お客様を迎える仕事」ではなく **「請求先を確定させる仕事」** だと理解してください。

【Fact】療担規則第3条第4項は、保険医療機関（同条第3項の適用を受けるものを除く）は、患者が電子資格確認によって資格の確認を受けることができるよう、
あらかじめ必要な体制を整備しなければならないと定めています（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索）。

---

### A-3. 問診

| 項目 | 内容 |
|---|---|
| **誰が** | 看護師・准看護師（看護機能） |
| **何を受け取るか** | 問診票、カルテ、患者本人 |
| **何を確認するか** | 【Typical】いつから、どんな症状か。今飲んでいる薬。アレルギーの有無。既往歴 |
| **何をするか** | 体温・血圧・脈拍などを測る（バイタル測定）。聞き取った内容をカルテに記載する |
| **何を作るか** | 問診記録、バイタルの記録 |
| **次に誰へ渡すか** | 医師 |
| **頻度** | 常時 |

> **なぜ医師の前に看護師が話を聞くのか**
> 【Inference】(a) 医師が診察に使える時間を確保するため、(b) 緊急性の高い患者を先に回すため、
> (c) 薬の重複やアレルギーなど、安全に関わる情報を先に拾うため、と整理できます。
> 【Fact】療担規則第20条第1号ロは「診察を行う場合は、患者の**服薬状況及び薬剤服用歴を確認しなければならない**。
> ただし、緊急やむを得ない場合については、この限りではない」と定めています（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索）。

---

### A-4. 診察

| 項目 | 内容 |
|---|---|
| **誰が** | 医師（診療機能） |
| **何を受け取るか** | カルテ、問診記録、バイタル、患者本人 |
| **何をするか** | 話を聞き、体を診る。必要な検査を指示する |
| **何を判断するか** | 【Typical】検査が必要か。今日の診療で完結するか。他の医療機関に紹介するか。入院が必要か |
| **何を作るか** | 診療録（カルテ）の記載、検査の指示（オーダー） |
| **次に誰へ渡すか** | 看護師・検査担当（検査の実施）、医療事務（会計） |
| **頻度** | 常時 |

【Fact】医師法第20条「医師は、**自ら診察しないで治療をし、若しくは診断書若しくは処方せんを交付し**、
自ら出産に立ち会わないで出生証明書若しくは死産証書を交付し、又は自ら検案をしないで検案書を交付**してはならない**。
但し、診療中の患者が受診後二十四時間以内に死亡した場合に交付する死亡診断書については、この限りでない」（出典：医師法／e-Gov法令検索）。

【Fact】療担規則第20条第1号ホ・ヘは、各種の検査について「診療上必要があると認められる場合に行う」、
「各種の検査は、**研究の目的をもつて行つてはならない**。ただし、治験に係る検査については、この限りでない」と定めています
（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索）。

> 本資料は、ここで医師が何をどう判断するか（医学的な中身）には踏み込みません。
> 業務としては「**診察の結果がカルテに書かれ、それが請求の根拠になる**」という点が重要です。

---

### A-5. 検査

| 項目 | 内容 |
|---|---|
| **誰が** | 看護師（採血・心電図など）、臨床検査技師【Varies】、検査センター（委託分） |
| **何を受け取るか** | 医師の検査指示 |
| **何をするか** | 採血・採尿・心電図・超音波などを実施する。院外に出す検体は、検体容器にラベルを貼り、集配便に渡す |
| **何を確認するか** | 【Typical】患者の取り違えがないか。検体のラベルと患者が一致しているか |
| **何を作るか** | 検査結果（院内検査は当日、外部委託は翌日〜数日後） |
| **次に誰へ渡すか** | 医師 |
| **頻度** | 常時（検体の集配は日次） |

【Fact】医療法施行規則第20条第6号は、病院の臨床検査施設について「検体検査の業務を委託する場合にあつては、
当該検査に係る設備を設けないことができる」と定めています（出典：医療法施行規則／e-Gov法令検索）。

> **なぜ結果が後日になる検査があるのか**
> 【Inference】外部の検査センターに出す検査は、集配 → 分析 → 結果返送の時間がかかるためです。
> 【Typical】このため「今日は採血だけして、結果は次回の受診で説明する」という流れが生まれます。
> これが**再診（次回の受診）を前提とした診療の流れ**を作っています。

---

### A-6. 診断・説明

| 項目 | 内容 |
|---|---|
| **誰が** | 医師（診療機能） |
| **何を受け取るか** | 検査結果、問診記録、診察所見 |
| **何をするか** | 診断し、治療方針を決め、患者に説明する |
| **何を作るか** | カルテの記載、（必要に応じて）説明文書、同意書 |
| **次に誰へ渡すか** | 看護師（処置）、医療事務（会計） |
| **頻度** | 常時 |

【Fact】医師法第23条「医師は、診療をしたときは、本人又はその保護者に対し、**療養の方法その他保健の向上に必要な事項の指導をしなければならない**」
（出典：医師法／e-Gov法令検索）。

### A-7. 処置・処方

| 項目 | 内容 |
|---|---|
| **誰が** | 医師（指示・実施）、看護師（準備・介助・実施） |
| **何を受け取るか** | 医師の指示 |
| **何をするか** | 注射・点滴・創傷処置などを実施する。薬が必要なら処方する |
| **何を作るか** | 処置の記録、処方箋（院外処方の場合） |
| **次に誰へ渡すか** | 医療事務（会計）、患者（処方箋） |
| **頻度** | 常時 |

【Fact】医師法第22条本文「医師は、患者に対し治療上薬剤を調剤して投与する必要があると認めた場合には、
**患者又は現にその看護に当たつている者に対して処方箋を交付しなければならない**。
ただし、患者又は現にその看護に当たつている者が処方箋の交付を必要としない旨を申し出た場合及び次の各号のいずれかに該当する場合においては、この限りでない。」
（同条は第1号〜第8号に例外を掲げています。）（出典：医師法／e-Gov法令検索）

【Fact】保健師助産師看護師法第37条「保健師、助産師、看護師又は准看護師は、**主治の医師又は歯科医師の指示があつた場合を除くほか**、
診療機械を使用し、医薬品を授与し、医薬品について指示をしその他医師又は歯科医師が行うのでなければ衛生上危害を生ずるおそれのある行為をしてはならない。
ただし、臨時応急の手当をし、又は助産師がへその緒を切り、浣腸を施しその他助産師の業務に当然に付随する行為をする場合は、この限りでない」
（出典：保健師助産師看護師法／e-Gov法令検索）。

> **実務上の意味**
> 【Inference】看護師が注射を打つのは「医師の指示があるから」です。指示がないまま行うことは法律上できません。
> このため医療機関の業務は、**「指示 → 実施 → 記録」というセット**で動きます。
> 指示が口頭だけだと後で確認できないため、カルテに指示を残すことが実務上重要になります。

### A-8. 診療録（カルテ）の記載

| 項目 | 内容 |
|---|---|
| **誰が** | 医師（記載）、看護師（看護記録） |
| **何をするか** | その日の診療内容をカルテに書く |
| **何を作るか** | 診療録 |
| **次に誰へ渡すか** | 医療事務（会計・算定） |
| **頻度** | 常時（法定・契約上のタイミング：診療をしたとき遅滞なく） |

【Fact】医師法第24条第1項「医師は、診療をしたときは、**遅滞なく**診療に関する事項を診療録に記載しなければならない」
【Fact】同条第2項「前項の診療録であつて、病院又は診療所に勤務する医師のした診療に関するものは、**その病院又は診療所の管理者において**、
その他の診療に関するものは、その医師において、**五年間**これを保存しなければならない」
（出典：医師法／e-Gov法令検索）

【Fact】療担規則第8条「保険医療機関は、第二十二条の規定による診療録に**療養の給付の担当に関し必要な事項を記載**し、
これを**他の診療録と区別して整備**しなければならない」（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索）。

【Fact】療担規則第9条「保険医療機関は、療養の給付の担当に関する帳簿及び書類その他の記録を**その完結の日から三年間**保存しなければならない。
ただし、**患者の診療録**にあつては、**その完結の日から五年間**とする」（出典：同上）。

> **保存年限を整理する（数字が複数出てくるので混乱しやすい）**
>
> | 対象 | 保存期間 | 根拠 |
> |---|---|---|
> | 診療録（カルテ） | 5年 | 【Fact】医師法第24条第2項／療担規則第9条ただし書 |
> | 療養の給付の担当に関する帳簿・書類その他の記録 | 3年 | 【Fact】療担規則第9条本文 |
> | 病院の「診療に関する諸記録」 | 過去2年間分 | 【Fact】医療法施行規則第20条第10号 |
> | 調剤済みとなった処方箋（薬局） | 3年 | 【Fact】薬剤師法第27条 |
> | 調剤録（薬局） | 最終の記入の日から3年 | 【Fact】薬剤師法第28条第3項 |
>
> 【Fact】医療法施行規則第20条第10号は、病院の「診療に関する諸記録」を
> 「過去二年間の病院日誌、各科診療日誌、処方せん、手術記録、看護記録、検査所見記録、エックス線写真、
> 入院患者及び外来患者の数を明らかにする帳簿並びに入院診療計画書」としています（出典：医療法施行規則／e-Gov法令検索）。
>
> 【Inference】「2年」「3年」「5年」は**対象が違う別々のルール**です。カルテだけを見れば5年と覚えて差し支えありませんが、
> 「医療の書類はぜんぶ5年」ではありません。

### A-9. 会計（一部負担金の収受）

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（医療事務・受付機能） |
| **何を受け取るか** | その日の診療内容（カルテの記載、処置・検査の伝票） |
| **何をするか** | 診療内容を点数に置き換える（算定する）。合計点数から患者の負担割合分を計算して請求する |
| **何を確認するか** | 【Typical】算定漏れがないか。算定してはいけない組み合わせになっていないか。負担割合が正しいか |
| **何を作るか** | 領収証、診療明細書、次回予約 |
| **次に誰へ渡すか** | 患者（領収証・明細書・処方箋）、レセプト請求機能（算定データ） |
| **頻度** | 常時 |

【Fact】療担規則第5条第1項は、保険医療機関が、被保険者について健康保険法第74条の規定による一部負担金等の支払を受けるものとしています
（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索）。

> **ここで「その日の収入」と「2か月後の収入」が分かれます。**
> 医療事務が入力した算定データは、その日の会計に使われると同時に、**そのまま月末のレセプトの材料になります**。
> だから、この時点の入力ミスは、2か月後の入金額に直結します。

### A-10. 処方箋の交付

| 項目 | 内容 |
|---|---|
| **誰が** | 医師（交付）、医療事務（手渡し） |
| **何を受け取るか** | 医師が発行した処方箋 |
| **何をするか** | 患者に処方箋を渡し、院外の薬局で薬を受け取ってもらう |
| **何を作るか** | 処方箋 |
| **次に誰へ渡すか** | 患者 → 調剤薬局 |
| **頻度** | 常時 |

【Fact】療担規則第20条第3号イ「**処方箋の使用期間は、交付の日を含めて四日以内**とする。
ただし、長期の旅行等特殊の事情があると認められる場合は、この限りでない」
【Fact】同号ロは、**リフィル処方箋**（保険医が診療に基づき、別に厚生労働大臣が定める医薬品以外の医薬品を処方する場合に限り、
**複数回（三回までに限る。）の使用を認めた処方箋**）について、2回目以降の使用期間を定めています。
（出典：保険医療機関及び保険医療養担当規則／e-Gov法令検索）

【Fact】薬剤師法第23条第1項「薬剤師は、医師、歯科医師又は獣医師の処方せんによらなければ、販売又は授与の目的で調剤してはならない」
【Fact】同条第2項「薬剤師は、処方せんに記載された医薬品につき、**その処方せんを交付した医師、歯科医師又は獣医師の同意を得た場合を除くほか、これを変更して調剤してはならない**」
【Fact】薬剤師法第24条「薬剤師は、処方せん中に疑わしい点があるときは、**その処方せんを交付した医師、歯科医師又は獣医師に問い合わせて、その疑わしい点を確かめた後でなければ、これによつて調剤してはならない**」
（出典：薬剤師法／e-Gov法令検索）

> **用語：疑義照会（ぎぎしょうかい）**
> → 薬局の薬剤師が、処方箋の内容に疑問があるときに、処方した医師に電話などで確認すること。
> → 実務例：「この薬とこの薬は一緒に飲めないのでは」「用量が通常より多いのでは」といった照会が、診療中の医師宛てに入ります。
> → **医療機関側の業務として何が起きるか**：【Typical】診療中に電話が入り、医師が応対して回答し、必要ならカルテと処方を直します。
>    診療所の日常業務のなかで、一定量発生する割り込み業務です（頻度：常時）。

## 4-B. レセプト請求サイクル（月次）

ここからが、医療機関の収入の7〜9割を左右する工程です。

---

### B-1. 診療内容の入力（日次）

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（レセプト請求機能） |
| **何を受け取るか** | 当日のカルテ、処置・検査の伝票、処方の内容 |
| **何をするか** | レセプトコンピュータ（医事会計システム）に、診療行為ごとの算定を入力する |
| **何を確認するか** | 【Typical】病名と診療行為の対応がついているか。算定の要件を満たしているか |
| **何を作るか** | 算定データ（月次でレセプトになる元データ） |
| **次に誰へ渡すか** | 自分（月末の締め処理へ） |
| **頻度** | 日次 |

> **用語：レセプトコンピュータ（レセコン）**
> → 診療内容を入力すると、点数表に従って点数を計算し、会計額とレセプトを作るシステムのこと。
> → 実務例：受付で「再診」「血液検査」「処方箋料」と入力すると、合計点数と患者負担額が出てきます。
> → **何のための道具か**：診療報酬の点数表は膨大で、算定のルールも細かいため、手計算では現実的でないからです。
>    なお本資料は、システムの導入や選定については扱いません。

---

### B-2. 月末締め（月次）

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（レセプト請求機能） |
| **何をするか** | その月の診療分をすべて確定させる。未入力・未確定のものを洗い出す |
| **何を作るか** | 月次の算定データ一式 |
| **次に誰へ渡すか** | 自分（点検へ） |
| **頻度** | 月次（法定・契約上のタイミング：翌月10日の提出期限から逆算） |

---

### B-3. レセプト点検（月次）

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（主担当）＋医師 |
| **何を受け取るか** | 月次の算定データ、レセコンが出力した点検結果 |
| **何を確認するか** | 【Typical】(1) 病名の抜け（算定した検査・処置に対応する病名があるか）、(2) 資格の誤り（保険者番号・記号番号・負担割合）、(3) 算定の要件（回数制限、併算定できない組み合わせ）、(4) 摘要欄への記載の要否 |
| **何をするか** | 疑わしいレセプトを抜き出し、医師に確認する。医師がカルテを見て判断し、必要なら病名を追加・修正する |
| **何を判断するか** | 【Typical】このまま出すか、取り下げるか、記載を追加して出すか |
| **何を作るか** | 提出用のレセプトデータ |
| **次に誰へ渡すか** | 審査支払機関 |
| **頻度** | 月次 |

> **なぜ点検が必要なのか**
> 【Inference】提出後に不備が見つかると、返戻（差し戻し）や査定（減額）になります。
> 返戻になれば入金が1か月以上遅れ、査定になれば収入そのものが減ります。
> **点検は「後で減らされる分を、事前に減らす」ための工程**です。
> 【Typical】このため月初の数日は、医療事務にとって最も負荷が高い期間になります。

---

### B-4. 審査支払機関への提出（月次・法定期限あり）

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（レセプト請求機能） |
| **何を受け取るか** | 点検済みのレセプトデータ |
| **何をするか** | オンライン請求システムで送信する |
| **何を作るか** | 請求データ、請求の控え |
| **次に誰へ渡すか** | 審査支払機関（支払基金／国保連） |
| **頻度** | **法定・契約上のタイミング（各月分について翌月10日まで）** |

【Fact】療養の給付及び公費負担医療に関する費用の請求に関する命令第2条第1項
「第一条第一項の請求は、**各月分について翌月十日までに行わなければならない**」
【Fact】同条第2項「第一条第一項の請求は、**審査支払機関の使用に係る電子計算機に備えられたファイルへの記録がされた時に
当該審査支払機関に到達したものとみなす**」
（出典：療養の給付及び公費負担医療に関する費用の請求に関する命令／e-Gov法令検索）

【Fact】同令第1条第1項は、費用を請求しようとするときは「**電子情報処理組織の使用による請求**」により行うものとする、と定めています
（同令附則には、書面による請求を行っている保険医療機関等に関する規定が置かれています）（出典：同上）。

【Fact】請求先は、患者が加入している保険により分かれます。
支払基金・国保連は、それぞれ保険者から審査・支払の事務の委託を受けています
（健康保険法第76条第5項、国民健康保険法第45条第5項、高齢者の医療の確保に関する法律第70条第4項／出典：e-Gov法令検索）。

---

### B-5. 審査（月次／医療機関の外で行われる）

| 項目 | 内容 |
|---|---|
| **誰が** | 審査支払機関 |
| **何をするか** | 提出されたレセプトの内容を審査する |
| **医療機関側の作業** | なし（待つ） |
| **頻度** | 月次 |

【Fact】健康保険法第76条第4項「保険者は、保険医療機関又は保険薬局から療養の給付に関する費用の請求があったときは、
第七十条第一項及び第七十二条第一項の厚生労働省令並びに前二項の定めに照らして**審査の上、支払うもの**とする」（出典：健康保険法／e-Gov法令検索）。

### B-6. 入金（診療月の約2か月後）

| 項目 | 内容 |
|---|---|
| **誰が** | 経理・財務機能（モデルAでは院長＋顧問税理士） |
| **何を受け取るか** | 審査支払機関からの支払額の通知、入金 |
| **何をするか** | 請求額と入金額を突き合わせる。差額があれば内訳を確認する |
| **何を確認するか** | 【Typical】返戻になったレセプトはどれか。査定（減点）されたのはどの項目か |
| **何を作るか** | 入金の記録、返戻・査定の一覧 |
| **次に誰へ渡すか** | 医療事務（再請求・再審査請求の検討へ） |
| **頻度** | 月次（入金時） |

> **【Inference】時間軸の整理**
> ```
>  4月  1日〜30日  4月分の診療を行う（患者からは一部負担金をその都度収受）
>  4月 30日        4月分を締める
>  5月  1日〜10日  レセプトを点検し、翌月10日までに提出【Fact：請求命令第2条第1項】
>  5月 中          審査支払機関が審査
>  6月 下旬ごろ    4月分の診療報酬が入金される【Typical】
> ```
> 【Varies】入金日は審査支払機関や地域により異なります。

### B-7. 返戻・査定への対応（月次／トラブル発生時）

| 項目 | 内容 |
|---|---|
| **誰が** | 医療事務（主担当）＋医師 |
| **何を受け取るか** | 返戻されたレセプト、増減点（査定）の連絡 |
| **何を確認するか** | 【Typical】なぜ返戻・査定になったか。医療機関側の記載の問題か、資格の問題か、算定の解釈の問題か |
| **何をするか** | **返戻**：内容を直して、次の月の請求に乗せ直す（再請求）／**査定**：内容に納得できない場合は再審査請求を行う |
| **何を判断するか** | 【Typical】再審査請求をするか、受け入れるか |
| **何を作るか** | 再請求データ、再審査請求の書類 |
| **次に誰へ渡すか** | 審査支払機関 |
| **頻度** | 月次 |

> **返戻と査定の違い（初心者が必ず混同します）**
>
> | | **返戻（へんれい）** | **査定（さてい）／査定減** |
> |---|---|---|
> | 何が起きるか | レセプトそのものが戻ってくる | レセプトは通るが、一部の点数が減らされる |
> | 原因の例 | 【Typical】保険者番号の誤り、資格喪失後の受診、必要な記載の欠落 | 【Typical】病名と診療行為の対応がつかない、算定回数の超過 |
> | お金は | 【Typical】いったん入らない。直して再請求すれば入る可能性がある | 【Typical】その分は入らない。再審査請求が通れば後から入る |
> | 遅れ | 【Inference】さらに1か月以上 | — |
>
> 【Inference】どちらも「医療行為そのものが否定された」という意味ではなく、**請求という手続の問題**です。
> しかし収入には直接効くため、医療事務の腕が問われる部分になります。

## 4-C. 医療に固有の、業務フローに常時ぶら下がる仕事

サイクルAでもBでもないが、常に走っている仕事があります。

### C-1. 施設基準の届出と維持

| 項目 | 内容 |
|---|---|
| **誰が** | 院長＋医療事務（施設基準・届出管理機能） |
| **何をするか** | 算定したい点数について、人員・設備・実績の条件を確認し、地方厚生局に届け出る。届出後も条件を満たし続けているかを確認する |
| **頻度** | 法定・契約上のタイミング（診療報酬改定時、人員の変動時、新たな点数を算定しようとするとき） |

> 【Inference】届け出ていない加算は算定できません。逆に、条件を満たさなくなったまま算定を続けると、後の指導で返還を求められることがあります。
> 【Typical】このため、職員の退職・入職があったとき、施設基準に影響がないかを確認する作業が発生します。

### C-2. 医療安全・インシデント報告

| 項目 | 内容 |
|---|---|
| **誰が** | 全職員（報告）、院長・看護師（医療安全機能） |
| **何をするか** | ヒヤリとした出来事を記録し、共有し、記録として整備する |
| **頻度** | トラブル発生時＋定期的な研修 |

【Fact】医療法施行規則第1条の11第1項は、安全管理体制として
「一 医療に係る安全管理のための**指針を整備**すること」
「三 ……医療に係る安全管理のための基本的な事項及び具体的な方策についての**職員研修を実施**すること」
「四 医療機関内における**事故報告等**の医療に係る安全の確保を目的とした改善のための方策を講ずること」
「六 当該病院等における医療に係る安全管理に関する**記録を整備**すること」を掲げています
（第2号の医療安全管理委員会の設置および第5号の医療安全管理者の配置は、病院、患者を入院させるための施設を有する診療所及び入所施設を有する助産所に限る）
（出典：医療法施行規則／e-Gov法令検索）。

### C-3. 医療事故が発生した場合の報告

| 項目 | 内容 |
|---|---|
| **誰が** | 管理者（院長） |
| **何をするか** | 【Fact】医療法第6条の10第1項に定める医療事故が発生した場合、遅滞なく医療事故調査・支援センターに報告する。報告に当たり、あらかじめ遺族に厚生労働省令で定める事項を説明する（同条第2項。遺族がないとき、又は所在が不明であるときを除く） |
| **頻度** | トラブル発生時（法定・契約上のタイミング） |

### C-4. 院内感染対策

| 項目 | 内容 |
|---|---|
| **誰が** | 院長・看護師（院内感染対策機能） |
| **何をするか** | 【Fact】医療法施行規則第1条の11第2項第1号に基づき、イ 院内感染対策のための指針の策定、ハ 従業者に対する研修の実施、ニ 感染症の発生状況の報告その他の改善のための方策の実施（ロの委員会の開催は病院・有床診療所等に限る） |
| **頻度** | 常時（手指衛生・器具の洗浄滅菌）＋定期的な研修 |

> 【Typical】日常業務としては、手指消毒、手袋・マスクの使用、器具の洗浄と滅菌、環境の清拭、
> 感染の疑いがある患者の動線を分けること（発熱患者を別室・別時間帯にするなど）が該当します。

### C-5. 医療廃棄物の管理

| 項目 | 内容 |
|---|---|
| **誰が** | 看護師（分別・保管）、院長または指名された者（特別管理産業廃棄物管理責任者） |
| **何をするか** | 感染性廃棄物を専用容器に分別し、保管し、許可を持つ業者に委託して処分する |
| **頻度** | 常時（分別）／【Varies】回収は施設と契約により異なる |

【Fact】廃棄物処理法第2条第5項は「特別管理産業廃棄物」を「産業廃棄物のうち、爆発性、毒性、**感染性**その他の
人の健康又は生活環境に係る被害を生ずるおそれがある性状を有するものとして政令で定めるもの」と定義し、
同法施行令第2条の4第4号が「**感染性産業廃棄物**」を掲げています。
【Fact】同法第12条の2第5項は、運搬・処分を他人に委託する場合には、運搬は特別管理産業廃棄物収集運搬業者等に、
処分は特別管理産業廃棄物処分業者等に委託しなければならないと定めています。
【Fact】同法第12条の2第2項は「事業者は、その特別管理産業廃棄物が運搬されるまでの間、環境省令で定める技術上の基準
（特別管理産業廃棄物保管基準）に従い、生活環境の保全上支障のないようにこれを保管しなければならない」と定めています。
【Fact】同法第12条の2第8項は、事業場ごとに**特別管理産業廃棄物管理責任者**を置かなければならないと定めています
（自ら管理責任者となる事業場を除く）。
（出典：廃棄物処理法、同法施行令／e-Gov法令検索）

### C-6. 行政の立入検査・指導への対応

| 項目 | 内容 |
|---|---|
| **誰が** | 院長＋医療事務 |
| **何をするか** | 【Typical】保健所の立入検査（医療法に基づくもの）と、地方厚生局の指導（保険診療に関するもの）に対応する。カルテ、帳簿、届出書類、職員の資格証などを準備する |
| **頻度** | 法定・契約上のタイミング |

【Fact】医療法施行令第4条の4は、「法第二十五条第一項の規定により、病院、診療所若しくは助産所の開設者若しくは管理者……に対し、
必要な報告を命じ、又は当該職員に、病院、診療所、助産所……に立ち入り、その有する人員若しくは清潔保持の状況、
構造設備若しくは**診療録、助産録、帳簿書類その他の物件を検査**させた保健所を設置する市の市長又は特別区の区長」について規定しています
（出典：医療法施行令／e-Gov法令検索）。

> **2種類の「検査・指導」を分けて理解する**
> 【Inference】(a) 医療法に基づく立入検査は「医療機関として適正に運営されているか」を見るもので、窓口は保健所・都道府県です。
> (b) 保険診療に関する指導は「保険の請求が適正か」を見るもので、窓口は地方厚生局です。
> 目的も根拠法も別です。

### C-7. 診療報酬改定への対応

| 項目 | 内容 |

| **誰が** | 院長＋医療事務 |

## 4-D. 【Example】1人の患者を、受診から入金まで追跡する

> **【Example】以下は説明用の架空の事例です。実在の患者・医療機関の事例ではなく、金額・点数も架空です。**
> **実際の点数は診療報酬点数表により定まります。**

### 登場人物

- **患者**：Aさん（52歳・会社員・健康保険組合の被保険者・自己負担3割）
- **医療機関**：モデルA「さくら内科クリニック」（架空・無床の内科診療所）

### 4月13日（月）— 1回目の受診

| 時刻 | 誰が | 何をしたか |
|---|---|---|
| 9:05 | Aさん | 「2週間ほど胃のあたりが重い」と来院 |
| 9:06 | 医療事務 | 【Fact：療担規則第3条第1項】資格を確認。健康保険組合の被保険者、負担割合3割と確定。初診のため問診票を渡す |
| 9:15 | 看護師 | 問診を聞き取り、体温・血圧を測定。服薬状況と薬剤服用歴を確認【Fact：療担規則第20条第1号ロ】。カルテに記載 |
| 9:25 | 医師（院長） | 診察。血液検査と腹部超音波を指示 |
| 9:35 | 看護師 | 採血を実施。検体にラベルを貼り、検査センターの集配便に渡す準備 |
| 9:45 | 医師 | 腹部超音波を実施。所見をカルテに記載 |
| 9:55 | 医師 | 現時点の見立てを説明【Fact：医師法第23条】。薬を処方し、処方箋を交付【Fact：医師法第22条】。血液検査の結果説明のため1週間後の再診を案内 |
| 10:00 | 医療事務 | その日の診療内容を算定して入力。会計。領収証・明細書・処方箋を渡し、次回予約を取る |
| 10:05 | Aさん | 近くの薬局へ。**処方箋の使用期間は交付の日を含めて4日以内**【Fact：療担規則第20条第3号イ】 |

**この日のお金（【Example】架空の金額）**

```
  この日の診療報酬（合計）  12,000円
  Aさんが窓口で払う（3割）    3,600円  ← その場で医療機関に入る
  残り（7割）               8,400円  ← まだ入っていない
```

### 4月20日（月）— 2回目の受診（再診）

医師が血液検査の結果を説明し、薬を継続。医療事務が算定・会計。
【Example】この日の診療報酬は3,000円、Aさんの窓口負担は900円。

### 4月30日（木）— 月末締め

医療事務が4月分の算定データを確定させる。

### 5月7日（木）— レセプト点検

医療事務が4月分のレセプトを1件ずつ点検する。
【Example】Aさんのレセプトでは、腹部超音波を算定しているのに対応する病名が入っていなかったため、医師に確認。
医師がカルテを確認して病名を追加。

### 5月9日（土）— 提出

【Fact：請求命令第2条第1項】翌月10日までにオンライン請求システムで送信。
【Example】Aさんのレセプトには、4月13日分と4月20日分が**まとめて1枚**に記載される（レセプトは患者ごと・月ごと）。

```
  Aさんの4月分レセプト
    診療報酬の合計   15,000円（12,000円 + 3,000円）
    一部負担金        4,500円（すでに窓口で受領済み）
    請求額           10,500円  ← 審査支払機関へ請求する額
```

### 5月中 — 審査

【Fact：健康保険法第76条第4項】審査支払機関が審査する。

### 6月下旬 — 入金

【Example】4月分の請求額が入金される。院長が請求額と入金額を突き合わせる。

**【Example】もし査定されていたら**：腹部超音波の点数が認められず減点されていた場合、その分だけ入金額が請求額より少なくなる。
医療事務が増減点の連絡を確認し、医師と相談して再審査請求をするかを判断する。

**【Example】もし返戻されていたら**：Aさんが4月中に転職していて保険が変わっていた場合、レセプトはそのまま戻ってくる。
正しい保険者に請求し直すため、入金はさらに1か月以上先になる。

### 時間軸のまとめ

```
  4/13 診療   ──▶ 3,600円 入金（患者から）
  4/20 診療   ──▶   900円 入金（患者から）
                            ＝ 4月中に入ったのは合計 4,500円（全体の30%）
  4/30 締め
  5/09 請求   ──▶（待つ）
  6月下旬      ──▶ 10,500円 入金（審査支払機関から）
                            ＝ 診療から約2か月後に、残りの70%が入る
```

> **【Inference】この事例が示していること**
> 4月13日に提供した医療の対価の7割は、6月下旬まで手元に来ません。
> その間にも、職員の給与、テナントの家賃、医薬品の仕入代金、リース料は支払わなければなりません。
> **医療機関の資金繰りは、この「約2か月の時間差」を前提に組み立てられています。**

## 4-E. 中小病院（モデルB）ではどこが変わるか

| 工程 | モデルA（無床診療所） | モデルB（中小病院） |
|---|---|---|
| 受付 | 外来受付のみ | 外来受付＋入院受付（入院手続、入院診療計画書の作成） |
| 診療 | 外来のみ | 外来＋病棟回診＋手術 |
| 看護 | 日中のみ | 24時間交代制 |
| 記録 | 診療録＋看護記録 | 【Fact】医療法施行規則第20条第10号の「診療に関する諸記録」（病院日誌、各科診療日誌、処方せん、手術記録、看護記録、検査所見記録、エックス線写真、入院患者及び外来患者の数を明らかにする帳簿、入院診療計画書）を過去2年間分備える |
| 会計 | 診療のたびに会計 | 外来はそのつど、入院は【Typical】月ごと・退院時にまとめて会計 |
| レセプト | 外来レセプトのみ | 外来レセプト＋入院レセプト（金額が大きく、点検の重みが違う） |
| 給食 | なし | 【Fact】医療法第21条第1項第8号により給食施設を有する |
| 廃棄物 | 【Typical】量が少ない | 【Typical】量が多く、種類も多い |
