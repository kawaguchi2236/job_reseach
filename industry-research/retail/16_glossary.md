# 16_glossary.md — 小売業の用語集＋初心者が間違えやすいこと

**対象**：日本国内の中小小売業
**前提**：`01_overview.md`〜`15_rules-customs.md` を読んでいること
**最終更新**：2026-09-16

---

> **このファイルの使い方**
>
> **前半（16-1〜16-10）**は用語集です。
> 小売業で働く人との会話についていくために必要な語を、
> **業界固有語**と**商取引・会計の基本語**の両方で収録しています（**計155語**）。
>
> 各用語は **「辞書的な意味」で終わらせず、「実務ではどう使うか」まで**書いています。
>
> **後半（16-11）**は「初心者が間違えやすいこと」です。
> 似た言葉・混同しやすい概念を、
> **「何と何が違うか」「なぜ混同するか」「実務でどう効くか」**の3点で整理しています。
> **ここが最も重要な部分**です。用語を1つずつ覚えるより、
> **混同しやすいペアを区別できること**の方が、実務の理解に直結します。

# 前半：用語集

## 16-1 売場・陳列に関する用語

| 用語 | 正式名称・読み方 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **売場** | うりば | 客が入って商品を選ぶ空間 | 店舗は売場とバックヤードに分かれる。`【Fact】` 食品スーパーではバックヤードが延べ面積の約30.5％（2024年、スーパーマーケット年次統計調査報告書） |
| **バックヤード** | 後方（こうほう）、BY | 客が立ち入らない、荷受・保管・加工・事務のための空間 | 「バックヤードに在庫ある？」は「棚に出ていない分がまだあるか」という意味 |
| **定番（ていばん）** | 定番売場 | その商品がいつも置かれている決まった位置 | 「定番から外す」＝取扱いをやめる、または場所を変えること。客が毎回同じ場所で見つけられるようにするための概念 |
| **エンド** | ゴンドラエンド | 棚（ゴンドラ）の端にある、通路に面した売場 | 目に入りやすいので特売品を置く。「今週のエンドは何を置く？」は販促の重要な決定 |
| **ゴンドラ** | — | 商品を並べる棚のこと | 「ゴンドラ2本分」のように、売場の広さを数える単位にもなる |
| **フェイス** | フェイシング | 商品が正面を向いて並んでいる「面」の数 | 醤油を横に3本並べれば3フェイス。増やせば目立つが、他の商品の場所が減る |
| **棚割（たなわり）** | プラノグラム | どの棚のどの位置に、どの商品を何フェイス置くかを決めた設計図 | 担当者が変わっても売場が変わらないようにする。四半期・半期で大きく見直す |
| **平台（ひらだい）・ワゴン** | — | 特売品を積んで売る台 | 大量に積むことで「安い」という印象を作る |
| **POP（ポップ）** | Point of Purchase advertising | 売場に置く手書きや印刷の広告物 | 「この商品を買う理由」を売場で伝える。同じ価格でもPOPの有無で売れ方が変わる |
| **プライスカード** | 棚札（たなふだ） | 棚に付ける値段の表示 | 税込価格を表示する（`15_rules-customs.md` 総額表示義務）。補充する場所の目印にもなる |
| **什器（じゅうき）** | — | 商品を陳列するための棚・台・ケースなどの備品 | 「什器が古い」「什器を入れ替える」のように使う |
| **前出し（まえだし）** | フェイスアップ | 商品を棚の手前にそろえる作業 | 見やすさが売れ方に直結する。同時に欠品と期限切れに気づく機会になる |
| **品出し（しなだし）** | 補充 | バックヤードの在庫を売場に出す作業 | 常時発生する。`A-9 在庫補充` |
| **売場変更・作り替え** | — | 季節や特売に合わせて売場の構成を変えること | 週次で特売を切り替え、四半期・半期で棚割を大きく見直す |
| **ゾーニング** | — | 売場全体のどこに何の部門を配置するかの大枠 | 入口に青果、奥に生鮮、レジ前に菓子、といった配置の考え方 |

## 16-2 商品・在庫に関する用語

| 用語 | 正式名称・読み方 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **SKU（エスケーユー）** | Stock Keeping Unit | 在庫を管理する最小の単位 | 同じ醤油でも500mlと1Lは別SKU。容量・色・サイズが違えば別管理 |
| **アイテム／品目** | — | 取り扱う商品の種類 | SKUとほぼ同じ意味で使われる。`【Example】` X社（架空）は1店舗約1万5,000品目 |
| **生鮮（せいせん）** | 生鮮3品 | 青果・鮮魚・精肉のこと | 「生鮮が強い店」＝この3部門の品質・鮮度で選ばれている店 |
| **日配（にっぱい）** | 日配品 | 毎日または高頻度で配送される日持ちの短い加工食品 | 牛乳、豆腐、納豆、練り物、パン、漬物など。発注を誤ると即座に廃棄ロスになる |
| **惣菜（そうざい）** | デリカ | 店内などで調理した、そのまま食べられる食品 | `【Fact】` 粗利率が最も高い（目標38.5％）が、ロス率も最も高い（10.6％）。2024年、同調査 |
| **グロサリー** | 一般食品、ドライグロサリー | 常温で日持ちする加工食品 | 調味料、缶詰、レトルト、菓子、飲料など。日持ちするため発注の自由度が高い |
| **非食品** | 雑貨、ノンフード | 日用品・洗剤・雑貨など食品以外の商品 | `【Fact】` 食品スーパーでの売上構成比は5.4％（2024年、同調査） |
| **売れ筋（うれすじ）** | — | よく売れる商品 | 切らさないことが最優先。フェイスを増やす対象 |
| **死に筋（しにすじ）** | — | ほとんど売れない商品 | 棚の面積を占めるだけで粗利を生まない。棚割見直しで入れ替えの対象になる |
| **定番商品** | — | 常時取り扱う商品 | 季節商品・スポット商品の対義語 |
| **スポット** | スポット商品 | 一時的に仕入れて売る商品 | 産地の事情や特売のために単発で入れる |
| **先入先出（さきいれさきだし）** | FIFO | 先に入った商品から先に売る（棚の手前に出す）こと | 期限の古いものを前に出す。これを守らないと奥に残った商品が期限切れになる |
| **入数（いりすう）** | — | 1ケース・1ボールに何個入っているか | 発注の単位。誤ると意図の何倍もの量が届く |
| **ケース／ボール** | — | 商品をまとめる荷姿の単位 | 「1ケース＝24本」「1ボール＝6個」のように使う |
| **荷姿（にすがた）** | — | 商品がどういう形で梱包されているか | 検品・保管・陳列のしやすさに関わる |
| **在庫（ざいこ）** | 棚卸資産 | まだ売れていない商品 | 「お金が形を変えたもの」。増えれば現金が減る |
| **バックストック** | — | 売場に出ていない、バックヤードにある在庫 | 「まだバックにある？」という会話で使う |
| **リードタイム** | 発注リードタイム | 発注してから納品されるまでの時間 | 短ければ少量ずつ発注できる。長ければまとめて持つ必要がある |
| **欠品（けっぴん）** | 品切れ | 売場にあるべき商品が無いこと | 売り逃しになるだけでなく、客が他店へ行く理由になる。どの帳票にも記録が残らない |
| **回収（リコール）** | — | 商品に問題が見つかり、市場から引き上げること | 該当商品を売場・在庫から撤去し、販売済み分を告知する |

## 16-3 発注・仕入に関する用語

| 用語 | 正式名称・読み方 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **発注（はっちゅう）** | — | 仕入先に「何を・いくつ・いつまでに」と注文すること | `【Typical】` 小売業で最も重要な工程。粗利は発注した瞬間にほぼ決まる |
| **EOS（イーオーエス）** | Electronic Ordering System | 発注内容をデータで仕入先に送る仕組み | ハンディ端末でバーコードを読み、数量を入れて送信する |
| **発注端末／ハンディ** | ハンディターミナル | 売場を歩きながら発注数量を入力する携帯端末 | 棚を見ながらその場で発注できることが要点 |
| **発注締め時刻** | — | その日の発注を受け付ける最終時刻 | `【Typical】` これが店舗の1日の業務の時間割を決める |
| **発注残（はっちゅうざん）** | — | 発注したがまだ届いていない数量 | これを見落とすと二重に発注してしまう |
| **荷受（にうけ）** | 入荷 | 納品されたものを受け取ること | `A-3 入荷・荷受` |
| **検品（けんぴん）** | — | 発注書・納品書・現物の3つを突き合わせること | 数量・品目・鮮度・温度・破損を確認する。`A-4 検品` |
| **検収（けんしゅう）** | — | 受け取りを認めること | ここで在庫になり、同時に支払義務が発生する。**モノの情報とカネの情報の分岐点** |
| **納品書** | — | 「これだけ納めました」という仕入先側の書類 | 検品で現物と突き合わせる |
| **受領書** | — | 「確かに受け取りました」と店が認めた書類 | 押印した後は数量の訂正が通りにくくなる |
| **仕入先（しいれさき）** | 取引先、ベンダー、納入業者 | 商品を納めてくれる相手 | 卸売業者、メーカー、産地、市場など |
| **卸売業者（おろしうりぎょうしゃ）** | 問屋（とんや） | メーカーと小売業の間で商品を流通させる事業者 | 多数のメーカーの商品をまとめて供給してくれる |
| **買取仕入** | — | 商品を買い取る形の仕入 | 店の在庫になり、売れ残りは店の損失。**食品スーパーの大部分** |
| **委託仕入** | — | 商品を預かって売場に置き、売れた分だけ払う形 | 在庫は仕入先のもの。売れ残りは返す |
| **消化仕入** | 売上仕入 | 売れた時点で仕入と売上が同時に立つ形 | 売れるまで店の在庫にならない。棚卸の対象外 |
| **リベート** | 報奨金、割戻金 | 仕入額や販売実績に応じて仕入先から支払われる（差し引かれる）金銭 | 請求額と振込額が一致しない主な原因 |
| **センターフィー** | 物流センター使用料 | 物流センターを経由する納品で納入業者が負担する費用 | `【Varies】` 自社センターを持つ一定規模以上の小売業の論点 |
| **建値（たてね）** | — | メーカー・卸が定める基準となる価格 | 「建値の○掛け」という形で仕切価格を表す |
| **仕切価格（しきりかかく）** | 仕切値 | 実際に取引される価格 | 取引先・数量・条件で異なり、通常は公開されない |
| **バイイングパワー** | 購買力 | 大量に仕入れることで有利な条件を引き出せる力 | 中小小売業は協同組合・ボランタリーチェーンの共同仕入で補うことがある `【Varies】` |
| **PB（ピービー）** | Private Brand、プライベートブランド | 小売業者が自ら企画し、自社の名前で売る商品 | 他店と比較されにくく、粗利を取る役割を担いやすい |
| **NB（エヌビー）** | National Brand、ナショナルブランド | メーカーが企画し、メーカーの名前で全国的に売られる商品 | 他店と直接価格を比較される |

## 16-4 価格・粗利に関する用語

| 用語 | 正式名称・読み方 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **売価（ばいか）** | 販売価格 | 客に売る価格 | 総額表示義務により税込で表示する |
| **原価（げんか）** | 仕入原価 | 仕入れた価格 | 売価と原価の差が利幅になる |
| **値入（ねいれ）** | 当初値入 | 仕入原価にいくらの利幅を乗せて売価を決めたかという**計画**の数字 | `値入率 ＝ (売価 − 原価) ÷ 売価`。**粗利とは別物** |
| **荒利（あらり）／粗利** | 売上総利益 | 実際に売れた**結果**残った利益 | `粗利 ＝ 売上 − 売上原価`。小売業で最も重視される数字 |
| **粗利率** | 荒利率、売上総利益率 | 売上に対する粗利の割合 | `【Fact】` 食品スーパー平均26.34％（2024年、同調査） |
| **値付け（ねつけ）** | — | 商品に価格を付ける作業 | プライスカードの確認、生鮮・惣菜は電子秤で値札を印字。`A-6 値付け` |
| **売価変更** | マークダウン | 売価そのものを変更すること | 記録しないと、後で粗利のずれの原因を説明できない |
| **見切り（みきり）** | 見切り販売 | 売り切るために値下げすること | 「何時に何％引くか」が日々の判断。`A-10 売価変更・見切り` |
| **値引き（ねびき）** | — | 会計時に金額を引くこと | 売価そのものは変えない。**値下げとは別**（16-11 参照） |
| **均一価格** | — | 「全品○円」のようにそろえた価格 | 特売の手法の1つ |
| **二重価格表示** | — | 「通常価格500円 → 本日298円」のように2つの価格を並べる表示 | `【Fact】` 実際の販売実績がない価格を比較対照にすると景品表示法上の問題になり得る |
| **総額表示** | — | 税込価格を表示すること | `【Fact】` 2021年4月1日から義務（消費税法第63条） |
| **売価マスタ** | — | どの商品がいくらか、というシステム上の登録情報 | ここが間違っているとレジが違う金額を出す |
| **価格改定** | — | メーカー・卸の価格変更に伴い売価を見直すこと | 売価マスタ・プライスカード・POPをすべて変更する必要がある |

## 16-5 ロス・鮮度に関する用語

| 用語 | 正式名称・読み方 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **ロス** | — | 売れるはずだった金額のうち失われた分 | 廃棄・値下げ・不明の3種類に分けて見る |
| **廃棄ロス** | — | 期限切れ・傷み・破損で捨てた商品による損失 | 発注量・製造量の判断が適切だったかを直接示す |
| **値下げロス** | 値下げ高 | 当初の売価より安く売ったぶんの損失 | 廃棄よりはよいが粗利は削られる |
| **不明ロス** | 棚卸ロス、ロス差異 | 帳簿にはあるが現物が無い、原因不明の損失 | `不明ロス ＝ 帳簿在庫 − 実地棚卸高`。**棚卸をするまで分からない** |
| **ロス率** | — | 売上に対するロスの割合 | `【Fact】` 惣菜10.6％〜非食品1.5％と部門で大きく違う（2024年、同調査） |
| **鮮度管理** | — | 商品の鮮度・期限を保ち、期限切れを売場に残さないこと | 日次の鮮度チェックと見切りが実務 |
| **消費期限** | — | 安全に食べられる期限 | 弁当・惣菜・生菓子など傷みやすい食品に表示。この日を過ぎたものは販売しない |
| **賞味期限** | — | 品質が十分に保たれる期限 | 菓子・カップ麺・缶詰など比較的日持ちする食品に表示 |
| **日付管理** | — | 商品の期限を売場・在庫で把握しておくこと | 先入先出と一体で運用する |
| **温度帯（おんどたい）** | — | 常温・冷蔵（チルド）・冷凍という保管温度の区分 | 荷受後、温度帯ごとに仮置きする。誤ると商品が傷む |
| **歩留まり（ぶどまり）** | — | 元の材料のうち、商品として売れる部分の割合 | 丸ごとの魚を切り身にすると、骨・内臓は商品にならない。生鮮の原価計算に効く |

## 16-6 レジ・現金に関する用語

| 用語 | 正式名称・読み方 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **POS（ポス）** | Point of Sale、販売時点情報管理 | 売れた瞬間に「何が・いつ・いくつ・いくらで」を記録する仕組み | 売った記録がそのまま次の発注の判断材料になる |
| **JANコード** | Japan Article Number | 商品を識別するバーコードの番号 | POS・発注・在庫のすべてがこの番号で結びつく |
| **レジ締め** | 精算 | その日のレジの売上と現金を確定させる作業 | 毎日必ず発生する。他業界にない小売業の特徴 |
| **レジ点検** | — | 営業中に途中経過を確認すること | 釣銭の過不足、現金の溜まりすぎを見る |
| **レジ精算票** | 精算レシート | レジ締め時にPOSが印字する集計票 | 決済手段別の売上と、レジ内にあるべき現金の理論額が載る |
| **釣銭準備金** | 釣銭、両替金 | 日次で（開店前に）レジに入れておく釣銭用の現金 | **売上ではなく、店が持ち出している元手**。混同すると売上がずれる |
| **レジ差異** | 現金過不足 | 理論上の現金額と実際の現金額の差 | 金額が小さくても、合わないこと自体が問題として扱われる |
| **売上金** | — | その日にレジで受け取った現金 | 金庫に保管し、翌営業日に銀行へ入金する |
| **決済手段** | — | 現金／クレジット／電子マネー／コード決済などの支払い方法 | 手段別に売上を集計する。入金のタイミングが手段ごとに違う |
| **キャッシュレス** | — | 現金以外の支払い方法の総称 | `【Fact】` 日本の決済比率39.3％（2023年、キャッシュレス・ロードマップ2024） |
| **セミセルフレジ** | 会計分離型 | 読み取りは店員、支払いは客が別の精算機で行う方式 | レジ担当者が現金を直接扱わなくなる |
| **レシート** | — | 客に渡す購入内容の記録 | `【Fact】` 小売業では**適格簡易請求書**として扱える（インボイス制度） |
| **年齢確認** | — | 酒類・たばこの販売時に20歳以上かを確認すること | `【Fact】` 法律で販売が禁止されているため、常時の業務になる |

## 16-7 数字・KPIに関する用語

| 用語 | 正式名称・読み方 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **客数** | 買上客数、レジ通過客数 | 買い物をした人の数（実務上はレジでの会計の件数） | 売上を分解する最初の軸 |
| **客単価** | — | 1回の会計あたりの購入金額 | `売上 ÷ 客数`。`【Fact】` 食品スーパー平日平均2,094.2円（2024年、同調査） |
| **買上点数** | — | 1回の買い物で買った商品の個数 | `【Fact】` 平日平均9.5点（2024年、同調査）。客単価が落ちた原因の切り分けに使う |
| **PI値** | Purchase Index | 来店客1,000人あたり、その商品が何個売れたか | 客数の違う店・日を同じものさしで比べられる |
| **在庫回転率** | 商品回転率 | 一定期間に在庫が何回入れ替わったか | 回転が遅いほど資金が在庫に縛られる |
| **交差比率** | 交差主義比率 | `粗利率 × 在庫回転率` | 粗利率が低くても回転が速ければ稼げることを示す |
| **坪効率** | 売場面積あたり売上高 | 売場1坪（1㎡）あたりの売上 | 家賃は面積に比例するため、広げた分稼げているかを見る。1坪＝約3.3㎡ |
| **人時（にんじ）** | マンアワー | 1人が1時間働くことを1単位とした労働量 | 「10人いた」ではなく「150人時投入した」と数える |
| **人時売上高** | — | 1人時あたりの売上 | `売上 ÷ 総労働時間` |
| **人時生産性** | — | 1人時あたりの粗利 | `粗利 ÷ 総労働時間`。給与は粗利から払われるため、こちらが実態に近い |
| **労働分配率** | — | 粗利のうち人件費に充てた割合 | `【Fact】` 食品スーパー（売上高30億円未満）で平均50.81％（2024年、同調査） |
| **損益分岐点売上高** | — | 利益がちょうどゼロになる売上高 | `固定費 ÷ 粗利率` |
| **部門別売上構成比** | — | 売上全体に占める各部門の割合 | 部門で粗利率が違うため、構成比が変われば全体の粗利率も変わる |
| **前年同期比** | 前年比 | 前年の同じ時期と比べた増減 | 季節性が強い業界なので、前月比より前年同月比で見る |
| **日報（日計表）** | — | その日の売上・客数・ロス・天候などをまとめた記録 | 翌日の発注・人員・売場の判断材料 |
| **棚卸（たなおろし）** | 実地棚卸 | 実際に在庫を数えること | これをしないと売上原価が出ず、粗利も利益も確定しない |

# 後半：初心者が間違えやすいこと

> **なぜこれが重要か**
> `【Inference】` 業界の会話についていけない原因の多くは、**知らない言葉があること**ではなく、
> **似た言葉を同じ意味だと思い込んでいること**です。
> 以下の各項目は、**「何と何が違うか」「なぜ混同するか」「実務でどう効くか」**の順に整理します。

---

## 16-11-1 【全業界共通】基本の混同

### (1) 売上 ≠ 入金

| | |
|---|---|
| **何が違うか** | **売上**は「売れたという事実」、**入金**は「お金が口座や手元に入ること」 |
| **なぜ混同するか** | 小売業では現金払いなら同時に起きるため、区別する必要を感じにくい |
| **実務でどう効くか** | `【Fact】` キャッシュレス決済比率は39.3％（2023年）。**キャッシュレス分は入金が後**（`08_money.md` 8-1）。「今日30万円売れた」と「今日30万円手元に入った」は違う。資金繰りを見るときに必ず効く |

### (2) 受注 ≠ 売上

| | |
|---|---|
| **何が違うか** | **受注**は注文をもらった時点、**売上**は商品を引き渡して代金が確定した時点 |
| **なぜ混同するか** | 小売業の店頭販売では、注文と引き渡しが同時なので区別が現れない |
| **実務でどう効くか** | `【Typical】` **EC・通販、予約商品（おせち・恵方巻）では両者がずれます。** 12月に予約を受けても、売上が立つのは商品を渡した日。予約件数を売上と混同すると、実績を読み違えます |

### (3) 発注 ≠ 仕入計上

| | |
|---|---|
| **何が違うか** | **発注**は「頼んだ」、**仕入計上**は「受け取って、払う義務が確定した」 |
| **なぜ混同するか** | どちらも「仕入れる」という言葉で語られるため |
| **実務でどう効くか** | `04_end-to-end-process.md` のとおり、`A-2 発注` と `B-3 仕入計上` の間には `A-4 検品`・`A-5 検収` があります。**発注しただけでは在庫でも仕入でもありません。** 発注残を在庫と数えると、在庫を二重に数えることになります |

### (4) 在庫 ≠ すべてが同じ状態

| | |
|---|---|
| **何が違うか** | 小売業の在庫には**売場にある在庫**と**バックヤードにある在庫**があり、さらに**買取仕入の在庫**と**委託・消化仕入の（自社のものではない）商品**が混在し得る |
| **なぜ混同するか** | 見た目はどれも「店にある商品」だから |
| **実務でどう効くか** | `【Typical】` 棚卸の対象になるのは自社の在庫です。委託・消化の商品を数え込むと在庫金額が過大になり、**売上原価と粗利が狂います**（`15_rules-customs.md` 15-13） |

### (5) 粗利 ≠ 利益

| | |
|---|---|
| **何が違うか** | **粗利（売上総利益）**は売上から仕入代金を引いた段階の利益。ここから人件費・家賃・光熱費などをすべて払って、残りが**営業利益** |
| **なぜ混同するか** | 現場で最も頻繁に語られるのが粗利なので、「粗利が出ている＝儲かっている」と感じやすい |
| **実務でどう効くか** | `【Fact】` X社のモデルでは粗利約7.8億円に対し、人件費約4.0億円・その他販管費約3.7億円で**営業利益はほぼ±0**（`12_business-model.md` 12-10）。**粗利が出ていても利益が残るとは限りません** |

### (6) 見積 ≠ 契約（小売業では出番が少ない）

| | |
|---|---|
| **何が違うか** | **見積**は価格の提示、**契約**は取引の確定 |
| **なぜ混同するか** | 他業界では中心的な論点だが、小売業の店頭販売には原則登場しない |
| **実務でどう効くか** | `【Varies】` 小売業でこれが効くのは、**法人向けの大口販売、什器・内装の発注、EC の受注**など限られた場面。**「小売業には見積・契約の業務が原則ない」ことを理解しておくことが、他業界との違いの理解につながります** |

---

## 16-11-2 【小売業固有】必ず区別すべき混同ペア

### (7) 値入 ≠ 粗利 ／ 値入率 ≠ 粗利率 ★最重要★

| | |
|---|---|
| **何が違うか** | **値入は「こう儲けるつもりだった」という計画**、**粗利は「実際にこれだけ残った」という結果** |
| **なぜ混同するか** | どちらも「売価 − 原価」という同じ形の計算に見えるため。また現場では両方とも「利幅」と呼ばれることがある |
| **実務でどう効くか** | `粗利率 ≒ 値入率 − ロス率 − 値下げ率`。**この差を説明できることが小売業の数字の仕事の中心**です。「値入で27％取ったのに粗利が23％しかない」という会話の意味が分からないと、業務の議論についていけません（`08_money.md` 8-2、`12_business-model.md` 12-3） |

### (8) 売上 ≠ 利益

| | |
|---|---|
| **何が違うか** | 売上は売れた金額の合計、利益はそこから費用をすべて引いた残り |
| **なぜ混同するか** | 小売業は売上の金額が大きいため、「30億円売っている会社」＝「儲かっている会社」と見えやすい |
| **実務でどう効くか** | `【Fact】` 食品スーパーの売上高営業利益率は、売上高30億円未満で平均▲0.32％（2024年、同調査）。**売上規模と利益はまったく別**。`【Inference】` 売上を伸ばす手段として値下げを使えば、売上は増えて利益は減ります |

### (9) 在庫 ≠ 売れる在庫

| | |
|---|---|
| **何が違うか** | 帳簿上の在庫金額には、**売れ筋も死に筋も、期限間近の商品も、シーズンが終わった商品も同じように計上されます** |
| **なぜ混同するか** | 会計上はどれも同じ「棚卸資産」として金額で並ぶため |
| **実務でどう効くか** | `【Inference】` 在庫1,000万円と言っても、**そのまま定価で売り切れる1,000万円**と、**値下げしないと売れない1,000万円**では意味がまったく違います。`12_business-model.md` 12-4 の**在庫回転率・交差比率**は、この違いを見るための指標です |

### (10) 廃棄ロス ≠ 不明ロス ★重要★

| | |
|---|---|
| **何が違うか** | **廃棄ロス**＝捨てたことが分かっている損失。**不明ロス**＝帳簿にはあるのに現物が無く、**原因が分からない**損失 |
| **なぜ混同するか** | どちらも「商品が無くなって損をした」という結果は同じだから |
| **実務でどう効くか** | **打つ手がまったく違います。** 廃棄ロスが大きい → 発注・製造の数量判断の問題。不明ロスが大きい → 盗難・レジ打ちミス・記録漏れ・納品不足のどれか分からない。`【Typical】` **廃棄記録を残さずに捨てると、分かっていた損失が不明ロスに紛れ込み、手が打てなくなります**（`07_goods.md` 7-6、`14_kpi.md` 14-2） |

### (11) 客数 ≠ 来店人数 `【Varies】`

| | |
|---|---|
| **何が違うか** | 実務でいう**客数は「レジでの会計の件数」**。来店した人数でも、店に入った人数でもありません |
| **なぜ混同するか** | 「客数1,000人」と表現するため、人数だと思ってしまう |
| **実務でどう効くか** | 家族4人で1回会計すれば客数は1。買わずに帰った人は客数に入りません。`【Varies】` 入店客数を数える仕組みを持つ店では**買上率（買った人 ÷ 入店した人）**を見ますが、中小小売業で常に把握できるとは限りません。**「客数が減った」は「来店が減った」と同じではない可能性がある**、と理解しておく必要があります（`14_kpi.md` 14-1(2)） |

### (12) 仕入 ≠ 売上原価 ★重要★

| | |
|---|---|
| **何が違うか** | **仕入**はその期間に買い入れた金額の合計。**売上原価**は**そのうち売れた分だけ**の金額 |
| **なぜ混同するか** | 会計に慣れていないと、「仕入れた金額を売上から引けば儲けが出る」と考えてしまうため |
| **実務でどう効くか** | `売上原価 ＝ 期首在庫 ＋ 仕入 − 期末在庫`。**期末在庫は棚卸をするまで分かりません。** つまり**棚卸をしないと売上原価が出ず、粗利も利益も計算できません**（`08_money.md` 8-4）。`【Inference】` 大量に仕入れた月は「仕入が多いから赤字」に見えますが、在庫として残っていれば売上原価にはなっていません |

### (13) 卸売 ≠ 小売

| | |
|---|---|
| **何が違うか** | **誰に売るか**が違います。小売業は**一般消費者**に、卸売業は**小売業者・事業者**に売ります。扱う商品が同じでも区分は変わります |
| **なぜ混同するか** | 同じ商品が同じ形で流れていくため、外から見ると区別がつきにくい |
| **実務でどう効くか** | `【Fact】` 中小企業基本法上の定義が違います。**小売業は資本金5,000万円以下 または 従業員50人以下**、**卸売業は資本金1億円以下 または 従業員100人以下**（出典：中小企業基本法／e-Gov法令検索）。補助金・制度の対象判定に直結します。また `【Fact】` 企業数も**小売業527,138社／卸売業202,432社**（2021年、中小企業庁「中小企業の企業数・事業者数」）と規模が違います |

### (14) 買取仕入 ≠ 消化仕入 ★重要★

| | |
|---|---|
| **何が違うか** | **買取仕入**は検収した時点で店の在庫になり、売れ残りは店の損失。**消化仕入**は売れた時点で初めて仕入が立ち、売れ残りは店の損失にならない |
| **なぜ混同するか** | **どちらも「店の売場に商品が並んでいる」という見た目が同じ**だから |
| **実務でどう効くか** | (a) **棚卸の対象が違う**（消化仕入の商品は数えない）。(b) **粗利率の水準が違う**（リスクを負う買取の方が利幅は厚い `【Typical】`）。(c) **資金繰りへの影響が違う**（買取は先に支払義務が立つ）。`【Inference】` 同じ売上でも、どの仕入形態かによって在庫・粗利・資金の姿がまったく変わります（`15_rules-customs.md` 15-13） |

### (15) キャッシュレス売上 ≠ 即時入金 ★重要★

| | |
|---|---|
| **何が違うか** | **決済が成立すること**と、**店の口座にお金が入ること**は別の出来事です |
| **なぜ混同するか** | レジの画面では現金もキャッシュレスも同じように「売上」として処理されるため |
| **実務でどう効くか** | (a) **入金までに日数がかかる**（`【Varies】` 決済事業者・契約による）。(b) **手数料が引かれる**ため、**売上金額と入金金額が一致しない**。(c) `【Fact】` キャッシュレス比率39.3％（2023年）、食品スーパーの導入率95.6％（2024年）。**比率が上がるほど「先に入って後から出ていく」という小売業の資金構造の余裕は縮みます**（`08_money.md` 8-1、`12_business-model.md` 12-8） |

### (16) 値引き ≠ 値下げ

| | |
|---|---|
| **何が違うか** | **値下げ（売価変更・マークダウン）**は**売価そのものを変える**こと。値札・プライスカード・売価マスタが変わります。**値引き**は売価は変えずに、**会計のときに金額を引く**こと（レジでの割引、クーポン、会員割引など） |
| **なぜ混同するか** | 客から見れば「安く買えた」という結果は同じだから。日常語でも両方「値引き」と言ってしまう |
| **実務でどう効くか** | (a) **記録される場所が違う**：値下げは売価変更票、値引きはPOSの会計データ。(b) **粗利への現れ方が違う**：値下げは値下げロス、値引きは割引額。(c) `【Inference】` どちらかしか見ていないと、**粗利が落ちた原因を取り違えます** |

### (17) 粗利率 ≠ 値入率（再掲・計算の向きの注意）

| | |
|---|---|
| **何が違うか** | (7) のとおり計画と結果の違いですが、**計算式の分母にも注意**が必要です。`値入率 ＝ (売価 − 原価) ÷ **売価**`。`【Varies】` 業界によっては原価を分母にする「マークアップ率」を使うこともあり、**同じ「利益率○％」でも意味が違います** |
| **なぜ混同するか** | どちらも「％」で語られるため |
| **実務でどう効くか** | `【Example】`（架空）原価100円・売価150円のとき、売価を分母にすると約33.3％、原価を分母にすると50％。**数字が1.5倍違って見えます。** 会話の中で「利益率」と言われたら、**分母が売価か原価かを確認する**のが実務の作法です |

### (18) 欠品 ≠ 在庫ゼロ

| | |
|---|---|
| **何が違うか** | **欠品**は「売場にあるべき商品が無い」状態。**バックヤードに在庫があっても、売場に出ていなければ客にとっては欠品**です |
| **なぜ混同するか** | システム上の在庫数はバックヤード分も含むため、「在庫あり」と表示されていても売場は空、ということが起きる |
| **実務でどう効くか** | `【Inference】` `13_periodic-work.md` 13-2 の**品出し・補充が「常時」業務**である理由がこれです。**在庫があることと、売れる状態にあることは別**です |

### (19) 営業時間 ≠ 従業員の労働時間

| | |
|---|---|
| **何が違うか** | 店が開いている時間と、従業員が働いている時間は一致しません。**開店前の品出し・値付け、閉店後のレジ締め・清掃・仕込み**があります |
| **なぜ混同するか** | 客として見える範囲が営業時間だけだから |
| **実務でどう効くか** | `【Fact】` 食品スーパーの平均営業時間は10.7時間（2024年、同調査）ですが、**従業員の稼働はその前後に広がります。** 人時の計画（`14_kpi.md` 14-4）は営業時間ではなく**作業量**に基づいて組まれます |

### (20) 本部が決めること ≠ 店舗が決めること

| | |
|---|---|
| **何が違うか** | `09_information.md` 9-5 のとおり、**本部は取引条件・仕入価格・全社の数字**を持ち、**店舗は売場の実態**（今日の売れ行き、天候、客の反応）を持ちます |
| **なぜ混同するか** | 中小小売業では**社長がバイヤー兼販促兼店舗統括**を兼ねることが多く（`06_people.md` 6-5）、境界が見えにくいため |
| **実務でどう効くか** | `【Inference】` **どちらか一方の情報だけでは決められない判断があります。** たとえば「この商品を特売にするか」は、仕入条件（本部）と売場での動き（店舗）の両方が必要です。会話の相手がどちらの情報を持っている人かを見極めることが、実務のやりとりでは重要になります |

## この章のまとめ

1. 用語は**155語**を収録した。業界固有語だけでなく、**商取引・会計の基本語**も押さえること。
2. 最も重要な混同ペアは次の5つ。
   - **値入 ≠ 粗利**（計画と結果。差を作るのがロスと値下げ）
   - **仕入 ≠ 売上原価**（棚卸をしないと売上原価は出ない）
   - **廃棄ロス ≠ 不明ロス**（原因も打つ手も違う）
   - **買取仕入 ≠ 消化仕入**（見た目は同じでも、在庫・粗利・資金がすべて違う）
   - **キャッシュレス売上 ≠ 即時入金**（入金は後、手数料も引かれる）
3. **売上 ≠ 利益**。`【Fact】` 食品スーパーの営業利益率はほぼ±0（2024年）。
   小売業で1円・1点・1％が細かく語られる理由はここにある。
4. **客数はレジでの会計件数**であり、来店人数ではない `【Varies】`。
5. **値引きと値下げは別物**。記録される場所も、粗利への現れ方も違う。
6. **在庫があることと、売れる状態にあることは別。** バックヤードの在庫は客には見えない。
