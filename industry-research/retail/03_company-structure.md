## 3-1 説明用モデル企業「X食品スーパー株式会社」

### 【Example】重要な注意

> **以下の「X食品スーパー株式会社」（以下「X社」）は、本資料の説明を具体的にするために
> 設定した架空のモデル企業です。実在する企業ではなく、統計上の平均値そのものでもありません。**
>
> ただし、読者が現実からかけ離れたイメージを持たないよう、
> 各項目は**公表統計の実数値を手がかり（アンカー）として組み立てて**います。
> どの数字が `【Fact】`（実際の統計値）で、どれが `【Example】`（モデル設定）かを、都度明示します。

### 会社プロフィール

| 項目 | 設定 | 根拠・補足 |
|---|---|---|
| 商号 | X食品スーパー株式会社 | `【Example】` |
| 業態 | **食品スーパー**（生鮮3部門＋惣菜＋日配＋一般食品＋非食品少々） | `【Example】` |
| 事業エリア | 同一県内の1商圏（本店＋近隣3店舗） | `【Example】` |
| 店舗数 | **4店舗** | `【Example】`。単店〜十数店舗という中小小売の典型帯 `【Typical】` |
| 年商 | **約30億円**（1店舗あたり約7.5億円） | `【Example】`。食品スーパー経営指標の集計で「売上高30億円未満」が335社中74社を占める規模帯 `【Fact】`（2024年スーパーマーケット年次統計調査報告書） |

| 取扱アイテム数 | **1店舗あたり 約1万5,000品目（SKU）** | `【Example】` **モデル上の設定値であり統計値ではありません** `【Varies】`（実際の品目数は売場面積・品揃え方針により大きく異なる） |

> **SKU（エスケーユー／Stock Keeping Unit）**
> → 在庫を管理する最小の単位のこと。「品目数」「アイテム数」とほぼ同じ意味で使われます。
> → 実務例：同じ銘柄の醤油でも「500ml」と「1L」は別のSKU。
>   「同じ商品」に見えても、容量・色・サイズが違えば発注も在庫も別管理になります。
>   食品スーパーの品目数が万単位になるのは、この数え方によります。

### 売上の内訳（モデル設定）

| 項目 | 設定値 | 根拠 |
|---|---|---|
| 1店舗1日あたり客数（レジ通過人数） | 約1,000人 | `【Example】` |
| 客単価 | 平日 約2,100円／土日祝 約2,400円 | `【Fact】` 平均客単価は平日2,094.2円、土日祝2,437.8円（2024年、同調査） |
| 1人あたり買上点数 | 平日 約9.5点／土日祝 約10.8点 | `【Fact】` 同調査の平均値 |
| 年間売上（1店舗） | 約1,000人 × 約2,100円 × 365日 ≒ **約7.7億円** | `【Example】`（上記からの計算） |
| 年間売上（4店舗計） | **約30億円** | `【Example】` |

`【Inference】` 検算として、売場面積1㎡あたりの年間販売額は
約30億円 ÷ 4,000㎡ ≒ **約77万円/㎡**。
商業動態統計における2024年の百貨店・スーパー計の売場面積1㎡あたり販売額は79.3万円 `【Fact】` なので、
モデルの設定は現実の水準とおおむね整合しています。

### 商品構成（モデル設定）

`【Fact】` 食品スーパーの商品カテゴリー別売上高構成比（2024年、同調査）を、そのままモデルに採用します。

| 部門 | 売上構成比 `【Fact】` | 目標粗利率 `【Fact】` | ロス率 `【Fact】` | X社での年間売上 `【Example】` |
|---|---|---|---|---|
| 一般食品（グロサリー） | 24.3％ | 19.9％ | 1.7％ | 約7.3億円 |
| 日配品 | 19.0％ | 23.0％ | 4.0％ | 約5.7億円 |
| 青果 | 15.8％ | 23.2％ | 3.2％ | 約4.7億円 |
| 畜産（精肉） | 13.8％ | 28.4％ | 6.6％ | 約4.1億円 |
| 水産（鮮魚） | 10.9％ | 28.2％ | 8.6％ | 約3.3億円 |
| 惣菜 | 10.9％ | 38.5％ | 10.6％ | 約3.3億円 |
| 非食品 | 5.4％ | 21.5％ | 1.5％ | 約1.6億円 |

> **日配品（にっぱいひん）**
> → 「日々配送される商品」の略。毎日または高頻度で納品される、日持ちの短い加工食品のこと。
> → 実務例：牛乳、ヨーグルト、豆腐、納豆、練り物、パン、漬物など。
>   賞味期限が数日〜2週間程度のものが多く、**発注を間違えると即座に廃棄ロスになる**ため、
>   売場担当者が毎日発注数量を判断します。

> **グロサリー（一般食品）**
> → 常温で日持ちする加工食品のこと。「ドライグロサリー」とも呼びます。
> → 実務例：調味料、缶詰、レトルト、乾麺、菓子、飲料など。
>   日持ちするため発注の自由度が高く、まとめ買い・特売の対象になりやすい。

### 収益構造（モデル設定）

| 項目 | 金額・率 | 根拠 |
|---|---|---|
| 売上高 | 約30億円 | `【Example】` |
| 売上総利益（粗利） | 約7.8億円（粗利率 約26％） | `【Fact】` 食品スーパー企業の売上高総利益率 平均26.34％、売上高30億円未満で25.99％（2024年、同調査 経営指標レポート） |
| 人件費 | 約4.0億円 | `【Fact】` 労働分配率（人件費÷売上総利益）は売上高30億円未満で平均50.81％（同上）から算出 |
| その他の販管費（家賃・水道光熱費・消耗品・広告販促・配送費・設備の保守費 等） | 約3.7億円 | `【Inference】`（残差） |
| 営業利益 | **ほぼ±0（▲0.3％〜＋1％程度）** | `【Fact】` 売上高営業利益率は売上高30億円未満で平均▲0.32％、全体平均1.39％（同上） |

> **この会社の姿を一言でいうと**
> 30億円売って、7.8億円の粗利を稼ぎ、そのうち約4億円が人件費に消え、
> 残りで家賃・光熱費・その他を払うと、**利益はほとんど残らない**。
> `【Inference】` だからこそ、粗利率が1ポイント動くこと（＝年間3,000万円）や、
> ロス率が1ポイント動くことが、経営上の重大事になります。
> 小売業で「1円」「1点」「1％」の話が細かく語られる理由はここにあります。

### 人員構成（モデル設定）

| 区分 | 人数 | 根拠 |
|---|---|---|
| **正社員** | **約60名** | `【Fact】` 1店舗あたり正社員数 平均14.0人（2024年、同調査）× 4店舗 ≒ 56名 ＋ 本部専任 約4名 |
| うち管理職（店長・部門長級） | 約12名 | `【Fact】` 1店舗あたり管理職者数 平均2.9人 × 4店舗 |
| **パート・アルバイト** | **約140名**（実人数） | `【Fact】` 店舗勤務者に占めるパート・アルバイト比率 71.2％（2024年、同調査）から算出 |
| **合計** | **約200名** | `【Example】` |

> `【Fact】` 中小企業基本法上、小売業の中小企業者は「資本金5,000万円以下 または 従業員50人以下」
> （出典：中小企業基本法／e-Gov法令検索）。
> `【Inference】` X社は従業員数では基準を超えますが、**資本金基準（5,000万円以下）を満たせば中小企業者**に該当します。
> 小売業は「人数は多いが、1人あたりの売上は小さい」構造のため、
> 従業員数だけで企業規模を判断すると実態を見誤ります。

#### 人数と「人時（にんじ）」は別物

> **人時（にんじ／マンアワー）**
> → 「1人が1時間働く」を1単位として数えた労働量のこと。
> → 実務例：パート4人が4時間ずつ働けば16人時。正社員1人が8時間働けば8人時。
>   **小売業では「何人いるか」より「何人時を投入したか」で人員を管理します。**
>   パート・アルバイトの勤務時間は人によってバラバラなので、
>   人数で数えても仕事量と対応しないためです。

`【Typical】` X社のような会社では、
「正社員60名＋パート140名」という人数よりも、
**「今日この店に、何時から何時まで、何人時を配置するか」**が日々の管理対象になります。

## 3-2 小売業の組織は「本部機能」と「店舗機能」の二層で理解する

### なぜ二層で見るのか

小売業の組織が他業界と決定的に違うのは、
**「決める場所（本部）」と「実行する場所（店舗）」が物理的に離れている**点です。

- 製造業なら、工場と事務所が同じ敷地にあることが多い。
- 小売業は、**売場が複数あり、それぞれが独立した現場**として動いている。

したがって小売業の組織を理解するには、必ず次の2つを分けて考えます。

```
 ┌──────────────────────────────────────────────────────────┐
 │                    【第1層】本部機能                       │
 │   「何を売るか」「いくらで売るか」「どこに出すか」を決める     │
 │   ── 商品調達／販促・販売企画／店舗開発                     │
 │   ── 経理・財務／人事・労務／情報システム                   │
 └──────────────────────────────────────────────────────────┘
                          │           ▲
       商品・売価・企画・   │           │  売上・在庫・ロス・現場の声
       ルール・人員配置     │           │  （実績情報）
                          ▼           │
 ┌──────────────────────────────────────────────────────────┐
 │                    【第2層】店舗機能                       │
 │   「決まったものを、実際に売れる状態にして、売り、お金を受け取る」│
 │   ── 店長（店舗運営責任）                                  │
 │   ── 売場担当（発注・陳列・鮮度管理）                       │
 │   ── レジ・接客                                           │
 │   ── バックヤード（荷受・検品・加工・保管）                  │
 └──────────────────────────────────────────────────────────┘
```

### 【最重要】中小小売業では、この二層は「部署」ではなく「役割」として存在する

`【Typical】` X社規模（4店舗・約30億円）では、
**本部機能は独立した部署になっていません。** 実態はこうです。

| 本部機能 | 大手チェーンでの姿 `【Typical】` | X社での実態 `【Example】`／`【Typical】` |
|---|---|---|
| 商品調達（バイヤー） | 商品部にカテゴリー別の専任バイヤーがいる | **社長が主要カテゴリーのバイヤーを兼務**。生鮮は各店の部門チーフが市場・仲卸と直接やりとり |
| 販促・販売企画 | 販促部が全店共通の企画・チラシを作る | **社長＋事務担当1名**でチラシ内容と特売品を決める。店長も意見を出す |
| 店舗開発 | 店舗開発部が出店候補地を調査する | **社長が案件発生時に対応**。常設の機能ではない |
| 経理・財務 | 経理部・財務部が分かれている | **事務担当2名**が経理・支払・給与計算まで行う。決算は税理士に依頼 `【Varies】` |
| 人事・労務 | 人事部が採用・教育・労務を担当 | **採用は各店長が行い、社会保険等の手続は事務担当**が行う |
| 情報システム | 情報システム部がPOS・発注システムを運用する | **専任者なし**。ベンダーの保守に依存し、社内では事務担当が窓口になる `【Varies】` |

> **本資料の読み方のルール（重要）**
>
> 以降のファイルで「商品調達機能」「販促機能」と書いてあっても、
> それは**「そういう部署がある」という意味ではありません**。
> **「その仕事は必ず誰かがやっている」**という意味です。
>
> ✕「小売業には商品部がある」
> ○「**商品を決めて仕入れる仕事（商品調達機能）は必ず存在する**。
>   大手では商品部のバイヤーが、中小では社長や部門チーフが担っている」

`【Typical】` そして中小小売業で最も典型的なのは、
**社長が「バイヤー」「販促責任者」「店舗統括」「資金繰り責任者」を同時に兼ねている**姿です。
これは兼務というより、**その4つの判断が分かれていないこと自体が中小小売の特徴**です。

> `【Example】`（説明用の架空例）X社の社長の1日
> - 早朝：市場で相場を見て、その日の目玉商品と仕入量を決める（＝バイヤー）
> - 午前：その仕入値から売価を決め、店舗に「本日の特売」を指示する（＝販促責任者）
> - 昼：4店舗を回り、売場の作り込みと客数の出方を確認する（＝店舗統括）
> - 夕方：値下げ開始の指示、翌日の発注方針を店長と詰める（＝店舗統括）
> - 夜：日々の売上と入金予定、支払予定を確認する（＝資金繰り責任者）
>
> **大手チェーンなら4つの部署に分かれている判断が、1人の中で数時間のうちに連結している。**
> これが中小小売業の意思決定の速さの正体でもあります。

## 3-4 パート・アルバイト中心のシフト運営 — 小売業の人員の特徴

### なぜパート・アルバイト中心になるのか

`【Fact】` 食品スーパーの店舗勤務者のうち**71.2％がパート・アルバイト**（2024年、業界推計値。
出典：2024年スーパーマーケット年次統計調査報告書）。

`【Inference】` この構造が生まれる理由は、小売業の仕事量の性質にあります。

```
  1日の来店客数のイメージ（食品スーパーの例）【Typical】

   客数
    ▲
    │                    ██                        ██
    │                    ██                    ██  ██
    │            ██      ██              ██    ██  ██  ██
    │      ██    ██  ██  ██  ██    ██    ██    ██  ██  ██  ██
    │  ██  ██    ██  ██  ██  ██    ██    ██    ██  ██  ██  ██  ██
    └──┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴──▶ 時刻
      開店                  昼のピーク            夕方のピーク      閉店
```

- **仕事量が時間帯によって何倍も変わる。** 開店直後と夕方のピークでは必要な人手が違う。
- **仕事が細かい単位に分解できる。** 「レジを打つ」「品出しをする」「値下げシールを貼る」は
  それぞれ数時間単位で切り出せる。
- **ピークに合わせて正社員だけを配置すると、閑散時間帯に人が余る。**

`【Inference】` したがって、**必要な時間帯に必要な人数だけ配置できるパート・アルバイトが
運営の中心になる**、という構造が生まれます。

### シフト運営とは何をすることか

> **シフト**
> → 従業員ごとの「いつからいつまで働くか」を決めた勤務時間割のこと。
> → 実務例：Aさんは9時〜13時、Bさんは13時〜17時、Cさんは16時〜21時、というように
>   1日を複数人で分担して埋めます。

`【Typical】` シフト運営には、次の一連の仕事が含まれます。

| 手順 | 何をするか | 誰が | 頻度（§5の語彙） |
|---|---|---|---|
| ① 希望の収集 | 各パート・アルバイトから勤務可能日・時間の希望を集める | 店長／部門チーフ | 月次 `【Varies】` |
| ② 必要人時の設定 | 予想客数・特売・季節要因から、時間帯ごとに必要な人時を決める | 店長 | 週次〜月次 `【Varies】` |
| ③ シフト表の作成 | 希望と必要人時を突き合わせ、時間帯ごとに人を割り付ける | 店長／部門チーフ | 月次・週次 `【Varies】` |
| ④ 日々の調整 | 欠勤・急な客数増減に応じて当日の配置を変える | 店長／部門チーフ | 日次 |
| ⑤ 勤怠の集計 | 実際の出退勤を集計し、給与計算に渡す | 店長 → 人事・労務機能 | 月次 |

> **なぜシフト作成が重要なのか**
> `【Inference】` 人件費は売上総利益の約半分を占めます（労働分配率：売上高30億円未満の企業で50.81％ `【Fact】`）。
> つまり**シフトを1時間多く／少なく組むことが、そのまま利益に直結**します。
> 一方で、人を減らしすぎればレジに行列ができ、品出しが間に合わず、売場が荒れて売上が落ちます。
> **「人を減らすと経費は下がるが、売上も下がる」**という板挟みの中で毎日判断する——
> これが小売業の店長の中心的な仕事のひとつです。

### 人の面での特徴（中小小売業）

`【Typical】`

- **技能が部門に紐づく。** 鮮魚の三枚おろし、精肉のスライス、惣菜の調理は、
  誰でもすぐにできる仕事ではありません。**部門の技能者が抜けると売場が回らなくなる**という
  構造的な特徴があります。
- **正社員は「管理する人」であると同時に「現場で作業する人」でもある。**
  1店舗あたり正社員14.0人 `【Fact】` という人数では、管理専任のポジションは置けません。
- **採用は店舗単位で行われることが多い。** `【Varies】`
  通勤圏が限られるため、店舗ごとに近隣で募集するのが一般的です。
- `【Fact】` 参考として、食品スーパー業界ではパート・アルバイトの上限年齢の平均は71.3歳
  （2024年。出典：2024年スーパーマーケット年次統計調査報告書）。

## 3-5 1店舗の物理的な構造（理解の前提）

`【Typical】` 小売店舗は、大きく次の3つの空間に分かれます。
業務フロー（`04`）を読む前提として押さえてください。

```
 ┌───────────────────────────────────────────────────────────┐
 │                       【店舗の外】                           │
 │   駐車場（約130台）／ 納品用の搬入口（荷受場）                 │
 └───────────────────────────────────────────────────────────┘
        │ 商品はここから入る
        ▼
 ┌───────────────────────────────────────────────────────────┐
 │        【バックヤード】（延べ面積の約30.5％）【Fact】           │
 │   ・荷受場：納品トラックから商品を受け取る                     │
 │   ・検品スペース：伝票と現物を照合する                         │
 │   ・冷蔵庫／冷凍庫／常温倉庫：保管する                         │
 │   ・作業場（鮮魚・精肉の加工場、惣菜の調理場）                  │
 │   ・事務所：売上金の管理、発注端末、シフト表、金庫              │
 │   ・休憩室、更衣室                                           │
 └───────────────────────────────────────────────────────────┘
        │ 商品はここへ出ていく
        ▼
 ┌───────────────────────────────────────────────────────────┐
 │                【売場】（約1,000㎡）                          │
 │   ・定番売場（ゴンドラ＝棚が並ぶ区画）                         │
 │   ・エンド（棚の端。目立つ位置）                              │
 │   ・平台・ワゴン（特売品を積む台）                            │
 │   ・冷蔵ケース・冷凍ケース（生鮮・日配・冷凍食品）              │
 │   ・レジ（約6台）【Fact】                                    │
 │   ・サービスカウンター（問い合わせ・返品・取り置き）             │
 └───────────────────────────────────────────────────────────┘
        │ 商品はここから出ていく（お客さまが持ち帰る）
        ▼
                        【消費者】
```

> **エンド**
> → 棚（ゴンドラ）の端にある、通路に面した売場のこと。
> → 実務例：通路を歩く客の目に入りやすいため、特売品や売り込みたい商品を置きます。
>   **同じ商品でも、定番の棚に置くかエンドに置くかで売れ方が大きく変わる**ため、
>   「今週のエンドに何を置くか」は販促企画の重要な決定事項になります。

> **フェイス**
> → 売場で商品が正面を向いて並んでいる、その「面」の数のこと。
> → 実務例：ある醤油を棚で横に3本並べれば「3フェイス」。
>   フェイスを増やせば目立ち、補充の頻度を減らせますが、その分ほかの商品の場所がなくなります。
>   **限られた棚の面積を、どの商品に何フェイス割り当てるか**が売場作りの基本単位です。

> **定番（ていばん）売場**
> → その商品がいつも置かれている、決まった位置の売場のこと。
> → 実務例：「醤油はこの棚のこの位置」と決めておくことで、
>   客は毎回同じ場所で見つけられ、従業員も補充場所を迷いません。
