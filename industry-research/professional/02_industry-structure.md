## 2-1. 登場するプレイヤー（誰が出てくるのか）

専門サービス業には、製造業の「仕入先→自社→得意先」のような一直線の並びがありません。
**事務所を中心に、性格の違う相手が放射状に取り巻いている**のが特徴です。

```
                       ┌──────────────┐
                       │   各士業会    │  登録・研修・指導
                       │（税理士会等） │
                       └──────┬───────┘
                              │
   ┌──────────┐              │              ┌──────────────┐
   │ 金融機関  │──紹介──┐    │    ┌──紹介──│  同業者（同じ士業）│
   │（銀行・信金）│          │    │    │          │ 提携・繁忙期の応援 │
   └──────────┘          ▼    ▼    ▼          └──────────────┘
                       ┌────────────────┐
   ┌──────────┐      │                    │      ┌──────────────┐
   │ 他士業    │─紹介─▶│     専門サービス     │◀─紹介─│  既存の顧問先   │
   │（社労士・   │      │      事務所         │      │（紹介元にもなる） │
   │ 司法書士等）│◀─紹介─│                    │      └──────────────┘
   └──────────┘      └──────┬──┬──────┘
                              │  │
        書類の提出・照会 ──────┘  └────── 業務の委託・道具の調達
                    ▼                              ▼
   ┌──────────────────────────┐   ┌────────────────────┐
   │ 行政機関                     │   │ ソフトウェアベンダー      │
   │ 税務署／都道府県税事務所／市町村 │   │ 会計ソフト・給与ソフト・   │
   │ 法務局／年金事務所／           │   │ 申告ソフトの提供元        │
   │ 労働基準監督署／ハローワーク     │   └────────────────────┘
   └──────────────────────────┘
                    ▲
                    │ 申告・申請・届出
   ┌────────────────────────┐
   │ 顧客（顧問先企業・個人顧客）      │ ← 本来の義務者はここ
   └────────────────────────┘
```

> **図の読み方で最も大事な点**
> 行政機関に対して申告・申請をする**本来の義務者は顧客自身**です。
> 事務所は、顧客に代わってそれをしています（＝代理・代行）。
> 「事務所が申告している」のではなく「**顧客が申告するのを、事務所が代理している**」という関係です。
> この関係を条文で示しているのが、次の規定です。
>
> 【Fact】税理士法第30条（税務代理の権限の明示）
> 「税理士は、税務代理をする場合においては、財務省令で定めるところにより、
> その権限を有することを証する書面を税務官公署に提出しなければならない。」（出典：税理士法／e-Gov法令検索）

### 各プレイヤーの詳細

#### ① 顧問先企業（最大の顧客層）

- **関係の性質**：継続。毎月または定期的に接触する。
- **事務所にとっての意味**：**毎月の売上（ストック収入）の源**。
- **何を渡してくれるか**：会計資料（通帳、領収書、請求書）、給与データ、契約書、質問。
- **何を受け取るか**：試算表、決算書、申告書、各種届出の控え、助言。
- 【Typical】顧客側の窓口は社長または経理担当者。従業員数名の会社では社長本人です。

#### ② 個人顧客

- **関係の性質**：多くが単発（スポット）。
- **例**：相続、確定申告、不動産登記、年金請求、各種許認可。
- 【Typical】接触は案件の期間中に集中し、終わると途切れます。
  ただし相続をきっかけに、その相続人が経営する会社の顧問につながることもあります【Typical】。

#### ③ 同業者（同じ資格の仲間）— 競合であり、同時に提携相手

【Typical】同じ士業どうしは、単なる競合ではありません。次のような関係が一般的に見られます。

| 関係 | 内容 |
|---|---|
| **仕事の紹介** | 自分の事務所では手が回らない案件、専門外の案件を同業者に回す |
| **繁忙期の応援** | 確定申告期などに、他の事務所や外部の担当者に応援を頼む【Varies】 |
| **専門分野の相談** | 相続専門、国際税務専門など、得意分野の違う同業者に相談する |
| **事業承継** | 高齢の所長が、顧問先ごと別の事務所に引き継ぐ【Varies】 |

#### ④ 他士業（違う資格の専門家）— ワンストップのための連携

【Typical】1つの顧客の困りごとは、1つの資格では完結しません。
`01_overview.md` の会社設立の例のように、複数の資格が順番に関わります。
そのため、**税理士は司法書士・社労士・弁護士と、それぞれつながりを持っている**のが一般的です。

> **ワンストップ**
> → 顧客が何か所も回らなくて済むように、窓口を1つにまとめて対応すること。
> → 実務例：顧客が税理士に「従業員を雇いたい」と相談する。税理士は社会保険の手続はできないので、
>    提携している社会保険労務士を紹介する。顧客は自分で社労士を探さずに済みます。

**ここで重要なのが、独占業務の壁です。**
税理士が顧客に頼まれても、社会保険の申請書を報酬をもらって作成することはできません
（社会保険労務士法第27条）。
だから紹介が必要になります。**紹介は「親切」である以前に、法律上そうせざるを得ない構造から生まれています**【Inference】。

#### ⑤ 金融機関（銀行・信用金庫・信用組合）

【Typical】金融機関は、専門サービス業にとって3つの顔を持ちます。

1. **紹介元**：融資先の会社に税理士がついていないとき、取引先の税理士を紹介する。
2. **決算書の読み手**：事務所が作った決算書を、融資の判断材料として読む。
3. **顧客の資金繰りの相手**：事務所が顧客の資金繰り相談に乗るとき、実際に話をつける先。

#### ⑥ 行政機関（書類の提出先であり、調査をする主体）

| 行政機関 | 主に何の窓口か | 関わる専門家 |
|---|---|---|
| **税務署**（国税庁） | 法人税・所得税・消費税・源泉所得税の申告と納付 | 税理士 |
| **都道府県税事務所・市町村** | 法人事業税・法人住民税・個人住民税・固定資産税 | 税理士 |
| **法務局**（法務省） | 不動産登記・商業登記・供託 | 司法書士・土地家屋調査士 |
| **年金事務所**（日本年金機構） | 厚生年金保険・健康保険（協会けんぽ）の資格取得・喪失・算定基礎届 | 社会保険労務士 |
| **健康保険組合** | 健康保険（組合管掌の場合） | 社会保険労務士 |
| **労働基準監督署**（厚生労働省） | 労災保険、就業規則の届出、労働条件の監督 | 社会保険労務士 |
| **公共職業安定所（ハローワーク）** | 雇用保険の資格取得・喪失、各種助成金 | 社会保険労務士 |
| **都道府県・市町村の許認可窓口** | 建設業許可、飲食店営業許可、産業廃棄物の許可 など | 行政書士 ほか |

【Fact】労働基準法第89条は「常時十人以上の労働者を使用する使用者は、次に掲げる事項について就業規則を作成し、
行政官庁に届け出なければならない。次に掲げる事項を変更した場合においても、同様とする」と定めています
（出典：労働基準法／e-Gov法令検索）。
このように、**顧客に法律上の義務があり、その義務を果たすために専門家が呼ばれる**という構図が繰り返し現れます。

#### ⑦ ソフトウェアベンダー

【Typical】専門サービス業では、次のような種類のシステムが業務の道具として使われます。
（※本資料は「今の仕事を理解するための道具の説明」として記載します。良し悪しや導入の提案は行いません。）

| システムの種類 | 何のための道具か |
|---|---|
| 会計ソフト | 仕訳を入力し、試算表・決算書の形に集計する |
| 申告ソフト | 決算書の数字から税額を計算し、申告書の様式に出力する |
| 電子申告の仕組み（e-Tax／eLTAX） | 作成した申告書を、紙ではなくデータで税務官公署に送る |
| 給与計算ソフト | 勤怠と支給項目から給与額・社会保険料・源泉所得税を計算する |
| 社会保険の電子申請の仕組み（e-Gov） | 社会保険・労働保険の届出をデータで提出する |
| 登記申請のオンラインシステム | 登記申請をデータで法務局に提出する |
| 顧客管理・進捗管理の仕組み | どの顧問先の、どの申告が、どこまで進んでいるかを一覧で管理する |

【Varies】どの製品を使うかは事務所により異なり、顧客側が使っているソフトに事務所が合わせる場合もあります。

#### ⑧ 各士業会（登録と指導の主体）

【Fact】多くの士業では、**資格試験に合格しただけでは業務を行えず、名簿への登録が必要**です。

- 税理士法第18条（登録）：「税理士となる資格を有する者が、税理士となるには、税理士名簿に、財務省令で定めるところにより、
  氏名、生年月日、事務所の名称及び所在地その他の事項の登録を受けなければならない。」
- 社会保険労務士法第14条の2第1項（登録）：「社会保険労務士となる資格を有する者が社会保険労務士となるには、
  社会保険労務士名簿に、氏名、生年月日、住所その他厚生労働省令で定める事項の登録を受けなければならない。」
- 税理士法第49条第1項（税理士会）：「税理士は、国税局の管轄区域ごとに、一の税理士会を設立しなければならない。」

（出典：いずれも e-Gov法令検索／デジタル庁）

【Fact】また、司法書士法第73条第1項は業務制限の対象を「**司法書士会に入会している**司法書士又は司法書士法人でない者」
と規定しており、**会への入会が条文上の要件として現れている**点が他の士業法と異なります（出典：司法書士法／e-Gov法令検索）。

【Typical】士業会は、登録の窓口であるほか、研修の実施、会員への指導、無料相談会の実施などを行います。
事務所にとっては**会費を払う先**であり、**同業者と知り合う場**でもあります。

## 2-2. 商流（仕事はどこから来るのか）

### 結論：紹介が主要な集客経路

【Typical】専門サービス業では、**紹介による受任が主要な経路**とされています。
理由は、この商売の性質から説明できます。

> **なぜ紹介が中心になるのか**【Inference】
> 顧客は、専門サービスの良し悪しを**事前に判断できません。**
> 車なら試乗できます。飲食なら食べれば分かります。
> しかし「この税理士は正しく申告してくれるか」は、頼む前には分かりません。
> しかも、頼む内容は**売上・給与・家庭の事情といった、他人に言いたくない情報**です。
> だから顧客は「知っている人が大丈夫だと言っている」ことを手がかりにします。
> これが紹介が効く理由です。

### 主な紹介経路

| 紹介元 | どういう場面で起きるか | 紹介の重み |
|---|---|---|
| **既存の顧問先** | 社長が、取引先や知人の社長に「うちの税理士はいいよ」と話す | 【Typical】最も多いとされる経路 |
| **金融機関** | 融資を検討している会社に専門家がついていないとき | 顧客の信用が担保されやすい |
| **他士業** | 司法書士が会社設立の登記をした顧客に、税理士を紹介する | 業務の順番から自然に発生する |
| **同業者** | 専門外・手一杯の案件を回す | 引き継ぎの情報が正確 |
| **保険会社・不動産業者等の取引先** | 相続・事業承継の相談が発生したとき | 【Varies】事務所により有無が分かれる |

### 紹介以外の経路

【Varies】以下は事務所により有無・比重が大きく異なります。

- 事務所のWebサイト・検索からの問い合わせ
- 士業会が実施する無料相談会
- 商工会議所・商工会・よろず支援拠点などの公的機関の相談窓口
- セミナー・勉強会の開催
- 既存顧客からの追加業務（顧問先からスポット業務を受ける）

> **「商流」という言葉について**
> 卸売業なら「メーカー→卸→小売→消費者」というモノと所有権の流れがあります。
> 専門サービス業には、**転売される商品がありません。**
> したがってここでいう商流とは、**「仕事がどこから来て、誰に届くか」という経路**を指します。
> 事務所が他の事務所に仕事を再委託することはありますが、それは商品の転売ではなく
> **業務の外注（下請け）**であり、守秘義務の観点から顧客の同意が問題になります【Inference】。

## 2-3. バリューチェーン（受任から継続まで）

専門サービス業の仕事は、次の6段階で進みます。**この6段階は業種を問わず概ね共通します**【Typical】。

```
① 受任  →  ② 情報収集  →  ③ 処理  →  ④ 申告・申請  →  ⑤ 報告  →  ⑥ 継続
 ↑                                                                    │
 └────────────────────────────────────────────────────────────────────┘
                      （顧問契約の場合は②〜⑥を毎月/毎年くり返す）
```

| 段階 | 何をするか | 誰が中心か | この段階で価値が生まれる理由 |
|---|---|---|---|
| **① 受任（じゅにん）** | 依頼を引き受けるかどうかを決め、業務範囲と報酬を決めて契約する | 所長（有資格者） | 引き受けた時点で責任が発生する。何を引き受け、何は引き受けないかを決めることが、後のトラブルを防ぐ |
| **② 情報収集** | 顧客から資料を預かる／ヒアリングする | 担当者 | **資料が揃わないと次に進めない。** ここが止まると全工程が止まる |
| **③ 処理** | 記帳・計算・整理・下書きの作成 | 担当者・入力担当 | 生の資料を、制度が要求する形に変換する |
| **④ 申告・申請** | 有資格者のチェックを経て、行政機関に提出する | **有資格者**（独占業務の場合） | 提出して初めて顧客の義務が果たされる。ここが仕事の完了点 |
| **⑤ 報告** | 顧客に結果を説明する。納税額・保険料額を伝える | 担当者＋所長 | 顧客は数字を見ただけでは意味が分からない。説明されて初めて価値になる |
| **⑥ 継続** | 次の期間へ。資料を保管し、次のサイクルに入る | 事務所全体 | 継続することで顧問料が続く。また蓄積した情報が次回の効率と精度を上げる |

> **用語：受任（じゅにん）**
> → 依頼を引き受けること。
> → 実務例：「A社から法人税の申告を受任した」＝A社の申告を引き受けた、という意味。
>    逆に断ることを「受任しない」と言います。
>
> **用語：委任（いにん）**
> → 民法上の契約の型のひとつで、「ある事務の処理を相手に任せる」契約のこと。
> → 実務例：専門サービスの契約は、この委任（または準委任）の形を取るのが一般的です【Typical】。
>    **請負（うけおい）との違いが重要です。** 請負は「完成させること」を約束する契約で、
>    完成しなければ報酬をもらえません。委任は「適切に事務を処理すること」を約束する契約です。
>    【Inference】だから顧問契約では、「今月は特に案件がなかった」場合でも顧問料が発生します。

## 2-4. モノの流れ（この業界には物理的なモノの流れが無い）

**結論：専門サービス業には、製造業・卸売業・小売業のような「モノの流れ」は存在しません。**

- 仕入先から材料が届くことはありません。
- 倉庫はありません。棚卸もありません。
- 製品を出荷するトラックもありません。
- 在庫が売れ残って値下げする、ということも起きません。

理由は単純で、**売っているものが物理的なモノではないから**です。
`common/methodology.md` §6 の定義に従い、ここでは「何が価値の実体か」を書きます。

### モノの代わりに動いているもの：預り資料と作成書類

```
【顧客】                    【事務所】                   【行政機関】

 通帳コピー ────預ける───▶ ┌──────────┐
 領収書の束                │ 受領       │
 請求書控え                │ 　↓        │
 給与データ                │ 保管（施錠）│
 契約書・登記簿等           │ 　↓        │
                          │ 処理・作成  │
                          │ 　↓        │
                          │ 有資格者    │
                          │ チェック    │
                          │ 　↓        │
 控え・報告書 ◀──返却・報告─│ 提出      │─── 申告書 ───▶ 税務署
 預り資料    ◀──返却───── └──────────┘    申請書        法務局
                                          届出書        年金事務所 等
```

### 「預り資料」という概念が、この業界のモノに相当する

> **預り資料（あずかりしりょう）**
> → 業務のために顧客から一時的に預かっている書類やデータのこと。**所有者は顧客のまま**です。
> → 実務例：1年分の領収書の入った段ボール箱を顧問先から預かり、記帳が終わったら返す。

**預り資料の管理責任が重い理由は3つあります。**

1. **中身が秘密情報だから。** 売上、給与、取引先、個人の住所・マイナンバー。
   `01_overview.md` の守秘義務（税理士法第38条ほか）の対象そのものです。
2. **顧客の財産だから。** 原本を紛失すると、再発行できないものがあります。
   （例：取引先が発行した請求書の原本、印鑑証明書、権利証にあたる書類）
3. **紛失すると業務が止まるから。** 資料がないと申告書が作れず、法定期限に間に合わなくなります。

【Typical】そのため、事務所では次のような扱いが一般的に行われます。

- 預かるときに**預り証**を発行し、何をいつ預かったかを記録する
- 書類は施錠できる場所に保管する
- 返却したときも記録を残す
- 職員の持ち出しにルールを設ける

### 事務所自身の「モノ」はごくわずか

【Typical】事務所が持っている物理的なものは、机・椅子・パソコン・複合機・書庫・金庫程度です。
製造業でいう設備投資や在庫投資が無いため、**事業を始めるときの初期投資が比較的小さい**一方、
**設備で生産性を上げることもできない**という構造になります【Inference】。

## 2-5. 関係者の役割整理（誰が実行し、誰が承認するのか）

専門サービス業の仕事は、**「実行する人」と「責任を負う人」が分かれている**のが特徴です。

### 簡易RACI（申告業務を例に）

> **RACI（レイシー）**
> → 誰が実行し（R）、誰が最終責任を負い（A）、誰に相談し（C）、誰に報告するか（I）を整理する表のこと。
> → 実務例：「入力は職員がやるが、最終責任は所長」というように役割を明確にするために使います。

| 作業 | 実行（R） | 最終責任（A） | 相談（C） | 報告先（I） |
|---|---|---|---|---|
| 資料の受領・預り証の発行 | 担当者 | 所長 | — | 顧客 |
| 記帳・入力 | 入力担当／担当者 | 所長 | 担当者 | — |
| 試算表の作成 | 担当者 | 所長 | — | 顧客 |
| 月次の打合せ | 担当者 | 所長 | 所長 | 顧客 |
| 決算整理・決算書の作成 | 担当者 | **有資格者（所長）** | 所長 | 顧客 |
| 申告書の作成 | 担当者 | **有資格者（所長）** | 所長 | 顧客 |
| 申告書の最終チェック・署名 | **有資格者（所長）** | **有資格者（所長）** | — | 顧客 |
| 電子申告の送信 | 担当者 | **有資格者（所長）** | — | 顧客 |
| 顧客への納税額の案内 | 担当者 | 所長 | — | 顧客 |

> **この表で押さえるべき点**
> **最終責任（A）の列が、独占業務では必ず有資格者になります。**
> 実行（R）は無資格の職員が行ってよくても、責任は資格者から離れません。
> この構造が、事務所の組織設計そのものを決めています（`03_company-structure.md` で詳述）。

### 社外関係者との関わり方

| 相手 | 事務所から見た関係 | 接触の頻度 |
|---|---|---|
| 顧問先の社長 | 顧客であり、意思決定者 | 月次【Typical】 |
| 顧問先の経理担当者 | 実務上の窓口 | 常時（質問のやり取り） |
| 税務署の担当者 | 提出先。調査の際は相手方 | 法定・契約上のタイミング／トラブル発生時 |
| 金融機関の担当者 | 紹介元であり、決算書の読み手 | 【Varies】 |
| 他士業 | 連携先 | 案件発生時 |
| 士業会 | 登録・研修・会費の相手 | 年次／随時 |

## 2-6. ★この業界に固有の構造（ここが他業界と決定的に違う5点）

### ① 独占業務と非独占業務が、同じ事務所の中に混在している

事務所が行う仕事は、法律上まったく性質の違う2種類に分かれます。

| | 独占業務 | 非独占業務 |
|---|---|---|
| **意味** | 有資格者（と有資格者の法人）でなければ行えないと法律が定めている業務 | 誰が行ってもよい業務 |
| **税理士事務所の例** | 税務代理、税務書類の作成、税務相談（税理士法第2条第1項の3つ。同法第52条が制限） | 記帳代行、財務書類の作成、経営相談、資金繰りの相談 |
| **社労士事務所の例** | 申請書等の作成、提出手続の代行（社会保険労務士法第2条第1項第1号〜第2号。同法第27条が制限） | 労務管理の相談・指導（同項第3号。第27条の制限の範囲外） |
| **誰が実行できるか** | 実行の補助は無資格の職員でも可能だが、**最終責任は有資格者** | 無資格の職員が担当できる |
| **競争の相手** | 同じ資格を持つ事務所のみ | 資格の有無を問わない事業者すべて |

【Fact】税理士法第2条第2項は「税理士は、前項に規定する業務（以下「税理士業務」という。）のほか、
税理士の名称を用いて、他人の求めに応じ、税理士業務に付随して、財務書類の作成、会計帳簿の記帳の代行その他財務に関する事務を
業として行うことができる。ただし、他の法律においてその事務を業として行うことが制限されている事項については、この限りでない。」
と定めています（出典：税理士法／e-Gov法令検索）。

> **なぜこの区別が構造として重要なのか**【Inference】
> 独占業務は、**資格を持つ事務所の間でしか競合が起きません。**
> 非独占業務は、**資格を持たない事業者とも競合します。**
> 同じ事務所の中で、この2つが1つの顧問料としてまとめて請求されることが多いため、
> 顧客からは区別が見えにくくなっています。
> （※本資料は、この構造を「評価」しません。事実として構造を記述しています。）

### ② 顧問契約（ストック収入）とスポット業務（フロー収入）の二本立て

| | 顧問契約 | スポット業務 |
|---|---|---|
| **契約の形** | 期間を区切らず継続 | 案件ごと |
| **請求のタイミング** | 月次 | 業務完了時／納品時 |
| **収入の予測** | 立つ | 立たない |
| **業務量の予測** | ある程度立つ（月次の作業が決まっている） | 立たない |
| **顧客との距離** | 近い。継続的に情報が蓄積する | 遠い。案件ごとにゼロから情報収集 |
| **例** | 月次の記帳確認・試算表作成・相談対応 | 決算・申告、相続税申告、会社設立、就業規則作成、許認可申請 |

【Typical】多くの事務所では、**顧問料で固定費（人件費・家賃）をまかない、スポットで上乗せする**という形になります【Inference】。
この比率の違いが、事務所ごとの経営の安定度と繁忙の波を決めます。
（詳しくは `12_business-model.md` で扱います。）

### ③ 繁忙期が「制度」で決まっている（自分では動かせない）

これは他の業界と決定的に違う点です。
小売業の繁忙期は客の行動で決まり、建設業の繁忙期は工期で決まります。
しかし**専門サービス業の繁忙期は、法律が定めた期限で決まります。**

【Fact】主な法定期限（いずれも出典：e-Gov法令検索）：

| 期限の内容 | 条文の文言（逐語） | 根拠 |
|---|---|---|
| **所得税の確定申告** | 「第三期（その年の翌年二月十六日から三月十五日までの期間をいう。…）において、税務署長に対し、次に掲げる事項を記載した申告書を提出しなければならない」 | 所得税法第120条第1項 |
| **法人税の確定申告** | 「内国法人は、各事業年度終了の日の翌日から二月以内に、税務署長に対し、確定した決算に基づき次に掲げる事項を記載した申告書を提出しなければならない」 | 法人税法第74条第1項 |
| **消費税の確定申告** | 「事業者（…）は、課税期間ごとに、当該課税期間の末日の翌日から二月以内に、次に掲げる事項を記載した申告書を税務署長に提出しなければならない」 | 消費税法第45条第1項 |
| **源泉所得税の納付** | 「その支払の際、その給与等について所得税を徴収し、その徴収の日の属する月の翌月十日までに、これを国に納付しなければならない」 | 所得税法第183条第1項 |
| **労働保険の確定保険料の申告（年度更新）** | 「事業主は、保険年度ごとに、次に掲げる労働保険料の額その他厚生労働省令で定める事項を記載した申告書を、次の保険年度の六月一日から四十日以内…に提出しなければならない」 | 労働保険徴収法第19条第1項 |
| **健康保険の報酬月額算定基礎届** | 「毎年七月一日現に使用する被保険者（…）の報酬月額に関する法第四十八条の規定による届出は、同月十日までに、様式第四号による健康保険被保険者報酬月額算定基礎届を機構又は健康保険組合に提出することによって行うものとする」 | 健康保険法施行規則第25条第1項 |

**この条文が、事務所の1年のカレンダーをそのまま決めています**【Inference】。

| 時期 | 何が集中するか | 主に誰が忙しいか |
|---|---|---|
| 1月 | 法定調書・給与支払報告書の提出、償却資産申告 | 税理士事務所 |
| 2月〜3月15日 | **所得税の確定申告**（所得税法第120条） | 税理士事務所（最大の繁忙期）【Typical】 |
| 5月 | 3月決算法人の法人税申告（法人税法第74条：事業年度終了の翌日から2月以内） | 税理士事務所【Typical】 |
| 6月〜7月上旬 | **労働保険の年度更新**（労働保険徴収法第19条） | 社会保険労務士事務所 |
| 7月10日まで | **算定基礎届**（健康保険法施行規則第25条） | 社会保険労務士事務所 |
| 11月〜12月 | 年末調整 | 税理士事務所・社会保険労務士事務所 |
| 毎月10日 | 源泉所得税の納付（所得税法第183条） | 税理士事務所（毎月） |

> **なぜこれが構造なのか**
> 繁忙期を**事務所の都合でずらすことができません。**
> 顧客に「今忙しいので来月にしてください」と言っても、法定期限は動きません。
> したがって、人員の配置・受任できる件数・繁忙期前の準備が、この期限に縛られます【Inference】。
> （※本資料は対策や改善策を提案しません。構造の説明にとどめます。）

### ④ 守秘義務（法律上の義務であり、事務所運営の前提条件）

条文は `01_overview.md` の1-3に逐語で掲載しています。ここでは**構造としての意味**を整理します。

1. **義務を負うのは、まず有資格者本人です。** 条文の名宛人は「税理士は」「行政書士は」といった形です。
2. **【Inference】しかし実務では、無資格の職員も同じ情報に触れます。** そのため事務所は、
   雇用契約や誓約書によって職員にも秘密保持を課すのが一般的です【Typical】。
3. **資格を失った後も続きます。** 「税理士でなくなつた後においても、また同様とする」（税理士法第38条）。
4. **業務の外注に制約が生まれます。** 他の事務所に仕事を回すことは、情報を外に出すことを意味します【Inference】。

> **実務例**【Example】（説明用の架空の例です）
> 同じ商店街にある2つの飲食店が、どちらも同じ税理士事務所の顧問先だとします。
> 事務所はA店の売上もB店の売上も知っています。
> しかしA店の社長に「B店さんは最近どうですか」と聞かれても、答えることはできません。
> これは「気を使っている」のではなく、法律上の義務です。

### ⑤ 賠償責任（ミスが顧客の金銭的損害に直結する）

**これが専門サービス業の最大のリスク構造です。**

他の業界では、ミスは作り直しややり直しで回復できることがあります。
しかし専門サービス業のミスは、**顧客のお金の損失として、直接、金額で現れます。**

【Typical】典型的に想定される損害の形：

| ミスの種類 | 顧客に何が起きるか |
|---|---|
| 申告期限に間に合わなかった | 顧客が本来受けられたはずの制度上の取扱いを受けられない、追加の負担が生じる |
| 計算を誤って税額を少なく申告した | 後から不足分の税金に加え、加算税・延滞税を負担することになる |
| 届出を出し忘れた | 保険給付が受けられない、助成金が受けられない |
| 登記を誤った・遅れた | 権利関係で不利益を受ける |

【Inference】そして重要なのは、**この損害額が、事務所が受け取った報酬をはるかに超えうる**ことです。
月額3万円の顧問料の事務所が、数百万円の損害の原因になる可能性があります。

> **だから何が起きるか（構造として）**
> 1. **チェック（レビュー）工程が業務フローに組み込まれます。** 作った人と確認する人を分けます。
> 2. **業務範囲を契約書で明確にします。** 「何を引き受けていないか」が重要になります。
> 3. **記録を残します。** 【Fact】税理士法第41条第1項は「税理士は、税理士業務に関して帳簿を作成し、
>    委嘱者別に、かつ、一件ごとに、税務代理、税務書類の作成又は税務相談の内容及びそのてん末を記載しなければならない」
>    と定め、同条第2項は「前項の帳簿は、閉鎖後五年間保存しなければならない」と定めています
>    （出典：税理士法／e-Gov法令検索）。
> 4. **【Typical】賠償責任保険への加入**が一般的に行われます【Varies】。
>
> （※本資料はこれらを「やるべきこと」として提案しているのではなく、
> 　現にそういう構造になっている、という事実として記述しています。）

## 2-7. まとめ：この章で押さえるべき5点

1. **事務所は放射状の関係の中心にいる。** 顧客・同業者・他士業・金融機関・行政・士業会・ベンダー。
2. **仕事は紹介から来る。** 事前に品質を判断できず、秘密情報を預ける商売だから。
3. **バリューチェーンは「受任→情報収集→処理→申告・申請→報告→継続」**の6段階。
4. **モノの流れは無い。** 代わりに「預り資料」と「作成書類」が動き、その管理責任が重い。
5. **固有の構造は5つ**：独占／非独占の混在、顧問（ストック）／スポット（フロー）、
   制度で決まる繁忙期、法律上の守秘義務、報酬を超えうる賠償責任。
