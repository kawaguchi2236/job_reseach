# 09_information.md — 情報の流れ（専門サービス業）

**対象**：日本国内の中小の専門サービス業（主モデル：税理士事務所／対比：社会保険労務士事務所）
**読み手**：専門サービス業をまったく知らない人
**前提**：`03_company-structure.md` の**【Example】X会計事務所**（9名／顧問先120件／年商7,000万円。架空）
**最終更新**：2026-09-20

> このファイルは `common/methodology.md` §6 の「4つの流れ」のうち**情報**を扱います。
> §6 は「『情報』という抽象語で終わらせない。具体的に命名する」と定めています。
> **そこでこのファイルでは、情報を16種類に分けて名前を付け、1つずつ何なのかを書きます。**

---

## 9-0. この業界の「情報」が特殊な3点

### ① 情報が、商品そのものである

`07_goods.md` 7-0 のとおり、この業界に商品としてのモノはありません。
**顧客から情報を受け取り、形を変えて、情報として返す。それが業務の全体です。**

```
  【製造業】   材料（モノ） → 加工 → 製品（モノ）を売る
              ※情報は、モノを作るための道具

  【専門サービス業】  情報 → 変換 → 情報を渡す／提出する
              ※**情報が材料であり、情報が製品**
```

### ② 情報が、すべて他人のものである

顧客の売上、顧客の借入、顧客の給与、顧客の家族の事情。
**事務所が扱う情報のほとんどが、顧客のものです。**

だから、この業界では**守秘義務が法律上の義務**として置かれています（9-5）。
そして`01_overview.md` 1-8 ③のとおり、**資格を失った後も続きます。**

### ③ ★資料が揃わないと、次に進めない

**このファイルの軸になる原則です。**

```
   資料受領情報 ──▶ 仕訳情報 ──▶ 試算表情報 ──▶ 月次報告情報 ──▶ 決算書情報 ──▶ 申告書情報
        │
        └─ **ここが揃わないと、右側のすべてが止まる**
```

`04_end-to-end-process.md` E② のとおり、**仕事の起点が事務所の外（顧客）にあります。**
【Inference】したがって、事務所の業務管理の中心は「進捗管理」ではなく、
「**どの顧問先の、何月分の資料が、まだ来ていないか**」の管理になります。

> **★これが他業界との決定的な違いです**
> 製造業なら、材料が無ければ「作れない」で止まります。
> この業界では、**顧客の資料が来なくても、法律上の期限は来ます。**
> 【Fact】法人税法第74条第1項「各事業年度終了の日の翌日から二月以内に…申告書を提出しなければならない」
> （出典：法人税法／e-Gov法令検索）。
> **期限は、資料が揃ったかどうかに関係なく来ます。**
> だから情報の流れの管理が、この業界の業務管理そのものになります【Inference】。

## 9-1. 情報の流れの全体像（16種類の情報）

```
  ┌─────────────────────────────────────────────────────────────────┐
  │  【受任まで】                                                       │
  │   ① 相談情報 ─▶ ② 受任判断の情報 ─▶ ③ 契約情報                      │
  └─────────────────────────────────────────────────────────────────┘
                                │
  ┌─────────────────────────────▼───────────────────────────────────┐
  │  【毎月くり返す】                                                   │
  │   ④ 資料受領情報 ─▶ ⑤ 仕訳情報 ─▶ ⑥ 試算表情報 ─▶ ⑦ 月次報告情報      │
  │        ▲                │                                        │
  │        │                ▼                                        │
  │        └──── ⑧ 質問・回答情報 ────┘                                │
  └─────────────────────────────────────────────────────────────────┘
                                │
  ┌─────────────────────────────▼───────────────────────────────────┐
  │  【年に1回】                                                        │
  │   ⑨ 決算整理情報 ─▶ ⑩ 決算書情報 ─▶ ⑪ 申告書情報                     │
  │                          │                                        │
  │                          ▼                                        │
  │   ⑫ **有資格者のチェック情報** ─▶ ⑬ 顧客の承認情報                    │
  │                          │                                        │
  │                          ▼                                        │
  │   ⑭ 申告情報（電子申告）─▶ ⑮ 納税額の情報 ─▶ ⑯ 控えの保管情報         │
  └─────────────────────────────────────────────────────────────────┘
```

### 一覧表

| # | 情報の名前 | 誰から誰へ | 何が書かれているか | 頻度 |
|---|---|---|---|---|
| ① | **相談情報** | 顧客・紹介者 → 所長 | 何に困っているか、どういう会社か | 問い合わせ時 |
| ② | **受任判断の情報** | 所内 → 所長 | 引き受けられるか（処理能力・利益相反・内容） | 案件発生時 |
| ③ | **契約情報** | 所長 ↔ 顧客 | 業務範囲・報酬・期間・解約・秘密保持 | 受任時 |
| ④ | **資料受領情報** | 顧客 → 担当者 | 何月分の、何を、何点受け取ったか | 月次 |
| ⑤ | **仕訳情報** | 入力担当 → 会計データ | 何が増えて何が減ったか | 月次 |
| ⑥ | **試算表情報** | 会計データ → 担当者 | 期首から今までの残高と損益 | 月次 |
| ⑦ | **月次報告情報** | 担当者 → 顧客 | 数字が何を意味しているか | 月次 |
| ⑧ | **質問・回答情報** | 担当者 ↔ 顧客 | 分からない取引の内容 | 月次／常時 |
| ⑨ | **決算整理情報** | 担当者 → 会計データ | 期末時点の正しい姿にするための調整 | 年次 |
| ⑩ | **決算書情報** | 担当者 → 顧客・行政 | 1年間の結果（貸借対照表・損益計算書） | 年次 |
| ⑪ | **申告書情報** | 担当者 → 有資格者 | 税額の計算結果 | 年次 |
| ⑫ | **有資格者のチェック情報** | 有資格者 → 担当者 | どこを直すか／承認するか | 年次 |
| ⑬ | **顧客の承認情報** | 顧客 → 事務所 | 内容を確認し、提出してよいという意思 | 年次 |
| ⑭ | **申告情報（電子申告）** | 事務所 → 行政 | 提出した申告の内容と、受け付けられた記録 | 法定・契約上のタイミング |
| ⑮ | **納税額の情報** | 事務所 → 顧客 | いくらを、いつまでに、どこへ納めるか | 年次／法定・契約上のタイミング |
| ⑯ | **控えの保管情報** | 事務所内 | 何を、どこに、いつまで残すか | 常時／年次 |

## 9-2. 受任までの情報（①〜③）

### ① 相談情報

| 項目 | 内容 |
|---|---|
| **誰から誰へ** | 顧客（または紹介者）→ 所長（⑤新規開拓・営業機能） |
| **何が含まれるか** | 会社か個人か／業種／規模（売上・従業員数）／経理の体制／帳簿の状態／いつから頼みたいか／**前任者がいるか、いた場合はなぜ変わるのか** |
| **どうやって入ってくるか** | 【Typical】紹介（金融機関・既存顧客・他士業）／電話・メール |
| **記録の形** | 問い合わせ記録／面談メモ（`04_end-to-end-process.md` A①②） |
| **頻度** | **問い合わせ時** |

> **なぜ「前任者がいるか」を聞くのか**
> 【Inference】前の事務所から変わる場合、**引継ぎに必要な情報がどこにあるか**が問題になります。
> 過去の決算書・申告書の控え、総勘定元帳、固定資産の一覧などが手元にあるかどうかで、
> 初期設定の作業量が変わります（`04_end-to-end-process.md` A⑧⑨）。
> （※変更の理由の内容そのものについて、本資料は論評しません。）

### ② 受任判断の情報

**これはこの業界に固有の情報です。**

| 何を確認するか | なぜ確認するか |
|---|---|
| **処理能力**（今の人員で受けられる量か） | 【Inference】期限は動かせないため、受けすぎると既存の顧問先の期限に影響する |
| **繁忙期との重なり** | 【Fact】所得税法第120条第1項の確定申告期・法人税法第74条第1項の2か月という期限は制度で決まっている |
| **業務の内容**（引き受けられる内容か） | 【Inference】申告書に署名するのは有資格者である（【Fact】税理士法第33条） |
| **利益相反の有無** | 【Typical】同じ案件の対立する双方から依頼を受けていないか、関係する顧問先がないか |

> **用語：利益相反（りえきそうはん）**
> → ある依頼を受けると、別の依頼者の利益と衝突してしまう状態のこと。
> → 実務例：ある会社と、その会社と取引上の争いがある別の会社の両方から、
> 　 同じ争いに関する依頼を受ける——といった場面が考えられます。
> → **なぜ確認するのか**：【Inference】どちらの側に立つかで、事務所が出すべき助言が変わります。
> 　 両方に対して誠実であることが構造的に難しくなります。
> 　 （※どの場面が利益相反に当たるかという個別の判断には、本資料は立ち入りません。）

- **誰が決めるか**：**所長（有資格者）。分担できません**（`06_people.md` 6-4 ①）。
- **頻度**：**案件発生時**。

### ③ 契約情報

| 項目 | 内容 |
|---|---|
| **どこに記録されるか** | **顧問契約書（委任契約書）**（`10_documents.md`／本セットの `pro_10`） |
| **何が書かれているか** | 【Typical】業務範囲／報酬（顧問料・決算料・スポット）／支払期日／契約期間／解約の方法／秘密保持 |
| **契約の性質** | 【Fact】民法第643条「委任は、当事者の一方が法律行為をすることを相手方に委託し、相手方がこれを承諾することによって、その効力を生ずる。」（出典：民法／e-Gov法令検索） |
| **どこへ流れるか** | ①顧客対応機能（担当者への引継ぎ）／⑥総務・経理機能（**請求の登録**。`05_departments.md` ⑥-1） |
| **頻度** | **受任時** |

> **★契約情報が請求情報になります**
> 【Inference】顧問料は毎月発生します（`08_money.md` 8-1）。
> その金額は契約で決まっています。
> だから契約情報が⑥総務・経理機能に渡らないと、**翌月の請求ができません。**
> `04_end-to-end-process.md` A⑥の「次に誰へ」に⑥総務・経理機能が入っているのは、このためです。

## 9-3. 毎月くり返す情報（④〜⑧）

### ④ 資料受領情報 — ★すべての起点

| 項目 | 内容 |
|---|---|
| **誰から誰へ** | 顧客（社長・経理担当者）→ 担当者（①顧客対応機能） |
| **何が含まれるか** | **どの顧問先の／何月分の／何を（通帳・領収書・請求書・給与明細等）／何点** |
| **記録の形** | **預り証**／受領記録（`07_goods.md` 7-6） |
| **何を確認するか** | **揃っているか。抜けている月・抜けている口座はないか**（`05_departments.md` ①-1） |
| **頻度** | **月次** |

#### なぜ「揃っているか」の確認が独立した業務になるのか

```
   通帳が3口座あるのに、2口座分しか来ていない
        → その口座の入出金が帳簿に入らない
        → 残高が合わない
        → 試算表が事実と違うものになる
        → 決算・申告の基礎が崩れる
```

【Inference】**抜けは、後の工程では見つけにくい**という性質があります。
無いものは、無いと分かりません。
だから受領の時点で「何月分の、どの口座が来ているか」を確認します。

#### 未着の管理（`05_departments.md` ①-2「未着資料の催促」）

| 段階 | 誰が | 何をするか | 頻度 |
|---|---|---|---|
| 1 | 担当者 | 未着の一覧を確認する | **月次** |
| 2 | 担当者 | 顧客に連絡する（電話・メール・訪問） | 月次 |
| 3 | 担当者 | 期限を示して再依頼する | 案件発生時 |
| 4 | **所長** | **どうするかを決める**（`06_people.md` 6-4 ⑤） | 案件発生時 |

> **★「未着一覧」という帳票が存在すること自体が、この業界の特徴です**
> 【Inference】製造業の「材料未入荷一覧」は、発注した相手（仕入先）に対する管理です。
> この業界の未着一覧は、**お金を払ってくれている顧客に対する管理**です。
> 催促する相手が顧客であるという点が、他業界と違います。
> （※だから催促しにくい、という論評はしません。事実として構造を記述します。）

### ⑤ 仕訳情報

| 項目 | 内容 |
|---|---|
| **誰が作るか** | 入力担当（②記帳代行・入力機能） |
| **何が含まれるか** | 日付／金額／**借方と貸方の勘定科目**／摘要（内容のメモ）／取引先 |
| **元になるもの** | 領収書・請求書・通帳のコピー・現金出納帳・給与明細 |
| **どこに入るか** | 会計ソフト（`11_systems.md`／本セットの `pro_11`） |
| **頻度** | **月次** |

> **用語：仕訳（しわけ）**
> → お金や物の動きを「何が増えて、何が減ったか」という形に翻訳した記録のこと。
> → 実務例：現金3,000円で文房具を買ったら「消耗品費3,000円／現金3,000円」と記録します【Example】。
> → **なぜするのか**：1年分の取引をこの形にそろえておくと、**足し算だけで決算書が作れる**ようになります。
>
> **用語：借方・貸方（かりかた・かしかた）**
> → 仕訳を書くときの左側（借方）と右側（貸方）のこと。
> → 実務例：上の例では「消耗品費」が借方、「現金」が貸方です。
> → **なぜ左右に分けるのか**：【Inference】1つの取引には必ず2つの面（何が増え、何が減ったか）があるため、
> 　 両方を書くことで記録に抜けが出にくくなります。

#### ★分からないものは、分からないまま止める

`05_departments.md` ②-7「不明点の洗い出しと保留（仮勘定）処理」

| 項目 | 内容 |
|---|---|
| **何をするか** | 内容の分からない入出金を、**推測で決めずに「保留」にする** |
| **なぜか** | 【Inference】入力担当は顧客に会いません。顧客の事情を知らずに推測すると、**帳簿が事実と違うものになります。** しかも後から見て、それが推測だったのか事実だったのか分からなくなります |
| **どこへ流れるか** | 担当者（⑧質問・回答情報へ） |
| **頻度** | 月次 |

> **用語：仮勘定（かりかんじょう）**
> → 内容が確定するまで、一時的に置いておくための勘定科目のこと。
> → 実務例：内容不明の入金10万円を「仮受金」として置き、後で内容が分かったら正しい科目に振り替えます。
> → **なぜ必要か**：金額だけは通帳に載っています。載っているものを無視すると残高が合いません。
> 　 **金額は記録しつつ、内容は未確定と示しておく**ための仕組みです。

### ⑥ 試算表情報

> **用語：試算表（しさんひょう）**
> → 期首から今日までの、すべての勘定科目の残高をまとめた表のこと。
> 　 正式には「合計残高試算表」と呼ばれます。
> → 実務例：「4月分の試算表ができました」＝4月末時点の貸借対照表と、
> 　 期首から4月末までの損益計算書ができた、という意味です。
> → **なぜ作るのか**：顧客が**年度の途中で自社の状況を知るため**です。
> 　 決算まで待つと、1年が終わってしまいます。

| 項目 | 内容 |
|---|---|
| **誰が作るか** | 担当者（会計ソフトから出力） |
| **何が含まれるか** | 貸借対照表（資産・負債・純資産の残高）／損益計算書（売上・費用・利益）／**推移表**（月ごとの並び） |
| **何を確認するか** | 通帳の残高と帳簿の残高が一致しているか／売上の計上漏れがないか／**前月と比べて不自然に増減している科目がないか** |
| **頻度** | **月次** |

> **なぜ「前月と比べる」のか**
> 【Inference】間違いは、絶対値では見つかりません。
> 「地代家賃が今月だけ2倍になっている」という**変化**が、入力の誤り（二重入力など）を示す手がかりになります。
> `05_departments.md` ①-5「試算表の確認」に対応します。

### ⑦ 月次報告情報

| 項目 | 内容 |
|---|---|
| **誰から誰へ** | 担当者 → 顧客（社長） |
| **何を伝えるか** | 今月の売上・利益／前月・前年との違い／資金の状況／**決算の見通し**／期限が近い手続 |
| **どこで伝えるか** | 【Varies】訪問（巡回監査）／来所／画面共有 |
| **記録の形** | **月次報告書**【Varies】／打合せの記録 |
| **頻度** | **月次** |

> **用語：巡回監査（じゅんかいかんさ）**
> → 担当者が**月次**で顧問先を訪問し、帳簿や証憑を確認する業務のこと。
> → 実務例：毎月、顧問先に行って通帳と帳簿の残高が合っているかを確認し、
> 　 「この支出は何ですか」と聞いて内容を確かめます。
> → 【Varies】この呼び方・やり方は事務所や所属する団体により異なります。
> 　 訪問せず来所や画面共有で行う場合もあります。
> （`03_company-structure.md` 3-4 ①と同じ記述です）

> **★なぜ「数字を渡す」だけでは終わらないのか**
> 【Inference】試算表は数字の一覧です。
> 顧客の多くは会計の専門家ではありません。
> **「売上が前年より落ちている」「この費用が増えている」という意味の説明**が無いと、
> 顧客は自社の状況を把握できません。
> `03_company-structure.md` 3-4 ①の「顧客は数字を見ただけでは意味が分かりません」に対応します。

### ⑧ 質問・回答情報

**この情報が、④〜⑦の流れを往復します。**

```
   ⑤仕訳情報（入力中に不明点が出る）
        │
        ▼
   担当者が **質問リスト** を作る
        │
        ▼
   顧客に照会 ──▶ 顧客が回答 ──▶ 仕訳を確定 ──▶ ⑥試算表情報へ
        │
        └─ **回答が来ないと、確定できない**
```

| 項目 | 内容 |
|---|---|
| **誰が作るか** | 担当者（`05_departments.md` ①-4） |
| **何が含まれるか** | 日付・金額・相手先・「これは何の支出ですか」という問い |
| **誰が答えるか** | 【Typical】経理担当者が答えられるものと、**社長本人しか答えられないもの**がある |
| **★資格の線** | **内容が税務上の判断を求めるものである場合、回答は有資格者の判断事項になる**（9-4） |
| **頻度** | **月次**（入力に伴うもの）／**常時**（顧客からの相談） |

> **なぜ「リスト」にするのか**
> 【Inference】1件ずつ電話すると、顧客の手間が増え、聞き漏れも起きます。
> まとめて渡し、顧客が手元の資料を見ながら答えられるようにするためです。
> また、**聞いたこと・答えてもらったことの記録が残ります**（`06_people.md` 6-6）。

## 9-4. ★税務相談に当たる情報は、誰が扱うのか

**⑧質問・回答情報の中に、資格の線が走っています。**

【Fact】税理士法第2条第1項第3号（出典：税理士法／e-Gov法令検索）

> 「三　**税務相談**（税務官公署に対する申告等、第一号に規定する主張若しくは陳述又は
> 申告書等の作成に関し、租税の課税標準等（…）の計算に関する事項について相談に応ずることをいう。）」

【Fact】税理士法第52条（税理士業務の制限）

> 「税理士又は税理士法人でない者は、この法律に別段の定めがある場合を除くほか、
> 税理士業務を行つてはならない。」（出典：税理士法／e-Gov法令検索）

【Fact】税理士法第41条の2（使用人等に対する監督義務）

> 「税理士は、税理士業務を行うため使用人その他の従業者を使用するときは、
> 税理士業務の適正な遂行に欠けるところのないよう当該使用人その他の従業者を監督しなければならない。」
> （出典：税理士法／e-Gov法令検索）

### 情報の流れとしてどう現れるか

```
   顧客からの質問
        │
        ├─ 事実の確認（「この入金は何ですか」）
        │      → 担当者が聞き、担当者が記録する
        │
        └─ 税務上の判断を求めるもの
               → **担当者は所長・勤務税理士に確認する**
               → 有資格者の判断として顧客に伝える
```

- **頻度**：**常時**。
- **【Example】X会計事務所での実際**：担当者Kさんは、社長から設備投資の相談を受けたとき、
  **その場で答えず、所長に確認してから回答しました**（`06_people.md` 6-7 の8月）。

> **本資料の姿勢（`03_company-structure.md` 3-5 と同じ）**
> どこまでが「相談に応ずること」に当たるかという線引きは、**個別の事案ごとの法的判断**になります。
> **本資料は個別の適法性の判断には立ち入りません。**
> ここで押さえるべきは、**情報の流れの中に、有資格者を通さなければならない経路がある**という点です。

## 9-5. ★守秘義務 — 士業ごとに根拠条文が違います

`common/methodology.md` §2 の鉄則に従い、**法律ごとに分けて、条文の語をそのまま引用します。**
**まとめて要約しません。**

### ① 税理士法

【Fact】税理士法第38条（秘密を守る義務）

> 「税理士は、正当な理由がなくて、税理士業務に関して知り得た秘密を他に洩らし、又は窃用してはならない。
> 税理士でなくなつた後においても、また同様とする。」（出典：税理士法／e-Gov法令検索）

- 条文の語は「**洩らし、又は窃用**」。
- 「**税理士でなくなつた後においても、また同様とする**」——**資格を失った後も続きます。**
- **主語は「税理士は」**です。職員については、同法第41条の2が税理士に監督義務を課す形になっています。

【Fact】税理士法第59条第1項第3号・第2項

> 「第五十九条　次の各号のいずれかに該当する場合には、その違反行為をした者は、
> 二年以下の拘禁刑又は百万円以下の罰金に処する。
> …三　第三十八条（第五十条第二項において準用する場合を含む。）又は第五十四条の規定に違反したとき。
> …２　**前項第三号の罪は、告訴がなければ公訴を提起することができない。**」
> （出典：税理士法／e-Gov法令検索）

> **用語：親告罪（しんこくざい）**
> → 被害者などの告訴がなければ、検察官が起訴できない犯罪のこと。
> → 実務例：税理士法第59条第2項が「前項第三号の罪は、告訴がなければ公訴を提起することができない」と
> 　 定めているため、第38条違反はこの類型に当たります。
> → **なぜこの形なのか**：【Inference】起訴すること自体が、守られるべき秘密を公にしてしまう場合があるためと解されますが、
> 　 本資料はここに立ち入りません。**条文にそう書かれている**という事実のみを記します。

### ② 社会保険労務士法（★職員に対する条文が別にあります）

【Fact】社会保険労務士法第21条（秘密を守る義務）

> 「開業社会保険労務士又は社会保険労務士法人の社員は、正当な理由がなくて、
> その業務に関して知り得た秘密を他に漏らし、又は盗用してはならない。
> 開業社会保険労務士又は社会保険労務士法人の社員でなくなつた後においても、また同様とする。」
> （出典：社会保険労務士法／e-Gov法令検索）

【Fact】社会保険労務士法第27条の2（開業社会保険労務士の使用人等の秘密を守る義務）

> 「開業社会保険労務士又は社会保険労務士法人の使用人その他の従業者は、正当な理由がなくて、
> その業務に関して知り得た秘密を他に漏らし、又は盗用してはならない。
> 開業社会保険労務士又は社会保険労務士法人の使用人その他の従業者でなくなつた後においても、また同様とする。」
> （出典：社会保険労務士法／e-Gov法令検索）

> **★税理士法との違いを正確に押さえてください**
>
> | | 税理士法 | 社会保険労務士法 |
> |---|---|---|
> | **有資格者本人** | 第38条「税理士は」 | 第21条「開業社会保険労務士又は社会保険労務士法人の社員は」 |
> | **職員（無資格者）** | **直接の義務規定を置かず、第41条の2で税理士に監督義務を課す** | **第27条の2で、使用人その他の従業者に直接義務を課す** |
> | 条文の語 | 「洩らし、又は窃用」 | 「漏らし、又は盗用」 |
>
> **義務の掛け方の構造が違います。** 一文にまとめてはいけません。

### ③ 行政書士法

【Fact】行政書士法第12条（秘密を守る義務）

> 「行政書士は、正当な理由がなく、その業務上取り扱つた事項について知り得た秘密を漏らしてはならない。
> 行政書士でなくなつた後も、また同様とする。」（出典：行政書士法／e-Gov法令検索）

- 条文の語は「**漏らしてはならない**」。**「窃用」「盗用」に当たる語はありません。**

### ④ 司法書士法

【Fact】司法書士法第24条（秘密保持の義務）

> 「司法書士又は司法書士であつた者は、**正当な事由がある場合でなければ**、
> 業務上取り扱つた事件について知ることのできた秘密を他に漏らしてはならない。」
> （出典：司法書士法／e-Gov法令検索）

- 条文の語は「**正当な事由**」です。
  税理士法第38条・社会保険労務士法第21条・行政書士法第12条は「**正当な理由**」です。
- 主語が「**司法書士又は司法書士であつた者**」と、**現在と過去の両方を1つの主語**に含めています。

### ⑤ 弁護士法

【Fact】弁護士法第23条（秘密保持の権利及び義務）

> 「弁護士又は弁護士であつた者は、その職務上知り得た秘密を保持する**権利を有し、義務を負う**。
> 但し、法律に別段の定めがある場合は、この限りでない。」（出典：弁護士法／e-Gov法令検索）

> **★この条文は「権利」と書いています**
> 他の士業法は義務のみを定めていますが、**弁護士法第23条は「権利を有し、義務を負う」**と書いています。
> **条文の作りが違います。** これを他の士業と同じものとして要約してはいけません。

### ⑥ 公認会計士法

【Fact】公認会計士法第27条（秘密を守る義務）

> 「公認会計士は、正当な理由がなく、その業務上取り扱つたことについて知り得た秘密を他に漏らし、
> 又は盗用してはならない。公認会計士でなくなつた後であつても、同様とする。」
> （出典：公認会計士法／e-Gov法令検索）

### ⑦ 6つの条文を並べて見る

| 法律 | 条 | 主語 | 禁止されている行為の語 | 「正当な」の語 | 資格を失った後 |
|---|---|---|---|---|---|
| **税理士法** | 第38条 | 税理士は | **洩らし、又は窃用** | 正当な**理由** | 「税理士でなくなつた後においても、また同様とする」 |
| **社会保険労務士法** | 第21条 | 開業社会保険労務士又は社会保険労務士法人の社員は | **漏らし、又は盗用** | 正当な**理由** | 「…でなくなつた後においても、また同様とする」 |
| **社会保険労務士法** | **第27条の2** | **使用人その他の従業者は** | **漏らし、又は盗用** | 正当な**理由** | 「…でなくなつた後においても、また同様とする」 |
| **行政書士法** | 第12条 | 行政書士は | **漏らしてはならない** | 正当な**理由** | 「行政書士でなくなつた後も、また同様とする」 |
| **司法書士法** | 第24条 | 司法書士**又は司法書士であつた者**は | **漏らしてはならない** | 正当な**事由** | 主語に含まれている |
| **弁護士法** | 第23条 | 弁護士**又は弁護士であつた者**は | 秘密を保持する**権利を有し、義務を負う** | （「但し、法律に別段の定めがある場合」） | 主語に含まれている |
| **公認会計士法** | 第27条 | 公認会計士は | **漏らし、又は盗用** | 正当な**理由** | 「公認会計士でなくなつた後であつても、同様とする」 |

（いずれも出典：各法／e-Gov法令検索）

> **★この表を一文にまとめてはいけません**
> 「士業には守秘義務がある」という要約は、次の違いを消してしまいます。
> ・**社会保険労務士法には、無資格の職員に対する直接の義務規定（第27条の2）がある。税理士法には無い。**
> ・**司法書士法第24条は「正当な事由」、他は「正当な理由」。**
> ・**弁護士法第23条は「権利」と「義務」の両方を書いている。**
> ・**税理士法第38条は「窃用」、社会保険労務士法・公認会計士法は「盗用」、行政書士法・司法書士法はこれらの語を置いていない。**

### ⑧ 個人情報保護法との関係（別の法律です）

**守秘義務とは別に、個人情報の取扱いに関する法律があります。**

【Fact】個人情報の保護に関する法律 第23条（安全管理措置）

> 「個人情報取扱事業者は、その取り扱う個人データの漏えい、滅失又は毀損の防止その他の
> 個人データの安全管理のために必要かつ適切な措置を講じなければならない。」
> （出典：個人情報の保護に関する法律／e-Gov法令検索）

【Fact】同法第27条第1項（第三者提供の制限）

> 「個人情報取扱事業者は、次に掲げる場合を除くほか、あらかじめ本人の同意を得ないで、
> 個人データを第三者に提供してはならない。
> 一　法令に基づく場合 …」（出典：個人情報の保護に関する法律／e-Gov法令検索）

【Fact】同法第26条第1項（漏えい等の報告等）

> 「個人情報取扱事業者は、その取り扱う個人データの漏えい、滅失、毀損その他の個人データの安全の確保に
> 係る事態であって個人の権利利益を害するおそれが大きいものとして個人情報保護委員会規則で定めるものが
> 生じたときは、個人情報保護委員会規則で定めるところにより、
> 当該事態が生じた旨を個人情報保護委員会に報告しなければならない。…」
> （出典：個人情報の保護に関する法律／e-Gov法令検索）

> **★守秘義務と個人情報保護法は、別の法律による、別の義務です**
> ・守秘義務（税理士法第38条 等）＝**その士業に課された義務**。対象は「業務に関して知り得た秘密」。
> ・個人情報保護法＝**個人情報を取り扱うすべての事業者**に課される義務。対象は「個人データ」。
>
> 【Inference】事務所が扱う情報には、**会社の情報**（秘密ではあるが個人情報ではないもの）と、
> **個人の情報**（従業員の氏名・生年月日・給与額など）の両方があります。
> 社労士事務所では後者の比重が大きくなります（`07_goods.md` 7-1）。
> ※具体的な該当性の判断には、本資料は立ち入りません。

## 9-6. 顧客の情報が、そのまま事務所の預かり物になる重さ

### どの範囲の情報を、事務所は知ることになるか

| 事務所が知る情報 | それは顧客にとって何か |
|---|---|
| 売上・利益 | 会社の実力。取引先にも従業員にも明かしていない場合がある |
| 借入金の残高・返済の状況 | 会社の資金の余力 |
| **従業員一人ひとりの給与額** | 従業員本人以外には知られたくない情報 |
| 役員報酬 | 社長自身の収入 |
| **社長個人の資産・家族の状況**（相続・贈与の場面）【Varies】 | 家庭の事情 |
| 取引先ごとの売上・未回収 | 取引関係の実態 |
| 赤字であること、資金が不足していること | 【Inference】外部に知られると取引に影響しうる情報 |

> **★事務所は「会社の中で最も知っている外部者」になります**
> 【Inference】従業員は自分の給与しか知りません。
> 取引先は自分との取引しか知りません。
> 金融機関は決算書という完成品しか見ません。
> **通帳の1行目から全部を見ているのは、社長と、事務所の担当者です。**
>
> だからこの業界では、守秘義務が**法律上の義務**として置かれ、
> **資格を失った後も続く**という形になっています（9-5）。

### 情報が事務所の中でどう扱われるか【Typical】

| 場面 | どう扱われるか | なぜ |
|---|---|---|
| **所内での会話** | 【Typical】顧問先名を出す範囲を限る運用がある【Varies】 | 来客・電話中の相手に聞こえうる【Inference】 |
| **担当外の顧問先の情報** | 【Varies】アクセスを限る運用がある | 必要のない者が見る理由が無い【Inference】 |
| **持ち出し** | 施錠できる鞄、持ち出し記録【Varies】 | `07_goods.md` 7-2 |
| **画面** | 【Varies】離席時の画面ロック等 | 来客の目に触れうる【Inference】 |
| **廃棄** | シュレッダー（`05_departments.md` ②N） | 控えにも秘密が含まれる |
| **退職するとき** | 【Fact】税理士法第38条は「税理士でなくなつた後においても」と定める。社会保険労務士法第27条の2は「使用人その他の従業者でなくなつた後においても」と定める | **辞めても義務は続く** |

（`05_departments.md` ⑥-11「守秘義務の体制の管理」）

### 情報を外に出す場面

| 場面 | 誰に | どう扱われるか |
|---|---|---|
| **金融機関への決算書の提出** | 金融機関 | 【Typical】顧客の依頼・同意に基づいて行われる。**顧客自身が提出する形もある**（`06_people.md` 6-7 の9月） |
| **他士業との連携** | 社労士・司法書士 等 | 【Typical】必要な範囲に限って共有される |
| **税務署への申告** | 行政 | 【Fact】法令に基づく提出 |
| **税務調査への対応** | 行政 | 【Fact】税理士法第2条第1項第1号（税務代理）／第34条（調査の通知） |

> **※本資料は、どの場面でどこまで出してよいかという個別の判断には立ち入りません。**
> 「**顧客の情報を外に出す場面が、業務の中に組み込まれている**」という構造の記述にとどめます。

| **誰が作るか** | 担当者（③）。小規模事務所では所長 |
| **何が含まれるか** | 課税所得の計算／税額の計算／各種の明細（勘定科目内訳明細書、事業概況説明書 等） |
| **どこへ流れるか** | **⑫有資格者のチェック情報へ** |
| **頻度** | **年次** |

### ⑫ ★有資格者のチェック情報 — 分担できない経路

| 項目 | 内容 |
|---|---|
| **誰が行うか** | **有資格者（所長・勤務税理士）。分担できません** |
| **何を見るか** | 決算書・申告書の内容 |
| **何が出てくるか** | **承認**、または**差し戻しの指示**（どこをどう直すか） |
| **根拠** | 【Fact】税理士法第33条第1項「税理士又は税理士法人が税務代理をする場合において、租税に関する申告書等を作成して税務官公署に提出するときは、当該税務代理に係る税理士は、当該申告書等に署名しなければならない。」（出典：税理士法／e-Gov法令検索） |
| **頻度** | **年次**（顧問先ごとの決算・申告のたび） |

> **★情報の流れとして見たときの意味**
> 【Inference】この工程は、**情報が必ず1つの点を通る**という形をつくります。
> 【Example】X会計事務所では120件すべてがここを通ります。有資格者は2名です。
> **情報の流量に対して、通過点の幅が固定されている**——これが繁忙期の負荷の集中の理由です
> （`03_company-structure.md` 3-7）。

【Fact】税理士法第33条第3項

> 「税理士は、前二項の規定により署名するときは、税理士である旨その他財務省令で定める事項を
> 付記しなければならない。」（出典：税理士法／e-Gov法令検索）

### ⑬ 顧客の承認情報

| 項目 | 内容 |
|---|---|
| **誰から誰へ** | 顧客（社長）→ 事務所 |
| **何が含まれるか** | 決算内容と税額を確認したこと／提出してよいという意思 |
| **形** | 【Typical】説明のうえ、申告書等への署名・押印。【Varies】電子的な承認の形もある |
| **根拠** | 【Fact】税理士法第33条第1項後段「…この場合において、当該申告書等が租税の課税標準等に関する申告書又は租税に関する法令の規定による還付金の還付の請求に関する書類であるときは、当該申告書等には、併せて本人（その者が法人又は法人でない社団若しくは財団で代表者若しくは管理人の定めがあるものであるときは、その代表者又は管理人）が署名しなければならない。」（出典：税理士法／e-Gov法令検索） |
| **頻度** | **年次** |

> **★条文が「併せて本人が署名しなければならない」と定めています**
> 税理士が署名するだけでは終わりません。
> **本人（法人であればその代表者）も署名する**と条文に書かれています。
> 【Inference】つまり「事務所が作って事務所が出す」のではなく、
> **顧客自身の申告である**という構造が、条文の中に現れています。
> この点は `16_glossary.md`（本セットの `pro_16`）の「間違えやすいこと」で改めて扱います。

### ⑭ 申告情報（電子申告）

| 項目 | 内容 |
|---|---|
| **誰が行うか** | **有資格者**（`05_departments.md` ④-4） |
| **どこへ** | 国税（e-Tax）／地方税（eLTAX） |
| **何が返ってくるか** | **受信通知**——提出が受け付けられたことの記録 |
| **期限** | 【Fact】法人税法第74条第1項「各事業年度終了の日の翌日から二月以内」／消費税法第45条第1項「当該課税期間の末日の翌日から二月以内」／所得税法第120条第1項「第三期（その年の翌年二月十六日から三月十五日までの期間をいう。）」（出典：各法／e-Gov法令検索） |
| **頻度** | **法定・契約上のタイミング** |

> **なぜ受信通知を確認するのか**
> 【Inference】送信した「つもり」と、受け付けられたことは別です。
> **受け付けられた記録が無ければ、期限内に提出した証拠がありません。**
> 期限は動かないため（【Fact】上記各条）、ここの確認が最後の関門になります。

【Fact】税理士法第30条（税務代理の権限の明示）

> 「税理士は、税務代理をする場合においては、財務省令で定めるところにより、
> その権限を有することを証する書面を税務官公署に提出しなければならない。」
> （出典：税理士法／e-Gov法令検索）

## 9-8. 「揃わないと進めない」を図で見る

```
  ④資料受領情報
     │
     ├─ 揃っている ────▶ ⑤仕訳 ─▶ ⑥試算表 ─▶ ⑦月次報告 ─▶（決算へ）
     │
     └─ 揃っていない
            │
            ├─ 一部だけ入力する（保留を残す）
            │      → ⑥試算表は**未確定のまま**出る
            │      → ⑦月次報告で「まだ確定ではない」と説明することになる【Typical】
            │
            └─ 催促する（①-2）→ それでも来ない → **所長が判断する**
                                                    │
                                    ┌───────────────┴────────────────┐
                                    │  ・ある資料だけで決算・申告を進めるか   │
                                    │  ・期限との関係をどう説明するか         │
                                    │  ・契約そのものをどうするか             │
                                    └────────────────────────────────┘
                                         ※個別の対応の適否には立ち入りません
```

### 情報が滞る場所と、その影響

| 滞る場所 | 何が起きるか | どこで見つけるか |
|---|---|---|
| ④資料が来ない | 全工程が止まる | **未着資料の一覧**（月次） |
| ⑤入力が終わらない | 試算表が出ない | **入力完了率**（`05_departments.md` ②O） |
| ⑧質問の回答が来ない | 仕訳が確定しない | **保留項目の未解決件数**（同） |
| ⑨決算資料が来ない | 決算整理ができない | 決算資料の依頼リストの回収状況（`05_departments.md` ①-9） |
| ⑫チェックが終わらない | 申告できない | **チェック待ちの件数**（`05_departments.md` ③O） |
| ⑬顧客の承認が取れない | 申告できない | 決算報告の実施状況 |

> **★最後の2つは、期限の直前に効いてきます**
> 【Inference】⑫⑬はどちらも**人の時間**に依存します。
> 有資格者の時間と、社長の時間です。
> どちらも繁忙期には取りにくくなります。
> `14_kpi.md`（本セットの `pro_14`）で「申告期限の遵守率」を見る理由がここにあります。

## 9-9. 社労士事務所の情報の流れはどう違うか（【Example】Y社会保険労務士事務所）

| 比較の軸 | X会計事務所（税理士） | Y社労士事務所（社会保険労務士） |
|---|---|---|
| **情報の起点** | **毎月、前月分の資料が届くこと** | **顧客の従業員に何かが起きたという連絡** |
| **扱う情報の中身** | 会社のお金の記録 | **従業員個人の情報**（氏名・生年月日・給与額・入退社・傷病） |
| **情報の相手** | 社長・経理担当者 | 社長・総務担当者・**従業員本人**【Varies】 |
| **提出先** | 税務署・都道府県・市町村 | 年金事務所・労働基準監督署・ハローワーク |
| **職員の守秘義務** | 【Fact】税理士法第41条の2（税理士の監督義務） | 【Fact】社会保険労務士法**第27条の2**（使用人その他の従業者に直接の義務） |
| **個人情報保護法との関係** | 【Inference】会社の情報が中心だが、給与関係で個人情報も扱う | 【Inference】**個人情報が業務の中心**になる |

> **★同じ「情報を扱う仕事」でも、情報の性質が違います**
> 【Inference】税理士事務所の情報は**会社の秘密**が中心です。
> 社労士事務所の情報は**個人の秘密**が中心です。
> だから社会保険労務士法には、**職員に対する直接の守秘義務の条文（第27条の2）**が置かれています。
> **この違いを「士業には守秘義務がある」と要約してはいけません。**

## 9-10. まとめ：この章で押さえるべき8点

1. **この業界では、情報が材料であり、情報が製品である。** モノは介在しない。
2. **情報は16種類に分けて名前を付けられる**——相談／受任判断／契約／資料受領／仕訳／試算表／月次報告／
   質問・回答／決算整理／決算書／申告書／**有資格者のチェック**／顧客の承認／申告（電子申告）／
   納税額／控えの保管。
3. **すべての起点は「資料受領情報」。揃わないと右側の全部が止まる。**
   だから「未着資料の一覧」が、この業界の中心的な管理帳票になる。
4. **顧客の資料が来なくても、法律上の期限は来る。**
   だから「揃わないときにどうするか」が独立した判断として存在する（A＝所長）。
5. **質問・回答情報の中に、資格の線が走っている。**
   【Fact】税理士法第2条第1項第3号（税務相談）・第52条・第41条の2。
6. **守秘義務は士業ごとに根拠条文が違う。まとめて要約してはいけない。**
   **社会保険労務士法第27条の2は、無資格の職員に直接義務を課している。税理士法には対応する規定が無く、
   第41条の2で税理士に監督義務を課す形になっている。**
   司法書士法第24条は「正当な**事由**」、他は「正当な**理由**」。
   弁護士法第23条は「**権利を有し、義務を負う**」と書いている。
7. **守秘義務と個人情報保護法は、別の法律による別の義務である。**
8. **事務所は「会社の中で最も知っている外部者」になる。**
   だから義務は、資格を失った後も続く。
