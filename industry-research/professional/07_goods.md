# 07_goods.md — モノの流れ（専門サービス業）

**対象**：日本国内の中小の専門サービス業（主モデル：税理士事務所／対比：社会保険労務士事務所）
**読み手**：専門サービス業をまったく知らない人
**前提**：`03_company-structure.md` の**【Example】X会計事務所**（9名／顧問先120件／年商7,000万円。架空）
**最終更新**：2026-09-20

---

## 7-0. ★最初に読んでください — この業界に、商品としてのモノは存在しません

`common/methodology.md` §6 は、「モノの流れ」について次のように定めています。

> 「物理的なモノが主要でない業界（サービス業等）は**無理に作らない**。
> 　代わりに『何が価値の実体か』を書く」

**専門サービス業は、まさにこれに当たります。**

### 何が無いのかを、はっきり書きます

| 他の業界にあるもの | 専門サービス業では |
|---|---|
| **原材料** | **無い**。仕入れるモノが無い |
| **仕掛品** | **無い**（作業途中の申告書は「モノ」ではなく情報） |
| **完成品（商品）** | **無い**。売っているのは知識・資格・信用（`01_overview.md` 1-8） |
| **在庫** | **無い**。したがって棚卸も、在庫評価も、倉庫も無い |
| **仕入先** | **無い**（ソフトウェアや事務用品の購入先はあるが、それは商品の仕入ではない） |
| **物流・配送** | **無い**。トラックも倉庫も出てこない |
| **工場・生産設備** | **無い**。あるのは事務所と机とパソコン |

> **なぜ「無い」とはっきり書くのか**
> 【Inference】他の業界の資料と同じ目次で読むと、
> 「在庫管理はどうしているのか」「仕入はどこからか」という問いが自然に出てきます。
> **この業界では、その問い自体が成立しません。**
> 空欄にせず「存在しない」と理由付きで書くのが、`common/methodology.md` §9 の求めるところです。

### では、何が動いているのか

**物理的に動くモノは、確かに存在します。ただし、それは商品ではありません。**

```
  ┌──────────────────────────────────────────────────────┐
  │  専門サービス業で物理的に動く「モノ」は、2種類しかない         │
  └──────────────────────────────────────────────────────┘

   ① 顧客から預かるもの（＝顧客の財産であり、顧客の秘密）
        通帳・領収書・請求書・契約書・証明書・印鑑 等
                    │
                    ▼  （事務所の中で情報に変換される）
   ② 事務所が作って渡す／提出するもの
        試算表・決算書・申告書・各種届出書・控え
```

**①は顧客のモノです。事務所のモノではありません。**
**②は事務所が作りますが、中身は顧客の情報です。**

つまりこの業界の「モノの流れ」とは、**商品の流れではなく、
顧客の財産と顧客の情報を、預かり・変換し・返す流れ**です。

### この章で扱うこと

1. **預り資料**（7-1〜7-4）——何を預かるか、どう管理するか、なくしたらどうなるか
2. **作成して提出する書類**（7-5）——何を作り、どこへ出すか
3. **受渡しの記録**（7-6）——いつ何を預かり、いつ返したか
4. **電子データでの受渡し**（7-7）【Varies】
5. **保存義務**（7-8）——**顧客側の義務と、事務所側の義務は別物**
6. **事務所が持っているモノ**（7-9）——机・書庫・パソコン等

## 7-1. 顧客から預かるもの（預り資料）の全体像

### 何を預かるのか

【Typical】税理士事務所が顧問先から預かる主なものです。
`05_departments.md` ①-1／②-1 に業務としての記述があります。ここでは**モノ**として整理します。

| 預かるもの | 何が書かれているか | いつ預かるか | 再発行できるか |
|---|---|---|---|
| **預金通帳（またはコピー）** | 入出金の記録 | 月次 | 通帳そのものは金融機関が再発行しうる。**ただし取引の記録の復元には手続と時間がかかる**【Inference】 |
| **領収書** | 何にいくら払ったか | 月次 | **原則として再発行されないものがある**【Typical】 |
| **請求書（受け取ったもの）** | 取引先からいくら請求されたか | 月次 | 取引先に依頼すれば再発行されうる【Varies】 |
| **請求書の控え（自社が出したもの）** | 自社がいくら請求したか | 月次 | 自社の控えなので再作成できる場合が多い【Varies】 |
| **現金出納帳** | 現金の増減の記録 | 月次 | 顧客が書いたもの。**手書きなら複製が無ければ復元できない**【Inference】 |
| **クレジットカードの明細** | カードで払った内容 | 月次 | カード会社から再発行されうる【Varies】 |
| **給与の支給明細・賃金台帳** | 誰にいくら払い、いくら預かったか | 月次 | 顧客の給与システムから再出力されうる【Varies】 |
| **契約書** | 取引の条件 | 案件発生時 | **相手方の同意がなければ作り直せない**【Inference】 |
| **借入金の返済予定表・残高証明** | いくら借り、いくら残っているか | 年次／案件発生時 | 金融機関から再発行されうる |
| **保険証券** | 保険の内容 | 年次／案件発生時 | 保険会社から再発行されうる |
| **棚卸表** | 期末の在庫の実数 | 年次（決算時） | **その時点でしか数えられない。後から作り直せない**【Inference】 |
| **登記事項証明書・印鑑証明書** | 会社の登記内容・実印の証明 | 案件発生時 | 法務局で再取得できる（手数料と時間がかかる） |
| **実印・代表者印**（預かる場合）【Varies】 | — | 案件発生時 | **再発行という概念が無い。紛失は改印手続になる**【Inference】 |
| **過去の決算書・申告書の控え** | 前の事務所が作ったもの | 受任時 | **前任者や税務署に頼らなければ入手できない場合がある**【Inference】 |

### 【Example】1か月にX会計事務所へ集まるモノの量（架空の設定）

> **架空の数値です。実在の事務所の実績ではありません。**

| 項目 | 【Example】設定値 |
|---|---|
| 顧問先 | 120件 |
| うち月次で資料を預かる先 | 約100件（残り20件は顧客が自社で入力、または年1回のみ）【Varies】 |
| 1件あたりの領収書・請求書 | 平均80枚 |
| **1か月に事務所へ入ってくる紙の枚数** | **約8,000枚** |
| 保管場所 | 施錠できる書庫・キャビネット（`05_departments.md` ②N） |

> **この数字から読み取ってほしいこと**
> 【Inference】8,000枚の紙は、**すべて他人の財産であり、他人の秘密**です。
> 事務所の中に、自分のモノはほとんどありません。
> 【Fact】税理士法第38条（秘密を守る義務）は
> 「税理士は、正当な理由がなくて、税理士業務に関して知り得た秘密を他に洩らし、又は窃用してはならない。
> 税理士でなくなつた後においても、また同様とする。」と定めています（出典：税理士法／e-Gov法令検索）。
> **机の上の紙の束の管理は、この条文の具体的な現れです。**

### 社労士事務所が預かるもの（【Example】Y社会保険労務士事務所）

`03_company-structure.md` 3-3 のとおり、**預かるモノの中身が違います。**

| Y社労士事務所が預かるもの | 何が書かれているか |
|---|---|
| 従業員の氏名・生年月日・住所・マイナンバー【Varies】 | 手続に必要な個人の情報 |
| 入社・退社の情報、雇用契約書 | いつ誰が入り、いつ誰が辞めたか |
| 勤怠データ（出勤簿・タイムカード） | 誰が何時間働いたか |
| 給与額・賞与額の資料 | 保険料の計算の基礎 |
| 健康保険証（返却・再交付の場面）【Varies】 | 本人の資格 |
| 年金手帳・基礎年金番号の資料【Varies】 | 本人の年金の記録 |
| 母子健康手帳の写し（育児の手続）【Varies】 | 出産・育児の事実 |

> **★中身の性質が違います**
> 税理士事務所が預かるのは**会社のお金の記録**です。
> 社労士事務所が預かるのは**従業員個人の情報**です。
> 【Fact】個人情報保護法第23条（安全管理措置）は
> 「個人情報取扱事業者は、その取り扱う個人データの漏えい、滅失又は毀損の防止その他の
> 個人データの安全管理のために必要かつ適切な措置を講じなければならない。」と定めています
> （出典：個人情報の保護に関する法律／e-Gov法令検索）。
> 詳細は `09_information.md`（本セットの `pro_09`）と `15_rules-customs.md`（同 `pro_15`）で扱います。

## 7-2. ★預り資料の管理責任 — 紛失したら再発行できないものがある

**この節が、このファイルで最も重要です。**

### 事務所にとって、預り資料は「借り物」である

【Fact】民法第646条第1項（受任者による受取物の引渡し等）

> 「受任者は、委任事務を処理するに当たって受け取った金銭その他の物を委任者に引き渡さなければならない。
> その収取した果実についても、同様とする。」（出典：民法／e-Gov法令検索）

【Fact】民法第644条（受任者の注意義務）

> 「受任者は、委任の本旨に従い、善良な管理者の注意をもって、委任事務を処理する義務を負う。」
> （出典：民法／e-Gov法令検索）

> **用語：善管注意義務（ぜんかんちゅういぎむ）**
> → 民法第644条の「善良な管理者の注意」を短く呼んだ言い方のこと。
> → 実務例：預かった通帳を机の上に置きっぱなしにして帰る、鞄ごと電車に置き忘れる、といった扱いは、
> 　 この義務との関係が問われます。
> → **なぜこの義務があるのか**：委任は「任せる」契約です。
> 　 任せた側は、任された側がどう扱っているかを見ていられません。
> 　 だから**見ていなくても大丈夫な水準の注意**を、法律が受任者に求めています。

### 再発行できるものと、できないものを分けて考える

```
  預り資料
      │
      ├─ 再取得できるもの（手数料・時間はかかる）
      │     登記事項証明書、印鑑証明書、残高証明、保険証券、
      │     カード明細、金融機関の取引明細 など
      │
      └─ ★再取得が難しい／できないもの
            ・領収書（発行者が再発行しない場合がある）【Typical】
            ・手書きの現金出納帳（控えが無ければ復元できない）
            ・契約書の原本（相手方の同意が要る）
            ・棚卸表（その日にしか数えられない）
            ・実印・代表者印（紛失は改印の手続になる）
            ・相続の場面の戸籍・遺産分割協議書の原本 等【Varies】
```

> **★この区別が、なぜ実務で効いてくるのか**
> 【Inference】再取得できるものを失くしても、時間と費用で取り戻せます。
> **再取得できないものを失くすと、取り戻す方法がありません。**
> 領収書が無ければ、その支出があったことを示す資料が無くなります。
> 棚卸表が無ければ、期末の在庫の数が分からなくなります。
> だから事務所は、**紙の束を「情報」ではなく「壊れたら戻らないモノ」として扱います。**

### 【Example】紛失が起きたらどうなるか（説明のための架空の例）

> **架空の例です。実在の事案ではありません。**

X会計事務所の担当者Kさんが、Z商事から4月分の資料（通帳コピー・領収書82枚）を預かり、
鞄に入れて次の訪問先へ向かいました。その移動中に鞄を紛失したとします。

| 起きること | なぜか |
|---|---|
| **領収書82枚が戻らない可能性がある** | 発行者に再発行を依頼しても応じられない場合がある【Typical】 |
| **顧客の秘密が外部に出た可能性が生じる** | 【Fact】税理士法第38条の問題になる |
| **顧客の従業員の個人情報が含まれていれば** | 【Fact】個人情報保護法第26条第1項の報告の問題になりうる（出典：個人情報の保護に関する法律／e-Gov法令検索）。※具体的な該当性の判断には本資料は立ち入りません |
| **賠償の問題が生じうる** | 【Varies】事務所が賠償責任保険に加入している場合がある（`08_money.md`／本セットの `pro_08` で扱う） |
| **顧客との信頼関係に影響する** | 【Inference】この業界が売っているのは信用である（`01_overview.md` 1-8） |

**だから `05_departments.md` ①N に「施錠できる鞄」が、②N に「施錠できる書庫」が挙がっています。**
道具の選び方が、法律上の義務から逆算されています。

### 事務所で見られる管理の形【Typical】（※評価はしません）

| 管理の形 | 何のためか |
|---|---|
| **預り証を発行する** | いつ何を預かったかを、双方が確認できる形にするため（7-6） |
| **顧問先ごとにケース・ファイルを分ける** | 他の顧問先の資料と混ざらないようにするため |
| **施錠できる書庫に保管する** | 部外者・来客の目に触れないようにするため |
| **持ち出しの記録を残す**【Varies】 | 誰が今どの資料を持っているかを分かるようにするため |
| **返却時に受領書をもらう** | 返し終わったことを記録に残すため（7-6） |
| **未返却の資料の一覧を作る** | 事務所に滞留している他人のモノを把握するため（`05_departments.md` ②O「証憑の未返却件数」） |

## 7-3. 預り資料が事務所の中をどう動くか

### 動線（テキスト図）

```
  【顧問先】                【X会計事務所】

   通帳コピー                ┌─────────────────────┐
   領収書       ──訪問──▶  │ ① 受領（担当者）         │ ← **預り証を発行**
   請求書       （または     │   中身を確認・数える      │
   給与明細      郵送・      └───────────┬─────────┘
                 来所・                   │
                 データ）                  ▼
                            ┌─────────────────────┐
                            │ ② 仕分け・整理（入力担当） │
                            │   月別・種類別に並べる     │
                            └───────────┬─────────┘
                                          ▼
                            ┌─────────────────────┐
                            │ ③ 入力（入力担当）        │ ← ここで**モノが情報になる**
                            │   1枚ずつ仕訳にする       │
                            └───────────┬─────────┘
                                          ▼
                            ┌─────────────────────┐
                            │ ④ 保管（施錠書庫）        │
                            │   顧問先ごとのファイル     │
                            └───────────┬─────────┘
                                          ▼
                            ┌─────────────────────┐
   ◀──返却──────────────── │ ⑤ 返却（担当者）          │ ← **受領書をもらう**
   原本が顧客に戻る           │   決算後にまとめて返す等   │
                            └─────────────────────┘
                                   【Varies】返却の時期・単位は事務所により異なる
```

### 各段階での「モノ」としての注意点

| 段階 | 頻度 | モノとして何が起きるか | 何に注意するか |
|---|---|---|---|
| ① 受領 | 月次 | 顧客の手から事務所の手へ移る | **この瞬間から管理責任が事務所に移る**【Inference】。だから預り証を出す |
| ② 仕分け | 月次 | 束がほどかれ、並べ替えられる | **他の顧問先の資料と混ざらないこと**。机の上で混ざると、混ざったことに気づきにくい【Inference】 |
| ③ 入力 | 月次 | 1枚ずつ手に取られる | 入力済みかどうかの印を付ける運用がある【Varies】。二重入力・入力漏れを防ぐため |
| ④ 保管 | 常時 | 事務所の中に他人のモノが積み上がる | **施錠。顧問先ごとに分ける。どこに何があるか分かる状態にする** |
| ⑤ 返却 | 年次（決算後）等【Varies】 | 事務所の手から顧客の手へ戻る | **返したことの記録**。返し忘れると、顧客が自分の資料を持っていない状態が続く |

> **★「事務所の中に他人のモノが積み上がる」という点**
> 【Inference】製造業の倉庫には自社の在庫があります。価値も責任も自社のものです。
> 会計事務所の書庫には、**120件分の他人の財産と秘密**があります。
> 事務所が所有しているモノはほとんどありません。
> **この非対称が、モノの管理を「在庫管理」ではなく「預り物の管理」にしています。**

## 7-4. 「モノが無い」ことが業務に与える影響

【Inference】在庫が無いことは、次の4つの結果をもたらします。
（※良し悪しの評価ではなく、構造の記述です。）

**① 生産を前倒しできない。**
製造業は、暇なときに作りためて繁忙期に備えることができます。
専門サービス業では、**顧客の資料が来ていない段階で決算を作ることはできません。**
`04_end-to-end-process.md` E② のとおり、仕事の起点が事務所の外にあります。
【Inference】したがって繁忙期の山を、在庫でならすことができません。

**② 売れ残りが発生しない。**
作ったものが売れずに残る、ということが起きません。
受任していない仕事は、そもそも存在しません。

**③ 仕入代金の支払いが無い。**
`08_money.md`（本セットの `pro_08`）で扱いますが、
**買掛金・仕入債務という項目が、事実上ほとんどありません。**
コストの中心は人件費です（`01_overview.md` 1-8）。

**④ 品質が「モノ」として検査できない。**
製造業なら、完成品を測って検査できます。
専門サービス業の成果物は書類であり、**正しいかどうかは中身を読まなければ分かりません。**
【Inference】だから `03_company-structure.md` 3-4 ④チェック・レビュー機能が必要になり、
それが有資格者に固定されています（`06_people.md` 6-3）。

## 7-5. 事務所が作って渡す／提出する書類（モノとしての側面）

**情報としての流れは `09_information.md`（本セットの `pro_09`）で、
帳票そのものの一覧は `10_documents.md`（同 `pro_10`）で扱います。**
ここでは**モノとして、どこへ何が行くか**だけを見ます。

### 顧客へ渡すもの

| 渡すもの | いつ | 形 | なぜ渡すのか |
|---|---|---|---|
| **月次試算表** | 月次 | 印刷またはデータ【Varies】 | 顧客が自社の状況を把握するため |
| **月次報告資料**【Varies】 | 月次 | 印刷またはデータ | 数字の意味を説明するため |
| **決算書**（貸借対照表・損益計算書） | 年次 | 【Typical】製本して渡す場合がある | 顧客が金融機関等に示すため |
| **申告書の控え** | 年次 | 印刷またはデータ | 顧客が自分の申告内容を保存するため |
| **電子申告の受信通知** | 年次 | 印刷またはデータ | **提出が受け付けられたことの記録**（`10_documents.md` 参照） |
| **納付書／納税額の案内** | 年次・法定・契約上のタイミング | 紙【Varies】 | 顧客が納税するため |
| **預かった資料の原本** | 決算後等【Varies】 | 現物 | **顧客のモノだから返す** |

> **なぜ決算書を「製本」することがあるのか**【Typical】
> 【Inference】決算書は、顧客が金融機関や取引先に示す書類です。
> 顧客の手を離れて第三者の目に触れるため、体裁が整えられることがあります。
> `05_departments.md` ③N に「製本用の表紙・ファイル」が挙がっているのは、このためです【Varies】。

### 行政へ提出するもの

| 提出先 | 何を | いつ | 形 |
|---|---|---|---|
| 税務署 | 法人税・所得税・消費税の申告書、各種届出書 | 年次・法定・契約上のタイミング | **電子申告が用いられることが多い**【Typical】。紙での提出もありうる【Varies】 |
| 都道府県・市町村 | 地方税の申告書、給与支払報告書 | 年次・法定・契約上のタイミング | 同上 |
| 年金事務所 | 算定基礎届・資格取得届・喪失届（社労士業務） | 年次・案件発生時 | 電子申請または紙【Varies】 |
| 労働基準監督署 | 労働保険の申告書、就業規則（社労士業務） | 年次・案件発生時 | 同上 |
| 法務局 | 登記の申請（司法書士業務） | 案件発生時 | 同上 |

> **★電子申告が中心になると、モノは何になるのか**
> 【Inference】申告書が電子的に送られる場合、**提出物としての紙は動きません。**
> 代わりに動くのは、
> ・顧客に渡す**控え**（紙またはデータ）
> ・**受信通知**（提出が受け付けられたことの記録）
> ・**納付書**（納税のための紙）【Varies】
> です。
> `11_systems.md`（本セットの `pro_11`）で仕組みを扱いますが、
> **本資料は電子化の是非を評価しません。紙で受け渡している顧問先もあります**【Varies】。

## 7-6. 受渡しの記録 — いつ何を預かり、いつ返したか

### なぜ記録が要るのか

【Inference】理由は3つあります。

1. **「預かった／預けていない」が後から争いになりうるから。**
   顧客は「渡したはずだ」と言い、事務所は「受け取っていない」と言う。
   どちらの記憶が正しいかを、記憶で決めることはできません。
2. **何が事務所にあるかを、事務所自身が把握するため。**
   120件分の資料が入り混じる中で、どこに何があるかは記録が無ければ分かりません。
3. **返し終わったことを示すため。**
   【Fact】民法第646条第1項は受取物の引渡しを定めています。
   返したかどうかは、記録が無ければ確認できません。

### 預り証（あずかりしょう）

> **用語：預り証**
> → 「いつ、誰から、何を、何点預かったか」を書いて、預けた側に渡す紙（またはデータ）のこと。
> → 実務例：「2026年4月8日、Z商事株式会社より、2026年3月分 普通預金通帳コピー1冊・
> 　 領収書82枚・請求書14枚を預かりました。X会計事務所 担当K」
> → **なぜするのか**：預けた側は、自分の手元から資料が無くなります。
> 　 何を渡したかを自分で覚えておくのは負担であり、争いのもとになります。
> 　 預かった側が書いて渡すことで、**双方の手元に同じ記録が残ります。**

【Typical】預り証に書かれる項目：

| 項目 | なぜ書くのか |
|---|---|
| 日付 | いつから事務所の管理下にあるかを示す |
| 顧問先名 | 誰のモノか |
| **対象期間**（○年○月分） | どの月の資料かを特定する |
| **品目と数量**（通帳○冊・領収書○枚 等） | 何をいくつ預かったかを特定する |
| 受領者の氏名 | **誰が受け取ったか**。事務所内の責任の所在 |
| 返却予定【Varies】 | いつ返すかの目安 |

### 返却の記録

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①顧客対応機能。`05_departments.md` ①-12） |
| **何をするか** | 預かっていた原本を顧客に返し、**受領書に署名または押印をもらう**【Varies】 |
| **いつ** | 【Varies】事務所により異なる。**年次（決算・申告が終わった後にまとめて返す）**／**月次（入力が終わり次第返す）** のいずれもある |
| **なぜ** | 返却の記録が無いと、事務所に無い資料が「まだ事務所にある」ことになってしまう【Inference】 |

> **★返却の時期が【Varies】である理由**
> 【Inference】決算・申告のときに前月までの資料を見返す必要が生じることがあります。
> 一方、事務所に他人の資料を長く置くほど、保管の責任と場所の負担が続きます。
> どちらを優先するかは事務所の運用であり、**本資料はどちらが良いとは書きません。**

### 未返却の管理

`05_departments.md` ②O に「**証憑の未返却件数**」という数字が挙がっています。

- **何を見ているか**：顧客に返すべき資料が、事務所にどれだけ滞留しているか。
- **なぜ見るか**：【Inference】滞留しているということは、
  **他人の財産を、必要のない期間、事務所が預かり続けている**ということです。
- **頻度**：**月次**／**年次**（決算後の一斉返却の前後）。

## 7-7. 電子データでの受渡し【Varies】

> **★本資料は、電子化の是非を評価しません。**
> **導入の提案もしません。** `common/methodology.md` §0 のとおり、これは提案資料ではありません。
> ここでは、**実務上どういう形があるか**を並べて書くだけにします。

### 実際にはどういう形があるか

| 受渡しの形 | どういうものか | モノとしての特徴 |
|---|---|---|
| **訪問して現物を預かる** | 担当者が顧問先へ行き、紙を受け取って持ち帰る | 紙が移動する。**紛失のリスクが移動中に生じる** |
| **顧客が来所して渡す** | 顧問先が事務所に持ってくる | 紙が移動する。移動の責任は顧客側にある間がある |
| **郵送・宅配** | 紙を送る | 紙が移動する。**送付の記録が残る形を使う場合がある**【Varies】 |
| **スキャンしてデータで送る** | 顧客または事務所が紙を読み取り、データで受け渡す | **原本の紙は顧客の手元に残る**。事務所が預かるのはデータ |
| **クラウドの受渡しの仕組み** | 共有のフォルダ等に顧客がデータを置く | 同上。紙が動かない |
| **金融機関のデータ連携** | 通帳の入出金データを直接取り込む | 【Varies】そもそも通帳のコピーを預からない形になる |

（`05_departments.md` ②M「証憑の電子化・読み取りの仕組み」「金融機関のデータ連携」参照）

### 紙で受け渡している顧問先もあります（価値判断抜きの記述）

【Varies】顧問先によって、受渡しの形は異なります。

- 【Typical】紙の領収書をそのまま箱で持ってくる顧問先があります。
- 【Typical】通帳のコピーを毎月郵送する顧問先があります。
- 【Typical】データで送ってくる顧問先があります。
- 【Varies】**同じ事務所の中で、顧問先ごとに形が違う**ことも一般的です。

> **なぜ形が統一されないのか**（構造の説明。評価ではありません）
> 【Inference】受渡しの形を決めるのは、**事務所ではなく顧客側の事情**です。
> 顧客が使っている道具、顧客の担当者の慣れ、顧客の事業の形によって変わります。
> `06_people.md` 6-2 ② のとおり、**顧客は事務所の業務プロセスの一部に組み込まれています。**
> 事務所が一方的に形を決められる部分ではありません。

### 電子データになっても消えない論点

| 論点 | 紙のとき | データのとき |
|---|---|---|
| **何を受け取ったかの記録** | 預り証 | 受信の記録・ファイル一覧【Varies】。**記録が要ることは変わらない** |
| **抜けが無いかの確認** | 枚数を数える | 月・口座・件数の照合。**「揃っているか」の確認は変わらない** |
| **秘密の管理** | 施錠書庫 | アクセスの管理。**【Fact】税理士法第38条の義務は変わらない** |
| **原本がどこにあるか** | 事務所にある | **顧客の手元にある場合がある**。保存義務との関係は 7-8 |
| **返却** | 現物を返す | 返すべき現物が無い場合がある【Varies】 |

## 7-8. ★保存義務 — 顧客側の義務と、事務所側の義務は別物です

**ここを混同しないでください。**
「決算書を7年保存する」という言い方をよく聞きますが、
**誰に課された義務なのか、どの法律に基づくのかを分けて見る必要があります。**

### ① 事務所（税理士）に課されている義務

【Fact】税理士法第41条（帳簿作成の義務）

> 「税理士は、税理士業務に関して帳簿を作成し、委嘱者別に、かつ、一件ごとに、
> 税務代理、税務書類の作成又は税務相談の内容及びそのてん末を記載しなければならない。
> ２　**前項の帳簿は、閉鎖後五年間保存しなければならない。**
> ３　税理士は、財務省令で定めるところにより、第一項の帳簿を電磁的記録をもつて作成することができる。」
> （出典：税理士法／e-Gov法令検索）

**これは税理士自身に課された義務です。** 顧客の帳簿の話ではありません。

| 何を | 誰が | どうする | 期間 |
|---|---|---|---|
| **税理士業務に関する帳簿**（業務処理簿と呼ばれることがある【Varies】） | **税理士** | 委嘱者別に、一件ごとに、税務代理・税務書類の作成・税務相談の内容と**てん末**を記載 | **閉鎖後5年間保存** |

> **用語：てん末（顛末）**
> → 物事の最初から最後までの経過のこと。
> → 実務例：「いつ相談を受け、どう検討し、どういう結論になり、いつ申告したか」という経過を書きます。
> → **なぜ書くのか**：条文が「その**てん末**を記載しなければならない」と定めているからです。
> 　 【Inference】結論だけでなく経過が求められている点が、この条文の特徴です。

### ② 顧客（納税者）に課されている義務

**これは税理士法ではなく、税法が顧客に対して課している義務です。**

【Fact】法人税法第126条第1項（青色申告法人の帳簿書類）

> 「第百二十一条第一項（青色申告）の承認を受けている内国法人は、財務省令で定めるところにより、
> 帳簿書類を備え付けてこれにその取引を記録し、かつ、**当該帳簿書類を保存しなければならない。**」
> （出典：法人税法／e-Gov法令検索）

【Fact】法人税法第150条の2第1項（帳簿書類の備付け等）

> 「普通法人、協同組合等並びに収益事業を行う公益法人等及び人格のない社団等
> （青色申告書を提出することにつき税務署長の承認を受けているものを除く。次項において「普通法人等」という。）は、
> 財務省令で定めるところにより、帳簿を備え付けてこれにその取引（…）を財務省令で定める簡易な方法により記録し、
> かつ、**当該帳簿（当該取引に関して作成し、又は受領した書類及び決算に関して作成した書類で
> 財務省令で定めるものを含む。次項において同じ。）を保存しなければならない。**」
> （出典：法人税法／e-Gov法令検索）

【Fact】所得税法第148条第1項（青色申告者の帳簿書類）

> 「第百四十三条（青色申告）の承認を受けている居住者は、財務省令で定めるところにより、
> 同条に規定する業務につき帳簿書類を備え付けてこれに不動産所得の金額、事業所得の金額及び
> 山林所得の金額に係る取引を記録し、かつ、**当該帳簿書類を保存しなければならない。**」
> （出典：所得税法／e-Gov法令検索）

【Fact】所得税法第232条第1項（事業所得等を有する者の帳簿書類の備付け等）

> 「その年において不動産所得、事業所得若しくは山林所得を生ずべき業務を行う居住者又は（…）
> （青色申告書を提出することにつき税務署長の承認を受けている者を除く。）は、
> 財務省令で定めるところにより、帳簿を備え付けてこれにこれらの所得を生ずべき業務に係るその年の取引（…）
> のうち総収入金額及び必要経費に関する事項を財務省令で定める簡易な方法により記録し、
> かつ、**当該帳簿（…）を保存しなければならない。**」（出典：所得税法／e-Gov法令検索）

> **★保存の年数について（本資料の姿勢）**
> 上記の各条文は、いずれも「**財務省令で定めるところにより**」と書いており、
> **保存の具体的な年数は法律本体ではなく財務省令（施行規則）に定められています。**
> 本資料は `common/methodology.md` §2 の鉄則に従い、
> **確認していない省令の年数を書きません**【Varies】。
> 押さえるべきは、**「保存しなければならない」という義務が顧客に課されている**という点です。
>
> なお、**税理士法第41条第2項の「閉鎖後五年間」は法律本体に書かれている年数**であり、
> これは逐語で確認しています。**同じ「保存」でも、条文の作りが違います。**

### ③ 両者を並べる

| | 事務所（税理士）側 | 顧客（納税者）側 |
|---|---|---|
| **根拠法** | **税理士法第41条** | **法人税法第126条第1項・第150条の2第1項／所得税法第148条第1項・第232条第1項** ほか |
| **義務を負う人** | **税理士** | **納税者（法人・個人事業主）** |
| **何を** | 税理士業務に関する帳簿（委嘱者別・一件ごと・内容とてん末） | 帳簿書類（取引の記録、取引に関して作成・受領した書類、決算に関して作成した書類 等） |
| **期間** | **閉鎖後5年間**（法律本体に明記） | **財務省令で定めるところによる**【Varies】（本資料では年数を断定しない） |
| **誰のモノか** | 事務所が作り、事務所が持つ | **顧客のモノ**。事務所が預かっている間も顧客のもの |

> **★ここが混同されやすい理由**
> 【Inference】実務では、**顧客の帳簿書類が事務所の書庫に置かれている**ことがあります。
> しかしそれは「事務所が保存義務を代わりに果たしている」のではなく、
> **顧客のモノを事務所が預かっている**という状態です（7-2、民法第646条第1項）。
> **義務を負っているのは顧客です。**
> `16_glossary.md`（本セットの `pro_16`）の「間違えやすいこと」でも取り上げます。

### ④ 事務所が持ち続ける「控え」

【Typical】事務所は、作成した決算書・申告書の控えを保管します。

| 何を | なぜ | 期間 |
|---|---|---|
| 決算書・申告書の控え | 翌期の作業で前期の数値が必要になるため／顧客からの問い合わせに答えるため【Inference】 | 【Varies】事務所の運用による |
| 税理士業務に関する帳簿 | **【Fact】税理士法第41条** | **閉鎖後5年間** |
| 顧問契約書 | 契約の内容を確認するため | 【Varies】 |
| 質問と回答の記録 | 過去の経緯を追えるようにするため（`06_people.md` 6-6） | 【Varies】 |

## 7-10. 【Example】Z商事の資料が1年でどう動くか

> **架空の例です。`04_end-to-end-process.md` F・`06_people.md` 6-7 と同じ設定です。**

| 時期 | 動くモノ | 誰の手から誰の手へ | 記録 |
|---|---|---|---|
| **毎月上旬** | 前月分の通帳コピー・領収書・請求書 | Z商事（社長の配偶者）→ 担当者Kさん | **預り証** |
| 毎月上旬 | 同上 | Kさん → 入力担当Mさん（事務所内） | 【Varies】所内の受渡し記録 |
| 毎月中旬 | 同上 | Mさん → 施錠書庫（事務所内） | ファイルに綴じる |
| 毎月中旬 | **月次試算表**（印刷またはデータ） | 事務所 → Z商事（社長） | 月次報告の記録 |
| **4月〜5月** | 棚卸表・残高明細・借入残高証明・保険証券 | Z商事 → Kさん | **預り証**（決算資料） |
| **5月下旬** | **決算書・申告書（顧客承認用）** | 事務所 → Z商事（社長） | 承認・押印 |
| **5月31日** | 申告データ | 事務所 → 税務署等（電子申告） | **受信通知** |
| 5月末 | **申告書の控え・納付書・納税額の案内** | 事務所 → Z商事 | 交付の記録【Varies】 |
| **6月** | **預かっていた原本一式**（1年分） | 事務所 → Z商事 | **受領書**【Varies】 |
| 6月以降 | 決算書・申告書の控え、税理士業務に関する帳簿 | 事務所の書庫に残る | **【Fact】税理士法第41条第2項：閉鎖後5年間保存** |

### この流れから読み取ってほしい4点

**① 1年を通して、事務所には常に他人のモノがある。**
【Inference】4月に預かった資料は、決算が終わるまで事務所にあります。
その間ずっと、管理の責任は事務所にあります（【Fact】民法第644条）。

**② 「返す」という工程が、必ずある。**
製造業の出荷とは意味が違います。
**売ったモノを出荷するのではなく、借りたモノを返しています**（【Fact】民法第646条第1項）。

**③ 提出物は、モノとして動かない場合がある。**
電子申告であれば、税務署へ紙は行きません。
代わりに**受信通知**という記録が残ります（`10_documents.md`／本セットの `pro_10`）。

**④ 返したあとも、事務所に残るものがある。**
控えと、税理士業務に関する帳簿です。
後者は**【Fact】税理士法第41条第2項により、閉鎖後5年間の保存が義務づけられています。**

## 7-11. まとめ：この章で押さえるべき7点

1. **この業界に商品としてのモノは無い。** 原材料も在庫も仕入先も物流も無い。
   売っているのは知識・資格・信用である。
2. **代わりに動くのは2種類**——**①顧客から預かる資料**と**②事務所が作って渡す／提出する書類**。
   **①は顧客の財産であり、事務所のモノではない。**
3. **預り資料には、紛失したら再発行できないものがある。**
   領収書、手書きの出納帳、契約書の原本、棚卸表、実印など。
4. **預かった瞬間から、管理の責任は事務所に移る。**
   【Fact】民法第644条（善良な管理者の注意）・第646条第1項（受取物の引渡し）。
5. **受渡しには記録を残す。** 預かるときは預り証、返すときは受領書【Varies】。
   記録が無ければ、「預かった／預けていない」を確かめる方法が無い。
6. **電子データでの受渡しもあり、紙での受渡しもある。**【Varies】
   形を決めているのは主に顧客側の事情であり、**本資料はどちらが良いとも書かない。**
7. **保存義務は、顧客側と事務所側で別物である。**
   顧客側＝【Fact】法人税法第126条第1項・第150条の2第1項／所得税法第148条第1項・第232条第1項 ほか
   （年数は財務省令による【Varies】）。
   事務所側＝【Fact】税理士法第41条（**閉鎖後5年間**）。
