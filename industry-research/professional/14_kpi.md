# 14_kpi.md — KPI・数字（専門サービス業）

**対象**：日本国内の中小の専門サービス業（主モデル：税理士事務所／対比：社会保険労務士事務所）
**読み手**：専門サービス業をまったく知らない人。経営指標の知識は前提にしません
**前提**：`03_company-structure.md` の**【Example】X会計事務所**（9名／顧問先120件／年商7,000万円。架空）
**最終更新**：2026-09-20

---

## 14-0. この章の読み方

### KPIとは

> **用語：KPI（ケーピーアイ／重要業績評価指標）**
> → 事業がうまく回っているかどうかを見るために、**日常的に確認している数字**のこと。
> → 実務例：「今月の未着資料が15件ある」「担当者1人あたり24件持っている」といった数字です。
> → **なぜ数字で見るのか**：【Inference】120件の顧問先の状況を、
> 　 感覚や記憶で把握することはできないからです。
> 　 **数字は「どこが詰まっているか」を指す道具**として使われます。

### ★この章で守ること

> ### ⚠ 報酬の水準は書きません【Varies】
> 「顧問料は月額いくらが相場」「決算料はいくら」といった**水準は一切書きません。**
> 報酬の水準は事務所・地域・業務範囲・顧客の規模により大きく異なります。
> 本章に出てくる金額は**すべて架空の設定値**です【Example】。
>
> ### ⚠ 目標値も書きません
> 「この数字は○○%であるべき」といった記述は、`common/methodology.md` §5 が禁じる評価・提案に当たります。
> 本章が書くのは、**その数字が何を意味しているか**と、**なぜ見るのか**だけです。

### この業界のKPIを4つのグループに分ける

```
  ┌──────────────────────────────────────────────┐
  │ A. 売上の「土台」を測る数字                        │
  │    顧問先数／顧問料の月額合計／スポット収入の比率     │
  │    1顧問先あたり年間報酬                           │
  └──────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────┐
  │ B. 処理能力を測る数字                              │
  │    担当者1人あたり顧問先数／有資格者1人あたり売上     │
  │    人件費率                                       │
  └──────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────┐
  │ C. 顧問先の増減を測る数字                           │
  │    解約件数／新規受任件数／紹介経由の比率【Varies】   │
  └──────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────┐
  │ D. 仕事が予定どおり進んでいるかを測る数字             │
  │    資料の回収率・遅延件数【Varies】                  │
  │    申告期限の遵守率／繁忙期と閑散期の売上差           │
  └──────────────────────────────────────────────┘
```

## 14-1. A. 売上の「土台」を測る数字

### ① 顧問先数

| 項目 | 内容 |
|---|---|
| **何を数えるか** | 顧問契約を結んでいる先の件数 |
| **どう分けて見るか** | 【Typical】法人／個人事業主、決算月別、担当者別、業種別 |
| **なぜ見るか** | 【Inference】`12_business-model.md` 12-1 のとおり、**売上＝顧問先数 × 単価**。この式の「数量」に当たる |
| **誰が見るか** | 所長（⑤営業機能） |
| **頻度** | **月次**（増減の確認）／**年次**（全体の見直し） |
| **【Example】X会計事務所** | 120件（法人90件・個人事業主30件。架空の設定値） |

> **★決算月別に分けて見る理由**
> 【Inference】決算月の分布が、**1年の作業の山の形**を決めます
> （`13_routine-tasks.md` 13-9）。
> 【Example】3月決算が30件あれば、4〜5月にその30件の作業が集中します。
> **件数の合計だけを見ていると、この偏りが見えません。**

### ② 顧問料の月額合計（ストック収入）

| 項目 | 内容 |
|---|---|
| **何を数えるか** | 顧問契約の月額報酬の**合計額** |
| **なぜ見るか** | **この業界で最も重要な数字の一つ**。【Inference】来月も入ってくる見込みのある金額を示す |
| **誰が見るか** | 所長 |
| **頻度** | **月次** |
| **【Example】X会計事務所** | 月あたり 約358万円（年間4,300万円 ÷ 12。架空の設定値） |

#### ★なぜこの数字が「経営の土台」を示すのか

```
   顧問料の月額合計   約358万円   ← 毎月入る（契約が続く限り）
   毎月の人件費       約350万円   ← 毎月出る（止められない）
   ────────────────────────────
   この関係が成り立っているか、が事務所の基本の姿
```

【Inference】`08_money-flow.md` 8-6 のとおり、
**毎月入る収入が、毎月出ていく人件費を支えている**というのが、この業界の資金の基本形です。
だから「今月の売上はいくらだったか」よりも、
**「毎月いくら入る状態になっているか」**を見ることに意味があります。

> **用語：ストック収入**
> → 契約が続いている限り、毎月継続して入ってくる収入のこと。
> → 実務例：顧問料。【Example】120件の顧問先があれば、来月も120件分が発生します。
> → **なぜ「ストック（積み上がる）」と呼ぶのか**：
> 　 新しい顧問先を1件増やすと、その分が**毎月ずっと積み上がる**からです。

### ③ スポット収入の比率

| 項目 | 内容 |
|---|---|
| **計算** | スポット収入 ÷ 年間売上 |
| **なぜ見るか** | **ストックとフローの比率が、経営の安定度を示す**（14-2 で詳述） |
| **誰が見るか** | 所長 |
| **頻度** | **年次** |
| **【Example】X会計事務所** | 800万円 ÷ 7,000万円 ＝ **11.4%**（架空の設定値） |

> **用語：フロー収入**
> → 案件が発生したときにだけ入ってくる収入のこと。
> → 実務例：相続税の申告、会社設立の届出、税務調査の対応。
> → **なぜ「フロー（流れる）」と呼ぶのか**：
> 　 その年に入ってきて、**翌年に持ち越されない**からです。

### ④ 1顧問先あたり年間報酬

| 項目 | 内容 |
|---|---|
| **計算** | （顧問料＋決算料＋その顧問先から受けたスポット報酬）÷ 1件 |
| **なぜ見るか** | 【Inference】顧問先ごとに、事務所がかけている時間は大きく違う。報酬と手間の関係を見るため |
| **誰が見るか** | 所長／担当者 |
| **頻度** | **年次** |
| **【Example】Z商事（架空）** | 月額顧問料3万円×12＋決算料20万円＋年末調整料5万円 ＝ **年間61万円**（架空の設定値） |

> ### ⚠ この数字を「相場」として読まないでください
> 【Example】の61万円は、`04_end-to-end-process.md` F で置いた**架空の設定値**です。
> **実際の報酬は事務所・顧客の規模・業務範囲により大きく異なります**【Varies】。

> **★この数字と「担当者の負担」を並べて見る**
> 【Inference】年間報酬が同じでも、
> ・毎月訪問し、質問が多く、資料が遅れる顧問先
> ・年に数回しか会わず、資料が整理されて届く顧問先
> では、かかる時間がまったく違います。
> `05_departments.md` ①O に「顧客ごとの年間報酬額」が挙がっているのは、
> **担当者の負担と報酬の釣り合いを見るため**です【Varies】。

## 14-2. ★ストック収入とフロー収入の比率 — 初心者向けの説明

**この節は、このファイルで最も重要です。**

### まず、2つの収入の違いから

```
  【ストック収入】＝ 顧問料
     1月  ████
     2月  ████   ← **契約が続く限り、毎月同じだけ入る**
     3月  ████
     4月  ████

  【フロー収入】＝ スポット報酬
     1月  （無し）
     2月  ████████  ← **案件があった月だけ入る**
     3月  （無し）
     4月  ██
```

### なぜ「比率」が安定度を示すのか

**来年の売上を予想してみる、という形で考えます。**

| | ストック中心の事務所 | フロー中心の事務所 |
|---|---|---|
| **来年の売上を予想できるか** | **ある程度できる**。今の契約が続けばいくら、という形で計算できる | **できない**。来年どんな案件が来るかは分からない |
| **人を雇えるか** | 【Inference】来年の収入の見込みが立つので、判断ができる | 【Inference】雇った人の来年の仕事が見えないため、判断が難しい |
| **売上が急に増えることがあるか** | **あまり無い**。1件増えても月額の分だけ | **ある**。大きな案件が入れば一度に増える |
| **売上が急に減ることがあるか** | **解約があれば減る。しかも毎月ずっと** | **案件が無ければゼロ** |

> **★言い換えると、こういうことです**
> **ストック収入は「積み上げるのに時間がかかり、崩れるときも少しずつ」。**
> **フロー収入は「一度に大きく入り、無ければゼロ」。**
>
> どちらが良い・悪いではありません。**事業の形が違う**というだけです
> （`12_business-model.md` 12-8 の Level 2 の表）。

### 【Example】3つの事務所を並べて比べる（すべて架空）

> **架空の数値です。実在の事務所ではなく、相場でも平均でもありません。**

| | 【Example】P事務所 | 【Example】X会計事務所 | 【Example】Q事務所 |
|---|---:|---:|---:|
| 年間売上 | 7,000万円 | 7,000万円 | 7,000万円 |
| 顧問料 | 5,500万円 | 4,300万円 | 1,000万円 |
| 決算料 | 1,200万円 | 1,900万円 | 500万円 |
| スポット | 300万円 | 800万円 | **5,500万円** |
| **顧問契約に紐づく比率** | **95.7%** | **88.6%** | **21.4%** |
| **スポット比率** | 4.3% | 11.4% | **78.6%** |

**同じ年商7,000万円でも、経営の姿がまったく違います。**

| | P事務所 | X会計事務所 | Q事務所 |
|---|---|---|---|
| 来年の見通し | 【Inference】立てやすい | 立てやすい | **立てにくい** |
| 解約が起きたとき | 【Inference】毎月の収入が直接減る | 同左 | 影響は小さい |
| 案件が無い年 | 影響は小さい | 影響は小さい | **売上が大きく落ちうる** |
| 月次の作業量 | 多い（毎月120件分） | 多い | **少ない**【Inference】 |

> **★この比較が示していること**
> 【Inference】**売上の金額が同じでも、「何で稼いでいるか」で事業の性格が変わります。**
> だから所長は、売上の合計だけでなく**内訳の比率**を見ます。
>
> `12_business-model.md` 12-8 のとおり、
> **行政書士・司法書士はQ事務所に近い形が一般的**です【Typical】。
> **これは「不安定だから悪い」という意味ではありません。**
> 登記や許認可は**出来事が起きたときだけ発生する**ため、構造的にそうなります。

### ★「ストック収入 ≠ 安定収入」

【Fact】民法第651条第1項

> 「委任は、各当事者がいつでもその解除をすることができる。」（出典：民法／e-Gov法令検索）

【Inference】毎月入っていても、解約されれば翌月から入りません。
**「毎月入る」ことと「ずっと入り続ける」ことは違います。**
だから次の 14-4（解約件数）を並べて見ることになります。

## 14-3. B. 処理能力を測る数字

### ⑤ 担当者1人あたり顧問先数

| 項目 | 内容 |
|---|---|
| **計算** | 顧問先数 ÷ 顧客と接する担当者の人数 |
| **なぜ見るか** | **この業界の生産性を最も直接に示す数字**（`12_business-model.md` 12-3） |
| **誰が見るか** | 所長（⑦教育・資格支援機能。担当替えの判断に使う） |
| **頻度** | **年次**／**案件発生時**（退職・欠員時） |
| **【Example】X会計事務所** | 120件 ÷ 5名 ＝ **約24件**（架空の設定値） |

#### この数字を左右する要因（`12_business-model.md` 12-3 の再掲）

| 要因 | どう効くか | 事務所で決められるか |
|---|---|---|
| 顧問先の規模（仕訳件数） | 多ければ1件の時間が長い | **決められない** |
| 顧客に経理担当者がいるか | いれば質問が減る | **決められない** |
| 顧客が自社で入力しているか【Varies】 | 作業が「入力」から「点検」に変わる | 【Varies】 |
| 訪問しているか／頻度【Varies】 | 移動時間が効く | 【Varies】契約による |
| 決算月の分布 | 集中すればその時期に処理しきれない | **決められない** |
| 資料が期限どおり届くか | 届かなければ後ろにずれる | **決められない** |

> **★「決められない」が並んでいることに注目してください**
> 【Inference】この業界の生産性は、**相当部分が顧客側の事情に依存しています。**
> 製造業なら、生産性は自社の設備と工程で決まります。
> **この違いが、KPIの意味を変えます。**
> 「1人あたり24件」という数字は、事務所の努力だけで作られた数字ではありません。
> （※だから顧客に協力を求めるべきだ、といった提案はしません。）

### ⑥ 有資格者1人あたり売上

| 項目 | 内容 |
|---|---|
| **計算** | 年間売上 ÷ 有資格者の人数 |
| **なぜ見るか** | **有資格者の数が、事務所の処理量の上限をつくる**ため |
| **誰が見るか** | 所長 |
| **頻度** | **年次** |
| **【Example】X会計事務所** | 7,000万円 ÷ 2名 ＝ **3,500万円**（架空の設定値） |

#### なぜ有資格者で割るのか

【Fact】税理士法第33条第1項（署名の義務）

> 「税理士又は税理士法人が税務代理をする場合において、租税に関する申告書等を作成して税務官公署に
> 提出するときは、**当該税務代理に係る税理士は、当該申告書等に署名しなければならない。**…」
> （出典：税理士法／e-Gov法令検索）

【Inference】**署名する人を増やさなければ、処理できる件数は増えません。**
`03_company-structure.md` 3-5 の「実行は分担できるが、責任は有資格者から離れない」が、
この数字に表れています。

**関連して見る数字：有資格者1人あたりのチェック件数**

| 項目 | 内容 |
|---|---|
| **計算** | 決算・申告の件数 ÷ 有資格者の人数 |
| **【Example】X会計事務所** | 120件 ÷ 2名 ＝ **60件** |
| **なぜ見るか** | 【Inference】繁忙期にここへ何件集中するかが、期限の遵守に直結する |

### ⑦ 人件費率

| 項目 | 内容 |
|---|---|
| **計算** | 人件費 ÷ 売上 |
| **なぜ見るか** | **この業界には仕入が無いため、人件費率が実質的に原価率の役割を果たす**（`12_business-model.md` 12-5） |
| **誰が見るか** | 所長 |
| **頻度** | **年次**／**月次**（`08_money-flow.md` 8-6 のとおり、賞与の月に大きく動く） |
| **【Example】X会計事務所** | 4,200万円 ÷ 7,000万円 ＝ **60.0%**（架空の設定値） |

> **★人件費率が「上がる」場面と「下がる」場面**
> 【Inference】`12_business-model.md` 12-5 の「階段」のとおりです。
> ・**人を採用した直後**：売上は変わらず人件費だけ増えるので、**率が上がる**。
> ・**その人が顧問先を担当し始めた後**：売上が増えるので、**率が下がる**。
> 　
> つまり、**この率が一時的に上がることは、採用したことの結果**でもあります。
> **率の高低だけを見て良し悪しを判断できる数字ではありません。**
> （※本資料は適正な水準を示しません。）

## 14-4. C. 顧問先の増減を測る数字

### ⑧ 解約件数

| 項目 | 内容 |
|---|---|
| **何を数えるか** | その期間に顧問契約が終了した件数 |
| **内訳で見るもの** | 【Typical】顧客の廃業・倒産／代替わり／他事務所への変更／顧客が自社で行うようになった【Varies】 |
| **なぜ見るか** | **解約は、翌月から毎月の収入が減ることを意味する**（14-2） |
| **誰が見るか** | 所長 |
| **頻度** | **月次**（発生のつど）／**年次**（集計） |

> **★解約1件の重さを、数字で見る**
> 【Example】月額顧問料3万円・決算料20万円の顧問先が1件解約した場合（架空の設定値）：
> ```
>    今年の残りの月数分の顧問料  ＋  来年以降 毎年 56万円
>                                     （3万×12 ＋ 20万）
> ```
> 【Inference】**一度きりの減少ではなく、毎年続く減少**になります。
> これが、スポット案件を1件失うのとの違いです。

### ⑨ 新規受任件数

| 項目 | 内容 |
|---|---|
| **何を数えるか** | その期間に新たに顧問契約を結んだ件数 |
| **なぜ見るか** | 【Inference】`03_company-structure.md` 3-4 ⑤のとおり、**顧問先は自然に減る**。補充しなければ売上は減り続ける |
| **誰が見るか** | 所長（⑤営業機能） |
| **頻度** | **月次**／**年次** |

**解約件数と並べて見ます。**

```
   純増減 ＝ 新規受任件数 − 解約件数

   【Example】ある年（架空）
     新規受任  8件
     解約      6件
     ────────────
     純増      2件   ← **見た目は増えている**

   ただし、金額で見ると違う姿になることがある【Inference】
     新規8件の年間報酬合計   320万円
     解約6件の年間報酬合計   410万円
     ────────────────────
     **金額では90万円の減少**
```

> **★件数と金額の両方を見る理由**
> 【Inference】顧問先の規模はさまざまです。
> **件数が増えていても、金額では減っていることがあります。**
> 逆も起こりえます。
> だから `05_departments.md` ①O には「担当先の解約件数・継続率」と
> 「顧客ごとの年間報酬額」の両方が挙がっています。

### ⑩ 紹介経由の比率【Varies】

| 項目 | 内容 |
|---|---|
| **計算** | 紹介による新規受任件数 ÷ 新規受任件数 |
| **紹介元の内訳** | 【Typical】既存の顧問先／金融機関／他士業（`02_industry-structure.md`） |
| **なぜ見るか** | 【Typical】`01_overview.md` 1-6 Level 1 ⑤のとおり、**紹介が主要な集客経路**である |
| **誰が見るか** | 所長（⑤営業機能） |
| **頻度** | **年次** |
| **【Varies】** | **測っていない事務所もあります。** 本資料は数値の水準を示しません |

> **★この数字が示していること**
> 【Inference】紹介が主要な経路であるということは、
> **既存の顧問先との関係と、他士業・金融機関との関係が、新規受任の前提になっている**ということです。
> `05_departments.md` ⑤-2「紹介元への連絡・関係の維持」が独立した業務として存在するのは、このためです。
> （※だから紹介を増やすべきだ、という提案はしません。構造の記述です。）

## 14-5. D. 仕事が予定どおり進んでいるかを測る数字

### ⑪ 資料の回収率・遅延件数【Varies】

| 項目 | 内容 |
|---|---|
| **何を数えるか** | 【Varies】「当月中に○月分の資料が届いた顧問先の件数 ÷ 対象の顧問先数」など。**数え方は事務所により異なる** |
| **なぜ見るか** | **この業界で最も上流の数字**。ここが詰まると全工程が止まる（`09_information-flow.md` 9-8） |
| **誰が見るか** | 担当者（①）／所長 |
| **頻度** | **月次** |
| **関連する帳票** | 未着資料の一覧（`05_departments.md` ①-2） |

> **★この数字が、この業界に固有である理由**
> 【Inference】製造業の「材料入荷率」は、**発注した相手（仕入先）**に対する数字です。
> この業界の「資料の回収率」は、**お金を払ってくれている顧客**に対する数字です。
>
> しかも、資料が来なくても**法律上の期限は来ます**
> （【Fact】法人税法第74条第1項ほか）。
> だから、この数字は「催促の進み具合」ではなく、
> **「期限に間に合うかどうかの先行指標」**として見られます。

**遅延件数を見るときに分けて見るもの**【Varies】：

| 分け方 | 何が分かるか |
|---|---|
| 顧問先別 | 【Inference】毎月遅れる先と、たまたま遅れた先を分けられる |
| 担当者別 | 【Inference】催促の状況を把握できる |
| 遅延の日数 | 【Inference】1週間の遅れと1か月の遅れでは意味が違う |
| 決算月との関係 | **決算が近い先の遅れは、期限に直結する** |

### ⑫ 入力完了率・保留項目の未解決件数

| 項目 | 内容 |
|---|---|
| **何を数えるか** | 「何件の顧問先の、何月分が入力済みか」／内容不明のまま保留になっている項目の件数 |
| **なぜ見るか** | 【Inference】入力が終わらなければ試算表が出ない。保留が残れば仕訳が確定しない |
| **誰が見るか** | 入力担当（②）／担当者（①） |
| **頻度** | **月次** |
| **参照** | `05_departments.md` ②O |

### ⑬ 試算表の完成日（決算月末からの日数）

| 項目 | 内容 |
|---|---|
| **何を数えるか** | 対象月の末日から、試算表ができるまでの日数 |
| **なぜ見るか** | 【Inference】顧客に数字を届けるまでの速さ。遅いほど、顧客が判断に使える期間が短くなる |
| **誰が見るか** | 担当者（①） |
| **頻度** | **月次** |
| **参照** | `05_departments.md` ①O |

### ⑭ ★申告期限の遵守率

**この業界で最優先の数字です。**

| 項目 | 内容 |
|---|---|
| **計算** | 期限内に申告した件数 ÷ 申告すべき件数 |
| **なぜ最優先か** | **期限は条文が定めており、動かせないため** |
| **誰が見るか** | 所長（④チェック・レビュー機能） |
| **頻度** | **年次**（顧問先ごとの申告のたびに確認） |
| **参照** | `05_departments.md` ③O「期限内申告の件数・率」 |

#### 根拠となる条文（逐語）

| 何の期限か | 条文の語 | 根拠 |
|---|---|---|
| 法人税 | 「各事業年度終了の日の翌日から**二月以内**に…提出しなければならない」 | 【Fact】法人税法第74条第1項 |
| 消費税 | 「当該課税期間の末日の翌日から**二月以内**に…提出しなければならない」 | 【Fact】消費税法第45条第1項 |
| 所得税 | 「**第三期（その年の翌年二月十六日から三月十五日までの期間をいう。）**において…提出しなければならない」 | 【Fact】所得税法第120条第1項 |

（いずれも出典：e-Gov法令検索）

> **★なぜ「率」で見るのか**
> 【Inference】1件でも期限を過ぎれば、その顧問先に影響が及びます。
> 「99%」は、120件のうち1件が間に合わなかったことを意味します。
> **この数字は、他のKPIのように「改善の余地」として見る数字ではありません。**
> （※本資料は目標値を示しません。）

#### この数字の先行指標

```
   資料の回収率（月次）
        ↓
   入力完了率・保留の未解決件数（月次）
        ↓
   決算資料の回収状況（年次）
        ↓
   ④チェック待ちの件数（年次・繁忙期）
        ↓
   顧客の承認が取れた件数（年次）
        ↓
   **申告期限の遵守率**
```

【Inference】上流の数字が悪いと、**下流の数字が期限の直前に悪化します。**
だから上流の数字（資料の回収率）を月次で見ることに意味があります。

### ⑮ ④チェック待ちの件数

| 項目 | 内容 |
|---|---|
| **何を数えるか** | 有資格者のチェックを待っている決算・申告の件数 |
| **なぜ見るか** | **ここが唯一、分担できない工程**（【Fact】税理士法第33条） |
| **誰が見るか** | 所長・勤務税理士 |
| **頻度** | **月次**／**週次**（繁忙期）【Varies】 |

### ⑯ ④での差し戻し件数・指摘件数

| 項目 | 内容 |
|---|---|
| **何を数えるか** | チェックで修正を求めた件数・指摘の件数 |
| **なぜ見るか** | 【Inference】作成する側の精度を示す。また、⑦教育機能の判断材料になる（`05_departments.md` ③O／⑦） |
| **誰が見るか** | 所長 |
| **頻度** | **年次** |

> **★この数字を「ミスの数」としてだけ見ない**
> 【Inference】差し戻しが起きるのは、**チェックが機能している**ということでもあります。
> `03_company-structure.md` 3-4 ④のとおり、この機能は「間違いを外に出さないための最後の関門」です。
> （※本資料は、この数字の多寡を評価しません。）

### ⑰ 繁忙期と閑散期の売上差

| 項目 | 内容 |
|---|---|
| **何を数えるか** | 月ごとの売上（または入金額）の最大と最小、およびその差 |
| **なぜ見るか** | **繁忙期は制度が決めており、動かせない**（`13_routine-tasks.md` 13-9）。どれだけ偏っているかを把握するため |
| **誰が見るか** | 所長 |
| **頻度** | **年次** |

#### 【Example】X会計事務所の月別入金（架空の設定値。`08_money-flow.md` 8-6 から）

| 月 | 入金額【Example】 |
|---|---:|
| 4月 | 458万円 |
| 5月 | 478万円 |
| **6月** | **838万円** ← 最大 |
| 7月 | 478万円 |
| 8月 | 548万円 |
| 9月 | 508万円 |
| 10月 | 478万円 |
| 11月 | 548万円 |
| 12月 | 508万円 |
| **1月** | **458万円** ← 最小 |
| 2月 | 468万円 |
| **3月** | **828万円** |

**最大838万円 ÷ 最小458万円 ＝ 約1.8倍**（架空の設定値）

> **★この差が示していること**
> 【Inference】**負荷の山と、入金の山はずれています。**
> 作業の山は4〜5月（3月決算法人の決算・申告）と2〜3月（所得税の確定申告）、
> 入金の山は6月と3月です。
> **その間も人件費は毎月同額出ていきます**（`08_money-flow.md` 8-6）。
>
> だから所長は、**年間の売上合計だけでなく、月ごとの波**を見ます。
> （※「波をならすべきだ」という提案はしません。
> 　 決算月の分布は顧問先の事情で決まっており、事務所が選べるものではありません。）

### ⑱ 証憑の未返却件数

| **なぜ見るか** | 【Inference】滞留は、**他人の財産を必要のない期間、預かり続けている**ことを意味する（【Fact】民法第646条第1項） |
| **誰が見るか** | 入力担当（②）／担当者（①） |
| **頻度** | **月次**／**年次**（決算後の返却の前後） |

## 14-7. 数字どうしのつながり

```
  【上流】                                          【下流】

  ⑪資料の回収率 ──▶ ⑫入力完了率 ──▶ ⑬試算表の完成日
        │                                    │
        └────────────────────────────────────┤
                                             ▼
                                   ⑮④チェック待ち件数
                                             │
                                             ▼
                                   ⑭**申告期限の遵守率**

  ⑤担当者1人あたり件数 ──┐
  ⑥有資格者1人あたり売上 ─┼──▶ 処理能力の上限 ──▶ ①顧問先数の上限
  ⑦人件費率 ─────────────┘

  ⑨新規受任 − ⑧解約 ──▶ ①顧問先数 ──▶ ②顧問料の月額合計 ──▶ ③スポット比率
                                              │
                                              ▼
                                    毎月の人件費を支えられるか
```

### この図から読み取ってほしい3点

**① 上流の数字が悪いと、期限の直前に効いてくる。**
【Inference】資料が来ないことは、その月には「まだ大丈夫」に見えます。
しかし、それが決算月の顧問先であれば、**2か月後の期限に直結します。**

**② 処理能力の上限が、顧問先数の上限をつくる。**
【Inference】担当者を増やしても、有資格者が増えなければ⑮が詰まります
（【Fact】税理士法第33条）。

**③ 顧問先数が、毎月の収入を決め、それが人件費を支える。**
【Inference】`08_money-flow.md` 8-6 のとおり、
**この業界の資金の基本形は「毎月入る顧問料が、毎月出る人件費を支える」**という形です。

## 14-8. 社労士事務所で見る数字はどう違うか（【Example】Y社会保険労務士事務所）

| 数字 | 税理士事務所 | 社会保険労務士事務所 |
|---|---|---|
| **件数の単位** | **顧問先数** | **顧問先数＋その顧問先の従業員数** |
| なぜ | 【Inference】仕訳件数が作業量を決める | 【Inference】**手続の件数は従業員数にほぼ比例する**（`03_company-structure.md` 3-3） |
| **月次で必ず発生する作業** | 記帳・試算表（毎月） | **給与計算を受託していれば毎月。していなければイベント待ち**【Varies】 |
| **期限の遵守率** | 申告期限（【Fact】法人税法第74条第1項ほか） | **年度更新・算定基礎届の期限**（【Fact】労働保険徴収法第19条第1項／健康保険法施行規則第25条第1項） |
| **繁忙期の集中** | 決算月がばらつけば分散する面がある | **全顧問先が同時に集中する**（`13_routine-tasks.md` 13-9） |
| **手続の件数** | — | **入退社の件数**が直接の作業量になる |
| 業務帳簿に記載する事項 | 【Fact】税理士法第41条：**内容及びそのてん末** | 【Fact】社会保険労務士法第19条：**事件の名称、依頼を受けた年月日、受けた報酬の額、依頼者の住所及び氏名又は名称** |

> **★「顧問先数」という同じ言葉でも、意味が違います**
> 【Inference】税理士事務所の120件と、社労士事務所の60社では、
> **1件あたりの作業量の決まり方が違います。**
> 社労士事務所では、**同じ1社でも従業員が5名か100名かで作業量がまったく違います。**
> だから `01_overview.md` 1-6 Level 2 の表は、
> 社会保険労務士の単価の決まり方を「**従業員数**をもとに提示することが多い」としています【Typical】。

## 14-9. まとめ：この章で押さえるべき8点

1. **KPIは4つのグループで整理できる**——A.売上の土台／B.処理能力／C.顧問先の増減／D.進捗と期限。
2. **最も重要な数字の一つが「顧問料の月額合計（ストック収入）」。**
   【Inference】毎月入る収入が、毎月出ていく人件費を支えているため。
3. **ストック収入とフロー収入の比率が、経営の安定度を示す。**
   同じ年商でも、何で稼いでいるかで事業の性格が変わる。
   **ただし「ストック収入＝安定収入」ではない**（【Fact】民法第651条第1項）。
4. **生産性は「担当者1人あたり顧問先数」と「有資格者1人あたり売上」の2つで見る。**
   後者が上限をつくる（【Fact】税理士法第33条）。
5. **人件費率が、この業界の実質的な原価率。** 仕入が無いため。
   **採用した直後に一時的に上がるのは、階段の性質による**（`12_business-model.md` 12-5）。
6. **解約1件は、一度きりの減少ではなく、毎年続く減少になる。**
   だから新規受任件数と並べ、**件数と金額の両方**で見る。
7. **「資料の回収率」がこの業界で最も上流の数字。**
   顧客が資料を出さなくても法律上の期限は来るため、**期限の先行指標**として見られる。
8. **「申告期限の遵守率」が最優先。**
   期限は条文が定めており（【Fact】法人税法第74条第1項／消費税法第45条第1項／
   所得税法第120条第1項）、動かせない。
   **※本資料は、いずれの数字についても目標値・相場・水準を示さない**【Varies】。
