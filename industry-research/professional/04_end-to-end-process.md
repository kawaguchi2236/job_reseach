## 4-0. この業界の業務フローの読み方（最初に理解すべきこと）

製造業なら「受注 → 生産 → 出荷 → 請求 → 入金」という**1本の線**を描けます。
しかし専門サービス業のフローは、**3本が同時に走っています。**

```
 ┌──────────────────────────────────────────────────────────┐
 │ A. 新規受任の流れ  ── 案件発生時。新しい顧客が増えるたびに1回だけ  │
 └──────────────────────────────────────────────────────────┘
                              ↓ 受任したら、以後は下の2つが回り続ける
 ┌──────────────────────────────────────────────────────────┐
 │ B. 月次の顧問業務サイクル ── 月次。毎月、終わりなく繰り返す       │
 │    資料受領 → 記帳・入力 → 試算表作成 → 月次報告 → 質問対応 → 次月 │
 └──────────────────────────────────────────────────────────┘
                              ＋（同時並行）
 ┌──────────────────────────────────────────────────────────┐
 │ C. 年次の申告業務サイクル ── 年次。法定期限に向かって走る          │
 │    決算資料収集 → 決算整理 → 決算書作成 → 申告書作成 →            │
 │    有資格者チェック → 顧客説明 → 電子申告 → 納税案内 → 控え保管    │
 └──────────────────────────────────────────────────────────┘
                              ＋（常時）
 ┌──────────────────────────────────────────────────────────┐
 │ D. スポット業務 ── 案件発生時。相続・会社設立・許認可・調査対応 など │
 └──────────────────────────────────────────────────────────┘
```

> **なぜ3本同時なのか**
> 顧問先120件の事務所では、**A（新規受任）とB（月次）とC（年次）が、常に同時に動いています。**
> しかも顧問先の決算月はバラバラなので、**Cはある顧問先では5月に、別の顧問先では11月に走ります。**
> 「今月は決算の月」という統一された月がありません。
> ただし、**3月決算の法人と個人事業主の確定申告は時期が固定されている**ため、
> 2月〜3月と5月に山ができます【Typical】。
>
> **この「複数の期限が並行して走っている」状態を管理すること自体が、この業界の業務の中身です**【Inference】。

## A. 新規受任の流れ（新しい顧客を引き受けるまで）

**頻度：案件発生時**（紹介や問い合わせがあったとき）

### 全体像

```
① 問い合わせ・紹介 → ② 初回面談 → ③ 業務範囲の確定 → ④ 見積・報酬の提示
  → ⑤ 受任の可否判断 → ⑥ 契約（委任契約）→ ⑦ 税務代理権限証書等の提出【Varies】
  → ⑧ 初回資料の受領 → ⑨ 初期設定 → ⑩ 業務開始
```

### ステップ①：問い合わせ・紹介を受ける

| 項目 | 内容 |
|---|---|
| **誰が** | 所長（⑤新規開拓・営業機能）。一次受けは事務職員（⑥）の場合もある |
| **何を受け取るか** | 問い合わせの内容（電話・メール・紹介者からの連絡） |
| **何をするか** | 相手の状況を聞く。会社か個人か、業種、規模、今どういう状態か、何に困っているか |
| **何を作るか** | 問い合わせ記録／面談の約束 |
| **次に誰へ** | 所長本人（面談へ） |
| **頻度** | 問い合わせ時 |

【Typical】`02_industry-structure.md` 2-2 のとおり、多くは紹介経由です。
紹介の場合、**紹介者が誰か**が、その後の対応の前提になります【Inference】。

### ステップ②：初回面談

| 項目 | 内容 |
|---|---|
| **誰が** | **所長（有資格者）**。【Typical】中小事務所では所長が自ら出ます |
| **何を受け取るか** | 顧客の現状の説明。直近の決算書・申告書の控え、通帳、前の事務所とのやり取り（あれば） |
| **何を確認するか** | 事業の内容／規模（売上・従業員数）／経理の体制（担当者がいるか）／現在の帳簿の状態／いつから頼みたいか／前任者がいるか、いた場合はなぜ変わるのか |
| **何をするか** | 事務所として何ができるかを説明し、顧客が何を求めているかを聞き取る |
| **何を作るか** | 面談メモ／業務範囲の素案 |
| **次に誰へ** | 所長（見積作成へ） |
| **頻度** | 案件発生時 |

> **なぜ「経理の体制」を必ず聞くのか**
> `01_overview.md` 1-4 のとおり、**顧客に経理担当者がいるかどうかで、事務所がやる仕事の量が何倍も変わります。**
> 領収書の束から入力するのか、顧客が入力したものを確認するのかで、
> かかる時間がまったく違うためです【Typical】。だから報酬の見積の前提として必ず確認されます。

### ステップ③：業務範囲の確定

| 項目 | 内容 |
|---|---|
| **誰が** | 所長 |
| **何を受け取るか** | 面談メモ |
| **何をするか** | **何を引き受け、何を引き受けないかを明確にする** |
| **何を作るか** | 業務範囲の一覧 |
| **次に誰へ** | 所長（見積へ） |
| **頻度** | 案件発生時 |

> **この業界で最も重要なステップのひとつです**【Inference】
> `02_industry-structure.md` 2-6 ⑤のとおり、この業界ではミスが顧客の金銭的損害に直結します。
> そして「やっていない仕事」について後から責任を問われることを避けるには、
> **引き受けていない範囲を明確にしておく**必要があります。
>
> 【Example】業務範囲の切り分けの例（説明用の架空の例です）：
> - 引き受ける：月次の記帳、試算表の作成、月次の面談、決算・法人税と消費税の申告、年末調整
> - 引き受けない：給与計算そのもの、社会保険の手続（→ 社会保険労務士へ）、登記（→ 司法書士へ）、
>   資金繰り表の作成代行
>
> この切り分けが、`02_industry-structure.md` 2-1 ④の「他士業との連携」が発生する起点になります。

### ステップ④：見積・報酬の提示

| 項目 | 内容 |
|---|---|
| **誰が** | 所長 |
| **何を受け取るか** | 業務範囲の一覧、顧客の規模情報 |
| **何をするか** | 顧問料（月額）と決算料（年1回）を分けて金額を出す。スポット業務があれば別途 |
| **何を作るか** | **見積書**（月額顧問料／決算料／その他業務の内訳） |
| **次に誰へ** | 顧客 |
| **頻度** | 案件発生時 |

【Typical】報酬の提示は、`01_overview.md` 1-5 の3つの考え方（時間で売る／成果物で売る／資格・関与で売る）
のうち、**顧問料は「関与で売る」、決算料は「成果物で売る」**形になるのが一般的です。
金額の水準は事務所・地域・顧客規模により大きく異なります【Varies】。本資料では相場を示しません。

> **見積 ≠ 契約**
> 見積書を出しただけでは仕事は確定していません。顧客が他の事務所と比べていることもあります。

### ステップ⑤：受任の可否判断（引き受けるかどうかを決める）

| 項目 | 内容 |
|---|---|
| **誰が** | **所長（有資格者）。この判断は分担できません** |
| **何を確認するか** | 事務所の処理能力に対して受け入れられる量か／繁忙期に重ならないか／内容に無理がないか／責任を負える範囲か |
| **何をするか** | 引き受ける／引き受けないを決める |
| **次に誰へ** | 顧客（回答） |
| **頻度** | 案件発生時 |

【Inference】「断る」という選択肢が現実に存在するのが、この業界の特徴です。
引き受けた以上は期限までに仕上げなければならず、**処理能力を超えて受けると、既存の顧問先の業務まで遅れます。**

### ステップ⑥：契約（委任契約）

| 項目 | 内容 |
|---|---|
| **誰が** | 所長と顧客（社長） |
| **何を受け取るか** | 顧客の承諾 |
| **何をするか** | 契約書を取り交わす |
| **何を作るか** | **顧問契約書／業務委託契約書**（業務範囲・報酬・支払期日・契約期間・解約の方法・秘密保持 等を記載）【Typical】 |
| **次に誰へ** | 担当者（業務の引き継ぎ）、⑥総務・経理機能（請求の登録） |
| **頻度** | 受注時（この業界では**受任時**） |

> **用語：委任契約（いにんけいやく）**
> → `02_industry-structure.md` 2-3 で説明したとおり、「事務の処理を任せる」型の契約。
> → **請負契約との違い**：請負は「完成させること」が約束の中身で、完成しなければ報酬が発生しません。
>    委任は「適切に事務を処理すること」が約束の中身です。
> → 実務例：顧問契約は委任（準委任）の形を取るのが一般的です【Typical】。
>    だから「今月は特に相談事がなかった」場合でも顧問料は発生します。

### ステップ⑦：税務代理権限証書等の提出【Varies】

| 項目 | 内容 |
|---|---|
| **誰が** | **有資格者** |
| **何をするか** | 税務代理を行う場合、その権限を有することを証する書面を税務官公署に提出する |
| **根拠** | 【Fact】税理士法第30条（税務代理の権限の明示）「税理士は、税務代理をする場合においては、財務省令で定めるところにより、その権限を有することを証する書面を税務官公署に提出しなければならない。」（出典：税理士法／e-Gov法令検索） |
| **頻度** | 法定・契約上のタイミング |

> **【Varies】と付けている理由**
> 条文は「税務代理をする場合においては」提出しなければならないと定めています。
> したがって**提出のタイミングや、どの業務でこの書面が必要になるかは、
> 何をいつ代理するかによって変わります。**
> 契約したら即座に全員が出す、という単純な話ではないため、ここは【Varies】としています。
> **社会保険労務士・行政書士・司法書士には、それぞれ別の法律・様式による提出の仕組みがあり、
> 税理士法第30条をそのまま当てはめることはできません。**

### ステップ⑧：初回資料の受領

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①顧客対応機能） |
| **何を受け取るか** | 過去の決算書・申告書の控え（【Typical】3期分程度）、総勘定元帳、固定資産の一覧、借入金の返済予定表、通帳、契約書類、給与の資料 |
| **何をするか** | 内容を確認し、**預り証**を発行する |
| **何を作るか** | 預り資料の一覧／預り証 |
| **次に誰へ** | ②記帳代行・入力機能 |
| **頻度** | 受注時（受任時） |

> **なぜ過去の資料が必要なのか**
> 会計も税務も、**前期からの続き**です。前期末の残高が今期の期首残高になります。
> 前期の内容を知らないまま今期だけ見ても、正しい数字にはなりません【Inference】。

### ステップ⑨：初期設定

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者＋入力担当（②） |
| **何を受け取るか** | 過去の決算書、総勘定元帳、預り資料 |
| **何をするか** | 会計ソフトに顧客を登録し、勘定科目の設定、期首残高の入力、固定資産の登録、部門設定などを行う |
| **何を作るか** | 使える状態になった会計データ |
| **次に誰へ** | 担当者（月次業務の開始） |
| **頻度** | 受注時（受任時） |

以降は **B. 月次の顧問業務サイクル** に入ります。

## B. 月次の顧問業務サイクル（毎月くり返す）

**頻度：月次**

### 全体像

```
① 資料の受領 → ② 記帳・入力 → ③ 内容の確認・不明点の洗い出し
  → ④ 試算表の作成 → ⑤ 月次報告・打合せ → ⑥ 質問対応（常時）
  → ⑦ 顧問料の請求 → ⑧ 入金確認 → 翌月へ
       ＋ 毎月10日：源泉所得税の納付の案内（法定・契約上のタイミング）
```

### ステップ①：資料の受領

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①） |
| **何を受け取るか** | 前月分の通帳のコピー、売上の請求書控え、仕入・経費の請求書と領収書、給与の支給明細、現金出納帳、クレジットカードの明細 |
| **何を確認するか** | **揃っているか。抜けている月・抜けている口座はないか** |
| **何をするか** | 受領。不足があればその場で依頼。訪問・来所・郵送・データ送付など方法は【Varies】 |
| **何を作るか** | 受領記録／預り証 |
| **次に誰へ** | ②記帳代行・入力機能 |
| **頻度** | 月次 |

> ### ★この業界の構造：資料が揃わないと仕事が進まない
> **これは専門サービス業を理解するうえで決定的に重要な点です。**
>
> 製造業では、材料が届かなければ仕入先を責めることができます。
> しかし専門サービス業では、**資料を出してくれない相手が「お客様」です。**
>
> - 顧客が領収書を出してくれなければ、記帳できません。
> - 記帳できなければ、試算表は作れません。
> - 試算表が作れなければ、決算も申告もできません。
> - **それでも法定期限は動きません。**
>
> 【Inference】したがって事務所の月次業務の相当部分が、
> **「まだ来ていない資料を催促すること」**に費やされます。
> これは事務所の努力不足ではなく、**業務が顧客の行動に依存しているという構造**です。
> （※本資料は、この状況への対策や改善策を提案しません。）

### ステップ②：記帳・入力

| 項目 | 内容 |
|---|---|
| **誰が** | 入力担当・パート職員（②）。顧客が自社で入力している場合はこの工程が無い【Varies】 |
| **何を受け取るか** | 預り資料一式 |
| **何をするか** | 領収書・請求書・通帳の1件ずつを仕訳の形にして会計ソフトに入力する |
| **何を判断するか** | どの勘定科目に当てはまるか。判断がつかないものは**「不明」として保留し、担当者に回す** |
| **何を作るか** | 仕訳データ（会計帳簿） |
| **次に誰へ** | 担当者（③へ） |
| **頻度** | 月次 |

### ステップ③：内容の確認・不明点の洗い出し

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①） |
| **何を受け取るか** | 入力済みの仕訳データ、保留になった項目 |
| **何を確認するか** | 通帳の残高と帳簿の残高が一致しているか／売上の計上漏れがないか／前月と比べて不自然に増減している科目がないか／内容の分からない支出はないか |
| **何をするか** | 顧客に質問し、内容を確認する。証憑と照合する |
| **何を作るか** | 質問リスト／修正後の仕訳データ |
| **次に誰へ** | 顧客（質問）→ 回答を受けて④へ |
| **頻度** | 月次 |

> **なぜ残高の一致を確認するのか**
> 通帳の残高は、銀行が管理している「動かせない事実」です。
> 帳簿の残高がそれと違えば、**どこかで入力が漏れているか、間違っている**ことになります【Typical】。
> だからここは必ず確認されます。

### ステップ④：試算表の作成

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①） |
| **何を受け取るか** | 確定した仕訳データ |
| **何をするか** | 会計ソフトから試算表を出力し、内容を確認する |
| **何を作るか** | **月次試算表**（貸借対照表・損益計算書）／推移表／【Varies】資金繰りの資料 |
| **次に誰へ** | 顧客（⑤で説明） |
| **頻度** | 月次 |

> **用語：試算表（しさんひょう）**
> → その時点までの会計帳簿を集計して、**貸借対照表と損益計算書の形にまとめた一覧表**のこと。
> → 実務例：「4月分の試算表ができました」＝4月末時点で、今期はいくら売上があって、
>    いくら利益が出ていて、現預金がいくら残っているかが分かる表、という意味です。
> → **なぜ毎月作るのか**：決算まで待つと、1年間何も分からないまま過ぎてしまいます。
>    毎月作ることで、社長は「今このくらいの利益が出ている」「このままだと税金がこのくらい」
>    という見通しを持てます【Typical】。

### ステップ⑤：月次報告・打合せ

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①）。重要な顧問先や判断が必要な場面では所長も同席【Varies】 |
| **何を受け取るか** | 試算表、前月からの変化 |
| **何をするか** | 訪問または面談し、試算表を説明する。数字の意味を伝える |
| **何を判断するか** | 顧客に伝えるべき事項があるか（大きな支出の予定、決算の見通し、期限が近い手続 等） |
| **何を作るか** | **月次報告書**【Varies】／打合せの記録 |
| **次に誰へ** | 顧客。所内には次月の課題を共有 |
| **頻度** | 月次 |

> **この業界の「納品」に相当する工程です**【Inference】
> モノを渡さない商売なので、**顧客が「サービスを受けた」と実感するのはこの場面**です。
> 試算表が郵送で届くだけと、担当者が来て説明するのとでは、顧客の受け取り方が変わります。
> 【Varies】訪問頻度は、毎月・隔月・四半期など事務所と顧客の契約により異なります。

### ステップ⑥：質問対応（常時）

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①）。判断が必要な内容は**有資格者**へ |
| **何を受け取るか** | 顧客からの電話・メール |
| **何をするか** | 回答する。内容によっては所長に確認してから回答する |
| **何を作るか** | 回答の記録 |
| **頻度** | 常時 |

> **★ここに独占業務の線が走っています**
> 【Fact】税理士法第2条第1項第3号は「税務相談」を税理士業務と定め、同法第52条がこれを制限しています。
> したがって、顧客からの質問が**税務上の判断を求めるもの**である場合、
> 誰がどう答えるかは、事務所の運用上きわめて慎重に扱われます【Typical】。
> （※どこまでが「相談」に当たるかという個別の法的判断には、本資料は立ち入りません。）

### ステップ⑦：顧問料の請求

| 項目 | 内容 |
|---|---|
| **誰が** | 事務職員（⑥総務・経理機能） |
| **何を受け取るか** | 顧問契約の一覧（契約時に登録された金額） |
| **何をするか** | 月額顧問料の請求書を作成し、送付する。または口座振替の手続をする【Varies】 |
| **何を作るか** | **請求書** |
| **次に誰へ** | 顧客 |
| **頻度** | **月次／請求時** |

### ステップ⑧：入金確認

| 項目 | 内容 |
|---|---|
| **誰が** | 事務職員（⑥） |
| **何を受け取るか** | 事務所の通帳・振替結果 |
| **何を確認するか** | 請求どおりの金額が入っているか。入っていない顧問先はどこか |
| **何をするか** | 消込を行い、未入金があれば担当者に連絡する |
| **何を作るか** | 入金一覧／未入金リスト |
| **次に誰へ** | 担当者（催促）、所長（報告） |
| **頻度** | **月次／入金時** |

> **用語：消込（けしこみ）**
> → 請求した金額と入金された金額を突き合わせて、「この請求分は入金済み」と印をつける作業のこと。
> → 実務例：120件の顧問先に請求し、通帳を見て入金があった分に印をつけていきます【Example】。

### 月次サイクルに乗る法定の期限

| 期限 | 条文の文言（逐語） | 根拠 | 頻度 |
|---|---|---|---|
| 源泉所得税の納付 | 「その支払の際、その給与等について所得税を徴収し、その徴収の日の属する月の翌月十日までに、これを国に納付しなければならない」 | 【Fact】所得税法第183条第1項（出典：e-Gov法令検索） | 法定・契約上のタイミング（毎月） |

【Typical】事務所は、顧問先が納付を忘れないよう、納付書の作成や金額の案内を行うことがあります【Varies】。

## C. 年次の申告業務サイクル（法定期限に向かって走る）

**頻度：年次**（ただし顧問先の決算月ごとに時期が異なる）

### 全体像と期限

```
決算月の末日
   │
   ├─▶ ① 決算資料の収集（決算月の翌月〜）
   │      ↓
   ├─▶ ② 決算整理
   │      ↓
   ├─▶ ③ 決算書の作成
   │      ↓
   ├─▶ ④ 申告書の作成
   │      ↓
   ├─▶ ⑤ 有資格者のチェック  ← ここは分担できない
   │      ↓
   ├─▶ ⑥ 顧客への説明・承認
   │      ↓
   ├─▶ ⑦ 申告（電子申告）     ← 【法人税】事業年度終了の日の翌日から2月以内
   │      ↓                     【消費税】課税期間の末日の翌日から2月以内
   ├─▶ ⑧ 納税額の案内          【所得税】その年の翌年2月16日〜3月15日
   │      ↓
   └─▶ ⑨ 控え・資料の保管・返却
          ↓
       ⑩ 決算料の請求・入金
```

【Fact】期限の根拠（いずれも出典：e-Gov法令検索）：

- **法人税**：法人税法第74条第1項「内国法人は、各事業年度終了の日の翌日から二月以内に、税務署長に対し、
  確定した決算に基づき次に掲げる事項を記載した申告書を提出しなければならない」
- **消費税**：消費税法第45条第1項「事業者（…）は、課税期間ごとに、当該課税期間の末日の翌日から二月以内に、
  次に掲げる事項を記載した申告書を税務署長に提出しなければならない」
- **所得税**：所得税法第120条第1項「…第三期（その年の翌年二月十六日から三月十五日までの期間をいう。…）において、
  税務署長に対し、次に掲げる事項を記載した申告書を提出しなければならない」

【Fact】また、法人税法第74条第3項は「第一項の規定による申告書には、当該事業年度の貸借対照表、損益計算書
その他の財務省令で定める書類を添付しなければならない」と定めています（出典：法人税法／e-Gov法令検索）。
**つまり決算書を作らずに申告書だけ出す、ということはできません。**

### ステップ①：決算資料の収集

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①） |
| **何を受け取るか** | 期末在庫の棚卸表、売掛金・買掛金の残高明細、借入金の残高証明、固定資産の増減、未払いの経費の資料、保険証券、契約書 |
| **何を確認するか** | 月次で処理しきれていなかった論点／期末時点で確定していない取引 |
| **何をするか** | 決算に必要な資料を一覧にして依頼し、回収する |
| **何を作るか** | 決算資料の依頼リスト／受領記録 |
| **次に誰へ** | 自分（②決算整理へ） |
| **頻度** | 年次（決算月の翌月〜） |

### ステップ②：決算整理

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（③申告書作成機能）。小規模事務所では所長 |
| **何を受け取るか** | 12か月分の仕訳データ、決算資料 |
| **何をするか** | 期末時点の正しい姿になるよう帳簿を整える（在庫の計上、減価償却、未払・前払の処理 等） |
| **何を判断するか** | 期をまたぐ取引をどちらの期に入れるか等 ※**個別の税務判断の内容には本資料では立ち入りません** |
| **何を作るか** | 決算整理後の総勘定元帳 |
| **次に誰へ** | 自分（③へ） |
| **頻度** | 年次 |

### ステップ③：決算書の作成

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（③） |
| **何を受け取るか** | 決算整理後の帳簿 |
| **何をするか** | 貸借対照表・損益計算書・株主資本等変動計算書・個別注記表・勘定科目内訳明細書を作成する |
| **何を作るか** | **決算書一式** |
| **次に誰へ** | 自分（④へ）、および⑤チェックへ |
| **頻度** | 年次 |

> **用語：勘定科目内訳明細書（かんじょうかもくうちわけめいさいしょ）**
> → 決算書の主な科目について、「その中身は誰のいくらか」を一覧にした書類のこと。
> → 実務例：売掛金1,000万円の内訳として「A社300万円、B社500万円、C社200万円」と書き出します【Example】。
>    申告書に添付する書類のひとつです。

### ステップ④：申告書の作成

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（③）／所長 |
| **何を受け取るか** | 決算書一式 |
| **何をするか** | 申告ソフトに数値を入力し、法人税・地方法人税・法人事業税・法人住民税・消費税の各申告書を作成する |
| **何を作るか** | **申告書一式**（国税＝税務署宛、地方税＝都道府県・市町村宛） |
| **次に誰へ** | **有資格者（⑤へ）** |
| **頻度** | 年次 |

> **提出先が1か所ではありません**
> 【Typical】法人の申告は、税務署（国税）だけでなく、都道府県税事務所と市町村にも提出します。
> つまり1件の決算で、**複数の役所に、複数の様式を出す**ことになります。

### ステップ⑤：有資格者のチェック（レビュー）

| 項目 | 内容 |
|---|---|
| **誰が** | **有資格者（所長・勤務税理士）。ここは絶対に分担できません** |
| **何を受け取るか** | 決算書、申告書、根拠となった資料 |
| **何を確認するか** | 数字のつながり／前期との整合／処理の適否／添付書類の漏れ／届出の要否 |
| **何をするか** | 確認し、必要があれば差し戻す。問題なければ署名する |
| **何を作るか** | チェック済みの申告書 |
| **次に誰へ** | 担当者（顧客説明の準備へ） |
| **頻度** | 年次 |
| **根拠** | 【Fact】税理士法第2条第1項第2号（税務書類の作成）、同法第52条（税理士業務の制限） |

> **なぜここがボトルネックになるのか**【Inference】
> `03_company-structure.md` 3-5 のとおり、有資格者が2名しかいない事務所では、
> **120件すべてのチェックがこの2名を通ります。**
> 3月決算法人が集中する5月には、この2名の机の上に大量の申告書が積み上がることになります。
> これは能力の問題ではなく、**法律上の責任の所在から生じる構造**です。

### ステップ⑥：顧客への説明・承認

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者＋所長 |
| **何を受け取るか** | チェック済みの決算書・申告書 |
| **何をするか** | 顧客に決算の内容と税額を説明し、内容の確認を受け、**押印または電子署名**をもらう |
| **何を判断するか** | 顧客が内容を理解し承認したか |
| **何を作るか** | 顧客の承認（押印済みの決算書・申告書） |
| **次に誰へ** | 有資格者（⑦送信へ） |
| **頻度** | 年次 |

> **なぜ顧客の承認が必要なのか**
> `02_industry-structure.md` 2-1 のとおり、**申告の義務者は顧客自身**です。
> 事務所は代理しているにすぎません。**顧客が内容を確認し、承認して初めて提出できます**【Typical】。

### ステップ⑦：申告（電子申告）

| 項目 | 内容 |
|---|---|
| **誰が** | **有資格者**（送信の操作は担当者が行う場合もある【Varies】） |
| **何を受け取るか** | 承認済みの申告書一式 |
| **何をするか** | e-Tax（国税）・eLTAX（地方税）で送信する。または紙で提出する |
| **何を確認するか** | **受信通知（送信が受け付けられた記録）が返ってきたか** |
| **何を作るか** | 申告済みの記録／受信通知 |
| **次に誰へ** | 担当者（納税案内へ）、⑥（保管へ） |
| **頻度** | **法定・契約上のタイミング**（法人税：事業年度終了の日の翌日から2月以内 ほか） |

> **受信通知の確認が重要な理由**【Inference】
> 電子申告は「送ったつもり」でエラーになっていることがあり得ます。
> 期限内に受け付けられたという記録を確認して初めて、申告が完了したと言えます。

### ステップ⑧：納税額の案内

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者（①） |
| **何を受け取るか** | 確定した税額 |
| **何をするか** | いくらを、いつまでに、どこへ納めるかを顧客に伝える。納付書を用意する【Varies】 |
| **何を作るか** | 納税の案内／納付書 |
| **次に誰へ** | 顧客 |
| **頻度** | 年次／法定・契約上のタイミング |

> **顧客にとって最も重みのある情報です**【Typical】
> 決算書の細かい数字より、「いくら払うのか」「いつまでに払うのか」が顧客の関心事です。
> **納税資金が用意できているか**は、顧客の資金繰りに直結します。

### ステップ⑨：控え・資料の保管・返却

| 項目 | 内容 |
|---|---|
| **誰が** | 担当者＋事務職員（⑥） |
| **何をするか** | 申告書の控え・決算書を顧客に渡す。預かっていた資料を返却する。事務所の控えを保管する |
| **何を作るか** | 返却の記録／保管された控え |
| **次に誰へ** | 顧客 |
| **頻度** | 年次 |
| **関連する法定の義務** | 【Fact】税理士法第41条第1項「税理士は、税理士業務に関して帳簿を作成し、委嘱者別に、かつ、一件ごとに、税務代理、税務書類の作成又は税務相談の内容及びそのてん末を記載しなければならない」／同条第2項「前項の帳簿は、閉鎖後五年間保存しなければならない」（出典：税理士法／e-Gov法令検索） |

> **返却も業務です**
> `02_industry-structure.md` 2-4 のとおり、預り資料の所有者は顧客です。
> 返し忘れたまま事務所に置いておくと、顧客が税務調査のときに資料を出せない、
> といった問題につながります【Inference】。

### ステップ⑩：決算料の請求・入金

| 項目 | 内容 |
|---|---|
| **誰が** | 事務職員（⑥） |
| **何をするか** | 決算料を請求する。顧問料とは別建てで請求するのが一般的【Typical】 |
| **何を作るか** | 請求書 |
| **頻度** | **請求時**（決算・申告の完了時） |

## D. スポット業務（案件発生時）

**頻度：案件発生時**

【Typical】顧問業務と並行して、次のような単発の業務が入ります。

| 業務 | きっかけ | 誰が担うか | 期限の性質 |
|---|---|---|---|
| 相続税の申告 | 顧客の親族に相続が発生した | 所長＋担当者 | 法定の期限がある |
| 会社設立に伴う税務の届出 | 顧客が会社を作った | 担当者 | 法定の期限がある |
| 税務調査の対応 | 税務署から連絡が来た | **所長（有資格者）** | トラブル発生時 |
| 融資の申込みに伴う資料作成 | 顧客が借入を検討 | 担当者＋所長 | 顧客の都合 |
| 年末調整 | 毎年11〜12月 | 担当者 | 法定・契約上のタイミング |
| 就業規則の作成（社労士） | 従業員が増えた | 社労士 | 【Fact】労働基準法第89条「常時十人以上の労働者を使用する使用者は、…就業規則を作成し、行政官庁に届け出なければならない」 |

> **スポット業務がフローに与える影響**【Inference】
> スポット業務は**予定に入っていない仕事**として割り込んできます。
> 特に税務調査の対応は、**顧客にとって最も重要な場面でありながら、時期を選べません。**
> しかもそれが繁忙期に重なることがあります。

## E. ★専門サービス業に固有の論点（フローを読むうえでの6つの前提）

### ① 期限が法律で決まっており、動かせない

`02_industry-structure.md` 2-6 ③および本ファイル C の条文一覧のとおりです。
**顧客の都合でも、事務所の都合でも、期限は動きません。**
【Inference】したがってフロー全体が「期限から逆算して組み立てられる」構造になります。

### ② 資料が揃わないと仕事が進まない

本ファイル B ①で述べたとおりです。**仕事の起点が、事務所の外（顧客）にあります。**
【Inference】このため、事務所の業務管理の中心的な作業は「進捗管理」ではなく
「**どの顧問先の、何月分の資料が、まだ来ていないか**」の管理になります。

### ③ 預り資料の管理

`02_industry-structure.md` 2-4 のとおり、預り資料は顧客の財産であり、秘密情報です。
フローの中では、**受領（A⑧・B①）と返却（C⑨）の両方で記録を残す**ことが対応する工程になります【Typical】。

### ④ 守秘義務

`01_overview.md` 1-3 に条文を掲載しています。
フロー上は、**B⑤の月次報告、B⑥の質問対応、D の税務調査対応**など、
外部と情報をやり取りするあらゆる場面で効いてきます。

### ⑤ 報酬の請求タイミングが業務のタイミングと一致しない

**これはこの業界のお金の流れを理解するうえで重要な点です。**

| 報酬 | いつ請求するか | 業務との関係 |
|---|---|---|
| **顧問料** | 月次（毎月） | 業務量に関係なく毎月同額【Typical】。忙しい月も暇な月も同じ |
| **決算料** | 決算・申告の完了時（年1回） | **作業は決算月の翌月から2か月間に集中するが、請求は最後**【Inference】 |
| **スポット報酬** | 業務完了時／納品時（【Varies】着手時に一部） | 案件ごと |
| **成功報酬** | 成果の確定時 | 成果が出なければ請求できない |

> **【Example】説明用の例（架空の数値です）**
> 3月決算の顧問先について、事務所は4月と5月に大量の作業をします。
> しかし決算料20万円を請求できるのは、申告が終わった5月末です。
> つまり**作業をしている間、そのぶんのお金はまだ入っていません。**
> 一方、職員の給与は毎月払わなければなりません。
> この時間差が、`12_business-model.md` で扱う資金繰りの論点になります。

### ⑥ 繁忙期が集中する

| 時期 | 集中する業務 | 根拠となる期限 |
|---|---|---|
| 1月 | 法定調書・給与支払報告書の提出 | 法定・契約上のタイミング |
| **2月16日〜3月15日** | **所得税の確定申告** | 【Fact】所得税法第120条第1項 |
| 3月末〜4月 | 3月決算法人の決算作業 | 【Fact】法人税法第74条第1項（5月末が期限） |
| **5月** | **3月決算法人の法人税・消費税申告** | 【Fact】法人税法第74条第1項、消費税法第45条第1項 |
| 6月1日〜7月上旬 | **労働保険の年度更新**（社労士） | 【Fact】労働保険徴収法第19条第1項「次の保険年度の六月一日から四十日以内」 |
| **〜7月10日** | **算定基礎届**（社労士） | 【Fact】健康保険法施行規則第25条第1項「毎年七月一日現に使用する被保険者（…）の報酬月額に関する法第四十八条の規定による届出は、同月十日までに…」 |
| 11〜12月 | 年末調整 | 法定・契約上のタイミング |
| 毎月10日 | 源泉所得税の納付 | 【Fact】所得税法第183条第1項 |

【Inference】税理士事務所と社会保険労務士事務所で繁忙期がずれているのは、
**根拠となる法律が違うから**です。同じ「士業」でも、1年の形が違います。

### 1年間の流れ

| 時期 | 何が起きるか | 誰が何をするか | 頻度の分類 |

| **4月** | 新年度の開始。前年度（3月期）の決算作業が始まる | Kさんが決算資料の依頼リストを渡す。並行して3月分の月次処理 | 月次＋年次 |

### この1年から読み取ってほしい4点

1. **月次（B）と年次（C）が重なっている。**
   4月〜5月は、3月分の月次処理と、前年度の決算作業が同時に走ります。
2. **所長が登場するのは、限られた場面だけ。**
   月次はKさんが回し、所長は**チェック（5月中旬）・決算報告（5月下旬）・決算対策の相談（3月中旬）**に出てきます。
   これが `03_company-structure.md` 3-5 の「実行と責任の分離」の実際の姿です。
3. **事務所の繁忙期と、この顧問先の重要な時期がずれている。**
   事務所の最大繁忙期は2〜3月ですが、Z商事の決算は3月末で、作業の山は4〜5月です。
   顧問先ごとに決算月が違うため、**事務所全体では山がならされる面と、集中する面の両方があります**【Inference】。
4. **お金の入り方が均一ではない。**
   毎月3万円（年36万円）に対し、5月に20万円、12月に5万円が加わります。
   年間61万円のうち、**約4割が特定の月に集中しています**【Example】。

## 4-9. まとめ：この章で押さえるべき6点

1. **フローは1本ではなく3本＋1本**（A新規受任／B月次／C年次／Dスポット）が同時に走る。
2. **A（受任）で最も重要なのは「何を引き受け、何を引き受けないか」を決めること。**
3. **B（月次）の実質的な起点は、顧客が資料を出してくれること。** 揃わないと全工程が止まる。
4. **C（年次）の最後には必ず有資格者のチェックがあり、ここは分担できない。**
5. **期限は法律が決めている。** 動かせない。だからフローは期限から逆算して組む。
6. **作業のタイミングと請求のタイミングがずれる。** 特に決算料は作業の後に請求する。
