# 06_people.md — ヒトの流れ（専門サービス業）

**対象**：日本国内の中小の専門サービス業（主モデル：税理士事務所／対比：社会保険労務士事務所）
**読み手**：専門サービス業をまったく知らない人
**前提**：`03_company-structure.md` で設定した**【Example】X会計事務所**
（有資格者2名・職員7名＝計9名／顧問先120件／年商7,000万円。架空）
および**【Example】Y社会保険労務士事務所**（4名／顧問先60社／年商3,000万円。架空）
**最終更新**：2026-09-20

> このファイルは、`common/methodology.md` §6 の「4つの流れ」のうち**ヒト**を扱います。
> 「誰が誰と関わるか」「誰が判断・承認・実行するか」を、事務所の中と外の両方について整理します。
> 各機能の中の業務そのものは `05_departments.md` に書いてあります。
> ここで見るのは、**機能と機能の間**、そして**事務所と事務所の外の間**です。

## 6-0. この章の前に——この業界の「ヒト」が特殊な理由

### ① 売っているのは、人の知識・資格・信用である

【Typical】製造業では、人は「材料を製品に変える人」です。売っているのは製品です。
小売業では、人は「商品を仕入れて売る人」です。売っているのは商品です。

専門サービス業では、**売っているものが人そのものに貼り付いています。**

```
  製造業     ：材料   → 人と機械 → 製品   → 売る
  小売業     ：商品   → 人と店舗 → 商品   → 売る
  専門サービス：（無い）→ 人の知識 → 書類・助言 → 売る
```

`01_overview.md` 1-8 のとおり、この業界には**仕入も在庫もありません。**
だから「人が足りない」は、そのまま「売れる量が足りない」ことを意味します【Inference】。
人を増やす以外に処理量を増やす道が、構造的に限られています。

### ② 有資格者にしかできない行為がある

これが、他の業界との最大の違いです。

製造業では、熟練工がやっても新人がやっても、**出来上がった製品が同じなら、それは同じ製品**です
（品質の話は別にあります）。
専門サービス業では違います。**誰がやったかによって、それが適法かどうかが変わる行為**があります。

【Fact】税理士法第52条（税理士業務の制限）は、次のとおり定めています。

> 「税理士又は税理士法人でない者は、この法律に別段の定めがある場合を除くほか、
> 税理士業務を行つてはならない。」（出典：税理士法／e-Gov法令検索）

この一文が、事務所の組織の形を決めています。
**実行（作業）は分担できても、責任は有資格者から離れません。**
詳細は 6-3 で、**士業ごとに条文を分けて**示します。

### ③ 仕事の起点が、事務所の外にある

【Typical】担当者が今日やるべき仕事は、**顧客が資料を出してくれたかどうか**で決まります。
`04_end-to-end-process.md` E② のとおり、資料が揃わないと工程は進みません。

つまりこの業界のヒトの流れは、**事務所の中だけを見ても完結しません。**
顧問先の社長や経理担当者が、事務所の業務プロセスの一部に組み込まれている、という見方が必要です。

### ④ 顧客から見える「事務所の顔」は、所長ではないことが多い

【Example】X会計事務所の顧問先120件のうち、所長が日常的に担当しているのは15件です
（`03_company-structure.md` 3-7）。
残り105件の顧客にとって、毎月会う相手は**担当者**です。そのうち無資格の担当者は3名います。

この「**接する人と、責任を負う人が違う**」という構造が、6-6 で扱う論点につながります。

## 6-1. 事務所の中のヒト（誰が誰と関わるか）

### 登場人物の一覧

| 呼び方 | 【Example】X会計事務所での人数 | 資格 | 主に担う機能（`03_company-structure.md` 3-4） |
|---|---:|---|---|
| **所長**（所長税理士） | 1名 | 税理士 | ⑤営業／④チェック／①顧客対応（主要先）／⑦教育 |
| **勤務税理士** | 1名 | 税理士 | ④チェック／①顧客対応／③申告書作成 |
| **主任担当者** | 1名 | なし（科目合格） | ①顧客対応／③申告書作成／②の指示出し |
| **担当者** | 2名 | なし | ①顧客対応／③申告書作成 |
| **入力担当（パート）** | 2名 | なし | ②記帳代行・入力 |
| **事務職員** | 1名 | なし | ⑥総務・経理 |
| **合計** | **9名** | 有資格者2名 | |

> **「部」は存在しません**
> 【Typical】9名の事務所に「営業部」「品質管理部」はありません。
> あるのは**機能**と、それを兼務する人です。
> `03_company-structure.md` 3-4 の7機能を、この9名で分け合っている、という読み方をしてください。

### 事務所内のヒトの流れ（テキスト図）

                          └──┬───────┬──────────┬──┘
           受任の指示・担当割当  │       │ 差し戻し   │ 会費・登録・請求の承認
                                ▼       │            ▼
                    ┌──────────────────┐│   ┌──────────────────┐
                    │ ①顧客対応（担当者）  ││   │ ⑥総務・経理（事務職員）│
                    │  訪問・資料受領     ││   │  請求・入金・給与・保管 │

                          ▼        │      │         （担当者へ催促の依頼）
                  ┌──────────────┐ │      │
                  │ ②記帳代行・入力 │ │      │
                  │  仕訳入力・保留  │─┘      │
                  └──────┬───────┘         │

### 主な「人と人のつながり」を1本ずつ見る

#### ① 所長 → 担当者（指示・割当・差し戻し）

- **何が流れるか**：どの顧問先を誰が担当するか（担当割当）／受任した新しい顧問先の引継ぎ／
  チェックで見つかった修正指示（差し戻し）。
- **頻度**：担当割当は**年次**または**案件発生時**（`05_departments.md` ⑦-7／⑦-8）。
  差し戻しは**案件発生時**（決算・申告のたび）。
- **なぜ必要か**：④チェック機能は所長と勤務税理士の2名しかいません。
  【Example】120件すべての決算・申告が、この2名の机を通ります。
  ここで見つかった誤りは、作った本人に戻さなければ直りません。

#### ② 担当者 → 入力担当（預り資料と仕訳の依頼）

- **何が流れるか**：顧問先から預かった通帳のコピー・領収書・請求書の束／
  「この顧問先の○月分をお願いします」という依頼／科目の判断の指示。
- **頻度**：**月次**。
- **なぜ必要か**：入力担当は顧客に会いません。
  **顧客の事情を知っているのは担当者だけ**なので、判断のつかない取引は担当者に戻ります
  （`05_departments.md` ②-7「不明点の洗い出しと保留（仮勘定）処理」）。

#### ③ 入力担当 → 担当者（保留項目の差し戻し）

- **何が流れるか**：「内容の分からない支出が7件ありました」という保留の一覧。
- **頻度**：**月次**。
- **なぜ必要か**：入力担当が推測で科目を決めてしまうと、帳簿が事実と違うものになります。
  分からないものは**分からないまま止めて、聞ける人に渡す**のが正しい流れです。

#### ④ 担当者 → 所長・勤務税理士（判断を仰ぐ）

- **何が流れるか**：顧客から受けた質問のうち、**税務上の判断を求めるもの**。
- **頻度**：**常時**。
- **なぜ必要か**：**ここに資格の線が走っています。**
  【Fact】税理士法第2条第1項第3号は「税務相談」を税理士業務と定め、同法第52条がこれを制限しています
  （出典：税理士法／e-Gov法令検索）。条文の語は 6-3 で全文を示します。

#### ⑤ 事務職員 → 担当者（未入金の連絡）

- **何が流れるか**：「A社の顧問料が2か月分入っていません」という連絡。
- **頻度**：**月次／入金時**。
- **なぜ必要か**：事務職員は顧客と日常的な関係を持ちません。
  督促の連絡は、関係のある担当者から行われることが多くあります【Typical】。

#### ⑥ 所長 → 全員（税制改正・法改正の共有）

- **何が流れるか**：改正された制度の内容と、どの顧問先に影響するか。
- **頻度**：**年次**（改正の公表時期に合わせる）および**案件発生時**。
- **なぜ必要か**：【Inference】制度が変わったことを知らずに前年と同じ処理をすると、
  それが全顧問先に同時に波及します。**1人の知識不足が、事務所全体の誤りになる構造**です。

## 6-2. 事務所の外のヒト（社外関係者）

### 全体像

```
                    ┌──────────────────┐
                    │  ⑦ 士業会（税理士会等） │ 登録・会費・研修
                    └────────┬─────────┘
                             │
  ┌──────────┐  資料・質問   ┌┴──────────────┐  申告・申請  ┌─────────────┐
  │ 顧問先     │─────────────▶│               │────────────▶│ 税務署・年金事務所 │
  │ 社長／経理  │◀─────────────│   X会計事務所    │◀────────────│ 労基署・法務局 等 │
  └──────────┘ 試算表・申告書 │               │  調査の通知   └─────────────┘
        │                    └──┬────────┬──┘
        │ 融資の相談              │        │
        ▼                        │        │ 業務の紹介・引継ぎ
  ┌──────────┐  決算書の提出     │        ▼
  │ 金融機関    │◀────────────────┘  ┌──────────────┐
  └──────────┘                      │ 他士業          │
                                     │ 社労士・司法書士 │
  ┌──────────────┐  保守・改正対応    │ 行政書士・弁護士 │
  │ ソフトウェアベンダー │◀──────────────└──────────────┘
  └──────────────┘
```

### ① 顧問先の社長 — 最も重要な相手

| 項目 | 内容 |
|---|---|
| **誰が窓口になるか** | 所長（主要先・重要な判断の場面）／担当者（月次のやり取り） |
| **何をやり取りするか** | 資料の受渡し、試算表の説明、決算の見込み、税額の説明、承認、押印 |
| **頻度** | **月次**（月次報告）＋**年次**（決算報告）＋**常時**（質問） |
| **なぜ社長本人なのか** | 中小企業では、**お金の使い方を決めているのが社長本人**であることが多いためです【Typical】。経理担当者では答えられない質問（この支出は何か、この入金は何か）が発生します |

> **【Example】説明用の例（架空）**
> Z商事株式会社（3月決算・従業員8名）には経理専任者がいません。
> 社長の配偶者が経理を兼務しています（`04_end-to-end-process.md` F）。
> 担当者Kさんは毎月この配偶者から資料を受け取り、
> 内容の分からない支出については**社長本人に直接聞きます。**

### ② 顧問先の経理担当者

| 項目 | 内容 |
|---|---|
| **誰が窓口になるか** | 担当者（①顧客対応機能）、入力担当が電話で確認することもある【Varies】 |
| **何をやり取りするか** | 月次資料の受渡し、残高の照合、質問リストへの回答、給与データの提供 |
| **頻度** | **月次**＋**常時** |
| **なぜ重要か** | 【Inference】経理担当者がいる顧問先と、いない顧問先では、**事務所の作業量が大きく変わります。** 経理担当者が自社で入力していれば、②記帳代行・入力機能の作業は「入力」から「点検」に変わります（`05_departments.md` ②-9） |

> **顧客の協力が、事務所の生産性をそのまま左右します**
> 【Inference】資料が月初に整理された状態で届く顧問先と、
> 決算直前に1年分の領収書が段ボールで届く顧問先とでは、同じ報酬でも作業量が違います。
> これは**事務所の努力だけでは動かせない変数**です。
> （※本資料は、どちらが良い・悪いという評価はしません。構造として記述します。）

### ③ 金融機関

| 項目 | 内容 |
|---|---|
| **誰が窓口になるか** | 所長（【Typical】）。担当者が資料作成を担うこともある |
| **何をやり取りするか** | 顧問先の融資申込みに伴う決算書・試算表・資金繰り表の提出【Varies】／新規顧問先の紹介 |
| **頻度** | **案件発生時**（顧問先が借入を検討したとき）／**年次**（決算書の提出） |
| **なぜ関わるか** | 【Typical】金融機関は融資の判断に決算書を使います。その決算書を作っているのが事務所だからです。また `02_industry-structure.md` のとおり、**金融機関は新規顧問先の主要な紹介経路の一つ**です |

> **★守秘義務がここで効いてきます**
> 【Fact】税理士法第38条（秘密を守る義務）は次のとおり定めています。
> 「税理士は、正当な理由がなくて、税理士業務に関して知り得た秘密を他に洩らし、又は窃用してはならない。
> 税理士でなくなつた後においても、また同様とする。」（出典：税理士法／e-Gov法令検索）
> 金融機関に顧問先の情報を渡す場面では、**顧客の意思に基づくかどうか**が前提になります。
> 詳しくは `09_information-flow.md`（本セットの `pro_09`）で扱います。

### ④ 他士業

| 相手 | どういう場面で関わるか | 頻度 |
|---|---|---|
| **社会保険労務士** | 顧問先が従業員を雇った／就業規則が必要になった／助成金の相談 | 案件発生時 |
| **司法書士** | 顧問先が会社を設立する／役員変更の登記／不動産の名義変更 | 案件発生時 |
| **行政書士** | 顧問先の事業に許認可が必要になった | 案件発生時 |
| **弁護士** | 顧問先に法的紛争が生じた／相続で争いがある | トラブル発生時 |
| **不動産鑑定士・土地家屋調査士** | 相続案件で土地の評価・測量が必要になった | 案件発生時 |

【Typical】`01_overview.md` 1-6 のとおり、これらは競合ではなく**役割分担**の関係です。
1人の顧客に複数の専門家が関わるため、**専門家どうしの紹介**が発生します。

> **なぜ「その場で引き受けてしまわない」のか**
> 【Fact】それぞれの法律が、**その資格を持つ者以外が行うことを制限している**からです。
> 6-3 で条文を示しますが、**制限の条件は法律ごとに違います。**
> 「士業には独占業務がある」とまとめてはいけません（`01_overview.md` 1-6 の注記）。

### ⑤ 行政（税務署・国税局・都道府県・市町村・年金事務所・労働基準監督署・ハローワーク）

| 相手 | どういう場面で関わるか | 誰が対応するか | 頻度 |
|---|---|---|---|
| **税務署** | 申告書の提出／届出書の提出／税務調査の連絡・立会い／問い合わせ | **有資格者**（税務代理） | 年次／トラブル発生時 |
| **都道府県・市町村** | 地方税の申告・届出／給与支払報告書の提出 | 担当者が作成、有資格者が確認 | 年次／法定・契約上のタイミング |
| **年金事務所** | 算定基礎届・資格取得届・喪失届の提出（社労士業務） | 社会保険労務士 | 年次／案件発生時 |
| **労働基準監督署** | 労働保険の年度更新／就業規則の届出（社労士業務） | 社会保険労務士 | 年次／案件発生時 |
| **法務局** | 登記の申請（司法書士業務） | 司法書士 | 案件発生時 |

> **★税務調査の場面は、有資格者の関与が条文に現れます**
> 【Fact】税理士法第34条第1項（調査の通知）は、次のとおり定めています。
> 「税務官公署の当該職員は、租税の課税標準等を記載した申告書を提出した者について、
> 当該申告書に係る租税に関しあらかじめその者に日時場所を通知してその帳簿書類…を調査する場合において、
> 当該租税に関し第三十条の規定による書面を提出している税理士があるときは、
> 併せて当該税理士に対しその調査の日時場所を通知しなければならない。」
> （出典：税理士法／e-Gov法令検索）
>
> つまり、**第30条の書面（税務代理権限証書）を出している税理士がいれば、
> 税務署はその税理士にも調査の日時場所を通知します。**
> 逆にいえば、この書面を出していなければ、通知の対象になりません。
> 「誰が代理人なのか」を書面で明示しておくことが、この場面の前提になっています。

### ⑥ ソフトウェアベンダー

| 項目 | 内容 |
|---|---|
| **誰が窓口になるか** | 所長または主任担当者【Varies】 |
| **何をやり取りするか** | 会計ソフト・申告書作成ソフトの保守契約、税制改正に伴うプログラム更新、操作の問い合わせ |
| **頻度** | **年次**（更新・契約更改）／**トラブル発生時** |
| **なぜ関わるか** | 【Inference】税制が変われば申告書の様式も計算も変わります。事務所が自力で様式を作り直すことはできないため、ソフトの更新が業務の前提になります。詳細は `11_systems.md`（本セットの `pro_11`）で扱います |

### ⑦ 士業会（税理士会・社会保険労務士会 等）

| 項目 | 内容 |
|---|---|
| **誰が窓口になるか** | **有資格者本人**（登録・会費・研修は個人に紐づく） |
| **何をやり取りするか** | 登録、登録事項の変更届、会費の納入、研修の受講、会からの通知 |
| **頻度** | **年次**（会費・研修）／**案件発生時**（登録事項の変更） |
| **根拠** | 【Fact】税理士法第39条（会則を守る義務）「税理士は、所属税理士会及び日本税理士会連合会の会則を守らなければならない。」／同法第39条の2（研修）「税理士は、所属税理士会及び日本税理士会連合会が行う研修を受け、その資質の向上を図るように努めなければならない。」（出典：税理士法／e-Gov法令検索） |

> **ここは事務所ではなく「人」に付いています**
> 登録も会費も研修も、**事務所ではなく有資格者個人**に対する制度です。
> だから所長が代わると、これらも付いて動きます【Inference】。
> 詳細は `13_routine-tasks.md`（本セットの `pro_13`）と `15_rules.md`（同 `pro_15`）で扱います。

## 6-3. ★有資格者しかできない行為と、無資格の職員ができる行為の線引き

**この節が、このファイルで最も重要です。**

`common/methodology.md` §2「法令の要件を書くときの鉄則」に従い、
**条文の語をそのまま引用します。要約・言い換えはしません。**
そして**士業ごとに根拠条文が違うため、法律ごとに分けて書きます。まとめません。**

### 6-3-1. 税理士法

#### 何が「税理士業務」なのか（第2条第1項）

【Fact】税理士法第2条第1項は、次の3つを掲げています（出典：税理士法／e-Gov法令検索）。

> 「税理士は、他人の求めに応じ、租税（…）に関し、次に掲げる事務を行うことを業とする。
> **一　税務代理**（税務官公署（…）に対する租税に関する法令若しくは行政不服審査法（…）の規定に基づく
> 申告、申請、請求若しくは不服申立て（…以下「申告等」という。）につき、
> 又は当該申告等若しくは税務官公署の調査若しくは処分に関し税務官公署に対してする主張若しくは陳述につき、
> 代理し、又は代行すること（次号の税務書類の作成にとどまるものを除く。）をいう。）
> **二　税務書類の作成**（税務官公署に対する申告等に係る申告書、申請書、請求書、不服申立書その他
> 租税に関する法令の規定に基づき、作成し、かつ、税務官公署に提出する書類（…）で財務省令で定めるもの
> （以下「申告書等」という。）を作成することをいう。）
> **三　税務相談**（税務官公署に対する申告等、第一号に規定する主張若しくは陳述又は申告書等の作成に関し、
> 租税の課税標準等（…）の計算に関する事項について相談に応ずることをいう。）」

やさしい言い換え（※これは条文ではなく、本資料による説明です）：

| 号 | 条文の語 | 何をすることか（本資料の説明） |
|---|---|---|
| 第1号 | **税務代理** | 顧客の代わりに、税務署などに対して申告・申請をしたり、主張・陳述をすること |
| 第2号 | **税務書類の作成** | 税務署などに出す申告書・申請書などを作ること |
| 第3号 | **税務相談** | 税額の計算に関わることについて、相談に応じること |

#### 誰がそれを行ってはならないのか（第52条）

【Fact】税理士法第52条（税理士業務の制限）

> 「税理士又は税理士法人でない者は、この法律に別段の定めがある場合を除くほか、
> 税理士業務を行つてはならない。」（出典：税理士法／e-Gov法令検索）

> **★ここに注目してください**
> **この条文に「報酬を得て」という語はありません。**
> 後で見る社会保険労務士法第27条・行政書士法第19条第1項には「報酬を得て」に当たる文言がありますが、
> 税理士法第52条にはありません。**法律ごとに条件が違います。**

#### 無資格の職員が担える業務が、条文のどこに書かれているか（第2条第2項）

【Fact】税理士法第2条第2項

> 「税理士は、前項に規定する業務（以下「税理士業務」という。）のほか、税理士の名称を用いて、
> 他人の求めに応じ、税理士業務に付随して、**財務書類の作成、会計帳簿の記帳の代行**その他
> 財務に関する事務を業として行うことができる。ただし、他の法律においてその事務を業として
> 行うことが制限されている事項については、この限りでない。」（出典：税理士法／e-Gov法令検索）

**「税理士業務」と定義されているのは第1項の3つだけ**であり、
**記帳の代行は第2項に別に規定されています。**
第52条が制限しているのは「税理士業務」＝第1項の3つです。

#### 補助者についての条文（第2条第3項）

【Fact】税理士法第2条第3項

> 「前二項の規定は、税理士が他の税理士又は税理士法人（…）の補助者として前二項の業務に
> 従事することを妨げない。」（出典：税理士法／e-Gov法令検索）

> **本資料の姿勢**
> この条文は「**税理士が**他の税理士・税理士法人の補助者として従事すること」について定めています。
> 無資格者の補助がどこまで許されるかという線引きは、**個別の事案ごとの法的判断**になります。
> `03_company-structure.md` 3-5 と同じく、**本資料は個別の適法性の判断に立ち入りません。**
> ここで押さえるべきは、**「実行は分担できるが、責任は有資格者から離れない」という構造がある**ことです。

#### 職員を使うときの、有資格者の義務（第41条の2）

【Fact】税理士法第41条の2（使用人等に対する監督義務）

> 「税理士は、税理士業務を行うため使用人その他の従業者を使用するときは、
> 税理士業務の適正な遂行に欠けるところのないよう当該使用人その他の従業者を監督しなければならない。」
> （出典：税理士法／e-Gov法令検索）

> **★これは組織論の条文です**
> 「職員に任せてよいか」ではなく、「**職員を使うなら監督しなさい**」と書かれています。
> 【Inference】所長が全件を見る構造は、事務所の方針である以前に、この条文が前提にしている形です。

#### そのほか、有資格者に名指しで課されている義務

| 条 | 見出し | 条文の語（抜粋・逐語） |
|---|---|---|
| **第30条** | 税務代理の権限の明示 | 「税理士は、税務代理をする場合においては、財務省令で定めるところにより、その権限を有することを証する書面を税務官公署に提出しなければならない。」 |
| **第33条第1項** | 署名の義務 | 「税理士又は税理士法人が税務代理をする場合において、租税に関する申告書等を作成して税務官公署に提出するときは、当該税務代理に係る税理士は、当該申告書等に署名しなければならない。」 |
| **第33条第2項** | 同上 | 「税理士又は税理士法人が税務書類の作成をしたときは、当該税務書類の作成に係る税理士は、当該書類に署名しなければならない。」 |
| **第36条** | 脱税相談等の禁止 | 「税理士は、不正に国税若しくは地方税の賦課若しくは徴収を免れ、又は不正に国税若しくは地方税の還付を受けることにつき、指示をし、相談に応じ、その他これらに類似する行為をしてはならない。」 |
| **第37条の2** | 非税理士に対する名義貸しの禁止 | 「税理士は、第五十二条又は第五十三条第一項から第三項までの規定に違反する者に自己の名義を利用させてはならない。」 |
| **第38条** | 秘密を守る義務 | 「税理士は、正当な理由がなくて、税理士業務に関して知り得た秘密を他に洩らし、又は窃用してはならない。税理士でなくなつた後においても、また同様とする。」 |
| **第41条の3** | 助言義務 | 「税理士は、税理士業務を行うに当たつて、委嘱者が不正に国税若しくは地方税の賦課若しくは徴収を免れている事実…があることを知つたときは、直ちに、その是正をするよう助言しなければならない。」 |

（いずれも出典：税理士法／e-Gov法令検索）

> **第33条の署名は「誰がやったか」を書面に残す仕組みです**
> 第33条第1項は「**当該税務代理に係る税理士**は、当該申告書等に署名しなければならない」と書いています。
> 事務所の名前ではなく、**その業務に関わった税理士個人**が署名します。
> 【Inference】担当者が下書きを作っても、署名する人は署名する人の責任で内容を確認することになります。
> これが `03_company-structure.md` 3-4 ④チェック・レビュー機能が分担できない理由です。

### 6-3-2. 社会保険労務士法（★税理士法とは条件が違います）

【Fact】社会保険労務士法第27条（業務の制限）

> 「社会保険労務士又は社会保険労務士法人でない者は、**他人の求めに応じ報酬を得て**、
> 第二条第一項第一号から第二号までに掲げる事務を業として行つてはならない。
> ただし、他の法律に別段の定めがある場合及び政令で定める業務に付随して行う場合は、この限りでない。」
> （出典：社会保険労務士法／e-Gov法令検索）

**この条文には「報酬を得て」という語があります。税理士法第52条には、この語はありません。**

さらに、制限の範囲が**第2条第1項第1号から第2号まで**に限定されている点も重要です。

【Fact】社会保険労務士法第2条第1項の各号（抜粋・逐語。出典：社会保険労務士法／e-Gov法令検索）

> 「一　別表第一に掲げる労働及び社会保険に関する法令（以下「労働社会保険諸法令」という。）に基づいて
> 申請書等（…）を作成すること。
> 一の二　申請書等について、その提出に関する手続を代わつてすること。
> 一の三　労働社会保険諸法令に基づく申請、届出、報告、審査請求、再審査請求その他の事項（…）について、
> 又は当該申請等に係る行政機関等の調査若しくは処分に関し当該行政機関等に対してする主張若しくは陳述（…）
> について、代理すること（…「事務代理」という。）。
> …
> 二　労働社会保険諸法令に基づく帳簿書類（…）を作成すること。
> 三　事業における労務管理その他の労働に関する事項及び労働社会保険諸法令に基づく社会保険に関する事項に
> ついて相談に応じ、又は指導すること（…）。」

> **★「第三号」が制限の外にあります**
> 第27条が制限しているのは「第二条第一項**第一号から第二号まで**」です。
> **第三号（相談に応じ、又は指導すること）は、この制限の条文に列挙されていません。**
> `01_overview.md` 1-6 の比較表にも同じ注記があります。
>
> **税理士法では「税務相談」が第2条第1項第3号として税理士業務に含まれ、第52条で制限されています。**
> **社会保険労務士法では、相談・指導は第27条の制限の範囲に入っていません。**
> **この2つを「士業には独占業務がある」と一文にまとめると、両方の姿を取り違えます。**

職員の守秘義務についても、社会保険労務士法には**別の条文**があります。

【Fact】社会保険労務士法第27条の2（開業社会保険労務士の使用人等の秘密を守る義務）

> 「開業社会保険労務士又は社会保険労務士法人の使用人その他の従業者は、正当な理由がなくて、
> その業務に関して知り得た秘密を他に漏らし、又は盗用してはならない。
> 開業社会保険労務士又は社会保険労務士法人の使用人その他の従業者でなくなつた後においても、また同様とする。」
> （出典：社会保険労務士法／e-Gov法令検索）

> **★ここは税理士法との重要な違いです**
> 社会保険労務士法は、**使用人その他の従業者（＝無資格の職員）に対して、法律が直接に守秘義務を課しています。**
> 【Fact】有資格者本人については同法第21条（秘密を守る義務）が別に定めています。
> 一方、税理士法第38条は「税理士は」と書かれており、職員に対しては第41条の2で
> **税理士に監督義務を課す**という形になっています。**義務の掛け方の構造が違います。**

なお、社会保険労務士法第28条は「業務の制限」ではありません。

【Fact】社会保険労務士法第28条（資質向上のための援助）

> 「厚生労働大臣は、社会保険労務士の資質の向上を図るため、講習会の開催、資料の提供その他必要な援助を
> 行なうように努めるものとする。」（出典：社会保険労務士法／e-Gov法令検索）

これは**国の側の努力義務**を定めた条文であり、士業側の義務ではありません。条番号が近いだけです。

### 6-3-4. 司法書士法（★「報酬を得て」がありません）

> 三　法務局又は地方法務局の長に対する登記又は供託に関する審査請求の手続について代理すること。
> 四　裁判所若しくは検察庁に提出する書類若しくは電磁的記録又は筆界特定の手続（…）において
> 法務局若しくは地方法務局に提出し若しくは提供する書類若しくは電磁的記録を作成すること。
> 五　前各号の事務について相談に応ずること。」

### 6-3-6. 公認会計士法

【Fact】公認会計士法第47条の2（公認会計士又は監査法人でない者の業務の制限）

### 6-3-7. ★「報酬を得て」という条件の有無を並べて見る

**同じ「業務の制限」でも、条文の語が違います。**

| 法律 | 条 | 制限される者 | 「報酬」に関する条文の語 |
|---|---|---|---|
| **税理士法** | 第52条 | 税理士又は税理士法人でない者 | **記載されていない** |
| **社会保険労務士法** | 第27条 | 社会保険労務士又は社会保険労務士法人でない者 | 「他人の求めに応じ**報酬を得て**」 |
| **行政書士法** | 第19条第1項 | 行政書士又は行政書士法人でない者 | 「他人の依頼を受け**いかなる名目によるかを問わず報酬を得て**」 |
| **司法書士法** | 第73条第1項 | **司法書士会に入会している**司法書士又は司法書士法人でない者 | **記載されていない** |
| **弁護士法** | 第72条 | 弁護士又は弁護士法人でない者 | 「**報酬を得る目的で**」 |
| **公認会計士法** | 第47条の2 | 公認会計士又は監査法人でない者 | 「他人の求めに応じ**報酬を得て**」 |

（いずれも出典：各法／e-Gov法令検索）

> **この表を一文にまとめてはいけません**
> 「無報酬なら誰がやってもよい」と読むことはできません。
> **税理士法第52条と司法書士法第73条第1項には、報酬に関する語が置かれていません。**
> 一方で、司法書士法第73条第1項には**「司法書士会に入会している」という、他にはない要件**があります。
> `common/methodology.md` §2 の「複数の法令をまとめて一文で要約しない」は、まさにこの場面のための注意です。

### 6-3-8. 【Example】X会計事務所の場面ごとの線引き（まとめ表）

> **架空の事務所を使った、理解のための整理です。**
> **どこまでが「補助」でどこからが「業務」かという個別の判断には、本資料は立ち入りません。**

| 場面 | 誰が行うか【Example】 | 条文上の位置づけ |
|---|---|---|

## 6-4. 簡易RACI — 主要な意思決定は誰が決めるのか

### RACIとは

**RACI（レイシー）**
→ ある仕事について「誰が実行し、誰が承認し、誰に相談し、誰に報告するか」を整理する考え方のこと。
→ 実務例：「申告書の最終確認は、担当者が作り（実行）、所長が承認し、必要なら顧客に相談し、
　 結果を顧客に報告する」というように、1つの仕事を4つの役割に分けて書きます。

本資料では、初心者向けに次の4つの記号を使います。

| 記号 | 意味 | 読み方 |
|---|---|---|
| **R** | **実行する人** | 実際に手を動かす人 |
| **A** | **決める人（承認する人）** | **最終的に決定する責任を負う人。1つの決定に1人** |
| **C** | **相談される人** | 決める前に意見を聞く相手 |
| **I** | **報告される人** | 決まった後に知らされる人 |

> **なぜ「A」が1人なのか**
> 【Inference】決める人が2人いると、決まらないか、責任の所在が消えます。
> この業界では、**Aが有資格者に固定されている決定**がいくつもあります。それが 6-3 の線引きの帰結です。

### 【Example】X会計事務所の簡易RACI

> **架空の事務所を使った整理です。実際の運用は事務所により異なります【Varies】。**

| 主要な意思決定 | 所長（税理士） | 勤務税理士 | 担当者 | 入力担当 | 事務職員 | 顧客（社長） |
|---|---|---|---|---|---|---|
| **① 受任するかどうか（引き受けるか）** | **A・R** | C | I | — | I | 申込み |
| **② 報酬額を決める（顧問料・決算料）** | **A・R** | C | C | — | I（請求に登録） | 承諾 |
| **③ 税務上の判断（この処理でよいか）** | **A** | R/A（担当先） | C・R（調べる） | — | — | I（説明を受ける） |
| **④ 申告書の最終確認・署名** | **A・R** | **A・R**（担当先） | R（作成） | — | — | 承認（押印） |
| **⑤ 資料が揃わないときの対応** | **A**（打切り・期限の判断） | C | **R**（催促） | I | — | **資料を出す当事者** |
| **⑥ 職員の担当替え** | **A・R** | C | C・I | I | I | I（事後に通知） |
| **⑦ 採用（職員を雇う）** | **A・R** | C | C | — | R（求人の事務） | — |
| **⑧ 会計ソフトの更新・入替え** | **A** | C | C | **C**（最も使う） | R（手続） | — |
| **⑨ 顧問契約の解約に応じるか** | **A・R** | C | I | — | I（請求の停止） | 申出 |
| **⑩ 税務調査に誰が立ち会うか** | **A・R** | C・R | I（同席する場合あり） | — | — | I |

### 各決定を1つずつ読む

#### ① 受任するかどうか — Aは所長

`04_end-to-end-process.md` A⑤のとおり、**この判断は分担できません。**

- **何を見て決めるか**：事務所の処理能力に対して受け入れられる量か／
  繁忙期に重ならないか／内容に無理がないか／責任を負える範囲か。
- **なぜ所長なのか**：【Inference】引き受けた以上、申告書に署名するのは有資格者です
  （【Fact】税理士法第33条）。**署名する人が引き受けるかどうかを決める**のが、責任の流れとして自然です。
- **頻度**：**案件発生時**。

> **【Example】断る判断の例（架空）**
> X会計事務所に、12月決算の法人から2月に問い合わせがありました。
> 決算・申告の期限は【Fact】法人税法第74条第1項により事業年度終了の日の翌日から2月以内＝2月末です。
> 一方、2月16日から3月15日は所得税の確定申告期【Fact】所得税法第120条第1項です。
> 所長は「この時期に新規の決算を引き受けると、既存の顧問先の期限に影響する」と判断しました。
> **期限は動かせないため、受ける量は事務所の側で調整するしかありません**【Inference】。

#### ② 報酬額を決める — Aは所長

- **何を見て決めるか**：`01_overview.md` 1-6 のとおり、【Typical】顧客の売上規模・仕訳件数・訪問頻度。
- **なぜ所長なのか**：【Inference】報酬額は、その顧問先にどれだけの人の時間を割くかという約束と同じです。
  人の時間の配分を決められるのは、全体を見ている人だけです。
- **頻度**：**案件発生時**（新規受任時）／**年次**（契約更新時に見直す場合【Varies】）。

> **本資料は報酬の相場・水準を書きません【Varies】**
> 金額の水準は事務所・地域・業務範囲により大きく異なります。
> `12_business-model.md`（本セットの `pro_12`）で、**構造**としてのみ扱います。

#### ③ 税務上の判断 — Aは有資格者

- **なぜか**：【Fact】税理士法第2条第1項第3号（税務相談）・第52条。
- **実務上どう流れるか**：担当者が調べ（R）、有資格者に相談し（C→A）、
  有資格者の判断として顧客に伝えます。
- **頻度**：**常時**。

> **※本資料は、個別の税務・法務の判断内容そのものには踏み込みません。**
> 「誰が決めるか」という組織の話としてのみ記述しています。

#### ④ 申告書の最終確認・署名 — Aは有資格者（分担不可）

- **なぜか**：【Fact】税理士法第33条第1項「当該税務代理に係る税理士は、当該申告書等に署名しなければならない」。
- **【Example】X会計事務所での実際**：120件すべてが所長・勤務税理士の2名を通ります。
  1人あたり60件です。繁忙期にはここに作業が集中します（`03_company-structure.md` 3-7）。
- **頻度**：**年次**（顧問先ごとの決算・申告のたび）。

#### ⑤ 資料が揃わないときの対応 — Rは担当者、Aは所長

**この業界に固有の決定です。**

```
  資料が来ない
      │
      ├─ 1回目：担当者が催促する（電話・メール・訪問）           ← R：担当者
      ├─ 2回目：担当者が期限を示して再依頼                      ← R：担当者
      ├─ 3回目：所長が顧客に直接連絡する                        ← R/A：所長
      └─ それでも揃わない：どうするかを所長が決める              ← **A：所長**
            ・ある資料だけで概算を出して申告するか
            ・期限との関係をどう説明するか
            ・契約そのものをどうするか
```

- **なぜ所長が決めるのか**：【Inference】期限は動きません（【Fact】法人税法第74条第1項ほか）。
  一方、資料が無ければ正しい申告書は作れません。
  この2つがぶつかる場面の判断は、**署名する人＝有資格者**の判断事項になります。
- **頻度**：**月次**（月次資料）／**年次**（決算資料）／**トラブル発生時**。

> **★この決定が存在すること自体が、この業界の特徴です**
> 製造業なら「材料が来ないから作れない」で止まります。
> この業界では、**顧客の資料が来なくても、法律上の期限は来ます。**
> だから「揃わないときにどうするか」が、独立した意思決定として存在します【Inference】。

#### ⑥ 職員の担当替え — Aは所長

- **何を見て決めるか**：職員の力量（`05_departments.md` ⑦-7）／担当件数の偏り／
  顧問先との相性【Varies】／退職・産休等の欠員。
- **なぜ所長なのか**：【Inference】担当替えは、顧客から見れば「窓口が変わる」ことです。
  後述 6-6 のとおり、顧問先との関係は担当者個人に紐づきやすいため、
  この決定は顧客との関係に直接影響します。
- **頻度**：**年次**（体制の見直し）／**案件発生時**（退職・欠員）。

#### ⑦ 採用 — Aは所長

- **なぜ所長なのか**：【Inference】`03_company-structure.md` 3-5 のとおり、
  処理できる量は有資格者の数と職員の数で決まります。採用は**事務所の受任可能量を決める判断**です。
- **頻度**：**年次**／**案件発生時**（欠員の発生時）。

## 6-6. 顧問先との関係が、担当者個人に紐づきやすい構造

**これは事実として記述します。論評はしません。**

### なぜそうなるのか（3つの理由）

**① 接触の頻度と密度が高い。**
【Typical】担当者は**月次**で顧問先を訪問または面談します。
`04_end-to-end-process.md` B のとおり、毎月、資料を受け取り、質問し、試算表を説明します。
【Example】1年で12回、3年で36回、同じ人が同じ会社に行きます。

**② 扱っている情報が、会社の最も内側にある。**
通帳、売上、給与、借入、社長個人の資金の動き。
`02_industry-structure.md` 2-4 のとおり、これは顧客の秘密情報です。
【Inference】これを日常的に見ている相手と、そうでない相手とでは、顧客の側の話しやすさが変わります。

**③ 過去の経緯を知っているのが、その担当者だけになりやすい。**
「3年前にこの資産を買ったときにこういう整理をした」「この入金はいつも社長個人からの立替の返済である」
といった情報は、記録に残る部分と、担当者の記憶にある部分があります【Typical】。

### その結果、何が起きるか（事実として）

| 場面 | 起きること |
|---|---|
| **担当者が退職する** | 引継ぎが必要になる。【Typical】顧問先への挨拶・後任の紹介が行われる |
| **担当替えをする** | 顧客が「前の人のほうがよかった」と言う場合がある【Varies】。引継ぎの範囲が問題になる |
| **担当者が長く同じ先を持つ** | 顧客の事情に詳しくなる一方、その担当者以外に分かる人がいない状態になりうる【Inference】 |
| **所長が全件を把握しきれない** | 【Inference】120件の細かい経緯を所長1人が記憶することは難しい。だから `05_departments.md` ⑦-8「担当替え・引継ぎ」が独立した業務として存在する |

### 事務所がこの構造にどう対応しているか（実務上の形。評価はしません）

【Typical】次のような運用が見られます。

- **顧問先カルテ**（顧客の基本情報・決算月・契約内容・過去の論点をまとめた書面）を作る
  （`05_departments.md` ①K「使用帳票」）。
- 質問と回答の記録を残す（`05_departments.md` ①-7）。
- 重要な顧問先には所長が同席する【Varies】。
- 担当替えのときに、前任・後任・所長の3名で訪問する【Varies】。

> **【Example】引継ぎの場面（架空）**
> X会計事務所の担当者Kさんが退職することになりました。担当していた26件を3名で分けます。
> 所長は、まずKさんに**顧問先ごとの引継書**を作ってもらいました。
> そこには、決算月、契約内容、社長の連絡先、過去3期の論点、
> 「この会社は資料が月末にまとめて出る」といった実務上の注意が書かれます。
> そのうえで、金額の大きい5件については**所長が同行して挨拶**しました。
> 【Inference】残りの21件は後任が単独で訪問しますが、
> 最初の数か月は前任に確認しながら進めることになります。

### この1年から読み取ってほしい5点

**① 顧客が接する相手は、ほぼKさん（無資格の担当者）である。**
1年のうち所長が顧客の前に出るのは、**5月下旬の決算報告と3月中旬の見込み説明**の2回です
（【Example】架空の設定）。
それでも申告書に署名するのは所長です（【Fact】税理士法第33条）。
**接する人と責任を負う人が違う**という 6-0 ④の構造が、ここに現れています。

**② 顧客側にも「仕事」がある。**
資料を用意するのは社長の配偶者、質問に答えるのは社長、押印するのも社長、納税するのもZ商事です。
**事務所だけでは1つも完結しません。**

**③ 他士業とのつなぎ目がある。**
社会保険の手続はT社労士が担います。Kさんは給与データの受渡しで関わりますが、
**手続そのものは行いません。**
【Fact】社会保険労務士法第27条が「社会保険労務士又は社会保険労務士法人でない者は、
他人の求めに応じ報酬を得て、第二条第一項第一号から第二号までに掲げる事務を業として行つてはならない」
と定めているためです（出典：社会保険労務士法／e-Gov法令検索）。

**④ 事務所の繁忙期と、この顧問先の重要な時期がずれている。**
事務所の最大繁忙期は2〜3月ですが、Z商事の作業の山は4〜5月です。
【Inference】顧問先ごとに決算月が違うため、事務所全体では山が分かれる面があります。

**⑤ 所長が「決める」場面は、年に数回に集約されている。**
受任済みの顧問先については、所長の出番は**④チェック（5月）・顧客への説明（5月・3月）・
税務上の判断（8月）**です。
**日常は担当者が回し、判断と責任は所長に集まる**——これがこの業界のヒトの流れの基本形です【Typical】。

## 6-8. 社労士事務所ではヒトの流れがどう違うか（【Example】Y社会保険労務士事務所）

> `03_company-structure.md` 3-3 の対比モデルです。4名・顧問先60社・年商3,000万円（架空）。

| 比較の軸 | X会計事務所（税理士） | Y社労士事務所（社会保険労務士） |
|---|---|---|
| **顧客側の窓口** | 社長または経理担当者 | 社長または総務・人事担当者 |
| **仕事が始まるきっかけ** | **毎月、前月分の資料が届くこと** | **顧客の従業員に何かが起きること**（入社・退社・結婚・出産・傷病） |
| **月次で必ず発生する接点** | ある（記帳・試算表） | 給与計算を受託していれば毎月。していなければ**イベント待ち**【Typical】 |
| **接する相手が増える方向** | 社長・経理担当者（少数） | **従業員本人**とやり取りする場面がある（傷病・育児の手続 等）【Varies】 |
| **行政の相手** | 税務署・都道府県・市町村 | 年金事務所・労働基準監督署・ハローワーク |
| **最大の繁忙期** | 2月16日〜3月15日、5月 | 6月1日〜7月上旬 |

【Inference】繁忙期がずれているのは、**根拠となる法律が違うから**です
（`04_end-to-end-process.md` E⑥）。

- 税理士事務所：【Fact】所得税法第120条第1項、法人税法第74条第1項、消費税法第45条第1項
- 社労士事務所：【Fact】労働保険徴収法第19条第1項「次の保険年度の六月一日から四十日以内」、
  健康保険法施行規則第25条第1項「毎年七月一日現に使用する被保険者…同月十日までに」

**同じ「士業」でも、1年のヒトの動き方が違います。**

## 6-9. まとめ：この章で押さえるべき7点

1. **売っているのは人の知識・資格・信用であり、モノも在庫も無い。**
   だから「人が足りない」は「売れる量が足りない」と同義になる。
2. **有資格者にしかできない行為があり、それが組織の形を決めている。**
   実行は分担できるが、責任は有資格者から離れない。
3. **根拠条文は士業ごとに違う。まとめて要約してはいけない。**
   「報酬を得て」という条件は、**社会保険労務士法第27条・行政書士法第19条第1項・
   公認会計士法第47条の2にはあり、税理士法第52条・司法書士法第73条第1項には無い。**
   司法書士法第73条第1項には「**司法書士会に入会している**」という、他に無い要件がある。
4. **主要な決定のAは、多くが所長（有資格者）に固定されている。**
   受任の可否／報酬額／税務上の判断／申告書の最終確認／資料が揃わないときの対応／担当替え／採用。
5. **「資料が揃わないときにどうするか」が、独立した意思決定として存在する。**
   顧客が資料を出さなくても、法律上の期限は来るからである。
6. **中小事務所では、7機能のすべてが所長1人の中に入っている。**
   機能が無いのではなく、人が分かれていないだけ。
7. **顧問先との関係は、担当者個人に紐づきやすい。**
   毎月会い、最も内側の情報を扱い、経緯を知っているのがその人だからである（事実としての記述）。
