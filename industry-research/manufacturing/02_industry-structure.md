**対象**：日本国内の中小製造業
**前提**：`01_overview.md` を読んでいること
**最終更新**：2026-09-16

## 11-1. プレイヤー（登場人物）

製造業には、モノを作る会社以外にも多数の事業者が関わります。
まず全体の登場人物を、役割ごとに整理します。

### プレイヤー一覧

| # | プレイヤー | 何をしている人か | 中小製造業との関係 |
|---|---|---|---|
| 1 | **完成品メーカー**（セットメーカー／OEM） | 最終製品を企画・設計し、自社ブランドで市場に出す。自動車、家電、産業機械、食品ブランドなど | 【Typical】最上流の発注者。中小企業が直接取引することは多くないが、**仕様と価格の起点**になる |
| 2 | **Tier1サプライヤー**（1次取引先） | 完成品メーカーに直接納入する部品・ユニットメーカー | 【Typical】中小製造業にとって最も多い「直接の顧客」の一つ |
| 3 | **Tier2サプライヤー**（2次取引先） | Tier1に部品を納入する | 【Typical】中小製造業が位置することの多い階層 |
| 4 | **Tier3以下**（3次・4次…） | Tier2にさらに部品・加工を納入する | 【Typical】小規模な専門加工業者（めっき、熱処理、研磨など）が多い |
| 5 | **商社・代理店**（専門商社／材料商社） | 売り手と買い手の間に立ち、材料・部品・製品の売買を仲介する。在庫保有・与信・物流・資金繰りの機能も担う | 【Typical】材料の仕入先として、また受注の入口としても関わる |
| 6 | **材料メーカー**（鉄鋼、非鉄、樹脂、化学、紙、食品原料など） | 加工の出発点になる素材を作る | 【Typical】中小企業が直接取引することは少なく、商社経由が一般的 |
| 7 | **加工外注先**（協力会社） | 自社でできない工程を代わりに行う。めっき、熱処理、塗装、研磨、レーザー切断、溶接など | 【Typical】自社の工程の一部を担う。**外注先が遅れれば自社が納期遅れになる** |
| 8 | **設備メーカー／機械商社** | 工作機械、成形機、印刷機、食品機械などの生産設備を作る・売る | 【Typical】設備を買う相手。据付・保守の窓口でもある |
| 9 | **工具・消耗品業者**（工場資材／MRO） | 刃物、砥石、油、手袋、ウエス、梱包材など、日々消費するものを供給する | 【Typical】月次で締めて請求される定常的な仕入先 |
| 10 | **物流事業者**（運送会社・倉庫会社） | 材料の引取り、製品の納入、保管を担う | 【Typical】自社便を持つ企業もあるが、多くは外部に委託 |
| 11 | **検査機関・認証機関** | 製品試験、材料分析、計測器の校正、ISO等の認証審査を行う | 【Typical】自社で測れないものを測ってもらう。認証維持のために定期的に関わる |
| 12 | **金型メーカー／治工具メーカー** | 量産に必要な型や固定具を作る | 【Typical】量産の立ち上げ時に発生する重要な取引先 |
| 13 | **産業廃棄物処理業者** | 切りくず、廃油、廃液、不良品などを処理する | 【Fact】廃棄物処理法により、排出事業者は処理の委託先・経路を管理する義務を負う |
| 14 | **金融機関**（銀行・信用金庫・政策金融機関） | 運転資金・設備資金の融資、手形・でんさいの決済 | 【Typical】設備投資と資金繰りの相談相手 |
| 15 | **行政・支援機関** | 中小企業庁、経済産業局、都道府県、公設試験研究機関、商工会議所、よろず支援拠点など | 【Typical】補助金、届出、技術相談、法令対応の窓口 |
| 16 | **業界団体・工業会** | 業種ごとの団体（各工業会・協同組合など） | 【Typical】統計・規格・共同購買・情報交換の場 |
| 17 | **人材関連**（派遣、請負、技能実習・特定技能の監理団体） | 製造現場の人員を供給する | 【Varies】活用の有無・程度は企業により大きく異なる |

### 中小製造業はどこに位置するか

【Typical】本資料が対象とする中小製造業は、上の表の **3〜4（Tier2〜Tier3）** に位置することが多く、
同時に自らも **7（加工外注先）を使う側** になります。
つまり中小製造業は、**「下請でもあり、元請でもある」という二面性**を持ちます。

```
【中小製造業の二面性】

  上を向いたとき                  自社                   下を向いたとき
 ┌──────────────┐        ┌──────────┐        ┌──────────────┐
 │ 顧客（発注者）      │ ──発注→ │  自社     │ ──発注→ │ 外注先（協力会社） │
 │ = 自社は「受注側」   │ ←納品── │ 中小製造業 │ ←納品── │ = 自社は「発注側」  │
 └──────────────┘        └──────────┘        └──────────────┘
   価格・納期を要求される                          価格・納期を要求する立場になる
```

> **なぜこの二面性が重要か**
> 取引の適正化に関する法律（取適法。旧・下請法）は、**発注側の立場になったときの自社の義務**を定めています。
> 中小企業であっても、自社より小さい相手に発注する場面では規制の対象になり得ます。
> 「守られる側」と「守る側」の両方を同時に持つのが中小製造業の立ち位置です（詳細は本ファイル 11-2 と `15_rules-customs.md`）。

## 11-2. 商流（誰から買って、誰に売るか）

### 商流の基本形

> **用語：商流（しょうりゅう）**
> → お金と契約が流れる経路のこと。「誰が誰に注文し、誰が誰に請求するか」の連鎖。
> → 物流（モノが動く経路）とは別物で、**両者は一致しないことがある**（後述の「直送」）。

```
【製造業の基本的な商流（受託加工の中小企業から見た図）】

  ┌────────────┐
  │ 材料メーカー  │   鋼板・樹脂・原料などを作る
  └──────┬─────┘
         │ 売る（商流）
         ▼
  ┌────────────┐
  │ 材料商社     │   在庫を持ち、小口に分けて売る／与信・物流も担う
  └──────┬─────┘
         │ 売る
         ▼
  ┌──────────────────────────┐
  │  ★自社（中小製造業）             │
  │   材料を加工して部品・製品にする   │
  └───┬──────────────────┬───┘
      │ 外注に出す（発注）      │ 売る（納品・請求）
      ▼                    ▼
  ┌────────────┐      ┌─────────────────┐
  │ 加工外注先     │      │ 顧客（Tier1／装置メーカー／商社）│
  │ めっき・熱処理等 │      └──────────┬──────────┘
  └────────────┘                 │ さらに売る
                                    ▼
                            ┌────────────┐
                            │ 完成品メーカー  │
                            └──────┬─────┘
                                   │
                                   ▼
                            最終ユーザー（消費者・企業・官公庁）
```

### 元請・下請の多重構造

日本の製造業を理解するうえで避けて通れないのが、**多重下請構造（ピラミッド構造）**です。

> **用語：元請（もとうけ）／下請（したうけ）**
> → 元請＝仕事を発注する側。下請＝仕事を受けて代わりに行う側。
> → 実務例：自動車メーカーがブレーキ部品をA社に発注する（A社は1次下請＝Tier1）。
>    A社はその部品の金属ケースをB社に発注する（B社は2次下請＝Tier2）。
>    B社はそのケースのめっきをC社に発注する（C社は3次下請＝Tier3）。
> → なお2026年1月以降、取引適正化に関する法律上の呼称は「親事業者→**委託事業者**」
>   「下請事業者→**中小受託事業者**」に改められています（後述）。

#### 多重構造の図解（テキスト図）

```
【製造業のピラミッド構造：自動車を例にした模式図】【Example】

                      ┌──────────────────┐
     第0階層           │  完成品メーカー         │  例：自動車メーカー
     （発注の起点）     │  設計・ブランド・販売     │  1社が数万点の部品を必要とする
                      └──────────┬───────┘
                                 │ 発注
              ┌──────────────────┼──────────────────┐
              ▼                   ▼                   ▼
     ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
第1階層│ Tier1 サプライヤー │  │ Tier1        │  │ Tier1        │
(1次) │ ユニット単位で納入  │  │              │  │              │
     │ 例：ブレーキ一式   │  │ 例：シート一式 │  │ 例：電装一式   │
     └──────┬──────┘  └──────┬──────┘  └──────┬──────┘
            │ 発注                │                   │
      ┌─────┼─────┐        ┌─────┼─────┐       ┌────┼────┐
      ▼     ▼     ▼        ▼     ▼     ▼       ▼    ▼    ▼
   ┌──────────────────────────────────────────────┐
第2階層│ Tier2：部品単位で納入する中小製造業                        │ ★本資料のモデル企業の位置
(2次) │ 例：ブラケット、シャフト、板金カバー、樹脂成形品             │
   └──────┬───────────────────────────────────┘
          │ 発注（工程の一部を外注）
     ┌────┼────┬────────┬────────┐
     ▼    ▼    ▼        ▼        ▼
   ┌────────────────────────────────────────┐
第3階層│ Tier3：単一工程に特化した専門加工業者                  │
(3次) │ 例：めっき、熱処理、塗装、研磨、バリ取り、溶接           │
   └────────────────────────────────────────┘
          │
          ▼
   ┌────────────────────────────┐
第4階層│ Tier4以下：さらに細かい工程・手作業           │
   └────────────────────────────┘
```

#### この構造がなぜ生まれたのか

【Inference】多重構造が生まれる理由は、以下のように整理できます。

1. **1つの製品に必要な工程・部品が多すぎて、1社ではまかなえない**
   自動車1台には数万点の部品が使われます。すべてを自社で作ることは現実的ではありません。
2. **工程ごとに必要な設備・許認可・技能がまったく違う**
   【Example】めっきは薬液槽と排水処理設備、水質汚濁防止法に基づく届出が必要です。
   切削加工が得意な会社が、めっきのためだけにこの設備を持つのは合理的ではありません。
   結果、工程ごとの専門会社が生まれます。
3. **需要の変動を分散させるため**
   発注側は、生産量が増えた分を外注に出し、減れば内製に戻すことで、自社の固定費を抑えられます。
4. **発注側の管理の手間を減らすため**
   完成品メーカーが数千社と直接取引すると管理しきれません。
   Tier1にユニット単位でまとめて発注し、その下はTier1に管理してもらう形になります。

#### この構造が実務にもたらす影響（重要）

| 影響 | 内容 |
|---|---|
| **情報が薄まる** | 【Typical】階層が下がるほど、「なぜこの部品が必要か」「最終製品は何か」の情報が届きにくくなる。図面と数量と納期だけが降りてくる |
| **需要変動が増幅される** | 【Typical】完成品メーカーの生産が1割減ると、下の階層では発注停止・前倒しなどの形で、より大きな変動として現れることがある |
| **価格の決まり方** | 【Fact】価格交渉促進月間（2026年3月）フォローアップ調査では、受注企業の取引階層が深くなるにつれて価格転嫁の割合が低くなる傾向が示されている（出典：経済産業省・中小企業庁、2026年6月26日公表） |
| **納期が連鎖する** | 【Typical】Tier3が1日遅れると、Tier2・Tier1を経て完成品メーカーまで遅れが伝播する |
| **品質要求も連鎖する** | 【Typical】完成品メーカーの品質基準・監査要求が、Tier1経由でTier2・Tier3へ降りてくる |

### 取引を規律する法律：取適法（旧・下請法）

【Fact】2026年1月1日、従来の「下請代金支払遅延等防止法（下請法）」が改正・改称され、
正式名称「**製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律**」、
通称「**中小受託取引適正化法（取適法）**」として施行されました（出典：公正取引委員会「2026年1月から『下請法』は『取適法』へ！」リーフレット／令和7年8月）。

用語も次のように改められています。

| 改正前 | 改正後 |
|---|---|
| 下請代金 | 製造委託等代金 |
| 親事業者 | **委託事業者** |
| 下請事業者 | **中小受託事業者** |

#### 適用対象（製造業に関係が深い部分）

【Fact】製造委託・修理委託・特定運送委託、および情報成果物作成委託・役務提供委託のうちプログラム作成・運送・倉庫保管・情報処理に該当する取引では、次の基準のいずれかに当てはまると適用対象になります（出典：同リーフレット）。

| 委託事業者（発注側） | 中小受託事業者（受注側） |
|---|---|
| 資本金3億円超 | 資本金3億円以下 |
| 資本金1千万円超3億円以下 | 資本金1千万円以下 |
| **従業員300人超** | **従業員300人以下** |

【Fact】改正により、従来の資本金基準に加えて**従業員基準（300人／100人）が追加**され、対象が拡充されました。
また、製造等の目的物の引渡しに必要な運送の委託（**特定運送委託**）が対象取引に追加されました（出典：同リーフレット）。

#### 委託事業者の4つの義務

【Fact】（出典：同リーフレット）

| # | 義務 | 内容 |
|---|---|---|
| ① | 発注内容等を明示する義務 | 発注にあたり、給付の内容・代金の額・支払期日・支払方法等を書面または電子メール等の電磁的方法で明示する |
| ② | 書類等を作成・保存する義務 | 取引完了後、給付内容・代金の額など取引の記録を作成し、**2年間保存**する |
| ③ | 支払期日を定める義務 | 検査の有無を問わず、**物品等を受領した日から起算して60日以内**のできる限り短い期間内で支払期日を定める |
| ④ | 遅延利息を支払う義務 | 支払遅延や減額を行った場合、日数・金額に応じ**年率14.6％**の遅延利息を支払う |

#### 11の禁止事項

【Fact】（出典：同リーフレット）

| # | 禁止項目 | 内容 |
|---|---|---|
| ① | 受領拒否 | 受注側に責任がないのに、発注した物品等の受領を拒む |
| ② | 支払遅延 | 支払期日までに代金を支払わない（**支払手段として手形払等を用いることを含む**） |
| ③ | 減額 | 受注側に責任がないのに、発注時に決めた代金を後から減らす |
| ④ | 返品 | 受注側に責任がないのに、受領後に返品する |
| ⑤ | 買いたたき | 通常支払われる対価に比べ著しく低い代金を不当に定める |
| ⑥ | 購入・利用強制 | 正当な理由なく、指定する物品・役務を強制的に購入・利用させる |
| ⑦ | 報復措置 | 公正取引委員会・中小企業庁・事業所管省庁へ違反を知らせたことを理由に不利益な扱いをする |
| ⑧ | **有償支給原材料等の対価の早期決済** | 有償で支給した原材料等の代金を、製品代金の支払日より早く支払わせる |
| ⑨ | 不当な経済上の利益の提供要請 | 金銭・役務等を不当に提供させる |
| ⑩ | 不当な給付内容の変更、やり直し | 受注側に責任がないのに発注を取り消したり、無償でやり直し・追加作業をさせる |
| ⑪ | **協議に応じない一方的な代金決定** | 価格協議の求めに応じない、必要な説明を行わないなど、一方的に代金を決める |

【Fact】⑪と、②に含まれる「手形払等の禁止」は、2026年1月施行の改正で**新たに追加された禁止行為**です（出典：同リーフレット）。

> **なぜ手形払いが禁止されたのか**
> 【Fact】手形は、受け取ってから現金化できるまでに期間があり、
> 受注側は支払期日まで代金相当額の満額を得ることが困難になります。
> 改正では、手形払のほか、電子記録債権等についても支払期日までに満額を得ることが困難なものが禁止されました（出典：同リーフレット）。
>
> 【Fact】実際の支払手段の状況として、価格交渉促進月間（2026年3月）フォローアップ調査では、
> 支払手段を「現金のみ」とした回答が87.5％まで増加し、
> 一方で支払期日が60日を超過している企業の割合が全体の6.6％残存する結果となっています
> （出典：経済産業省・中小企業庁、2026年6月26日公表）。

## 11-3. 中小製造業で頻出する商流の形態

ここからは、教科書的な「買って・作って・売る」以外に、中小製造業の現場で日常的に出てくる商流の形を説明します。
**これを知らないと、伝票や請求書の意味が読めません。**

### (1) 支給材（しきゅうざい）— 顧客から材料を預かる

> **用語：支給材**
> → 加工に使う材料を、顧客（発注者）が用意して、加工を行う会社に渡すこと。またはその材料。
>   「材料支給」「有償支給」「無償支給」などと呼ばれます。
> → 実務例：顧客が自社で一括購入した特殊鋼を、加工先である自社に送ってくる。
>    自社はその鋼材を削って部品にし、加工賃だけを請求する。

**なぜ顧客が材料を支給するのか**

| 理由 | 説明 |
|---|---|
| **材料を安く買えるから** | 【Typical】顧客が大量にまとめて購入すれば単価が下がる。加工先が小口で買うより安い |
| **材料の品質を管理したいから** | 【Typical】材質・ロット・メーカーを顧客が指定・統一したい場合がある（トレーサビリティ確保） |
| **加工先の資金負担を減らすため** | 【Typical】加工先が材料代を立て替えなくて済む |
| **材料の入手が難しいから** | 【Varies】特殊材や指定メーカー品で、加工先では買えない場合がある |

### (2) 有償支給と無償支給の違い

支給材には2つの方式があり、**会計処理も、在庫の持ち主も、リスクもまったく違います**。

| 比較軸 | **有償支給** | **無償支給** |
|---|---|---|
| ひとことで言うと | 顧客から材料を**買う**（代金を払う） | 顧客から材料を**預かる**（代金は払わない） |
| 材料の所有権 | 【Typical】支給を受けた時点で自社に移る | 【Typical】顧客のまま。自社は預かっているだけ |
| 自社の仕入計上 | 【Typical】材料費として仕入に計上する | 【Typical】仕入に計上しない（自社の資産ではない） |
| 自社の請求内容 | 【Typical】**材料費＋加工賃**を含んだ製品代金を請求 | 【Typical】**加工賃のみ**を請求 |
| 自社の売上規模への影響 | 大きくなる（材料費の分だけ売上が膨らむ） | 小さくなる（加工賃だけが売上） |
| 材料が不良になった場合 | 【Varies】自社の材料なので原則自社負担。契約による | 【Varies】顧客の材料のため、責任の所在は契約による |
| 在庫としての管理 | 自社の在庫として資産計上 | 【Typical】**預り品**として、自社在庫とは区別して管理（帳簿外で数量管理する） |

#### 【Example】数字で見る有償支給と無償支給の違い

> ※以下は理解のための架空の例であり、実在企業の実績値ではありません。

ある部品を1,000個作り、材料費が40万円、加工の対価が30万円だとします。

**有償支給の場合**
```
顧客 ──[材料を40万円で売る]──→ 自社     ： 自社は仕入40万円を計上（買掛金40万円）
自社 ──[完成品を70万円で売る]─→ 顧客     ： 自社は売上70万円を計上（売掛金70万円）
                                          差引きの利益は30万円
```

**無償支給の場合**
```
顧客 ──[材料を無償で預ける]──→ 自社      ： 自社は仕入を計上しない（預り品として数量のみ管理）
自社 ──[加工賃30万円を請求]──→ 顧客      ： 自社は売上30万円を計上（売掛金30万円）
                                          利益は同じ30万円
```

**同じ仕事でも、有償支給なら売上70万円、無償支給なら売上30万円になります。**

> **ここが初心者のつまずきどころ**
> 【Inference】売上高だけを見て会社の規模や忙しさを判断すると、実態を見誤ることがあります。
> 有償支給が多い会社は売上が大きく見え、無償支給が多い会社は売上が小さく見えます。
> 実際に自社が生み出した価値の大きさを見るには、**売上高ではなく付加価値（売上－材料費－外注費）**を見ます。

> **取適法との関係**
> 【Fact】有償支給の場合、委託事業者が支給した原材料等の対価を、製品代金の支払日より先に支払わせることは
> 取適法で禁止されています（禁止項目⑧「有償支給原材料等の対価の早期決済」）。
> 【Fact】公正取引委員会は、その理由を「有償支給した原材料等の対価を早期に決済することは、
> 中小受託事業者にとって資金繰りが苦しくなるなど不利益を被ることになるため」と説明しています
> （出典：公正取引委員会 中部事務所「下請法 知っておきたい豆情報 その10」）。
> 具体的には、代金の支払期日より前に原材料等の対価を支払わせること、
> 代金から原材料等の対価を控除（差し引き）すること等が問題となります。

### (3) 直送（ちょくそう）— 商流と物流が一致しない形

> **用語：直送**
> → 商流（お金・契約の流れ）は商社や元請を経由するが、モノ（物流）は自社から最終的な使用者へ直接届けること。
> → 実務例：商社から注文を受けたが、商社の倉庫には送らず、商社の顧客の工場へ直接納品する。
>    伝票は「商社宛の納品書」と「実際の届け先」が別になる。

```
【直送のときの商流と物流】

  商流（注文と請求）：  顧客工場 → 商社 → 自社        自社は商社に請求する
  物流（モノの動き）：  自社 ────────────→ 顧客工場   モノは商社を通らない
```

【Typical】直送では、納品書・受領印の取り扱い、運賃の負担者、検収の主体が複雑になるため、
事前に取り決めておくのが一般的です。

### (4) 商社を経由する取引（帳合／間接取引）

> **用語：帳合（ちょうあい）**
> → 実際の取引相手と、請求・支払いの相手が異なる場合の、その請求先の経路のこと。
> → 実務例：技術的な打ち合わせは顧客の設計者と直接行うが、注文書と請求書は商社を経由する。
>    この場合「A社（顧客）の仕事だが、帳合はB商社」と言う。

【Typical】商社を経由する理由は次のとおりです。

- **与信**：商社が代金回収のリスクを引き受ける。自社は商社に請求すればよい
- **支払条件**：顧客が多数の小口取引先を管理せずに済む
- **物流・在庫**：商社が在庫を持ち、小分けで供給する
- **資金**：商社が支払サイトの差を吸収する

【Typical】その代わり商社は口銭（手数料）を取るため、同じ製品でも直接取引より単価は下がることがあります。

### (5) 内製と外製（外注）の使い分け

> **用語：内製（ないせい）／外製（がいせい・外注）**
> → 内製＝自社の設備・人で作ること。外製（外注）＝他社に作ってもらうこと。
> → 実務例：切削と溶接は自社で行い（内製）、めっきと熱処理は外注に出す（外製）。

【Typical】中小製造業が外注を使う主な場面は次のとおりです。

| 外注する理由 | 【Example】具体例 |
|---|---|
| 設備を持っていない工程だから | めっき、熱処理、大型部品の切断 |
| 許認可・専門資格が必要だから | 排水処理を伴う表面処理 |
| 一時的に自社の生産能力を超えたから | 繁忙期の追加加工 |
| 自社でやるより安いから | 大量の単純加工 |
| 納期に間に合わないから | 並行して作業させる |

## 11-4. バリューチェーン（上流 → 中流 → 下流）

> **用語：バリューチェーン（価値連鎖）**
> → 原材料が最終製品になるまでに、どの段階でどんな価値が付け加えられていくかを並べたもの。
> → 実務例：鉄鉱石 → 鋼板 → 切断された板 → 曲げ加工された部品 → 塗装された部品 → 組み込まれた製品。
>    各段階で少しずつ価値（＝売れる値段）が上がっていく。

### 製造業全体のバリューチェーン

```
【上流】                    【中流】                        【下流】
資源・素材                  加工・組立                       流通・使用・回収

 原料調達        →  素材製造  →  一次加工 → 二次加工 → 組立 → 検査 →  販売 → 使用 → 保守 → 廃棄・リサイクル
 （鉱石・原油・   （製鉄・     （切断・   （曲げ・     （ユニット （寸法・   （商社・  （顧客の （部品供給・ （産廃処理・
   農産物・木材）   樹脂重合・    圧延・     溶接・       組立・    性能・    小売・    工場・   修理）      再資源化）
                  製紙）        押出）      切削・       最終組立） 外観）    直販）    消費者）
                                          表面処理）
```

### 中小製造業が担っている部分

【Typical】中小製造業の多くは、上図の **「一次加工〜二次加工〜組立〜検査」** の範囲を担当します。
自社製品を持つ企業はこれに「企画・設計」と「販売」が加わります。

| 段階 | 主な担い手 | 中小製造業の関与 |
|---|---|---|
| 原料調達 | 資源会社、商社 | 【Typical】関与しない |
| 素材製造 | 鉄鋼・化学・製紙など大手 | 【Typical】関与しない（買う側） |
| 一次加工 | 加工メーカー、専門加工業 | 【Typical】中小が多く担う（切断、押出、圧延の一部） |
| 二次加工 | 中小製造業、専門加工業 | 【Typical】**中心的な領域**（曲げ、溶接、切削、成形、表面処理） |
| 組立 | 中小製造業、Tier1/Tier2 | 【Typical】ユニット組立まで担う企業もある |
| 検査 | 自社、第三者検査機関 | 【Typical】自社で行い、必要に応じ外部機関に依頼 |
| 販売・流通 | 商社、完成品メーカー | 【Varies】自社製品を持つ企業のみ直接関与 |
| 使用・保守 | 顧客 | 【Varies】補修部品の供給という形で関与することがある |
| 廃棄・リサイクル | 産廃処理業者、再資源化業者 | 【Fact】排出事業者として、自社から出る廃棄物の処理責任を負う（廃棄物処理法） |

### 価値が付加される仕組み（金額で見る）【Example】

> ※以下は理解のための架空の例であり、実在企業の実績値ではありません。

```
鋼板（1kg 150円）を買う
   ↓ 切断する（レーザー加工機の時間＋人の時間）
   ↓ 曲げる（プレス機の時間＋金型）
   ↓ 溶接する（溶接技能者の時間）
   ↓ めっきに出す（外注費）
   ↓ 検査する（検査員の時間＋測定器）
完成部品（1個 800円）として売る

→ 上がった金額の分が「加工によって付け加えた価値」。
  ただしこの中には、設備の減価償却費・電気代・人件費・外注費が含まれており、
  すべてが利益になるわけではない。
```

## 11-5. サプライチェーン（原材料から最終顧客まで）

> **用語：サプライチェーン（供給連鎖）**
> → 原材料から最終顧客に届くまでの、**モノと情報の流れの全体**のこと。
>   バリューチェーンが「価値の積み上がり」を見るのに対し、サプライチェーンは「モノがどう流れ、
>   どこで止まり、どんな情報で動くか」を見ます。
> → 実務例：顧客の発注情報が上流へ遡り、それを受けて材料が下流へ流れていく。
>    どこか1か所が止まると、その先すべてが止まる。

### モノの流れと情報の流れは逆向き

```
【情報（需要）の流れ】  ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ←
                     注文・内示・仕様変更・納期変更が上流へ遡る

  材料メーカー → 商社 → 自社 → 外注先 → 自社 → 顧客(Tier1) → 完成品メーカー → 最終ユーザー

【モノ（供給）の流れ】  → → → → → → → → → → → → → → → → → →
                     材料・部品・製品が下流へ流れる
```

【Typical】この「情報は逆流、モノは順流」という関係が、製造業のサプライチェーンの基本です。
中小製造業の生産管理の仕事は、**上流から来る情報を受け取って、下流へ流すモノの段取りを組むこと**だと言えます。

### 供給が止まる主な要因

【Typical】中小製造業の現場で、サプライチェーンが滞る典型的な原因です。

| 要因 | 内容 | 【Example】 |
|---|---|---|
| 材料の入手難 | 材料メーカーの減産、需給逼迫、輸入の停滞 | 特殊鋼の納期が通常4週間から12週間に延びる |
| 外注先の遅延 | 外注先の設備故障、人員不足、他社案件の輻輳 | めっき屋が繁忙で、予定より1週間遅れる |
| 自社設備の故障 | 主力設備の突発停止 | レーザー加工機が停止し、切断工程が滞る |
| 品質不具合 | 検査で不合格が出て作り直しになる | 寸法不良で200個を再製作 |
| 顧客側の変更 | 仕様変更、数量変更、納期前倒し | 顧客都合で納期が2週間前倒しされる |
| 人員の不足 | 欠勤、退職、技能者不在 | 溶接の有資格者が休み、その工程が止まる |
| 物流の制約 | 運送便の確保困難 | 指定日の便が取れず、翌日納品になる |
| 災害・事故 | 地震、台風、火災、停電 | 工業団地全体が停電し1日操業停止 |

> **なぜ中小製造業でサプライチェーンの話が重要なのか**
> 【Inference】中小製造業は、自社の工程だけを管理していても納期を守れません。
> 「材料がいつ入るか」「外注先がいつ返してくるか」が、自社の納期を直接決めるためです。
> したがって、生産管理の仕事の実質的な中身は、**自社の外側の進捗を追いかけること**が大きな比重を占めます。

## 11-7. このファイルのまとめ
