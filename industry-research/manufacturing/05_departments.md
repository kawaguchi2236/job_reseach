# 05_departments.md — 部署別業務（機能別 A〜O 15項目）／業務一覧表／部署間連携

**対象**：日本国内の中小製造業
**前提**：`01_overview.md` `02_industry-structure.md` `03_company-structure.md` `04_end-to-end-process.md` を読んでいること
**最終更新**：2026-09-16

> このファイルは本資料の**中心**です。
> `04_end-to-end-process.md` が「1本の流れ」を追ったのに対して、このファイルは
> **「その流れの中で、どの機能が、いつ、何を受け取り、何を確認し、何を判断し、何を作って、次に誰へ渡すのか」**
> を機能ごとに分解します。

## 0. このファイルの読み方（最初に必ず読んでください）

### 0-1. 「部署」ではなく「機能」で書いてあります

【Typical】中小製造業では、**仕事（機能）は必ず存在しますが、その名前の部署が存在するとは限りません**。

```
✕ 「製造業には生産管理部がある」
○ 「いつ何をどれだけ作るかを決める生産管理機能は、どの製造業にも必ず存在する。
    ただしそれが『生産管理部』という部署になっているとは限らず、
    社長・工場長・事務担当が兼ねていることも多い」
```

このため本ファイルは、`03_company-structure.md` 3-3 で定義した**10機能**を単位として記述します。
各機能の冒頭（項目A）に「一般的な部署名称」と「【Varies】独立部署になるとは限らない理由」を必ず添えています。

### 0-2. 15項目（A〜O）の意味

`common/methodology.md` §7 に定める15項目を、全10機能について記述します。

| 記号 | 項目 | 何が書いてあるか |
|---|---|---|
| **A** | 部署・機能名 | 正式名称と、現場でよく使われる別名称 |
| **B** | 存在目的 | 「何のためにこの機能があるのか」を1〜3文で |
| **C** | 担当者 | 代表的な役職・担当。モデル企業での人数 |
| **D** | 主な業務一覧 | その機能が持つ仕事の洗い出し |
| **E** | 業務詳細 | **このファイルの心臓部**。Dの各業務について7つの観点で分解 |
| **F** | 業務頻度 | `methodology` §5 の語彙のみ使用 |
| **G** | インプット | 業務を始めるために必要なもの |
| **H** | アウトプット | 業務の結果できあがるもの |
| **I** | 関係部署 | 前工程・後工程 |
| **J** | 社外関係者 | 顧客・仕入先・外注先・行政等 |
| **K** | 使用帳票 | 製造業固有のものを優先 |
| **L** | 使用データ | 何の情報を扱うか |
| **M** | 使用システム | システムの**種別**。商品名の列挙が目的ではない |
| **N** | 使用設備・道具 | 業界理解に必要な範囲で |
| **O** | 見ている数字・KPI | その機能が日常的に見ている数字 |

**E（業務詳細）の7観点**は、すべての業務で次の順に書いています。

```
① 何をきっかけに始まるか   ② 誰が行うか      ③ 何を確認するか
④ 何をするか             ⑤ 何を判断するか   ⑥ 誰と連携するか
⑦ 最終的に何が出来上がるか
＋ 「なぜこの業務が必要なのか」
```

### 0-3. 頻度の語彙

本ファイルで使う頻度の語は次のものだけです（`methodology` §5）。

```
常時 / 日次 / 週次 / 月次 / 四半期 / 半期 / 年次
案件発生時 / 問い合わせ時 / 受注時 / 発注時 / 納品時 / 請求時 / 入金時
トラブル発生時 / 法定・契約上のタイミング / その他
```

【Varies】企業差が大きいものは「企業により異なる」と明記しています。
「毎週月曜日に行う」のような具体化は、法令に期限の定めがある場合を除いて行いません。

### 0-4. 業種による違い（Level 2）の扱い

`01_overview.md` 1-6 の Level 2（食品製造／金属加工／機械製造／電気機器／化学・プラスチック／印刷）で
**業務の姿が大きく変わる箇所**には、各機能の末尾に「**Level 2：業種による違い**」を設けています。
本文の基本形は、モデル企業（`03_company-structure.md` の X金属工業株式会社＝金属加工の受託加工）を前提としています。

### 0-5. 番号の読み方

- **機能番号**（① 〜 ⑩）：`03_company-structure.md` で定義した10機能。本ファイルでは必ず「**① 営業機能**」のように「機能」の語を付けます。
- **ステップ番号**（STEP ① 〜 ⑰）：`04_end-to-end-process.md` の全社フローの手順。本ファイルでは必ず「**STEP ⑤**」のように書きます。

# PART 1. 機能別業務詳細（A〜O 15項目）

本ファイルで扱う10機能は次のとおりです（`03_company-structure.md` 3-9 の一覧と完全に一致）。

```
① 営業機能                （営業部／営業課／業務部）
② 受注・生産管理機能        （生産管理部／業務部／工務）      ★ハブ
③ 生産技術（工程設計）機能   （生産技術課／技術部）           ※兼務が多い
④ 調達機能                （購買部／資材課）
⑤ 製造機能                （製造部／工場／製造課）
⑥ 品質保証機能             （品質保証部／品証／検査課）
⑦ 出荷・物流機能            （出荷課／物流課／倉庫）
⑧ 設備保全機能             （保全課／技術課）               ※専任者不在が多い
⑨ 経理・財務機能            （経理部／総務経理／管理部）
⑩ 人事・総務機能            （総務部／管理部／人事総務課）
```

※「経営（社長・役員）」は独立機能として扱わず、**各機能の承認者・最終判断者**として各所に登場します。

## 1. ① 営業機能

### A. 部署・機能名

| 項目 | 内容 |
|---|---|
| **機能名（本資料での呼称）** | **営業機能** |
| **一般的な部署名称** | 営業部、営業課、業務部、営業技術部、【Varies】社長直轄（部署なし） |
| **現場でよく使われる呼び方** | 「営業」「担当」「窓口」。顧客からは「〇〇さん（担当者名）」と個人名で呼ばれることが多い |
| **英語表記の例** | Sales / Sales Engineering |

> **【Varies】独立した営業部があるとは限りません**
> 【Typical】従業員10〜20名規模では、**社長が営業機能をすべて担っている**ことが珍しくありません。
> 既存顧客との取引が中心で新規開拓の必要が小さい場合、専任の営業担当を置かず、
> 生産管理担当や事務担当が電話・メールの窓口を兼ねている企業もあります。
> 【Typical】逆に「営業技術」「セールスエンジニア」という形で、
> 図面が読める技術者が営業を兼ねている企業も多くあります。受託加工では図面の話ができないと
> 引合いに答えられないためです。

### B. 存在目的

**顧客との唯一の窓口として、仕事を取ってきて、条件（価格・納期・仕様）を確定させ、
その条件を社内が実行できる形で引き渡すことが、営業機能の存在目的です。**

【Inference】受託加工型の中小製造業では、営業機能は「新しい顧客を探してくる」よりも、
**「既存顧客の生産計画をいち早く正確につかみ、自社の受注として確定させる」**役割の比重が大きくなります
（`03_company-structure.md` 3-2 のとおり、モデル企業は上位2社で売上の55％を占めるため）。

### C. 担当者

| 役職・担当 | 【Example】モデル企業での姿 | 主に何をするか |
|---|---|---|
| 営業責任者（営業部長・営業課長） | 1名 | 見積金額の社内承認、重要顧客対応、担当者の案件配分 |
| 営業担当者（ルートセールス） | 2名 | 顧客ごとの窓口、引合い受付、見積提出、納期回答、クレーム一次受け |
| 営業事務（内勤） | 【Varies】モデル企業では受注・生産管理機能が兼務 | 見積書・注文請書の作成、受注入力、顧客への書類送付 |
| **社長** | 1名 | **最終的な見積承認、新規顧客の与信判断、価格改定交渉、重要顧客への訪問** |

【Typical】中小製造業では、**金額が一定以上の見積は社長が承認する**運用が広く見られます。
赤字受注は会社の存続に直結するため、最終判断を経営者が握っておくためです。

|---|---|---|

### E. 業務詳細

---

#### E-1-1. 引合い受付・一次判断

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 顧客から問い合わせが入る（電話、メール、来訪、既存顧客の設計者や購買担当からの連絡、展示会や紹介による新規接触） |
| **② 誰が** | 営業担当者。【Varies】小規模企業では社長が直接受ける |
| **③ 何を確認** | 何を作るのか（品名・用途）／数量／希望納期／材質・表面処理の指定／図面の有無と版数／既存顧客か新規顧客か／過去に同じ品番を作った実績があるか |
| **④ 何をする** | 内容を聞き取り、引合い台帳に記録して案件番号を付ける。図面があれば受領し、社内の共有場所に保管する。過去の受注履歴を検索して、同一品番・類似品の実績があるか調べる |
| **⑤ 何を判断** | **自社の設備・技能でその形が作れるか**（サイズが機械に載るか、公差が自社の精度で収まるか）／**希望納期に間に合う見込みがあるか**／新規顧客の場合は**取引してよい相手か（与信）**／見積を作る工数をかける価値がある案件か |
| **⑥ 誰と連携** | ③ 生産技術機能（技術的に作れるかの相談）／② 受注・生産管理機能（現在の工場の混み具合の確認）／社長（新規顧客の与信判断） |
| **⑦ 出来上がるもの** | **引合い記録（引合い台帳への登録、案件番号）**、受領した図面・仕様書のファイル |

> **なぜこの業務が必要なのか**
> 【Typical】理由は2つあります。
> 1つは、**作れない仕事・間に合わない仕事を入口で断るため**です。見積を作るには工程を検討し、
> 材料価格を調べ、外注に照会する必要があり、1件あたり数十分〜数時間の工数がかかります。
> 受注できる見込みのない案件にこの工数をかけると、本来やるべき案件の対応が遅れます。
> もう1つは、**失注の理由を後から振り返るため**です。引合いを記録していなければ、
> 「価格で負けたのか、納期で負けたのか、そもそも見積を出し遅れたのか」が分かりません。

> **用語：与信（よしん）**
> → 取引相手が代金をきちんと支払える会社かどうかを判断し、「この会社には○○万円まで掛売りしてよい」と枠を決めること。
> → 実務例：新規の顧客から100万円の引合いが来た。会社概要を確認し、信用調査会社の情報を取り寄せ、
>    支払条件（締め日・支払サイト）を確認したうえで、社長が「初回は現金前払い」「50万円までなら掛売り可」などと決める。
> → 【Typical】製造業では**作ってから代金が入るまで2〜3か月かかる**ため、
>    代金が回収できなければ材料費と人件費だけが出ていきます。与信はこれを防ぐための判断です。

> **【Varies】新規顧客と既存顧客で対応が変わる**
> - **既存顧客**：過去の取引実績・単価・図面がすべて残っているため、確認事項は少ない。
> - **新規顧客**：与信確認、取引基本契約書の締結、支払条件の取り決め、工場見学の受入などが加わり、
>   最初の1件だけで数週間かかることもある【Typical】。

#### E-1-2. 仕様ヒアリング・図面受領

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 引合いを受け付け、案件として進めることを決めたとき |
| **② 誰が** | 営業担当者。技術的な内容が多い場合は ③ 生産技術機能の担当者が同席する |
| **③ 何を確認** | 図面の版数（Rev.）／寸法公差／材質と材料メーカーの指定／表面処理（めっき・塗装・アルマイト等）の種類と膜厚／溶接跡・バリ・キズの許容範囲／外観の仕上げ指定／検査要求（検査項目・抜取数・検査成績書の要否）／ミルシート（材料証明書）の要否／梱包の指定（荷姿・通い箱・入数）／納入場所・納入回数・納入時刻／支給材の有無 |
| **④ 何をする** | 図面と仕様書を読み込み、不明点を一覧にして顧客へ質問する。回答を文書（メール等）で残す。決まったことを「仕様確認メモ」としてまとめ、社内に展開する |
| **⑤ 何を判断** | **図面に書かれていない条件のうち、価格と工数に影響するものは何か**／顧客の言う「きれいに」「バリなく」が具体的にどのレベルを指すか／自社で決めてよい部分と、顧客に確認が必要な部分の線引き |
| **⑥ 誰と連携** | ③ 生産技術機能（製作可否・工程案）／⑥ 品質保証機能（検査要求の実現可能性）／④ 調達機能（指定材料が入手できるか）／顧客の設計者・購買担当 |
| **⑦ 出来上がるもの** | **確定した仕様情報**（見積依頼書、仕様確認メモ、質疑応答の記録、図面ファイル） |

> **なぜこの業務が必要なのか**
> 【Typical】**図面だけでは製品は決まらない**からです。
> 【Example】「板厚3mmのSUS304、曲げ加工」と図面にあっても、
> 表面の仕上げ（ヘアライン／鏡面／素地のまま）、溶接ビード（溶接の盛り上がり）を削るかどうか、
> 角のバリをどこまで取るか、といった点は図面に書かれていないことがあります。
> これを確認せずに作ると、納品後に「これでは使えない」と返品され、作り直しになります。
> 作り直しの費用は原則として自社負担になるため、**仕様確認は利益を守る工程**です。
> （`04_end-to-end-process.md` STEP ② と同じ考え方です。）

> **用語：Rev.（リビジョン／版数）**
> → 図面が改訂されるたびに付けられる版の記号。Rev.A → Rev.B → Rev.C と進む。
> → 実務例：Rev.B の図面で見積を出したのに、注文書にはRev.C と書かれていた。
>    C では穴が2つ増えているため、加工時間が増えて見積価格では合わない。
>    **図面の版数を照合しないと、違う製品を作ってしまう**。

#### E-1-3. 見積のとりまとめ・見積書作成・提出

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 仕様が確定したとき（E-1-2 の完了） |
| **② 誰が** | 営業担当者（とりまとめ）。原価の中身は ③ 生産技術機能（工程・時間）と ④ 調達機能（材料単価・外注単価）が作る。承認は営業責任者または社長 |
| **③ 何を確認** | 工程設計の結果（工程順・使用設備・標準時間・段取り時間）／材料の単価と必要量・歩留まり／外注工程の単価と期間／治具・型の要否と費用／自社の販管費率・目標粗利率／同一品番の過去単価／材料相場の直近の動き／顧客の予算感 |
| **④ 何をする** | ③④から集めた原価要素を積み上げて製造原価を計算し、販管費と利益を乗せて見積金額を決める。想定リードタイムを算出する。見積書を作成し、社内承認を取り、顧客へ提出する |
| **⑤ 何を判断** | **いくらで出すか**（原価＋目標利益で出すか、競合を意識して下げるか）／**有効期限を何日にするか**（材料相場の変動リスク）／数量が変わった場合の単価をどう提示するか（数量別単価を併記するか）／型費・治具費を初回に別途請求するか、単価に織り込むか／納期をいつと回答するか |
| **⑥ 誰と連携** | ③ 生産技術機能／④ 調達機能／② 受注・生産管理機能（納期回答のための負荷確認）／社長（承認）／顧客（提出・説明） |
| **⑦ 出来上がるもの** | **見積書**（見積番号、品名、品番、数量、単価、金額、納期、有効期限、支払条件、備考）、**見積原価の内訳（社内保管）** |

> **なぜこの業務が必要なのか**
> 【Inference】**受託加工では、見積時点で決めた単価が、その後の製造・納品を通じて変わりません。**
> 1個あたり50円安く見積もれば、1,000個作ったときに5万円の利益が消えます。
> しかも実際に作るのは見積の数週間〜数か月後であり、その間に材料価格が上がれば、
> 上がった分は自社の負担になります。
> **「まだ作っていないものの原価を、作る前に予測する」**という本質的に難しい作業であるため、
> 製造業では見積の精度が利益に直結します（`04_end-to-end-process.md` STEP ③ 参照）。

> **見積書に必ず書かれること【Typical】**
> | 記載項目 | なぜ書くのか |
> |---|---|
> | 数量と単価の組み合わせ | 段取り費の配賦が数量で変わるため、数量が違えば単価も違う |
> | 有効期限 | 材料相場が動くため。期限を切らないと半年後に同じ価格で発注される |
> | 納期（または「受注後○日」） | 現在の工場の負荷を前提にした納期であることを示す |
> | 型費・治具費の扱い | 初回のみ別途請求か、単価に含むかを明示する |
> | 運賃・梱包費の負担者 | 顧客負担か自社負担かで原価が変わる |
> | 支給材の有無 | 有償支給か無償支給かで請求金額の意味が変わる（`02_industry-structure.md` 11-3参照） |

> **【Varies】見積の作り方は企業により大きく異なります**
> - **積上げ方式**：工程ごとの時間×チャージレートを積み上げる。モデル企業はこの方式【Example】。
> - **類似品比較方式**：過去の似た製品の単価をもとに増減させる。図面が多く時間がない場合に使われる。
> - **顧客指値（さしね）方式**：顧客から「この単価でできるか」と提示され、可否を判断する。
> 【Typical】繰返生産では**初回のみ見積を作り、以降は同じ単価が継続する**ため、初回の精度が長く効きます。

#### E-1-4. 価格交渉・単価改定協議

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 顧客から値下げ要請を受けたとき／材料費・労務費・エネルギー費が上昇し、自社から単価改定を申し入れるとき／【Fact】半期ごとの価格改定時期（後述） |
| **② 誰が** | 営業担当者。金額が大きい場合・継続取引の単価改定は社長が同席または主導する |
| **③ 何を確認** | 現行単価と現在の実際原価との差／材料単価の変動幅（仕入先からの値上げ通知）／労務費・電力費の変動／その品番の年間数量と、単価変動が年間利益に与える影響／競合の存在／顧客との取引全体の採算 |
| **④ 何をする** | 原価の変動を示す資料（材料値上げ通知の写し、単価の内訳）を用意し、顧客へ説明する。値下げ要請に対しては、数量をまとめる・梱包を簡素化する・納期を延ばすなど、原価が下がる条件とセットで回答を作る |
| **⑤ 何を判断** | **どこまで下げても採算が合うか**（限界となる単価はいくらか）／断った場合に取引全体を失うリスクの大きさ／転嫁を求める場合の説明材料が十分か |
| **⑥ 誰と連携** | ⑨ 経理・財務機能（その品番の実際原価と粗利の実績）／④ 調達機能（材料・外注の値上げ状況）／社長（最終判断）／顧客の購買担当 |
| **⑦ 出来上がるもの** | **改定後の単価（合意事項）**、単価改定の通知書・覚書、更新された単価マスタ |

> **なぜこの業務が必要なのか**
> 【Typical】材料費は自社ではコントロールできません。鋼材やエネルギーの価格が上がれば、
> 同じ単価のまま作り続けると粗利が削られていきます。
> 一方で、単価を上げれば顧客の原価が上がるため、顧客は簡単には受け入れません。
> **原価の変動を価格に反映させる（＝価格転嫁）交渉は、受託加工の採算を保つための継続的な業務**です。

> **【Fact】価格転嫁をめぐる国の取組み**
> 中小企業庁は、原材料費・労務費・エネルギー費の上昇分を取引価格へ反映する状況を把握するため、
> 毎年3月と9月を「価格交渉促進月間」と設定し、受注側中小企業30万社にアンケート調査を実施しています。
> 2026年3月時点の調査では、「価格交渉が行われた」割合は90.7％、価格転嫁率は54.2％でした
> （出典：価格交渉促進月間（2026年3月）フォローアップ調査の結果／経済産業省・中小企業庁、2026年6月26日公表）。
> 【Fact】同庁は「価格の改定は、半期に一度、4月と10月に行う企業が比較的多いことから、
> その前月である3月と9月を価格交渉促進月間と設定している」と説明しています（出典：同上）。
> 【Typical】したがって**単価改定の協議は半期のタイミングで行われることが多い**というのが、製造業でよく見られる商習慣です。

#### E-1-5. 受注処理（注文書の受領と照合）

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 顧客から注文書（発注書、Purchase Order／PO）が届いたとき。繰返生産では確定注文（納入指示・かんばん）が届いたとき |
| **② 誰が** | 営業担当者が受領し、② 受注・生産管理機能が社内登録する。【Varies】企業により営業事務が登録する |
| **③ 何を確認** | 品番・品名／**図面の版数**／**数量**／**単価**／**納期**／納入場所／支給材の有無／梱包指定／注文書の記載内容が**見積と一致しているか** |
| **④ 何をする** | 注文書と自社の見積を1項目ずつ照合する。相違があれば顧客へ確認し、訂正された注文書を受け直すか、社内で条件を合わせる。一致を確認したうえで受注として登録する。必要に応じて注文請書を返送する |
| **⑤ 何を判断** | **相違があった場合に、そのまま受けるか・訂正を求めるか**／数量が見積より減っている場合に単価を見直す必要があるか／納期が見積時の回答より短い場合に対応できるか（② 生産管理機能へ確認） |
| **⑥ 誰と連携** | ② 受注・生産管理機能（受注登録・納期確認）／⑨ 経理・財務機能（単価マスタ・売掛の相手先情報）／顧客の購買担当 |
| **⑦ 出来上がるもの** | **受注データ**（受注番号、顧客、品番、数量、単価、納期、納入場所、指定仕様）、注文請書、受注残の更新 |

> **なぜこの業務が必要なのか**
> 【Typical】**見積と注文書は一致しないことがある**からです。
> 【Example】見積は1,000個前提で単価808円としたのに、注文書が200個で単価808円になっている。
> 段取り費は数量で割るため、200個では1個あたりの段取り負担が5倍になり、その単価では赤字になります。
> **数量が変われば適正な単価も変わる**ため、この照合は利益を守る作業です。

> **【重要】受注は売上ではありません**
> 【Typical】注文書を受け取っただけでは、会計上の売上にはなりません。
> 売上が立つのは、製品を納品し、顧客が受け取りを認めた（検収した）後です。
> 受注時点の金額は「**受注残**（まだ納めていない注文の残高）」として管理されます
> （`04_end-to-end-process.md` STEP ⑭ の対比表を参照）。

> **用語：内示（ないじ）と確定注文**
> → 内示＝顧客から届く「今後これくらい発注する見込みです」という予定数量。フォーキャストとも呼ぶ。
>   確定注文＝実際に「この日にこれだけ納めてください」と確定した指示。
> → 実務例：D自動車部品社から「4月2,000個、5月2,000個、6月1,800個」という3か月分の内示が届く。
>    材料の納期が3週間かかるため、この内示をもとに材料を先に手配する。
>    その後、納入の2週間前に「4月分は確定1,800個」という確定注文が来る。
>    **内示は約束ではない**ため、差の200個分の材料が余るリスクは自社が負う。
>    どこまで内示を信じて手配するかは、② 受注・生産管理機能の日常的な判断です。

#### E-1-6. 納期回答・納期変更の顧客連絡

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 見積時に納期を聞かれたとき／受注時に納期を確定するとき／社内の遅れ・外注の遅れ・材料の遅れが判明したとき（トラブル発生時） |
| **② 誰が** | 営業担当者（顧客への伝達）。納期そのものを決めるのは ② 受注・生産管理機能 |
| **③ 何を確認** | 現在の工場の負荷状況（どの設備がいつまで埋まっているか）／材料の調達期間／外注工程の往復日数／顧客の希望納期と、その納期が動かせるものかどうか（顧客のライン停止に直結するか） |
| **④ 何をする** | ② 受注・生産管理機能から回答納期を受け取り、顧客へ伝える。遅延が見込まれる場合は、判明した時点で速やかに連絡し、代替案（分納、一部先行納入、日程変更）を提示して調整する |
| **⑤ 何を判断** | **いつ顧客に伝えるか**（遅れが確定してからでは遅い）／分納（数量を分けて先に一部を納める）で顧客の生産が回るか／納期を守るために残業・外注を使う場合、その追加費用を誰が負担するか |
| **⑥ 誰と連携** | ② 受注・生産管理機能（納期の算定と再調整）／⑦ 出荷・物流機能（便の手配）／④ 調達機能（外注・材料の前倒し交渉）／顧客の購買・生産管理担当 |
| **⑦ 出来上がるもの** | **納期回答（正式な回答納期）**、納期変更の連絡記録、分納計画 |

> **なぜこの業務が必要なのか**
> 【Typical】顧客は、自社から届く部品を前提に**自分の生産計画を組んでいます**。
> 部品が1日遅れると、顧客の組立ラインが止まり、その先の顧客への納期にも波及します。
> だから顧客が最も嫌うのは「遅れること」そのものよりも「**遅れることを直前まで知らされないこと**」です。
> 早く伝えれば顧客は手を打てます。**納期連絡は、信用を守るための業務**です。

#### E-1-7. 支給材・貸与品（型・治具）の取り決め

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 顧客が材料を支給する取引を始めるとき／顧客が金型・治具・検査治具を貸与するとき（案件発生時・受注時） |
| **② 誰が** | 営業担当者。契約条件の最終判断は社長。現物の管理は ⑦ 出荷・物流機能と ⑤ 製造機能 |
| **③ 何を確認** | **有償支給か無償支給か**／支給材の単価と支給のタイミング／支給材に不良があった場合の責任分担／端材・スクラップの扱い（返却するか自社で処分するか）／貸与される型・治具の所有者と保管責任／型の修理費の負担者／返却条件 |
| **④ 何をする** | 支給・貸与の条件を文書で取り決める（覚書、取引基本契約書の個別条項）。社内に条件を周知し、⑦ 出荷・物流機能に預り品としての管理方法を伝える |
| **⑤ 何を判断** | **有償支給を受けるか無償支給にしてもらうか**（自社の資金負担と売上の見え方が変わる）／支給材の受入検査をどこまで自社で行うか／型の保管スペースと保管年数を引き受けられるか |
| **⑥ 誰と連携** | ⑦ 出荷・物流機能（預り品の保管・数量管理）／⑨ 経理・財務機能（有償支給の仕入計上・相殺処理）／⑤ 製造機能・⑧ 設備保全機能（型・治具の保管）／顧客 |
| **⑦ 出来上がるもの** | **支給・貸与に関する取り決め（覚書等）**、預り品台帳、貸与品台帳 |

> **なぜこの業務が必要なのか**
> 【Typical】支給材と貸与品は**自社の所有物ではありません**。
> 紛失・破損したとき、誰が負担するのかを先に決めていないと、金額の大きなトラブルになります。
> また、有償支給か無償支給かで、自社の売上高・仕入計上・在庫の持ち方がすべて変わります
> （`02_industry-structure.md` 11-3 (2) の対比表を参照）。
> 【Fact】なお、有償支給の場合、委託事業者が支給した原材料等の対価を製品代金の支払期日より早く支払わせることや、
> 代金から控除することは、取適法（旧・下請法）の禁止項目⑧「有償支給原材料等の対価の早期決済」に該当します
> （出典：公正取引委員会 中部事務所「下請法 知っておきたい豆情報 その10」）。

#### E-1-8. クレーム一次対応・顧客訪問

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 顧客から不具合の連絡が入ったとき（寸法違い、傷、数量違い、納期遅れ、組み付かない等）＝**トラブル発生時** |
| **② 誰が** | 営業担当者（一次受け・窓口）。原因調査は ⑥ 品質保証機能、対策は ⑤ 製造機能、代替品の日程は ② 受注・生産管理機能 |
| **③ 何を確認** | 何が・いつ・どこで・何個・どのように不具合だったか／現品が顧客の手元にあるか（返却してもらえるか）／顧客の生産ラインが止まっているか（緊急度）／代替品がいつ必要か／自社が納めたロットはどれか（現品票・検査記録から特定） |
| **④ 何をする** | 事実を正確に聞き取り、社内へ即時に共有する。顧客の生産が止まる場合は、代替品の最短納期を ② 受注・生産管理機能に確認して回答する。現品を引き取って社内で確認する。調査結果と対策を顧客へ報告する |
| **⑤ 何を判断** | **どこまでを自社の責任として引き受けるか**（自社工程の不良か、外注先の不良か、顧客側の取扱いによるものか）／代替品を無償で作るか／緊急便を使うか（費用負担）／顧客先へ選別に行くか |
| **⑥ 誰と連携** | ⑥ 品質保証機能（原因調査・是正処置報告書の作成）／⑤ 製造機能（手直し・再製作）／② 受注・生産管理機能（割込み生産の日程）／④ 調達機能（外注起因の場合）／社長（重大案件）／顧客 |
| **⑦ 出来上がるもの** | **クレーム受付記録**、代替品の出荷、⑥ 品質保証機能が作成する**是正処置報告書**（顧客提出） |

> **なぜこの業務が必要なのか**
> 【Typical】顧客が本当に知りたいのは「代替品を早く送ってほしい」だけではありません。
> **「同じことが二度と起きないか」**です。
> その部品が顧客の製品に組み込まれて市場に出た後で不具合が出れば、
> 顧客はリコールや信用失墜という、はるかに大きな損害を受けます。
> だから不具合対応は、**取引を継続できるかどうかを決める業務**になります。
> 【Typical】営業機能がここで担う役割は「事実を正確に持ち帰ること」と「社内の対応を顧客の時間軸に合わせること」です。

#### E-1-9. 売掛金回収のフォロー（未入金の確認）

| 観点 | 内容 |
|---|---|
| **① きっかけ** | ⑨ 経理・財務機能から「請求額と入金額が合わない」「入金がない」と連絡が来たとき（**入金時／月次**） |
| **② 誰が** | 営業担当者（顧客への確認）。主管は ⑨ 経理・財務機能 |
| **③ 何を確認** | 差額の内容（値引き、相殺、振込手数料の顧客負担、検収漏れ、翌月回し）／顧客側の検収状況／納品書の受領印の有無／支払通知書の内容 |
| **④ 何をする** | 顧客の購買・経理担当へ確認し、差額の理由を突き止める。自社側の請求誤りであれば訂正する。検収漏れであれば検収を依頼する |
| **⑤ 何を判断** | 差額が自社の非か顧客の事情か／支払遅延が継続している場合に取引条件を見直す必要があるか（社長へ報告） |
| **⑥ 誰と連携** | ⑨ 経理・財務機能（消込・売掛金残高）／⑦ 出荷・物流機能（受領印のある納品書控の確認）／社長／顧客 |
| **⑦ 出来上がるもの** | **差額の原因が特定された記録**、訂正請求書または追加請求、入金予定の確認 |

> **なぜこの業務が必要なのか**
> 【Typical】製造業は**材料費と人件費を先に払い、代金は2〜3か月後に受け取る**商売です
> （`04_end-to-end-process.md` 4-1 の時間軸参照）。回収できなければ、かけた原価がそのまま損失になります。
> 経理だけでは顧客側の事情（検収のタイミング、担当者の処理状況）が分からないため、
> 顧客の窓口である営業機能が確認役を担います。

#### E-1-10. 顧客情報・受注見込み（受注残・内示）の管理

| 観点 | 内容 |
|---|---|
| **① きっかけ** | 常時（受注・出荷・内示受領のつど更新）／月次で集計 |
| **② 誰が** | 営業担当者・営業責任者。データの管理は ② 受注・生産管理機能と共同 |
| **③ 何を確認** | 顧客別の受注残高（まだ納めていない注文の金額）／顧客別の内示数量と確定率／見積提出済みで未受注の案件（見込み案件）／顧客の担当者の異動・設備投資計画・生産計画の変化 |
| **④ 何をする** | 受注残・内示・見込み案件を集計し、翌月以降の売上見込みを作る。② 受注・生産管理機能へ「これから来る仕事の量」を伝える。顧客を定期訪問し、先の予定を聞き取る |
| **⑤ 何を判断** | 【Varies】内示のうちどこまでを「ほぼ確実」として社内に伝えるか／工場の負荷が空く時期に、どの顧客に声をかけるか／特定顧客への依存度が高まっていないか（社長へ報告） |
| **⑥ 誰と連携** | ② 受注・生産管理機能（先々の負荷見通し）／④ 調達機能（長納期材の先行手配判断）／⑨ 経理・財務機能（資金繰りの前提となる売上見込み）／社長 |
| **⑦ 出来上がるもの** | **受注残一覧**、**売上見込み表**、顧客別の取引状況の記録 |

> **なぜこの業務が必要なのか**
> 【Typical】工場は「来月どれだけ仕事が来るか」が分からないと、人員配置も材料手配も決められません。
> 【Inference】特に長納期材（電子部品や特殊鋼など）は、確定注文を待ってから手配すると納期に間に合わないため、
> **見込みの情報をどれだけ早く社内に流せるかが、納期を守れるかどうかを左右します**。
> これが、受託加工型の中小製造業で営業機能に「既存顧客の予定を早くつかむ」役割が求められる理由です。

### I. 関係部署（前工程・後工程）

```
【前工程】                    【① 営業機能】                 【後工程】

 顧客（引合い・図面・注文書） ──→  引合い受付              ──→ ③ 生産技術機能（工程検討）
 ③ 生産技術機能（工程・時間） ──→  見積とりまとめ           ──→ ④ 調達機能（材料単価照会）
 ④ 調達機能（材料・外注単価） ──→  見積書作成              ──→ 顧客（見積提出）
 ② 生産管理機能（負荷・納期） ──→  納期回答                ──→ 顧客
 顧客（注文書）             ──→  受注照合                ──→ ② 受注・生産管理機能（受注登録）
 ⑥ 品質保証機能（調査結果）   ──→  クレーム報告            ──→ 顧客
 ⑨ 経理機能（未入金情報）     ──→  回収フォロー            ──→ 顧客／⑨ 経理・財務機能
```

| 関係する機能 | 何をやり取りするか |
|---|---|
| ② 受注・生産管理機能 | **最も密接**。受注情報を渡し、納期・進捗の回答を受ける |
| ③ 生産技術機能 | 図面・仕様を渡し、製作可否・工程案・標準時間を受ける |
| ④ 調達機能 | 材料・外注の単価と納期を照会する |
| ⑥ 品質保証機能 | 顧客の検査要求を伝え、検査成績書・是正処置報告書を受ける |
| ⑦ 出荷・物流機能 | 納入条件（時間指定・荷姿）を伝え、納品実績・受領印の状況を受ける |
| ⑨ 経理・財務機能 | 単価・支払条件を渡し、売掛金・実際原価・粗利の情報を受ける |
| 経営（社長） | 見積承認、与信判断、価格交渉の最終判断を仰ぐ |

### Level 2：業種による営業機能の違い【Varies】

| 業種 | 営業機能の姿の違い |
|---|---|
| **食品製造** | 【Typical】見込生産が中心のため、案件ごとの見積・図面受領がない。代わりに**商談は「定番採用」「棚の獲得」「販促計画」**が中心になる。顧客はスーパー・コンビニ本部・食品卸で、年間の商談サイクル（棚替え時期）に合わせて動く。日々の受注は電話・EDIで自動的に入るため、営業は受注処理より**得意先との販売計画づくり**に時間を使う |
| **金属加工** | 本文の基本形。図面を受け取り、原価を積み上げて見積を出す。**図面が読めることが営業の前提条件**になる |
| **機械製造** | 【Typical】1件の金額が大きく、商談期間が数か月〜年単位。仕様を顧客と一緒に固めていく**提案型の営業**になり、③ 生産技術機能・設計機能との同行訪問が多い。**据付・試運転・引渡し**までが商談範囲に含まれ、支払も着手金・中間金・完成時払いに分かれることがある |
| **電気機器** | 【Typical】繰返生産が中心で、内示と確定注文の管理が営業の中心業務になる。**電子部品の調達期間が長い**ため、内示をどれだけ早く取れるかが納期を左右する。部品の生産終了（ディスコン）の連絡・代替品の提案も営業の仕事に入る |
| **化学・プラスチック** | 【Typical】汎用グレードは価格表があり、特注配合は技術部門を交えた商談になる。**安全データシート（SDS）の提供**が取引の前提として求められる |
| **印刷** | 【Typical】受注後に**校正（内容の確認と修正のやり取り）**が発生し、この往復の管理が営業の主要業務になる。顧客の広報・販促部門が相手のため、締切が固定されている（イベント日、発売日）ことが多い |
