# 15_rules-customs.md — 業界特有のルール（法規制・許認可・資格）と商習慣

**対象**：日本国内の中小製造業
**前提**：`02_industry-structure.md`（商流・取適法）、`03_company-structure.md`（モデル企業）を読んでいること
**最終更新**：2026-09-16

> ### ⚠️ このファイルを読むときの最重要の注意
>
> **「製造業だから、これらの法令がすべて適用される」わけではありません。**
> 適用されるかどうかは、次の要素によって1社ごとに変わります。
>
> - **何を作っているか**（食品か、金属部品か、化学品か）
> - **どんな物質を扱っているか**（危険物か、有機溶剤か、毒物・劇物か）
> - **どんな設備を持っているか**（ボイラー、クレーン、プレス機械、フォークリフト）
> - **従業員が何人いるか**（10人／50人／300人で義務が変わるものがある）
> - **誰と取引しているか**（取引先の規模により取適法の適用が決まる）
> - **輸出しているか**
>
> 【Example】モデル企業 X金属工業（45名・金属加工・塗装は外注）を例にすると、
> 食品衛生法は無関係で、化審法の届出義務も生じません。一方、労働安全衛生法と取適法は中心的に関わります。
> **本ファイルは「製造業で登場しうる法令の地図」であり、チェックリストではありません。**
>
> 本ファイルに記載した法令の条文は、**2026年9月16日時点でe-Gov法令検索および各省庁の公式情報で確認したもの**です。
> 法令は改正されます。実務では必ず最新の条文・所管省庁の案内を確認してください。

## 15-1. 製造物責任法（PL法）

### 何のための法律か

> **用語：製造物責任法（PL法）**
> → 製造した物の**欠陥**によって、人の生命・身体・財産に被害が生じたとき、
>   製造した側が**過失がなくても**損害賠償の責任を負うことを定めた法律。
> → **なぜこの仕組みがあるのか**：被害者が「メーカーに過失があったこと」を証明するのは極めて困難だからです。
>   欠陥の存在と被害との因果関係を示せば足りる、という形にすることで被害者の保護を図っています。

### 条文で確認できる要点【Fact】

（出典：製造物責任法（平成6年法律第85号）／e-Gov法令検索）

| 条 | 内容 |
|---|---|
| 第2条第1項 | 「**製造物**」とは、**製造又は加工された動産**をいう |
| 第2条第2項 | 「**欠陥**」とは、当該製造物の特性、通常予見される使用形態、引き渡した時期その他の事情を考慮して、**通常有すべき安全性を欠いている**ことをいう |
| 第2条第3項 | 「**製造業者等**」とは、①業として製造・加工・輸入した者、②自らの氏名・商号・商標等を製造業者として表示した者、③実質的な製造業者と認めることができる表示をした者 |
| 第3条 | 製造業者等は、引き渡した製造物の欠陥により他人の生命・身体・財産を侵害したとき、損害を賠償する責任を負う。**ただし、その損害が当該製造物についてのみ生じたときは、この限りでない** |
| 第4条 | **免責事由**：①引き渡した時点の科学・技術の知見では欠陥を認識できなかったこと（開発危険の抗弁）、②**他の製造物の部品・原材料として使用された場合に、欠陥が専らその設計指示に従ったことにより生じ、かつ過失がないこと** |
| 第5条 | **期間制限**：損害および賠償義務者を知った時から**3年**（生命・身体の侵害の場合は**5年**）、製造業者等が引き渡した時から**10年** |

> **【重要】中小製造業にとって特に関係が深い2点**
>
> **(1) 部品メーカーの免責（第4条第2号）**
> 【Fact】自社が作ったのが部品・原材料で、その欠陥が**顧客の設計指示に従ったことにより生じ**、
> かつ自社に過失がない場合、賠償責任を負わないと定められています。
> 【Inference】受託加工型の中小製造業にとっては、「顧客の図面どおりに作った」という**記録**が
> この主張の根拠になります。図面の版管理・検査記録の保存が実務上重要になるのはこのためです（`09_information.md` 9-5）。
>
> **(2) 「製造物についてのみ生じた損害」は対象外（第3条ただし書）**
> 【Fact】買った製品自体が壊れただけ、という損害はPL法の対象外です（民法の契約責任の問題になります）。
> PL法が扱うのは、**その製品の欠陥によって、それ以外の人や物に被害が及んだ場合**です。

## 15-2. 労働安全衛生法（安衛法）— 中小製造業に最も広く関わる法律

【Inference】製造業は機械・電気・化学物質・重量物を扱うため、労働安全衛生法の適用範囲が広く、
中小製造業の人事・総務機能と製造機能が日常的に関わる法律です。

### (1) 安全衛生の管理体制：従業員数で義務が変わる【Fact】

（出典：労働安全衛生法、労働安全衛生法施行令、労働安全衛生規則／e-Gov法令検索）

| 選任するもの | 製造業での選任要件 | 根拠 |
|---|---|---|
| **総括安全衛生管理者** | 常時**300人以上**の労働者を使用する事業場 | 安衛法第10条、安衛令第2条第2号（製造業は第2号に該当） |
| **安全管理者** | 常時**50人以上**の労働者を使用する事業場 | 安衛法第11条、安衛令第3条 |
| **衛生管理者** | 常時**50人以上**の労働者を使用する事業場 | 安衛法第12条、安衛令第4条 |
| **産業医** | 常時**50人以上**の労働者を使用する事業場 | 安衛法第13条、安衛令第5条 |
| **安全衛生推進者** | 常時**10人以上50人未満**の労働者を使用する事業場 | 安衛法第12条の2、安衛則第12条の2。選任事由が発生した日から**14日以内**に、その事業場に専属の者を選任する（安衛則第12条の3） |

> **【Example】モデル企業（45名）の場合**
> 【Fact】45名なので、安全管理者・衛生管理者・産業医の選任義務は生じません。
> 代わりに、**安全衛生推進者**の選任義務が生じます。
> 【Inference】この「50人の壁」は中小製造業にとって実務上大きな区切りで、
> 50人を超えると衛生委員会の設置、産業医の選任、定期健康診断結果報告書の提出などの義務が一度に増えます。

### (2) 安全衛生教育【Fact】

（出典：労働安全衛生法第59条・第60条／e-Gov法令検索）

| 種類 | いつ行うか | 根拠 |
|---|---|---|
| **雇入れ時教育** | 労働者を雇い入れたとき | 第59条第1項 |
| **作業内容変更時教育** | 労働者の作業内容を変更したとき | 第59条第2項 |
| **特別教育** | 厚生労働省令で定める危険・有害業務に就かせるとき | 第59条第3項 |
| **職長等教育** | 政令で定める業種で、新たに職長その他作業中の労働者を直接指導・監督する者になったとき | 第60条 |

### (3) 資格が必要な業務（就業制限）【Fact】

> **用語：就業制限**
> → 一定の危険な業務には、**免許を持つ者・技能講習を修了した者でなければ就かせてはならない**という規制。
> → **なぜあるのか**：これらの機械は、扱い方を誤ると死亡災害につながるためです。

【Fact】労働安全衛生法第61条第1項および労働安全衛生法施行令第20条により、製造業の現場で関係が深いものは次のとおりです
（出典：e-Gov法令検索）。**免許または技能講習の修了が必要**です。

| 業務 | 規模の要件 | 令第20条の号 |
|---|---|---|
| **フォークリフトの運転**（道路上の走行を除く） | **最大荷重1トン以上** | 第11号 |
| **クレーンの運転** | **つり上げ荷重5トン以上** | 第6号 |
| **移動式クレーンの運転**（道路上の走行を除く） | **つり上げ荷重1トン以上** | 第7号 |
| **玉掛けの業務** | つり上げ荷重**1トン以上**のクレーン等 | 第16号 |
| **ボイラーの取扱い**（小型ボイラーを除く） | — | 第3号 |
| **可燃性ガスおよび酸素を用いた金属の溶接・溶断・加熱**（ガス溶接） | — | 第10号 |
| **ショベルローダー／フォークローダーの運転** | 最大荷重1トン以上 | 第13号 |
| **不整地運搬車の運転** | 最大積載量1トン以上 | 第14号 |
| **高所作業車の運転** | 作業床の高さ10メートル以上 | 第15号 |

> **用語：玉掛け（たまかけ）**
> → クレーンで荷を吊るときに、ワイヤロープやベルトを荷に掛け外しする作業のこと。
> → 実務例：溶接した重い製品をクレーンで移動させるため、フックにベルトを掛ける。
> → **なぜ資格が要るのか**：掛け方を誤ると荷が落下し、重大災害になるためです。

【Fact】また、**規模が小さいもの**は「就業制限」ではなく**特別教育**の対象になります
（労働安全衛生規則第36条／出典：e-Gov法令検索）。製造業で関係が深いもの：

| 業務 | 号 |
|---|---|
| **研削といしの取替えまたは取替え時の試運転** | 第1号 |
| **動力プレス機械の金型・シャーの刃部・安全装置等の取付け、取外し、調整** | 第2号 |
| **アーク溶接機を用いて行う金属の溶接・溶断等** | 第3号 |
| **低圧の充電電路の敷設・修理等**（対地電圧50V超） | 第4号 |
| **最大荷重1トン未満のフォークリフトの運転** | 第5号 |
| **つり上げ荷重5トン未満のクレーンの運転** | 第15号 |
| **つり上げ荷重1トン未満のクレーン等の玉掛けの業務** | 第19号 |
| **産業用ロボットの教示等**（可動範囲内での動作の順序・位置・速度の設定、変更、確認） | 第31号 |
| **産業用ロボットの可動範囲内で行う検査・修理・調整等** | 第32号 |
| **特定粉じん作業に係る業務** | 第29号 |

### (4) 作業主任者【Fact】

> **用語：作業主任者**
> → 労働災害を防ぐための管理を必要とする作業について、**作業に従事する労働者を指揮する者**。
>   免許を受けた者、または技能講習を修了した者から選任する。

【Fact】労働安全衛生法第14条および労働安全衛生法施行令第6条により、製造業で関係が深い作業は次のとおりです
（出典：e-Gov法令検索）。

| 作業 | 要件 | 令第6条の号 |
|---|---|---|
| **プレス機械による作業** | 動力により駆動されるプレス機械を**5台以上**有する事業場 | 第7号 |
| **木材加工用機械による作業** | 丸のこ盤・帯のこ盤等を**5台以上**（自動送材車式帯のこ盤を含む場合は3台以上）有する事業場 | 第6号 |
| **有機溶剤を製造・取り扱う業務**（屋内作業場等） | 有機溶剤（5重量％超の混合物を含む） | 第22号 |
| **特定化学物質を製造・取り扱う作業** | 別表第3に掲げる特定化学物質 | 第18号 |
| **乾燥設備による物の加熱乾燥の作業** | 危険物等に係る設備で内容積1立方メートル以上、など | 第8号 |
| **ボイラーの取扱いの作業**（小型ボイラーを除く） | — | 第4号 |
| **第一種圧力容器の取扱いの作業** | 小型圧力容器等を除く | 第17号 |
| **アセチレン溶接装置・ガス集合溶接装置を用いた作業** | — | 第2号 |
| **酸素欠乏危険場所における作業** | 別表第6に掲げる場所 | 第21号 |
| **石綿等を取り扱う作業** | — | 第23号 |
| **鉛業務に係る作業** | 別表第4第1号〜第10号 | 第19号 |

> **【Example】モデル企業の場合**
> 【Example】塗装・めっきを外注しているため有機溶剤作業主任者の選任は不要ですが、
> タレットパンチプレス（動力プレス）の保有台数によってはプレス機械作業主任者が必要になります。
> **自社が何を保有し、何を内製しているかによって、必要な資格者が変わります。**

### (5) 化学物質の管理：ラベル表示・SDS・リスクアセスメント【Fact】

> **用語：SDS（安全データシート／Safety Data Sheet）**
> → その化学物質が何でできていて、どんな危険があり、どう扱い、事故のときどうするかを書いた文書。
> → 実務例：切削油や洗浄剤を仕入れると、メーカーからSDSが提供される。
>   自社が化学品を出荷する側なら、顧客にSDSを渡す。

【Fact】労働安全衛生法第57条の2により、**通知対象物**を譲渡・提供する者は、
名称、成分およびその含有量、物理的・化学的性質、人体に及ぼす作用、貯蔵・取扱い上の注意、
流出その他の事故時の応急措置等を、文書の交付その他の方法で相手方に通知しなければなりません
（出典：e-Gov法令検索）。

【Fact】同法第57条の3により、事業者は、これらの物による**危険性・有害性等の調査（リスクアセスメント）**を
行わなければならないと定められています（出典：e-Gov法令検索）。

### (6) 設備を設置・変更するときの届出【Fact】

【Fact】労働安全衛生法第88条により、危険・有害な作業を必要とする機械等のうち厚生労働省令で定めるものを
設置・移転・主要構造部分の変更をしようとするときは、その計画を**工事開始の日の30日前まで**に
労働基準監督署長へ届け出なければなりません（出典：e-Gov法令検索）。

### (7) 健康診断と報告【Fact】

| 項目 | 内容 | 根拠 |
|---|---|---|
| 定期健康診断 | 常時使用する労働者に対し、**1年以内ごとに1回** | 安衛則第44条 |
| 特定業務従事者の健康診断 | 深夜業等の特定業務に常時従事する者に対し、配置替えの際および**6か月以内ごとに1回** | 安衛則第45条 |
| 特殊健康診断 | 政令で定める有害業務に従事する労働者に対する特別の項目の健康診断 | 安衛法第66条第2項 |
| 健康診断結果報告 | **常時50人以上**の労働者を使用する事業者は、定期健康診断を行ったとき**遅滞なく**、電子情報処理組織を使用して所轄労働基準監督署長に報告 | 安衛則第52条 |
| 労働者死傷病報告 | 労働者が労働災害等により**死亡または休業**したときは、**遅滞なく**、電子情報処理組織を使用して所轄労働基準監督署長に報告 | 安衛則第97条 |

（出典：いずれもe-Gov法令検索）

## 15-3. 消防法（危険物・防火管理）

### 危険物の規制【Fact】

> **用語：危険物／指定数量**
> → 危険物＝消防法別表第一に掲げられた、火災の危険が高い物質（ガソリン、灯油、シンナー、塗料、切削油の一部など）。
> → 指定数量＝「これ以上の量を扱うなら、許可を受けた施設でなければならない」という基準量。物質ごとに定められている。

【Fact】消防法第10条により、**指定数量以上の危険物**は、
貯蔵所以外の場所で貯蔵すること、製造所・貯蔵所・取扱所以外の場所で取り扱うことができません
（所轄消防長・消防署長の承認を受けて10日以内の期間、仮に貯蔵・取扱いをする場合を除く）（出典：e-Gov法令検索）。

【Fact】同条により、**品名または指定数量を異にする2以上の危険物を同一の場所で扱う場合、
それぞれの数量を指定数量で割った商の和が1以上になるとき**は、指定数量以上を扱っているものとみなされます（出典：e-Gov法令検索）。

> **なぜこの「商の和」のルールがあるのか**
> 【Inference】1種類ずつは指定数量未満でも、複数を合わせれば同等の危険があるためです。
> 【Typical】塗料・シンナー・洗浄剤・切削油を少量ずつ持っている工場では、この合計の計算が必要になります。

### 危険物取扱者・危険物保安監督者【Fact】

（出典：消防法第13条・第13条の2／e-Gov法令検索）

| 項目 | 内容 |
|---|---|
| **危険物取扱者免状の種類** | **甲種・乙種・丙種**の3種類。都道府県知事が交付する |
| **立会いのルール** | 製造所・貯蔵所・取扱所では、危険物取扱者以外の者は、**甲種または乙種危険物取扱者が立ち会わなければ**危険物を取り扱ってはならない |
| **危険物保安監督者** | 政令で定める製造所等の所有者等は、甲種または乙種危険物取扱者で**6か月以上の実務経験**を有する者のうちから選任し、市町村長等に届け出る |

### 防火管理者【Fact】

【Fact】消防法第8条により、工場・事業場を含む政令で定める防火対象物の管理について権原を有する者は、
政令で定める資格を有する者のうちから**防火管理者**を定め、消防計画の作成、
消火・通報・避難の訓練の実施、消防用設備等の点検・整備、火気の使用・取扱いの監督等を行わせなければなりません。
選任したときは遅滞なく所轄消防長または消防署長に届け出ます（出典：e-Gov法令検索）。

【Fact】消防法第17条の3の3により、消防用設備等について定期に点検し、
その結果を消防長または消防署長に報告する義務があります（出典：e-Gov法令検索）。
【Varies】点検・報告の周期は防火対象物の区分により異なります。

## 15-4. 化学物質に関する規制

製造業では、扱う物質によって複数の法律が重なって適用されます。**それぞれ目的が違う**ことが理解の鍵です。

| 法律 | 何を守るための法律か | 誰にかかるか |
|---|---|---|
| **労働安全衛生法** | **働く人**の健康・安全 | 化学物質を**扱う**事業者（ラベル表示・SDS・リスクアセスメント） |
| **化審法** | **環境**（人の健康・生態系） | 化学物質を**製造・輸入する**事業者 |
| **毒物及び劇物取締法（毒劇法）** | **保健衛生上の危害防止** | 毒物・劇物を製造・輸入・販売・業務上取り扱う者 |
| **化管法（PRTR）** | 化学物質の**環境への排出量の把握** | 対象物質を一定量以上取り扱う指定業種の事業者 |
| **消防法** | **火災の防止** | 危険物を貯蔵・取り扱う者 |

### (1) 化審法（化学物質の審査及び製造等の規制に関する法律）【Fact】

【Fact】化審法第3条により、**新規化学物質を製造し、または輸入しようとする者**は、
あらかじめその名称等を厚生労働大臣・経済産業大臣・環境大臣に届け出なければなりません
（試験研究のため、試薬として、少量の確認を受けた場合等の適用除外があります）（出典：e-Gov法令検索）。

> **【重要】ここが誤解されやすい点**
> 【Fact】化審法の届出義務は、化学物質を**製造または輸入する**者にかかります。
> 【Inference】他社から仕入れた塗料や洗浄剤を**使うだけ**の中小製造業には、この届出義務は生じません。
> 使う側にかかるのは、主に労働安全衛生法（SDS・リスクアセスメント）と消防法（危険物）です。

### (2) 毒物及び劇物取締法（毒劇法）【Fact】

（出典：毒物及び劇物取締法／e-Gov法令検索）

| 条 | 内容 |
|---|---|
| 第7条 | **毒物劇物営業者**（製造業・輸入業・販売業）は、毒物・劇物を直接取り扱う製造所・営業所・店舗ごとに**専任の毒物劇物取扱責任者**を置かなければならない。置いたときは**30日以内**に都道府県知事に氏名を届け出る |
| 第22条 | 政令で定める事業を行う者で、業務上**シアン化ナトリウムその他政令で定める毒物・劇物を取り扱うもの**は、事業場ごとに、取り扱うこととなった日から**30日以内**に都道府県知事に届け出なければならない |

> 【Typical】第22条の届出は、**電気めっき業**など特定の事業が政令で定められています。
> 【Inference】めっきを外注しているモデル企業には直接には関係しませんが、
> 外注先がこの規制の対象であることを理解しておくと、外注先の選定や監査の場面で話が通じます。

## 15-5. 廃棄物処理法（廃棄物の処理及び清掃に関する法律）

### 産業廃棄物とマニフェスト【Fact】

> **用語：産業廃棄物管理票（マニフェスト）**
> → 産業廃棄物を他社に運搬・処分してもらうとき、「何を・どれだけ・誰に渡したか」を記録し、
>   最終処分が終わるまでを追跡するための伝票。
> → **なぜあるのか**：委託した廃棄物が適正に処理されたことを、排出した側が確認するためです。
>   不法投棄されれば、排出した事業者の責任が問われることがあります。

【Fact】廃棄物処理法第12条の3および同施行規則により、次のことが定められています（出典：e-Gov法令検索）。

| # | 義務 | 内容 |
|---|---|---|
| ① | 管理票の交付 | 事業活動に伴い産業廃棄物を生じる事業者は、運搬または処分を他人に委託する場合、**産業廃棄物の引渡しと同時に**、種類・数量・受託者名等を記載した管理票を交付する（第12条の3第1項） |
| ② | 交付した管理票の写しの保存 | **5年間**（第12条の3第2項、施行規則第8条の21の2） |
| ③ | 送付を受けた管理票の写しの保存 | 運搬・処分の終了を確認し、送付を受けた日から**5年間**（第12条の3第6項、施行規則第8条の26） |
| ④ | 報告書の提出 | 事業場ごとに、**毎年6月30日まで**に、その年の3月31日以前の1年間に交付した管理票の交付等の状況を、都道府県知事に提出する（第12条の3第7項、施行規則第8条の27） |
| ⑤ | 写しが返送されない場合の措置 | 定められた期間内に管理票の写しの送付を受けないとき等は、速やかに運搬・処分の状況を把握し、適切な措置を講ずる（第12条の3第8項） |

> **【Typical】中小製造業で発生する主な産業廃棄物**
> 【Typical】金属くず（切粉・端材）、廃油（切削油・洗浄油）、汚泥、廃プラスチック類、
> 廃酸・廃アルカリ、燃え殻、ガラス・陶磁器くず など。
> 【Typical】金属くずは有価物として**売却できる**場合があり、その場合は廃棄物ではなく売却収入になります
> （`08_money.md` の営業外収益「スクラップ売却益」）。
> 【Varies】有価か廃棄物かは相場や性状によって変わります。

## 15-6. フロン排出抑制法（フロン類の使用の合理化及び管理の適正化に関する法律）

### 誰にかかるのか

> **用語：第一種特定製品**
> → 業務用のエアコン・冷凍冷蔵機器のうち、冷媒としてフロン類が充塡されているもの。
> → 実務例：工場の業務用エアコン、冷却水チラー、コンプレッサの冷却機器、製品保管用の冷蔵庫。
> → 【Inference】**「化学工場だけの話」ではありません。** 業務用エアコンを持つ工場は広く対象になります。

### 管理者の義務【Fact】

| # | 義務 | 内容 | 出典 |
|---|---|---|---|
| ① | **簡易点検** | すべての第一種特定製品について**3か月に1回以上**。実施者の資格要件はない | 環境省「フロン排出抑制法」ポータルサイト／機器の点検 |
| ② | **定期点検** | 圧縮機の電動機の定格出力が**7.5kW以上**の機器について**1年に1回以上**（**50kW未満の空調機器は3年に1回以上**）。十分な知見を有する者が実施 | 同上 |
| ③ | **点検・整備の記録の保存** | 機器ごとに点検記録簿として作成・保存し、機器の廃棄等を行い冷媒の引渡しを完了した日から**3年**を経過するまで保存 | 環境省ポータルサイト／点検・整備の記録 |
| ④ | **算定漏えい量の報告** | フロン類算定漏えい量が**年間1,000トン（CO2換算）以上**の事業者は、毎年度、事業所管大臣に報告 | フロン排出抑制法第19条、フロン類算定漏えい量等の報告等に関する命令第3条／e-Gov法令検索 |
| ⑤ | **廃棄時のフロン類の引渡し** | 第一種特定製品の廃棄等の際は、第一種フロン類充塡回収業者へフロン類を引き渡す。回収依頼書・委託確認書の写し、および引取証明書を**3年間保存** | 環境省ポータルサイト／機器の廃棄 |

> 【Inference】④の1,000トン（CO2換算）という基準は大きく、中小製造業の多くは該当しません。
> 一方、①②③⑤は**業務用エアコンを1台でも持っていれば関係する**ため、
> 中小製造業で実際に発生するのはこちらです。

## 15-7. 計量法

### 何が規制されているか【Fact】

> **用語：取引または証明**
> → 取引＝有償・無償を問わず、物の受け渡しや役務の提供を行うこと。
>   証明＝公に、または業務上、一定の事実が真実であることを示すこと。
> → 実務例：「製品を重量で売る」「検査成績書に重量を記載して顧客に提出する」はどちらも該当します。
>   一方、社内の目安として重さを量るだけなら該当しません。

（出典：計量法、計量法施行令／e-Gov法令検索）

| 条 | 内容 |
|---|---|
| 第8条 | **非法定計量単位の使用の禁止**。法定計量単位以外の単位は、取引・証明に用いてはならない（輸出貨物の取引等を除く） |
| 第16条 | **使用の制限**。検定証印等が付されていない特定計量器、または検定証印等の有効期間を経過したものを、取引・証明における計量に使用してはならない |
| 第19条 | **定期検査**。政令で定める特定計量器を取引・証明に使用する者は、都道府県知事（特定市町村の長）が行う定期検査を受けなければならない |
| 施行令第10条 | 定期検査の対象となる特定計量器は、**非自動はかり、分銅およびおもり**、皮革面積計 |
| 施行令第11条 | 定期検査の実施の期間は、非自動はかり・分銅・おもりについて**2年**（皮革面積計は1年） |

> **【Typical】製造業で関係する場面**
> 【Typical】製品を重量で売る（鋳物、樹脂ペレット、化学品）、
> 検査成績書に重量を記載して顧客に提出する、といった場合、
> 使用するはかりは検定を受けたもので、かつ定期検査を受けている必要があります。
> 【Varies】社内管理用のはかりのみを使う企業には適用されません。

## 15-8. 電気用品安全法（電気機器を作る場合）

【Fact】電気用品安全法（昭和36年法律第234号）では、電気用品の製造・輸入の事業を行う者は
事業開始の日から**30日以内**に経済産業大臣へ届け出る義務があり（第3条）、
届出事業者は、製造する電気用品が**特定電気用品**である場合、
販売する時までに登録を受けた者の**適合性検査**を受け、証明書の交付を受けて保存しなければなりません（第9条）
（出典：電気用品安全法／e-Gov法令検索）。

※ 詳細は `01_overview.md` 1-6 を参照。【Varies】電気用品を製造しない企業には適用されません。

## 15-9. 食品衛生法（食品製造の場合）

【Fact】2018年の食品衛生法改正により、原則としてすべての食品等事業者に、
一般衛生管理に加えて「**HACCPに沿った衛生管理**」の実施が求められるようになりました。
主要な施行日は2020年6月1日で、営業許可・届出制度に関する経過措置は2021年6月1日に終了しています。
あわせて、営業許可が必要な業種の見直しと、許可対象外の事業者を把握するための**営業届出制度**が創設されました。
小規模営業者は、厚生労働省が公表する手引書に沿った簡略化されたアプローチが可能です
（出典：食品衛生法の改正について／厚生労働省）。

※ 詳細は `01_overview.md` 1-6 を参照。【Varies】食品を製造しない企業には適用されません。

## 15-10. 取適法（中小受託取引適正化法／旧・下請代金支払遅延等防止法）

【Fact】2026年1月1日、従来の「下請代金支払遅延等防止法（下請法）」が改正・改称され、
正式名称「製造委託等に係る中小受託事業者に対する代金の支払の遅延等の防止に関する法律」、
通称「**中小受託取引適正化法（取適法）**」として施行されました
（出典：取適法／e-Gov法令検索、公正取引委員会）。

> **詳細（適用対象の資本金・従業員基準、委託事業者の4つの義務、11の禁止事項）は
> `02_industry-structure.md` 11-2 に記載しています。ここでは要点のみ再掲します。**

### 中小製造業が受注側として関わる要点【Fact】

| 論点 | 内容 |
|---|---|
| **発注内容の明示** | 委託事業者は、給付の内容・代金の額・支払期日・支払方法等を書面または電磁的方法で明示する義務がある |
| **支払期日** | 検査の有無を問わず、**物品等を受領した日から起算して60日以内**のできる限り短い期間内で定める義務がある |
| **遅延利息** | 支払遅延・減額があった場合、日数・金額に応じ**年率14.6％**の遅延利息を支払う義務がある |
| **手形払等の禁止**（2026年1月〜） | 支払手段として手形払等を用いることが「支払遅延」として禁止された |
| **協議に応じない一方的な代金決定の禁止**（2026年1月〜） | 価格協議の求めに応じない、必要な説明を行わないなど、一方的に代金を決めることが禁止された |
| **買いたたきの禁止** | 通常支払われる対価に比べ著しく低い代金を不当に定めることの禁止 |
| **有償支給原材料等の対価の早期決済の禁止** | 有償で支給した原材料等の代金を、製品代金の支払日より早く支払わせることの禁止 |
| **従業員基準の追加**（2026年1月〜） | 従来の資本金基準に加え、**従業員基準（300人／100人）**が追加され、対象が拡充された |
| **特定運送委託の追加**（2026年1月〜） | 製造等の目的物の引渡しに必要な運送の委託が対象取引に追加された |
| **取引記録の保存** | 委託事業者は取引完了後、給付内容・代金の額など取引の記録を作成し**2年間**保存する義務がある |

（出典：いずれも取適法／e-Gov法令検索、公正取引委員会）

## 15-11. 労働基準法

【Fact】製造業に特有というより、すべての事業者に共通する法律ですが、
中小製造業の人事・総務機能が日常的に関わるものとして主要な条文を挙げます（出典：e-Gov法令検索）。

| 条 | 内容 |
|---|---|
| 第24条 | **賃金の支払**。賃金は通貨で、直接労働者に、全額を支払わなければならない（一定の例外あり）。また**毎月1回以上、一定の期日を定めて**支払わなければならない |
| 第36条 | **時間外及び休日の労働**。法定労働時間を超えて労働させる場合、労働者の過半数で組織する労働組合（ない場合は労働者の過半数を代表する者）との**書面による協定**（いわゆる36協定）を締結し、行政官庁に届け出る必要がある |
| 第39条第7項 | **年次有給休暇の時季指定義務**。年10労働日以上の年次有給休暇が付与される労働者について、**基準日から1年以内に5日**、使用者が時季を定めて与えなければならない |
| 第89条 | **就業規則の作成及び届出の義務**。**常時10人以上**の労働者を使用する使用者は、就業規則を作成し行政官庁に届け出なければならない。変更した場合も同様 |
| 第109条 | **記録の保存**。労働者名簿、賃金台帳および雇入れ、解雇、災害補償、賃金その他労働関係に関する重要な書類を**5年間**保存しなければならない（※経過措置により当分の間3年間。出典：厚生労働省） |

> **【Typical】製造業で特に論点になりやすいこと**
> 【Typical】交替勤務（2交替・3交替）、深夜業、繁忙期の時間外労働、
> 変形労働時間制の採用などは、製造業でよく見られる論点です。
> 【Varies】どの制度を採用しているかは企業により大きく異なります。

## 15-12. 外国為替及び外国貿易法（外為法）— 輸出する場合【Varies】

【Fact】外為法第48条第1項により、国際的な平和および安全の維持を妨げることとなると認められるものとして
政令で定める特定の地域を仕向地とする特定の種類の貨物の輸出をしようとする者は、
政令で定めるところにより**経済産業大臣の許可**を受けなければなりません（出典：e-Gov法令検索）。

【Fact】同条第2項により、経済産業大臣は、その確実な実施を図るため必要があると認めるときは、
特定の種類の貨物をそれ以外の地域を仕向地として輸出しようとする者に対しても、許可を受ける義務を課すことができます（出典：e-Gov法令検索）。

> **用語：リスト規制／キャッチオール規制**
> → リスト規制＝政令（輸出貿易管理令 別表第1）に列挙された貨物・技術についての規制。
> → キャッチオール規制＝リストに載っていなくても、用途や需要者によっては許可が必要になる規制。
> → **なぜこの2段構えなのか**：軍事転用されうる品目をすべてリストに列挙することはできないためです。
> → 【Varies】具体的にどの品目が該当するかは、輸出貿易管理令および関係省令で定められます。
>   **工作機械・計測機器・特殊材料・炭素繊維などの部品が該当する場合があります。**
>   自社製品が該当するかの判定（該非判定）は、輸出する企業ごとに行われます。

> 【Inference】国内取引のみの中小製造業には直接には関係しませんが、
> **顧客が輸出する製品の部品を作っている場合**、顧客から該非判定書（非該当証明書）の提出を求められることがあります。

## 15-13. 許認可・資格の全体像

### (1) 事業を始める・続けるために必要な許認可【Varies】

> **【重要】製造業には、業界全体に共通する「製造業の許可」はありません。**
> 【Inference】建設業の建設業許可や、運送業の運送事業許可のような、業界横断の入口規制は存在しません。
> 必要になる許認可は、**何を作るか・何を扱うか**によって個別に決まります。

| 許認可・届出 | 必要になる場合 | 根拠 |
|---|---|---|
| 食品製造業の営業許可・営業届出 | 食品を製造する場合 | 食品衛生法【Fact】 |
| 電気用品製造事業の届出 | 電気用品を製造する場合（事業開始から30日以内） | 電気用品安全法第3条【Fact】 |
| 危険物製造所・貯蔵所・取扱所の設置許可 | 指定数量以上の危険物を扱う場合 | 消防法第10条・第11条【Fact】 |
| 毒物劇物取扱責任者の設置・届出 | 毒物・劇物の製造業・輸入業・販売業を営む場合 | 毒物及び劇物取締法第7条【Fact】 |
| 業務上取扱者の届出 | 政令で定める事業で、シアン化ナトリウム等を業務上取り扱う場合（30日以内） | 同法第22条【Fact】 |
| 医薬品・医療機器の製造業の登録・製造販売業の許可 | 医薬品・医療機器を製造する場合 | 医薬品医療機器等法【Varies】 |
| 特定施設の設置届出 | 政令で定める水質汚濁・大気汚染に関わる施設を設置する場合 | 水質汚濁防止法、大気汚染防止法【Varies】 |

### (2) 人に必要な資格・免許・技能講習

【Typical】製造業では、**人につく資格**が非常に多く登場します。整理すると3段階です。

| 段階 | 位置づけ | 例 |
|---|---|---|
| **免許**（国家資格） | もっとも重い。試験に合格して都道府県労働局長等が交付 | クレーン・デリック運転士、ボイラー技士、危険物取扱者、電気主任技術者、ガス溶接作業主任者 |
| **技能講習** | 登録教習機関の講習を修了。就業制限業務や作業主任者の要件になる | フォークリフト運転技能講習（1トン以上）、玉掛け技能講習（1トン以上）、有機溶剤作業主任者技能講習、特定化学物質及び四アルキル鉛等作業主任者技能講習、プレス機械作業主任者技能講習、乾燥設備作業主任者技能講習 |
| **特別教育** | 事業者が自ら（または外部に委託して）行う教育 | アーク溶接、研削といしの取替え、動力プレスの金型取付等、フォークリフト（1トン未満）、玉掛け（1トン未満）、産業用ロボットの教示等・検査等、低圧電気取扱 |

（根拠：労働安全衛生法第14条・第59条・第61条、労働安全衛生法施行令第6条・第20条、労働安全衛生規則第36条／出典：e-Gov法令検索）

【Typical】このほか、法令上の義務ではないが実務でよく取得されるものとして、
**技能検定**（機械加工、溶接、機械保全など／職業能力開発促進法に基づく国家検定）、
**溶接技能者評価試験**（一般社団法人日本溶接協会）、
**非破壊検査技術者資格**などがあります【Varies】。

> **【Typical】中小製造業での実態**
> 【Typical】1人が複数の資格を持ち、複数の作業を担当します（多能工。`06_people.md` 6-6）。
> 【Inference】人数が限られるため、「その資格を持っているのが1人だけ」という状態になりやすく、
> その人が不在だと特定の作業ができない、という構造が生まれます。

## 15-14. 品質・記録に関するルール

### (1) ISO 9001（品質マネジメントシステム）

> **用語：ISO 9001**
> → 品質マネジメントシステムに関する国際規格。**法律ではなく、任意の認証**です。
> → **なぜ取得されるのか**：顧客から取引の条件として求められることがあるためです。
>   また、社内の手順を文書化し、記録を残す仕組みそのものが顧客への説明材料になります。
> → 【Example】モデル企業 X金属工業も ISO 9001 を取得している設定です（`03_company-structure.md` 3-2）。

【Fact】ISO 9001 では、あらかじめ定めた間隔での**内部監査**（箇条9.2）と、
トップマネジメントによる**マネジメントレビュー**（箇条9.3）が要求されます。
また、**文書化した情報の保持**が要求されますが、保存期間は組織が決定します（箇条7.5）。

> **【重要】ISO 9001 は「良い製品を作ることを保証する規格」ではありません**
> 【Inference】規格が求めているのは、**決めたことを決めたとおりに行い、それを記録し、
> うまくいかなかったときに原因を調べて手を打つ仕組み**があることです。
> このため、ISO 9001 を取得していても不良は発生します。

### (2) IATF 16949（自動車産業向け）【Varies】

> **用語：IATF 16949**
> → 自動車産業に特化した品質マネジメントシステムの規格。ISO 9001 を土台に、
>   自動車産業固有の要求（工程能力、変更管理、トレーサビリティ等）を上乗せしたもの。
> → 【Typical】自動車メーカーおよびそのサプライチェーンに部品を供給する企業で求められることがあります。
> → 【Varies】自動車向けの取引がない中小製造業には関係しません。
> → 【Inference】ISO 9001 より要求が細かく、認証の維持に必要な社内の手間は大きくなります。

### (3) トレーサビリティ（追跡可能性）

> **用語：トレーサビリティ**
> → 「この製品は、いつ・どの材料で・どの設備で・誰が作ったか」を後から追える状態にしておくこと。
> → 実務例：ある顧客から「先月納入した部品に不具合があった」と連絡が来たとき、
>   **同じ材料ロット・同じ製造日の製品が、他にどこへ何個出荷されているか**をすぐに調べられる状態。
> → **なぜ必要なのか**：不具合が見つかったとき、**影響範囲を特定できなければ、
>   疑わしいものすべてを回収するしかなくなる**ためです。
> → 【Typical】これを支えるのが、ミルシート（材料証明書）、現品票、製造指示書、検査記録の突き合わせです
>   （`07_goods.md` 7-7、`10_documents.md`）。

### (4) 記録の保存期間【Fact】

| 記録 | 保存期間 | 根拠 |
|---|---|---|
| 取適法に基づく取引記録 | **2年間** | 取適法（委託事業者の義務）／公正取引委員会リーフレット |
| 帳簿および請求書等（消費税の仕入税額控除） | **7年間**（6年目・7年目はいずれか一方でよい） | 消費税法／国税庁 |
| 労働者名簿、賃金台帳等 | **5年間**（経過措置により当分の間3年間） | 労働基準法第109条 |
| 産業廃棄物管理票（マニフェスト）の写し | **5年間** | 廃棄物処理法第12条の3、同施行規則第8条の21の2・第8条の26 |
| フロン類の点検・整備の記録 | 冷媒の引渡し完了日から**3年** | 環境省フロン排出抑制法ポータルサイト |
| フロン類の引取証明書、回収依頼書・委託確認書の写し | **3年間** | 同上 |
| 品質記録（検査記録等） | 【Varies】**法令ではなく顧客との契約・ISO 9001 の要求により決まる** | ISO 9001 箇条7.5 |

> 【Typical】顧客から「製品の納入後○年間、検査記録を保存すること」と求められることがあります。
> 【Varies】期間は業種・顧客により大きく異なり、自動車・航空・医療機器などでは長期の保存が求められる場合があります。
> ※ `09_information.md` 9-5 の再掲・補足です。

## 15-15. 商習慣（法律ではないが、知らないと会話が通じないこと）

ここからは**法令ではなく、業界の慣行**です。企業・業種・顧客により異なります【Varies】。

### (1) 相見積（あいみつもり）

> **用語：相見積／あいみつ**
> → 顧客が複数社に同じ条件で見積を依頼し、価格・納期・技術力を比較すること。
> → 実務例：「今回はあいみつです」と言われたら、他社と比較されていることを意味します。
> → 【Typical】製造業では広く行われます。特に新規の品番、または金額の大きい案件で行われやすい【Varies】。
> → 【Inference】これが、受託加工型で粗利率が上がりにくい構造の一因になっています（`12_business-model.md` 12-5）。

### (2) 指値（さしね）

> **用語：指値**
> → 顧客側から「この値段で作ってほしい」と価格を提示されること。
> → 実務例：「前回780円だったが、今回は750円でお願いしたい」。
> → 【Typical】顧客が自社の販売価格やコスト目標から逆算して提示することが多い【Varies】。
> → 【Fact】**なお、取適法では「買いたたき」（通常支払われる対価に比べ著しく低い代金を不当に定めること）
>   および「協議に応じない一方的な代金決定」が委託事業者の禁止行為として定められています**
>   （出典：取適法／e-Gov法令検索、公正取引委員会）。

### (3) 元請・下請の多重構造

> 【Typical】製造業では、最終製品メーカー（完成品メーカー）を頂点に、
> Tier1（一次サプライヤー）→ Tier2（二次）→ Tier3（三次）という階層構造が形成されていることがあります
> （詳細は `02_industry-structure.md` 11-2）。
>
> **なぜこの構造ができるのか**
> 【Inference】1つの製品に必要な部品と工程が多岐にわたるため、
> すべてを1社で内製するより、専門の会社に分担させるほうが成立しやすいためです。
>
> **実務でどう効いてくるか**
> - 【Typical】**自分の顧客が誰の下請なのか**によって、要求される品質基準・記録・納期の厳しさが変わります。
> - 【Typical】最終製品メーカーの減産は、階層を下るほど遅れて、しかし増幅されて伝わることがあります。
> - 【Typical】Tier1経由で「最終メーカーの監査基準」が下位に適用されることがあります。

### (4) 支給材（有償支給・無償支給）

> 【Typical】顧客が材料を渡してくる取引です。詳細は `02_industry-structure.md` 11-3、`07_goods.md` 7-5。
>
> | | **無償支給** | **有償支給** |
> |---|---|---|
> | 材料の所有権 | 顧客のまま | **自社に移る**（仕入になる） |
> | 自社の売上 | 加工賃のみ | 材料費込みの金額 |
> | 在庫としての扱い | 自社の在庫にならない（**預かり品**） | 自社の在庫になる |
> | 材料をロスしたら | **顧客の材料を損なったことになる** | 自社の損失 |
>
> 【Fact】有償支給の場合、取適法により「**有償支給原材料等の対価の早期決済**」（有償で支給した原材料等の代金を、
> 製品代金の支払日より早く支払わせること）が禁止行為として定められています
> （出典：取適法／e-Gov法令検索、公正取引委員会）。

### (5) 型（金型）の所有権

> 【Typical】型費を顧客が支払った場合、**型の所有権は顧客に帰属し、自社は預かって使用する**という扱いが一般的です。
>
> **実務でどう効いてくるか**【Typical】
> - 取引が終了すれば、型を顧客に返却することになります。
> - 顧客の指示で型を保管し続ける場合があり、保管スペースと維持（錆止め・メンテナンス）が発生します。
> - 型を他社の製品に転用することはできません。
> - 【Varies】保管費用の負担、廃棄の判断、修理費の負担については、契約や覚書で定めることがあります。

### (6) 締め支払い（締め日と支払サイト）

> 【Typical】企業間取引では、納品のたびに支払うのではなく、
> **一定の締め日で1か月分をまとめ、その後の決まった日に支払う**のが一般的です。
> 「月末締め翌月末払い」「20日締め翌月20日払い」など【Varies】。
> **詳細は `08_money.md` 8-4 を参照してください。**
>
> 【Fact】取適法では、検査の有無を問わず**物品等を受領した日から起算して60日以内**の
> できる限り短い期間内で支払期日を定めることが委託事業者の義務とされています
> （出典：取適法／e-Gov法令検索、公正取引委員会）。

### (7) 年間単価契約

> 【Typical】1年間の予定数量を前提に単価をあらかじめ決めておき、実際の注文はその都度出す契約です。
> 繰返生産の顧客でよく用いられます。
>
> **実務でどう効いてくるか**【Inference】
> - 期中に材料が値上がりしても、単価は据え置かれるため、**材料相場の変動リスクを受注側が負う**形になります。
> - このため、価格改定の交渉が年次の業務として発生します（`13_periodic-work.md` 13-8）。
> - 【Typical】原材料費・エネルギー費・労務費の上昇分について、価格転嫁の協議が行われます。

### (8) VA／VE提案

> **用語：VA（Value Analysis／価値分析）／VE（Value Engineering／価値工学）**
> → 製品の機能を保ったまま、材料・形状・工程を見直してコストを下げる提案のこと。
>   VEは設計段階、VAは生産段階で行うもの、という使い分けがされることがあります【Varies】。
> → 実務例：「この部品、板厚を2.3mmから2.0mmに変えても強度は足りるので、材料費を下げられます」と
>   加工側から顧客へ提案する。
> → 【Typical】顧客から定期的にVA/VE提案を求められることがあります。
> → **なぜ求められるのか**：顧客は製品の原価を下げたいが、実際に作っている側のほうが
>   工程と材料の実態を知っているためです。
> → 【Inference】提案が採用されると単価は下がりますが、採用によって自社の工数も減る場合、
>   受注量の維持や次の案件の受注につながることがあります。この効果の配分は取引ごとに異なります【Varies】。

### (9) 内示（ないじ）

> **用語：内示**
> → 顧客から「来月はこれくらい注文する見込みです」と事前に知らされる**予定の数量**のこと。
>   正式な注文書（確定注文）とは別物です。
> → 実務例：「AB-2041 は6月1,000個、7月1,200個、8月900個の見込み」という3か月分の内示をもらい、
>   確定注文は毎月届く。
> → **なぜ内示があるのか**：材料の調達に1週間、外注の往復に1週間かかる場合、
>   確定注文を受けてから動いたのでは納期に間に合わないためです。
>   受注側が**先に材料を手配できるように**、見込みが共有されます。

> **【最重要】内示は確定注文ではありません**
> 【Typical】内示に基づいて材料を手配したが、実際の確定注文が内示より少なかった場合、
> 余った材料は自社の在庫として残ります。
> 【Varies】内示と確定注文の差をどう扱うか（材料費の補償があるか、どの範囲まで保証されるか）は、
> 顧客との取り決めによって異なります。取り決めがない場合、受注側が在庫リスクを負う形になります。
> 【Inference】このため、内示をどこまで信じて先行手配するかは、中小製造業の生産管理機能にとって
> 判断が難しい論点の一つです。

### (10) 季節性・年度末の駆け込み需要

| 時期 | 【Typical】製造業で見られること | 【Inference】なぜか |
|---|---|---|
| **年度末（1〜3月）** | 受注が増えることがある | 顧客側の予算執行、設備投資の期末計上、決算に向けた売上確保などの事情があるため【Varies】 |
| **年度初め（4〜5月）** | その反動で受注が落ちることがある | 前年度に前倒しされた分が抜けるため【Varies】 |
| **大型連休・夏季休暇・年末年始** | 稼働日数が減り、その前後に納期が集中する | 顧客も休むため、休み明けに必要な品物を休み前に納めることになるため |
| **顧客の棚卸時期** | 顧客が受入を制限することがある | 顧客側が在庫を数えるため、一時的に入庫を止めることがある【Varies】 |

> 【Varies】季節性の有無と大きさは業種によってまったく異なります。
> 【Typical】食品製造では、歳暮・中元・行楽シーズン・気温による需要変動が明確に現れます。
> 【Typical】印刷では、年度末の予算執行や、入学・入社シーズンに関わる印刷物の需要が集中することがあります。
> 【Varies】産業機械向けの金属加工では、顧客の設備投資サイクルの影響のほうが大きく、
> 暦の季節性は相対的に小さい場合があります。

### (11) その他、現場で交わされる約束事【Typical】

| 慣行 | 内容 |
|---|---|
| **注文請書（ちゅうもんうけしょ）の返送** | 注文書を受け取ったら、内容を確認して請書を返す。数量・単価・納期・仕様の認識を合わせるため |
| **納入指定・指定日納入** | 顧客が納入日時・納入場所（何番ゲート、何時まで）を細かく指定する。顧客側の受入体制と生産ラインの都合による |
| **通い箱（かよいばこ）** | 製品を入れる専用の箱を顧客と自社の間で繰り返し使う。梱包材の削減と、製品の保護のため。空箱の返却も物流の一部になる |
| **検収後の請求** | 顧客が受け入れ（検収）を済ませて初めて請求できる。検収のタイミングが月をまたぐと、その月の売上に立たない（`08_money.md` 8-1） |
| **年1回の工場監査** | 顧客が自社の工程・記録・管理状態を確認しに来る【Varies】 |
| **不具合発生時の報告書提出** | 顧客の様式（8D、なぜなぜ分析シート等）で原因と対策を報告する【Varies】 |

## 15-16. 業種によって適用される法規制はどう変わるか【Varies】

| 業種 | 【Fact／Varies】特に関わりの深い法規制 |
|---|---|
| **食品製造** | 食品衛生法（営業許可・届出、HACCPに沿った衛生管理）、食品表示法、計量法（内容量の表示）、労働安全衛生法 |
| **金属加工** | 労働安全衛生法（プレス・クレーン・玉掛け・研削といし・アーク溶接）、消防法（塗料・切削油）、廃棄物処理法（金属くず・廃油）、水質汚濁防止法（洗浄排水を出す場合）【Varies】 |
| **機械製造** | 製造物責任法（PL法）、労働安全衛生法、機械の安全に関する規格【Varies】、外為法（輸出する場合） |
| **電気機器** | 電気用品安全法（PSEマーク）、電波法【Varies】、製造物責任法、RoHS等の含有化学物質規制【Varies】 |
| **化学・プラスチック** | 消防法（危険物）、化審法、化管法（PRTR）、毒物及び劇物取締法、高圧ガス保安法【Varies】、大気汚染防止法・水質汚濁防止法、労働安全衛生法（有機溶剤・特定化学物質） |
| **印刷** | 労働安全衛生法（有機溶剤・特定化学物質）、消防法（インキ・溶剤）、**著作権法**（他者の著作物を扱うため）、廃棄物処理法（廃インキ・古紙） |

> 【Inference】この表から読み取れるのは、**「作るもの」より「扱う物質と設備」が適用法令を決める**ということです。
> 金属加工の会社でも、塗装を内製すれば有機溶剤の規制がかかり、
> めっきを内製すれば排水規制と毒劇法がかかります。
> **外注に出すか内製するかは、設備投資だけでなく、法令対応の範囲も変える判断になります。**

## 15-17. このファイルのまとめ

1. **製造業に共通する「製造業の許可」は存在しない。** 必要な許認可は、
   何を作り、何を扱い、どんな設備を持つかによって1社ごとに決まる。
2. **製造物責任法（PL法）**は、製造物の欠陥による損害について過失がなくても賠償責任を負わせる法律。
   部品メーカーには、顧客の設計指示に従ったことによる欠陥についての免責規定がある（第4条第2号）。
   期間制限は「知った時から3年（生命・身体は5年）／引渡しから10年」。
3. **労働安全衛生法**は中小製造業に最も広く関わる。
   従業員数（10人／50人／300人）で管理体制の義務が変わり、
   危険な機械の操作には免許・技能講習・特別教育が段階的に必要になる。
4. **消防法**は危険物の量（指定数量）で規制がかかる。複数の危険物は「商の和」で合算して判定される。
5. **化学物質の規制は目的ごとに別の法律**がかかる。
   働く人を守るのが安衛法、環境を守るのが化審法、火災を防ぐのが消防法。
   **化審法の届出義務は「製造・輸入する者」にかかり、「使うだけ」の企業には生じない。**
6. **廃棄物処理法**では、マニフェストの交付、写しの**5年間保存**、
   **毎年6月30日まで**の交付等状況報告書の提出が定められている。
7. **フロン排出抑制法**は、業務用エアコンを持つ工場に広く関わる。
   **3か月に1回以上の簡易点検**と、7.5kW以上の機器の定期点検が義務。
8. **計量法**は「取引または証明」に使うはかりが対象。**2年に1回の定期検査**がある。
9. **取適法（旧・下請法）**が製造業の取引価格と支払条件を規律している。
   2026年1月の改正で、従業員基準の追加、手形払等の禁止、一方的な代金決定の禁止が加わった。
10. **商習慣で最も誤解されやすいのが「内示」**である。内示は予定であって確定注文ではなく、
    内示に基づく先行手配のリスクをどちらが負うかは取り決めによって異なる。
11. **型の所有権は代金を払った側にある**のが一般的で、受注側は預かって使用する立場になる。
