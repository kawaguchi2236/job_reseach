# 14_kpi.md — KPI・数字（現場と経営が見ている指標）

**対象**：日本国内の中小製造業
**前提**：`08_money.md`（カネの流れ）、`12_business-model.md`（収益構造）を読んでいること
**最終更新**：2026-09-16

> **このファイルで扱うもの・扱わないもの**
> 扱うのは、中小製造業の現場と経営が**日常的に見ている業務・経営の数字**です。
> 各指標について「**名称／意味／計算方法／誰が見るか／なぜ重要か**」を初心者向けに説明します。
>
> **数値の目安について**：本ファイルでは、公的統計等で確認できない「望ましい水準」は書きません。
> 業種・規模・生産形態によって適正水準はまったく異なるため、`【Varies】` としています。
> 【Example】の数値は `03_company-structure.md` の架空モデル企業に基づく説明用の数字です。

---

## 14-1. まず全体像：数字は4つの層に分かれている

| 層 | 何を測っているか | 主に見る人 | 代表的な指標 |
|---|---|---|---|
| **① お金の層** | 会社としていくら稼ぎ、いくら残ったか | 社長、経理・財務 | 売上高、粗利率、営業利益率、労働分配率 |
| **② 仕事の量の層** | どれだけ仕事があり、これからどうなるか | 社長、営業、生産管理 | 受注高、受注残、売上見込 |
| **③ 現場の層** | 設備と人がどう動き、品質はどうか | 工場長、製造、品質保証、生産技術 | 稼働率、可動率、直行率、不良率、歩留まり、段取り時間、OEE |
| **④ 時間と在庫の層** | 納期は守れているか、モノとお金がどこで止まっているか | 生産管理、経理・財務 | リードタイム、納期遵守率、在庫回転率、売掛回転日数、資金繰り |

> **なぜ層に分けて考えるのか**
> 【Inference】製造業の数字は互いにつながっています。
> 段取り時間が長ければ → 可動率が下がり → 生産できる量が減り → 納期遵守率が下がり → 顧客の信頼が落ちる。
> 不良が出れば → 歩留まりが下がり → 材料費が増え → 粗利率が下がる。
> **1つの数字だけを見ても原因は分かりません。** どの層の話をしているかを区別することが出発点になります。

## 14-2. ① お金の層

### (1) 売上高

| 項目 | 内容 |
|---|---|
| **意味** | 顧客に請求した金額の合計。「どれだけ売れたか」を表す最も基本的な数字 |
| **計算方法** | 単価 × 数量 の合計（期間で集計）。**納品・検収された分だけ**が売上になる（`08_money.md` 8-1） |
| **誰が見るか** | 社長、営業機能、経理・財務機能 |
| **なぜ重要か** | 会社の規模と、仕事がどれだけ入っているかを示す最も分かりやすい数字だから |
| **【重要】注意点** | **売上高の大きさだけでは、稼ぐ力は測れません。** 材料費込みで請求すれば売上は大きくなり、加工賃だけなら小さくなりますが、自社の儲けはほとんど変わりません（`12_business-model.md` 12-3）。このため、必ず粗利額・加工高と併せて見ます |

【Example】モデル企業 X金属工業の年商は約8億円（架空の設定）。

### (2) 売上総利益（粗利）／粗利率

| 項目 | 内容 |
|---|---|
| **意味** | 「モノを作って売った段階での儲け」。売上から、作るためにかかった費用（売上原価）を引いたもの |
| **計算方法** | `粗利額 ＝ 売上高 − 売上原価`　／　`粗利率（％） ＝ 粗利額 ÷ 売上高 × 100` |
| **誰が見るか** | 社長、経理・財務機能、営業機能（案件ごとの粗利） |
| **なぜ重要か** | ここが薄いと、どれだけ売っても会社にお金は残らないから。**材料費の値上がり・不良の発生・単価の値下げは、すべてここに現れます** |
| **目安** | 【Varies】業種・生産形態により大きく異なる。加工賃商売か材料費込みかでも変わる |

【Example】モデル企業では粗利率20％（粗利額160,000千円）。`08_money.md` 8-8 の架空の数値。

> **【重要】粗利は「全社の平均」で見ても実態が分かりません**
> 【Inference】全社粗利率20％の内訳は、粗利35％の仕事と粗利5％の仕事の混ざり物です。
> どの仕事が利益を生み、どの仕事が薄いかは、**受注ごと（品番ごと）の粗利**を見なければ分かりません。

### (3) 営業利益／営業利益率

| 項目 | 内容 |
|---|---|
| **意味** | 「本業での儲け」。粗利から、営業・経理・総務などの費用（販管費）を引いたもの |
| **計算方法** | `営業利益 ＝ 粗利額 − 販売費及び一般管理費`　／　`営業利益率（％） ＝ 営業利益 ÷ 売上高 × 100` |
| **誰が見るか** | 社長、経理・財務機能、金融機関 |
| **なぜ重要か** | 会社が事業として成り立っているかを示す数字だから。借入の審査でも重視される |
| **目安** | 【Varies】 |

【Example】モデル企業の営業利益率は4％（32,000千円）。

### (4) 労働分配率

| 項目 | 内容 |
|---|---|
| **意味** | 会社が生み出した付加価値のうち、どれだけを人件費として分配しているかの割合 |
| **計算方法** | `労働分配率（％） ＝ 人件費 ÷ 付加価値額 × 100`　※人件費には給与・賞与・法定福利費（社会保険料の会社負担分）を含む |
| **誰が見るか** | 社長、経理・財務機能、人事・総務機能 |
| **なぜ重要か** | 賃上げ・賞与の判断材料になるから。**この比率が高すぎれば利益が残らず、低すぎれば人が定着しにくい**という関係にある |
| **目安** | 【Varies】業種・規模により大きく異なる。付加価値額の定義も複数あるため、他社と比べるときは定義を揃える必要がある |

> **用語：付加価値額（ふかかちがく）**
> → 会社が外部から買ってきたもの（材料・外注・電力など）に、自社が**新たに付け加えた価値**の金額。
> → 計算の考え方（控除法）：`付加価値額 ＝ 売上高 − 外部購入価値（材料費・外注費・購入部品費 等）`
> → 実務例：売上8億円、材料費2.4億円、外注費1.2億円 → 付加価値額 約4.4億円【Example】。
> → 【Varies】付加価値額の計算方法には複数の方式があり（控除法・加算法）、統計や指標により定義が異なります。

### (5) 1人当たり付加価値（労働生産性）

| 項目 | 内容 |
|---|---|
| **意味** | 従業員1人が1年間にどれだけの付加価値を生み出したか |
| **計算方法** | `1人当たり付加価値 ＝ 付加価値額 ÷ 従業員数` |
| **誰が見るか** | 社長、経理・財務機能 |
| **なぜ重要か** | 人を増やしたときに会社が本当に強くなったかを測るため。**売上が伸びても人数が同じ割合で増えていれば、1人当たりは変わっていません** |
| **目安** | 【Varies】。【Fact】製造業全体の中小企業と大企業では労働生産性に差があることが中小企業白書等で示されているが、業種・規模により大きく異なるため、単純比較はできない |

【Example】モデル企業：付加価値額約4.4億円 ÷ 45名 ＝ **1人当たり約978万円**（架空の計算）。

> **用語：労働生産性**
> → 「投入した労働に対して、どれだけの成果が出たか」を表す考え方の総称。
> → 製造業では次の2種類が使い分けられます。
>   - **物的労働生産性**：`生産量 ÷ 労働時間`（何個作れたか）
>   - **付加価値労働生産性**：`付加価値額 ÷ 従業員数（または労働時間）`（いくら稼いだか）
> → **なぜ2つあるのか**：たくさん作れても、単価の安い仕事ばかりなら会社は稼げません。
>   逆に、生産個数は少なくても高付加価値な仕事なら会社は稼げます。両方を見る必要があります。

## 14-3. ② 仕事の量の層

### (6) 受注高

| 項目 | 内容 |
|---|---|
| **意味** | その期間に**新しく受けた注文の金額**の合計 |
| **計算方法** | 期間中に受注登録した注文金額の合計 |
| **誰が見るか** | 社長、営業機能、生産管理機能 |
| **なぜ重要か** | 売上は「過去に受けた注文の結果」であるのに対し、受注高は**これから先の売上の材料**だから。受注高が落ち始めれば、数か月後に売上が落ちる |

### (7) 受注残（じゅちゅうざん）

| 項目 | 内容 |
|---|---|
| **意味** | **注文はもらったが、まだ納品していない金額**の合計。「これから作らなければならない仕事の量」 |
| **計算方法** | `受注残 ＝ 前期末の受注残 ＋ 当期の受注高 − 当期の売上高` |
| **誰が見るか** | 社長、営業機能、生産管理機能、工場長 |
| **なぜ重要か** | **この先の工場の忙しさが分かるから。** 受注残が積み上がれば残業・外注が必要になり、減れば手が空く。金融機関に事業の見通しを説明するときにも使われる |
| **目安** | 【Varies】。何か月分の受注残を持つかは、生産形態（受注生産か見込生産か）とリードタイムによりまったく異なる |

> **【重要】受注残は売上ではありません**
> 【Example】受注残が1億円あっても、それは「将来の売上の予定」であって、
> まだ1円も売上に計上されておらず、1円も入金されていません。
> 受注をもらった時点では、むしろ**材料を買うためにお金が出ていく側**です（`12_business-model.md` 12-7）。

### (8) 売上見込（フォーキャスト）

| 項目 | 内容 |
|---|---|
| **意味** | 受注残に、これから受注できそうな案件の見込みを加えた、今後数か月の売上の予測 |
| **計算方法** | 【Varies】確定受注分＋引合い中の案件×受注確度、など企業により異なる |
| **誰が見るか** | 社長、営業機能、生産管理機能、経理・財務機能 |
| **なぜ重要か** | 人員・外注・材料の手配、資金繰りの計画の前提になるから |

## 14-4. ③ 現場の層

### 【最重要】(9) 稼働率と (10) 可動率の違い

**ここは初心者が必ず混乱する部分です。読み方も、測っているものも、目指す方向もまったく違います。**

まず結論を表にします。

| | **稼働率（かどうりつ）** | **可動率（べきどうりつ）** |
|---|---|---|
| **読み方** | かどうりつ | **べきどうりつ**（「かどうりつ」と読むと区別がつかないため、現場ではこう読み分ける）【Typical】 |
| **一言でいうと** | **仕事がどれだけ入っているか** | **動かしたいときに、設備がちゃんと動いてくれたか** |
| **何に左右されるか** | **受注量**（＝外の事情） | **設備の状態・段取り・材料待ち**（＝中の事情） |
| **100％が目標か** | **いいえ。** 100％は「これ以上受注できない」状態でもある | **はい。** 100％＝止まらずに動いた、が理想 |
| **下がったときの意味** | 仕事が減った／能力が余っている | 故障・段取り・材料待ちで設備が止まった |
| **主に見る人** | 社長、営業機能、生産管理機能 | 工場長、製造機能、設備保全機能 |

#### (9) 稼働率（かどうりつ）

| 項目 | 内容 |
|---|---|
| **意味** | 持っている生産能力のうち、**どれだけを実際に使ったか**の割合。「仕事の入り具合」を表す |
| **計算方法**【Varies】 | `稼働率（％） ＝ 実際の生産量（または実稼働時間） ÷ 生産能力（または操業可能時間） × 100` |
| **統計上の定義** | 【Fact】経済産業省の鉱工業指数では「**稼働率指数**＝製造工業の設備の稼働状況を表すために、生産と生産能力の比から求めた指数」と定義されている（出典：経済産業省「経済産業統計まる分かり／用語の解説」）。また生産能力は「操業日数や設備、労働力に一定の基準を設け、これらの条件が標準的な状態で生産可能な最大生産量」と定義されている（同上） |
| **誰が見るか** | 社長、営業機能、生産管理機能 |
| **なぜ重要か** | 設備という**固定費**を抱えている以上、使われていない設備の費用も毎月発生するから（`12_business-model.md` 12-4）。稼働率が下がれば、1個あたりに配賦される間接費が増え、原価が上がる |
| **目安** | 【Varies】 |

【Example】レーザー加工機の月間操業可能時間が160時間で、実際に加工していた時間が112時間なら、
稼働率は `112 ÷ 160 × 100 ＝ 70％`（架空の計算）。

> **稼働率100％が必ずしも良い状態ではない理由**
> 【Inference】すべての設備が常にふさがっていると、急な注文・短納期の依頼・トラブルによるやり直しを
> 受け入れる余地がなくなります。1件の遅れが他のすべての注文に波及します。
> このため、稼働率は「高ければ高いほど良い」という単純な指標ではありません。

#### (10) 可動率（べきどうりつ）

| 項目 | 内容 |
|---|---|
| **意味** | **動かそうとしたときに、設備が実際に動いた割合。** 故障・段取り・材料待ち・不良による停止をどれだけ減らせたかを表す |
| **計算方法**【Varies】 | `可動率（％） ＝ 実際に動いた時間 ÷ 動かそうとした時間 × 100`　（動かそうとした時間＝生産に充てる予定だった時間） |
| **誰が見るか** | 工場長、製造機能、設備保全機能 |
| **なぜ重要か** | **仕事が入っているのに設備が動いていない時間**を可視化するため。ここには、故障・段取り替え・材料待ち・図面待ち・作業者不在・不良発生による停止が含まれる |
| **目安** | 【Typical】100％を目指す指標として扱われる。実際の水準は【Varies】 |

【Example】ある日、マシニングセンタを8時間動かす計画だったが、
朝の段取りに50分、刃物折損の復旧に30分、材料待ちで20分止まり、実際に加工していたのは6時間20分だった場合、
可動率は `380分 ÷ 480分 × 100 ＝ 約79％`（架空の計算）。

> **2つの指標の関係を1つの場面で見る**
> 【Example】ある月、仕事が少なく、レーザー加工機は160時間のうち80時間しか使う予定がなかった（＝稼働率は低い）。
> しかしその80時間の中で、段取りと材料待ちで16時間止まり、実際に切っていたのは64時間だった（＝可動率80％）。
> **稼働率が低いのは営業・受注の問題、可動率が低いのは現場・段取り・保全の問題です。**
> この2つを分けずに「稼働率が低い」と言ってしまうと、**誰が何を見ればよいのかが分からなくなります。**
> これが、現場でわざわざ「べきどうりつ」と読み分ける理由です【Typical】。

> **参考**：稼働率と可動率を生産性診断の指標として区別して論じた研究として、
> 安田正義「可動率と稼働率による生産性の診断―継続性と即時性のためのIoT活用―」
> 『日本経営診断学会論集』23巻（2023年）がある（出典：J-STAGE）。

### (11) 設備総合効率（OEE）

| 項目 | 内容 |
|---|---|
| **正式名称** | 設備総合効率（Overall Equipment Effectiveness／Efficiency、OEE） |
| **意味** | 設備が「**止まらず・遅れず・不良を出さず**」に動いた度合いを、1つの数字にまとめたもの |
| **計算方法**【Typical】 | `OEE ＝ 時間稼働率 × 性能稼働率 × 良品率`　（3つを掛け算する） |
| **誰が見るか** | 工場長、製造機能、設備保全機能、生産技術機能 |
| **なぜ重要か** | 設備が生む損失は**止まる・遅い・不良**の3種類あり、どれか1つだけを見ても実態がつかめないから |
| **目安** | 【Varies】 |

3つの要素の意味：

| 要素 | 何を測るか | 計算の考え方 | 【Example】ロスの例 |
|---|---|---|---|
| **時間稼働率** | **止まらなかったか** | `実稼働時間 ÷ 負荷時間` | 故障停止、段取り替え、刃物交換 |
| **性能稼働率** | **本来の速さで動いたか** | `（基準サイクルタイム × 生産数） ÷ 実稼働時間` | 空転・チョコ停（短時間の停止）、速度低下 |
| **良品率** | **良品を作れたか** | `良品数 ÷ 生産数` | 不良品、手直し品、立上げ時の捨て打ち |

> **【Example】3つとも90％なら、OEEは？**
> `0.9 × 0.9 × 0.9 ＝ 0.729` → **約73％**。
> 【Inference】一つ一つは「90％できている」ように見えても、掛け算になるため全体では約7割にしかなりません。
> これがOEEを1つの数字にまとめる意味です。

> **⚠️ OEEと「可動率」の関係**
> 【Varies】企業・文献によって、OEEの構成要素の呼び方や、可動率をどこに位置づけるかは異なります。
> 「時間稼働率」を可動率と呼ぶ場合もあります。
> **社内で数字を比べるときは、まず計算式の定義を揃えることが前提になります。**

### (12) 直行率（ちょっこうりつ）

| 項目 | 内容 |
|---|---|
| **意味** | 投入したもののうち、**一度も手直し・やり直しをせずに、そのまま良品として完成した割合** |
| **計算方法** | `直行率（％） ＝ 手直しなしで良品になった数 ÷ 投入数 × 100` |
| **誰が見るか** | 品質保証機能、製造機能、工場長、生産技術機能 |
| **なぜ重要か** | 手直しをすれば最終的な良品数は同じでも、**その分だけ人と設備の時間を余計に使っています**。その時間は原価に乗るのに、顧客に請求できません |
| **目安** | 【Varies】 |

【Example】1,000個投入し、そのまま良品になったのが920個、手直しして良品にしたのが60個、廃棄が20個の場合。
- 直行率 ＝ `920 ÷ 1,000 × 100 ＝ 92％`
- 良品率（最終） ＝ `(920 + 60) ÷ 1,000 × 100 ＝ 98％`

> **【重要】直行率と良品率の差が「見えない損失」です**
> 【Example】上の例では、最終的な良品率は98％で「ほとんど問題なし」に見えます。
> しかし実際には60個分の手直し作業が発生しており、その工数は原価に乗っています。
> **良品率だけを見ていると、この60個分の手間が数字に表れません。**

### (13) 不良率

| 項目 | 内容 |
|---|---|
| **意味** | 作ったもののうち、規格を満たさなかったものの割合 |
| **計算方法** | `不良率（％） ＝ 不良数 ÷ 生産数 × 100`（ppm＝100万分のいくつ、で表すこともある） |
| **誰が見るか** | 品質保証機能、製造機能、顧客（報告を求められることがある） |
| **なぜ重要か** | 不良が出れば、材料も加工時間も無駄になり、納期も遅れるから。**顧客に流出した不良は、信頼と次の受注に直結します** |
| **目安** | 【Varies】。顧客から目標値を提示されることがある【Typical】 |

【Typical】不良は発生場所によって呼び分けられます。

| 種類 | 意味 | なぜ区別するか |
|---|---|---|
| **工程内不良** | 自社の工程内で発見した不良 | 社内で止められた。損失は自社の材料費・工数 |
| **流出不良（客先不良）** | 顧客に納入した後に発見された不良 | **顧客の生産を止める可能性がある。** 原因調査報告書の提出・選別作業・代替品の緊急対応が発生する |

### (14) 歩留まり（ぶどまり）

| 項目 | 内容 |
|---|---|
| **意味** | 投入した材料のうち、**製品になった割合**。「材料をどれだけ有効に使えたか」 |
| **計算方法** | `歩留まり（％） ＝ 製品になった量 ÷ 投入した材料の量 × 100` |
| **誰が見るか** | 生産技術機能、製造機能、調達機能、経理・財務機能（原価） |
| **なぜ重要か** | **材料費は中小製造業の原価の最大項目の一つ**だから（`08_money.md` 8-3）。歩留まりが数％変わるだけで粗利が動く |
| **目安** | 【Varies】。板取りの形状、材料の規格寸法、業種によりまったく異なる |

【Example】1,220×2,440mmの鋼板から部品を切り出し、板の面積の85％が製品になり、15％が端材になった場合、歩留まりは85％。
`04_end-to-end-process.md` の見積では、この歩留まり0.85を使って必要材料量を計算しています。

> **【重要】歩留まりと直行率は違います**
> - **歩留まり** ＝ **材料**の話。「1枚の板から何個取れたか」
> - **直行率** ＝ **工程**の話。「作ったもののうち、手直しなしで通ったのはどれだけか」
>
> 【Example】板取りが上手で歩留まりは95％だが、溶接の手直しが多くて直行率は80％、という状態はあり得ます。
> **材料の使い方が上手なことと、工程がうまく流れることは別の問題です。**

### (15) 段取り時間

| 項目 | 内容 |
|---|---|
| **意味** | ある製品の加工を始める前に、機械の準備（金型交換、刃物交換、プログラム呼出、試し加工）にかかる時間 |
| **計算方法** | 段取り開始から、良品が連続して出始めるまでの時間 |
| **誰が見るか** | 生産技術機能、製造機能、工場長、生産管理機能 |
| **なぜ重要か** | **段取り中は製品が1個もできていないのに、人と設備の費用は発生している**から。かつ、段取り費は数量に関係なく1回分かかるため、小ロットになるほど1個あたりの原価を押し上げる（`12_business-model.md` 12-3） |
| **目安** | 【Varies】。設備・製品・段取りの複雑さにより大きく異なる |

> **用語：内段取り／外段取り**
> → 内段取り＝**機械を止めなければできない**準備（金型の取り付けなど）。
>   外段取り＝**機械を動かしたままできる**準備（次に使う金型を手元に運んでおく、など）。
> → **なぜこの区別があるのか**：機械が止まっている時間は生産ができない時間だからです。
>   同じ準備でも、機械を止めずにできる部分と、止めなければできない部分を分けて考えます。

### (16) 生産数量・生産高

| 項目 | 内容 |
|---|---|
| **意味** | 期間中に完成した製品の数量、またはその金額換算 |
| **計算方法** | 完成報告のあった数量の合計 |
| **誰が見るか** | 工場長、製造機能、生産管理機能 |
| **なぜ重要か** | 計画どおりに作れているかの確認。計画に対する達成率（`生産実績 ÷ 生産計画`）として見ることが多い【Typical】 |

## 14-5. ④ 時間と在庫の層

### (17) リードタイム

| 項目 | 内容 |
|---|---|
| **意味** | ある工程の始まりから終わりまでにかかる期間。文脈によって指す範囲が違うため、**どのリードタイムの話かを必ず確認する必要があります** |
| **誰が見るか** | 生産管理機能、営業機能、調達機能 |
| **なぜ重要か** | 顧客への納期回答の根拠になるから。また、リードタイムが長いほど、その間ずっと材料費と人件費を立て替えることになる（`12_business-model.md` 12-7） |
| **目安** | 【Varies】。業種による差が極めて大きい（`01_overview.md` 1-6 Level 2 参照） |

【Typical】主なリードタイムの種類：

| 種類 | 何から何まで | 【Example】モデル企業の案件では |
|---|---|---|
| **受注〜納品リードタイム** | 注文をもらってから納品するまで | 4月20日受注 → 5月26日納品 ＝ **36日** |
| **製造リードタイム** | 製造着手から完成まで | 5月7日着手 → 5月25日完了 ＝ **19日** |
| **正味加工時間** | 実際に加工していた時間の合計 | **約7.5日分**（残りは待ち時間・外注往復） |
| **調達リードタイム** | 材料を発注してから入荷するまで | 4月22日発注 → 5月1日入荷 ＝ **約7日** |
| **外注リードタイム** | 外注に出してから戻るまで | めっき：**往復7日** |

※ `04_end-to-end-process.md` 4-4 の架空の案件例に基づく【Example】。

> **【重要】リードタイムの大半は「待ち時間」です**
> 【Example】上の例では、受注から納品まで36日かかるのに、実際に加工している時間は7.5日分しかありません。
> 残りは、材料が届くのを待つ時間、外注先での往復、前工程が終わるのを待つ時間です。
> **受託加工ではこれが一般的な姿です**【Typical】。

### (18) 納期遵守率（オンタイム納入率）

| 項目 | 内容 |
|---|---|
| **意味** | 約束した納期どおりに納品できた割合 |
| **計算方法** | `納期遵守率（％） ＝ 納期どおりに納入できた件数 ÷ 総納入件数 × 100` |
| **誰が見るか** | 生産管理機能、営業機能、社長、**顧客** |
| **なぜ重要か** | **顧客が取引先を評価する最重要項目の一つ**だから。製造業では、自社の納品遅れが顧客の生産ラインを止めることがあり、影響が自社の損失にとどまらない |
| **目安** | 【Varies】。顧客から目標値を提示されることがある【Typical】 |

> **【Typical】「遅れ」の数え方は企業により異なります**【Varies】
> 1日でも遅れたら未達とするか、数量が一部でも不足したら未達とするか、
> 顧客都合の変更をどう扱うか。**社内・顧客間で定義を揃えないと、同じ数字を見ても話が噛み合いません。**

### (19) 在庫回転率／在庫日数

| 項目 | 内容 |
|---|---|
| **意味** | 在庫が1年間（または1か月）に何回入れ替わったか。在庫が滞留していないかを見る |
| **計算方法** | `在庫回転率（回） ＝ 売上原価 ÷ 平均在庫金額`　／　`在庫日数 ＝ 365 ÷ 在庫回転率` |
| **誰が見るか** | 経理・財務機能、生産管理機能、調達機能、社長 |
| **なぜ重要か** | **在庫は現金がモノに変わった姿**だから（`08_money.md` 8-8）。在庫が増えれば、その分の現金は手元から消えている |
| **目安** | 【Varies】。受注生産か見込生産か、部品の調達期間がどれだけ長いかで適正水準がまったく違う |

> **【重要】在庫は3種類あり、意味が違います**（`07_goods.md` 7-2）
> - **原材料**：まだ加工していないもの。買った分だけ現金が出ている
> - **仕掛品（しかかりひん）**：加工の途中のもの。材料費に加え、そこまでの加工費も乗っている
> - **製品（完成品）**：完成して出荷を待つもの。全部の原価が乗っている
>
> 【Inference】仕掛品が増えているということは、**工程のどこかで流れが止まっている**ということです。
> 在庫金額の合計だけを見ていると、この違いが見えません。

### (20) 売掛回転日数（売上債権回転日数）

| 項目 | 内容 |
|---|---|
| **意味** | 売上が立ってから、実際に現金として入金されるまでの平均日数 |
| **計算方法** | `売掛回転日数 ＝ 売掛金残高 ÷ （年間売上高 ÷ 365）`　※簡便法 |
| **誰が見るか** | 経理・財務機能、社長、金融機関 |
| **なぜ重要か** | この日数の分だけ、**自社が顧客に代金を貸している状態**になるから。日数が長いほど、必要な運転資金が増える（`08_money.md` 8-7） |
| **目安** | 【Varies】。顧客ごとの締め日・支払サイトの組み合わせで決まる |

> **【Fact】支払期日には法律上の上限があります**
> 取適法（旧・下請法）では、委託事業者の義務として、検査の有無を問わず
> **物品等を受領した日から起算して60日以内**のできる限り短い期間内で支払期日を定めることが定められています
> （出典：公正取引委員会「2026年1月から『下請法』は『取適法』へ！」リーフレット／令和7年8月）。
> 【Fact】2026年1月施行の改正では、支払手段として手形払等を用いることが「支払遅延」として禁止されました（同上）。

### (21) 買掛回転日数

| 項目 | 内容 |
|---|---|
| **意味** | 仕入・外注の代金を、実際に支払うまでの平均日数 |
| **計算方法** | `買掛回転日数 ＝ 買掛金残高 ÷ （年間仕入高 ÷ 365）`　※簡便法 |
| **誰が見るか** | 経理・財務機能、調達機能、社長 |
| **なぜ重要か** | 入金より支払が先に来るかどうかは、この日数と売掛回転日数の差で決まるから |

> **用語：CCC（キャッシュ・コンバージョン・サイクル）**
> → 材料にお金を払ってから、製品の代金が入ってくるまでの日数。
> → 計算の考え方：`CCC ＝ 売掛回転日数 ＋ 在庫日数 − 買掛回転日数`
> → 実務例：売掛75日＋在庫40日−買掛60日 ＝ **55日**【Example】。
>   つまり、**55日分の運転資金を自社で立て替えている**ことになります。
> → **なぜ重要なのか**：売上が2倍になれば、立て替える金額も約2倍になります。
>   受注が急増したときに資金が苦しくなるのは、この構造によるものです（`08_money.md` 8-7）。

### (22) 資金繰り（現預金残高・資金繰り表）

| 項目 | 内容 |
|---|---|
| **意味** | いつ・いくらお金が入り、いつ・いくら出ていくかを日付順に並べ、**残高がマイナスにならないか**を先に確認するもの |
| **計算方法** | `翌月末残高 ＝ 当月末残高 ＋ 入金予定 − 支払予定`（月次または日次で作成） |
| **誰が見るか** | **社長、経理・財務機能**（金融機関にも提出することがある） |
| **なぜ重要か** | **利益が出ていても、支払日に残高が足りなければ会社は事業を続けられない**から。利益と現金は別物（`08_money.md` 8-8） |

【Typical】特に注意される支払：
- **給与**（月次・支給日をずらせない）
- **社会保険料・源泉所得税**（法定期限がある。`13_periodic-work.md` 13-5）
- **借入金の返済**（費用ではないが現金は出ていく）
- **賞与・決算賞与**（半期に大きな金額が一度に出る）
- **納税**（決算期後2か月以内。`13_periodic-work.md` 13-8）

## 14-6. 数字はどこから生まれるか（帳票・システムとの対応）

【Typical】KPIは自然に出てくるものではなく、**現場で記録された帳票やデータを集計したもの**です。

| KPI | 元になる記録 | 記録する人 | 参照 |
|---|---|---|---|
| 売上高、粗利率 | 納品書、請求書、仕入請求書 | 経理・財務機能 | `10_documents.md`、`11_systems.md` 11-3 |
| 受注残 | 受注データ、納品実績 | 生産管理機能 | `11_systems.md` 11-2 |
| 稼働率、可動率、OEE | 設備の稼働記録、作業日報 | 製造機能（作業者） | `10_documents.md`、`11_systems.md` 11-2 |
| 直行率、不良率 | 検査記録、不適合報告書 | 品質保証機能、製造機能 | `10_documents.md` |
| 歩留まり | 材料の投入記録、製品数 | 製造機能、生産技術機能 | `07_goods.md` |
| 段取り時間 | 作業日報（段取り時間の区分記入） | 製造機能（作業者） | `10_documents.md` |
| リードタイム、納期遵守率 | 受注データ、製造実績、出荷記録 | 生産管理機能、出荷・物流機能 | `09_information.md` |
| 在庫回転率 | 在庫データ、棚卸結果 | 出荷・物流機能、経理・財務機能 | `07_goods.md` 7-9 |
| 売掛・買掛回転日数、資金繰り | 売掛金・買掛金の残高、入出金記録 | 経理・財務機能 | `08_money.md` 8-5 |
| 労働分配率、1人当たり付加価値 | 給与データ、決算数値 | 人事・総務機能、経理・財務機能 | `08_money.md` 8-8 |

> **【重要】数字の精度は、現場の記録の精度で決まります**
> 【Inference】作業日報に「段取り」と「加工」を分けて書いていなければ、段取り時間は計算できません。
> 不良を出した数を記録していなければ、直行率は出せません。
> **KPIは、現場の記録の写し鏡です。** これが、日次の作業日報が製造業で重視される理由です（`13_periodic-work.md` 13-3）。

## 14-7. 業種によって見る数字はどう変わるか【Varies】

| 業種 | 【Typical】特に重視される数字 | なぜか |
|---|---|---|
| **食品製造** | **歩留まり**、廃棄率、期限内出荷率、日々の受注充足率、衛生管理の記録完了率 | 原材料費の比率が高く、期限があるため。売れ残りは廃棄＝直接の損失になる |
| **金属加工** | 本ファイルの基本形。**可動率・段取り時間・直行率・材料歩留まり・納期遵守率** | 加工時間と材料が原価の主役であり、納期が顧客評価の中心のため |
| **機械製造** | **案件別の予実差（見積工数と実績工数の差）**、進捗率、設計変更件数、試運転での手直し工数 | 1台あたりの期間が長く、工数の見積違いがそのまま利益の増減になるため |
| **電気機器** | **実装の直行率**、部品の欠品率、部品在庫日数、部品の調達リードタイム | 部品費の比率が高く、1点でも部品が欠ければ製品が完成しないため |
| **化学・プラスチック** | **バッチ成功率**、収率（歩留まり）、エネルギー原単位、成形の**ショット数**・不良率 | 1バッチ失敗すると丸ごと損失になり、エネルギー費の比率も高いため |
| **印刷** | **刷り直し率**、校正回数、用紙のロス率、**段取り時間**、機械の実稼働時間 | 小ロット化により段取りの比率が上がり、刷り直しは全額自社負担になり得るため |

## 14-8. このファイルのまとめ

1. 製造業の数字は、**お金の層／仕事の量の層／現場の層／時間と在庫の層**の4つに分かれる。
   1つの数字だけを見ても原因は分からない。
2. **売上高の大きさは、稼ぐ力を表さない。** 材料費込みか加工賃かで売上は大きく変わる。
   粗利額・加工高・付加価値額を併せて見る必要がある。
3. **受注残は将来の売上の予定であり、売上でも入金でもない。** 受注した時点ではむしろお金が出ていく側である。
4. **稼働率（かどうりつ）＝仕事がどれだけ入っているか（外の事情）。**
   **可動率（べきどうりつ）＝動かしたいときに設備が動いたか（中の事情）。**
   稼働率100％は必ずしも良い状態ではなく、可動率は100％を目指す。混同すると、誰が何をすべきかが分からなくなる。
5. **OEE ＝ 時間稼働率 × 性能稼働率 × 良品率。** それぞれ90％でも、掛け算で全体は約73％になる。
6. **歩留まりは材料の話、直行率は工程の話。** 良品率だけを見ると、手直しに使った工数が数字に現れない。
7. **リードタイムの大半は待ち時間**である。実際に加工している時間は、受注から納品までのごく一部にすぎない。
8. **売掛回転日数＋在庫日数−買掛回転日数（CCC）**の分だけ、自社が資金を立て替えている。
   売上が増えれば立て替え額も増える。
9. **KPIは現場の記録の写し鏡**である。作業日報・検査記録・在庫記録の精度が、そのまま数字の精度になる。
