## 4-1. 全体像（17ステップ）

### 全社フローの骨格

```
【受注生産（個別受注）の場合の基本フロー】

  ①引合い受付 → ②仕様ヒアリング・図面受領 → ③見積（工程設計・原価計算）
        → ④見積提出・価格交渉 → ⑤受注（注文書受領・受注登録）
        → ⑥生産計画（日程計画） → ⑦材料手配・外注手配
        → ⑧材料受入・受入検査 → ⑨製造（各工程） → ⑩工程内検査
        → ⑪最終検査（出荷検査） → ⑫出荷準備・梱包 → ⑬納品・納入
        → ⑭検収 → ⑮請求（締め・請求書発行） → ⑯入金
        → ⑰アフター対応（不具合対応・是正処置／リピート受注）
```

### 時間軸のイメージ【Example】

> ※以下は理解のための架空の例です。実際の期間は製品・業種・取引条件により大きく異なります。

```
 Day 0     Day 3      Day 7        Day 10          Day 25      Day 30    Day 60    Day 90
   │         │          │            │               │           │         │         │
 引合い    見積提出    受注       材料入荷        製造完了      納品      請求     入金
   │←─3日─→│←──4日──→│←──3日───→│←───15日────→│←──5日──→│         │
   │                                                            │←─翌月末─→│
   │                                                            │                   │
   └────────────── リードタイム（受注から納品まで約23日） ────────┘
                                                                └─── 回収サイト ───┘
                                                                     （締め支払い）
```

> **ここが製造業を理解するうえで最重要**
> 【Typical】**材料を買うためのお金は Day 10 前後に出ていく（または支払日に出る）のに、
> 売上の代金が入るのは Day 90 前後**です。この**約2〜3か月のズレ**を自社の手元資金で埋める必要があります。
> これが「製造業は運転資金が必要な商売」と言われる理由です（詳細は `08_money.md` `12_business-model.md`）。

## 4-2. 各ステップの詳細

以下、各ステップについて **［誰が］［何を受け取り］［何をして］［何を作り］［次に誰へ渡すか］［頻度］［なぜするのか］** を記述します。

---

### ① 引合い受付

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能（担当：営業担当者。小規模企業では社長） |
| **何を受け取り** | 顧客からの問い合わせ（電話、メール、来訪、Web、既存顧客の担当者からの連絡）。図面が添付されていることも、口頭の相談だけのこともある |
| **何をして** | 案件の内容を聞き取り、対応可否を一次判断する。自社の設備でできるか、納期に対応できるか、既存顧客か新規顧客かを確認する。案件として記録する |
| **何を作り** | 引合い記録（引合い台帳への登録、案件番号の付与） |
| **次に誰へ** | ② へ進む（自社で対応できる場合）／ お断り（対応できない場合） |
| **頻度** | **問い合わせ時**（モデル企業では【Example】月200〜300件程度の引合い） |

> **なぜするのか**
> 【Typical】引合いをすべて記録するのは、受注できなかった案件の理由（価格・納期・技術）を後から振り返るためです。
> また、対応できない案件に見積作成の工数をかけないよう、入口で判断するためでもあります。

> **用語：引合い（ひきあい）**
> → 顧客から「これ作れますか」「いくらになりますか」と聞かれること。正式な注文の前段階。
> → 実務例：顧客の設計者から「新しい装置のカバーを作りたいのですが、図面を送るので見てもらえますか」という
>    メールが来る。これが引合い。この時点ではまだ仕事にはなっていない。

> **【Varies】新規顧客の場合**
> 【Typical】新規顧客からの引合いでは、この段階で**与信確認**（相手が代金を支払える会社か調べること）を行うことが多い。
> 具体的には、会社概要の確認、信用調査会社の情報、取引条件（支払サイト）の確認など。
> 判断は社長が行うことが多い。

### ② 仕様ヒアリング・図面受領

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能（技術的な内容は ③ 生産技術機能が同席することもある） |
| **何を受け取り** | 顧客から：図面（紙・PDF・3Dデータ）、仕様書、数量、希望納期、材質指定、表面処理の指定、検査要求、梱包・納入条件 |
| **何をして** | 図面の内容を確認し、不明点を顧客に質問する。公差（許される寸法の誤差）、材質、表面処理、検査要求、納入場所と回数、支給材の有無を確定させる |
| **何を作り** | 確定した仕様情報（見積依頼書、図面ファイル、仕様確認メモ） |
| **次に誰へ** | ③ 生産技術機能・④ 調達機能（見積のための工程検討と材料価格照会） |
| **頻度** | **案件発生時** |

> **なぜするのか**
> 【Typical】図面だけでは決まらないことが多くあります。
> 【Example】「板厚3mmのSUS304」と書かれていても、表面の仕上げ（ヘアライン・鏡面・素地）、
> 溶接跡を残してよいか、角のバリ（削り残しの尖り）をどこまで取るか、といった点は図面に書かれないことがあります。
> これを確認せずに見積・製作すると、納品後に「これでは受け取れない」となり、作り直しになります。
> **仕様確認は、後工程の手戻りを防ぐための工程**です。

> **用語：公差（こうさ）**
> → 図面で指定された寸法に対して、許される誤差の範囲のこと。
> → 実務例：「100 ±0.1」と書かれていれば、99.9mm〜100.1mmの範囲に入っていれば合格。
>    公差が厳しい（±0.01など）ほど、精密な設備と時間が必要になり、価格が上がる。
>
> **用語：ミルシート（材料証明書／材料ミルシート）**
> → 材料メーカーが発行する、その材料の成分・強度などを証明する書類。
> → 実務例：顧客から「SUS304のミルシートを添付してください」と求められる。
>    材料の素性を後から追跡できるようにするためで、これを**トレーサビリティ**という。

### ③ 見積（工程設計・原価計算）

**製造業の利益を左右する、最重要のステップです。**

| 項目 | 内容 |
|---|---|
| **誰が** | ③ 生産技術機能（工程設計）＋ ④ 調達機能（材料・外注価格）＋ ① 営業機能（取りまとめ） |
| **何を受け取り** | ② で確定した図面・仕様・数量・希望納期 |
| **何をして** | 下記の3段階を行う（後述） |
| **何を作り** | 見積原価の内訳、見積金額、想定リードタイム |
| **次に誰へ** | ① 営業機能（見積書作成へ）。金額が大きい場合は社長の承認を経る |
| **頻度** | **案件発生時**（モデル企業では【Example】年間約3,000件） |

#### 見積の3段階

**第1段階：工程設計（どう作るかを決める）**

【Typical】図面を見て、次を決めます。

| 決めること | 【Example】具体例 |
|---|---|
| 工程の順番 | 切断 → 抜き → 曲げ → 溶接 → めっき（外注） → 検査 |
| 使う設備 | レーザー加工機、ベンディングマシン、半自動溶接 |
| 各工程の標準時間 | 切断2分/個、曲げ3分/個、溶接8分/個 |
| 段取り時間 | 曲げの金型交換 30分（ロット全体で1回） |
| 必要な材料と量 | SUS304 t3.0 板材 1,220×2,440 を3枚 |
| 外注に出す工程 | めっき（外注単価 80円/個） |
| 必要な治具の有無 | 溶接用の位置決め治具を新規製作（1式 3万円） |

**第2段階：原価計算（いくらかかるか計算する）**

【Typical】中小製造業で一般的な原価の考え方です。

```
   材料費       = 材料単価 × 使用量 ÷ 歩留まり
 + 加工費       = Σ（各工程の時間 × その工程のチャージレート）
 + 段取り費      = 段取り時間 × チャージレート ÷ ロット数
 + 外注費       = 外注単価 × 数量
 + 治具・型費     = 治具製作費 ÷ 想定生産数（または初回に別途請求）
 + その他経費     = 運賃、梱包材、検査費用など
 ─────────────────────────────
 = 製造原価
 + 販売管理費・利益  = 製造原価 × 一定率（または個別に設定）
 ─────────────────────────────
 = 見積金額
```

> **用語：チャージレート（賃率・加工費率／マシンレート）**
> → その設備を1時間動かすのに、いくらのコストがかかるとみなすかの単価。
>   人件費・設備の減価償却費・電気代・工場の固定費などを1時間あたりに割り戻して算出します。
> → 実務例：マシニングセンタのチャージレートが5,000円/時なら、
>    加工に30分かかる部品の加工費は 5,000 × 0.5 = 2,500円として見積る。
> → 【Varies】レートの決め方は企業により大きく異なり、設備別に細かく設定する企業もあれば、
>    工場全体で1つのレートを使う企業もあります。
>
> **用語：歩留まり（ぶどまり）**
> → 投入した材料のうち、実際に製品になった割合。
> → 実務例：1枚の板から10個取れる設計でも、端材や切りしろで実際には8個しか取れなければ歩留まり80％。
>    材料費は「必要量 ÷ 歩留まり」で計算しないと、材料費が不足して赤字になる。
>
> **用語：ロット数と単価の関係**
> → 段取り時間は、ロットが1個でも1,000個でも同じだけかかります。
> → 実務例：段取り30分（＝2,500円）を10個で割れば1個あたり250円、1,000個で割れば1個あたり2.5円。
>    **同じ製品でも、数量が変われば適正な単価が変わる**。これが「数量を確認せずに単価を出せない」理由です。

**第3段階：納期の算定**

【Typical】材料の調達期間 ＋ 自社の工程時間 ＋ 外注の往復期間 ＋ 検査・出荷準備 ＋ 現在の負荷状況を合算します。
「作業時間の合計」ではなく、**すでに入っている他の仕事との兼ね合い（設備の空き）**で決まる点が重要です。

> **なぜ見積が最重要なのか**
> 【Inference】受託加工では、見積時点で決めた単価が、その後の製造・納品を通じて変わりません。
> 見積を1個あたり50円安く出してしまえば、1,000個作れば5万円の利益が消えます。
> 逆に高すぎれば失注します。しかも実際に作るのは見積の数週間後であり、
> その間に材料価格が上がるリスクもあります。
> **「作る前にすべての原価を予測する」という、本質的に難しい作業**であるため、
> 製造業では見積の精度が利益に直結します。

### ④ 見積提出・価格交渉

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能（承認：社長または営業責任者） |
| **何を受け取り** | ③ で作成した見積原価と見積金額 |
| **何をして** | 見積書を作成し、社内承認を得て、顧客へ提出する。顧客からの値下げ要請・納期短縮要請に対応する。競合他社との比較にさらされる |
| **何を作り** | **見積書**（見積番号、品名、数量、単価、金額、納期、有効期限、条件を記載） |
| **次に誰へ** | 顧客（見積書を提出）。受注に至れば ⑤ へ |
| **頻度** | **案件発生時** |

> **なぜ有効期限を書くのか**
> 【Typical】材料価格が変動するため、「この見積は○月○日まで有効」と書いておかないと、
> 半年後にその価格で発注されて赤字になることがあります。

> **価格交渉について**
> 【Fact】原材料費・労務費・エネルギー費の上昇分を取引価格へ反映する「価格転嫁」の状況について、
> 中小企業庁は毎年3月と9月を「価格交渉促進月間」と設定し、受注側中小企業30万社にアンケート調査を実施しています。
> 2026年3月時点の調査では、「価格交渉が行われた」割合は90.7％、価格転嫁率は54.2％でした
> （出典：価格交渉促進月間（2026年3月）フォローアップ調査の結果／経済産業省・中小企業庁、2026年6月26日公表）。
> 【Fact】同庁は「価格の改定は、半期に一度、4月と10月に行う企業が比較的多いことから、
> その前月である3月と9月を価格交渉促進月間と設定している」と説明しています（出典：同上）。
> 【Typical】したがって**単価改定の交渉は半期ごとに行われることが多い**というのが、製造業でよく見られる商習慣です。

### ⑤ 受注（注文書受領・受注登録）

**ここが「仕事が確定する」瞬間です。**

| 項目 | 内容 |
|---|---|
| **誰が** | ① 営業機能（受領）→ ② 受注・生産管理機能（登録） |
| **何を受け取り** | 顧客から：**注文書**（発注書、Purchase Order／PO）。品番、品名、数量、単価、納期、納入場所が記載されている |
| **何をして** | 注文書の内容が見積と一致しているか確認する（数量・単価・納期・仕様）。相違があれば顧客に確認する。受注として社内に登録する |
| **何を作り** | **受注データ**（受注番号、顧客、品番、数量、単価、納期、指定仕様）。注文請書（発行する場合） |
| **次に誰へ** | ② 生産管理機能 → ⑥ 生産計画へ |
| **頻度** | **受注時**（モデル企業では【Example】年間約1,800件、月平均150件） |

> **なぜ注文書と見積の照合が必要なのか**
> 【Typical】見積では1,000個だったのに注文書が200個になっている、という食い違いが起こり得ます。
> 単価は1,000個前提で計算していたため、200個では段取り費が吸収できず赤字になります。
> **数量が変われば単価も変わる**ため、この照合は利益を守る作業です。

> **【重要】受注は売上ではない**
> 【Typical】注文書を受け取っただけでは、会計上の売上にはなりません。
> 売上が立つのは製品を納品し、顧客が受け取りを認めた（検収した）後です。
> 受注時点の金額は「**受注残**（まだ納めていない注文の残高）」として管理されます。

> **用語：内示と確定注文（繰返生産の場合）**
> → 繰返生産では、注文書の前に「内示（フォーキャスト）」が来ます。
> → 実務例：D社から「4月2,000個、5月2,000個、6月1,800個」という3か月分の内示が届く。
>    材料の納期が3週間かかるため、この内示をもとに材料を先に手配する。
>    その後、納入の2週間前に「4月分は確定1,800個」という確定注文（かんばん、納入指示）が来る。
>    **内示は約束ではない**ため、差分（200個分）の材料が余るリスクを自社が負う。
>    どこまで内示を信じて手配するかは、生産管理機能の日常的な判断です。

### ⑥ 生産計画（日程計画）

| 項目 | 内容 |
|---|---|
| **誰が** | ② 受注・生産管理機能（相談：⑤ 製造機能の工場長・リーダー） |
| **何を受け取り** | 受注データ（品番・数量・納期）、現在の負荷状況（各設備にすでに入っている仕事）、人員の出勤予定、外注先の空き状況 |
| **何をして** | 納期から逆算して「どの設備で、いつ、何を、どれだけ作るか」を決める。設備・人・材料・外注の制約を考慮して、実行可能な日程に組む。他の受注と優先順位を調整する |
| **何を作り** | **生産計画（日程計画／工程計画）**、製造指示書（作業指示書）、材料所要量 |
| **次に誰へ** | ④ 調達機能（材料・外注の手配依頼）、⑤ 製造機能（製造指示）、① 営業機能（納期回答の確定） |
| **頻度** | **週次**（週次で計画を立て直す）＋ **日次**（日々の調整）＋ **受注時**（新規受注の組み込み） |

> **なぜ生産計画が必要なのか**
> 【Typical】設備の数も人数も限られているため、すべての注文を同時には作れません。
> 計画がないと、納期が近い仕事が後回しになり、納期遅れが発生します。
> また、材料をいつ注文すればよいかも計画から逆算して決まります。
> **計画がないと、材料が間に合わず納期遅れが発生する**、これが生産計画の存在理由です。

> **用語：負荷（ふか）／能力**
> → 負荷＝各設備・各作業者に割り当てられている仕事の量（時間）。
>   能力＝その設備・作業者が実際に働ける時間。
> → 実務例：マシニングセンタの今週の能力が40時間なのに、入っている仕事の合計（負荷）が55時間なら、
>    15時間分は今週中に終わらない。この場合、残業する、外注に出す、納期を交渉する、のいずれかを選ぶ。
>    この判断が生産管理の中心的な仕事です。
>
> **用語：バックワード／フォワード（日程の組み方）**
> → バックワード＝納期から逆算して「いつ始めればよいか」を決める組み方。
>   フォワード＝今日から順に積んでいって「いつ終わるか」を出す組み方。
> → 実務例：納期が5月20日の仕事は、検査2日・めっき外注5日・溶接3日・曲げ1日・切断1日かかるので、
>    5月8日には切断を始めないと間に合わない、と逆算する（バックワード）。

### ⑦ 材料手配・外注手配

| 項目 | 内容 |
|---|---|
| **誰が** | ④ 調達機能（依頼元：② 生産管理機能） |
| **何を受け取り** | 材料所要量（品目・材質・寸法・数量・要求納期）、外注依頼（工程・数量・要求納期）、図面 |
| **何をして** | 在庫を確認し、不足分を発注する。複数の仕入先から価格・納期を比較することもある（相見積）。外注先の空き状況を確認して手配する。注文書を発行する |
| **何を作り** | **注文書（発注書）**（仕入先向け・外注先向け）、発注残データ |
| **次に誰へ** | 仕入先・外注先（注文書）、② 生産管理機能（入荷予定日の連絡） |
| **頻度** | **発注時**（受注のたび）＋ **週次**（定期発注品）＋ **月次**（消耗品のまとめ発注） |

> **なぜ在庫確認が先なのか**
> 【Typical】社内にある材料で足りるなら買う必要がありません。
> 二重に買えば余分な在庫（＝寝ているお金）が増えます。

> **外注手配で気をつけること**
> 【Typical】外注先の納期は自社ではコントロールできません。
> 外注に出した瞬間、その期間は自社の工程が止まった状態になります。
> このため外注工程を含む案件は、リードタイムが大きく伸びます。
> 【Fact】なお、自社が発注側になる場合、取適法（旧・下請法）上の義務
> （発注内容の明示、書類の作成・保存、支払期日の設定、遅延利息）を負う可能性があります
> （`02_industry-structure.md` 11-2、出典：取適法／e-Gov法令検索、公正取引委員会）。

### ⑧ 材料受入・受入検査

| 項目 | 内容 |
|---|---|
| **誰が** | ⑦ 出荷・物流機能（受入担当）＋ ⑥ 品質保証機能（検査） |
| **何を受け取り** | 仕入先から：材料・部品、納品書、ミルシート（材料証明書）。外注先から：加工済み品、納品書、検査成績書 |
| **何をして** | 納品書と現物を照合する（品名・数量・材質・寸法）。外観に傷・変形がないか確認する。必要に応じて寸法・材質を検査する。受入記録を付ける。指定の置き場に格納する |
| **何を作り** | **受入記録（検収記録）**、在庫データの更新、不適合があれば不適合報告 |
| **次に誰へ** | ② 生産管理機能（入荷完了の連絡）、④ 調達機能（数量違い・不良の連絡）、⑨ 経理機能（仕入計上の根拠） |
| **頻度** | **納品時**（毎日、複数回発生） |

> **なぜ受入検査をするのか**
> 【Typical】間違った材料で加工を始めてしまうと、加工した分がすべて無駄になります。
> 材料の段階で気づけば材料代だけの損失で済みますが、
> 溶接・めっきまで進んでから間違いに気づくと、そこまでの加工費と時間がすべて失われます。
> **不具合は上流で見つけるほど損失が小さい**という原則がここに現れています。

> **【重要】発注と仕入計上は別物**
> 【Typical】注文書を出した時点（発注）ではまだ仕入にはなりません。
> 現物を受け取って検収した時点で仕入として計上されます。
> この差を「**発注残**」と呼びます。

### ⑨ 製造（各工程）

| 項目 | 内容 |
|---|---|
| **誰が** | ⑤ 製造機能（各工程の作業者。指示：工場長・現場リーダー） |
| **何を受け取り** | 製造指示書（作業指示書）、図面、作業標準書、材料（または前工程からの仕掛品）、治具、NCプログラム |
| **何をして** | 指示された工程の加工を行う。段取り（機械の準備・型や刃物の交換）を行い、最初の1個を作って寸法を確認し（初品確認）、問題なければ本生産に入る。加工数量・不良数・所要時間を記録する |
| **何を作り** | 加工済みの仕掛品（次工程へ渡すもの）、**作業日報**（実績工数・数量・不良数）、**現品票**（その品物が何の注文の何かを示す札） |
| **次に誰へ** | ⑤ 製造機能の次工程 → 最終的に ⑥ 品質保証機能。実績は ② 生産管理機能と ⑨ 経理機能へ |
| **頻度** | **常時**（就業時間中は継続的に稼働）／実績記録は **日次** |

#### 工程の流れ【Example】板金加工品の場合

```
 材料（鋼板）
   ↓
 ①切断・抜き   レーザー加工機で板から形を切り出す         → 現品票を付ける
   ↓
 ②バリ取り     切断面の尖り・ささくれを取る
   ↓
 ③曲げ        ベンディングマシンで所定の角度に曲げる      → 初品で角度・寸法を確認
   ↓
 ④溶接        治具に固定して部品同士を溶接する           → 溶接後の変形を確認
   ↓
 ⑤（外注）めっき 外注先へ出し、表面処理をして戻してもらう    → 往復で5日程度
   ↓
 ⑥組立・仕上げ  ねじ・ナットを取り付け、外観を仕上げる
   ↓
 完成品 → 最終検査へ
```

> **用語：現品票（げんぴんひょう）**
> → 加工中のモノに付けておく札。何の注文の、何の品物が、何個あり、次にどの工程へ行くかが書いてある。
> → 実務例：工場内には同時に何十種類もの部品が流れています。
>    札がないと「これは何の仕事のものか」が分からなくなり、別の注文の品物と混ざります。
>    **現品票は、モノと情報を結び付けておくための仕組み**です。
>
> **用語：初品確認（しょひんかくにん）／初物チェック**
> → 本格的に作り始める前に、最初の1個を作って寸法・形状を確認すること。
> → 実務例：曲げ角度が0.5度ずれていることに1個目で気づけば、機械を調整して作り直せます。
>    気づかずに1,000個作れば、1,000個すべてが不良になります。
>    **初品確認は、不良を最小限にとどめるための工程**です。
>
> **用語：作業日報**
> → 誰が、いつ、どの注文の、どの工程を、何分かけて、何個作り、何個不良だったかを記録する帳票。
> → 実務例：この記録がないと、後から「この仕事は見積どおりの時間で作れたのか」が分かりません。
>    実績工数を集計して原価を計算し、次回の見積に反映するための基礎データになります。

### ⑩ 工程内検査

| 項目 | 内容 |
|---|---|
| **誰が** | ⑤ 製造機能（作業者による自主検査）＋ ⑥ 品質保証機能（巡回・抜取検査） |
| **何を受け取り** | 加工中・加工直後の仕掛品、図面、検査基準 |
| **何をして** | 寸法・外観・溶接状態などを、工程の途中で確認する。全数検査の場合と、抜き取り検査の場合がある。結果を記録する |
| **何を作り** | 工程内検査記録。不適合があれば**不適合品報告書** |
| **次に誰へ** | 合格なら次工程へ。不合格なら ⑤ 製造機能へ差し戻し（手直し・作り直し）、② 生産管理機能へ納期影響の連絡 |
| **頻度** | **常時**（工程ごと）／ロットの切り替わりごと |

> **なぜ最終検査だけでなく工程の途中でも検査するのか**
> 【Typical】最終検査で初めて不良に気づくと、それまでのすべての工程の費用と時間が無駄になります。
> また、溶接後・めっき後では手直しが困難になるものもあります。
> 工程ごとに確認することで、**手直しが可能なうちに発見する**ことが目的です。

### ⑪ 最終検査（出荷検査）

| 項目 | 内容 |
|---|---|
| **誰が** | ⑥ 品質保証機能（検査員） |
| **何を受け取り** | 完成品、図面、顧客の検査要求（検査項目・抜取数・成績書の要否） |
| **何をして** | 図面の指定寸法を測定する。外観（傷、めっきムラ、変形）を確認する。数量を数える。必要に応じて三次元測定機で測定する。記録を作成する |
| **何を作り** | **検査成績書**（顧客提出用）、検査記録（社内保管用）、合格品の識別（合格票の貼付） |
| **次に誰へ** | ⑦ 出荷・物流機能（合格品と検査成績書）／不合格なら ⑤ 製造機能へ |
| **頻度** | **納品時**（出荷の前） |

> **なぜ検査成績書を顧客に出すのか**
> 【Typical】顧客は、受け取った部品が図面どおりであることを自分で全部測る余裕がありません。
> 検査成績書は「当社で測定した結果、図面どおりでした」という**証明書**です。
> 顧客はこれを信頼して受け入れ、自社の工程に組み込みます。
> したがって検査成績書は、顧客との信頼関係を成り立たせている書類です。
> 【Varies】提出を求められるかどうか、どの項目を記載するかは顧客によって異なります。

### ⑫ 出荷準備・梱包

| 項目 | 内容 |
|---|---|
| **誰が** | ⑦ 出荷・物流機能 |
| **何を受け取り** | 検査合格品、検査成績書、出荷指示（納入先・納入日時・数量・荷姿指定） |
| **何をして** | 数量を数え、指定の荷姿で梱包する（通い箱、段ボール、パレット、緩衝材）。ラベル・現品票を貼る。納品書を作成する。運送便を手配する |
| **何を作り** | 梱包済みの荷物、**納品書**（受領書付き）、送り状、出荷記録 |
| **次に誰へ** | 運送会社（または自社便）→ 顧客 |
| **頻度** | **納品時**（モデル企業では【Example】1日10〜20件程度の出荷） |

> **用語：荷姿（にすがた）／通い箱**
> → 荷姿＝どのような形で梱包するかの指定。
>   通い箱＝顧客と自社の間を往復して繰り返し使う専用の箱。
> → 実務例：顧客から「この専用箱に20個ずつ、緩衝材を入れて納めてください」と指定される。
>    箱は納品後、空箱として返却される。繰返生産ではよく使われる方式。
>
> **なぜ梱包の指定があるのか**
> 【Typical】顧客は受け取った部品をそのまま自社の組立ラインへ運びます。
> 決まった箱に決まった数だけ入っていれば、数を数える手間が省け、ラインに直接投入できます。
> また、輸送中の傷を防ぐ意味もあります。めっき品や塗装品は、傷が付けば不良品になります。

### ⑬ 納品・納入

| 項目 | 内容 |
|---|---|
| **誰が** | ⑦ 出荷・物流機能（実際の輸送は運送会社への委託が多い） |
| **何を受け取り** | 梱包済みの荷物、納品書、送り状 |
| **何をして** | 指定の日時・場所へ届ける。顧客の受入担当者に引き渡し、**受領印**をもらう |
| **何を作り** | 受領印のある納品書控え（＝納品した証拠） |
| **次に誰へ** | 顧客（⑭ 検収へ）、② 生産管理機能（納入完了の連絡）、⑨ 経理機能（売上計上の根拠） |
| **頻度** | **納品時**（顧客の指定による。日次で納入する顧客もある） |

> **なぜ受領印が重要なのか**
> 【Typical】受領印のある納品書控えは、「たしかに納めた」ことを示す証拠書類です。
> 後日「届いていない」と言われた場合の唯一の裏付けになり、請求の根拠にもなります。
> 【Varies】電子化が進んだ企業では、システム上の受領データで代替される場合もあります。

> **【Varies】納入形態のバリエーション**
> - **自社便納入**：自社のトラックで運ぶ。急な対応がしやすい
> - **運送会社委託**：一般的。時間指定がある場合は事前予約が必要
> - **直送**：商社経由の取引で、商社の顧客へ直接届ける（`02_industry-structure.md` 11-3参照）
> - **納入代行・指定納入業者**：顧客が指定した物流業者に集約する形式
> - **納入時刻指定（着荷時間指定）**：顧客のライン稼働に合わせて時刻が細かく指定されることがある

### ⑭ 検収

**ここが「売上が立つ」瞬間です。**

| 項目 | 内容 |
|---|---|
| **誰が** | 顧客（自社ではない）。自社側は ② 生産管理機能／⑨ 経理機能が確認する |
| **何を受け取り** | 顧客が製品と納品書・検査成績書を受け取り、内容を確認する |
| **何をして** | 顧客が数量・品質・仕様を確認し、注文どおりであることを認める。問題があれば返品・手直し要求となる |
| **何を作り** | **検収通知**（受領データ、検収明細、支給品の相殺明細など。形式は顧客による） |
| **次に誰へ** | ⑨ 経理機能（売上計上）、⑮ 請求へ |
| **頻度** | **納品時**（顧客の検収サイクルによる）／【Varies】月次でまとめて検収する顧客もある |

> **用語：検収（けんしゅう）**
> → 顧客が、納品された品物を確認して「注文どおりのものを受け取りました」と認めること。
> → 実務例：納品した翌日に顧客の受入検査で寸法が測定され、合格すれば検収される。
>    検収されて初めて、売上として確定し、代金を請求できる状態になる。

> **【重要】納品 ≠ 検収 ≠ 売上 ≠ 入金**
> 【Typical】この4つは別の時点で起こります。初心者が最も混同しやすい箇所です。
>
> | 出来事 | 何が起きているか | お金は動いたか |
> |---|---|---|
> | 受注 | 注文をもらった | 動いていない |
> | 納品 | モノを渡した | 動いていない |
> | 検収 | 顧客が受け取りを認めた | 動いていない |
> | 売上計上 | 帳簿に売上として記録した | **動いていない**（売掛金が立つだけ） |
> | 入金 | 銀行口座にお金が入った | **ここで初めて動く** |

### ⑮ 請求（締め・請求書発行）

| 項目 | 内容 |
|---|---|
| **誰が** | ⑨ 経理・財務機能 |
| **何を受け取り** | 当月分の出荷・検収データ（品番、数量、単価、納品日） |
| **何をして** | **締め日**で当月分の取引を区切り、顧客ごとに集計する。顧客側の検収データと自社の売上データを突き合わせる（**照合**）。差異があれば原因を調べて調整する。請求書を発行し、顧客へ送付する |
| **何を作り** | **請求書**、売掛金データ（誰にいくら請求中か） |
| **次に誰へ** | 顧客（請求書）。⑯ 入金の管理へ |
| **頻度** | **月次**（締め日の翌日〜数営業日以内）／**請求時** |

> **用語：締め日（しめび）**
> → 1か月分の取引を区切る日。この日までの取引をまとめて請求します。
> → 実務例：「20日締め」なら、前月21日〜当月20日の納品分をまとめて請求する。
>    顧客ごとに締め日が違うことがあり（月末締め、20日締め、25日締め）、経理はそれぞれに対応する。
>
> **用語：支払サイト**
> → 締め日から実際に入金されるまでの期間。
> → 実務例：「月末締め翌月末払い」なら、4月中に納品した分は5月31日に入金される。
>    4月1日に納品したものは、入金まで約60日かかる計算になる。
>    【Fact】取適法では、物品等を受領した日から起算して60日以内のできる限り短い期間内で
>    支払期日を定めることが委託事業者の義務とされています
>    （出典：取適法／e-Gov法令検索、公正取引委員会）。

> **なぜ顧客側のデータと突き合わせるのか**
> 【Typical】自社は「4月に100万円納品した」と思っていても、顧客側は「検収は90万円分、10万円分は5月検収」
> と認識していることがあります。この差異を放置すると、入金額が請求額と合わなくなります。
> 【Varies】顧客によっては「**支払通知書**」を先に送ってきて、その金額どおりに請求させる方式もあります
> （支払通知書方式、買掛計上方式）。

### ⑯ 入金

| 項目 | 内容 |
|---|---|
| **誰が** | ⑨ 経理・財務機能 |
| **何を受け取り** | 顧客からの支払（銀行振込、電子記録債権など）、支払通知書 |
| **何をして** | 入金額を請求額と照合する（**消込**）。差額があれば原因を調べる（値引き、相殺、振込手数料の負担、検収漏れ）。有償支給材の代金が相殺されている場合はその明細を確認する |
| **何を作り** | 入金消込記録、売掛金残高の更新、未入金リスト |
| **次に誰へ** | 未入金があれば ① 営業機能へ確認依頼。社長へ資金繰り報告 |
| **頻度** | **入金時**（支払日）／**月次**（残高確認） |

> **用語：消込（けしこみ）**
> → 請求した金額に対して入金があったことを確認し、売掛金の残高から消していく作業。
> → 実務例：A社に100万円請求し、99万5,000円の入金があった。
>    差額5,000円は振込手数料を顧客が差し引いたものと判明し、その旨を記録して処理する。
>
> **用語：相殺（そうさい）**
> → お互いに債権と債務がある場合、差し引きして残りだけをやり取りすること。
> → 実務例：顧客に100万円請求しているが、顧客から有償支給で40万円分の材料を買っている。
>    顧客は差額の60万円だけを振り込んでくる。これが相殺。
>    【Fact】ただし取適法では、有償支給原材料等の対価を製品代金の支払期日より早く支払わせることや、
>    代金から控除することが禁止項目⑧として定められています
>    （出典：公正取引委員会 中部事務所「下請法 知っておきたい豆情報 その10」）。

> **【Fact】支払手段の状況**
> 価格交渉促進月間（2026年3月）フォローアップ調査では、支払手段を「現金のみ」とした回答が87.5％まで増加し、
> 支払期日が60日を超過している企業の割合が全体の6.6％残存する結果となっています
> （出典：経済産業省・中小企業庁、2026年6月26日公表）。
> 【Fact】2026年1月施行の取適法では、支払手段として手形払等を用いることが「支払遅延」として禁止されました
> （出典：取適法／e-Gov法令検索、公正取引委員会）。

---

### ⑰ アフター対応

納品して入金されたら終わり、ではありません。製造業では納品後にも複数の仕事が発生します。

| 対応の種類 | 内容 | 誰が | 頻度 |
|---|---|---|---|
| **不具合（クレーム）対応** | 顧客から「寸法が違う」「傷がある」「組み付かない」と連絡が入る。現品を確認し、原因を調べ、代替品を手配し、報告書を提出する | ① 営業（受付）→ ⑥ 品質保証（原因調査）→ ⑤ 製造（対策）→ ② 生産管理（代替品の日程） | **トラブル発生時** |
| **是正処置・再発防止** | なぜ起きたかを分析し、作業標準・治具・検査方法を見直して、同じことが起きないようにする。顧客へ**是正処置報告書**を提出する | ⑥ 品質保証（主管） | **トラブル発生時** |
| **リピート受注** | 同じ品番の再注文。図面・工程・治具が残っているため、②から始まらず⑤（受注）から始まる | ① 営業 → ② 生産管理 | **受注時** |
| **仕様変更対応** | 顧客の設計変更により図面が改訂される。新旧の図面番号を管理し、旧仕様の在庫をどうするか決める | ① 営業 → ③ 生産技術 → ② 生産管理 | **案件発生時** |
| **補給部品の供給** | 量産終了後も、顧客の保守用に少量の部品を作る | ① 営業 → ② 生産管理 | **受注時** |
| **顧客監査の受入** | 顧客が自社工場に来て、品質管理の状況を確認する | ⑥ 品質保証（主管）＋ 社長 | **年次**／**法定・契約上のタイミング** |
| **単価改定の協議** | 材料費・労務費の変動に応じて単価を見直す | ① 営業 ＋ 社長 | **半期**（【Fact】4月・10月に改定する企業が比較的多い／出典：中小企業庁） |
| **金型・治具の保管と管理** | 顧客から預かった型・治具を保管し、次回生産に備える。定期的に状態を確認する | ⑤ 製造 ＋ ⑧ 設備保全 | **年次**／**受注時** |

> **なぜ是正処置報告書を出すのか**
> 【Typical】顧客が知りたいのは「代替品を早く送ってほしい」だけではありません。
> 「同じことが二度と起きない」ことを確認したいのです。
> なぜなら、その部品が顧客の製品に組み込まれて市場に出た後で不具合が出れば、
> 顧客がリコールや信用失墜という、はるかに大きな損害を受けるためです。
> **是正処置報告書は、取引を継続するための信頼の担保**として機能しています。

## 4-3. 「受注生産」と「見込生産」でフローはどう変わるか

`01_overview.md` 1-8 で説明した3つの生産形態のうち、**受注生産と見込生産ではフローの前半が根本的に変わります**。

### フローの対比

```
【受注生産（個別受注）の場合】

  ①引合い → ②仕様確認 → ③見積 → ④見積提出 → ⑤受注 → ⑥生産計画 → ⑦手配
       → ⑧受入 → ⑨製造 → ⑩工程内検査 → ⑪最終検査 → ⑫梱包 → ⑬納品 → ⑭検収 → ⑮請求 → ⑯入金
       ▲
       └─ 注文が起点。注文がなければ何も始まらない


【見込生産の場合】

  ①’需要予測・販売計画 → ②’生産計画（見込） → ③’材料手配 → ④’受入
       → ⑤’製造 → ⑥’検査 → ⑦’【製品在庫として保管】
                                      ↓
                          （ここで注文を待つ）
                                      ↓
  ⑧’受注（注文書・発注データ受領） → ⑨’在庫引当 → ⑩’ピッキング・梱包
       → ⑪’出荷・納品 → ⑫’検収 → ⑬’請求 → ⑭’入金
       ▲
       └─ 作るのは注文より前。注文が来たら在庫から出すだけ
```

### 主な違い（対比表）

| 項目 | **受注生産（個別受注）** | **見込生産** |
|---|---|---|
| 起点になる情報 | **注文書** | **需要予測・販売計画・在庫水準** |
| 見積のステップ | 案件ごとに必ず発生（③④） | 原則発生しない（価格表・定価がある） |
| 仕様の決定者 | 顧客 | 自社 |
| 作るタイミング | 受注後 | 受注前 |
| 在庫リスクの持ち主 | 自社は低い | **自社が全部負う** |
| 注文が来てから納品までの時間 | 長い（製造期間が必要） | 短い（在庫から出すだけ） |
| 生産計画の立て方 | 受注ごとにバックワードで日程を組む | 販売計画と在庫水準から、定期的に補充量を決める |
| 主に管理するもの | 納期、工数、進捗 | 在庫数量、在庫回転、欠品、賞味期限 |
| 追加で必要になる機能 | 見積機能、工程設計機能 | 需要予測、在庫管理、（食品では）期限管理 |
| 「作りすぎ」が起きたら | 原則起きない | 廃棄・値引きの損失 |
| 「作らなすぎ」が起きたら | 納期遅れ | **欠品**（売る機会を失い、顧客の信用も失う） |
| 【Example】代表的な業種 | 機械製造、金型、印刷、金属加工の一品物 | 食品、日用品、標準規格品 |

### 繰返生産（リピート生産）の場合

【Typical】繰返生産は両者の中間です。フローは次のようになります。

```
【繰返生産の場合】

  ①内示（フォーキャスト）受領  ← 顧客から3〜6か月先の見込み数量が届く
       ↓
  ②内示に基づく材料手配・生産計画   ← ★ここが自社のリスク。内示は約束ではない
       ↓
  ③確定注文（納入指示・かんばん）受領  ← 納入の1〜2週間前に確定数量が届く
       ↓
  ④製造 → ⑤検査 → ⑥出荷（指定日・指定数量）
       ↓
  ⑦検収 → ⑧請求（月次まとめ） → ⑨入金
```

| 繰返生産の特徴 | 内容 |
|---|---|
| 見積 | 【Typical】**初回のみ**。以降はその単価が継続する。だから初回の原価計算の精度が長期間効く |
| 図面・工程・治具 | 【Typical】**すでに確定している**ため、③生産技術のステップが省略される |
| 生産計画 | 【Typical】月次の大枠＋日次の調整 |
| 主なリスク | 【Typical】内示と確定注文の差（数量変動）、単価改定の難しさ、長期にわたる材料価格上昇 |
| 請求 | 【Typical】納入のたびではなく、**月次でまとめて請求**することが多い |

> **用語：かんばん**
> → 顧客が「この部品をこれだけ、この日に納入してほしい」と指示するための札（または電子データ）。
>   使った分だけ補充を指示する仕組みで、主に自動車産業で使われます。
> → 実務例：顧客が部品を使うと、その箱に付いていたかんばんが自社に戻ってくる。
>    自社はそのかんばんの枚数分だけ作って納める。
>    注文書を1件ずつ発行しなくても、継続的に補充が回る仕組み。

## 4-4. 【Example】1案件を最初から最後まで追跡する

> ### ⚠️ この節はすべて架空の例です
> 以下の企業名・金額・日付・数量は、**理解のために設定した架空のもの**であり、
> 実在企業の実績値でも、業界の平均値でもありません。

### 案件の概要

**X金属工業株式会社（`03_company-structure.md` のモデル企業）が、
A産業機械株式会社から「装置用ブラケット 1,000個」の注文を受けた案件**

| 項目 | 内容 |
|---|---|
| 顧客 | A産業機械株式会社（売上構成比35％の最大顧客） |
| 品名 | 装置用ブラケット（品番：AB-2041） |
| 数量 | 1,000個 |
| 材質 | SPCC（冷間圧延鋼板） t2.3 |
| 工程 | レーザー切断 → バリ取り → 曲げ → 溶接 → 亜鉛めっき（外注） → 検査 |
| 生産形態 | 繰返生産（2回目のリピート品。図面・治具は既存） |
| 希望納期 | 5月26日 |

### 日を追った記録

---

#### 【4月10日（金）】① 引合い受付 — 頻度：問い合わせ時

- **誰が**：営業担当の佐藤（架空の担当者名）
- **受け取ったもの**：A社の購買担当者からのメール。「AB-2041 を1,000個、5月26日納入でお願いしたい。単価は前回同様で見積をください」
- **やったこと**：過去の受注履歴を確認。1年前に500個を単価780円で納入した実績があることを確認。図面は最新版（Rev.B）のままか確認するメールを返信
- **できたもの**：引合い記録（案件番号 2026-0410-03）
- **次へ**：③ 生産技術へ見積依頼（数量が500→1,000に倍増しているため、単価を再計算する必要がある）

---

#### 【4月13日（月）】③ 見積（工程設計・原価計算） — 頻度：案件発生時

- **誰が**：生産技術担当の田中＋調達担当の鈴木（架空の担当者名）
- **受け取ったもの**：図面（Rev.B、変更なし）、数量1,000個、納期5月26日
- **やったこと**：前回の作業日報から実績工数を確認。材料単価の変動を商社に照会（前回比+8％の値上がり）。めっき外注の単価を外注先に照会。1,000個での段取り費の配賦を再計算

**原価の内訳【Example】**

| 費目 | 計算 | 金額 |
|---|---|---|
| 材料費 | 鋼板3.2枚 × 単価18,500円 ÷ 歩留まり0.85 | 69,600円 |
| 切断（レーザー） | 1.2分/個 × 1,000個 × レート6,000円/時 | 120,000円 |
| バリ取り | 0.8分/個 × 1,000個 × レート3,600円/時 | 48,000円 |
| 曲げ | 1.5分/個 × 1,000個 × レート4,800円/時 | 120,000円 |
| 溶接 | 2.2分/個 × 1,000個 × レート5,400円/時 | 198,000円 |
| 段取り（切断・曲げ・溶接 計90分） | 90分 × レート平均5,400円/時 | 8,100円 |
| めっき外注 | 72円/個 × 1,000個 | 72,000円 |
| 検査 | 抜取20個 ＋ 記録作成 計4時間 × 3,600円/時 | 14,400円 |
| 梱包・運賃 | 通い箱使用、納入1回 | 12,000円 |
| **製造原価 合計** | | **662,100円**（1個あたり約662円） |
| 販管費・利益 | 製造原価 × 22％ | 145,700円 |
| **見積金額** | | **807,800円** → 1個あたり **808円** |

- **できたもの**：原価内訳、見積金額（単価808円）
- **次へ**：① 営業へ。単価が前回780円から808円へ上昇するため、社長の承認を取得

> **なぜ数量が倍になったのに単価が上がったのか**
> 【Example】段取り費は数量が増えれば1個あたりは下がりました（500個時は約16円／個 → 1,000個時は約8円／個）。
> しかしそれを上回って**材料単価が8％上昇**したため、結果として単価が上がっています。
> このように、単価は「数量」と「材料相場」の両方で動きます。

---

#### 【4月15日（水）】④ 見積提出・価格交渉 — 頻度：案件発生時

- **誰が**：営業担当の佐藤（承認：社長）
- **やったこと**：見積書（単価808円、有効期限5月31日）をA社へ提出。材料単価の上昇分を示した資料を添付して説明。A社の購買担当から「795円にならないか」と打診され、社内で再検討
- **結果**：梱包を通い箱の再利用で簡素化することで、**単価800円**で合意
- **できたもの**：見積書（最終版、単価800円、金額800,000円）
- **次へ**：⑤ 受注待ち

---

#### 【4月20日（月）】⑤ 受注 — 頻度：受注時

## 4-5. 業種によってフローはどう変わるか【Varies】

`01_overview.md` 1-6 の Level 2 の6業種について、上記フローとの主な違いを整理します。

| 業種 | フロー上の主な違い |
|---|---|
| **食品製造** | 【Typical】見込生産が中心のため③④の見積ステップがなく、①’需要予測から始まる。⑨製造の前後に**衛生管理（HACCPに沿った衛生管理）の記録**が入る。⑪検査には微生物検査・官能検査が含まれる。⑫には賞味期限・消費期限の表示が必須。受注から納品までが1日以内のことも多い |
| **金属加工** | 本ファイルの基本フローそのもの。外注工程（めっき・熱処理・塗装）の往復がリードタイムを支配する |
| **機械製造** | 【Typical】⑤受注と⑨製造の間に**設計**の工程が入り、数週間〜数か月を要する。⑪検査は「試運転・動作確認」が中心。⑬納品後に**据付・立会い運転・引渡し**という工程が加わり、⑭検収はその完了をもって行われる。代金は着手金・中間金・完成時払いに分割されることがある |
| **電気機器** | 【Typical】⑦材料手配で**電子部品の調達期間が長い**（数か月のことも）ため、内示段階での先行手配が不可欠。⑨製造は基板実装が中心で機械依存度が高い。⑪検査に電気的特性試験が加わる。【Fact】電気用品安全法（昭和36年法律第234号）では、電気用品の製造・輸入の事業を行う者は事業開始の日から30日以内に経済産業大臣へ届け出る義務があり（第3条）、届出事業者は製造する電気用品が**特定電気用品**である場合、販売する時までに経済産業大臣の登録を受けた者の適合性検査を受け、証明書の交付を受けて保存しなければならない（第9条）（出典：電気用品安全法／e-Gov法令検索） |
| **化学・プラスチック** | 【Typical】⑨製造は「バッチ（釜単位）」で行われ、反応・成形・冷却に必要な時間は短縮できない。⑪検査は成分分析・物性試験。【Fact】消防法上の危険物を扱う場合、貯蔵・取扱いに関する許可と資格者の配置が必要 |
| **印刷** | 【Typical】②仕様確認の後に**校正（こうせい）**という工程が入る。顧客が内容を確認し、修正を指示し、再確認する往復が数回発生し、これがリードタイムの大半を占める。⑤受注後に版を作り（製版）、⑨印刷 → 加工（断裁・折り・製本）→ ⑪検査（色・文字）→ ⑬納品。刷り直しは全数が無駄になるため校了（こうりょう＝顧客の最終承認）の管理が要 |

## 4-6. このファイルのまとめ

1. 全社フローは17ステップ：引合い → 仕様確認 → 見積 → 見積提出 → 受注 → 生産計画 → 手配 → 受入 → 製造 → 工程内検査 → 最終検査 → 梱包 → 納品 → 検収 → 請求 → 入金 → アフター。
2. 受注生産は「注文が起点」、見込生産は「予測が起点」。この違いで前半のフローが根本的に変わる。
3. 繰返生産は内示と確定注文の2段階で動き、内示をどこまで信じて手配するかが自社のリスクになる。
4. 受注・納品・検収・売上・入金はすべて別の時点。混同すると製造業のお金の流れが理解できなくなる。
5. リードタイムの大半は待ち時間（材料調達・外注工程）であり、納期管理の実質は社外の進捗管理である。
6. 見積の精度が利益を決める。作る前にすべての原価を予測する必要がある。
7. 納品は終わりではなく、不具合対応・是正処置・単価改定・リピート受注へと続く。
