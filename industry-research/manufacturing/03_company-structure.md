## 3-1. 説明用モデル企業の設定

### ⚠️ 最重要の注意書き

> **【Example】以下の「X金属工業株式会社」は、本資料の説明を具体的にするために設定した架空のモデル企業です。**
> **実在企業ではなく、統計上の平均値・代表値でもありません。**
> **従業員数・売上高・顧客構成・部門別人数は、説明の一貫性のために置いた仮の数値です。**
> **実際の企業は業種・規模・地域・取引先によって大きく異なります（`01_overview.md` の Level 2 参照）。**

### なぜ金属加工の受託加工企業をモデルにするのか

【Inference】理由は3つあります。

1. 【Fact】事業所数でみると金属製品製造業が製造業計の13.6％と最も多い（2021年6月1日時点／令和3年経済センサス‐活動調査）。数の上で代表的である。
2. 【Typical】受託加工型は中小製造業に広く見られる形態であり、「顧客の図面で作る」という製造業の基本構造がもっとも素直に現れる。
3. 【Typical】受注生産・繰返生産・外注・支給材・検査・納期管理といった、製造業の主要な論点がひととおり登場する。

## 3-2. モデル企業のプロフィール【Example】

### 基本情報

| 項目 | 設定 |
|---|---|
| 商号 | **X金属工業株式会社**（架空） |
| 業種 | 金属加工（日本標準産業分類 中分類24 金属製品製造業 相当） |
| 事業内容 | 産業機械・装置向け板金加工品および機械加工部品の**受託製造**。顧客支給図面に基づく製作 |
| 創業 | 1968年（2代目社長が経営） |
| 資本金 | 3,000万円 |
| 従業員 | **45名**（正社員38名、パート・アルバイト5名、技能実習生2名） |
| 年商 | **約8億円** |
| 所在地 | 地方都市の工業団地 |
| 拠点 | 本社兼工場1か所（工場棟 約2,000㎡＋事務所棟） |
| 取得認証 | ISO 9001（品質マネジメントシステム） |
| 生産形態 | 個別受注生産 約8割／繰返生産 約2割（`01_overview.md` 1-8参照） |

> **中小企業基本法上の位置づけ**
> 【Fact】資本金3,000万円・従業員45名であり、中小企業基本法第2条第1項の「製造業その他の業種：
> 資本金3億円以下**または**従業員300人以下」に該当するため、中小企業にあたる。
> 【Fact】ただし従業員20人以下ではないため、「小規模企業」には該当しない。
> 【Inference】製造業の企業の83.9％が小規模企業（従業員20人以下）であることを踏まえると（2021年6月時点）、
> 本モデル企業は**中小製造業の中ではやや大きめ**の位置にある。
> これは、本資料で扱う10の機能をひととおり説明するために、機能がある程度分化している規模を選んだためである。

### 顧客構成【Example】

| 順位 | 顧客 | 業種・立ち位置 | 売上構成比 | 取引形態 |
|---|---|---|---|---|
| 1 | A産業機械株式会社 | 産業機械メーカー（自社にとってのTier1発注元） | **35％** | 直接取引。個別受注中心。月20〜40件の発注 |
| 2 | B装置工業株式会社 | 半導体製造装置向けの装置メーカー | **20％** | 直接取引。個別受注。大型・高精度品 |
| 3 | C商事株式会社 | 機械部品を扱う専門商社 | **15％** | 商社経由（帳合）。実際の使用先は複数のエンドユーザー |
| 4 | D自動車部品株式会社 | 自動車部品メーカー（Tier1） | **10％** | 繰返生産。内示＋確定注文。有償支給あり |
| 5〜25 | その他 約20社 | 地場の機械メーカー、設備業者など | **20％** | スポット受注が中心 |

> **この構成が示していること**
> 【Typical】上位2社で売上の55％、上位4社で80％を占める。
> 中小製造業でよく見られる**特定顧客への依存**の形である（`01_overview.md` 1-4参照）。
> 【Inference】A社の設備投資が一巡すれば、自社の受注はただちに減る。
> このため営業機能の役割は「新規開拓」よりも「既存顧客の生産計画を早く正確につかむこと」に比重が置かれやすい。

### 兼務の実態【Typical】

**中小製造業では、機能は必ず存在するが、独立した部署になるとは限りません。**
モデル企業でも次のような兼務が発生しています。

| 機能 | 兼務の実態 |
|---|---|
| **設備保全機能** | 専任者を置かず、製造部の熟練者2名が日常点検・簡易修理を兼務。大きな故障は設備メーカーに依頼 |
| **生産技術機能** | 1名のみ。繁忙期は生産管理と工程設計を兼ねる |
| **調達機能** | 2名のうち1名は生産管理と兼務。外注手配は生産管理側で行うことも多い |
| **出荷・物流機能** | 2名だが、繁忙時は製造部の人員が梱包を手伝う。運転は運送会社に委託 |
| **経理・人事・総務** | 実質2名で、経理・給与計算・社会保険・採用・庶務・安全衛生事務のすべてを担当。専務が統括 |
| **品質保証機能** | 3名。ISO 9001の事務局（文書管理・内部監査の運営）も兼務 |
| **経営** | 社長は最終的な見積承認・与信判断・金融機関対応・重要顧客対応を自ら行う |

> **なぜ兼務が起きるのか**
> 【Inference】45名規模では、1つの機能に専任者を1名割り当てると、その人が休んだ瞬間に機能が止まります。
> また、機能ごとの仕事量が1人分に満たないことも多くあります。
> このため「複数の機能を1人が持ち、互いにバックアップする」形が自然に生まれます。
> 本資料で**部署名ではなく機能で整理する**のはこのためです。
> 会社によって「生産管理部」が調達まで持つこともあれば、「業務部」が営業と受注を持つこともあります。

## 3-3. 組織・部署を「機能」で整理する

### 機能の一覧（本資料で一貫して使う10機能）

以下が、本資料の `04`〜`16` で一貫して使う機能の定義です。
**後続のすべてのファイルはこの10機能を前提にしてください。**

| # | 機能名 | 一言でいうと何をする機能か | 一般的な部署名称 | 【Varies】中小での独立性 |
|---|---|---|---|---|
| 1 | **営業機能** | 顧客との窓口となり、引合いを取り、見積を出し、受注を取り、価格を交渉する | 営業部、営業課、業務部 | 独立していることが多い。ただし社長が営業を兼ねる企業も多い |
| 2 | **受注・生産管理機能** | 受注情報を登録し、いつ何をどれだけ作るかを決め、進捗を追い、納期を守らせる | 生産管理部、業務部、工務、生産管理課 | **製造業の中枢**。小規模企業では社長や工場長が兼ねる |
| 3 | **生産技術（工程設計）機能** | 図面を見て「どの設備で、どの順番で、どれだけの時間で作るか」を決める。治具・プログラムを準備する | 生産技術課、技術部、製造技術 | 独立部署になることは少なく、製造や生産管理と兼務されることが多い |
| 4 | **調達機能** | 材料・部品・外注加工・消耗品を、必要な時期に必要な量だけ、適正な価格で手配する | 購買部、資材課、調達課 | 生産管理と一体化していることが多い |
| 5 | **製造機能** | 実際に材料を加工し、組み立て、製品にする | 製造部、工場、製造課、第一製造課／第二製造課 | 必ず独立して存在する。工程別に課が分かれることもある |
| 6 | **品質保証機能** | 「図面どおりにできているか」を確認し、記録を残し、不具合の原因を追究して再発を防ぐ | 品質保証部（品証）、検査課、QC | 独立させるかは企業差が大きい。製造部内の検査係としている企業も多い |
| 7 | **出荷・物流機能** | 完成品を梱包し、伝票を作り、指定日に指定場所へ届ける。入荷品の受入も担う | 出荷課、物流課、倉庫、資材倉庫 | 製造や調達と兼務されることが多い |
| 8 | **設備保全機能** | 設備が止まらないように点検・給油・部品交換を行い、故障時は復旧させる | 保全課、技術課、設備課 | 【Varies】専任者を置く企業は限られ、製造の熟練者が兼務することが多い |
| 9 | **経理・財務機能** | 売上・仕入・経費を記録し、請求・入金・支払を管理し、資金繰りと決算を行う | 経理部、総務経理、管理部 | 1〜2名であることが多い。税理士事務所に一部を委託することも多い |
| 10 | **人事・総務機能** | 採用・給与・社会保険・教育・安全衛生・庶務・法令対応を行う | 総務部、管理部、人事総務課 | 経理と一体であることが多い |

> **⚠️ 後続エージェントへの申し送り**
> `05_departments.md` では、上記10機能すべてについて methodology §7 の A〜O 15項目を記述してください。
> 「経営機能（社長・役員）」は独立した機能としては扱わず、各機能の**承認者・最終判断者**として
> 各機能の記述の中に登場させる方針とします。

### なぜ「部署」ではなく「機能」で整理するのか

| 部署で整理した場合の問題 | 機能で整理した場合 |
|---|---|
| 「営業部がある」と書くと、営業部がない会社の説明ができない | 「顧客窓口・見積・受注を担う営業機能は必ず存在する」と言える |
| 会社ごとに部署名が違い、比較できない（生産管理部／業務部／工務） | 機能名で統一すれば、どの会社にも当てはめられる |
| 兼務の実態が表現できない | 「1人が複数機能を持つ」と自然に表現できる |
| 部署がない＝その仕事をしていない、と誤解される | 「部署はないが機能は存在する（社長が兼ねている）」と正しく理解できる |

## 3-5. 生産管理機能が「中枢」である理由

【Inference】上の機能マップを見ると、**② 受注・生産管理機能がほぼすべての機能と接続している**ことがわかります。
これは偶然ではなく、製造業の構造上そうなります。

```
【製造業で「決めなければならないこと」と、それを決める機能】

  何を作るか      → 顧客と営業が決める
  どう作るか      → 生産技術が決める
  誰が作るか      → 製造が決める
  何で作るか      → 調達が手配する
  ★いつ作るか★    → 生産管理が決める  ← ここが全部をつなぐ
  正しくできたか   → 品質保証が判定する
  いつ届けるか    → 出荷・物流が実行する
```

【Typical】「いつ作るか」を決めるには、材料がいつ届くか、設備が空いているか、人がいるか、外注がいつ返してくるか、
顧客の希望納期はいつか——これらすべてを知っている必要があります。
だから生産管理機能は、自然とすべての情報が集まる場所になります。

【Varies】ただし、**専任の生産管理担当者を置けるかどうかは企業規模によって異なります**。
従業員10名規模では、社長または工場長が生産計画を頭の中で組み、ホワイトボードで管理していることも珍しくありません。
機能は必ず存在しますが、それが誰の仕事になっているかは企業により異なります。

## 3-6. 会社全体の数字の骨格【Example】

> ※以下は理解のための架空の例であり、実在企業の実績値でも業界平均でもありません。
> 実際の比率は業種・製品・取引条件により大きく異なります（`12_business-model.md` で詳述）。

### モデル企業の年間の姿【Example】

| 項目 | 金額 | 備考 |
|---|---|---|
| 売上高 | 800,000千円 | 年商8億円 |
| 材料費 | 240,000千円 | 売上の30％ |
| 外注加工費 | 120,000千円 | 売上の15％（めっき・熱処理・塗装等） |
| 労務費（製造部門の人件費） | 160,000千円 | 売上の20％ |
| 製造経費（電力・消耗品・減価償却等） | 120,000千円 | 売上の15％ |
| **売上原価 計** | **640,000千円** | 売上の80％ |
| **売上総利益（粗利）** | **160,000千円** | 売上の20％ |
| 販売費及び一般管理費 | 128,000千円 | 営業・管理部門の人件費、地代、通信費等 |
| **営業利益** | **32,000千円** | 売上の4％ |

> **用語：売上総利益（粗利）／営業利益**
> → 粗利＝売上高 − 売上原価。「モノを作って売った段階での儲け」。
> → 営業利益＝粗利 − 販売費及び一般管理費。「会社を運営した後に残った本業の儲け」。
> → 実務例：8億円売って粗利1.6億円でも、営業・経理・総務の人件費や家賃を払うと、
>    手元に残る本業の利益は3,200万円。**粗利が出ていても利益が出るとは限らない。**

### モデル企業の1件あたりの仕事の規模感【Example】

| 項目 | 目安 |
|---|---|
| 年間の受注件数 | 約1,800件（月平均150件） |
| 1件あたりの平均受注金額 | 約44万円 |
| 1件あたりの平均数量 | 【Varies】1個（一品物）〜数千個（繰返品）まで幅が大きい |
| 見積件数 | 年間約3,000件（受注率は約6割） |
| 標準的なリードタイム | 【Typical】2〜4週間（外注工程を含む場合は3〜6週間） |

## 3-7. 規模によって組織はどう変わるか【Varies】

モデル企業（45名）は中小製造業の中では機能が分化しているほうです。
規模が違えば組織の姿も変わるため、参考として整理します。

| 規模 | 【Typical】組織の姿 | 機能の持ち方 |
|---|---|---|
| **従業員5名以下**（小規模企業） | 社長＋家族＋職人数名。部署の概念がない | 社長が営業・見積・受注・生産計画・調達・経理を1人で担い、全員が製造を行う。経理は税理士に委託 |
| **従業員10〜20名**（小規模企業） | 社長／工場長／事務1〜2名／現場 | 社長が営業・見積・調達。工場長が生産計画・製造・品質。事務が受注入力・請求・給与 |
| **従業員20〜50名** | 営業／生産管理／製造／検査／総務経理 に分かれ始める | **モデル企業の位置**。機能ごとに担当者が付くが、設備保全・生産技術は兼務 |
| **従業員50〜100名** | 部・課の階層ができる | 品質保証・生産技術が独立部署になることが増える。工程別に製造課が分かれる |
| **従業員100〜300名** | 部門制になる | 設備保全・情報システム・安全衛生が専任化することが増える |

【Fact】製造業の企業のうち83.9％は従業員20人以下の小規模企業である（2021年6月時点／中小企業庁「産業別規模別企業数」2023年12月13日公表）。
【Inference】したがって、実際の中小製造業の多数派は上の表の1〜2行目に近い姿であり、
本資料のモデル企業は「機能を説明するために、機能が見えやすい規模を選んだ」ものであることに留意してください。

## 3-8. 中小製造業でよく見られる会社の特徴【Typical】

| 特徴 | 内容 |
|---|---|
| **社長が最終判断者** | 見積の最終承認、新規顧客の与信判断、設備投資、人事はほぼ社長が決める。稟議書を回さず口頭で決まることも多い |
| **工場長・現場リーダーの影響が大きい** | 日々の作業配分・優先順位は現場のリーダーが決めていることが多い |
| **技能が人に紐づいている** | 【Typical】「この溶接はこの人でないとできない」という状態が生じやすい。技能承継が継続的なテーマになる |
| **設備が会社の性格を決める** | 持っている設備でできる仕事しか受けられないため、設備投資の判断が事業内容を決める |
| **工場と事務所が同じ敷地にある** | 情報が口頭で素早く伝わる一方、記録として残りにくい面がある |
| **多能工化** | 1人が複数の機械を扱えるようにすることで、欠勤や繁閑に対応する |
| **家族経営の要素** | 【Varies】役員に親族が入っていることが多い。事業承継が経営上の大きな論点になる |
| **地域とのつながり** | 工業団地の組合、地元の商工会議所、近隣企業との相互外注などの関係を持つ |
