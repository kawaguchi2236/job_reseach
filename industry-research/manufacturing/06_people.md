# 06_people.md — ヒトの流れ（誰が誰と関わり、誰が決めるか）

**対象**：日本国内の中小製造業
**前提**：`03_company-structure.md`（10機能とモデル企業）／`04_end-to-end-process.md`（17ステップ）を読んでいること
**最終更新**：2026-09-16

> **このファイルは「従業員一覧」ではありません。**
> 追うのは次の2つです。
> 1. **誰が誰と関わるか**（社内の上下・横のつながり／社外との関係）
> 2. **誰が判断し、誰が承認し、誰が実行するか**（意思決定の所在）
>
> 製造業の仕事は「1人で完結する仕事がほとんどない」という特徴があります。
> 見積1つを出すにも、営業・生産技術・調達・社長の4者が関わります。
> したがって「誰が何をするか」だけでなく、**「誰から話が来て、誰へ渡すか」**を理解しないと、
> 実際の仕事の姿が見えません。

## 6-1. まず全体像：中小製造業のヒトの構図

### 社内の構図（モデル企業 X金属工業の場合）【Example】

```
                        ┌───────────────────────┐
                        │  社長（代表取締役）        │  ← 最終判断者
                        │  2代目。45名の会社の中心   │
                        └───────┬───────────┘
                                │
                   ┌────────────┼────────────┐
                   │            │            │
            ┌──────▼─────┐      │      ┌─────▼──────┐
            │ 専務（取締役） │      │      │  工場長      │
            │ 管理部門を統括 │      │      │  製造現場の長 │
            │ 経理・人事・総務│      │      │（製造機能の長）│
            └──────┬─────┘      │      └─────┬──────┘
                   │            │            │
       ┌───────────┴──┐   ┌─────┴──────┐  ┌──┴──────────────┐
       │              │   │            │  │                  │
  ┌────▼────┐ ┌──────▼─┐ ┌▼────────┐ ┌▼────────┐  ┌────────▼───┐
  │⑨経理・財務│ │⑩人事・総務│ │①営業機能 │ │②生産管理 │  │⑤製造機能（27名）│
  │  1名     │ │  1名     │ │  3名     │ │  3名     │  │ 工程ごとに班    │
  └─────────┘ └──────────┘ └─────────┘ └────┬────┘  │ 切断／曲げ／機械 │
                                                │       │ 加工／溶接／組立 │
                            ┌───────────────────┼───┐   │ 各班に「班長」   │
                            │                   │   │   └────────────────┘
                     ┌──────▼──┐ ┌──────▼─┐ ┌──▼──────┐ ┌──────────┐
                     │③生産技術  │ │④調達    │ │⑥品質保証 │ │⑦出荷・物流 │
                     │  1名      │ │  2名    │ │  3名     │ │  2名       │
                     └──────────┘ └─────────┘ └──────────┘ └──────────┘

                     ⑧設備保全機能：専任者なし。製造の熟練者2名が兼務
```

【Varies】上の図は45名規模の一例です。従業員10名の会社であれば、社長・工場長・事務員の3人がこの図の全部を持ちます。
**箱（機能）の数は変わりませんが、箱を持つ人の数が変わります。**

### 中小製造業のヒトの構図を理解する3つのポイント【Typical】

| ポイント | 内容 | なぜそうなるのか |
|---|---|---|
| **階層が浅い** | 社長 → 部門責任者 → 担当者、という2〜3階層で収まることが多い | 【Inference】人数が少なく、社長が全員の顔と仕事を把握できる規模のため。稟議書を何段階も回す仕組みを持たない企業が多い |
| **横のつながりが太い** | 隣の席の人、隣の工程の人に直接話す。書類で回さない | 【Inference】工場と事務所が同じ敷地にあり、歩いて行ける距離に関係者全員がいるため |
| **1人が複数の顔を持つ** | 同じ人が「調達担当」であり「生産管理担当」でもある | 【Typical】機能ごとの仕事量が1人分に満たないため（`03_company-structure.md` 3-2） |

## 6-2. 社内の関係：上下のつながり

### 役職とその役割【Typical】

製造業でよく使われる役職名と、その人が実際に何をしているかを整理します。
**役職名は会社によって異なります**（`03_company-structure.md` 3-3）。ここでは「その役割を担う人」として読んでください。

| 呼び名 | 【Typical】何をする人か | 誰と接するか |
|---|---|---|
| **社長（代表取締役）** | 会社全体の最終判断者。見積の最終承認、新規取引の可否、設備投資、採用、金融機関対応、重要顧客への訪問を自ら行う | 全機能／顧客の経営層・購買責任者／銀行／税理士／取引先社長 |
| **専務・常務（取締役）** | 【Varies】社長の親族であることが多い。管理部門（経理・人事・総務）を統括、または工場側を統括する | 経理・人事・総務／社長／金融機関 |
| **工場長（製造部長）** | 製造現場全体の責任者。日々の人員配置、作業の優先順位、残業の要否、設備トラブルの一次判断を行う | 生産管理／各班長／品質保証／設備保全／社長 |
| **職長（しょくちょう）／班長／組長** | **工程ごとの現場リーダー**。その工程の作業者に仕事を割り振り、進捗を見て、異常があれば止める。自分も作業する | 自工程の作業者／前後工程の班長／工場長／品質保証 |
| **作業者（オペレーター／技能者）** | 実際に機械を動かし、加工・組立を行う。作業日報を書く | 自工程の班長／前後工程の作業者／検査員 |
| **担当者（営業担当・生産管理担当 等）** | 各機能の実務を担う。会社によっては「主任」「係長」の肩書が付く | 社外（顧客・仕入先）／他機能の担当者／社長 |

> **用語：職長（しょくちょう）**
> → 作業者を直接指揮・監督する現場の責任者のこと。「班長」「組長」「リーダー」など呼び方は企業により異なります。
> → 実務例：溶接班の職長は、朝に製造指示書を見て「この注文は田中さん、こっちは佐々木さん」と割り振り、
>    昼過ぎに進み具合を見て回り、遅れていれば応援を入れるか工場長に相談します。
> → **なぜこの役割が必要か**：生産管理機能が作るのは「どの工程を何日までに終える」という計画までで、
>    「誰がどの機械で何時から」という最終の割り振りは現場でしかできません。
>    人の得意・不得意、当日の欠勤、機械の調子は、現場にいる人しか分からないためです。

> **【Fact】職長教育は法令上の義務です**
> 労働安全衛生法第60条は、新たに職務につくことになった職長その他の作業中の労働者を直接指導または監督する者に対し、
> 安全または衛生のための教育を行うことを事業者に義務づけています
> （出典：労働安全衛生法／e-Gov法令検索）。
> 【Typical】このため製造業では「職長・安全衛生責任者教育」を外部機関で受講させることが一般的です。

### 指示はどう流れるか【Typical】

```
【計画の指示（何を、いつまでに）】

  顧客の注文 → ① 営業機能 → ② 生産管理機能 → ⑤ 製造機能（工場長）
                                                    ↓
                                             各工程の職長・班長
                                                    ↓
                                                 作業者

【現場の判断（誰が、どの機械で、今日）】

  工場長 ←→ 職長・班長 ←→ 作業者     ← 日次で、その場で決まる


【異常の連絡（止まった、できない、間に合わない）】

  作業者 → 職長・班長 → 工場長 → ② 生産管理機能 → ① 営業機能 → 顧客
                          ↓
                    ⑧ 設備保全／⑥ 品質保証
```

> **ここが製造業の実務で重要なところ**
> 【Typical】上から下への流れ（計画）と、下から上への流れ（異常）は、**別のルートではなく同じ人たちを逆向きに通ります**。
> 異常が上がってこないと、生産管理機能は納期の遅れに気づけず、営業機能は顧客に事前連絡ができません。
> 顧客にとって「納期が遅れる」こと自体よりも、「当日まで知らされなかった」ことのほうが問題になります。
> **異常を早く上げる連絡経路が成立しているかどうかが、納期遵守の実質**です。

## 6-3. 社内の関係：横のつながり（機能間）

`03_company-structure.md` 3-4 の機能マップを、**「人と人」の視点**で言い換えます。

### 日常的に会話が発生する組み合わせ【Typical】

| 誰と誰 | 何について話すか | 頻度 |
|---|---|---|
| 営業担当 ⇄ 生産管理担当 | 「この注文、いつ出せる？」「納期を1週間早められないか」 | **日次**／**受注時** |
| 生産管理担当 ⇄ 工場長 | 「明日からこれを流したい」「今週はもう入らない」 | **日次** |
| 生産管理担当 ⇄ 調達担当 | 「この材料いつ入る？」「外注の戻りは？」 | **日次** |
| 工場長 ⇄ 各職長 | 「今日はどこまで進んだ」「誰を応援に回す」 | **日次** |
| 職長 ⇄ 作業者 | 作業の割り振り、段取りの相談、異常の報告 | **常時** |
| 品質保証担当 ⇄ 製造の作業者 | 「この寸法、狙いを少し外している」「初品を見てほしい」 | **常時**／**トラブル発生時** |
| 出荷担当 ⇄ 生産管理担当 | 「今日の出荷分、まだ検査から上がってこない」 | **日次** |
| 経理担当 ⇄ 営業担当 | 「A社の入金が合わない」「この請求、単価が違う」 | **月次**／**入金時** |
| 生産技術担当 ⇄ 作業者 | 「この治具、使いにくくないか」「プログラムを直した」 | **案件発生時** |
| 人事・総務担当 ⇄ 全員 | 勤怠、資格の有効期限、健康診断、安全衛生 | **月次**／**年次** |

> **【Typical】「会議」より「その場の会話」が多い**
> 中小製造業では、朝礼・生産会議といった定例の場のほかに、**現場での立ち話**で多くのことが決まります。
> 工場と事務所が同じ敷地にあるため、生産管理担当が工場に歩いて行き、職長と5分話して調整が済む、という形が成り立ちます。
> 【Varies】どの程度を会議体にし、どの程度を口頭で済ませるかは企業により大きく異なります。
> なお、口頭で決めたことは記録に残りにくいため、後から「言った・言わない」になりやすい性質があります
> （情報の媒体については `09_information.md` で扱います）。

### 【Typical】よく設けられる定例の場

| 場の名前（例） | 誰が出るか | 何を決めるか | 頻度 |
|---|---|---|---|
| 朝礼 | 全員、または製造部門全員 | 当日の予定、安全に関する注意喚起、連絡事項 | **日次** |
| 生産会議／工程会議 | 生産管理、工場長、各職長、調達 | 今週の生産順序、遅れている案件の対応、材料・外注の状況 | **週次** |
| 品質会議／不適合検討会 | 品質保証、工場長、生産技術、該当工程の職長 | 発生した不適合の原因と対策 | **月次**／**トラブル発生時** |
| 安全衛生委員会 | 【Fact】法定の構成（後述） | 労働災害の防止に関する事項 | **月次** |
| 役員会・経営会議 | 社長、専務、各機能の責任者 | 受注状況、資金繰り、設備投資、人員 | **月次** |

> **【Fact】安全衛生委員会は法令上の設置義務があります**
> 労働安全衛生法第18条により、常時50人以上の労働者を使用する事業場では**衛生委員会**を設置しなければなりません。
> また同法第17条と労働安全衛生法施行令第8条により、**金属製品製造業・化学工業・鉄鋼業・木材木製品製造業・輸送用機械器具製造業**などでは
> 常時50人以上、その他の製造業では常時100人以上の事業場で**安全委員会**を設置しなければなりません
> （出典：労働安全衛生法施行令／e-Gov法令検索）。
> 【Fact】労働安全衛生法施行令第2条により、**総括安全衛生管理者**は製造業では常時300人以上の事業場で選任義務があります（同上）。
> 【Fact】常時10人以上50人未満の事業場では、労働安全衛生法第12条の2により**安全衛生推進者**の選任が必要です
> （出典：労働安全衛生法／e-Gov法令検索）。
> 【Example】モデル企業は45名のため、安全衛生推進者の選任対象にあたり、安全委員会・衛生委員会の法定設置義務の規模には達していません。
> 【Varies】法定義務がなくても、任意に安全衛生の会議を設けている企業もあります。
> 詳細は `15_rules-customs.md` を参照してください。

## 6-4. 社外との関係：誰が誰と話すか

製造業の仕事は社内で完結しません。**社外の誰と、社内の誰が接するのか**を整理します。

### 社外関係者と社内の窓口【Typical】

| 社外の相手 | 相手側の担当者 | 自社側の主な窓口 | 何を話すか | 頻度 |
|---|---|---|---|---|
| **顧客（発注元）** | 購買担当（バイヤー） | ① 営業担当 | 見積、単価、納期、発注数量、支払条件 | **常時**／**案件発生時** |
| 同上 | 設計者・技術者 | ① 営業担当＋③ 生産技術担当 | 図面の内容、公差、材質、作りやすさの相談 | **案件発生時** |
| 同上 | 受入検査・品質保証 | ⑥ 品質保証担当 | 検査成績書の内容、不適合の連絡、是正処置 | **納品時**／**トラブル発生時** |
| 同上 | 生産管理・資材 | ② 生産管理担当 | 納入日時の調整、内示の変更、在庫状況 | **日次**／**週次** |
| 同上 | 受入・倉庫 | ⑦ 出荷・物流担当 | 納入口、時間指定、荷姿、通い箱の返却 | **納品時** |
| 同上 | 経理・支払 | ⑨ 経理担当 | 請求内容の照合、支払通知、相殺の明細 | **月次**／**入金時** |
| 同上 | 経営層・購買責任者 | **社長** | 年間の取引方針、単価改定、新規案件、工場監査 | **半期**／**年次** |
| **仕入先（材料商社・メーカー）** | 営業担当 | ④ 調達担当 | 材料の価格、納期、在庫、相場動向 | **日次**／**発注時** |
| **外注先（めっき・熱処理・塗装等）** | 営業・工務 | ④ 調達担当＋② 生産管理担当 | 加工単価、空き状況、納期、品質 | **発注時**／**週次** |
| **運送会社** | 営業・配車担当 | ⑦ 出荷・物流担当 | 集荷時間、便の手配、運賃 | **日次**／**納品時** |
| **設備メーカー・保守業者** | サービス担当 | ⑧ 設備保全（兼務者）＋工場長 | 故障の修理、定期点検、部品供給 | **トラブル発生時**／**年次** |
| **金融機関（銀行）** | 融資担当 | **社長**＋⑨ 経理担当 | 借入、返済、資金繰り、設備投資の相談 | **月次**／**四半期** |
| **税理士・会計事務所** | 担当会計士・職員 | ⑨ 経理担当＋社長 | 月次試算表、決算、税務申告 | **月次**／**年次** |
| **社会保険労務士** | 担当者 | ⑩ 人事・総務担当 | 社会保険、給与計算、労務相談 | **月次** |
| **労働基準監督署・年金事務所** | 担当官 | ⑩ 人事・総務担当＋社長 | 労災、届出、調査 | **法定・契約上のタイミング**／**トラブル発生時** |
| **消防署・自治体** | 担当官 | ⑩ 人事・総務担当＋工場長 | 危険物、消防設備、排水・廃棄物の届出 | **年次**／**法定・契約上のタイミング** |
| **ISO審査機関** | 審査員 | ⑥ 品質保証（ISO事務局） | 定期審査、更新審査 | **年次** |
| **人材紹介・求人媒体・学校** | 担当者 | ⑩ 人事・総務担当＋社長 | 採用 | **年次**／**案件発生時** |
| **工業団地組合・商工会議所・業界団体** | 事務局 | 社長＋⑩ 総務 | 地域の情報交換、共同での取り組み | **年次** |

> **ここが初心者のつまずきどころ**
> 【Typical】「顧客＝営業が対応する相手」ではありません。
> **1社の顧客の中に、話す相手が5〜6人いて、それぞれ自社側の別の人が対応します。**
> 顧客の購買担当は価格と納期を見ており、設計者は図面どおりかを見ており、受入検査は品質を見ており、
> 経理は金額を見ています。この4人は、同じ会社にいても互いの事情を知らないことがあります。
> 【Example】購買担当と「単価を下げる代わりに数量をまとめる」と合意しても、
> 顧客の生産管理が従来どおりの小口納入を求めてくれば、実際にはまとめて作れません。
> **社外との関係は「会社対会社」ではなく「担当者対担当者」の束**である、という理解が実務では重要になります。

## 6-5. 簡易RACI：誰が決めて、誰がやるのか

### RACIとは何か（初心者向け）

> **用語：RACI（レイシー）**
> → 1つの仕事について、関わる人の役割を4つに分けて整理する考え方です。
>   4つの頭文字を取って RACI と呼びます。
>
> | 記号 | 英語 | 日本語で言うと | 中身 |
> |---|---|---|---|
> | **R** | Responsible | **実行する人** | 実際に手を動かして作業する人。複数いてもよい |
> | **A** | Accountable | **承認する人・責任を負う人** | 最終的に「これでよい」と決める人。**1つの仕事に1人** |
> | **C** | Consulted | **相談される人** | 決める前に意見を聞く人。双方向のやり取りがある |
> | **I** | Informed | **報告を受ける人** | 決まった後に知らされる人。一方向の連絡でよい |
>
> → 実務例：見積書を作る仕事であれば、
>   生産技術担当が工程と時間を計算し（**R**）、
>   調達担当に材料価格を聞き（**C**）、
>   営業担当が見積書の形にまとめて（**R**）、
>   社長が金額を見て「出してよい」と決め（**A**）、
>   生産管理担当には「この納期で見積を出した」と伝えておく（**I**）。
>
> → **なぜこれを整理するのか**：
>   「やる人」と「決める人」を分けて考えないと、
>   「誰かがやっていると思っていたら、誰もやっていなかった」
>   「担当者が独断で決めてしまい、後で社長がひっくり返した」といったことが起きます。
>   特に中小企業では兼務が多いため、**同じ人が R でもあり A でもある**ことがよくあり、
>   その場合は「この人が止まると仕事が全部止まる」という構造になります。

### この表から読み取れること

> **1. 【Typical】A（承認）の欄に「社長」が非常に多く現れる**
> 20項目のうち、社長が承認者または承認者候補になっているものが11項目あります。
> 【Inference】これは中小製造業の構造上の特徴です。理由は次のとおりです。
> - 会社の資産（現金・設備）を動かす判断は、所有者である社長がすることになる
> - 顧客との取引条件は、会社としての約束であり、社長が責任を負う
> - 45名程度であれば、社長が全案件を把握することが物理的に可能である
>
> 【Typical】このため、**社長の不在が業務の停滞につながる**場面が生じます。
> 社長が出張中でも進むように、「○○円まではこの人が決めてよい」という基準を設けている企業が多く見られます。
> 【Varies】その基準の有無・水準は企業により異なります。

> **2. 【Typical】C（相談）の欄に製造現場（工場長・職長）が繰り返し出てくる**
> 見積、納期回答、生産順序、外注判断——どれも「実際に作れるのか」を現場に確認しないと決められません。
> 【Inference】製造業では、**決める人（事務所側）と、できるかどうかを知っている人（現場側）が別**であるため、
> 両者の行き来が仕事の中身の大部分を占めます。

> **3. 【Typical】R（実行）が複数機能にまたがる仕事が多い**
> 見積（#3）は3機能、設備投資（#16）は3機能が実行に関わります。
> 【Inference】これが「製造業の仕事は1人で完結しない」と言われる理由です。

## 6-6. 現場のヒトを理解する3つの概念

### (1) 多能工（たのうこう）

> **用語：多能工**
> → 1人の作業者が、複数の工程・複数の機械を扱えるようにすること。またはそのような作業者。
>   反対に、1つの工程しかできない状態を「単能工」と呼びます。
> → 実務例：溶接しかできなかった作業者が、曲げ（ベンディングマシン）の操作も覚える。
>    溶接の仕事が少ない日は曲げ工程を手伝える。
>
> **なぜ多能工化するのか**【Typical】
> | 理由 | 説明 |
> |---|---|
> | 欠勤・休暇に対応するため | 1工程1人では、その人が休むと工程が止まる |
> | 仕事量の波に対応するため | 受注は工程ごとに均等には来ない。今週は溶接が多く、来週は曲げが多い、という波がある |
> | 少人数で工場を回すため | 45名で5工程を動かすには、固定配置では人が足りない場面が出る |
>
> 【Typical】一方で、多能工化には**教育の時間**がかかります。
> 溶接や機械加工は、資格を取れば即できるという性質のものではなく、実作業の経験を要します。
> このため中小製造業では、「どの人がどの工程をどの水準までできるか」を一覧にした表
> （**スキルマップ／力量表**と呼ばれることが多い）を作って管理することが広く見られます【Typical】。
> 【Fact】ISO 9001 では、製品・サービスの適合に影響する業務を行う人の「力量」を明確にし、
> 必要な力量を持つことを確実にし、その証拠を文書化した情報として保持することが要求されています（箇条7.2 力量）。

### (2) 技能承継（ぎのうしょうけい）

> **用語：技能承継**
> → 熟練した作業者が持っている技能を、次の世代の作業者に引き継ぐこと。
> → 実務例：40年の経験を持つ溶接工が、図面に書かれていない「この材質はこの順番で溶接しないと歪む」という
>    判断を、若手に伝えていく。
>
> **なぜ製造業でこれが継続的な論点になるのか**【Typical】
> 1. **図面や作業標準書に書き切れない判断がある**
>    【Example】「今日は湿度が高いから塗装の乾燥を長めに取る」「この鋼材はロットによって硬さが違うので送り速度を落とす」
>    といった判断は、文章にしにくく、経験の中にあります。
> 2. **技能が人に紐づく**（`03_company-structure.md` 3-8）
>    「この加工はこの人でないとできない」という状態が生じると、その人の休暇・退職が事業の制約になります。
> 3. **教えるには時間と、教える側の余裕が必要**
>    熟練者は最も忙しい人でもあるため、教育の時間をどう確保するかが論点になります。
>
> 【Fact】製造業の就業者数は2023年に1,055万人、2024年に1,046万人と推移しています
> （出典：2025年版ものづくり白書／経済産業省・厚生労働省・文部科学省、原資料は総務省「労働力調査」）。
>
> 【Typical】中小製造業で一般的に見られる承継の方法は次のとおりです。
> - OJT（実際の作業を一緒に行いながら教える）
> - 作業標準書・要領書に、判断の理由まで書き込む
> - 作業の様子を記録に残す（媒体は企業により異なる【Varies】）
> - 技能検定など、公的な資格取得を目標に置く

> **用語：技能検定**
> → 【Fact】職業能力開発促進法に基づき、働く人の技能の程度を国が定めた基準で検定し、
>   公証する国家検定制度です。合格者には「技能士」の称号が付与されます（出典：技能検定制度／厚生労働省）。
> → 実務例：「機械加工（普通旋盤作業）1級」「金属プレス加工」「溶接」など、製造業に関係する職種が多数あります。
>    社内の技能水準を客観的に示す目安として使われます。

### (3) 兼務が生む「その人が止まると業務が止まる」構造

【Typical】`03_company-structure.md` 3-2 のとおり、中小製造業では兼務が常態です。
ヒトの視点で見ると、これは次のことを意味します。

| 【Example】兼務の例 | その人が不在になると何が起きるか |
|---|---|
| 生産管理担当が調達も兼ねている | 材料発注が止まり、翌週以降の生産計画も止まる |
| 品質保証担当がISO事務局も兼ねている | 検査が滞り、審査対応の準備も止まる |
| 経理担当1名が請求・支払・給与を担っている | 締め日をまたぐと、請求書の発行が遅れ、入金も遅れる |
| 社長が営業と与信判断を担っている | 新規案件の見積承認が止まる |

> 【Inference】このため中小製造業では、**「担当を2人にする」よりも「1人が休んでもその期間は誰かが代わる」**という形での
> 備えが取られることが多くなります。具体的には、業務の手順を書き残す、複数人が同じ画面を見られるようにする、
> 締め日の前後に休暇を取らない、といった運用です。
> 【Varies】どこまで備えるかは企業により大きく異なります。

## 6-8. 業種によってヒトの関わり方はどう変わるか【Varies】

`01_overview.md` 1-6 の Level 2 の6業種について、ヒトの視点での違いを整理します。

| 業種 | 【Typical】ヒトの関わり方の特徴 |
|---|---|
| **食品製造** | 見込生産が中心のため、**営業と生産管理の間で「販売計画」をめぐるやり取り**が日常業務になる。衛生管理の責任者（食品衛生責任者、HACCPの管理担当）が置かれ、現場作業者への衛生教育が定期的に行われる。パート・アルバイトの比率が高い企業が多く、多数の短時間勤務者をどう配置するかが現場リーダーの主要な仕事になる |
| **金属加工** | 本ファイルの基本形。**外注先との関係を誰が持つか**が実務上の要点になる（調達担当か、生産管理担当か、社長か）。技能が人に紐づきやすく、技能承継が継続的な論点 |
| **機械製造** | 受注後に**設計者**が入るため、設計・生産技術・製造の三者のやり取りが長期間続く。据付・試運転で**顧客の工場に自社の人が出向く**ため、サービス担当という役割が生まれる。顧客の設備担当者との長期的な関係ができる |
| **電気機器** | 部品調達の期間が長いため、**調達担当と顧客の生産管理の直接のやり取り**が増える（内示の精度を詰める必要があるため）。基板実装は機械依存度が高く、設備の段取り・保守を担う人の役割が相対的に大きい |
| **化学・プラスチック** | 【Fact】消防法上の危険物を扱う場合、**危険物保安監督者**の選任が必要になる（`15_rules-customs.md` 参照）。毒物劇物を扱う場合は【Fact】毒物及び劇物取締法第7条により**毒物劇物取扱責任者**の設置が必要（出典：毒物及び劇物取締法／e-Gov法令検索）。**有資格者が現場にいないと操業できない**構造があり、資格者の配置が人員計画の制約になる |
| **印刷** | 顧客との**校正（内容確認）のやり取り**が業務の中心にあり、営業担当が顧客とデータ制作担当の間を何度も往復する。校了（顧客の最終承認）を誰がどう確認するかが、刷り直しを防ぐ要になる |

## 6-9. このファイルのまとめ

1. 中小製造業の組織は階層が浅く、横のつながりが太い。1人が複数の機能を持つ。
2. 現場には**職長・班長**という役割があり、当日の人員配置と作業の割り振りを担う。計画は生産管理が作るが、最終的な割り振りは現場でしかできない。
3. 社外との関係は「会社対会社」ではなく「担当者対担当者」の束である。1社の顧客の中に、話す相手が複数いる。
4. RACI（実行・承認・相談・報告）で整理すると、**中小製造業では多くの意思決定の承認者が社長**である。
5. 見積・納期回答・生産順序といった主要な判断は、**事務所側（決める人）と現場側（できるかを知っている人）の往復**で成立している。
6. 多能工化と技能承継は、少人数で工場を回すという構造から生じる継続的なテーマである。
7. 1案件には社内のほぼ全機能と、社外の複数社が関わる。仕事の多くは「確認の往復」でできている。
