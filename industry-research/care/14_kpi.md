**対象**：日本国内の中小の介護事業者
**読み手**：介護・福祉をまったく知らない人
**最終更新**：2026-09-20

> 使う説明用モデルは `03_company-structure.md` の
> **「S デイサービスセンター」**（通所介護・利用定員30名・1日平均利用者25名・従業員20名程度）と、

## 14-0. この章の前提

### KPIとは何か

> **用語：KPI（Key Performance Indicator／重要業績評価指標）**
> → 「うまくいっているか」を判断するために、日常的に見ている数字のこと。
> → 実務例：デイサービスでは「今日は定員30名に対して何人来たか」を毎日見る。
>    これが減り続けていれば、2か月後の入金が減ることが分かる。

### 本資料での数値の扱い【重要】

```
✓ 出典のある統計は【Fact】として、年度・出典とともに示す
✓ 計算の仕組み（式）は示す
✕ 「稼働率は○%が目安」といった業界水準の数値は、出典がない限り示さない【Varies】
✕ 「この数字を改善すべき」といった提案・評価は書かない
```

`19_sources.md` §5 のとおり、**事業所の経営指標（人件費率等）は本調査の範囲外**です。
したがって本章では、**数値の目安を示さず、何を見ているか・なぜ見るかを説明します**。

## 14-1. まず全体の分解式を押さえる

### 収入を分解する

```
   月の介護報酬
     ＝ 総単位数 × 1単位あたりの単価
     ＝ （利用者1人あたりの単位数 × 延べ利用者数） × 単価
     ＝ （1日あたりの単位数 × 1人あたりの利用回数 × 実利用者数） × 単価

   通所介護では、これを「器」の側から見ると次のようになる：

   月の介護報酬
     ＝ 利用定員 × 稼働率 × 営業日数 × 1日あたりの平均単位数 × 単価
         │          │          │          │                    │
         │          │          │          │                    └─ 【Fact】地域区分で決まる。事業所は選べない
         │          │          │          └─ 要介護度の構成＋加算・減算で変わる
         │          │          └─ 営業日（【Varies】）
         │          └─ ★事業所が動かせる中心的な変数
         └─ 【Fact】面積で制約される（基準第95条第2項第1号イ）。簡単には変えられない
```

> **この式から、見るべき数字が決まる**
> 【Inference】事業所が日常的に見ている数字は、この式の各項に対応しています。
> - 利用定員　→ 固定（設備と人員）
> - **稼働率**　→ 毎日見る
> - 営業日数　→ 固定
> - 1日あたりの平均単位数 → 要介護度の構成、加算の算定状況
> - 単価　　　→ 固定（地域区分）
>
> つまり、**日々見る数字の中心は「稼働率」**になります。

### 「稼働率 × 単価 ＝ 収入」を初心者向けに言い換える

```
【Example】説明用の架空の計算です。1単位＝10円として計算します。
          実際の単価は地域区分により異なります【Varies】。

  器（定員）           30名分の席がある
  今日埋まった席       25名         → 稼働率 25 ÷ 30 ≒ 83.3%
  1席あたりの値段      777単位      （要介護2・7時間以上8時間未満の場合。
                                     出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）
  ────────────────────────────────────────────
  今日の売上  = 777単位 × 25名 = 19,425単位
              = 19,425単位 × 10円 = 194,250円

  もし席が30名埋まっていたら
              = 777単位 × 30名 = 23,310単位 = 233,100円  （＋38,850円）

  空いていた5席は、**その日のうちに取り戻せません。**
  （飛行機の座席や宿泊施設の客室と同じ性質です）
```

> **在庫の効かない事業である【Inference】**
> 製造業なら、今日作らなかった分を明日作れます。
> 通所介護は、**今日空いた席を明日に持ち越せません。**
> だから稼働率を毎日見ることになります。

## 14-2. 稼働率に関する数字

### (1) 稼働率

| 項目 | 内容 |
|---|---|
| **計算式** | 1日平均利用者数 ÷ 利用定員 |
| **誰が見るか** | ①管理者・②生活相談員・経営者 |
| **いつ見るか** | 日次（当日の実績）／週次・月次（平均） |
| **なぜ見るか** | 【Inference】収入をほぼ決める。定員は簡単に変えられないため、器をどれだけ埋められたかが収益に直結する |
| **数値の目安** | **【Varies】事業所により異なる。本資料では目安を示しません** |

**参考になる【Fact】の統計（施設系）**

【Fact】介護保険施設の利用率は次のとおりです
（出典：令和6年介護サービス施設・事業所調査の概況 表3／厚生労働省。2024年10月1日現在）。

| 施設 | 1施設当たり定員 | 利用率 |
|---|---|---|
| 介護老人福祉施設 | 70.4人 | 94.5% |
| 介護老人保健施設 | 87.0人 | 88.2% |
| 介護医療院 | 58.2人 | 91.1% |

> **注意：これは施設系の数値であり、通所介護の稼働率ではありません**
> 施設系は入所者が毎日そこで生活しているため、利用率は空床の有無で決まります。
> 通所介護は、利用者が曜日ごとに入れ替わります。**同じ「率」でも意味が違います。**
> 通所介護の稼働率の統計は本調査では取得していません【Varies】。

### (2) 曜日別の稼働率【Typical】

| 項目 | 内容 |
|---|---|
| **計算式** | 曜日ごとの利用者数 ÷ 利用定員 |
| **なぜ見るか** | 【Inference】月平均では見えない偏りを把握するため |

```
【Example】説明用の架空の例です

  定員30名の事業所
    月曜 30名（100.0%）  火曜 18名（60.0%）  水曜 29名（96.7%）
    木曜 20名（66.7%）   金曜 28名（93.3%）  土曜 25名（83.3%）
    ─────────────────────────────────────
    平均 25.0名（83.3%）

  平均だけ見れば83.3%だが、**火曜と木曜は器が3分の1以上空いている。**
  一方、月曜は満員で、これ以上受け入れられない。
```

> **なぜ偏りが問題として見られるのか【Inference】**
> 1. 空いている曜日の分、収入が発生していない
> 2. 【Fact】介護職員の必要数は利用者数に応じて決まる（基準第93条第1項第3号）。
>    人数の少ない曜日は必要人数が減るが、**常勤職員の勤務時間は曜日で変えにくい**
> 3. 満員の曜日には新規の利用者を受け入れられない
>
> **本資料は「偏りを解消すべき」といった提案は書きません。**
> ここで説明しているのは、**なぜこの数字を分けて見るのか**という理由です。

### (3) キャンセル率

| 項目 | 内容 |
|---|---|
| **計算式** | キャンセル数 ÷ 予定利用者数 |
| **誰が見るか** | ②生活相談員・①管理者 |
| **いつ見るか** | 日次／月次 |
| **なぜ見るか** | 【Inference】予定が入っていても、当日欠席があれば収入にならない。食材費だけが残ることもある（`07_goods.md` 7-5） |
| **数値の目安** | **【Varies】** |

> **キャンセルの理由は収入とは別の意味も持つ【Inference】**
> 体調不良によるキャンセルが増えている利用者は、状態が変化している可能性があります。
> つまり、キャンセルの記録は**利用者の状態変化を知る手がかり**でもあります。
> この情報は⑨ケアマネジャーへの報告情報につながります（`09_information.md` 9-5）。

### (4) 新規利用者数・利用終了者数

| 項目 | 内容 |
|---|---|
| **計算式** | 月ごとの新規契約者数／利用終了者数 |
| **誰が見るか** | ②生活相談員・①管理者 |
| **いつ見るか** | 月次 |
| **なぜ見るか** | 【Inference】利用者は入院・入所・転居・死亡により必ず減っていく。減った分を新規で埋められなければ、稼働率は下がり続ける |

```
【Example】説明用の架空の例です

  9月  実利用者60名  新規 2名  終了 3名  → 10月 59名
  10月 実利用者59名  新規 1名  終了 4名  → 11月 56名
  11月 実利用者56名  新規 3名  終了 2名  → 12月 57名

  【Inference】終了は事業所の都合では止められない（入院・死亡等）。
  だから「新規が何名入ったか」は毎月確認される数字になる。
```

> **利用終了の理由を分けて見る【Typical】**
> 入院／施設入所／転居／死亡／他事業所への変更／利用者・家族の希望による中止。
> 【Inference】理由によって意味が違います。
> 「他事業所への変更」が続いているなら、それは事業所に関わる事情の可能性があります。

### (5) 実利用者数と延べ利用者数

> **この2つを混同しないこと**
> ```
> 実利用者数  ： その月に1回でも利用した人の数（頭数）
> 延べ利用者数： その月の利用回数の合計
> ```
> 【Example】60名が平均8回利用した月 → 実利用者数 60名、延べ利用者数 480回。
>
> 【Inference】収入に直結するのは**延べ利用者数**です。
> 一方、**実利用者数**は「何人の生活に関わっているか」を示し、
> 人員配置（【Fact】基準第93条第1項第3号は「利用者の数」で必要数を決める）にも関わります。

## 14-3. 単位数・報酬に関する数字

### (6) 総単位数

| 項目 | 内容 |
|---|---|
| **計算式** | その月に算定したすべての単位数の合計（基本報酬＋加算−減算） |
| **誰が見るか** | ⑨請求事務・①管理者・経営者 |
| **いつ見るか** | 月次（実績確定時） |
| **なぜ見るか** | 【Inference】**請求額の確定前に、その月の収入の大きさが分かる唯一の数字**。単価を掛ければ金額になる |

> **入金より2か月早く分かる数字【Inference】**
> `08_money.md` 8-8 のとおり、保険給付分の入金はサービス提供月の約2か月後です。
> つまり、通帳を見ていては業績の変化に2か月遅れて気づくことになります。
> **総単位数は、その月のうちに確定する数字**です。

### (7) 利用者1人あたりの単位数

| 項目 | 内容 |
|---|---|
| **計算式** | 総単位数 ÷ 実利用者数（または ÷ 延べ利用者数） |
| **誰が見るか** | ①管理者・⑨請求事務 |
| **いつ見るか** | 月次 |
| **なぜ見るか** | 【Inference】同じ人数でも、要介護度の構成と加算の算定状況によって収入が変わる。その差を見るため |

```
【Example】説明用の架空の例です

  A月：実利用者60名、総単位数 466,200単位 → 1人あたり 7,770単位
  B月：実利用者60名、総単位数 420,000単位 → 1人あたり 7,000単位

  人数は同じなのに総単位数が減っている。考えられること【Inference】：
    ・1人あたりの利用回数が減った
    ・要介護度の軽い利用者の比率が上がった
    ・算定できていた加算が算定できなくなった
    ・減算に該当した
```

### (8) 請求額と入金額

| 項目 | 内容 |
|---|---|
| **計算式** | 総単位数 × 単価 → 保険給付分（7〜9割）と利用者負担分（1〜3割）に分かれる |
| **誰が見るか** | ⑨請求事務・⑩経理財務 |
| **いつ見るか** | 月次（請求時）／入金時 |
| **なぜ見るか** | 請求額と入金額の差＝返戻・査定の存在を示す |

### (9) 返戻率【Varies】

| 項目 | 内容 |
|---|---|
| **計算式**【Typical】 | 返戻件数 ÷ 請求件数（または返戻金額 ÷ 請求金額） |
| **誰が見るか** | ⑨請求事務・①管理者 |
| **いつ見るか** | 月次 |
| **なぜ見るか** | 【Inference】返戻はその月の入金が発生しないことを意味する。再請求すればさらに約2か月遅れる（`08_money.md` 8-3） |
| **数値の目安** | **【Varies】** |

> **返戻率は「事務のミス率」ではない【Inference】**
> `08_money.md` 8-3 のとおり、返戻は事業所の外で起きた変化（区分変更認定、
> ケアマネジャーの給付管理の変更）でも起こります。
> したがって、返戻率を見るときは**理由の内訳**とあわせて見ることになります【Typical】。

### (10) 加算の算定状況

| 項目 | 内容 |
|---|---|
| **見る内容** | どの加算を算定しているか／算定できている利用者の数／算定できなかった月があるか |
| **誰が見るか** | ①管理者・⑨請求事務 |
| **いつ見るか** | 月次 |
| **なぜ見るか** | 【Fact】介護報酬は基本報酬と加算・減算で構成される（介護保険制度の概要／厚生労働省老健局）。基本報酬は全国共通のため、**事業所ごとの単位数の差はここから生じる**【Inference】 |

> **本資料は「どの加算を取るべきか」を提案しません。**
> ここで説明しているのは、**算定状況が月次で確認される数字である**という事実です。
> 【Typical】算定の要件を満たす取組を行い、記録に残せていたかを月次で確認します
> （`13_periodic-work.md` 13-4）。

### (11) 減算への該当の有無

| 項目 | 内容 |
|---|---|
| **見る内容** | 定員超過／看護・介護職員の員数／BCPの策定／虐待防止措置／送迎の実施 |
| **誰が見るか** | ①管理者 |
| **いつ見るか** | 月次 |
| **なぜ見るか** | 【Fact】いずれも介護報酬の算定構造に減算項目として置かれている（介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。**該当すると単価そのものが下がる** |

> **これは「率」ではなく「該当しているかどうか」**
> 【Inference】減算は、％で管理する数字ではなく、**○か×かで点検する項目**です。
> だから `05_departments.md` ①-6 は「点検」という業務になっています。

## 14-4. 人に関する数字

### (12) 人員配置基準の充足状況

**この業界に固有の、最も重要な「数字」です。**

| 項目 | 内容 |
|---|---|
| **計算式（通所介護・介護職員）** | 【Fact】「介護職員が**勤務している時間数の合計数**を…**提供している時間数で除して得た数**」が、利用者の数が15人までは**1以上**、15人を超える場合は「15人を超える部分の数を5で除して得た数に1を加えた数」以上（基準第93条第1項第3号） |
| **計算式（通所介護・生活相談員）** | 【Fact】「提供している時間帯に生活相談員が**勤務している時間数の合計数**を…**提供している時間帯の時間数で除して得た数**が**一以上**」（同項第1号） |
| **計算式（訪問介護）** | 【Fact】**常勤換算方法**で2.5以上（基準第5条第1項）。常勤換算方法＝「従業者の**勤務延時間数**を…**常勤の従業者が勤務すべき時間数で除する**」（基準第2条第8号） |
| **誰が見るか** | ①管理者・⑪人事労務 |
| **いつ見るか** | **日次**（当日の配置）／月次（勤務形態一覧表） |
| **なぜ見るか** | 【Fact】下回れば「**看護・介護職員の員数が基準に満たない場合**」の減算に該当する（介護報酬の算定構造／厚生労働省） |

```
【Example】説明用の架空の計算です（`03_company-structure.md` 3-2 と同じ例）

  サービス提供時間 8時間、利用者25名の日

  必要数： 25 − 15 = 10 → 10 ÷ 5 = 2 → 2 + 1 = 3 以上

  実際の配置：
    介護職員A（8時間）＋B（8時間）＋C（8時間）＋D（4時間）= 28時間
    28時間 ÷ 8時間 = 3.5  → 3以上を満たす ○

  ここでDさんが急に休んだら：
    24時間 ÷ 8時間 = 3.0  → ぎりぎり満たす ○
  さらにCさんも休んだら：
    16時間 ÷ 8時間 = 2.0  → **満たさない ×**
```

> **この数字が他のKPIと決定的に違う点【Inference】**
> 稼働率や返戻率は「良い・悪い」を見る数字です。
> 人員配置基準の充足状況は、**満たしているか・満たしていないか**という、
> **法令上の状態を示す数字**です。
> 満たしていなければ減算になり、状態が続けば指定に関わります。

### (13) 職員1人あたりの利用者数

| 項目 | 内容 |
|---|---|
| **計算式**【Typical】 | 1日平均利用者数 ÷ その日の勤務職員数（または常勤換算職員数） |
| **誰が見るか** | ①管理者 |
| **いつ見るか** | 日次／月次 |
| **なぜ見るか** | 【Inference】人員配置基準は「最低ライン」であり、実際にどれだけの手があるかを見るための数字。介助に手がかかる利用者が多い日は、基準を満たしていても余裕がないことがある |

**参考になる【Fact】の統計**

【Fact】令和6年経済センサス‐基礎調査（2024年）による1事業所当たり従業者数は次のとおりです
（出典：令和6年経済センサス‐基礎調査 甲調査 第4-2表／総務省。
1事業所当たり従業者数は同表の事業所数と従業者数から算出したものです）。

| 産業小分類 | 事業所数 | 従業者数 | 1事業所当たり |
|---|---|---|---|
| 854 老人福祉・介護事業 | 120,218 | 2,587,436 | 約21.5人 |
| 85E 通所・短期入所介護事業 | 37,860 | 588,780 | 約15.6人 |
| 85F 訪問介護事業 | 20,842 | 348,001 | 約16.7人 |
| 85C 特別養護老人ホーム | 10,039 | 634,945 | 約63.2人 |

> **この統計の読み方の注意**
> - 「通所・短期入所介護事業」は通所介護と短期入所を合わせた区分です
> - 従業者には非常勤が含まれます（常勤換算ではありません）
> - **事業所ごとの規模差が大きいため、平均値をそのまま自事業所に当てはめられません**【Varies】

### (14) 離職率・採用数【Varies】

| 項目 | 内容 |
|---|---|
| **計算式**【Typical】 | 期間中の離職者数 ÷ 期首の職員数 |
| **誰が見るか** | ⑪人事労務・①管理者・経営者 |
| **いつ見るか** | 年次／月次（採用・退職の発生時） |
| **なぜ見るか** | 【Inference】職員が減ることは、そのまま**人員配置基準の充足の問題**になる。他業界では「忙しくなる」だけだが、介護では**減算＝単価の低下**につながる |
| **数値の目安** | **【Varies】本資料では業界の離職率の数値を示しません**（本調査では一次資料を取得していないため） |

> **介護における「人が辞める」ことの意味【Inference】**
> ```
> 一般の会社： 人が辞める → 残った人の負担が増える／採用する
> 介護事業所： 人が辞める → 【Fact】人員基準を割れば減算（＝単価が下がる）
>                          → 受け入れられる利用者数にも影響しうる
>                          → 【Fact】資格要件のある職種は代替が限られる
>                             （訪問介護員等は「介護福祉士又は…政令で定める者」。基準第5条第1項）
> ```

### (15) 資格保有者数

| 項目 | 内容 |
|---|---|
| **見る内容** | 介護福祉士、看護師・准看護師、介護支援専門員、機能訓練指導員となりうる資格 の人数 |
| **誰が見るか** | ⑪人事労務・①管理者 |
| **いつ見るか** | 月次／採用時 |
| **なぜ見るか** | 【Fact】法定職種の要件を満たすため。【Fact】訪問介護のサービス提供責任者は「**介護福祉士その他厚生労働大臣が定める者**」（基準第5条第4項）。【Fact】居宅介護支援の管理者は原則**主任介護支援専門員**（指定居宅介護支援等基準第3条第2項）。【Inference】加算の要件に職種・資格が関わるものもある |

## 14-5. 費用に関する数字

### (16) 人件費率

| 項目 | 内容 |
|---|---|
| **計算式** | 人件費 ÷ 売上 |
| **誰が見るか** | 経営者・⑩経理財務 |
| **いつ見るか** | 月次 |
| **なぜ見るか** | 【Inference】介護事業の費用の最大項目が人件費であり、しかも【Fact】人員配置基準が下限を決めている（基準第93条ほか）。「下げようと思っても下げられない部分がある」費用として見る |
| **数値の目安** | **【Varies】本資料では業界の人件費率の数値を示しません**（`19_sources.md` §5 のとおり、経営指標は本調査の範囲外） |

> **なぜ「目安」を示さないのか**
> `common/methodology.md` §3 は「確信が持てない数値は**書かない**」としています。
> 人件費率は事業種別・規模・地域・常勤比率により大きく異なり、
> 出典のない数値を示すと誤解を生みます【Varies】。

### (17) 1人あたり（または1日あたり）の食材費・消耗品費【Typical】

| 項目 | 内容 |
|---|---|
| **計算式** | 食材費 ÷ 延べ食数 など |
| **誰が見るか** | ⑧調理給食・⑩経理財務・①管理者 |
| **いつ見るか** | 月次 |
| **なぜ見るか** | 【Fact】食費は介護報酬とは別に利用者から受け取る実費（基準第96条第3項第3号）。実費として受け取る額と、実際にかかる費用の関係を見るため【Inference】 |

### (18) 送迎の効率【Varies】

| 項目 | 内容 |
|---|---|
| **見る内容**【Typical】 | 1便あたりの乗車人数／1台あたりの走行距離／送迎に要する時間 |
| **誰が見るか** | ⑦送迎運転・①管理者 |
| **いつ見るか** | 日次／週次（ルート見直し時） |
| **なぜ見るか** | 【Inference】送迎の時間は、職員が事業所にいない時間でもある。【Fact】一方で「介護職員を**常時一人以上**…従事させなければならない」（基準第93条第2項）。つまり送迎ルートは人員配置と結びついている |
| **数値の目安** | **【Varies】** |

> **送迎の効率は「受け入れられる人数」を決める【Inference】**
> 1台の車が1回の運行で回れる件数と時間には限りがあります。
> 遠方の利用者を1人受け入れると、その分だけ他の利用者を回れなくなることがあります。
> 【Fact】なお、通常の事業の実施地域以外に居住する利用者の送迎に要する費用は、
> 利用者から受け取ることができます（基準第96条第3項第1号）。

## 14-7. 数字の見る順番【Inference】

```
【日次で見る】
   今日の利用者数 ／ キャンセル数 ／ 当日の人員配置（基準を満たしているか）
        │
        ▼
【週次で見る】
   曜日別の稼働率 ／ 翌週の予約状況 ／ 空き枠
        │
        ▼
【月次で見る】
   稼働率（月平均） ／ 実利用者数・延べ利用者数 ／ 新規・終了
   総単位数 ／ 1人あたり単位数 ／ 加算の算定状況 ／ 減算への該当
   請求額 ／ 返戻の件数と理由
   人件費率 ／ 勤務形態一覧表（常勤換算数）
        │
        ▼
【入金時に見る】
   入金額と請求額の差 ／ 利用者負担分の未収
        │
        ▼
【年次で見る】
   決算 ／ 離職率 ／ 法定の取組の実施状況
```

> **入金額を見るのは一番最後になる【Inference】**
> `08_money.md` 8-8 のとおり、保険給付分の入金はサービス提供月の約2か月後です。
> 通帳の残高だけを見ていると、**業績の変化に約2か月遅れて気づく**ことになります。
> だから、日次の稼働率と月次の総単位数を先に見る形になります。

## この章のまとめ

- 収入は **利用定員 × 稼働率 × 営業日数 × 1日あたりの平均単位数 × 単価** に分解できる。
  このうち**事業所が動かせるのは主に稼働率**と、加算・減算の該当状況。
- **通所介護は在庫の効かない事業**である。空いた席は翌日に持ち越せない【Inference】。
  だから稼働率を日次で見る。**曜日別**に分けて見るのが実務上の姿【Typical】。
- **総単位数は、入金より約2か月早く分かる数字**である。通帳だけを見ていると変化に気づくのが遅れる。
- **人員配置基準の充足状況**は、他のKPIと性格が違う。
  「良い・悪い」ではなく**法令上の状態**を示し、満たさなければ【Fact】減算になる。
- 減算への該当と法定の取組の実施状況は、**率ではなく○×で点検する項目**である。
- **本資料は業界水準の数値（稼働率・人件費率・離職率・返戻率の目安）を示さない**【Varies】。
  出典のある【Fact】は、施設系の利用率（介護老人福祉施設94.5%／介護老人保健施設88.2%／介護医療院91.1%。
  出典：令和6年介護サービス施設・事業所調査の概況 表3／厚生労働省）と、
  1事業所当たり従業者数（令和6年経済センサス‐基礎調査 第4-2表／総務省から算出）にとどまる。
- **数字の改善提案は書かない。** この章が示すのは「何を、なぜ見ているか」である。

次章 `15_rules-customs.md` では、この業界を規定している法令と、商習慣を整理します。
