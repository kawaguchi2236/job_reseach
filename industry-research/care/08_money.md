## 8-0. 介護のカネの流れは、どこが他業界と違うのか

一般の業界のカネの流れは、おおむね次のとおりです。

```
見積 → 契約 → 納品 → 請求 → （締め日）→ 入金
        ↑ 価格は当事者が決める      ↑ 相手は買った人
```

介護は、ここが3か所ずれます。

```
① 価格を当事者が決められない       → 介護報酬という公定価格
② 払う人が1人ではない             → 利用者が1〜3割、残りは保険から（国保連経由）
③ 請求してすぐ入金にならない       → 保険給付分はサービス提供月の約2か月後
```

**この3つを押さえれば、介護事業所の経理で起きていることの大半は説明できます。**

### 用語：この章で繰り返し出てくる基本語

> **売上 ≠ 入金**
> → サービスを提供した時点で「売上」は発生します。しかし現金はまだ入っていません。
> → 実務例：11月にサービスを提供すれば11月の売上になる。
>    しかし保険給付分の現金が入るのは翌年1月ごろ（約2か月後）。

> **売掛金（うりかけきん）**
> → 「売上は立ったが、まだ受け取っていないお金」を表す会計上の項目。
> → 実務例：11月分の保険給付分62,937円は、入金されるまで「売掛金」として帳簿に残る。

> **公定価格（こうていかかく）**
> → 国が決めた価格。事業者が自由に値段を付けられない。
> → 実務例：通所介護（通常規模型・7時間以上8時間未満・要介護2）は777単位。
>    【Fact】出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省。
>    どの事業所が提供しても、この単位数は同じ。

## 8-1. 収入は2つの経路に分かれる

### 全体像

```
                     1か月分のサービスの費用額（＝単位数 × 単価）
                                  │
                ┌─────────────────┴──────────────────┐
                ▼                                     ▼
      【利用者負担 1〜3割】                    【保険給付分 7〜9割】
      利用者・家族から直接受け取る              国保連を経由して受け取る
      【Varies】口座振替／振込／現金            【Fact】翌月10日までに請求
      【Typical】翌月に請求                    【Typical】約2か月後に入金
                │                                     │
                └─────────────────┬──────────────────┘
                                  ▼
                          事業所の介護報酬収入
                                  ＋
                  【保険外】食費・おむつ代・実施地域外の送迎費 等
                          （利用者から直接。介護保険の外）
```

### なぜ利用者は1割だけ払えばよいのか（代理受領）

【Fact】介護保険法第41条第4項第1号は、居宅介護サービス費の額を
サービスに要する費用の額の「**百分の九十**に相当する額」と定めています
（出典：介護保険法第41条第4項／e-Gov法令検索）。

【Fact】同条第6項は
「…市町村は、当該居宅要介護被保険者が当該指定居宅サービス事業者に支払うべき当該指定居宅サービスに要した費用について、
居宅介護サービス費として当該居宅要介護被保険者に対し支給すべき額の限度において、
**当該居宅要介護被保険者に代わり、当該指定居宅サービス事業者に支払うことができる**」としています（同上）。

> **用語：代理受領（だいりじゅりょう）**
> → 本来は「利用者がいったん全額を事業者に払い、あとから9割分を市町村から受け取る」建前だが、
>    実際には市町村側が9割分を直接事業者に払い、利用者は1割だけを払えばよい形にする仕組み。
> → 実務例：1か月の費用額が100,000円なら、利用者は10,000円を事業所に払い、
>    残り90,000円は事業所が国保連に請求して受け取る。利用者が10万円を立て替える必要はない。

【Fact】一定以上の所得がある人については、介護保険法第49条の2が
「**百分の八十**」または「**百分の七十**」と定めています（同上）。
これが実務でいう**2割負担・3割負担**です。

> **用語：負担割合証（ふたんわりあいしょう）**
> → 利用者の自己負担が1割・2割・3割のどれかを示す、市町村が交付する証明書。毎年更新される。
> → 実務例：利用者が新しい負担割合証を持ってきたら、事業所は請求システムの設定を変更する。
>    見落とすと、利用者から受け取る額と国保連に請求する額の両方が間違う。

### 用語：法定代理受領サービス

【Fact】指定居宅サービス等基準第96条第1項は
「指定通所介護事業者は、**法定代理受領サービスに該当する指定通所介護を提供した際には**、
その利用者から**利用料の一部**として、当該指定通所介護に係る**居宅介護サービス費用基準額**から
当該指定通所介護事業者に支払われる**居宅介護サービス費の額を控除して得た額**の支払を受けるものとする」
と定めています（出典：同基準第96条第1項／e-Gov法令検索）。

> **条文を分解して読む（初心者向け）**
> ```
> 居宅介護サービス費用基準額     …… サービス全体の費用額（10割）
>  − 事業者に支払われる居宅介護サービス費 …… 保険から入る分（7〜9割）
> ─────────────────────────────
>  ＝ 利用者から受け取る額         …… 1〜3割
> ```
> 条文は「1割を取る」とは書いていません。「**全体から保険給付分を引いた残り**」と書いています。
> 負担割合が人によって違うため、この書き方になっています【Inference】。

## 8-2. 介護報酬が入金されるまで（C①〜C⑤）

### 時間軸の全体図

```
【11月】サービス提供（＝売上が発生する月）
   │  日々：実績を入力する
   ▼
【11月末〜12月初】C① 実績の確定
   │  介護記録とシステム入力の突き合わせ／加算・減算の確認／限度額の確認
   │  ケアマネジャーの給付管理内容との突き合わせ
   ▼
【12月10日まで】C② 国保連へ請求 ← 法定・契約上のタイミング
   │  【Fact】「各月分について翌月十日までに行わなければならない」
   │         （介護給付費及び公費負担医療等に関する費用等の請求に関する命令第3条第1項）
   ├─▶ C③ 利用者負担分の請求書を発行（利用者・家族へ）
   ▼
【12月】C④ 国保連が審査
   │   【Fact】介護保険法第41条第9項・第10項
   ├─ 通った   → 支払へ
   └─ 通らない → **返戻**（その月は入金されない）→ 修正して翌月以降に再請求
   ▼
【翌年1月】C⑤ 入金 ← サービス提供月から約2か月後【Typical】
   ▼
【翌年1月】C⑥ 消込（請求額と入金額の突き合わせ）／必要なら過誤申立て
```

### C① 実績の確定 ── ここで「いくらになるか」が決まる

| 確認すること | なぜ確認するか |
|---|---|
| 実際に提供した日と時間区分 | 【Fact】通所介護の単位数は**提供時間の区分ごと**に異なる（介護報酬の算定構造／厚生労働省） |
| 要介護度 | 【Fact】同じ時間区分でも要介護度ごとに単位数が異なる（同上） |
| 認定有効期間 | 期間が切れていると請求が通らない【Typical】 |
| 負担割合 | 利用者から受け取る額が変わる |
| 算定する加算の要件を満たしているか | 要件を満たさずに算定すると、後で返還を求められることがある【Inference】 |
| 区分支給限度基準額を超えていないか | 超えた分は**全額利用者負担**になる（8-5 参照） |
| ケアマネジャーの給付管理内容と一致するか | 不一致は返戻の原因になる【Typical】 |

> **なぜ月末〜月初に仕事が集中するのか**
> 【Fact】区分支給限度額の管理期間は「当該月の**初日からの一月間**」（介護保険法施行規則第67条）。
> 【Fact】請求期限は「各月分について**翌月十日まで**」（請求に関する命令第3条第1項）。
> **月末で区切り、10日以内に確定させる**というサイクルが法令で決まっているためです。

### C② 国保連へ請求

【Fact】請求の方法について、請求に関する命令第2条第1項は
「**電子情報処理組織**を使用して…審査支払機関の電子計算機に備えられたファイルに記録し、
又は…**光ディスク等**を審査支払機関に提出して行う」と定めています。

【Fact】同命令第3条第2項は
「電子情報処理組織による…請求は、審査支払機関の電子計算機に備えられたファイルに**記録された時に**
審査支払機関に到達したものとみなす」としています。

> **「送った」ではなく「記録された時」**
> 期限の判定は、事業所が送信した時点ではなく、**審査支払機関のファイルに記録された時点**です。
> 【Inference】締切日の直前に送信して通信が滞ると、期限を過ぎるおそれがあります。
> これが、請求事務が月初に前倒しで進められる理由のひとつです。

### C③ 利用者負担分の請求

【Fact】介護保険法第41条第8項は、指定居宅サービス事業者について
利用者から支払を受けたときは**領収証を交付しなければならない**旨を定めています
（出典：介護保険法第41条第8項／e-Gov法令検索）。

【Typical】利用者への請求書には、次の2種類がまとめて載ります。

```
【介護保険のサービス】
  通所介護費（要介護2・7時間以上8時間未満）  777単位 × 9回 = 6,993単位
  6,993単位 × 単価 = 費用額
  うち利用者負担（1割）                              6,993円  ← 保険の対象
【介護保険外の実費】
  食費   700円 × 9回                                6,300円  ← 保険の対象外
  おむつ代                                          （実費）
  ─────────────────────────────────
  請求額合計                                       13,293円
```
※【Example】説明用の架空例です（1単位＝10円として計算。`01_overview.md` 1-5 と同じ前提）。

> **利用者が「デイの料金」と呼んでいるものは、実は2つに分かれている**
> これが `16_glossary.md` で扱う **「介護保険サービス ≠ 実費サービス」** の混同ペアです。

### C④ 審査

【Fact】介護保険法第41条第9項は
「市町村は、指定居宅サービス事業者から居宅介護サービス費の請求があったときは、
第四項各号の厚生労働大臣が定める基準及び…**指定居宅サービスの事業の設備及び運営に関する基準**
（指定居宅サービスの取扱いに関する部分に限る。）に**照らして審査した上、支払うものとする**」と定めています。

【Fact】同条第10項は、市町村がこの審査及び支払に関する事務を
「**国民健康保険団体連合会に委託することができる**」としています。

> **審査されているのは金額だけではない**
> 条文は「**運営に関する基準…に照らして審査**」と書いています。
> つまり、**基準を満たした形でサービスが提供されたか**が審査の対象に含まれます【Inference】。
> ここが、記録の整備が収入に直結する理由です（`04_end-to-end-process.md` B 参照）。

### C⑤ 入金

【Typical】入金はサービス提供月の**約2か月後**です。
【Inference】この時間差は、請求期限（翌月10日）と、その後の審査の期間から生じています。

## 8-3. 返戻と過誤 ── 「請求したのに入らない」が起きる

> **用語：返戻（へんれい）**
> → 請求が審査を通らず、差し戻されること。その月は入金されない。
> → 実務例：被保険者番号が1桁違っていた。認定有効期間が切れていた。
>    ケアマネジャーが送った給付管理票の内容と事業所の請求内容が一致していなかった。
> → 【Typical】原因を特定して修正し、翌月以降に再請求する。

> **用語：過誤（かご）**
> → いったん支払われた請求を取り下げ、正しい内容で請求し直すこと。
> → 実務例：算定していた加算の要件を満たしていなかったことが後から分かった場合、
>    保険者に**過誤申立て**を行い、取り下げたうえで正しい内容で再請求する。

### 返戻・過誤がカネの流れに与える影響

```
【返戻が起きた場合】

  11月分の請求（12月10日まで）
      → 12月の審査で返戻
      → 1月に入金されない  ← ★ここで資金繰りに穴があく
      → 1月に修正して再請求
      → 3月ごろに入金      ← 約2か月さらに遅れる
```

> **返戻は「請求ミス」だけで起きるわけではない**
> 【Inference】利用者が月の途中で区分変更認定を受けた、
> ケアマネジャーが給付管理の内容を変更した、といった**事業所の外で起きた変化**でも返戻は起こります。
> だから返戻への対応は、請求事務機能（⑨）の通常業務の一部です（`05_departments.md` ⑨-9）。

## 8-4. 保険外の実費 ── 食費・おむつ代は介護保険ではない【重要】

### 条文が列挙しているもの

【Fact】指定居宅サービス等基準第96条第3項は、指定通所介護事業者が
第1項・第2項の支払を受ける額のほかに利用者から支払を受けることができる費用として、次を列挙しています。

> 「一 利用者の選定により**通常の事業の実施地域以外の地域に居住する利用者に対して行う送迎に要する費用**
> 　二 指定通所介護に**通常要する時間を超える**指定通所介護であって利用者の選定に係るものの提供に伴い
> 　　　必要となる費用の範囲内において、通常の指定通所介護に係る居宅介護サービス費用基準額を超える費用
> 　三 **食事の提供に要する費用**
> 　四 **おむつ代**
> 　五 前各号に掲げるもののほか、指定通所介護の提供において提供される便宜のうち、
> 　　　**日常生活においても通常必要となるもの**に係る費用であって、
> 　　　その利用者に**負担させることが適当と認められる費用**」
> （出典：指定居宅サービス等の事業の人員、設備及び運営に関する基準第96条第3項／e-Gov法令検索）

【Fact】同条第4項は「前項第三号に掲げる費用（＝食事の提供に要する費用）については、
**別に厚生労働大臣が定めるところによる**ものとする」としています。

【Fact】同条第5項は
「指定通所介護事業者は、第三項の費用の額に係るサービスの提供に当たっては、**あらかじめ**、
利用者又はその家族に対し、当該サービスの内容及び費用について**説明を行い、利用者の同意を得なければならない**」
としています。

### カネの流れとしてどう違うのか

| | 介護報酬（保険の対象） | 実費（保険の対象外） |
|---|---|---|
| 価格を決めるのは | 【Fact】厚生労働大臣（法第41条第4項）＝**公定価格** | 【Varies】事業所（ただし食費は【Fact】基準第96条第4項により別に厚生労働大臣が定めるところによる） |
| 誰が払うか | 利用者1〜3割＋保険給付分7〜9割 | **利用者が全額** |
| 入金経路 | 利用者から直接＋国保連経由 | **利用者から直接のみ** |
| 入金のタイミング | 保険給付分は約2か月後 | 【Typical】翌月の請求で回収 |
| 限度額の対象か | 【Fact】区分支給限度基準額の対象（法第43条第1項） | **対象外** |

> **経営上の意味（評価ではなく構造の説明として）**
> 【Inference】実費は**利用者から直接、翌月に回収できる**お金です。
> 一方、保険給付分は**約2か月後**にしか入りません。
> つまり、同じ「収入」でも、現金になるタイミングがまったく違います。
> 資金繰り表（8-8）では、この2つを分けて置く必要があります。

### 利用者負担分が回収できない場合【Typical】

【Typical】利用者負担分は、事業所が直接回収します。
口座振替が失敗した、家族が支払を忘れている、といった理由で**未収金**が生じることがあります。
【Varies】回収の方法・督促の手順は事業所により異なります。

> **保険給付分には未収が起きにくい**
> 【Inference】保険給付分は国保連を経由して支払われるため、
> 「相手にお金がなくて払えない」という形の未収は起きにくい構造です。
> 一方、利用者負担分は通常の売掛金と同じ性質を持ちます。

## 8-5. 区分支給限度基準額 ── 超えた分は全額自己負担

### 条文

【Fact】介護保険法第43条第1項は、1か月に受けた居宅サービス等について支給する
居宅介護サービス費等の額の合計額は
「**居宅介護サービス費等区分支給限度基準額**を基礎として、厚生労働省令で定めるところにより算定した額の
**百分の九十に相当する額を超えることができない**」と定めています
（出典：介護保険法第43条第1項／e-Gov法令検索）。

【Fact】同条第2項は、この額を
「**要介護状態区分に応じた標準的な利用の態様**…等を勘案して**厚生労働大臣が定める額**とする」としています。

【Fact】管理期間は、介護保険法施行規則第67条により
「要介護認定有効期間に係る日が属する月についてそれぞれ**当該月の初日からの一月間**」です。

【Fact】同条第3項により、市町村は条例で限度額を上回る額を定めることもできます。

> **本資料では金額（単位数）を書きません**
> `19_sources.md` §5 のとおり、**要介護度別の具体的な単位数を示す一次資料を取得できていない**ため、
> 制度の仕組みのみを記載します【Varies】。

### カネの流れとして何が起きるか

```
【Example】説明用の架空例です

  Aさんのケアプラン：通所介護 週2回 ＋ 訪問介護 週2回 ＋ 福祉用具貸与
      合計が限度額の範囲内 → それぞれ1〜3割負担

  Aさんが「もう1回デイを増やしたい」と希望した
      → その1回分が限度額を超える
      → **超えた分は保険給付の対象外となり、全額（10割）が利用者の負担になる**
```

> **なぜ事業所にとって重要なのか**
> 【Inference】限度額は「1つの事業所の使用量」ではなく、
> **その利用者が使うすべての介護保険サービスの合計**で管理されます。
> つまり、他の事業所のサービスが増えれば、自事業所の分が限度額を超えることがありえます。
> だからケアマネジャーが**給付管理**を行い、請求事務機能（⑨）は
> その内容と自事業所の請求内容を突き合わせます（`05_departments.md` ⑨-5・⑨-6）。
>
> 突き合わせを怠ると、**返戻**になって入金が遅れます。

## 8-6. 加算と減算 ── 同じサービスでも収入が変わる

### 構造

【Fact】介護報酬は「**基本報酬**」と「**加算・減算**」で構成されます
（出典：介護保険制度の概要（令和7年7月）／厚生労働省老健局）。

```
  基本報酬（提供時間区分 × 要介護度で決まる）  ← 全国共通
      ＋ 加算（要件を満たす取組をした場合に算定できる）
      − 減算（基準を満たしていない場合に引かれる）
  ────────────────────────────────
  ＝ その月の単位数
      × 地域区分に応じた単価  ← 【Fact】法第41条第4項第1号「事業所の所在する地域等を勘案して」
  ────────────────────────────────
  ＝ サービスの費用額
```

### 加算：取りに行くもの

【Fact】通所介護の加算には、入浴介助加算、中重度者ケア体制加算、個別機能訓練加算、
栄養アセスメント加算、栄養改善加算、口腔機能向上加算、科学的介護推進体制加算などがあります
（出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。

【Typical】加算を算定するには、一般に次の両方が必要です（`04_end-to-end-process.md` 介護固有トピック(2)）。

```
① 体制を整え、指定権者に体制届を提出する
   （届出をした月の翌月から算定できるのが通例【Varies：届出の取扱いは加算により異なる】）
② 実際にその要件を満たす取組を行い、**記録に残す**
```

> **加算 ≠ 値上げ**
> 【Inference】加算は「事業所が値段を上げること」ではありません。
> **要件を満たした場合に算定できる**ものです。
> 要件を満たさないまま算定すれば、あとで返還を求められることがあります。
> この混同は `16_glossary.md` の混同ペアで改めて扱います。
>
> **本資料は「どの加算を取るべきか」という提案は一切しません。**
> ここで説明しているのは、**加算というものが収入構造の一部として存在する**という事実です。

### 減算：気づかないうちに該当するもの

【Fact】通所介護の減算項目には次のものがあります（同上）。

- 「**利用者の数が利用定員を超える場合**」
- 「**看護・介護職員の員数が基準に満たない場合**」
- 「**高齢者虐待防止措置未実施減算**」
- 「**業務継続計画未策定減算**」
- 「**事業所が送迎を行わない場合**」

> **人員が足りないことが、売上の減少と単価の低下の両方になる**
> ```
> 一般の会社： 人が足りない → 受注を断る（数量が減る）
> 介護事業所： 人が足りない → 提供できる数量も減り、**さらに単価も減算される**
> ```
> 【Fact】これは `03_company-structure.md` 3-2 で扱った人員配置基準の構造そのものです。

## 8-7. 出ていくお金（コスト構造）

### コストの一覧

| # | 費目 | 中身 | 支払のタイミング【Typical】 |
|---|---|---|---|
| 1 | **人件費**（最大の費目） | 給与、賞与、法定福利費（社会保険料の事業主負担）、通勤手当、研修費 | 毎月（給与）。社会保険料は翌月納付 |
| 2 | **送迎の費用** | 燃料費、車両のリース料・減価償却費、保険料、車検・点検費、駐車場代 | 毎月／年次（車検・保険） |
| 3 | **食材費・給食委託費** | 自事業所調理なら食材費、委託なら委託料【Varies】 | 毎月 |
| 4 | **消耗品費** | おむつ・手袋・エプロン・消毒液・リネン・記録用紙 | 毎月 |
| 5 | **建物の費用** | 家賃または減価償却費、水道光熱費（**浴室があるため水道・ガスの比重が大きい**【Inference】） | 毎月 |
| 6 | **設備・備品** | 入浴設備、機能訓練機器、車いす等の備品、システム利用料 | 購入時／毎月（システム） |
| 7 | **その他** | 通信費、損害保険料、税理士・社会保険労務士の報酬、広告費【Varies】、研修の外部受講費 | 毎月／年次 |

### 人件費には「法令上の下限」がある【この業界固有】

**一般の会社と最も違うのがここです。**

【Fact】指定居宅サービス等基準第93条第1項第3号は、通所介護の介護職員について
「…介護職員（専ら当該指定通所介護の提供に当たる者に限る。）が**勤務している時間数の合計数**を
当該指定通所介護を提供している時間数で除して得た数が、利用者の数が**十五人までの場合にあっては一以上**、
**十五人を超える場合にあっては十五人を超える部分の数を五で除して得た数に一を加えた数以上**確保されるために
必要と認められる数」と定めています。

【Fact】同条第2項は「指定通所介護の単位ごとに、前項第三号の介護職員を、
**常時一人以上**当該指定通所介護に従事させなければならない」としています。

【Fact】同条第6項は「第一項の**生活相談員又は介護職員のうち一人以上は、常勤でなければならない**」としています。

> **これが意味すること（初心者向け）**
> ```
> 一般の会社： 売上が落ちた → 人件費を減らす判断ができる
> 介護事業所： 売上が落ちても、**基準を満たす人数は置き続けなければならない**
>             下回れば「看護・介護職員の員数が基準に満たない場合」の減算に該当する
> ```
> つまり、**人件費は「変動費」ではなく、法令が下限を決めている固定的な費用**という性格を持ちます【Inference】。
> 具体的な人件費率は事業所により異なるため、本資料では数値を示しません【Varies】
> （`19_sources.md` §5 のとおり、経営指標は本調査の範囲外です）。

### 会計を区分する義務

【Fact】指定居宅サービス等基準第38条（第105条により通所介護に準用）は
「指定訪問介護事業者は、**指定訪問介護事業所ごとに経理を区分**するとともに、
**指定訪問介護の事業の会計とその他の事業の会計を区分**しなければならない」と定めています
（出典：同基準第38条／e-Gov法令検索）。

> **なぜ区分が必要なのか**
> 【Inference】介護報酬は公費と保険料を財源とする公定価格です。
> 複数の事業（たとえば通所介護と居宅介護支援、あるいは介護保険外の自費サービス）を行っている場合に、
> どの事業にいくら使ったのかが分からなければ、報酬の水準を検証できません。
> 実務上は、事業ごとの部門別会計（部門コードを付けて集計する）という形をとることが多くあります【Typical】。

## 8-8. 資金繰り ── 「今入っている現金は、2か月前の仕事の分」

### 何が起きるか

```
【時間の流れ】

  11月：サービス提供（売上 発生）
        職員の給与を支払う ← ★現金が出ていく
  12月：請求（10日まで）
        職員の給与を支払う ← ★現金が出ていく
   1月：11月分の保険給付分が入金 ← ★やっと現金が入る
        職員の給与を支払う
```

**サービスを提供してから保険給付分の現金が入るまでの約2か月間、人件費は毎月出ていきます。**

### 開業時に何が起きるか【Inference】

```
【Example】説明用の架空例です

  4月  開業。利用者を受け入れ始める。職員の給与が発生する
  5月  4月分を請求。給与が発生する
  6月  4月分が入金される。給与が発生する
       → **開業から最初の入金まで、給与を2〜3か月分先に払う必要がある**
```

> 【Inference】この構造から、介護事業を始めるには
> **「最初の入金までの運転資金」を確保しておく必要がある**ことが分かります。
> 具体的な必要額は事業所の規模・費用構造により異なるため、本資料では金額を示しません【Varies】。

### 業績の変化に気づくのが遅れやすい構造【Inference】

```
  9月  利用者が減り始めた（稼働率が下がった）
  10月 9月分を請求 → 請求額が前月より少ないことに気づく
  11月 9月分が入金 → **現金として実感するのはここ**
```

> 【Inference】通帳の残高だけを見ていると、**悪化に気づくのが約2か月遅れます**。
> だから介護事業所では、**入金額ではなく「その月の稼働率・請求予定額」を先に見る**ことになります。
> どの数字を見るかは `14_kpi.md` で扱います。

### 資金繰り表に置くべき項目【Typical】

| 区分 | 項目 | タイミング |
|---|---|---|
| 入り | 保険給付分（国保連） | サービス提供月の約2か月後 |
| 入り | 利用者負担分 | 【Varies】翌月の口座振替日など |
| 入り | 実費（食費・おむつ代等） | 利用者負担分と同時【Typical】 |
| 出 | 給与 | 毎月の支給日 |
| 出 | 社会保険料 | 【Typical】翌月納付 |
| 出 | 源泉所得税 | 【Fact】原則として支払月の翌月10日まで（法定・契約上のタイミング） |
| 出 | 家賃・水道光熱費・燃料費・食材費 | 毎月 |
| 出 | 借入金の返済 | 毎月 |

## 8-9. 介護報酬改定 ── 収入の前提が入れ替わる

### 周期

【Fact】介護保険法第117条第1項は、市町村介護保険事業計画を「**三年を一期とする**」計画として定めるものとしています。
【Fact】同法第129条第3項は、第1号被保険者の保険料率を
「**おおむね三年を通じ財政の均衡を保つことができるもの**でなければならない」としています
（出典：介護保険法第117条第1項・第129条第3項／e-Gov法令検索）。

この3年を一期とする周期に合わせて、介護報酬も改定されるのが通例です。

【Fact】ただし、周期の途中で改定が行われることもあります。
2026年度（令和8年度）には期中改定が実施され、改定率は**＋2.03%（公費＋518億円）**とされました
（出典：令和8年度介護報酬改定の概要／厚生労働省老健局）。

### 改定が事業所のカネに与える影響【Typical】

| 変わるもの | 事業所で起きること |
|---|---|
| 基本報酬の単位数 | 同じ利用者数でも収入額が変わる |
| 加算の要件・単位数 | 算定していた加算が取れなくなる／新たに算定できる加算が生まれる |
| 減算の項目 | これまで該当しなかった項目に該当しうる |
| 人員基準・運営基準 | 体制の見直しが必要になる |

【Typical】改定時に事業所が行うこと：

- 算定する加算の見直しと**体制届の再提出**
- 請求システムの**単位数マスタの更新**
- **重要事項説明書の改訂**（利用料の記載が変わるため）
- **運営規程の変更**と変更届出【Varies：変更の内容による】
- 利用者・家族への説明

> **カネの流れとして重要なのは「改定月をまたぐ請求」**
> 【Inference】改定の施行日をまたぐ月は、施行日前と施行日後で単位数が変わります。
> 請求データもそれに合わせて分ける必要があります。
> 【Varies】実際の取扱いは改定ごとの通知によります。

## 8-10. 【Example】1か月の収入が現金になるまでを時系列で追う

> **【Example】以下はすべて説明用の架空の事例です。実在の事業所・利用者ではありません。**
> 単位数は【Fact】介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省 の
> 通常規模型通所介護の基本部分を用います。
> **1単位あたりの単価は説明のため10円として計算します。実際の単価は地域区分により異なります【Varies】。**
> 加算は説明を簡単にするため計算に含めていません。

### 前提

```
S デイサービスセンター
  利用者数：説明のため、要介護2の利用者が20名、それぞれ月9回利用したと仮定する【Example】
  提供時間：7時間以上8時間未満
  食費：1回700円
  利用者の負担割合：全員1割と仮定する【Example】
```

### 【11月】サービスを提供した月

```
■ 介護報酬（保険の対象）
  777単位／回 × 9回 × 20名 = 139,860単位
  139,860単位 × 10円 = 1,398,600円  ← サービスの費用額（11月の介護報酬の売上）
     ├─ 利用者負担（1割）   139,860円 → 利用者20名へ請求
     └─ 保険給付分（9割） 1,258,740円 → 国保連へ請求

■ 実費（保険の対象外）
  食費 700円 × 9回 × 20名 = 126,000円 → 利用者20名へ請求

■ 11月の収入（売上）合計 = 1,398,600円 + 126,000円 = 1,524,600円
   ※ただし、この時点で入っている現金は 0円
```

### 【11月30日】この時点の会計上の状態

```
  売上         1,524,600円（11月に計上）
  売掛金       1,524,600円（まだ1円も入金されていない）
  一方で11月中に出ていった現金：給与、燃料費、食材費、家賃、水道光熱費 …
```

### 【12月1日〜9日】C① 実績の確定

```
  ・介護記録と請求システムの入力を突き合わせる
  ・欠席・追加を反映する
  ・加算・減算の該当を確認する
  ・限度額を超えていないか確認する
  ・ケアマネジャーの給付管理の内容と突き合わせる
```

### 【12月10日まで】C② 国保連へ請求／C③ 利用者へ請求

```
  国保連へ  1,258,740円 を電子データで請求
  利用者へ  1人あたり 6,993円（介護保険1割）＋ 6,300円（食費）= 13,293円 の請求書を発行
            20名分合計 265,860円
```

### 【12月】C④ 審査

```
  国保連が審査
    ・18名分は問題なく通った
    ・2名分が返戻になった【Example】
        Bさん：認定有効期間が11月20日で切れており、更新の認定結果がまだ反映されていなかった
        Cさん：ケアマネジャーの給付管理票の内容と回数が一致していなかった
```

### 【12月下旬〜1月】利用者負担分の回収

```
  12月27日 口座振替（【Varies】事業所により日付は異なる）
    ・18名は振替できた
    ・1名は残高不足で振替不能 → 家族へ連絡し、翌月に再請求【Typical】
```

### 【翌年1月】C⑤ 入金／C⑥ 消込

```
  国保連から入金：18名分 = 1,132,866円
      （2名分 125,874円は返戻のため入金されない）

  C⑥ 消込
    ・請求額 1,258,740円 と入金額 1,132,866円 の差額 125,874円 の原因を確認
    ・返戻の内容を確認し、修正して再請求の準備をする
```

### 【翌年2月10日まで】返戻分の再請求

```
  Bさん分：更新後の認定情報を反映して再請求
  Cさん分：ケアマネジャーと回数を突き合わせたうえで再請求
      → 入金は3月ごろ  ← **11月に提供したサービスの現金が、4か月後に入る**
```

### この例から読み取れること

| 観察 | 意味 |
|---|---|
| 11月の売上 1,524,600円 のうち、11月中に入る現金は **0円** | 売上 ≠ 入金 |
| 1月に入るのは 1,132,866円（保険給付分の一部）＋ 12月に回収した利用者負担分 | **入金は2つの経路と2つのタイミングに分かれる** |
| 返戻2名分で 125,874円 の入金が2か月遅れた | **返戻は資金繰りの穴になる** |
| 食費126,000円は12月の口座振替で回収できた | **実費は保険給付分より早く現金になる** |
| 11月・12月の給与は、11月の売上が現金になる前に支払っている | **人件費は先に出ていく** |

## 8-11. 訪問介護（S ヘルパーステーション）ではカネの流れがどう変わるか【対比】

| 比較軸 | 通所介護 | 訪問介護 |
|---|---|---|
| **報酬の数え方** | 【Fact】1日ごと・提供時間区分ごと・要介護度ごと | 【Fact】1回ごと・所要時間区分ごと・身体介護／生活援助の別ごと |
| **実費として受け取れるもの** | 【Fact】実施地域外の送迎費、通常要する時間を超える分、食事の提供に要する費用、おむつ代 ほか（基準第96条第3項） | 【Fact】実施地域外の居宅で提供する場合の**交通費**（基準第20条第3項） |
| **食材費** | 事業所の費用として発生する【Varies】 | **発生しない**（生活援助は利用者宅の食材を使う） |
| **設備の費用** | 浴室・厨房・食堂等があり、水道光熱費の比重が大きい【Inference】 | 【Fact】「事業の運営を行うために必要な広さを有する専用の区画」（基準第7条第1項）。設備費は小さい【Inference】 |
| **収入が止まる要因** | 定員割れ／当日キャンセル | 訪問の中止／訪問介護員を確保できず訪問に入れない |
| **請求・入金の仕組み** | **同じ**（国保連へ翌月10日まで／約2か月後入金） | **同じ** |
| **利用者負担の回収** | **同じ**（事業所が直接回収） | **同じ** |

> **共通していること**
> `01_overview.md` 1-6 Level 1 のとおり、
> **公定価格・国保連経由・翌月10日までの請求・約2か月後の入金**は、
> 介護保険の指定サービスであれば業種が違っても共通です。
> 違うのは「何を数えて単位数にするか」と「どんな費用がかかるか」です。

## この章のまとめ

- 介護のカネの流れは、**①公定価格 ②払う人が2者（利用者1〜3割＋保険給付分） ③保険給付分は約2か月後入金**
  の3点で他業界と違う。
- 利用者が1〜3割だけ払えばよいのは**代理受領**の仕組みによる（【Fact】介護保険法第41条第6項）。
  条文上、利用者から受け取るのは「費用基準額 − 保険給付分」（【Fact】基準第96条第1項）。
- 請求は**各月分について翌月10日まで**（【Fact】請求に関する命令第3条第1項）。
  到達は「**記録された時**」（同条第2項）。審査は運営基準にも照らして行われる（【Fact】法第41条第9項）。
- **返戻・過誤**は入金をさらに約2か月遅らせる。原因は事業所の外で起きることもある。
- **食費・おむつ代等は介護保険の外**（【Fact】基準第96条第3項第3号・第4号）。
  あらかじめ説明し同意を得る（同条第5項）。限度額の対象にもならない。
- **区分支給限度基準額**を超えた分は保険給付の対象外となり、全額利用者負担になる（【Fact】法第43条第1項）。
  金額は本資料では示さない【Varies】。
- **加算・減算**が収入を左右する。人員基準を満たせないと減算される（【Fact】介護報酬の算定構造）。
  加算は「値上げ」ではなく、要件を満たした場合に算定できるもの。
- コストの最大は**人件費**で、**人員配置基準が法令上の下限を決めている**（【Fact】基準第93条）。
  会計は事業ごとに区分する義務がある（【Fact】基準第38条）。
- **資金繰りは「今の入金は2か月前の仕事の分」という前提**で組み立てる。
  業績の変化が現金に表れるのは約2か月後になる【Inference】。
- **介護報酬改定（原則3年に1度の周期。期中改定もありうる）**で収入の前提が入れ替わる
  （【Fact】法第117条第1項・第129条第3項／令和8年度改定＋2.03%）。

次章 `09_information.md` では、このカネの流れを支えている「情報」を扱います。
