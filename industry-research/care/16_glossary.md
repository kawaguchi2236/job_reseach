# PART 1. 用語集

## A. 制度の骨格（18語）

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **介護保険法** | 介護保険法（平成9年法律第123号） | 介護保険制度の骨格を定めた法律。要介護認定、指定、保険給付、限度額などを定める | 【Fact】第1条は目的として「これらの者が**尊厳を保持し**、その有する能力に応じ自立した日常生活を営むことができるよう」と定める。事業所の仕事の前提にある法律だが、**日々の運営の細かいルールは別の省令（運営基準）にある**ので、混同しないこと |
| **保険者** | ― | 介護保険を運営する主体 | 【Fact】「**市町村及び特別区**は、この法律の定めるところにより、介護保険を行うものとする」（法第3条第1項）。事業所から見ると、要介護認定を出す相手、事故報告を出す相手、市町村への通知を出す相手 |
| **被保険者** | 第1号被保険者／第2号被保険者 | 介護保険に加入している人 | 【Fact】法第9条。第1号＝**65歳以上**、第2号＝**40歳以上65歳未満**の医療保険加入者。【Fact】第2号は第7条第3項の「特定疾病」による場合に限られる |
| **要介護認定** | ― | 介護保険のサービスを使うために、市町村から受ける認定 | 【Fact】「介護給付を受けようとする被保険者は、要介護者に該当すること及びその該当する要介護状態区分について、市町村の**認定**…を受けなければならない」（法第19条第1項）。**これがないとサービスが始まらない** |
| **要介護状態区分** | 要支援1〜2／要介護1〜5 | 介護がどれくらい必要かを表す区分 | 【Fact】法第7条。事業所にとっては**単位数を決める数字**（`12_business-model.md` 12-1）。同時に**限度額**も決まる |
| **認定調査** | ― | 市町村の職員等が本人に面接して心身の状況を調べること | 【Fact】法第27条第2項。【Fact】基本調査74項目と特記事項（出典：介護保険制度の概要（令和7年7月）／厚生労働省老健局） |
| **主治医意見書** | ― | 市町村が主治の医師に求める、本人の状態についての意見 | 【Fact】法第27条第3項。認定調査とあわせて一次判定に使われる |
| **介護認定審査会** | ― | 一次判定の結果と主治医意見書をもとに、要介護度を審査・判定する合議体 | 【Fact】法第27条第4項・第5項。これが二次判定にあたる |
| **認定有効期間** | ― | 要介護認定の効力が続く期間 | 【Fact】介護保険法施行規則第38条。【Fact】更新の申請は満了の日の**60日前**から（同規則第39条）。**切れていると請求が通らないことがある**ため、⑨請求事務機能が期限管理を行う |
| **区分支給限度基準額** | 居宅介護サービス費等区分支給限度基準額 | 1か月に保険を使える上限（単位数） | 【Fact】法第43条第1項「…**区分支給限度基準額**を基礎として…算定した額の**百分の九十に相当する額を超えることができない**」。【Fact】管理期間は「**当該月の初日からの一月間**」（施行規則第67条）。現場では「**限度額**」と略す。**超えた分は全額自己負担** |
| **指定** | 指定居宅サービス事業者の指定 ほか | 介護保険のサービスを提供してよい、という行政の指定 | 【Fact】居宅サービスは**都道府県知事**（法第41条第1項）、地域密着型サービスと居宅介護支援は**市町村長**（法第42条の2第1項、第46条第1項）。**指定がなければ介護報酬を請求できない** |
| **指定権者** | ― | 指定を行う行政 | 実務では「指定権者に体制届を出す」「指定権者から実地指導の通知が来た」という使い方をする |
| **指定の更新** | ― | 指定は期限つきで、更新しないと効力を失う | 【Fact】「第四十一条第一項本文の指定は、**六年ごとにその更新**を受けなければ、その期間の経過によって、その効力を失う」（法第70条の2第1項） |
| **運営基準** | 指定居宅サービス等の事業の人員、設備及び運営に関する基準（平成11年厚生省令第37号） | 事業所が守るべき人員・設備・運営の具体的なルールを定めた省令 | 日々の運営で最も参照される。**介護保険法とは別の法令**。「基準第99条」のように条番号で呼ぶ |
| **人員配置基準** | ― | どの職種を、何人以上、どういう勤務形態で置かなければならないかの最低ライン | 【Fact】通所介護は基準第93条、訪問介護は基準第5条。**満たせないと減算**（介護報酬の算定構造／厚生労働省）。現場では「人員基準を割る」という言い方をする |
| **設備基準** | ― | 事業所が備えなければならない設備の基準 | 【Fact】通所介護は「**食堂、機能訓練室、静養室、相談室及び事務室**」（基準第95条第1項）。【Fact】食堂＋機能訓練室の合計面積は「**三平方メートル**に…**利用定員**…を乗じて得た面積以上」（同条第2項第1号イ）。**これが定員の上限を決める** |
| **常勤換算方法** | ― | 非常勤も含めた職員の人数を、常勤の人数に換算する数え方 | 【Fact】「当該事業所の従業者の**勤務延時間数**を当該事業所において**常勤の従業者が勤務すべき時間数で除する**ことにより…換算する方法」（基準第2条第8号）。【Fact】訪問介護は「常勤換算方法で、**二・五以上**」（基準第5条第1項） |
| **地域密着型サービス** | ― | その市町村の住民が利用することを基本とするサービス類型 | 【Fact】市町村長が指定する（法第42条の2第1項）。【Fact】通所介護は利用定員19人以上、18人以下は**地域密着型通所介護**（法第8条第7項・第17項、施行規則第10条の2）。事業者から見ると、**市町村をまたいで利用者を集めることが原則できない**【Inference】 |

## B. 人・職種（12語）

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **ケアマネジャー** | 介護支援専門員 | 利用者の状態と希望に応じてケアプランを作り、サービス全体を調整する専門職 | 【Fact】法第7条第5項の定義。【Fact】介護支援専門員証の有効期間は**5年**（法第69条の7第3項）。**社外の人だが、事業所の入口を握る位置にいる**（`06_people.md` 6-3）。現場では「ケアマネ」と略す |
| **主任介護支援専門員** | ― | 一定の要件を満たしたケアマネジャー | 【Fact】「指定居宅介護支援事業所の管理者は、**主任介護支援専門員**でなければならない」（指定居宅介護支援等基準第3条第2項。原則） |
| **生活相談員** | ― | 通所介護等で、利用者・家族・ケアマネジャーとの窓口になる職種 | 【Fact】通所介護の法定職種（基準第93条第1項第1号）。条文上「提供している時間帯に…勤務している時間数の合計数を…除して得た数が**一以上**」。**一般の業界でいう営業に最も近い機能**だが、価格交渉はない（公定価格のため） |
| **介護職員** | ― | 入浴・排せつ・食事等の介護を直接行う職種 | 【Fact】通所介護の法定職種（基準第93条第1項第3号）。【Fact】「介護職員を、**常時一人以上**…従事させなければならない」（同条第2項）。**通所介護の介護職員には条文上の資格の限定がない** |
| **介護福祉士** | ― | 社会福祉士及び介護福祉士法に基づく国家資格 | 【Fact】「**介護福祉士の名称を用いて**、専門的知識及び技術をもつて…介護…を行い…指導を行うことを業とする者」（社会福祉士及び介護福祉士法第2条第2項）。**名称独占であって業務独占ではない**（`03_company-structure.md` ③） |
| **訪問介護員** | 訪問介護員等 | 利用者の自宅を訪問して介護を行う職種。現場では「ヘルパー」と呼ぶ | 【Fact】「指定訪問介護の提供に当たる**介護福祉士又は法第八条第二項に規定する政令で定める者**」（基準第5条第1項）。**訪問介護には資格要件がある**点が通所介護と違う |
| **サービス提供責任者** | ― | 訪問介護事業所で、計画作成・ケアマネジャー対応・訪問介護員の指導等を担う職種 | 【Fact】「**利用者…の数が四十又はその端数を増すごとに一人以上**の者を…としなければならない」（基準第5条第2項）。【Fact】利用者の数は「**前三月の平均値**」（同条第3項）。【Fact】「**介護福祉士その他厚生労働大臣が定める者**であって、**専ら指定訪問介護に従事するもの**」（同条第4項）。現場では「サ責（させき）」と略す |
| **看護職員** | 看護師又は准看護師 | 医療の視点で健康状態を確認し、判断・連絡する職種 | 【Fact】通所介護の法定職種（基準第93条第1項第2号）。「今日入浴させてよいか」「この血圧で運動してよいか」の判断を担う |
| **機能訓練指導員** | ― | 心身の機能の減退を防ぐ訓練を計画・実施する職種 | 【Fact】通所介護の法定職種で「**一以上**」（基準第93条第1項第4号）。【Fact】「**日常生活を営むのに必要な機能の減退を防止するための訓練を行う能力を有する者**」とし、「**他の職務に従事することができる**」（同条第5項）。【Typical】看護職員や理学療法士等が兼務することが多い |
| **福祉用具専門相談員** | ― | 福祉用具の選定の相談に応じ、貸与計画を作る職種 | 【Fact】指定福祉用具貸与事業所に**常勤換算方法で2以上**（基準第194条第1項）。【Fact】福祉用具貸与計画を作成し、利用者の同意を得て、**利用者及び介護支援専門員に交付**する（基準第199条の2） |
| **管理者** | ― | 事業所の従業者と業務を一元的に管理する責任者 | 【Fact】通所介護は「専らその職務に従事する**常勤の管理者**」（基準第94条）。ただし管理上支障がない場合は他の職務・他の事業所の職務を兼ねられる（同条ただし書）。【Fact】**通所介護計画の作成は管理者の職務**（基準第99条第1項） |
| **地域包括支援センター** | ― | 地域住民を包括的に支援する施設 | 【Fact】法第115条の46第1項。【Fact】要介護認定の申請手続の代行が認められている（法第27条第1項後段）。事業所から見ると、**相談の入口のひとつ** |

## C. 計画・プロセス（10語）

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **ケアプラン** | 居宅サービス計画 | 利用者の生活全体の目標と、使うサービスの組み合わせを書いた計画 | 【Fact】**ケアマネジャーが作る**（指定居宅介護支援等基準第13条第8号）。【Fact】事業者は「**当該計画に沿った**…サービスを**提供しなければならない**」（指定居宅サービス等基準第16条）。**事業所の個別援助計画の上位にある計画** |
| **個別援助計画** | ― | 事業所が自分のサービスについて作る計画の総称 | 通所介護なら通所介護計画、訪問介護なら訪問介護計画。**ケアプランとは作る人も範囲も違う**（PART 2 参照） |
| **通所介護計画** | ― | 通所介護事業所が作る個別援助計画 | 【Fact】基準第99条。**管理者**が作成（第1項）→ 居宅サービス計画の内容に沿って（第2項）→ 説明と**同意**（第3項）→ **交付**（第4項）→ **実施状況及び目標の達成状況の記録**（第5項）。**完結の日から2年間保存**（基準第104条の4第2項第1号） |
| **訪問介護計画** | ― | 訪問介護事業所が作る個別援助計画 | 【Fact】基準第24条。**サービス提供責任者**が作成（第1項）。【Fact】「作成後、…**実施状況の把握**を行い、**必要に応じて…変更**を行う」（第5項）。**条文の書き方が通所介護と違う** |
| **アセスメント** | ― | 心身の状況、環境、希望を把握して、解決すべき課題を明らかにすること | 【Fact】ケアマネジャーは「**利用者の居宅を訪問し、利用者及びその家族に面接して**行わなければならない」（指定居宅介護支援等基準第13条第7号）。【Fact】事業者側にも把握の努力義務（指定居宅サービス等基準第13条） |
| **サービス担当者会議** | ― | ケアマネジャーが開催し、関係する専門職が集まって検討する会議 | 【Fact】指定居宅介護支援等基準第13条第9号。**事業所どうしが情報を交換できる数少ない場**【Inference】。【Fact】個人情報を用いるには**あらかじめ文書による同意**が必要（指定居宅サービス等基準第33条第3項） |
| **モニタリング** | ― | 計画どおりに進んでいるかを継続して確認すること | 【Fact】ケアマネジャーは特段の事情のない限り「**少なくとも一月に一回**、利用者の居宅を訪問し、**利用者に面接すること**」「**少なくとも一月に一回**、モニタリングの結果を**記録すること**」（指定居宅介護支援等基準第13条第14号）。事業所はこれに協力する |
| **居宅介護支援** | ― | ケアマネジャーが行うサービスそのもの | 【Fact】法第8条第24項に定義。【Fact】**利用者負担が発生しない**（法第46条第2項に「百分の九十」の定めがない）。【Fact】市町村長が指定（法第46条第1項） |
| **給付管理／給付管理票** | ― | 1人の利用者が1か月に使ったサービスの量を、ケアマネジャーが取りまとめること／その書類 | 【Varies】「給付管理票」は**実務上の帳票名であり、この名称を用いた条文は確認できていない**（`19_sources.md` §5）。国保連はこれと事業所の明細書を突き合わせる【Typical】。**内容が一致しないと返戻になる** |
| **重要事項説明書** | ― | サービス開始前に利用者・家族に交付して説明する文書 | 【Fact】「…**運営規程の概要**、…**勤務の体制**その他の…**重要事項を記した文書を交付して説明**を行い、…**同意を得なければならない**」（基準第8条第1項。第105条で準用）。利用料・実費・苦情窓口・緊急時の対応が書かれる |

## D. お金（15語）

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **介護報酬** | ― | 介護保険のサービスを提供したときに受け取る報酬。公定価格 | 【Fact】「基本報酬」と「加算・減算」で構成される（出典：介護保険制度の概要（令和7年7月）／厚生労働省老健局）。**事業所が値段を決められない** |
| **単位** | ― | 介護報酬の大きさを表す数え方。円ではない | 【Fact】通所介護（通常規模型・7時間以上8時間未満・要介護2）は**777単位**（出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。**円に換算するには地域区分に応じた単価を掛ける** |
| **地域区分** | ― | 1単位あたりの円換算額を地域ごとに分けた区分 | 【Fact】**1級地・2級地・3級地・4級地・5級地・6級地・7級地・その他の8区分**（出典：介護給付費算定に係る体制等に関する届出等における留意点について／厚生労働省）。体制届の「地域区分」欄で届け出る。**本資料では級地ごとの円単価を示していない**【Varies】 |
| **基本報酬** | ― | サービスの基本的な提供に対する報酬 | 【Fact】通所介護は提供時間区分と要介護度で決まる。**全国共通なので、これだけでは事業所ごとの差は生まれない**【Inference】 |
| **加算** | ― | 要件を満たした場合に、基本報酬に上乗せして算定できるもの | 【Fact】通所介護には入浴介助加算、中重度者ケア体制加算、個別機能訓練加算 ほか（同上）。【Typical】体制届の提出と、要件を満たす取組の実施・**記録**の両方が必要。**値上げではない**（PART 2 参照） |
| **減算** | ― | 基準を満たしていない場合に引かれるもの | 【Fact】利用者の数が利用定員を超える場合、**看護・介護職員の員数が基準に満たない場合**、高齢者虐待防止措置未実施減算、業務継続計画未策定減算、事業所が送迎を行わない場合 ほか（同上）。**気づかないうちに該当しうる** |
| **法定代理受領サービス** | ― | 保険給付分が事業者に直接支払われる形でのサービス提供 | 【Fact】基準第2条に定義。【Fact】「…**居宅介護サービス費用基準額**から…**居宅介護サービス費の額を控除して得た額**の支払を受ける」（基準第96条第1項）＝利用者から受け取るのは1〜3割 |
| **代理受領** | ― | 市町村が保険給付分を利用者に代わって事業者に支払う仕組み | 【Fact】「…当該居宅要介護被保険者に**代わり**、当該指定居宅サービス事業者に**支払うことができる**」（法第41条第6項）。**利用者が全額を立て替えなくてよい** |
| **負担割合証** | ― | 利用者の自己負担が1割・2割・3割のどれかを示す、市町村が交付する証明書 | 毎年更新される。新しいものを確認してシステムの設定を変更する。**見落とすと、利用者から受け取る額と国保連に請求する額の両方が間違う** |
| **国保連** | 国民健康保険団体連合会 | 市町村から委託を受けて介護報酬の請求を審査し、支払う組織 | 【Fact】「…審査及び支払に関する事務を**国民健康保険団体連合会に委託することができる**」（法第41条第10項）。【Fact】サービスの質の向上に関する調査と事業者への指導・助言も行う（法第176条第1項第3号） |
| **介護給付費請求書・介護給付費明細書** | ― | 国保連に提出する請求の書類（電子データ） | 【Fact】「**電子情報処理組織**を使用して…記録し、又は…**光ディスク等**を…提出して行う」（請求に関する命令第2条第1項）。【Fact】「各月分について**翌月十日まで**」（同第3条第1項） |
| **サービス提供実績記録票** | ― | 利用者ごとの提供実績をまとめた帳票 | 【Typical：様式名】ケアマネジャーに実績を報告し、給付管理の内容と突き合わせるために使う |
| **返戻** | へんれい | 請求が審査を通らず差し戻されること。その月は入金されない | 【Typical】原因は被保険者番号の誤り、認定有効期間切れ、給付管理票との不一致、限度額超過など。**事業所の外で起きた変化でも起こる**（`08_money.md` 8-3） |
| **過誤** | かご | いったん支払われた請求を取り下げ、正しい内容で請求し直すこと | 【Typical】保険者に**過誤申立て**を行い、取り下げてから再請求する |
| **介護報酬改定** | ― | 介護報酬の単位数・要件が見直されること | 【Fact】市町村介護保険事業計画は「**三年を一期とする**」（法第117条第1項）。この周期に合わせて改定されるのが通例。【Fact】2026年度（令和8年度）は期中改定で**＋2.03%（公費＋518億円）**（出典：令和8年度介護報酬改定の概要／厚生労働省老健局） |

## F. 安全・記録・その他（12語）

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **身体的拘束等** | ― | 利用者の身体を拘束し、行動を制限する行為 | 【Fact】「**当該利用者又は他の利用者等の生命又は身体を保護するため緊急やむを得ない場合を除き**、身体的拘束等を**行ってはならない**」（基準第98条第3号）。【Fact】行う場合は「**態様及び時間**、その際の**利用者の心身の状況**並びに**緊急やむを得ない理由**」を記録（同条第4号）。**完結の日から2年間保存** |
| **BCP** | 業務継続計画 | 感染症や災害が起きても、サービスを続ける／早く再開するための計画 | 【Fact】基準第30条の2第1項（第105条で準用）。第2項＝**周知と研修及び訓練を定期的に実施**、第3項＝**定期的な見直し**。【Fact】**業務継続計画未策定減算**がある（介護報酬の算定構造／厚生労働省）。**作っていないこと自体が収入を下げる** |
| **ヒヤリハット** | ― | 事故には至らなかったが「ヒヤリとした」「ハッとした」出来事 | 【Varies】**法令が記録を義務づけているわけではない**。【Typical】多くの事業所が自主的に記録している。事故報告（基準第104条の3）とは別のもの |
| **事故報告** | ― | 事故が発生した場合の連絡と記録 | 【Fact】「**市町村、当該利用者の家族、当該利用者に係る居宅介護支援事業者等に連絡**を行うとともに、**必要な措置**を講じなければならない」（基準第104条の3第1項）。【Fact】記録（同条第2項）、賠償（同条第3項）。**様式・報告対象は市町村により異なる**【Varies】 |
| **運営推進会議** | ― | 利用者・家族・地域住民の代表者・市町村の職員等で構成する協議会 | 【Fact】**地域密着型サービス**の規定。「…を**設置**し、**おおむね六月に一回以上**、…**活動状況を報告**し、…**評価を受ける**」（指定地域密着型サービス基準第34条第1項）。【Fact】記録を作成し**公表**（同条第2項）。**定員19人以上の通所介護には、この義務はない** |
| **虐待の防止** | ― | 虐待の発生・再発を防ぐための措置 | 【Fact】基準第37条の2：①**委員会を定期的に開催**、②**指針の整備**、③**研修を定期的に実施**、④**担当者を置く**。【Fact】**高齢者虐待防止措置未実施減算**がある |
| **要配慮個人情報** | ― | 取扱いに特に配慮を要する個人情報 | 【Fact】「本人の**人種、信条、社会的身分、病歴、犯罪の経歴、犯罪により害を被った事実**その他…政令で定める記述等が含まれる個人情報」（個人情報保護法第2条第3項）。**介護記録には「病歴」が含まれる**【Inference】 |
| **秘密保持** | ― | 業務上知り得た利用者・家族の秘密を漏らさないこと | 【Fact】「**従業者**は、**正当な理由がなく**、その業務上知り得た**利用者又はその家族の秘密を漏らしてはならない**」（基準第33条第1項）。【Fact】**従業者であった者**についても事業者が必要な措置を講じる（同条第2項） |
| **運営規程** | ― | 事業所のルールブック | 【Fact】基準第100条が**11事項**を列挙（`10_documents.md` 10-6）。【Fact】**掲示**の対象でもある（基準第32条第1項） |
| **通常の事業の実施地域** | ― | 事業所が通常サービスを提供する範囲 | 【Fact】運営規程に定める（基準第100条第6号）。【Fact】この地域以外に居住する利用者の送迎に要する費用は、利用者から受け取ることができる（基準第96条第3項第1号） |
| **勤務形態一覧表** | ― | 職員ごとの職種・勤務形態・勤務時間をまとめた表 | 【Typical：様式名】【Fact】「**従業者の勤務の体制を定めておかなければならない**」（基準第101条第1項）に対応する。**人員配置基準を満たしていることを示す書類**。実地指導で確認される代表的な書類【Typical】 |

## G. 商取引・会計の基本語（18語）

**介護業界固有ではありませんが、事業を理解するうえで必要な言葉です。**

| 用語 | 正式名称 | 簡単な意味 | 実務ではどう使う？ |
|---|---|---|---|
| **売上** | ― | サービスを提供したことで発生する収益 | 介護では**サービスを提供した月**に発生する。現金が入る月とは違う |
| **入金** | ― | 実際にお金が口座に入ること | 保険給付分は**サービス提供月の約2か月後**【Typical】 |
| **売掛金** | ― | 売上は立ったが、まだ受け取っていないお金 | 11月分の保険給付分は、入金されるまで売掛金として残る |
| **未収金** | ― | 回収できていないお金 | 【Typical】利用者負担分の口座振替が失敗した場合などに生じる。**保険給付分には、この形の未収は起きにくい**【Inference】 |
| **締め日** | ― | 請求のために集計を区切る日 | 介護では**月末**が締めになる。【Fact】限度額の管理期間が「当該月の初日からの一月間」（施行規則第67条）であることと整合している |
| **消込（けしこみ）** | ― | 入金があったときに、対応する売掛金を帳簿上で消すこと | 【Typical】請求額と入金額を突き合わせ、差があれば返戻・査定の内容を確認する |
| **粗利（あらり）** | 売上総利益 | 売上から直接かかった費用を引いたもの | 介護では人件費の比重が大きいため、一般の製造業・小売業のような「売上−仕入」という形にはなりにくい【Inference】 |
| **販管費** | 販売費及び一般管理費 | 事業を運営するためにかかる費用 | 家賃、水道光熱費、通信費、保険料、専門家報酬など |
| **営業利益** | ― | 粗利から販管費を引いたもの | 「粗利＝利益」ではない |
| **固定費** | ― | 売上が減っても減らない費用 | 介護では家賃、設備、**人件費の一部**が該当する【Inference】。【Fact】人員配置基準が下限を決めているため（基準第93条ほか） |
| **変動費** | ― | 売上に比例して増減する費用 | 介護では食材費、消耗品費が該当しやすい【Inference】 |
| **資金繰り** | ― | 現金の入りと出のやりくり | 介護では**保険給付分が約2か月後に入る**ため、利益とは別に管理する必要がある |
| **運転資金** | ― | 事業を回していくために必要な手元の現金 | 【Inference】開業時は、最初の入金までの数か月分の人件費等を先に支払うことになる |
| **減価償却** | ― | 建物や設備の購入額を、使用する期間にわたって費用として配分すること | 送迎車両、入浴設備、建物が対象になりうる |
| **リース** | ― | 設備を買わずに借りて使う契約 | 【Varies】送迎車両を自社所有にするかリースにするかは事業所による |
| **与信** | ― | 相手が支払えるかを見極めること | 【Inference】介護では、保険給付分は国保連を経由するため、一般の取引のような与信管理はなじまない。一方、**利用者負担分は通常の売掛金と同じ性質**を持つ |
| **公定価格** | ― | 国が決めた価格。事業者が自由に決められない | 【Fact】介護報酬がこれにあたる（法第41条第4項）。**価格競争が起きにくい構造**をつくっている【Inference】 |
| **稼働率** | ― | 器（定員・座席・客室など）がどれだけ埋まったかの割合 | 通所介護では **1日平均利用者数 ÷ 利用定員**。【Inference】空いた席は翌日に持ち越せない |

**合計：18＋12＋10＋15＋11＋12＋18 ＝ 96語**

# PART 2. 初心者が間違えやすいこと

各項目は **①何と何が違うか ②なぜ混同するか ③実務でどう効いてくるか** の順で書きます。

---

## 【共通の基本】6項目

### 共通1. 売上 ≠ 入金

| | 内容 |
|---|---|
| **何と何が違うか** | **売上**はサービスを提供した時点で発生する。**入金**は現金が口座に入った時点。介護では保険給付分の入金が**サービス提供月の約2か月後**になる【Typical】 |
| **なぜ混同するか** | 一般の生活では「売れた＝お金が入った」という感覚があるため。また、介護では利用者負担分（1〜3割）が比較的早く入るので、「入っている」と感じやすい |
| **実務でどう効くか** | 【Inference】通帳の残高だけを見ていると、**業績の悪化に約2か月遅れて気づく**。だから事業所は、入金額ではなく**その月の稼働率・総単位数**を先に見る（`14_kpi.md` 14-7）。開業時は、最初の入金まで人件費を先に払い続けることになる |

### 共通2. 受注 ≠ 売上（介護では「照会を受けた ≠ 売上」）

| | 内容 |
|---|---|
| **何と何が違うか** | 一般の業界の「受注」にあたるのは、介護では**ケアマネジャーからの照会に「受入れ可能」と回答した時点**。しかし**そこではまだ売上にならない**。売上になるのは、**ケアプランに位置づけられ、契約し、個別援助計画を作り、実際にサービスを提供した**とき |
| **なぜ混同するか** | 「利用が決まった」と聞くと、注文が確定したように感じるため |
| **実務でどう効くか** | 【Inference】照会から利用開始までには、サービス担当者会議、契約、計画作成という段階がある（`04_end-to-end-process.md` A①〜A⑨）。途中で利用者・家族の意向が変わることもある。**「受入れ可能と答えた件数」と「実際に利用が始まった件数」は別の数字**として見ることになる |

### 共通3. 発注 ≠ 仕入計上

| | 内容 |
|---|---|
| **何と何が違うか** | 食材や消耗品を**注文しただけ**では費用にならない。**納品されて初めて**仕入・費用になる |
| **なぜ混同するか** | 注文した時点で「買った」と感じるため |
| **実務でどう効くか** | 【Typical】食材は前日までに手配する。当日キャンセルが出ても、すでに納品された食材の費用は残る（`07_goods.md` 7-5）。**注文の時点と費用が立つ時点がずれる** |

### 共通4. 在庫 ≠ すべて完成品（介護では「在庫という概念が薄い」）

| | 内容 |
|---|---|
| **何と何が違うか** | 介護には、製造業のような原材料・仕掛品・完成品という在庫がない。**あるのは消耗品の在庫（おむつ・手袋・リネン・食材）だけ**。しかも**サービスそのものは在庫できない** |
| **なぜ混同するか** | 他業界の枠組みをそのまま当てはめようとするため |
| **実務でどう効くか** | 【Inference】今日空いた席を明日に持ち越せない（`14_kpi.md` 14-1）。一方、消耗品を切らすと**決められた手順が実行できなくなる**（感染対策の手袋・エプロン等）。**「在庫を減らす」という考え方がそのままは通用しない** |

### 共通5. 粗利 ≠ 利益

| | 内容 |
|---|---|
| **何と何が違うか** | 粗利（売上総利益）から販管費を引いて初めて営業利益になる |
| **なぜ混同するか** | 「売上が大きい＝儲かっている」と感じるため |
| **実務でどう効くか** | 【Inference】介護では**人件費が最大の費目**であり、【Fact】人員配置基準がその下限を決めている（基準第93条ほか）。売上が大きくても、必要な人員を置けば費用も大きい。**「売上が増えた」だけでは経営状態は分からない** |

### 共通6. 見積 ≠ 契約（介護では「見学・体験 ≠ 利用開始」）

| | 内容 |
|---|---|
| **何と何が違うか** | 見学・体験利用をしても、**契約が成立したわけではない**。さらに契約しても、**個別援助計画に同意を得るまでサービスは始まらない**（【Fact】基準第99条第3項） |
| **なぜ混同するか** | 体験まで来た人は「もう決まった」と感じやすいため |
| **実務でどう効くか** | 【Inference】稼働率の見込みを立てるとき、「体験に来た人数」をそのまま計算に入れると実態と合わなくなる。**見学・体験・契約・利用開始を分けて数える**ことになる |

## 【介護固有】12ペア

### 固有1. 介護保険 ≠ 医療保険

| | 内容 |
|---|---|
| **何と何が違うか** | **介護保険**は介護保険法（平成9年法律第123号）に基づく制度で、【Fact】保険者は**市町村及び特別区**（法第3条第1項）、利用には【Fact】**要介護認定**が必要（法第19条第1項）。**医療保険**は別の制度で、保険者も給付の仕組みも異なる |
| **なぜ混同するか** | どちらも「保険証を出して1〜3割払う」ように見えるため。また、デイサービスに**看護職員**がいて、バイタルを測り、主治医と連絡をとるため、医療に見える場面がある |
| **実務でどう効くか** | 【Inference】同じ行為でも、どちらの制度で給付されるかが違う。請求先も違う（介護は国保連への介護給付費請求）。利用者・家族から「保険がきくのか」と聞かれたときに、**どちらの保険の話かを確認する**必要がある。**本資料は医療保険制度の詳細を扱っていない**ため、断定的な説明はしない【Varies】 |

### 固有2. 要支援 ≠ 要介護

| | 内容 |
|---|---|
| **何と何が違うか** | 【Fact】介護保険法第7条は**要介護状態**（第1項）と**要支援状態**（第2項）、**要介護者**（第3項）と**要支援者**（第4項）を**別々に定義**している。区分も要支援1〜2と要介護1〜5で分かれる |
| **なぜ混同するか** | どちらも「認定を受けている人」であり、日常会話では「介護認定を受けている」とまとめて言われるため |
| **実務でどう効くか** | 【Inference】受けられるサービスの枠組みが違い、限度額も違う。ケアマネジメントを担う相手も異なることがある（【Fact】地域包括支援センターは法第115条の46）。**照会を受けた段階で、要支援か要介護かを必ず確認する**ことになる |

### 固有3. ケアプラン ≠ 個別援助計画

**この2つの混同が、介護の初心者が最もつまずく点です。**

| | 内容 |
|---|---|
| **何と何が違うか** | **ケアプラン（居宅サービス計画）**＝**ケアマネジャー**が作る。**生活全体**の目標と、使うサービスの組み合わせを書く。／ **個別援助計画（通所介護計画）**＝**事業所**が作る。**自分の事業所のサービス**について、目標と具体的なサービスの内容を書く。【Fact】通所介護計画は**管理者**が作成（基準第99条第1項）、訪問介護計画は**サービス提供責任者**が作成（基準第24条第1項） |
| **なぜ混同するか** | どちらも「計画」という名前で、どちらも利用者の目標が書かれているため。しかも内容は関連している |
| **実務でどう効くか** | 【Fact】「通所介護計画は、既に居宅サービス計画が作成されている場合は、**当該居宅サービス計画の内容に沿って作成しなければならない**」（基準第99条第2項）。つまり**上下関係がある**。ケアプランが変われば個別援助計画も変わる。**どちらも利用者の同意と交付が必要**（【Fact】基準第99条第3項・第4項／指定居宅介護支援等基準第13条第10号・第11号）。実地指導では**両方**が確認される【Typical】 |

### 固有4. 単位 ≠ 円

| | 内容 |
|---|---|
| **何と何が違うか** | 介護報酬は「**単位**」で定められており、円ではない。【Fact】円に換算するには、事業所の所在する地域等を勘案して厚生労働大臣が定める基準による（法第41条第4項第1号）。【Fact】地域区分は**8区分**（出典：介護給付費算定に係る体制等に関する届出等における留意点について／厚生労働省） |
| **なぜ混同するか** | 「1単位＝10円」という説明例が広く使われるため、**そのまま実際の金額だと思い込みやすい** |
| **実務でどう効くか** | 【Inference】同じ777単位でも、東京23区の事業所と地方の事業所では円換算額が違う。したがって、**他の地域の事業所の売上と単純に比較できない**。また、【Fact】区分支給限度基準額も**単位数**で定められているため、限度額の管理は単位で行う。**本資料では級地ごとの円単価を示していない**【Varies】 |

### 固有5. 利用者が払う額 ≠ 事業所の収入

| | 内容 |
|---|---|
| **何と何が違うか** | 利用者が窓口で払うのは、介護保険部分については**1〜3割だけ**（【Fact】法第41条第4項・第49条の2）。残りの7〜9割は**国保連を経由して**事業所に入る（【Fact】法第41条第6項の代理受領、第10項の委託） |
| **なぜ混同するか** | 買い物では「払った額＝店の売上」だから。利用者・家族も「1万円しか払っていないのに」と感じることがある |
| **実務でどう効くか** | 【Example】1か月の費用額が100,000円（1割負担の人）なら、利用者から10,000円、国保連から90,000円。つまり**事業所の収入の大半は利用者以外から入る**。一方、**入るタイミングも違う**（利用者負担分は翌月【Typical】、保険給付分は約2か月後【Typical】）。資金繰り表では**2つを分けて置く**（`08_money.md` 8-8） |

### 固有6. 請求 ≠ 入金

| | 内容 |
|---|---|
| **何と何が違うか** | 【Fact】請求は「各月分について**翌月十日まで**」（請求に関する命令第3条第1項）。しかしその後、【Fact】国保連による**審査**があり（法第41条第9項・第10項）、入金は【Typical】**サービス提供月の約2か月後** |
| **なぜ混同するか** | 「請求した＝お金が入る」と考えてしまうため。また、請求作業が終わると仕事が完了した感覚になるため |
| **実務でどう効くか** | 【Inference】請求した額がそのまま入るとは限らない。**返戻**になればその月は入らず、再請求すればさらに約2か月遅れる。だから⑨請求事務機能の仕事は、請求を出して終わりではなく、**返戻の確認・再請求・消込**まで続く（`04_end-to-end-process.md` C④〜C⑥） |

### 固有7. 介護保険サービス ≠ 実費サービス

| | 内容 |
|---|---|
| **何と何が違うか** | 【Fact】基準第96条第3項は、介護報酬とは別に利用者から受け取ることができる費用として「**食事の提供に要する費用**」「**おむつ代**」「通常の事業の実施地域以外の地域に居住する利用者に対して行う**送迎に要する費用**」などを列挙している。これらは**介護保険の外**である |
| **なぜ混同するか** | 利用者への請求書に、介護保険の自己負担分と実費が**一緒に載る**ため。利用者からは「デイの料金」に見える |
| **実務でどう効くか** | 【Inference】① **限度額の対象にならない**（限度額を超えても、食費は変わらない）。② **保険給付分のような約2か月の時間差がない**（利用者から直接、翌月に回収できる【Typical】）。③ 【Fact】あらかじめ説明し、**利用者の同意を得なければならない**（基準第96条第5項）。説明していない費用は受け取れない。④ 会計上も分けて管理する |

### 固有8. 加算 ≠ 値上げ

| | 内容 |
|---|---|
| **何と何が違うか** | 加算は事業所が値段を上げるものではない。**要件を満たした場合に算定できる**もの。【Typical】体制届の提出と、要件を満たす取組の実施・**記録**の両方が必要 |
| **なぜ混同するか** | 利用者から見ると「請求額が増えた」という点で値上げと同じに見えるため |
| **実務でどう効くか** | 【Inference】① 要件を満たさないまま算定すれば、あとで**返還**を求められることがある。② 【Fact】審査は「運営に関する基準…に**照らして**」行われる（法第41条第9項）ため、**記録がなければ算定の根拠を示せない**。③ 加算には職員の配置・計画の作成・実施と記録といった**業務（＝費用）が伴う**。④ 算定を始めるときは、利用者への説明と重要事項説明書の記載も関わる【Typical】。**本資料はどの加算を取るべきかを提案しない** |

### 固有9. 人員基準を満たす ≠ 十分な人手がある

| | 内容 |
|---|---|
| **何と何が違うか** | 人員配置基準は**法令上の最低ライン**である。【Fact】たとえば通所介護の介護職員は「利用者の数が**十五人までの場合にあっては一以上**、十五人を超える場合にあっては十五人を超える部分の数を五で除して得た数に一を加えた数以上」（基準第93条第1項第3号）。これは「これだけいれば余裕がある」という意味ではない |
| **なぜ混同するか** | 「基準を満たしている」＝「問題ない」と読めてしまうため |
| **実務でどう効くか** | 【Inference】介助に手がかかる利用者が多い日、入浴の人数が多い日、送迎で職員が外に出ている時間帯は、**基準を満たしていても実際の手は足りないことがある**。だから `14_kpi.md` 14-4 では、人員配置基準の充足状況とは別に「職員1人あたりの利用者数」を見る。**本資料は人手の多寡について評価を書かない** |

### 固有10. 記録した ≠ 請求できる

| | 内容 |
|---|---|
| **何と何が違うか** | 記録があることは必要だが、それだけでは足りない。**算定する加算の要件を満たしていることが記録から分かる**必要がある。【Fact】審査は「…**指定居宅サービスの事業の設備及び運営に関する基準**…に**照らして審査した上、支払うものとする**」（法第41条第9項） |
| **なぜ混同するか** | 「書いておけば大丈夫」と考えてしまうため |
| **実務でどう効くか** | 【Inference】たとえば「入浴した」とだけ書いてあっても、その加算の要件が満たされたことを示せるとは限らない。【Fact】通所介護計画については「**通所介護計画に従ったサービスの実施状況及び目標の達成状況の記録**を行う」（基準第99条第5項）と、**何を記録するかが条文に書かれている**。**逆に、記録がなければ「実施していても請求できない」**（`09_information.md` 9-0）。**記録は事務作業ではなく、売上の裏付けそのもの** |

### 固有11. 身体拘束の禁止 ≠ 委員会・研修の義務（サービス種別で違う）

| | 内容 |
|---|---|
| **何と何が違うか** | **【通所介護】**＝【Fact】原則禁止（基準第98条第3号）＋記録（同条第4号）**のみ**。身体的拘束等の適正化のための委員会・指針・研修の規定は**ない**。／ **【短期入所生活介護・特定施設入居者生活介護・認知症対応型共同生活介護 等】**＝【Fact】上記に加えて「**身体的拘束等の適正化のための対策を検討する委員会**…を**三月に一回以上**開催」「**指針を整備**」「**研修を定期的に実施**」（基準第128条第6項・第183条第6項、指定地域密着型サービス基準第97条第7項） |
| **なぜ混同するか** | どのサービスでも身体拘束は原則禁止なので、**付随する義務も同じだと思い込みやすい**ため。また、**虐待の防止**については通所介護にも委員会・指針・研修・担当者の規定がある（【Fact】基準第37条の2）ので、これと混ざりやすい |
| **実務でどう効くか** | 【Inference】自事業所に求められる取組を、**サービス種別ごとに条文で確認する**ことになる。「デイサービスだから」「介護事業所だから」と一般化すると、必要な取組を落としたり、不要な取組を求めたりする。**準用の範囲も条文で確認する**（【Fact】基準第105条が列挙する条文だけが通所介護に準用される） |

### 固有12. 通所介護 ≠ 地域密着型通所介護（デイサービスは1種類ではない）

| | 内容 |
|---|---|
| **何と何が違うか** | **通所介護**＝【Fact】利用定員**19人以上**（法第8条第7項、施行規則第10条の2）。指定権者は**都道府県知事**（法第41条第1項）。／ **地域密着型通所介護**＝【Fact】利用定員**18人以下**（法第8条第17項）。指定権者は**市町村長**（法第42条の2第1項）。【Fact】**運営推進会議**をおおむね6月に1回以上（指定地域密着型サービス基準第34条第1項） |
| **なぜ混同するか** | どちらも日常会話では「デイサービス」と呼ばれるため |
| **実務でどう効くか** | 【Inference】① 適用される基準の省令が違う（指定居宅サービス等基準 ／ 指定地域密着型サービス基準）。② 報酬の表も違う。③ 指定・届出・実地指導の相手が違う。④ 地域密着型は、**市町村をまたいで利用者を集めることが原則できない**。⑤ 【Fact】運営推進会議の設置・報告・評価・**記録の公表**という業務が追加される（地域密着型サービス基準第34条第1項・第2項） |

## PART 2 のまとめ ── 混同を避けるための3つの習慣【Inference】

```
【1】「誰が作るか」「誰が決めるか」を必ず確認する
      ケアプラン → ケアマネジャー
      通所介護計画 → 管理者
      訪問介護計画 → サービス提供責任者
      要介護度 → 市町村
      単価 → 厚生労働大臣（地域区分）

【2】「保険の中か外か」を必ず分ける
      介護報酬（1〜3割＋保険給付分。限度額の対象）
      実費（食費・おむつ代等。全額利用者負担。限度額の対象外）

【3】「どの法令か」「どのサービス種別か」を必ず確認する
      介護保険法 と 指定居宅サービス等基準 は別
      指定居宅サービス等基準 と 指定地域密着型サービス基準 は別
      準用される条文は、第105条が列挙しているものだけ
```

## この章のまとめ

- 用語集は**96語**。制度の骨格（18）／人・職種（12）／計画・プロセス（10）／お金（15）／
  サービス種別（11）／安全・記録（12）／商取引・会計の基本語（18）。
- 初心者が間違えやすいこと：**共通6項目＋介護固有12ペア**。
- 介護固有の混同で特に重要なのは次の5つ【Inference】。
  - **ケアプラン ≠ 個別援助計画**（作る人が違い、上下関係がある）
  - **単位 ≠ 円**（地域区分で換算が変わる）
  - **利用者が払う額 ≠ 事業所の収入**（1〜3割のみ）
  - **請求 ≠ 入金**（約2か月後。返戻があればさらに遅れる）
  - **記録した ≠ 請求できる**（要件を満たしたことが分かる記録が要る）
- サービス種別によって適用される条文が違う。
  **「介護事業所だから同じ」と一般化しない。** 準用の範囲は【Fact】基準第105条で確認する。
