## 11-0. この章の立場（最初に明記します）

`common/methodology.md` §0 に従い、**この章は次のことを一切書きません。**

```
✕ DX・ICT化・デジタル化の提案／評価

✕ 「紙は遅れている」「システムを入れるべき」等の価値判断
```

**この章が書くのは1つだけです。**

> **今の介護事業所の仕事を理解するために、
> 「どんな道具が、何のために使われているのか」を説明すること。**

同じ理由で、**紙で記録している事業所についても、価値判断を加えずに事実として記述します**【Varies】。

```
⑬入金情報（と費用の情報）
        └──────── 会計ソフト
```

## 11-1. 介護記録システム

### 何のための道具か

> **用語：介護記録システム（介護ソフトの記録機能）**
> → 利用者の基本情報、計画、日々のバイタル・食事・排せつ・入浴・機能訓練の記録を、
>    紙のかわりに電子的に入力・保存・検索する仕組み。
> → 実務例：介護職員がタブレットで「体温36.5／血圧128-76／昼食 主食10割 副菜8割」と入力すると、
>    その利用者の記録として保存され、月末に実績と突き合わせるときに一覧で見られる。
> → なぜ使うのか：【Fact】事業者には「**提供した具体的なサービスの内容等を記録する**」義務があり
>    （指定居宅サービス等基準第19条第2項。第105条により通所介護に準用）、
>    その記録は【Fact】**完結の日から2年間保存**しなければならない（同基準第104条の4第2項）。
>    記録は毎日・利用者ごとに発生するため、**保管と検索の対象になる情報量が大きい**【Inference】。

### 扱う情報

| 扱う情報（`09_information.md` の番号） | 具体的に入る内容 |
|---|---|
| ⑥契約情報 | 氏名、被保険者番号、保険者番号、要介護度、認定有効期間、負担割合、担当ケアマネジャー、緊急連絡先 |
| ②アセスメント情報 | 心身の状況、できること・できないこと、本人・家族の希望 |
| ⑤個別援助計画情報 | 通所介護計画の目標、具体的なサービスの内容 |
| ⑦日々の介護記録情報 | バイタル、食事・水分の摂取量、排せつ、入浴の実施／中止、機能訓練、特記事項、送迎 |
| ⑧事故・ヒヤリハット情報 | 発生日時・状況・処置【Varies：別管理の事業所もある】 |

### 誰が使うか

| 機能 | 何をするか |
|---|---|
| ③介護職員 | 日々の記録を入力する |
| ④看護職員 | バイタルを確認し、看護に関する記録を入力する |
| ⑤機能訓練指導員 | 機能訓練の実施記録と達成状況を入力する |
| ②生活相談員 | 利用者情報・計画を登録し、ケアマネジャーへの報告に使う |
| ①管理者 | 計画を作成し、記録の整備状況を確認する |
| ⑨請求事務 | 月末に記録と実績入力を突き合わせる |

### 入力される端末【Varies】

【Varies】パソコン、タブレット、スマートフォンなど、事業所により異なります。
【Typical】通所介護では、フロアに据え置いた端末や持ち運べる端末に、その場で入力する形が見られます。

### 記録システムと請求が「つながっている場合」と「つながっていない場合」【Varies】

```
【つながっている場合】
  介護記録の入力  →  そのまま実績データになる  →  請求データへ

【つながっていない場合】
  介護記録（紙またはシステム）
          ↓ 人が読み取って転記する
  請求ソフトへの実績入力
```

> **どちらであっても、月末の突き合わせは行われる**
> 【Inference】つながっている場合でも、「記録はあるが実績入力がない」「実績入力はあるが記録がない」という
> 食い違いは、入力の抜けによって起こりえます。
> `05_departments.md` ⑨-3（月末の実績確定（記録との突き合わせ））は、どちらの形でも必要な業務です。

## 11-2. 介護報酬請求ソフトと、国保連への伝送

### 何のための道具か

> **用語：介護報酬請求ソフト（請求機能）**
> → 提供実績から、サービスコード・単位数・加算・利用者負担額を計算し、
>    **介護給付費請求書・介護給付費明細書**のデータを作る仕組み。
> → 実務例：「要介護2、7時間以上8時間未満、9回、入浴介助加算あり」と実績を確定すると、
>    単位数が集計され、保険給付分と利用者負担分に分かれた請求データができる。

> **用語：伝送ソフト（国保連への請求データの送信に使う仕組み）**
> → 作った請求データを、国民健康保険団体連合会（国保連）へ電子的に送る仕組み。
> → 【Fact】請求は「**電子情報処理組織**を使用して…審査支払機関の電子計算機に備えられたファイルに記録し、
>    又は…**光ディスク等**を審査支払機関に提出して行う」
>    （介護給付費及び公費負担医療等に関する費用等の請求に関する命令第2条第1項）。
> → 【Fact】「電子情報処理組織による…請求は、審査支払機関の電子計算機に備えられたファイルに
>    **記録された時に**審査支払機関に到達したものとみなす」（同命令第3条第2項）。

> **条文が「電子情報処理組織」と書いていることの意味**
> 【Inference】条文は、電子的な方法か光ディスク等による提出かを請求の方法として定めています。
> つまり、**請求という業務そのものが電子的な仕組みを前提に組み立てられています。**
> これは、事業所が導入を選んだ結果ではなく、制度の側の仕組みです。

### 扱う情報

| 扱う情報 | 具体的に入る内容 |
|---|---|
| ⑩実績情報 | 提供日、サービス種類、時間区分、加算の該当、キャンセル |
| ⑪請求情報 | サービスコード、単位数、回数、加算、利用者負担額、保険給付分 |
| ⑫審査結果情報・返戻情報 | 返戻の件数と理由、過誤の申立て |
| ⑬入金情報 | 支払決定額【Varies：会計ソフト側で管理する場合もある】 |

### 誰が使うか

【Typical】⑨請求事務機能。中小事業所では①管理者・②生活相談員が兼務していることが多くあります。

### いつ使うか

| 業務 | 頻度 |
|---|---|
| 日々の実績入力 | 日次 |
| 月末の実績確定 | 月次 |
| 加算・減算の該当確認 | 月次 |
| 区分支給限度基準額の確認 | 月次（【Fact】管理期間は当該月の初日からの一月間。介護保険法施行規則第67条） |
| 請求データの作成と送信 | 月次（【Fact】翌月10日まで。請求に関する命令第3条第1項） |
| 返戻の確認と再請求 | 月次／トラブル発生時 |

### 介護報酬改定のたびに更新が必要になる

【Fact】介護報酬は改定されます（`01_overview.md` 1-5、`08_money.md` 8-9）。
2026年度（令和8年度）には期中改定が行われ、改定率は＋2.03%とされました
（出典：令和8年度介護報酬改定の概要／厚生労働省老健局）。

【Typical】改定時には、請求ソフトの**単位数マスタ**（サービスコードごとの単位数の一覧）を更新します。

> **なぜこれが業務として重いのか**
> 【Inference】単位数マスタが古いままだと、請求額が誤ります。
> 誤った請求は返戻・過誤の原因になり、入金が遅れます。
> つまり、システムの更新が**そのまま収入に直結**します。

### 地域区分の設定

【Fact】1単位あたりの円換算は、事業所の所在する地域等を勘案して算定されます（介護保険法第41条第4項第1号）。
【Fact】実務上、地域は**1級地・2級地・3級地・4級地・5級地・6級地・7級地・その他**の8区分に整理されており、
事業所は体制届の「地域区分」欄で届け出ます
（出典：介護給付費算定に係る体制等に関する届出等における留意点について／厚生労働省）。

【Typical】この地域区分は請求ソフトにも設定され、金額の計算に使われます。

## 11-3. ケアプラン作成ソフト【Varies】

### この道具が置かれる場所

**通所介護事業所には、通常この道具はありません。**
ケアプランを作るのは**居宅介護支援事業所のケアマネジャー**だからです
（`06_people.md` 6-3、`09_information.md` ③ケアプラン情報）。

【Varies】法人が居宅介護支援事業所を併設している場合に限り、この道具が社内にあります。

### 何のための道具か

> **用語：ケアプラン作成ソフト（居宅介護支援ソフト）**
> → アセスメント、居宅サービス計画書（第1表〜第7表等の様式）、サービス担当者会議の記録、
>    モニタリングの記録、**給付管理票**を作成する仕組み。
> → 実務例：ケアマネジャーが「通所介護 週2回、訪問介護 週2回、福祉用具貸与」と計画に位置づけると、
>    月の合計単位数が集計され、区分支給限度基準額の範囲に収まっているかを確認できる。
> → なぜ使うのか：【Fact】ケアマネジャーには、アセスメント（指定居宅介護支援等基準第13条第7号）、
>    原案の作成（同第8号）、サービス担当者会議（同第9号）、説明・同意・交付（同第10号・第11号）、
>    モニタリング（同第14号）といった一連の手続が条文で定められており、
>    それぞれが書類として残る【Inference】。

### 事業所側との接点

```
  【居宅介護支援事業所】               【通所介護事業所】
  ケアプラン作成ソフト                  介護記録システム／請求ソフト
        │                                      │
        │ ケアプラン（③ケアプラン情報）──────▶│
        │                                      │
        │◀── サービス提供実績（⑩実績情報）────│
        │                                      │
   給付管理票 ───┐                  介護給付費明細書 ───┐
                 ▼                                      ▼
              国保連が突き合わせて審査（⑫審査結果情報）
```

【Varies】事業所とケアマネジャーの間で、この情報を**紙・FAX・電子データのどれでやりとりするか**は
事業所とケアマネジャーの組み合わせにより異なります。

## 11-4. 勤務シフト管理・勤怠管理

### 何のための道具か

> **用語：シフト管理（勤務形態一覧表の作成を含む）**
> → 誰がいつ勤務するかを組み、職種ごとの勤務時間を集計する仕組み。
>    表計算ソフトで作っている事業所もあれば、専用の機能を使う事業所もある【Varies】。
> → 実務例：ある日の介護職員の勤務時間の合計を、その日のサービス提供時間で割り、
>    人員配置基準を満たしているかを確認する。
> → なぜ必要なのか：【Fact】「指定通所介護事業所ごとに従業者の**勤務の体制を定めておかなければならない**」
>    （指定居宅サービス等基準第101条第1項）。
>    【Fact】介護職員の員数は「**勤務している時間数の合計数**を…**提供している時間数で除して得た数**」で
>    数える（同基準第93条第1項第3号）。
>    【Fact】訪問介護は**常勤換算方法**で2.5以上（同基準第5条第1項）。
>    常勤換算方法は「当該事業所の従業者の**勤務延時間数**を当該事業所において
>    **常勤の従業者が勤務すべき時間数で除する**」方法（同基準第2条第8号）。

> **この計算が道具を必要にしている**
> 【Inference】人数を「頭数」で数えるなら、紙のシフト表を見れば足ります。
> しかし条文は「**勤務時間の合計を提供時間で割った数**」で数えることを求めています。
> 短時間のパート職員が多い事業所では、この計算を毎日行うことになります。

### 扱う情報

| 扱う情報 | 内容 |
|---|---|
| 勤務予定 | 誰がいつ、どの職種として勤務するか |
| 勤務実績 | 実際の出退勤時刻（タイムカード・打刻） |
| 常勤換算数 | 職種ごとの計算結果 |
| 資格情報 | 介護福祉士、看護師、介護支援専門員 等【Typical】 |

### 誰が使うか

⑪人事・労務機能、①管理者機能。
【Typical】中小事業所では管理者が兼務し、表計算ソフトで作成していることが多くあります【Varies】。

## 11-5. 給与計算・社会保険の手続

### 何のための道具か

【Typical】介護事業所の費用の最大項目は人件費です（`08_money.md` 8-7）。
給与計算は、勤怠の実績から支給額・控除額を計算し、給与明細を作る仕組みです。

| 扱う情報 | 内容 |
|---|---|
| 勤怠情報 | 出退勤、残業、休暇 |
| 給与情報 | 基本給、各種手当、時間給、賞与 |
| 控除情報 | 社会保険料、雇用保険料、源泉所得税、住民税 |

【Varies】自社で計算する事業所と、社会保険労務士に委託する事業所があります。

> **介護に固有の要素【Typical】**
> - 非常勤（登録ヘルパー、短時間パート）の比率が高い場合、時間給の計算が中心になる
> - 資格手当、処遇改善に関する加算に基づく賃金改善など、給与の内訳が複数に分かれることがある【Varies】
> - 【Fact】介護職員等処遇改善加算は、令和8年度改定で拡充されたとされている
>   （出典：令和8年度介護報酬改定の概要／厚生労働省老健局）。
>   **本資料は、この加算をどう算定すべきかという提案は書きません。**

## 11-6. 会計ソフト

### 何のための道具か

> **用語：会計ソフト**
> → 日々の入出金と取引を記録し、試算表・決算書を作る仕組み。
> → 実務例：「11月分の介護報酬 1,258,740円を国保連へ請求」を売掛金として記録し、
>    1月に入金があったときに消し込む（消込）。

### 介護事業所に固有の使い方

#### (1) 事業ごとに会計を区分する

【Fact】指定居宅サービス等基準第38条（第105条により通所介護に準用）は
「指定訪問介護事業者は、指定訪問介護事業所ごとに**経理を区分**するとともに、
指定訪問介護の事業の会計と**その他の事業の会計を区分**しなければならない」と定めています
（出典：同基準第38条／e-Gov法令検索）。

【Typical】実務上は、事業ごとに部門コードを設定して集計する形をとることが多くあります。

#### (2) 保険給付分と実費を分けて管理する

```
【収入の区分】
  介護報酬（保険給付分）  ← 国保連経由。約2か月後に入金
  介護報酬（利用者負担分）← 利用者から直接。翌月に回収【Typical】
  実費（食費・おむつ代等）← 介護保険の外（【Fact】基準第96条第3項）
```

#### (3) 売掛金の管理と資金繰り

【Inference】サービス提供月と入金月が約2か月ずれるため、
会計上の売上と、実際の現金の動きが一致しません。
このため、試算表とは別に**資金繰り表**を作ることが一般的です【Typical】（`08_money.md` 8-8）。

## 11-7. 送迎の配車・ルート作成【Varies】

### 何のための道具か

【Typical】通所介護では、その日の利用者の顔ぶれに合わせて、
どの車で、誰を、どの順に迎えに行くかを決めます。

| 決めるときに考えること【Typical】 |
|---|
| 利用者の自宅の位置関係 |
| 乗車時間（長く乗っていられない人がいる） |
| 車いすのまま乗車する人がいるか（リフト付き車両の割り当て） |
| 到着してからの動線（入浴の順番と合わせる） |
| その日の欠席・追加 |
| 運転できる職員の勤務（送迎中はフロアの人員が減る） |

### 何を使っているか【Varies】

【Varies】ルートを紙や表計算ソフトで管理している事業所と、
配車の機能を持つ仕組みを使っている事業所があります。
**どちらであるかは事業所により異なります。本資料はどちらが良いかを書きません。**

> **送迎が人員配置と結びついている**
> 【Inference】送迎に出ている間、その職員は事業所内にいません。
> 【Fact】一方で、通所介護では「指定通所介護の単位ごとに、…介護職員を、**常時一人以上**
> 当該指定通所介護に従事させなければならない」とされています（基準第93条第2項）。
> つまり、配車を決めることは、同時に**その時間帯の人員配置を決めること**でもあります。

## 11-8. バイタル測定機器との連携【Varies】

### 何が行われているか

【Typical】到着時のバイタル測定（体温・血圧・脈拍）は、毎日、利用者ごとに行われます。
S デイサービスセンターの場合、1日25名分です【Example】。

【Varies】測定した値を、
- 紙のバイタル記録用紙に書き、後で介護記録システムに入力する
- 測定機器から介護記録システムへ値が渡る形にする

など、事業所により扱いが異なります。

> **本資料での扱い**
> **どの方法をとるかは事業所により異なり、本資料は方法の優劣を書きません。**
> 【Fact】として確認できるのは、バイタルが
> 「今日入浴させてよいか」「運動してよいか」の判断材料になること
> （`03_company-structure.md` ④看護職員機能）と、
> 記録が提供したサービスの内容等の記録の一部として扱われること（【Fact】基準第19条第2項）です。

## 11-10. 紙で記録している事業所もある【Varies】

**これは事実の記述であり、評価ではありません。**

【Varies】介護事業所の記録は、電子的な仕組みで行われている場合と、紙で行われている場合があります。
両方を併用している事業所もあります。

### 紙で行われている場合の実務の姿【Typical】

```
  バイタル記録用紙 ── フロアのバインダーに利用者ごとに綴じる
  介護記録         ── 個人ファイルに日ごとに綴じる
  連絡帳           ── 利用者が毎日持ち帰る
  実績             ── 紙の記録を見ながら請求ソフトへ入力する
  保存             ── 【Fact】完結の日から2年間保存（基準第104条の4第2項）のため、
                       利用者ごと・年度ごとにファイルを保管する
```

### 制度の側で電子的な方法が前提になっている部分

一方で、制度の側には電子的な方法を前提とした規定があります。

| 場面 | 条文 |
|---|---|
| 国保連への請求 | 【Fact】「**電子情報処理組織**を使用して…記録し、又は…**光ディスク等**を審査支払機関に提出して行う」（請求に関する命令第2条第1項） |
| 重要事項の掲示 | 【Fact】「原則として、重要事項を**ウェブサイトに掲載**しなければならない」（基準第32条第3項） |
| 重要事項説明書の交付 | 【Fact】基準第8条第2項以下は、利用申込者又はその家族の**承諾を得て**、**電磁的方法**により提供することができるとし、この場合「当該文書を交付したものとみなす」としている |
| 委員会の開催 | 【Fact】感染症対策の委員会は「**テレビ電話装置等を活用して行うことができる**」（基準第104条第2項第1号） |

> **本資料での整理**
> 【Inference】つまり、**請求は電子的な方法（または光ディスク等）が制度上の前提**である一方、
> **日々の介護記録を電子的に行うことを条文が求めているわけではありません**。
> どちらで記録するかは事業所の運営の問題です。
> **本資料は、どちらが望ましいかを書きません。**

## 11-11. システムが扱う情報の「重さ」

【Fact】介護記録には、バイタル、既往症、服薬、主治医、認知症の状態といった情報が日常的に含まれます。

【Fact】個人情報の保護に関する法律第2条第3項は
「この法律において『**要配慮個人情報**』とは、本人の**人種、信条、社会的身分、病歴、犯罪の経歴、
犯罪により害を被った事実**その他本人に対する不当な差別、偏見その他の不利益が生じないように
その取扱いに特に配慮を要するものとして政令で定める記述等が含まれる個人情報をいう」と定めています
（出典：個人情報の保護に関する法律第2条第3項／e-Gov法令検索）。

【Fact】また、介護の側にも規定があります。
指定居宅サービス等基準第33条第1項（第105条により通所介護に準用）は
「指定訪問介護事業所の**従業者**は、**正当な理由がなく**、その業務上知り得た
**利用者又はその家族の秘密を漏らしてはならない**」と定め、
同条第2項は**従業者であった者**についても必要な措置を講じることを事業者に求めています。

> **本資料での扱い**
> ここで示しているのは、**システムが扱っている情報がどういう性質のものか**という事実です。
> **具体的な情報セキュリティ対策の提案は書きません**（`common/methodology.md` §0 による）。

## 11-12. 訪問介護（S ヘルパーステーション）で使う道具の違い【対比】

| 道具 | 通所介護 | 訪問介護 |
|---|---|---|
| **介護記録** | 事業所内で入力する【Typical】 | **訪問先で記録する**。【Fact】提供日及び内容等は「利用者の**居宅サービス計画を記載した書面又はこれに準ずる書面**に記載しなければならない」（基準第19条第1項） |
| **職員の端末**【Varies】 | 据え置き端末・共用のタブレット【Typical】 | 【Varies】訪問介護員が携帯する端末を使う事業所と、紙の記録を事業所に持ち帰る事業所がある |
| **勤務時間の集計** | 提供時間帯の勤務時間の合計（【Fact】基準第93条第1項） | **常勤換算方法**（【Fact】基準第5条第1項、第2条第8号） |
| **移動・スケジュール** | 送迎の配車 | **訪問スケジュール**（誰がどの利用者宅へ何時に行くか）。【Typical】1日に複数件を回る |
| **請求ソフト・伝送** | **同じ**（国保連へ翌月10日まで） | **同じ** |
| **会計** | **同じ**（【Fact】事業ごとの会計の区分。基準第38条） | **同じ** |

> **訪問介護に固有の事情【Inference】**
> 訪問介護では、訪問介護員が直行直帰することが多く、事業所に集まる機会が限られます
> （`06_people.md` 6-7）。
> そのため、「誰が今どこにいるか」「訪問が終わったか」を把握する手段が必要になります。
> 【Varies】電話、連絡ノート、システムなど、方法は事業所により異なります。

## この章のまとめ

- 介護事業所で使われている主な道具は、
  **①介護記録システム ②介護報酬請求ソフト＋伝送ソフト ③ケアプラン作成ソフト【Varies】
  ④勤務シフト・勤怠管理 ⑤給与計算 ⑥会計ソフト ⑦送迎の配車【Varies】 ⑧バイタル測定機器【Varies】**。
- **請求は制度の側が電子的な方法（または光ディスク等）を前提にしている**
  （【Fact】請求に関する命令第2条第1項、同第3条第2項の「記録された時に…到達したものとみなす」）。
- **記録を電子的に行うことを条文が求めているわけではない。** 紙で記録している事業所もある【Varies】。
  **本資料はどちらが望ましいかを書かない。**
- 勤務時間を集計する道具が必要なのは、条文が人数を
  「**勤務時間の合計 ÷ 提供時間**」（【Fact】基準第93条第1項第3号）や
  **常勤換算方法**（【Fact】基準第2条第8号）で数えているためである。
- 会計は**事業ごとに区分する**義務がある（【Fact】基準第38条）。
- 介護記録は**病歴を含む**情報を扱う（【Fact】個人情報保護法第2条第3項の要配慮個人情報の定義）。
  秘密保持は**従業者であった者**にも及ぶ（【Fact】基準第33条第2項）。
