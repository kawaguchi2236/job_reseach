# 04_end-to-end-process.md — 全社End-to-End業務フロー（CHAPTER 4）

**対象**：日本国内の中小の介護事業者
**読み手**：介護・福祉をまったく知らない人
**最終更新**：2026-09-17

> この章では、`03_company-structure.md` で設定した説明用モデル
> 「S デイサービスセンター」（通所介護・定員30名）を軸に、
> 仕事が入ってから入金されるまでを追いかけます。
>
> **介護が他業界と決定的に違うのは、「利用開始までにケアマネジャーを経由する」ことです。**
> 一般の業界のように「引き合い → 見積 → 受注」とは進みません。
> このため、本章は次の3つの流れを**併記**します。
>
> | | 流れ | 何のサイクルか |
> |---|---|---|
> | **A** | 利用開始までの流れ | 1人の利用者につき1回（新規のたび） |
> | **B** | 日々のサービス提供 | 毎日の運営 |
> | **C** | 介護報酬請求サイクル | 毎月のお金の確定と回収 |
>
> AとBとCは並行して動いています。Aで利用者が増え、Bで日々提供し、Cで毎月お金に換える、という関係です。

---

## A. 利用開始までの流れ

### A の全体図

```
① 問い合わせ                       ← ケアマネジャー／地域包括支援センター／家族
        │
        ▼
② ケアマネジャーからの照会（空き状況・受入可否の確認）
        │
        ▼
③ 見学・体験利用
        │
        ▼
④ アセスメント（自事業所として利用者の状態を把握）
        │
        ▼
⑤ ケアプラン（居宅サービス計画）への位置づけ  ← ケアマネジャーが行う
        │
        ▼
⑥ サービス担当者会議（事業所として出席し、専門的見地から意見を述べる）
        │
        ▼
⑦ 契約・重要事項説明（利用者・家族の同意）
        │
        ▼
⑧ 個別援助計画（通所介護計画）の作成 → 説明 → 同意 → 交付
        │
        ▼
⑨ 利用開始
```

### A① 問い合わせ

| 項目 | 内容 |
|---|---|
| **誰が** | 生活相談員機能（管理者が兼ねる場合あり） |
| **何を受け取るか** | 利用の相談。相手はケアマネジャー、地域包括支援センター、家族など【Typical】 |
| **何をするか** | 相手が誰か、利用者の状況（要介護度、認知症の有無、医療的な処置の有無、住所）、希望する曜日・回数を聞き取る |
| **何を判断するか** | 自事業所の空き枠、送迎ルートに乗るか、対応できる状態像か |
| **何を作るか** | 相談記録【Typical】 |
| **次に誰へ渡すか** | ケアマネジャー（可否の回答） |
| **頻度** | 問い合わせ時 |

> **なぜケアマネジャーからの問い合わせが多いのか**
> `02_industry-structure.md` 11-3 で見たとおり、ケアマネジャーは
> 【Fact】「利用者によるサービスの選択に資するよう、当該地域における指定居宅サービス事業者等に関する
> サービスの内容、利用料等の情報を適正に利用者又はその家族に対して提供するものとする」
> とされています（指定居宅介護支援等基準第13条第5号）。
> この「情報を提供する」ために、ケアマネジャーは日ごろから地域の事業所の状況を把握しようとします。
> だから事業所への問い合わせは、まずケアマネジャーから来ることが多くなります【Inference】。

> **提供を拒めるのか**
> 【Fact】「指定訪問介護事業者は、**正当な理由なく**指定訪問介護の提供を**拒んではならない**」
> （指定居宅サービス等基準第9条。同基準第105条により通所介護にも準用）。
> つまり「気に入らないから断る」ことはできません。
> 一方、定員に空きがない、対応できる体制がない、といった事情は「正当な理由」になりえます【Inference】。

### A② ケアマネジャーからの照会

| 項目 | 内容 |
|---|---|
| **誰が** | 生活相談員機能 |
| **何を受け取るか** | 利用者の基本情報、要介護度、認定有効期間、現在のサービス利用状況、希望内容 |
| **何を確認するか** | 定員の空き（曜日ごと）、送迎の可否（自宅の位置・道路事情・玄関の状況）、医療的ケアの有無、食事形態（きざみ・ミキサー等）の対応可否 |
| **何をするか** | 受入の可否と、可能な曜日・時間を回答する |
| **何を作るか** | 受入検討の記録【Typical】 |
| **次に誰へ渡すか** | ケアマネジャー |
| **頻度** | 問い合わせ時 |

### A③ 見学・体験利用

| 項目 | 内容 |
|---|---|
| **誰が** | 生活相談員機能＋介護職員機能 |
| **何を受け取るか** | 利用者本人・家族の来所（ケアマネジャーが同行することもある【Typical】） |
| **何をするか** | 事業所を案内し、1日の流れ・食事・入浴・レクリエーションの内容を説明する。体験利用を行う場合は実際に1日過ごしてもらう |
| **何を確認するか** | 本人が場に馴染めそうか、他の利用者との関係、移動・移乗の介助量、入浴の可否 |
| **何を判断するか** | 自事業所で安全にサービスを提供できるか |
| **次に誰へ渡すか** | 本人・家族（検討）／ケアマネジャー（結果の共有） |
| **頻度** | 案件発生時 |

### A④ アセスメント

| 項目 | 内容 |
|---|---|
| **誰が** | 生活相談員機能・看護職員機能・機能訓練指導員機能 |
| **何を受け取るか** | ケアマネジャーからの情報、体験利用での観察、家族からの情報 |
| **何を確認するか** | ADL（日常生活動作）、既往歴、服薬、認知機能、本人の希望、家族の状況 |
| **何をするか** | 自事業所として「何を目標に、どう関わるか」を検討する |
| **何を作るか** | アセスメント記録【Typical】 |
| **次に誰へ渡すか** | 通所介護計画の作成へ（A⑧） |
| **頻度** | 案件発生時 |

【Fact】この段階で、基準上次のことが求められます。
「指定訪問介護事業者は、指定訪問介護の提供に当たっては、利用者に係る居宅介護支援事業者が開催する
**サービス担当者会議**…**等を通じて**、利用者の心身の状況、その置かれている環境、
他の保健医療サービス又は福祉サービスの利用状況等の**把握に努めなければならない**」
（指定居宅サービス等基準第13条。同基準第105条により通所介護にも準用）。

> **ケアマネジャーのアセスメントとの違い**
> ケアマネジャーが行うアセスメントは、【Fact】「利用者の居宅を訪問し、利用者及びその家族に面接して」行われ、
> 「利用者が現に抱える問題点を明らかにし、…**解決すべき課題を把握**」するものです
> （指定居宅介護支援等基準第13条第6号・第7号）。
> **生活全体を見ます。**
> 一方、事業所が行うアセスメントは「**自事業所のサービスの中で**何をするか」を決めるためのものです。
> 対象範囲が違います。

### A⑤ ケアプラン（居宅サービス計画）への位置づけ

**この工程は事業所ではなく、ケアマネジャーが行います。**

| 項目 | 内容 |
|---|---|
| **誰が** | ケアマネジャー（居宅介護支援事業所） |
| **何をするか** | 【Fact】アセスメントの結果に基づき、「最も適切なサービスの組合せについて検討し」、居宅サービス計画の原案を作成する（指定居宅介護支援等基準第13条第8号） |
| **何を作るか** | 【Fact】居宅サービス計画の原案。記載事項は「利用者及びその家族の生活に対する意向、総合的な援助の方針、生活全般の解決すべき課題、**提供されるサービスの目標及びその達成時期**、サービスの種類、内容及び利用料並びにサービスを提供する上での留意事項等」（同号） |
| **次に誰へ渡すか** | サービス担当者会議の参加者（＝自事業所を含む） |
| **頻度** | 案件発生時 |

> **事業所から見ると、ここが「受注」に相当します**
> 一般の業界でいえば、見積が通って注文書が届いた状態に近いですが、
> **注文しているのは利用者でもケアマネジャーでもなく、「計画に載った」という事実**です。
> そして`02_industry-structure.md` 11-2 で述べたとおり、
> ケアプランに載っていないサービスを提供しても、保険請求は通りません。

### A⑥ サービス担当者会議

| 項目 | 内容 |
|---|---|
| **誰が** | 事業所側は生活相談員機能（訪問介護ならサービス提供責任者）【Typical】 |
| **何を受け取るか** | ケアマネジャーからの招集、居宅サービス計画の原案 |
| **何をするか** | 【Fact】「担当者から、**専門的な見地からの意見**を求めるものとする」とされる会議に出席し、自事業所の立場から意見を述べる（指定居宅介護支援等基準第13条第9号） |
| **何を確認するか** | 原案に書かれた目標・内容が、自事業所で実行できるか。他のサービスとの役割分担 |
| **誰と連携するか** | 本人・家族・ケアマネジャー・他のサービス事業者・（必要に応じ）主治医 |
| **次に誰へ渡すか** | ケアマネジャー（原案の確定へ） |
| **頻度** | 案件発生時／法定・契約上のタイミング（要介護更新認定を受けた場合・要介護状態区分の変更の認定を受けた場合。【Fact】同基準第13条第15号） |

【Fact】会議は「利用者及びその家族の参加を基本としつつ」行われ、
テレビ電話装置等を活用して行うこともできます（利用者等が参加する場合はその同意が必要）（同基準第13条第9号）。

### A⑦ 契約・重要事項説明

| 項目 | 内容 |
|---|---|
| **誰が** | 生活相談員機能（管理者が行う場合あり） |
| **何をするか** | 【Fact】「指定通所介護の提供の開始に際し、**あらかじめ**、利用申込者又はその家族に対し、…**運営規程の概要**、…**重要事項を記した文書を交付して説明**を行い、当該提供の開始について利用申込者の**同意を得なければならない**」（指定居宅サービス等基準第8条第1項。第105条により通所介護に準用。準用にあたり「第二十九条」は「第百条」と読み替え） |
| **何を確認するか** | 被保険者証（要介護度・認定有効期間）、**負担割合証**（1割・2割・3割）、緊急連絡先、かかりつけ医 |
| **何を作るか** | 契約書、重要事項説明書（同意の記録）、利用者台帳【Typical】 |
| **次に誰へ渡すか** | 請求事務機能（利用者情報の登録） |
| **頻度** | 案件発生時 |

【Fact】重要事項説明書の文書交付は、利用者等の申出と承諾があれば電磁的方法によることもできます
（同基準第8条第2項〜第6項）。

【Fact】また、事業者は介護報酬とは別に受け取る費用（食費、おむつ代、実施地域外の送迎費など）について、
「あらかじめ、利用者又はその家族に対し、当該サービスの内容及び費用について説明を行い、
**利用者の同意を得なければならない**」とされています（同基準第96条第3項・第5項）。

> **なぜ「あらかじめ」なのか**
> 介護保険サービスは、利用者から見れば「1割で使えるサービス」です。
> しかし実際には、食費・おむつ代など**保険の外で払う費用**があります。
> これを説明せずに提供すると、後から「聞いていない」という苦情になります。
> 条文が「あらかじめ」「同意を得なければならない」と定めているのは、そのためと考えられます【Inference】。

### A⑧ 個別援助計画（通所介護計画）の作成

| 項目 | 内容 |
|---|---|
| **誰が** | 【Fact】「指定通所介護事業所の**管理者**」（指定居宅サービス等基準第99条第1項）。訪問介護の場合は【Fact】「**サービス提供責任者**」（同第24条第1項） |
| **何を受け取るか** | 居宅サービス計画（ケアプラン）、自事業所のアセスメント結果 |
| **何をするか** | 【Fact】「利用者の心身の状況、希望及びその置かれている環境を踏まえて、**機能訓練等の目標**、当該目標を達成するための**具体的なサービスの内容等**を記載した通所介護計画を作成」する（同第99条第1項） |
| **何を確認するか** | 【Fact】「通所介護計画は、既に居宅サービス計画が作成されている場合は、**当該居宅サービス計画の内容に沿って**作成しなければならない」（同条第2項） |
| **何を作るか** | 通所介護計画（訪問介護なら訪問介護計画） |
| **誰の同意が必要か** | 【Fact】「その内容について利用者又はその家族に対して説明し、**利用者の同意を得なければならない**」（同条第3項） |
| **次に誰へ渡すか** | 【Fact】「通所介護計画を作成した際には、当該通所介護計画を**利用者に交付**しなければならない」（同条第4項） |
| **頻度** | 案件発生時（作成時）／状態の変化時（変更時） |

> **計画の階層をもう一度整理する**
>
> ```
> 居宅サービス計画（ケアプラン）  ← ケアマネジャーが作る。生活全体
>   └─ 通所介護計画            ← 事業所の管理者が作る。デイでの目標と内容
>   └─ 訪問介護計画            ← サービス提供責任者が作る
> ```
>
> 【Fact】ケアマネジャーは、計画に位置づけた事業者に対して「訪問介護計画…等
> 指定居宅サービス等基準において位置付けられている**計画の提出を求めるものとする**」とされています
> （指定居宅介護支援等基準第13条第12号）。
> つまり、**事業所が作った個別援助計画は、ケアマネジャーにも渡ります。**

### A⑨ 利用開始

【Fact】「指定訪問介護事業者は、**居宅サービス計画**…が作成されている場合は、
**当該計画に沿った**指定訪問介護を提供しなければならない」
（指定居宅サービス等基準第16条。第105条により通所介護に準用）。

## B. 日々のサービス提供

### B の全体図（1日の流れ）

```
朝
 ├─ 送迎（往路）：職員が利用者宅へ迎えに行く
 │    ・玄関先での引き継ぎ、乗降介助、戸締まりの確認
 ├─ 到着・バイタル測定：体温・血圧・脈拍
 │    ・看護職員が「今日入浴できるか」「運動してよいか」を判断
 ├─ 入浴：脱衣・洗身・洗髪・着衣の介助、皮膚の状態の観察
 ├─ 昼食：食事形態の確認、食事介助、水分摂取量の記録、服薬の確認
 ├─ 機能訓練・レクリエーション
 ├─ 介護記録の記載：その日の様子、提供したサービス、特記事項
 ├─ 送迎（復路）：自宅へ送り、家族または本人へ引き継ぐ
 │    ・連絡帳を渡す
 └─ 事業所に戻り、記録の確認・翌日の準備・申し送り
```

### B の各ステップ

| ステップ | 誰が | 何を確認するか | 何を作るか | 頻度 |
|---|---|---|---|---|
| 送迎（往路） | 介護職員機能／送迎・運転機能 | 利用者の在宅、体調、服装、持ち物 | 送迎記録【Typical】 | 日次 |
| バイタル測定 | 介護職員機能→看護職員機能 | 体温・血圧・脈拍、顔色、いつもと違う様子 | バイタル記録 | 日次 |
| 入浴 | 介護職員機能（看護職員が可否を判断） | 皮膚の状態、傷、あざ、浴室での安全 | 入浴記録 | 【Varies】利用日ごと／週数回 |
| 食事 | 介護職員機能／調理・給食機能 | 食事形態、アレルギー、摂取量、水分量、むせの有無 | 食事・水分記録 | 日次 |
| 機能訓練 | 機能訓練指導員機能 | 通所介護計画の目標、本人の体調 | 機能訓練記録 | 【Varies】計画による |
| 介護記録の記載 | 介護職員機能 | その日提供したサービスの内容、特記事項 | **介護記録（サービス提供記録）** | 日次 |
| 送迎（復路）・家族への報告 | 介護職員機能 | 家族の在宅、当日の様子の伝達 | 連絡帳【Typical】 | 日次 |
| ケアマネジャーへの報告 | 生活相談員機能 | 利用実績、状態の変化 | 報告記録 | 月次／トラブル発生時 |
| モニタリングへの協力 | 生活相談員機能 | ケアマネジャーからの照会 | ― | 月次 |

### 介護記録は「なぜ」書くのか【この業界の核心のひとつ】

介護記録には、**2つのまったく異なる役割**があります。この2つを分けて理解することが重要です。

#### 役割1：報酬の根拠

【Fact】「指定訪問介護事業者は、指定訪問介護を提供した際には、
**提供した具体的なサービスの内容等を記録する**とともに、利用者からの申出があった場合には、
文書の交付その他適切な方法により、その情報を利用者に対して提供しなければならない」
（指定居宅サービス等基準第19条第2項。第105条により通所介護に準用）。

【Fact】そして、請求は審査されます。
「市町村は、指定居宅サービス事業者から居宅介護サービス費の請求があったときは、
第四項各号の厚生労働大臣が定める基準及び…**指定居宅サービスの事業の設備及び運営に関する基準**
（指定居宅サービスの取扱いに関する部分に限る。）に**照らして審査した上、支払うものとする**」
（介護保険法第41条第9項）。

> **つまり、記録がなければ「提供した」と言えません。**
> 実地指導や監査で「この加算を算定しているが、実施した記録がない」となれば、
> 報酬の返還を求められることがあります【Inference】。
> **介護記録は、事業所の売上の裏付けそのものです。**

#### 役割2：事故が起きたときの事実の記録

【Fact】「指定通所介護事業者は、…**事故の状況及び事故に際して採った処置について記録しなければならない**」
（指定居宅サービス等基準第104条の3第2項）。

【Fact】また、身体的拘束等を行った場合には
「その**態様及び時間**、その際の**利用者の心身の状況**並びに**緊急やむを得ない理由**を記録しなければならない」
（同基準第98条第4号）。

> **記録は、利用者を守り、職員を守るものです**
> 「いつ、どんな状態で、誰が、何をしたか」が記録されていれば、
> 何かが起きたときに事実に基づいて話すことができます。
> 記録がなければ、誰の記憶が正しいかという話になってしまいます。
> **記録は事務作業ではなく、サービスの一部です。**

#### 記録の保存期間

【Fact】「指定通所介護事業者は、利用者に対する指定通所介護の提供に関する次の各号に掲げる記録を整備し、
その**完結の日から二年間保存**しなければならない」（同基準第104条の4第2項）。対象は次の6つです。

1. 通所介護計画
2. 提供した具体的なサービスの内容等の記録
3. 身体的拘束等の態様及び時間、その際の利用者の心身の状況並びに緊急やむを得ない理由の記録
4. 市町村への通知に係る記録
5. 苦情の内容等の記録
6. 事故の状況及び事故に際して採った処置についての記録

（訪問介護については同基準第39条第2項が、訪問介護計画を含む同様の6項目について同じく2年間の保存を定めています【Fact】。）

## C. 介護報酬請求サイクル（月次）

### C の全体図

```
【当月（例：11月）】
  日々：サービス提供実績を入力する（提供日、サービス種類、時間区分、加算の該当）
        │
【月末〜翌月初（11月末〜12月初）】
  ① 実績の確定
     ・介護記録とシステム入力を突き合わせる
     ・キャンセル・追加・時間区分の変更を反映する
     ・加算・減算の該当を確認する
     ・限度額を超えていないか確認する
     ・ケアマネジャーからの給付管理の内容と一致するか確認する
        │
【翌月10日まで（12月10日まで）】← 法定期限
  ② 国保連へ請求（介護給付費請求書・介護給付費明細書を電子データで送信）
        │
  ③ 利用者負担分の請求書・領収証を発行し、利用者・家族へ
        │
【翌月中（12月）】
  ④ 国保連が審査
        ├─ 通った  → 支払へ
        └─ 通らない → 返戻（12月中に事業所へ通知）
                        │
                        ▼ 修正して翌月以降に再請求
【翌々月（1月）】
  ⑤ 国保連から事業所へ入金 ← サービス提供月（11月）から約2か月後
        │
  ⑥ 入金額と請求額の突き合わせ（消込）
     ・差異があれば原因を確認する
     ・過誤（いったん取り下げて再請求）が必要なら申立てを行う
```

### C の各ステップ

#### C① 実績の確定

| 項目 | 内容 |
|---|---|
| **誰が** | 請求事務機能（中小では管理者・生活相談員が兼務することが多い【Typical】） |
| **何を受け取るか** | 日々の介護記録、送迎記録、体調不良による欠席の連絡、追加利用の記録 |
| **何を確認するか** | ①実際に提供した日と時間区分 ②算定する加算の要件を満たしているか ③要介護度と認定有効期間 ④負担割合 ⑤区分支給限度基準額を超えていないか |
| **何をするか** | 請求システムに実績を確定入力する |
| **何を作るか** | 月次のサービス提供実績記録票【Typical】 |
| **次に誰へ渡すか** | 国保連（請求）／ケアマネジャー（実績の報告） |
| **頻度** | 月次 |

> **なぜ月末〜月初が忙しいのか**
> 【Fact】区分支給限度額の管理期間は「当該月の**初日からの一月間**」です（介護保険法施行規則第67条）。
> 【Fact】請求期限は「各月分について**翌月十日まで**」です（請求に関する命令第3条第1項）。
> つまり、**月末で区切り、10日以内に確定させる**というサイクルが法令で決まっています。
> ここに、日々の記録の突き合わせ、ケアマネジャーとの実績のすり合わせ、加算の確認が集中します。

#### C② 国保連へ請求【法定期限】

| 項目 | 内容 |
|---|---|
| **誰が** | 請求事務機能 |
| **何を作るか** | 介護給付費請求書・介護給付費明細書（電子データ）【Typical：様式名】 |
| **どう送るか** | 【Fact】「**電子情報処理組織**を使用して…審査支払機関の電子計算機に備えられたファイルに記録し、又は…**光ディスク等**を審査支払機関に提出して行う」（請求に関する命令第2条第1項） |
| **いつまでに** | 【Fact】「各月分について**翌月十日まで**」（同命令第3条第1項）＝法定・契約上のタイミング |
| **到達の時点** | 【Fact】「電子情報処理組織による…請求は、審査支払機関の電子計算機に備えられたファイルに**記録された時に**審査支払機関に到達したものとみなす」（同条第2項） |
| **頻度** | 月次 |

#### C③ 利用者負担分の請求

| 項目 | 内容 |
|---|---|
| **誰が** | 請求事務機能 |
| **何を作るか** | 利用者向け請求書、【Fact】領収証（介護保険法第41条第8項「領収証を交付しなければならない」） |
| **金額の内訳** | 介護報酬の自己負担分（1〜3割）＋【Fact】食事の提供に要する費用・おむつ代・実施地域外の送迎費など（指定居宅サービス等基準第96条第3項） |
| **回収方法** | 【Varies】口座振替、振込、現金 |
| **頻度** | 月次 |

#### C④ 審査と返戻

| 用語 | 何が起きるか | 事業所が何をするか |
|---|---|---|
| **返戻（へんれい）** | 請求が審査を通らず差し戻される。その月は入金されない | 【Typical】原因（被保険者番号の誤り、認定有効期間切れ、給付管理票との不一致、限度額超過など）を特定し、修正して翌月以降に再請求する |
| **過誤（かご）** | いったん支払われた請求を取り下げ、正しい内容で再請求する | 【Typical】保険者に過誤申立てを行い、取下げ後に再請求する |

> **返戻は「請求ミス」だけで起きるわけではありません**
> 【Inference】たとえば、利用者が月の途中で要介護度の変更認定を受けた、
> ケアマネジャーが給付管理の内容を変更した、といった**事業所の外で起きた変化**でも返戻は起こります。
> だから返戻への対応は、請求事務機能の通常業務の一部です。

#### C⑤ 入金と消込

| 項目 | 内容 |
|---|---|
| **誰が** | 請求事務機能＋経理・財務機能 |
| **何を受け取るか** | 国保連からの支払決定通知【Typical】と入金 |
| **何を確認するか** | 請求額と入金額が一致するか。差異があれば返戻・査定の内容を確認する |
| **いつ** | 【Typical】サービス提供月の約2か月後 |
| **頻度** | 月次 |

## 介護固有の重要トピック

ここまでの流れの中に出てきた、介護特有の論点をまとめます。

### (1) 個別援助計画 — 「計画がなければサービスではない」

【Fact】通所介護計画（基準第99条）、訪問介護計画（基準第24条）。
いずれも **作成 → 説明 → 同意 → 交付 → 実施状況の記録／把握** という流れが条文で定められています。

【Fact】「通所介護従業者は、それぞれの利用者について、**通所介護計画に従ったサービスの実施状況及び
目標の達成状況の記録**を行う」（基準第99条第5項）。

【Fact】訪問介護計画については「サービス提供責任者は、訪問介護計画の作成後、
当該訪問介護計画の**実施状況の把握**を行い、**必要に応じて当該訪問介護計画の変更**を行うものとする」（基準第24条第5項）。

> **計画・実施・記録がひとつながりである**
> 「計画に書いたことを、実際にやり、やったことを記録する」。
> この3つがそろって初めて、サービスとして成立し、報酬の根拠になります。

### (2) 加算・減算 — 体制と実施の両方が必要

【Fact】介護報酬は「基本報酬」と「加算・減算」で構成されます
（出典：介護保険制度の概要（令和7年7月）／厚生労働省老健局）。

【Typical】加算を算定するには、一般に次の両方が必要です。

```
① 体制を整え、指定権者に体制届を提出する（届出をした月の翌月から算定できるのが通例【Varies：届出の取扱いは加算により異なる】）
② 実際にその要件を満たす取組を行い、記録に残す
```

【Fact】通所介護の加算には、入浴介助加算、中重度者ケア体制加算、個別機能訓練加算、
栄養アセスメント加算、栄養改善加算、口腔機能向上加算、科学的介護推進体制加算などがあります
（出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。

【Fact】減算には、利用定員超過、看護・介護職員の員数が基準に満たない場合、
高齢者虐待防止措置未実施減算、業務継続計画未策定減算などがあります（同上）。

> **加算と減算の非対称性**
> 加算は「取りに行くもの」ですが、減算は「気づかないうちに該当してしまうもの」です。
> 【Inference】職員が辞めて人員基準を割った、BCPの見直しをしていなかった、という状態は、
> 誰かが指摘するまで気づかないことがあります。
> このため、管理者機能には「自事業所が減算に該当していないか」を定期的に点検する仕事が含まれます。

### (3) 事故報告

【Fact】「指定通所介護事業者は、利用者に対する指定通所介護の提供により事故が発生した場合は、
**市町村、当該利用者の家族、当該利用者に係る居宅介護支援事業者等に連絡**を行うとともに、
**必要な措置**を講じなければならない」（基準第104条の3第1項）。

【Fact】「前項の**事故の状況及び事故に際して採った処置について記録**しなければならない」（同条第2項）。

【Fact】「利用者に対する指定通所介護の提供により**賠償すべき事故**が発生した場合は、
**損害賠償を速やかに行わなければならない**」（同条第3項）。

| ステップ | 誰が | 何をするか | 頻度 |
|---|---|---|---|
| 発生時の対応 | 発見した職員→看護職員機能→管理者機能 | 安全確保、応急手当、必要なら救急要請 | トラブル発生時 |
| 連絡 | 管理者機能・生活相談員機能 | 【Fact】市町村・家族・居宅介護支援事業者等へ連絡（基準第104条の3第1項） | トラブル発生時 |
| 記録 | 管理者機能 | 【Fact】事故の状況と採った処置を記録（同条第2項） | トラブル発生時 |
| 賠償 | 経営者・管理者機能 | 【Fact】賠償すべき事故なら速やかに損害賠償（同条第3項） | トラブル発生時 |
| 再発防止 | 全職員 | 【Typical】原因の検討、手順の見直し、職員への周知 | トラブル発生時 |

> **【Varies】市町村への事故報告の様式・対象範囲**
> 事故報告書の様式や、どの範囲の事故を報告するかの基準は、保険者である市町村が定めており、
> **自治体によって異なります**。複数の市町村の利用者を受け入れている事業所は、
> それぞれの市町村のルールを把握しておく必要があります。

### (4) 身体拘束の原則禁止

【Fact】「指定通所介護の提供に当たっては、**当該利用者又は他の利用者等の生命又は身体を保護するため
緊急やむを得ない場合を除き、身体的拘束等を行ってはならない**」（基準第98条第3号）。

【Fact】「前号の身体的拘束等を行う場合には、その**態様及び時間**、その際の**利用者の心身の状況**並びに
**緊急やむを得ない理由**を記録しなければならない」（同条第4号）。

> **条文をそのまま読むことの大切さ**
> 条文は「行ってはならない」と原則を書いたうえで、
> 例外を「**当該利用者又は他の利用者等の生命又は身体を保護するため緊急やむを得ない場合**」に限っています。
> 「手がかかるから」「危ないかもしれないから」は、条文の書き方から外れます。
> そして例外にあたる場合でも、**態様・時間・心身の状況・理由の記録が義務**です。
>
> これは介護の仕事の根本に関わる規定です。
> `01_overview.md` の冒頭で引用したとおり、介護保険法第1条は給付の目的を
> 「これらの者が**尊厳を保持し**」と定めています。身体拘束の原則禁止は、この理念の具体化です【Inference】。

【Fact】虐待防止についても基準が置かれています。
「指定訪問介護事業者は、**虐待の発生又はその再発を防止**するため、次の各号に掲げる措置を講じなければならない。
一 …**虐待の防止のための対策を検討する委員会**…を**定期的に開催**するとともに、その結果について…周知徹底を図ること。
二 …**虐待の防止のための指針を整備**すること。
三 …**虐待の防止のための研修を定期的に実施**すること。
四 前三号に掲げる措置を適切に実施するための**担当者を置く**こと」
（基準第37条の2。第105条により通所介護に準用）。

【Fact】また、事業の一般原則として
「指定居宅サービス事業者は、利用者の**人権の擁護、虐待の防止等**のため、必要な体制の整備を行うとともに、
その従業者に対し、**研修を実施する等の措置**を講じなければならない」とされています（基準第3条第3項）。

### (5) 感染症・食中毒対策

【Fact】通所介護については基準第104条が次のとおり定めています。

- 第1項：「利用者の使用する**施設、食器その他の設備又は飲用に供する水**について、
  **衛生的な管理に努め、又は衛生上必要な措置を講じ**なければならない」
- 第2項：感染症が発生し、又はまん延しないように次の措置を講じなければならない
  1. 「**感染症の予防及びまん延の防止のための対策を検討する委員会**（テレビ電話装置等を活用して行うことができる）を
     **おおむね六月に一回以上開催**するとともに、その結果について、通所介護従業者に**周知徹底**を図ること」
  2. 「**感染症の予防及びまん延の防止のための指針を整備**すること」
  3. 「通所介護従業者に対し、感染症の予防及びまん延の防止のための**研修及び訓練を定期的に実施**すること」

| 業務 | 頻度 |
|---|---|
| 感染症対策委員会の開催 | 【Fact】おおむね6月に1回以上（基準第104条第2項第1号） |
| 指針の整備・見直し | 【Varies】 |
| 研修及び訓練 | 【Fact】定期的に（同項第3号。具体的な回数は条文に定めなし） |

### (6) BCP（業務継続計画）の策定義務

【Fact】基準第30条の2（第105条により通所介護に準用）は次のとおり定めています。

- 第1項：「**感染症や非常災害の発生時**において、利用者に対する指定訪問介護の提供を**継続的に実施**するための、
  及び**非常時の体制で早期の業務再開を図る**ための計画（以下「**業務継続計画**」という。）を**策定**し、
  当該業務継続計画に従い必要な措置を講じなければならない」
- 第2項：「訪問介護員等に対し、業務継続計画について**周知**するとともに、
  必要な**研修及び訓練を定期的に実施**しなければならない」
- 第3項：「**定期的に業務継続計画の見直し**を行い、必要に応じて業務継続計画の**変更**を行うものとする」

【Fact】そして、介護報酬の算定構造には「**業務継続計画未策定減算**」という減算項目があります
（出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。

> **なぜBCPが介護事業所に義務づけられているのか**
> 【Inference】感染症の流行や災害が起きても、利用者の介護を止めることはできません。
> 「今日から休業します」と言えば、その日から入浴も食事も受けられなくなる人が出ます。
> 条文が「**提供を継続的に実施するため**」「**早期の業務再開を図るため**」と書いているのは、この事情によります。

【Fact】これとは別に、非常災害対策の規定もあります。
「指定通所介護事業者は、**非常災害に関する具体的計画**を立て、非常災害時の**関係機関への通報及び連携体制**を整備し、
それらを**定期的に従業者に周知**するとともに、**定期的に避難、救出その他必要な訓練**を行わなければならない」
（基準第103条第1項）。
「前項に規定する訓練の実施に当たって、**地域住民の参加が得られるよう連携に努め**なければならない」（同条第2項）。

### (7) 苦情処理

【Fact】基準第36条（第105条により通所介護に準用）は次のとおり定めています。

- 第1項：「利用者及びその家族からの苦情に**迅速かつ適切に対応**するために、
  **苦情を受け付けるための窓口を設置する等**の必要な措置を講じなければならない」
- 第2項：「苦情を受け付けた場合には、当該**苦情の内容等を記録**しなければならない」
- 第3項：市町村が行う調査に協力し、指導・助言を受けた場合は「当該指導又は助言に従って必要な改善を行わなければならない」
- 第5項：「**国民健康保険団体連合会**が行う法第百七十六条第一項第三号の**調査に協力**するとともに、
  …指導又は助言を受けた場合においては、当該指導又は助言に従って必要な改善を行わなければならない」

> **苦情の窓口は事業所だけではありません**
> 【Fact】国保連は、法第176条第1項第3号により「サービスの質の向上に関する調査」と
> 「事業者に対する必要な指導及び助言」を行います。
> 利用者は、事業所に直接言いにくい場合に、市町村や国保連に相談することができます。

### (8) 市町村への通知

【Fact】「指定訪問介護事業者は、指定訪問介護を受けている利用者が次の各号のいずれかに該当する場合は、
**遅滞なく、意見を付してその旨を市町村に通知**しなければならない。
一 **正当な理由なしに**指定訪問介護の利用に関する**指示に従わない**ことにより、要介護状態の程度を増進させたと認められるとき。
二 **偽りその他不正な行為によって保険給付を受け、又は受けようとした**とき」
（基準第26条。第105条により通所介護に準用）。

## 【Example】1人の利用者を追跡する — 利用開始から報酬入金まで

> **【Example】以下はすべて説明用の架空の事例です。実在の利用者・事業所ではありません。**
> 単位数は【Fact】介護報酬の算定構造（R8.6.1）／厚生労働省 に基づく通常規模型通所介護の基本部分を用います。
> 1単位あたりの単価は説明のため10円として計算しています（実際の単価は地域区分により異なります）。

### 登場人物

| 役 | 設定 |
|---|---|
| Tさん | 82歳。妻と2人暮らし。半年前に自宅で転倒し、歩行が不安定になった。入浴が一人ではできない |
| Tさんの妻 | 79歳。Tさんの入浴介助が体力的に難しくなってきた |
| Uさん | 居宅介護支援事業所のケアマネジャー |
| S デイサービスセンター | 説明用モデル事業所（定員30名、7時間以上8時間未満、送迎あり） |

### 時系列

#### 【9月上旬】相談と申請

1. Tさんの妻が市の地域包括支援センターに相談する。
2. 地域包括支援センターの職員が、要介護認定の申請手続を代わって行う。
   【Fact】法第27条第1項後段が、地域包括支援センターによる申請手続の代行を認めている。

#### 【9月中旬】認定調査と主治医意見書

3. 市の認定調査員がTさん宅を訪問し、面接して調査する（基本調査74項目と特記事項）。
   【Fact】法第27条第2項／介護保険制度の概要（厚生労働省老健局）。
4. 市がTさんの主治医に意見を求める（主治医意見書）。【Fact】法第27条第3項。

#### 【10月上旬】認定結果

5. 一次判定（コンピュータ判定）を経て、介護認定審査会が審査・判定する。【Fact】法第27条第4項・第5項。
6. 市がTさんを**要介護2**と認定し、通知する。
   【Fact】申請に対する処分は原則として申請日から30日以内（法第27条第11項）。
   【Fact】認定の効力は申請日にさかのぼる（法第27条第8項）。
7. 認定有効期間は、認定の効力が生じた日からその月の末日まで＋6月間。【Fact】施行規則第38条第1項。

#### 【10月中旬】ケアプランの作成

8. Tさんと妻が、居宅介護支援事業所のケアマネジャーUさんと契約する。
   【Fact】居宅介護支援には利用者負担が発生しない（法第46条第2項に「百分の九十」の定めがない）。
9. UさんがTさん宅を訪問し、Tさんと妻に面接してアセスメントを行う。【Fact】指定居宅介護支援等基準第13条第7号。
10. Uさんが「週2回の入浴と、歩行機能の維持」を目標に、通所介護を週2回組み込んだケアプラン原案を作る。
    【Fact】同基準第13条第8号。
11. UさんがS デイサービスセンターに空き状況を照会する。生活相談員Aさんが受け、火曜・金曜なら受入可能と回答する。

#### 【10月下旬】見学・会議・契約

12. Tさんと妻がS デイを見学し、1日体験利用をする。
13. **サービス担当者会議**が開かれる。Tさん、妻、Uさん、S デイの生活相談員Aさん、福祉用具貸与事業者が参加する。
    Aさんは「入浴は2名介助で行う」「機能訓練指導員が歩行訓練を担当する」と専門的見地から述べる。
    【Fact】同基準第13条第9号。
14. UさんがケアプランをTさんに説明し、**文書による同意**を得て、Tさんと担当者（S デイを含む）に交付する。
    【Fact】同基準第13条第10号・第11号。
15. S デイとTさんが**契約**する。生活相談員Aさんが重要事項説明書を交付して説明し、同意を得る。
    【Fact】指定居宅サービス等基準第8条第1項。
    あわせて、食費（介護報酬とは別）についても説明し、同意を得る。【Fact】同基準第96条第3項第3号・第5項。
    被保険者証と**負担割合証**を確認する。Tさんの負担割合は1割だった。

#### 【10月末】通所介護計画

16. S デイの管理者が**通所介護計画**を作成する。
    ケアプランの内容に沿って、「安全に入浴できること」「屋内歩行が自立して行えること」を目標に据える。
    【Fact】同基準第99条第1項・第2項。
17. Tさんと妻に説明し、**同意**を得て、Tさんに**交付**する。【Fact】同条第3項・第4項。

#### 【11月】サービス提供

18. 11月の火曜・金曜、合計**9回**利用した（1回は体調不良で欠席）。
19. 毎回、送迎 → バイタル測定 → 入浴 → 昼食 → 機能訓練 → 記録 → 送迎 の流れで提供する。
20. 毎回、**介護記録**に提供した具体的なサービスの内容を記載する。【Fact】同基準第19条第2項（第105条で準用）。
21. 11月中旬、Uさんが**モニタリング**のためTさん宅を訪問し、面接する。
    【Fact】指定居宅介護支援等基準第13条第14号イ・ロ。S デイの生活相談員Aさんにも利用状況を照会する。

#### 【11月末〜12月初】実績の確定

22. S デイの請求事務担当が、介護記録とシステム入力を突き合わせ、11月の実績を確定する。

```
【Example】11月分の計算（説明用の架空の例）

  通所介護費（通常規模型・7時間以上8時間未満・要介護2）  777単位／回
  777単位 × 9回 = 6,993単位
  （加算は説明を簡単にするため、ここでは計算に含めていません）

  6,993単位 × 10円 = 69,930円 ← サービスの費用額
      ├─ 利用者負担（1割）    6,993円 → Tさんに請求
      └─ 保険給付分（9割）   62,937円 → 国保連に請求

  ＋ 食費（介護報酬とは別。重要事項説明書で説明済み）
      仮に1回700円 × 9回 = 6,300円 → Tさんに請求

  → Tさんへの請求額合計 = 6,993円 + 6,300円 = 13,293円
```

#### 【12月10日まで】請求

23. 11月分の保険給付分（62,937円相当）を**国保連に電子データで請求**する。
    【Fact】「各月分について翌月十日までに行わなければならない」（請求に関する命令第3条第1項）。
24. Tさんに請求書を発行する。入金があったら**領収証を交付**する。【Fact】介護保険法第41条第8項。

#### 【12月】審査

25. 国保連が審査する。【Fact】介護保険法第41条第9項・第10項。
    ケアマネジャーUさんが送った給付管理の内容とS デイの請求内容が一致していたため、返戻はなかった。

#### 【翌年1月】入金

26. 国保連からS デイに入金される。**サービスを提供した11月から約2か月後**。
27. 請求事務担当が、請求額と入金額を突き合わせる（消込）。

### この例から読み取れること

```
9月上旬  相談・申請
   ↓ 約1か月（認定に原則30日以内）
10月上旬 認定結果
   ↓ 約3週間（ケアプラン作成・会議・契約・計画作成）
11月    サービス提供開始（＝売上が発生）
   ↓ 約2か月（請求 → 審査 → 入金）
翌1月   入金

  相談から入金まで、およそ 4〜5か月
```

> **【Inference】この時間軸が示していること**
> - 新規の利用者が増えても、**その売上が現金になるのは数か月先**です。
> - 一方、職員の給与は毎月支払われます。
> - このため、介護事業所の資金繰りは「**今の入金は2か月前の仕事の分**」という前提で組み立てられます。
> - 逆に、利用者が急に減った場合も、その影響が現金として現れるのは2か月後です。
>   **業績の悪化に気づくのが遅れやすい構造**である、ともいえます。
>
> 金額面の詳細は `08_money.md` `12_business-model.md` で扱う想定です。

### 3つの流れの名前（後続ファイルで参照するためのステップ名）

|---|---|
| **A. 利用開始まで** | ①問い合わせ ②ケアマネジャーからの照会 ③見学・体験 ④アセスメント ⑤ケアプランへの位置づけ ⑥サービス担当者会議 ⑦契約・重要事項説明 ⑧個別援助計画の作成 ⑨利用開始 |
| **B. 日々のサービス提供** | 送迎（往路）→バイタル測定→入浴→食事→機能訓練→介護記録の記載→送迎（復路）→家族への報告／ケアマネジャーへの報告→モニタリングへの協力 |
| **C. 介護報酬請求サイクル** | ①実績の確定 ②国保連へ請求（翌月10日まで） ③利用者負担分の請求 ④審査・返戻 ⑤入金（約2か月後） ⑥消込・過誤対応 |

### 介護固有のトピック（後続で深掘りする論点）

- **介護記録**：報酬の根拠であり、事故時の事実の記録。完結の日から2年間保存。
- **個別援助計画**：作成 → 説明 → 同意 → 交付 → 実施状況の記録。
- **加算・減算**：体制届と実施記録の両方が必要。減算は気づかないうちに該当しうる。
- **事故報告**：市町村・家族・居宅介護支援事業者等へ連絡し、記録する。様式は市町村により異なる【Varies】。
- **身体拘束の原則禁止**：例外は「生命又は身体を保護するため緊急やむを得ない場合」に限る。記録が義務。
- **感染症・食中毒対策**：委員会をおおむね6月に1回以上、指針の整備、研修及び訓練を定期的に。
- **BCP（業務継続計画）**：策定義務、周知、研修及び訓練を定期的に、定期的な見直し。未策定は減算。
