## 12-0. 最初に：この章の数値の扱いについて【重要】

### 1単位あたりの円換算額は、本資料では確定した金額を示しません

【Fact】介護保険法第41条第4項第1号は、費用の額の算定に当たり
「当該指定居宅サービスの内容、**当該指定居宅サービスの事業を行う事業所の所在する地域等を勘案して**算定される
当該指定居宅サービスに要する平均的な費用…の額を勘案して**厚生労働大臣が定める基準**」によるとしています
（出典：介護保険法第41条第4項第1号／e-Gov法令検索）。

【Fact】実務上、この「地域」は**1級地・2級地・3級地・4級地・5級地・6級地・7級地・その他**の
**8区分**に整理されており、事業所は体制届の「地域区分」欄で届け出ます
（出典：介護給付費算定に係る体制等に関する届出等における留意点について（令和8年度介護報酬改定関係）／厚生労働省）。

> **【Varies】級地ごとの1単位あたりの円単価を示す一次資料（厚生労働大臣告示）は、本調査では取得できていません**
> （`19_sources.md` §5 に記録済み）。
>
> **したがって、この章の計算例では次のようにします。**
> - **【Example】説明のため「1単位＝10円」として計算します。**
> - **実際の1単位あたりの単価は、地域区分とサービス種類により異なります【Varies】。**
> - この前提は `01_overview.md` 1-5、`04_end-to-end-process.md`、`08_money.md` と同じです。

### 区分支給限度基準額の金額も示しません

【Fact】介護保険法第43条第2項は、区分支給限度基準額を
「要介護状態区分に応じた標準的な利用の態様…等を勘案して**厚生労働大臣が定める額**とする」としています。
**要介護度別の具体的な単位数を示す一次資料は取得できていないため、金額は記載しません**【Varies】。

### 経営指標（人件費率等）の数値も示しません

`19_sources.md` §5 のとおり、事業所の初期投資額・人件費率などの経営指標は本調査の範囲外です。
**質的な構造のみを記述し、数値は示しません**【Varies】。

## 12-1. 売上の基本式

### 介護事業所の売上は、3つの要素の掛け算でできている

```
   売上（介護報酬）  ＝  単位数  ×  1単位あたりの単価  ×  利用者数（利用回数）
                         │          │                    │
                         │          │                    └─ 事業所が増やせる部分
                         │          └─ 【Fact】地域区分により決まる（事業所は選べない）
                         └─ 【Fact】公定価格。全国共通（事業所は選べない）

   ＋ 実費収入（食費・おむつ代等）  ← 【Fact】介護保険の外（基準第96条第3項）
```

> **この式が示す、介護事業の決定的な特徴**
> 3つの要素のうち、**事業所が動かせるのは「利用者数（利用回数）」だけ**です。
> - 単位数：【Fact】公定価格。同じサービスを同じ時間提供すれば、どの事業所でも同じ
> - 単価　：【Fact】事業所の所在する地域で決まる（法第41条第4項第1号）
> - 利用者数：**ここだけが事業所の動き方で変わる**
>
> ただし、単位数には**加算・減算**が乗ります（12-4）。
> つまり正確には「**利用者数**」と「**加算・減算の該当状況**」の2つが変数です【Inference】。

### 通所介護の単位数の決まり方

【Fact】通常規模型の通所介護（7時間以上8時間未満）の基本部分は次のとおりです
（出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。

| 要介護度 | 1日あたりの単位数 |
|---|---|
| 要介護1 | 658単位 |
| 要介護2 | 777単位 |
| 要介護3 | 900単位 |
| 要介護4 | 1,023単位 |
| 要介護5 | 1,148単位 |

> **2つの軸で単位数が決まる**
> ```
> 【軸1】提供時間の区分   3時間以上4時間未満 〜 8時間以上9時間未満
> 【軸2】要介護度         要介護1 〜 要介護5
> ```
> つまり、**同じ1日でも、誰が来たかによって売上が変わります。**
> 要介護5の人が1日来るのと、要介護1の人が1日来るのでは、単位数が約1.7倍違います
> （1,148 ÷ 658 ≒ 1.74）。

### 訪問介護の単位数の決まり方【対比】

【Fact】訪問介護の身体介護（基本部分）は次のとおりです（同上）。

| 所要時間 | 単位数 |
|---|---|
| 20分未満 | 163単位 |
| 20分以上30分未満 | 244単位 |
| 30分以上1時間未満 | 387単位 |
| 1時間以上1時間30分未満 | 567単位（以降30分を増すごとに ＋82単位） |

【Fact】生活援助は、20分以上45分未満が179単位、45分以上が220単位です（同上）。

> **数える単位が違う**
> ```
> 通所介護： 1日ごと × 提供時間区分 × 要介護度
> 訪問介護： 1回ごと × 所要時間区分 × 身体介護／生活援助の別
> ```
> 【Inference】訪問介護では、**要介護度によって1回あたりの単位数が変わりません**。
> 変わるのは「何分の訪問か」「身体介護か生活援助か」です。
> これは、訪問介護が「その人に何をしたか」で数えるのに対し、
> 通所介護が「その人を1日受け入れた」ことで数えるという、数え方の違いによります。

## 12-2. 稼働率 ── 通所介護の収入を決める最大の要素

### 稼働率とは何か

> **用語：稼働率（かどうりつ）**
> → 利用定員に対して、実際に何人が利用したかの割合。
> → 計算：**稼働率 ＝ 1日平均利用者数 ÷ 利用定員**
> → 実務例：定員30名の事業所に、その日25名が来た → 25 ÷ 30 ≒ 83.3%
> → なぜ見るのか：【Inference】定員は法令と設備で決まっており、簡単には増やせない。
>    したがって、**決まった器をどれだけ埋められたか**が収入をほぼ決める。

### なぜ定員を簡単に増やせないのか

【Fact】指定居宅サービス等基準第95条第2項第1号イは
「食堂及び機能訓練室は、それぞれ必要な広さを有するものとし、その**合計した面積は、
三平方メートルに当該指定通所介護事業所の利用定員…を乗じて得た面積以上**とすること」と定めています。

【Fact】同基準第102条は
「指定通所介護事業者は、**利用定員を超えて指定通所介護の提供を行ってはならない**。
ただし、災害その他のやむを得ない事情がある場合は、この限りではない」としています
（出典：同基準第102条／e-Gov法令検索）。

【Fact】さらに、介護報酬の算定構造には
「**利用者の数が利用定員を超える場合**」という減算項目が置かれています
（出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。

```
  定員を増やしたい
      → 【Fact】食堂＋機能訓練室の面積が「3㎡ × 定員」以上必要（基準第95条第2項第1号イ）
      → 物件の広さが定員の上限を決めてしまう
      → 【Fact】人員配置基準も利用者数に応じて増える（基準第93条第1項第3号）

  定員を超えて受け入れる
      → 【Fact】基準第102条「利用定員を超えて…提供を行ってはならない」
      → さらに定員超過は減算の対象
```

> **つまり、通所介護は「上限が固定された器」を運営する事業です**【Inference】。
> 売上を伸ばす方向は、**器を埋めること**（稼働率）と、**単位数を上げること**（要介護度の構成・加算）に
> 限られます。

### 稼働率が下がる要因【Typical】

| 要因 | 何が起きるか |
|---|---|
| **当日キャンセル** | その日の1人分の単位数が失われる。食材費は残ることがある |
| 利用者の入院・入所 | 長期にわたって利用が止まる |
| 利用者の死亡・転居 | 利用が終了する |
| ケアプランの変更 | 回数が減る／他事業所に変わる |
| 新規の利用者が入らない | 減った分を埋められない |
| 曜日の偏り | 月・水・金は満員だが火・木は空いている、という状態【Typical】 |

> **「曜日の偏り」という、通所介護に特徴的な問題**
> 【Inference】稼働率は「月平均」で見ると実態が見えないことがあります。
> 定員30名の事業所で、月曜30名・火曜15名という状態なら、
> 平均は22.5名でも、**火曜は器が半分空いている**わけです。
> 職員は曜日ごとに必要な人数を配置しなければならず、
> 【Fact】介護職員の必要数は利用者数に応じて決まります（基準第93条第1項第3号）。
> だから `05_departments.md` ①-13（稼働率・利用定員の管理）は
> **曜日別**に予約人数と定員を突き合わせる業務になります。

### 訪問介護では「稼働」の意味が変わる【対比】

| | 通所介護 | 訪問介護 |
|---|---|---|
| 器にあたるもの | **利用定員**（設備と人員で決まる） | **訪問介護員が働ける時間**（人で決まる） |
| 稼働の指標 | 定員に対する利用者数 | 【Typical】1人のヘルパーが1日に何件回れたか／登録利用者に対する訪問件数 |
| 収入が止まる要因 | 定員割れ、当日キャンセル | 訪問の中止、**訪問介護員を確保できず訪問に入れない** |

> 【Inference】訪問介護では、利用の希望があっても、
> その時間に行ける訪問介護員がいなければ売上になりません。
> つまり、**制約が「箱」ではなく「人の時間」**にあります。

## 12-3. 人件費 ── 法令が下限を決めている費用

### 構造

【Fact】`03_company-structure.md` 3-2 で見たとおり、通所介護の介護職員の員数は
「…介護職員…が**勤務している時間数の合計数**を当該指定通所介護を提供している時間数で除して得た数が、
利用者の数が**十五人までの場合にあっては一以上**、**十五人を超える場合にあっては
十五人を超える部分の数を五で除して得た数に一を加えた数以上**確保されるために必要と認められる数」とされています
（指定居宅サービス等基準第93条第1項第3号）。

【Fact】同条第2項は「介護職員を、**常時一人以上**当該指定通所介護に従事させなければならない」。
【Fact】同条第6項は「**生活相談員又は介護職員のうち一人以上は、常勤でなければならない**」。
【Fact】同基準第94条は「専らその職務に従事する**常勤の管理者**」。
【Fact】同基準第93条第1項第2号は看護職員「**一以上**」、同項第4号は機能訓練指導員「**一以上**」。

### この構造が収益に与える意味【Inference】

```
【一般の会社】
   売上が減る → 人件費を減らす判断ができる → 利益を守れる

【介護事業所】
   利用者が減る → 必要な人員数の下限はある程度下がるが、
                  【Fact】常勤の管理者、常時1人以上の介護職員、看護職員1以上、
                  機能訓練指導員1以上 といった「利用者数にかかわらず必要な職種」は残る
                → 売上の減り方に比べて、人件費は同じ割合では減らない
```

> **人件費が「固定費に近い性格」を持つ理由**
> 【Inference】人員配置基準の一部は利用者数に連動しますが（介護職員）、
> 一部は利用者数にかかわらず必要です（管理者、看護職員、機能訓練指導員、常勤要件）。
> つまり、**稼働率が下がっても減らせない人件費がある**ということです。
>
> さらに、基準を下回れば
> 【Fact】「**看護・介護職員の員数が基準に満たない場合**」の減算に該当します
> （出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。
> **人を減らして費用を抑えると、単価そのものが下がる**という構造です。
>
> **本資料は「人件費率が高いことが問題だ」といった評価は書きません。**
> ここで説明しているのは、**法令が費用の下限を決めているという構造**です。

### 人件費以外の費用【Typical】

`08_money.md` 8-7 の一覧のとおりです。要点だけ再掲します。

| 費目 | 稼働率との関係【Inference】 |
|---|---|
| 人件費 | 一部は利用者数に連動するが、下限がある |
| 送迎の燃料費・車両費 | ルートが同じなら、利用者が減っても大きくは減らない |
| 食材費 | 利用者数に連動する（ただし当日キャンセルは間に合わないことがある） |
| 消耗品費 | 利用者数に連動する |
| 家賃・水道光熱費・設備 | 利用者数にほとんど連動しない |

> **利用者が1人減ったときに何が起きるか【Inference】**
> ```
> 売上   ：その人の単位数 × 単価 の分だけ減る（＋食費の実費も減る）
> 食材費 ：1人分減る
> 人件費 ：ほとんど減らない
> 家賃等 ：まったく減らない
> ```
> つまり、**稼働率の変動が、そのまま利益の変動に近い形で表れます。**

## 12-4. 加算・減算の積み上げが収益に効く構造

### 構造としての説明

```
  基本報酬（提供時間区分 × 要介護度）   ← 全国共通
       ＋ 加算（要件を満たす取組をした場合に算定できる）
       − 減算（基準を満たしていない場合に引かれる）
  ────────────────────────────────
  ＝ その月の単位数
```

【Fact】通所介護の加算には、入浴介助加算、中重度者ケア体制加算、個別機能訓練加算、
栄養アセスメント加算、栄養改善加算、口腔機能向上加算、科学的介護推進体制加算などがあります
（出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。

【Fact】減算には、利用定員超過、看護・介護職員の員数が基準に満たない場合、
高齢者虐待防止措置未実施減算、業務継続計画未策定減算、事業所が送迎を行わない場合 などがあります（同上）。

### なぜ「積み上げ」なのか

【Inference】基本報酬は全国共通です。つまり、
**同じ利用者が同じ時間だけ来れば、どの事業所でも基本部分の単位数は同じ**です。

したがって、事業所ごとの単位数の差は
- どの加算を算定しているか
- 減算に該当していないか

という2点から生じます。

> **ただし、本資料は「どの加算を取るべきか」を一切提案しません。**
> `common/methodology.md` §0 の定めによります。
>
> ここで説明しているのは、**加算・減算という仕組みが収益構造の一部として存在する**という事実です。

### 加算には「要件を満たす取組」と「記録」が伴う

【Typical】加算を算定するには、一般に次の両方が必要です（`04_end-to-end-process.md` 介護固有トピック(2)）。

```
① 体制を整え、指定権者に体制届を提出する
   （届出をした月の翌月から算定できるのが通例【Varies：届出の取扱いは加算により異なる】）
② 実際にその要件を満たす取組を行い、**記録に残す**
```

> **加算は「収入が増えるだけ」ではない**
> 【Inference】多くの加算には、職員の配置、計画の作成、実施と記録といった業務が伴います。
> つまり、加算を算定することは**費用（主に人の時間）も伴う**ということです。
> これも、収益構造として理解しておくべき点です。
>
> なお、**どの加算がどれだけの費用を伴うかを具体的に比較することは、本資料の範囲外です**【Varies】。

### 減算の非対称性

| | 加算 | 減算 |
|---|---|---|
| 性質 | 取りに行くもの | **気づかないうちに該当してしまうもの** |
| きっかけ | 事業所が判断して体制を整える | 職員の退職、研修の未実施、計画の未策定 など |
| 気づき方 | 意図的 | 【Inference】誰かが点検しなければ気づかない |

> 【Fact】だから `05_departments.md` ①-6 には
> 「減算に該当していないかの点検」という業務が、**月次**で置かれています。

## 12-5. 【Example】S デイサービスセンターの収入構造を組み立てる

> **【Example】以下はすべて説明用の架空の計算です。実在事業所のデータではありません。**
> **1単位＝10円として計算します。実際の単価は地域区分により異なります【Varies】。**
> 加算は説明を簡単にするため含めていません。

### 前提

```
利用定員        30名
1日平均利用者数  25名（稼働率 25 ÷ 30 ≒ 83.3%）
営業日          月曜〜土曜（この例では月25日として計算する）
提供時間        7時間以上8時間未満
要介護度の構成   説明のため、平均して要介護2相当（777単位／日）とする【Example】
食費            1回700円
利用者の負担割合  説明のため全員1割とする【Example】
```

### ステップ1：1日の単位数

```
777単位 × 25名 = 19,425単位／日
```

### ステップ2：1か月の単位数

```
19,425単位 × 25日 = 485,625単位／月
```

### ステップ3：円に換算する

```
485,625単位 × 10円 = 4,856,250円／月  ← 介護報酬（サービスの費用額）

  ├─ 利用者負担（1割）    485,625円 → 利用者から直接。翌月に回収【Typical】
  └─ 保険給付分（9割）  4,370,625円 → 国保連へ請求。約2か月後に入金【Typical】
```

### ステップ4：実費（介護保険の外）を加える

```
食費 700円 × 25名 × 25日 = 437,500円／月  ← 【Fact】基準第96条第3項第3号

月の収入合計 = 4,856,250円 + 437,500円 = 5,293,750円
```

### 稼働率が変わると何が変わるか【Example】

```
【稼働率 83.3%（25名）】 485,625単位 × 10円 = 4,856,250円
【稼働率 90.0%（27名）】 777 × 27 × 25 = 524,475単位 × 10円 = 5,244,750円  （＋388,500円）
【稼働率 70.0%（21名）】 777 × 21 × 25 = 407,925単位 × 10円 = 4,079,250円  （−777,000円）
```

> **【Inference】この差が意味すること**
> 利用者が4名減っただけで、月の介護報酬が約78万円減ります。
> 一方、12-3 で見たとおり、人件費・家賃・設備の費用はほとんど減りません。
> **稼働率の変動は、ほぼそのまま利益の変動になります。**
>
> だから `14_kpi.md` で扱うKPIの中心が「稼働率」になります。

### 要介護度の構成が変わると何が変わるか【Example】

```
【全員が要介護2（777単位）】 777 × 25 × 25 = 485,625単位
【全員が要介護4（1,023単位）】1,023 × 25 × 25 = 639,375単位  （＋153,750単位＝＋1,537,500円）
【全員が要介護1（658単位）】  658 × 25 × 25 = 411,250単位   （−74,375単位＝−743,750円）
```

> **【Inference】同じ人数でも収入が変わる**
> 要介護度が重い人ほど単位数が大きくなります。
> ただし、要介護度が重い人は**介助に手がかかる**ため、必要な人員も変わりえます。
> また、【Fact】通所介護には「中重度者ケア体制加算」という加算項目があります
> （出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。
>
> **本資料は「どういう利用者を受け入れるべきか」という提案は書きません。**
> ここで示しているのは、**要介護度の構成が単位数に影響する**という構造です。

### 居宅介護支援の収益構造が特殊である理由

【Fact】`01_overview.md` 1-6 のとおり、居宅介護支援は次の3点で他と違います。

1. 【Fact】**利用者負担がない**（法第46条は「百分の九十」という定めを置いていない）。10割が保険から給付される
2. 【Fact】**他の事業者のサービスを計画に位置づける立場**にある（法第8条第24項）
3. 【Fact】**管理者は原則として主任介護支援専門員**でなければならない（指定居宅介護支援等基準第3条第2項）

> **収益構造としてどう効くか【Inference】**
> - **月額報酬**なので、提供の回数が直接には売上にならない。
>   代わりに、**担当できる利用者の数**が売上の上限を決める。
> - 【Fact】担当件数は「利用者の数が**四十四**又はその端数を増すごとに一」
>   （一定の情報処理システムを利用し、かつ事務職員を配置している場合は「**四十九**又はその端数を増すごとに一」）
>   と条文で定められている（指定居宅介護支援等基準第2条第2項）。
> - 【Fact】居宅介護支援には「**特定事業所集中減算**」という減算項目が置かれている
>   （出典：介護報酬の算定構造のイメージ（R8.6.1）／厚生労働省）。

### 施設系の収益構造【Varies】

**本資料では、施設系（介護老人福祉施設・特定施設入居者生活介護）の人員基準・報酬の詳細を扱いません**
（`19_sources.md` §5 に記録済み。条文を取得していないため）。

構造として確認できていることのみ記します。

- 【Fact】1施設当たりの定員と利用率が統計で公表されている
  （介護老人福祉施設70.4人・利用率94.5%、介護老人保健施設87.0人・88.2%、介護医療院58.2人・91.1%。
  出典：令和6年介護サービス施設・事業所調査の概況 表3／厚生労働省）
- 【Inference】上記の利用率は、施設系では**空床が収入に直結する**ことを示している

### 障害福祉サービスの収益構造【Varies】

【Fact】障害者の日常生活及び社会生活を総合的に支援するための法律第29条第3項第2号は、
利用者負担について「**家計の負担能力をしん酌して政令で定める額**」とし、
その額が「百分の十に相当する額を超えるときは、当該相当する額」とする旨を定めています
（出典：同法第29条第3項／e-Gov法令検索）。これが実務でいう**応能負担**です。

> **介護保険との決定的な違い**
> ```
> 介護保険    ： 利用した額に対して1〜3割（応益負担の考え方）
> 障害福祉    ： 【Fact】家計の負担能力をしん酌して政令で定める額（応能負担）。百分の十が上限
> ```
> 【Fact】実際の数値として、令和7年3月の障害福祉サービスの利用者負担額は
> 総費用額2,774.4億円に対して7.5億円（**総費用額の0.27%**）でした
> （出典：障害福祉サービス、障害児給付費等の利用状況について（令和7年7月11日）／厚生労働省）。
>
> 【Inference】つまり、障害福祉サービスでは**事業者の収入のほとんどが給付費**であり、
> 利用者から直接受け取る額の比重が、介護保険よりはるかに小さいことが分かります。

【Fact】障害福祉サービスの人員基準の詳細（指定障害福祉サービス基準。平成18年厚生労働省令第171号）は
本調査では条文を取得していないため、扱いません【Varies】。

## 12-7. 利益が出るまでの構造（まとめの図）

```
【収入】
   単位数（公定価格）
      × 地域区分による単価（【Fact】法第41条第4項第1号。金額は本資料では示さない【Varies】）
      × 利用者数・利用回数        ← ★事業所が動かせる主な変数
      ± 加算・減算                ← ★もうひとつの変数
   ＝ 介護報酬
      ├─ 利用者負担 1〜3割 → 利用者から直接（翌月に回収【Typical】）
      └─ 保険給付分 7〜9割 → 国保連経由（**約2か月後**に入金【Typical】）
   ＋ 実費（食費・おむつ代等）→ 利用者から直接（【Fact】基準第96条第3項）

【費用】
   人件費                        ← ★【Fact】人員配置基準が下限を決めている（基準第93条ほか）
   送迎（燃料・車両・保険・点検）
   食材費・給食委託費【Varies】
   消耗品費（おむつ・手袋・リネン 等）
   建物（家賃・水道光熱費。浴室があるため水道・ガスの比重が大きい【Inference】）
   設備・備品・システム利用料
   その他（通信・保険・専門家報酬・研修 等）

【利益】
   収入 − 費用

【現金】
   利益が出ていても、保険給付分は約2か月後にしか現金にならない
   → **資金繰りは利益とは別に管理する必要がある**（`08_money.md` 8-8）
```

## 12-8. この収益構造から見える、介護事業の性格【Inference】

**以下はすべて構造の説明であり、良し悪しの評価ではありません。**

| 性格 | 根拠 |
|---|---|
| **価格競争が起きにくい** | 【Fact】単位数は公定価格で全国共通（法第41条第4項）。事業所が値引きする対象がない |
| **立地が収入に直接影響する** | 【Fact】単価は事業所の所在する地域で決まる（法第41条第4項第1号、地域区分8区分）。さらに送迎範囲・利用者の分布が稼働率を左右する【Inference】 |
| **売上の上限が設備で決まる（通所・施設）** | 【Fact】定員は面積で制約され（基準第95条第2項第1号イ）、定員超過は禁止（基準第102条）かつ減算 |
| **費用の下限が法令で決まる** | 【Fact】人員配置基準（基準第93条ほか）。下回れば減算 |
| **収入の前提が3年周期（＋期中改定）で入れ替わる** | 【Fact】法第117条第1項「三年を一期とする」／令和8年度の期中改定＋2.03% |
| **現金化が遅い** | 【Fact】請求は翌月10日まで（請求に関する命令第3条第1項）。【Typical】入金は約2か月後 |
| **記録が売上の裏付けになる** | 【Fact】記録義務（基準第19条第2項）＋運営基準に照らした審査（法第41条第9項） |

## この章のまとめ

- **売上＝単位数 × 1単位あたりの単価 × 利用者数（利用回数）** ＋ 実費収入。
  単位数は**公定価格**、単価は**地域区分**で決まる。
  **事業所が動かせるのは「利用者数」と「加算・減算の該当状況」**。
- **1単位あたりの円換算額は本資料では示さない。**
  計算例は**【Example】1単位＝10円**として行い、**実際は地域区分により異なる【Varies】**。
- 通所介護の収入は**稼働率（定員に対する利用者数）**がほぼ決める。
  定員は【Fact】面積（3㎡×定員。基準第95条第2項第1号イ）で制約され、
  【Fact】定員超過は禁止（基準第102条）かつ減算の対象。
- **人件費は法令が下限を決めている**（【Fact】基準第93条・第94条）。
  減らせば【Fact】「看護・介護職員の員数が基準に満たない場合」の減算に該当し、単価が下がる。
- **加算の積み上げが単位数を左右する**が、**本資料はどの加算を取るべきかを提案しない**。
  加算には要件を満たす取組と記録が伴う。減算は気づかないうちに該当しうる。
- Level 2 の違いは「**何を数えて売上にするか**」と「**収入の上限を決めるもの**」で整理できる。
  訪問介護＝人の時間／通所介護＝定員／施設系＝入所定員（空床が直結）／
  居宅介護支援＝**月額報酬・担当件数・利用者負担なし**／障害福祉＝**応能負担**。

次章 `13_periodic-work.md` では、これらを回すために何を、どの頻度で行っているのかを整理します。
